# PRODUCT.md — 平静实验室知识库 (Peace Lab Database) · GTM 页面

## 产品

身心疗愈与个人进化专业知识库，与结构化课程（直接认知冥想课程等）相结合。当前规模：4,922+ 篇文档，398+ 专题，1,160,183+ 行，24 件 Agent Skills（8 个模块），统计截至 2026-08。整库亦作为泛疗愈智能体的具身智能语料库（Embodied Agent Corpus）。

## 平台

Web。纯静态 HTML+CSS+JS，入口 `GTM/index.html`，无构建步骤、无运行时依赖。

## 访客与各自行动

1. **学习者**：按六大支柱与十条学习路径进入内容，行动 = 开始探索 / 查看学习路径。
2. **AI 开发者**：将语料库与 Agent Skills 接入智能体，行动 = 查看 Agent Skills / 查看整库索引；语料四层（冥想引导词库、课程全文本、术语与检索层、安全边界层）。
3. **机构与合作方**：评估内容体系与许可，行动 = 查阅术语表 / 查看许可。
4. **公众与危机需求者**：立即获得帮助，行动 = 危机资源（tel:12356 等），页脚常驻危机资源带。

页面数字只允许来自仓库实况（INDEX.md、README.md 统计），禁止发明商业声明。危机资源为强制项，任何改版不得移除。许可 CC BY-NC-SA 4.0，引用署名 Peace Lab Global。
