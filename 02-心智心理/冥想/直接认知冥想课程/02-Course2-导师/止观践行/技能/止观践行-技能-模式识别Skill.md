# 止观践行模式识别技能

## 技能信息

**技能ID**: S_025
**技能名称**: 模式识别
**功能**: 分析止观践行笔记，识别修行模式、表达模式与思维模式，运用中观唯识框架深度解析，输出结构化分析报告与实用改进建议
**输入**: 止观践行笔记（周记/每日践行记录）文本
**输出**: 模式识别分析报告 + 个性化修行指导

---

## 分析工作流

```
分析流程

STEP 1: 通读笔记，提取事实
│
├─ 梳理笔记范围（周次、天数、事件清单）
├─ 提取每个事件的"发生了什么-怎么做的-结果如何"
└─ 标记原文关键句（金句、比喻、情绪词）

STEP 2: 修行模式识别
│
├─ 按五大类别分类（见修行模式分类表）
├─ 统计各类出现频次与分布
└─ 标注代表实例（引用原文）

STEP 3: 表达模式分析
│
├─ 描述方式：叙述体还是概念化
├─ 语言特点：白话、比喻系统、金句密度
├─ 情感表达：直接与含蓄、觉察分离度
├─ 叙事结构：时间线、顿悟弧线
└─ 写作规范检查：标点、引语、框架融入

STEP 4: 思维模式识别
│
├─ 对照思维模式识别表逐项排查
├─ 找出反复出现的思考习惯与认知偏差
└─ 区分健康觉察与惯性运作

STEP 5: 中观唯识深度解析
│
├─ 三性说映射：事件 → 依他起/遍计所执/圆成实
├─ 八识认知链条：六识分别→七识执我→八识种习气
├─ 中观见地检查（八不检查表）
└─ 修行阶段定位（觉察→分析→看透→放下→转化→安住）

STEP 6: 生成报告
│
├─ 按输出模板生成结构化报告
└─ 建议必须具体、可执行、锚定笔记原文
```

## 修行模式分类表

| 类别 | 定义 | 识别线索 | 示例（取自本课程笔记） |
|:-----|:-----|:---------|:----------------------|
| 禅修方法 | 具体练习方法 | 数息、吐气计数、观想、听引导音频、读经典 | 吐气计数 1-8 升降序 |
| 觉察技巧 | 面对念头与情绪的技术 | 标记、只是看着、不抓、不迎不拒、停息 | 第二支箭悬在头上，不去抓下来 |
| 心境变化 | 状态记录 | 平静、清明、恐惧、散乱、渴爱、孤独 | 定力渐长，少了烂事 |
| 生活践行 | 日常场景中的应用 | 会议、跑步、社交、阅读、睡眠 | 关掉老友记，接纳本来的平静 |
| 理论内化 | 用教理理解自身经验 | 三性说、八识、唯识的思考 | 唯识唯的是眼镜，不是桌子 |

**判定标准**：每个模式必须能用"发生了什么-怎么做的-结果如何"三要素坐实，找不到三要素的不计入模式，只算散记。

## 表达模式分析维度

| 维度 | 观察点 | 健康信号 | 警示信号 |
|:-----|:-------|:---------|:---------|
| 描述方式 | 叙述体 vs 概念化 | 事件锚定、细节具体、有场景 | 抽象空转、贴标签、无事实 |
| 语言特点 | 白话程度、比喻系统、金句密度 | 比喻服务于领悟，金句由经验长出 | 比喻替代思考，金句空洞堆砌 |
| 情感表达 | 直接/含蓄、情绪与觉察的分离度 | 情绪可被看见而不淹没 | 情绪倾泻无觉察，或完全压抑回避 |
| 叙事结构 | 时间线、顿悟弧线 | 起承转合自然，问题-反转-领悟 | 记录断裂、回避冲突话题 |

**写作规范检查**（本课程三规范）：
- 标点：只用逗号句号（发现破折号、分号、冒号、顿号、引号即违规）
- 引语：以"有句话说"引导（直接使用引号即违规）
- 框架：佛教概念自然融入经验叙述，禁止概念解释段落

## 思维模式识别表

| 模式 | 特征 | 中观唯识解读 | 识别示例 |
|:-----|:-----|:-------------|:---------|
| 自我反诘 | 用问题逼问自己 | 第六识分别转向自我觉察 | 凭什么信这面镜子 |
| 类比推理 | 用比喻理解复杂经验 | 依他起的善巧分别 | 两扇门进同一座大厦 |
| 向内归因 | 从心上找答案 | 唯识的修行入口 | 这几年我的问题回到了里面 |
| 自我证明 | 需要验证自身价值 | 遍计所执的我执运作 | 证明自己是美玉才肯雕琢 |
| 灾难化想象 | 放大最坏可能 | 依他起事实被遍计加工 | 猝死新闻→不敢跑步 |
| 渴爱抓取 | 想要→念头有去处 | 第八识种子的现行熏习 | 想要，念头就有了去处 |
| 模式化他见 | 看穿他人运作模式 | 觉察力外放（定力的运用） | 在别人的模式里拿到结果 |
| 见地成熟 | 对法、师、我的关系清醒 | 依法不依人，指头非月亮 | 他悟的是他的，我跪的是我的 |

**排查要点**：
- 找出跨周反复出现的同类思维（那才是"模式"，单次不算）
- 区分"觉察到模式"（健康）与"被模式带着走"（惯性）
- 注意思维模式与修行模式的联动：如"灾难化想象"如何阻碍"跑步践行"

## 中观唯识深度解析框架

### 1. 三性说映射

对每个关键事件建立映射表：

| 笔记事件 | 依他起性（缘起事实） | 遍计所执性（执着加工） | 圆成实性（本然显现） |
|:---------|:---------------------|:----------------------|:---------------------|
| 示例：会议没叫我 | 会议召开，未收到邀请 | 暗自纳闷甚至难受，"我该被叫" | 看着箭悬着不抓，随后没有然后 |

要点：
- 依他起对应前六识，因缘聚合无固定本质，不可完全控制，只能调环境（选择浸泡的环境，环境熏习意识）
- 遍计所执对应第七识，恒审思量，计度分别，执我执我所，多是不经过头脑的惯性力量，是修心真正关键点
- 圆成实对应第八识，来什么储藏什么，不预见不计较，无需调整，乌云散去光芒自现

### 2. 八识认知链条

对一个觉察事件标出认知链条：

```
前五识接触外境 → 第六识分别（建构标准）→ 第七识执我（计度、抓取）
→ 觉察即破（看见执着本身）→ 破即熏习（向第八识种下新种子）
```

- 若笔记只记录到"分别"或"执我"而未到"觉察"，说明觉察滞后，是下一步修行要点
- 若笔记出现"看到自己在想""看着它悬在那里"，即链条在"觉察即破"处截断

### 3. 中观见地检查（八不检查表）

| 检查项 | 落入常见的表现 | 落入断见的表现 | 中观正见 |
|:-------|:---------------|:---------------|:---------|
| 不常 | 把暂时心境当作永久的我 | — | 心境缘起，无常住实体 |
| 不断 | — | 否认修行成果"一点没进步" | 种子相续，功不唐捐 |
| 不一 | 把某次经验当作全部 | 把某次失败当作定局 | 一即一切，经验是暂时的显现 |
| 不来不去 | 执念于回到过去好状态 | 畏惧未来变化 | 现在法即当下，无来无去 |
| 缘起性空 | 标准（快慢好坏）被第六识建构为绝对 | 否定因果作用 | 急躁非事物本有属性，快慢皆缘起 |
| 二谛 | 把修行结果当真 | 把修行本身当空而废修 | 世俗谛认真践行，胜义谛不执结果 |

### 4. 修行阶段定位

六步定位：觉察 → 分析 → 看透 → 放下 → 转化 → 安住

- 逐事件判断练习停在哪一步
- 统计各阶段占比，指出最常停留的阶段与下一步
- 常见滞后：只到"觉察"不到"放下"（看见了仍抓着）；或跳步（未觉察就谈放下）

## 使用示例

### 输入

第五周.md（止观践行 DAY 1-7，主题：唯识三性说）

### 生成的报告（节选）

```
【止观践行模式识别报告】

一、分析概览
   - 笔记范围: 第五周 DAY 1-7，含课程总结与每日践行
   - 整体印象: 从"被动承受执着"转向"主动看着执着"，三性说已活用于日常

二、修行模式识别
   - 禅修方法: 吐气计数 1-8 升降序（每日两次以上）、30分钟数息（DAY2）、听冥想音频
   - 觉察技巧: 第二支箭观察（会议事件）、不迎不拒（跑步与恐惧共处）、看清"想要"（DAY7）
   - 心境变化: 定力渐长（DAY1）→ 看见渴爱（DAY7），从处理事件到处理根源
   - 生活践行: 关掉老友记、极慢跑、互助对象散步、朋友圈环境选择
   - 理论内化: 三性说活学活用，唯识之唯的深度思考（DAY4）

三、表达模式分析
   - 描述方式: 叙述体为主，事件锚定（会议、猫酒吧、关音频），概念解释极少
   - 语言特点: 大白话，比喻系统成熟（第二支箭、乌云、眼镜、指头与月亮）
   - 情感表达: 觉察与情绪分离度高（"看着箭悬着，然后没有然后了"）
   - 写作规范: 标点、引语、框架融入均合规

四、思维模式识别
   - 反复模式: 自我反诘（凭什么信这面镜子）、向内归因（问题回到里面）
   - 认知偏差: 自我证明（美玉/瓦砾/抹布）、灾难化想象（猝死新闻）
   - 健康觉察: 依法不依人，指头不是月亮（DAY7 见地成熟）

五、中观唯识深度解析
   - 三性说映射: 会议事件三性俱全，是遍计所执→觉察即破的完整示现
   - 八识链条: 链条在"觉察即破"处干净截断，未再熏入旧种子
   - 中观见地: 未落常见断见；对"唯"的思考已触及认知工程本质
   - 阶段定位: 多数事件已达"放下"与"转化"之间，DAY7 接近"安住"

六、整体发现
   1. 主线: 从事件处理（会议）推进到根源处理（渴爱）
   2. 进展: 觉察速度显著提升，第二支箭的滞留时间缩短
   3. 卡点: 灾难化想象仍会启动（跑步），且与健康担忧绑定
   4. 联动: 自我证明模式与"渴爱"同源，都是第七识在打方向盘

七、具体指导建议
   1. 首要: 跑步场景单独做一次"灾难化想象"标记练习，当张雪峰新闻念头生起时，不说"不要怕"，而是标记"这是依他起+遍计的复合念头，我看到你了"，与呼吸并行
   2. 次要: 把 DAY7 的"看清想要"从晚上扩展到白天，选一个固定触发点（如打开微信时）暂停三秒问"这一刻我想要什么"
   3. 长期: 保持"关掉老友记"式的小实验，每周一个，用行为巩固觉察成果

八、下周践行提示
   - 实验: 每天记录一次"第二支箭从生起到放下"的时长，看趋势是否缩短
```

## 注意事项

1. **理论准确性**：三性说、八识、八不中观的表述必须与课程及知识库一致，禁止自造概念
2. **客观深入**：所有判断必须引用笔记原文作证据；无证据不判断
3. **建议实用性**：每条建议必须能落地为具体动作（何时、何地、怎么做），禁止空泛的"继续加油"
4. **不替代导师**：本技能输出分析供参考，导师评语与课程指导优先
5. **尊重笔记边界**：不臆造笔记中不存在的细节，不补写用户未记录的内容

---

*模式识别是把镜子照向镜子本身。分析报告是第七识的尽职调查，但最终放下调查报告的，也是第七识。*
