# 烧烤冥想 · 首场直播带领师 Checklist（单页 · 首场直播用，日期以实际排期为准）

> 用途：上场前 2 小时逐项打勾。配合《烧烤冥想-首场直播带练脚本.md》与《烧烤冥想-首场物料包.md》使用。

---

## 一、时间轴

| 时点 | 事项 | ✓ |
|---|---|---|
| T-24h | 群发课前通知（文案见物料包） | ☐ |
| T-24h | 平台建好直播预约 + 开播提醒；测试推流一次（画质/音质/延迟） | ☐ |
| T-3h | 授权音乐歌单敲定（入场布鲁斯、炭火环境音、暖调钢琴，全部来自授权曲库） | ☐ |
| T-3h | 食材到位：五花肉 3–5 片、豆腐块、萝卜厚片、一杯温水；**多烤一份备用**（防止第一份翻车） | ☐ |
| T-2h | 设备架设 + 全流程彩排一遍（重点：音乐切换、音量、计时器；并演练一次音乐故障：无声人声带练） | ☐ |
| T-60min | 烤炉试火、试烤一片（彩排时吃掉也可，顺便练第一口） | ☐ |
| T-30min | 开播测试：推流正常、音画同步、音乐路由正常、弹幕可读 | ☐ |
| T-30min | 助教到位：分工确认、话术卡在手、时间节点提醒表在手 | ☐ |
| T-15min | 手机静音（勿扰模式）、计时器归零、提词器载入脚本、水杯在手边 | ☐ |
| T-10min | 音乐起 35dB、画面炭火特写、带领师深呼吸安顿自己 | ☐ |
| 0:00 | 开播（助教同步发入场弹幕） | ☐ |
| 下播后 | 群内发课后三问 + 微作业卡；收集反馈；10 分钟复盘（记录：时间偏差、哪段卡壳、弹幕热点） | ☐ |

## 二、设备与场景清单

- ☐ 相机/手机（固定中景，带领师与烤架同框；确认不会失焦）
- ☐ 麦克风（领夹/枪麦，**必须收音清晰**，冥想课音质即体验）
- ☐ 灯光（面部补光 + 炭火氛围灯；避免顶光阴影）
- ☐ 烤炉（小炭炉或电烤炉）+ 灭火毯放在镜头外一米内
- ☐ 计时器（大屏可见；勿用会响铃的手机闹钟）
- ☐ 提词器/平板（脚本载入，字号放大）
- ☐ 备用：热点/备用网络、备用麦克风、备用食材一份、插线板

## 三、音乐与声音路由（最容易翻车的一环）

1. **音乐必须走内录路由**（OBS 桌面音频/虚拟声卡混入直播流），**不要用蓝牙音箱外放**：外放会被麦克风二次拾音，声音发糊。
2. 三条音轨预设好：① 入场布鲁斯 35dB → ② 炭火环境音 15dB → ③ 暖调钢琴 20dB；切换点已在脚本里标出（2:00 / 7:00 / 25:00 / 28:00）。
3. 曲目全部来自授权曲库（Epidemic Sound / Artlist 等），慢速布鲁斯 instrumental、BPM 60–80、无人声或低歌词密度；**不用流媒体直接放流行录音**。
4. 彩排时戴耳机听一遍直播回传音质，确认引导词是绝对的声音中心。
5. **两手方案**：音乐放不出来，直接关掉，人声引导，流程不动。所有引导词不依赖音乐，停顿就是音乐。

## 四、助教分工

| 角色 | 职责 |
|---|---|
| 助教（弹幕） | 入场弹幕、互动问题（15:30 / 21:00）、"一个词"分享筛选、冷场暖场、标记需私信跟进的人、音乐异常立即私聊带领师 |
| 助教（报时） | 在 5' / 10' / 17' / 25' 四个节点私聊报时；音乐 cue 提前 30 秒提醒 |
| 助教（群管） | 开播提醒、课后三问收集、微作业卡发放、私信转介（话术见物料包） |

若只有 1 名助教：优先保"报时 + 弹幕"两项，群管动作延后到下播。

## 五、安全与伦理速查

- ☐ 口播免责声明（脚本 2:00–7:00 已含"非心理治疗"+ 转介提示）
- ☐ 烫伤提醒（脚本第三步开头已含"烫就吹一吹、等一等"；食物烤好后放置 1–2 分钟再入口）
- ☐ 情绪触发预案（脚本应急预案已含落地技术口播版：睁眼→双脚踩地→说出五样物品）
- ☐ 进食障碍迹象 → 不公开回应，助教私信转介（话术见物料包）
- ☐ 隐私：口播"请勿录屏"；若提供官方回放，剪辑掉分享环节

## 六、下播后复盘（10 分钟，三问）

1. 时间：哪个环节超时/提前？下次怎么调？（对照脚本时间控制预案）
2. 语言：有没有不小心说出评判词？（回看录播 2 倍速扫一遍）
3. 数据：同时在线、互动条数、新增关注、课后三问反馈（表格见物料包）。
