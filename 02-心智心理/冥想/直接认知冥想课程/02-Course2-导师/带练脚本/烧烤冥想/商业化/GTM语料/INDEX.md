# 烧烤冥想 GTM 语料 | 目录索引

> 本目录是《烧烤冥想》推向市场的全套可复制语料：从一条短视频，到一次直播，到一句私聊回复，直接取用。
> 语料的策略来源是上级目录《获客与转化.md》《产品与定价.md》《合规与风控.md》，语言来源是《烧烤冥想·教学大纲.md》。

## 使用总则（先读这一节，再取语料）

1. **无效果承诺**：不出现减重、掉秤、治愈、疗效类表述，不承诺任何身体变化结果。
2. **无体重与卡路里数字**：正文、字幕、口播均不出现公斤数与热量数。
3. **邀请式语言**：用"如果你愿意，可以……"开头，不用命令句，不用"坚持""管住"。
4. **平台适配**：同一主题在视频号偏完整，在小红书偏段落，在抖音取前 3 秒钩子，落地页取长版。
5. **一次创作，多处改写**：一个主题先写长文版，再改口播版与图文版，不做无源之水的新选题。
6. **每条素材底部留三样**：所属分线、对应产品、下一步动作（问卷、直播、私聊），缺一样不发。
