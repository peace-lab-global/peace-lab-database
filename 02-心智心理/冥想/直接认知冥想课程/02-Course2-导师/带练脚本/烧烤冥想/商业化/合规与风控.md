# 烧烤冥想 · 合规与风控

> 这门课的三条边界（不教减肥、不讲营养、不做心理治疗）同时是它的合规护城河。守住边界，就是守住生意。

## 一、广告与宣传合规

1. 《广告法》第 17 条：医疗、药品、医疗器械广告以外，禁止其他广告涉及疾病治疗功能。宣传中不出现「治愈」「治疗」「疗效」「康复」。
2. 不承诺体重结果：不出现「月瘦多少斤」「几天掉秤」；学员案例不发体重前后对比。
3. 禁用绝对化用语：「最」「第一」「100%」「彻底」。
4. 课程声明进入每一份物料：「这是觉察训练，不是心理治疗。」
5. 学员故事使用前取得书面授权。

## 二、预付费合规

1. 产品以单次与短期为主：单场课、7 天营、21 天营。不推一年以上大额预付。
2. 退费规则写进报名页，见《财务测算.md》第六节。
3. 收款走企业微信商户或对公账户。

## 三、食品安全（线下含真实食材）

1. 场地优先选择已有食品经营许可的餐厅或场地合作，食材由其提供。
2. 报名表必填过敏与饮食禁忌，素食者默认提供豆腐与萝卜（已有）。
3. 生熟分开，烤制熟度检查；烫伤预案沿用课程设计：等它凉一等。
4. 建议配置活动责任险，每年数百元。

## 四、版权

1. 音乐：线下与录播用已确认授权曲目；直播背景音乐用平台自带曲库，避免版权投诉限流。
2. 课程内容：脚本与物料申请著作权登记；切片与回放加水印。

## 五、临床边界与转介网络

1. 转介话术沿用现有版本：只发一次，不追问，不诊断，不给饮食建议。
2. 开课前建立合作名单：2 至 3 位心理咨询师或机构，1 家进食障碍相关医疗资源。
3. 课堂观察标准沿用课程设计：出现临床迹象，停止该学员进食暴露类练习并转介。
4. 商业上这是双向门：心理机构把非临床人群转进来，这里把临床迹象转回去。

## 六、风险清单

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 直播冷场，需求验证失败 | 中 | 高 | 选题快速迭代，异业导流保底 |
| 复购率低 | 中 | 中 | 觉察卡加会员设计加晚宴毕业场 |
| 依赖带领师个人 | 高 | 高 | 课程标准化，培养助教独立带体验场 |
| 季节波动 | 低 | 低 | 内容跟节气走：贴秋膘季、双 11、立冬晚宴 |
| 同质化竞品 | 中 | 中 | 烧烤场景锚点加四线细分 |
| 食品安全事故 | 低 | 高 | 合规场地合作加活动责任险 |
| 违规宣传被投诉 | 中 | 高 | 宣传物料双人审核，红线清单进 SOP |
| 平台限流 | 中 | 中 | 多平台分发，私域为主阵地 |
