# 烧烤冥想 · 课程设计说明（督导版）

> 用途：供 9.27 下午团体督导审阅，与《烧烤冥想-督导展示30分钟脚本.md》配套使用
> 审阅重点：课程定位、理论内核、安全边界、音乐设计、评估方式
> 版本：2026-09-27 第一版

---

## 一、课程定位

**一句话**：「烧烤冥想」是一套以正念和直接认知为内核的进食觉察训练。它借中国人最熟悉的进食场景，把'自动驾驶'式的吃，换成'有觉察'的吃。

**三条边界**：它不教减肥，不讲营养，也不做心理治疗。烤架只是道具，食物只是锚点，练习的对象，是注意力本身。

**具体帮什么**：想少吃一点的人，重新听见身体的信号，饿和馋分开，"想吃"和"吃"之间出现选择；觉得身体不够好的人，重新看待身体，评判可以先休息，食物重新只是食物，身体重新只是身体。这两条，就是开场要回答的两个问题。

**为什么是烧烤**，三个理由：

1. **零准备门槛**：谁都有围着烤架吃饭的记忆，不用先解释什么叫"修行"，一坐进来就能练。
2. **五感齐备**：油花、滋滋声、焦香、温度、味道的变化，教具自己就长全了。
3. **想吃和吃之间有几秒距离**：看到油花翻动的那一刻，欲望升起来了，手还没有伸出去。那个缝隙，就是练习发生的地方。

## 二、理论内核

课程不要求学员学习理论，但每句引导词的背后都有依据。以下五个概念，是整套设计的骨架。

**1. 直接认知**
练习的方向是先体会，不急着分析。看就是看，尝就是尝。前五识只做单纯的接触，评判晚一点再进来，甚至不进来。

**2. 痛苦的结构**
痛苦常常是不舒服，加上抗拒，加上演绎。身体信号是事实，那一句"这口不该吃"是叠加在上面的故事。认知解离，练的就是把这两层分开。

**3. 所缘境**
注意力需要地方可去。炭火、食物、呼吸，都是所缘境。以一念取代万念：注意力落在食物上，评判就没有地方站。

**4. 五步流程（简化版）**
完整的禅观疗愈流程是：止心调整 → 主题思考 → 联结自身 → 松动转化 → 浸泡浸润。课程把它简化成：安顿（止）→ 观察（联结自身）→ 转化（微笑、慈悲）→ 收尾浸泡。要点只有一条：观察之后一定要转化收尾，后半段比前半段更重要，观察了负面情绪，就要陪着学员走出来。

**5. 厌离的真义**
"停，不是忍"背后的意思：够了，不需要了。它不压抑食欲，它只是清清楚楚地知道，自己已经够了。欲望本身没有错，练习练的，是那几秒里的清楚。

## 三、四大设计原则

| 原则 | 含义 | 落地位置 |
|---|---|---|
| 去评判化 | 没有哪一口是好的，哪一口是坏的 | 全程引导词 |
| 认知解离 | 身体信号是事实，羞耻和补偿是故事，把两者分开 | "要不要再来一口"环节 |
| 具身锚定 | 不跟学员讲道理，一切落在一个具体的感觉上 | 第一口在舌尖停十秒 |
| 自我慈悲 | 观察之后要转化收尾，收尾是流程本身 | 慈悲收尾环节 |

## 四、服务人群与四条分线

同一套技术，服务四种和食欲的关系：

| 分线 | 人群 |
|---|---|
| 01 减脂线 | 想少吃一点的人 |
| 02 吃饭节奏线 | 吃太快的人、想慢慢找回吃饭乐趣的人 |
| 03 运动表现线 | 把鸡胸肉吃成任务的人 |
| 04 身材焦虑线 | 跟肚腩较劲、长期觉得身体不够好的人 |

分线，是给练习定锚点，不给人贴标签。通识场四条线一起练，分线场按自评进入，也欢迎旁听。本次督导展示的带练，站在 01 减脂线和 04 身材焦虑线的角度。

🚩 **临床边界（重要）**：厌食症这类进食障碍是临床问题，要遵医嘱，课程不碰。课堂上一旦看到临床迹象，只做转介：私下沟通，建议就医，同时停止该学员的进食暴露类练习。不诊断，不追问，不给饮食建议。

## 五、方式方法

**五感阶梯**：进食带练统一走 闭眼先触 → 看 → 听 → 闻 → 尝。先不睁眼，用手拿起食物，指尖认识温度、软硬，手掌托一托重量，不给它起名字，绕开"哦，是块肉啊"的自动判断；再睁眼第一次看。第一口放进嘴里先不咽不嚼，在舌尖停十秒，再开始慢慢嚼。

**标准课结构**：开场两问（为什么叫烧烤冥想、这门课具体帮什么）→ 安顿呼吸 → 身体扫描 → 主题引导 → 五感带练 → 慈悲收尾 → 分享与作业。慈悲收尾固定四步：感谢身体 → 留足停顿 → 食物无罪 → 评判先休息（没有评判升起的学员，自然进入慈心句），目标是把身体焦虑放下来，重新看待食物和身体。

**核心练习**："要不要再来一口"。想吃，和吃，之间那几秒，就是练习发生的地方。再来一口可以，停在这里也可以，两个选择都是好的。

**语言红线**：
- 全程邀请式："如果你愿意，可以……"
- 零评判词："坚持住""管住嘴""罪恶""胖"这类词不出现
- 不提体重与卡路里数字
- 标点只用逗号、句号、冒号，不用破折号

## 六、安全与伦理

1. **声明**：开课前口头和文字各一次。这是觉察训练，不是心理治疗。
2. **转介**：临床迹象只做转介，话术温和，只发一次，不追问、不诊断、不给饮食建议。
3. **情绪预案**：身体扫描可能触发强烈情绪。落地的方法是睁眼、感受双脚踩在地上、看看四周说出五样东西。任何时候都可以退出。
4. **隐私**：分享的内容留在教室里，线上课禁止录屏。

## 七、音乐设计

**总原则**：入场有歌，带练有床，收尾有送。带人声的歌不进带练段。

**分层设计**：

| 时段 | 音乐处理 | 说明 |
|---|---|---|
| 入场（开场前 2-3 分钟） | 轻快暖场曲，音量垫底 | 学员陆续进场，心情预备自己完成 |
| 安顿与观呼吸 | 最空：纯环境音或极轻 pad | 引导词"只是听"需要真安静 |
| 看／听与闻 | 音乐降到接近零 | 练习对象是食物和房间，音乐就是干扰 |
| 触与第一口、要不要再来一口 | 稳定低频 pad 床，60 BPM 左右 | 练习最深处，垫一张地毯，不抢戏 |
| 慈悲收尾 | 加一层更暖的 pad，随"欢迎回来"淡出 | 收尾升温，音乐跟着升 |
| 送客 | 前奏轻轻推入 | 收尾的延伸 |

**推荐曲目**（均无人声，版权已确认）：

- 入场曲：Bob Marley《Three Little Birds》。歌词"Don't worry about a thing"，就是课程内核的口语版：松开担心，允许一切。
- 带练床：Brian Eno《Music for Airports》1/1、《Thursday Afternoon》（61 分钟单曲，免循环接缝）；Hiroshi Yoshimura《Green》《Wet Land》；Max Richter《Dream 3》；Harold Budd & Brian Eno《The Pearl》。
- 环境音：炭火噼啪声（与炭火意象呼应）、溪流、雨声。

**技术参数**：

- 音乐底噪 -20 dB 左右，引导词说话时再降 6-8 dB，说完 1 秒恢复（ducking）
- 不用有明显节拍和打击乐的曲子，BPM 控制在 50-70
- 正式直播前戴着耳机完整跑一遍 17 分钟，重点检查循环接缝和情绪起伏点；再演练一次无声人声带练（两手方案）

**两手方案**：直播和排练中背景音乐失败很常见。音乐放不出来时，直接关掉，人声引导，流程不动。所有引导词本身不依赖音乐，停顿就是音乐。

**本次督导展示**：带练背景音乐按分层设计的最简版准备，音乐放不出来就按两手方案关掉，人声引导，流程不动；督导展示的重点是引导词本身。

## 八、评估设计

1. **课前自评分线**：学员按四条分线自评，进入对应练习角度。
2. **课后一分钟三问**：此刻身体的感受？进食时注意力在哪里？有没有评判升起？
3. **系列结束产出**：个人《进食觉察卡》，记录自己的进食模式和觉察锚点。

## 九、本次督导展示安排（30 分钟）

| 时间 | 环节 | 时长 | 内容 |
|---|---|---|---|
| 0:00-2:00 | 开场 | 2' | 结构 + 物料 + 静音/摄像头 |
| 2:00-10:00 | 设计思路与方式方法 | 8' | 定位 → 为什么烧烤 → 四原则 → 四线 → 五感阶梯 → 伦理 → 评估 |
| 10:00-27:00 | 压缩版带练 | 17' | 安顿 2.5' → 闭眼触 1.5' → 第一次看 1.5' → 听闻 2.5' → 第一口 4' → 再来一口 2' → 慈悲收尾 3' |
| 27:00-30:00 | 设计自述 + 督导反馈 | 3' | 30 秒自述 + 三个反馈问题 |

与正式课的关系：本场压缩掉了长版身体扫描和自由进食段，其余同构。物料以一小口食物为主，一杯水为备选；吃什么不重要，看见自己在吃，才重要。

## 十、请督导指教的三个问题
