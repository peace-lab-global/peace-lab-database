## 二、🧑‍🏫 教师 · 中高度倦怠

### 2.1 关键数据

| 指标 | 数据 | 来源 |
| :--- | :--- | :--- |
| 中国专任教师总数 | **1880 万**（2023）| 教育部 2023 统计 |
| 中小学教师抑郁症状检出率 | **23.3%**（2024 中国教师心理健康蓝皮书）| 北师大 2024 |
| 中小学教师焦虑症状检出率 | **34.8%** | 同上 |
| 班主任每周工作时长 | **60-80 小时** | 班主任调查 2024 |
| 高校教师 burnout 率 | **45%**（高校教师职业倦怠调查）| 2024 |
| 高校 1:4000 心理教师目标 | 17 部委 2023 计划 | [17 部委档案](../社会心理服务/应用心理-社会心理服务-17部门学生心理专项行动计划.md) |
| 因心理问题调离 / 离职率 | **4-7%**（高中阶段）| 行业估算 |

### 2.2 主要压力源

1. **学生管理压力** — 抑郁症/自伤学生增多，"不敢管、管不了"
2. **家校沟通压力** — 家长情绪化、对立
3. **教学绩效压力** — 中高考升学率考核
4. **形式主义负担** — 各类非教学任务、迎检、评比
5. **职称晋升压力** — 论文、课题、课时
6. **待遇与地位落差** — 收入与付出不匹配

### 2.3 典型案例

> **2024-2025 案例**：北京某重点中学班主任 35 岁女性，因学生自伤事件后失眠、焦虑，PHQ-15 自评 18 分（中重度躯体化），后接受 CBT-I + 短程 CBT 治疗 8 周后回到工作岗位。
>
> **2025 案例**：某地高中数学教师 42 岁男性，连续 3 年高三，2025-03 突发焦虑性高血压住院 2 周。

### 2.4 干预路径

```
学校心理辅导室（兼职）→ 区县教师心理服务中心
   ↓
EAP（部分大企业附属学校）→ 简单心理 / KY 平台咨询
   ↓
17 部委 2023 计划 → 高校 1:4000 心理教师配置
   ↓
重者转介 → 精神卫生中心（地市级三甲）
```

### 2.5 政策窗口
- 17 部委 2023 行动（学生端间接要求）
- 教育部 2024《全面加强新时代教师队伍建设意见》要求关注教师心理健康
- 25 部委 2026-04《实施方案》要求教育系统全覆盖

## 三、🩺 医生 · 重度抑郁高发

### 3.1 关键数据

| 指标 | 数据 | 来源 |
| :--- | :--- | :--- |
| 中国执业（助理）医师 | **约 450 万**（2024）| 国家卫健委 2024 |
| 医生抑郁症状检出率 | **35-50%** | 多项研究 |
| 住院医师重度抑郁 | **25-30%** | 2018-2024 多项调查 |
| 麻醉/急诊/ICU 倦怠率 | **60%+** | 2024 中国医师协会 |
| 自杀率（医生 vs 普通人群）| **1.5-3 倍**（男 1.5× / 女 3×）| Medscape 2024 + 多源 |
| 夜班频率（住院医师）| 平均 4-6 天/月 | 行业调查 2024 |
| 医患冲突发生率 | **80%+ 医生经历过** | 中国医师协会 2023 |

### 3.2 主要压力源

1. **医患矛盾** — 暴力伤医事件年均 100+ 起（2023-2025 公开报道）
2. **超长工作时间** — 住院医师每周 60-80 小时常态
3. **夜班透支** — 慢性睡眠剥夺
4. **职业暴露** — 传染病、辐射、危重抢救
5. **晋升与科研** — "医而优则仕"，论文压力大
6. **道德困境** — 资源有限时的分配决策

### 3.3 典型案例

> **2024-08 北京某三甲医院规培医生自杀事件**，引发规培生心理危机关注，2024-09 国家卫健委发布《关于进一步加强住院医师规范化培训对象关心关爱的通知》。
>
> **2025-11 湖南某县医院急诊科医生**，连续夜班 3 天后猝死（脑出血），引发对值班制度的反思。

### 3.4 干预路径

```
科室心理联络员 → 医院心理科（部分三甲设立）
   ↓
医师协会 EAP（部分试点）→ 商业心理平台（壹心理 / 简单心理）
   ↓
重症转介 → 精神专科医院
```

### 3.5 政策窗口
- 2024-09 国家卫健委规培关心关爱通知
- 2025 多省试点"医师心理关爱专项"
- 2026-04 25 部委《实施方案》要求卫生系统加强医务人员心理关爱

### 3.6 国际对照
- 美国 **Medscape 医生倦怠报告 2024**：医生 burnout 率 49%
- 斯坦福 **WellMD 计划**（2008 起）— 行业标杆
- 英国 **NHS Practitioner Health**（2008 起）— 医生专属心理服务

## 四、👮 警察 · PTSD 高发群体

### 4.1 关键数据

| 指标 | 数据 | 来源 |
| :--- | :--- | :--- |
| 中国警察总数 | 约 200 万（公安 190 万 + 司法 10 万）| 公安部 2024 |
| 辅警总数 | 约 400 万+ | 行业估算 |
| 警察 PTSD 检出率 | **14-25%**（一线刑警 30%+）| 公安部 2018 心理工作 + 多项研究 |
| 警察抑郁症状检出率 | **25-40%** | 多项研究 |
| 警察年均因公牺牲 | **约 400-500 人**（牺牲 200+ / 病故 200+）| 公安部历年数据 |
| 一线民警每周工作时长 | **50-70 小时** | 行业调查 |

### 4.2 主要压力源

1. **暴力与突发事件** — 重大事故现场、刑事案件、群体性事件
2. **高风险执法** — 抓捕、抢险、维稳
3. **24h 值班** — 备勤状态长期应激
4. **PTSD 累积** — 长期暴露创伤事件
5. **家庭关系紧张** — 倒班、出差影响家庭
6. **职业风险** — 因公负伤、牺牲

### 4.3 典型案例

> **2023-2024 案例**：某地派出所民警 28 岁，处理重大交通事故现场后出现闪回、失眠，被诊断 PTSD，接受 EMDR + 团体心理辅导 12 周。
>
> **2024-05 公安部统计数据**：全国公安机关心理服务站覆盖率 **75%+**（2024）

### 4.4 干预路径

```
基层所队心理联络员 → 县级公安机关心理服务站
   ↓
市级心理服务中心 → 省级警察心理训练基地
   ↓
重大事件 → CISM（关键事件应激管理）+ SAFER-R
   ↓
重症转介 → 精神专科医院 / 公安民警英烈基金会
```

### 4.5 政策窗口
- **公安部 2018《关于进一步加强公安民警心理健康服务工作的意见》** — 体系化起点
- 公安院校 5 所（北京/上海/江苏/湖北/广东）设心理学专业
- 2018 起 200+ 心理服务站建设

### 4.6 国际对照
- **美国 Officer Down Memorial Page** + **CopLine**（1-800-267-5463，警察专属热线，2006 起）
- **英国 Police Care**（2024 改名 Police Care UK）— 警察心理健康慈善机构
- **澳大利亚 Fortem Australia**（2019 起）— 急救/警察/军人家庭支持

## 五、💻 程序员 · 35 岁危机叠加

### 5.1 关键数据

| 指标 | 数据 | 来源 |
| :--- | :--- | :--- |
| 中国程序员总数 | **700 万**（主流估算）| 行业报告 2024 |
| 35+ 程序员占比 | **30-40%** | 行业调查 |
| 互联网行业 burnout 率 | **50-65%** | 多项调查 2023-2024 |
| 互联网大厂工作时长 | 平均 **50-60 小时/周**（996 模式仍存部分公司）| 行业调查 |
| 程序员焦虑症状检出率 | **40-50%** | 2024 多项研究 |
| 程序员失眠率 | **35-45%** | 2024 |
| 大厂裁员 / 优化 | 2022-2024 累计 30 万+ | 行业估算 |

### 5.2 主要压力源

1. **35 岁危机** — 行业隐性年龄歧视
2. **996 / 大小周** — 部分公司长期加班
3. **绩效压力（OKR / 360）** — 持续紧张
4. **技术迭代焦虑** — AI 冲击
5. **裁员的群体性焦虑** — 2022-2024 大厂裁员潮
6. **副业 / 跳槽 / 创业压力** — 路径多元但风险高
7. **社交 / 婚育压力** — 高压下的关系困境

### 5.3 典型案例

> **2024 案例**：北京某大厂 P7 工程师 32 岁，连续 3 个月每天 12 点下班后突发惊恐发作（心悸、手抖），诊断为急性焦虑发作，住院 1 周后接受 CBT 治疗。
>
> **2025 案例**：某厂 35 岁程序员被优化后出现中度抑郁，6 个月未就业，PHQ-9 17 分（中重度）。

### 5.4 干预路径

```
公司 EAP（仅头部大厂）→ 商业心理平台（KY / 简单心理 / 壹心理）
   ↓
CISM（关键事件如裁员）→ 团体辅导
   ↓
Wysa / Woebot（部分公司引入）→ AI 心理助手
   ↓
重者转介 → 互联网医院（好心情 / 昭阳医生）
```

### 5.5 政策窗口
- 2021 最高法、人社部明确"996"违法（但执行难）
- 2024 互联网行业 EAP 普及率提升至 30%（头部 60%+）
- 25 部委 2026-04《实施方案》要求 IT/互联网行业关注员工心理

### 5.6 国际对照
- 美国 **Stack Overflow 开发者调查 2024**：56% 报告 burnout
- **GitHub Copilot 团队** 内部研究 — AI 工具可降低 30% 焦虑（争议中）
- 谷歌 / Meta 内部 EAP 体系相对成熟

## 六、🛵 外卖员 / 网约车司机 · 新就业群体

### 6.1 关键数据

| 指标 | 数据 | 来源 |

| 快递员 | **约 450 万** | 国家邮政局 |
| 合计新就业群体 | **1200 万+** | 多源 |

| 骑手月均收入 | **5000-8000 元**（一线城市）| 行业报告 2024 |
| 骑手焦虑症状检出率 | **45-55%** | 2024 北京大学研究 |
| 骑手抑郁症状检出率 | **30-40%** | 同上 |

### 6.2 主要压力源

1. **算法压力** — 配送时间压缩、罚款机制
2. **交通安全** — 高频事故风险
3. **收入波动** — 天气、平台规则、订单密度
4. **缺乏保障** — 社保缺位、纠纷维权难
5. **社会认同** — 职业歧视、客诉压力
6. **家庭分离** — 异地就业、聚少离多
7. **健康透支** — 久坐、不规律饮食

### 6.3 典型案例

> **2024-09 央视报道**：《困在算法里的外卖员》后续报道 — 平台陆续优化算法、取消"最严惩罚"
>
> **2025 案例**：某外卖骑手 30 岁，连续工作 12 小时后猝死（脑溢血），引发对骑手工作强度的关注

### 6.4 干预路径

```
平台内部心理服务（美团"骑手之家" + 滴滴司机关怀）→ 心理热线
   ↓
工会 + 行业协会（中国物流与采购联合会）→ 心理关爱
   ↓
新就业群体专项（2025 启动）→ 商业心理平台
   ↓
CISM（重大事故后）→ 团体辅导
```

### 6.5 政策窗口

- **2021 7 部门《关于落实网络餐饮平台责任切实维护外卖送餐员权益的指导意见》**

## 七、跨群体共性 + 干预框架

