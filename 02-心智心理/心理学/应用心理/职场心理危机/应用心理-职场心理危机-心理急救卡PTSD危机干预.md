# 心理急救卡 · PTSD 与危机干预实操手册

> **目的**：6 大心理危机场景的 5-10 分钟可操作急救方案 — 个人自助 + 他助
> **适用**：平时收藏、危机时直接抄
> **更新**：2026-08-05

---

## 🚨 0 号急救：判断"是否需要立即呼叫"

### 🆘 立即拨打 120 / 110 / 12356 的信号

```
□ 正在或即将自伤 / 自杀
□ 听到 / 看到不存在的（幻觉）
□ 意识混乱 / 不能说出自己姓名
□ 严重胸痛 / 呼吸困难（可能躯体疾病）
□ 失控的暴力倾向
□ 失去意识 / 抽搐
```

> **拨打 120（医疗）+ 110（必要时）+ 12356（心理援助）**
> **北京心理危机研究与干预中心：010-82951332 / 010-62716165**
> **不要让当事人独处，移除危险物品**

## 1️⃣ 场景 1：惊恐发作（Panic Attack）

### 1.1 典型表现
- 突发强烈恐惧 / 濒死感
- 心悸、胸闷、出汗、颤抖
- 感觉"要疯"、"要死"
- 持续 5-30 分钟（峰值 10 分钟内）

### 1.2 🚑 自助（5 分钟内可缓解）

#### 方法 A：4-7-8 呼吸法（**首选**）
```
步骤：
1. 闭嘴，用鼻吸气，数 4 秒
2. 屏住呼吸，数 7 秒
3. 用嘴缓缓呼气（发出"呼"声），数 8 秒
4. 重复 3-4 轮

原理：激活副交感神经，降低心率
```

#### 方法 B：腹式呼吸
```
步骤：
1. 一手放胸口，一手放腹部
2. 鼻吸气 4 秒，腹部鼓起（胸口不动）
3. 屏 2 秒
4. 嘴呼气 6 秒，腹部收缩
5. 重复 5-10 轮
```

#### 方法 C：5-4-3-2-1 接地技术
```
步骤（感官 grounding）：
看：说出 5 件你能看到的东西
摸：说出 4 件你能触摸到的东西
听：说出 3 件你能听到的声音
闻：说出 2 件你能闻到的气味
尝：说出 1 件你能尝到的味道
原理：把注意力从"内"拉回"外"
```

#### 方法 D：冷水刺激
```
方法：将脸浸入冷水（10-15°C）10-30 秒
或：用冷毛巾敷面部 / 颈后
原理：激活"潜水反射"，立即降低心率
```

### 1.3 🧑‍🤝‍🧑 他助（身边有人时）
1. 保持冷静，不评判
2. 用平静语气引导呼吸（"和我一起，吸…呼…"）
3. 把对方带到安静、光线柔和的环境
4. **不要**说"别紧张""没什么大不了"
5. 持续陪伴到症状缓解（5-30 分钟）
6. 之后建议就医（排除躯体疾病）

## 2️⃣ 场景 2：急性焦虑 / 广泛性焦虑发作

### 2.1 典型表现
- 持续紧张、坐立不安
- 肌肉紧张、头痛、胃肠不适
- 注意力难以集中、易怒
- 睡眠困难

### 2.2 🚑 自助

#### 渐进式肌肉放松（PMR，10 分钟）
```
步骤：
1. 找安静地方坐/卧
2. 脚趾用力绷紧 5 秒 → 突然放松 10 秒
3. 小腿肌肉绷紧 5 秒 → 放松 10 秒
4. 大腿 → 腹部 → 双手 → 双臂 → 肩膀 → 面部
5. 重复 2 轮
6. 配合深呼吸

推荐：每天睡前练习 1 次
```

#### 认知重构（3 分钟）
```
步骤（识别灾难化思维）：
1. 现在最担心什么？
2. 这件事最坏的结果是什么？
3. 发生的概率有多大（实际）？
4. 即使最坏发生，我能应对吗？
5. 有什么证据支持/反驳这个想法？
6. 换个角度看会怎样？
```

#### 行动清单
- 离开焦虑触发场景
- 散步 10-20 分钟（**有氧运动效果最直接**）
- 联系信任的人倾诉
- 写焦虑日记（具体事件 + 想法 + 情绪 + 替代想法）

### 2.3 持续 2 周以上 → 建议就医 / 心理咨询

## 3️⃣ 场景 3：自杀危机（最紧急）

### 3.1 识别信号（**问就对了**）

#### 高危信号
- 直接说"我不想活了"
- 寻找自杀方式（搜索、上网查）
- 安排后事（写遗书、转赠财物）
- 突然"平静"（决定后的解脱感）
- 送走珍贵物品

#### 中危信号
- 谈论死亡、想死
- 自我评价极低（"我是负担"）
- 严重失眠
- 滥用酒精/药物
- 突然退缩 / 告别

### 3.2 🆘 立即行动（5 步）

```
第 1 步：直接询问（**不会"诱导"对方自杀**，但能救命）
   "你现在有想自杀的念头吗？"
   "你打算怎么做？"
   "你有具体的计划吗？"

第 2 步：保持冷静、倾听、不评判
   - 不说"别傻了"、"振作起来"、"为了家人"
   - 不说"你不应该这样想"
   - **说**："我很担心你"、"你愿意告诉我吗？"
   - **说**："我们一起想办法"

第 3 步：移除危险物品
   - 药物、刀具、绳索、玻璃、车辆钥匙
   - 不让当事人独处

第 4 步：拨打急救电话
   - 120（医疗急救）
   - 12356（全国心理援助热线，24h）
   - 010-82951332（北京心理危机研究与干预中心）
   - 当地精神卫生中心

第 5 步：陪伴到专业人员到场
   - 不让当事人独处
   - 不让其开车
   - 不让其接触危险物品
```

### 3.3 🛡️ 后续 24-72 小时
- 持续陪伴（轮流值班）
- 移除家中危险物品
- 陪同就医
- 联系 24h 支持网络
- 服用抗抑郁药需监督（防过量）
- 通知关键人（家人、朋友、医生）

## 4️⃣ 场景 4：PTSD 闪回（创伤再体验）

### 4.1 典型表现
- 突然"回到"创伤事件（闪回）
- 噩梦、闪回、侵入性画面
- 心跳加速、出汗、颤抖
- 过度警觉、回避创伤相关刺激

### 4.2 🚑 闪回时（5 分钟内）

#### 紧急 grounding 协议
```
1. 自我暗示（大声说）：
   "我现在在 [具体地点]，今天是 [具体日期]，
    我是 [你的名字]，我已经安全了。"

2. 身体 grounding：
   - 双脚用力踩地板
   - 手握冰块 / 握力球
   - 用冷水洗脸
   - 闻强烈气味（薄荷油、柠檬）

3. 感官扫描（5-4-3-2-1）：
   - 看 5 个东西
   - 摸 4 个东西
   - 听 3 个声音
   - 闻 2 个气味
   - 尝 1 个味道

4. 身体动作：
   - 拍膝盖（左右交替）
   - 抱紧自己
   - 站起来快速走动
```

### 4.3 🩺 长期方案（建议专业治疗）
- **EMDR**（眼动脱敏与再加工）— PTSD 一线推荐
- **创伤聚焦 CBT**（TF-CBT）
- **延长暴露疗法**（PE）
- **药物治疗**（SSRI 类，遵医嘱）
- **CISM 团体干预**（事件后 24-72h）

### 4.4 CISM（关键事件应激管理）5 步法

```
适用于：重大事故、灾难、暴力事件后 24-72 小时内
人员：经过培训的心理专业人员 + 同伴支持
1. 准备阶段（事件前或即刻）：建立信任
2. 减压阶段（事件后 24h）：集体信息+情感表达
3. 分享阶段：倾诉经历（自愿）
4. 正常化阶段：普及应激反应
5. 资源对接：转介专业服务
```

## 5️⃣ 场景 5：急性应激反应（重大事件后 24-72h）

### 5.1 典型表现
- 麻木、震惊、否认
- 情绪混乱、哭泣、愤怒
- 注意力涣散
- 失眠、噩梦

### 5.2 🚑 急性期（24-72h）干预

#### SAFER-R 模型（5 步）

```
S - Stabilize（稳定化）
   确保安全：人、场所、情绪稳定
   移除危险物品

A - Acknowledge（确认）
   "这件事发生了，你现在的反应是正常的"
   "创伤不是你的错"
   不评判、不说教

F - Facilitate（促进）
   鼓励表达：让当事人说话、哭泣、释放
   不强迫，但创造表达空间

E - Encourage（鼓励）
   鼓励自助：饮食、睡眠、运动
   鼓励利用支持系统

R - Restoration（恢复）
   恢复正常节律：作息、饮食、工作
   阶段性任务：先处理紧急，再处理复杂

R - Referral（转介）
   评估是否需要专业介入
   PHQ-9 / PCL-5 筛查
   必要时转介
```

### 5.3 时间线

```
0-24h    危机稳定期
   ↓
1-3 天   急性应激期（CISM 介入窗口）
   ↓
3-30 天  适应期（大部分人自然恢复）
   ↓
1-3 月   慢性化风险期
   ↓
> 1 月   PTSD 高风险（需专业评估）
```

## 6️⃣ 场景 6：失眠急救

### 6.1 短期失眠（< 1 周）急救

#### 睡眠卫生 + CBT-I

```
1. 固定起床时间（每天，包括周末）
2. 床只用于睡觉和性（不在床上工作、刷手机）
3. 20 分钟睡不着 → 起床去另一个房间
4. 避免午睡（>30 分钟）
5. 下午 3 点后不喝咖啡
6. 晚上不喝酒（影响 REM 睡眠）
7. 卧室：凉爽、安静、黑暗
8. 睡前 1 小时不看屏幕
```

#### 4-7-8 呼吸法（同 1.2）

#### 身体扫描（10 分钟）
```
从头到脚（反过来也行），
每个部位停留 5-10 秒，
注意并释放紧张，
配合深呼吸。
```

### 6.2 持续 1 个月以上 → 推荐 CBT-I

- **SleepioRx**（Big Health，FDA 批准数字疗法）
- **CBT-I** 4-8 周 60% 有效
- 严重者就医（排除睡眠呼吸暂停等）

## 🔟 急救口诀（10 字诀）

```
"问、听、陪、稳、转" — 5 字现场急救
"呼、握、触、嗅、动" — 5 字自助 grounding
```

**5 字现场急救**（他助）：
- **问** — 直接询问自杀念头
- **听** — 倾听不评判
- **陪** — 不离不弃
- **稳** — 稳定情绪（呼吸/接地）
- **转** — 转介专业

**5 字自助 grounding**：
- **呼** — 4-7-8 呼吸
- **握** — 握冰/握力球
- **触** — 摸 4 个物件
- **嗅** — 闻强烈气味
- **动** — 起身走动/拍膝
