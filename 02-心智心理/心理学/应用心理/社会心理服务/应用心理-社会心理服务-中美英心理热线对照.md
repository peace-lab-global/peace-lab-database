## 二、🇨🇳 中国 12356

### 2.1 起源与建设
- **2024-12-26** 国家卫健委公告 12356 启用
- **2025-05-01** 全国 31 省并轨
- 22 部委 2016《关于加强心理健康服务的指导意见》铺垫
- 25 部委 2026-04《心理健康服务实施方案》强化

### 2.2 组织架构
```
国家卫健委
   ├─ 各省卫健委
   │     ├─ 省级心理援助热线中心（依托精神卫生中心）
   │     ├─ 地市级分中心
   │     └─ 县区级接听点
   └─ 12356 公共服务热线（接入）
```

### 2.3 关键数据
- **2024 年试点期间**：10+ 省市先行（北上广深苏浙粤等）
- **2025-05 全国并轨后**：覆盖 31 省
- **截至 2025 年底**：累计 70+ 万通来电
- **危机干预**：近万起
- **平均接通率**：>90%
- **接听人员**：5000+ 精神卫生专业人员 + 志愿者

### 2.4 配套资源
- **12355** — 共青团青少年心理热线
- **12320** — 卫生健康热线（含心理）
- **希望 24 热线** — 400-161-9995
- **北京心理危机研究与干预中心** — 010-82951332

### 2.5 优势 / 挑战

| 优势 | 挑战 |
| :--- | :--- |
| ✅ 3 位短号易记 | ⚠️ 部分省份 24h 实际响应能力待提升 |
| ✅ 政策强推动 | ⚠️ 接听人员资质参差（部分志愿者）|
| ✅ 与精神卫生中心联动 | ⚠️ 危机干预后续跟踪薄弱 |
| ✅ 公益免费 | ⚠️ 与 120/110 联动机制待加强 |

## 三、🇺🇸 美国 988

### 3.1 起源与建设
- **2018** 联邦立法确定建立
- **2020** FCC 批准 988 为全国短号
- **2022-07-16** 正式启用（全美 50 州 + DC + 波多黎各）
- 由 SAMHSA（药物滥用与精神卫生服务管理局）牵头

### 3.2 组织架构
```
SAMHSA（联邦）
   ├─ Vibrant Emotional Health（总部协调中心）
   │     └─ 全美 200+ 地方危机中心（Local Crisis Centers）
   │           ├─ 接听 988 来电
   │           ├─ 移动危机响应（Mobile Crisis Response）
   │           └─ 危机稳定设施（Crisis Stabilization Units）
   └─ 各州 / 县心理健康局
```

### 3.3 关键数据
- **2022-07-16 启用当年**：约 200 万通来电
- **2023 全年**：470 万通
- **2024 累计**：1000 万+ 通
- **2024 一年接听**：约 600 万通
- **平均响应时间**：约 40 秒
- **接听率**：90%+（目标 95%）
- **短视频/短信渠道**：2024 推出 988 短信服务（988）
- **西班牙语服务**：独立线路（标记选项 2）

### 3.4 配套资源
- **911** — 紧急（警察 / 消防 / 医疗）
- **Crisis Text Line** — 短信 HOME 至 741741
- **Veterans Crisis Line** — 988 后按 1
- **The Trevor Project** — LGBTQ+ 青少年，1-866-488-7386
- **Trans Lifeline** — 877-565-8860
- **National Suicide Prevention Lifeline**（与 988 合并）
- **移动危机响应车**（Mobile Crisis Response Team）— 部分州部署
- **危机稳定设施**（Crisis Stabilization Units / CSUs）— 短期住院替代

### 3.5 资金与人员
- **2022 财政**：联邦 + 州配套共 10 亿美元（5 年）
- **2024 追加**：5 亿美元（移动危机响应专项）
- **志愿者**：5 万+（培训 60+ 小时）
- **专业人员**：4000+（持照心理师 / 社工）

### 3.6 优势 / 挑战

| 优势 | 挑战 |
| :--- | :--- |
| ✅ 短号 988 易记 | ⚠️ 移动危机响应覆盖率低（仅 30% 州）|
| ✅ 多年运营经验（从 2005 Lifeline 升级）| ⚠️ 高峰时段仍会 wait time |
| ✅ 短信 / 视频 / 网络多渠道 | ⚠️ 各州服务质量参差 |
| ✅ 移动危机响应（警察+心理师联合）| ⚠️ 资金可持续性 |
| ✅ 危机稳定设施配套 | ⚠️ 后续护理衔接 |
| ✅ 退伍军人 / LGBTQ+ 等专项 | ⚠️ 农村地区响应延迟 |

## 四、🇬🇧 英国 Samaritans

### 4.1 起源与建设
- **1953** 创立（伦敦）
- **1965** 起 24h 服务
- 由独立慈善机构运营（非政府）
- 短号 **116 123**（欧盟统一，2009 年起）

### 4.2 组织架构
```
Samaritans（独立慈善）
   ├─ 201 个分会（英格兰 150 / 苏格兰 18 / 威尔士 9 / 北爱 6 / 爱尔兰 4 / 海外 14）
   ├─ 总协调办公室（Surrey）
   └─ 募款与宣传团队
```

### 4.3 关键数据
- **每年接听**：约 400 万通
- **每天**：约 1.1 万通
- **平均响应时间**：5 秒
- **志愿者**：2 万+（每人每年义务 200+ 小时）
- **培训时长**：6-9 周（每周 1 个晚上 + 周末）
- **每年募款**：8000 万英镑

### 4.4 配套资源
- **NHS 111** — 非紧急医疗
- **999** — 紧急（警察/消防/医疗）
- **Childline** — 儿童青少年，0800-1111
- **Papyrus** — 青少年自杀预防，0800-068-4141
- **SHOUT** — 短信危机服务，85258
- **C.A.L.L. Helpline**（威尔士）— 0800 132 737
- **Lifeline**（北爱）— 0808 808 8000
- **Samaritans 自杀者亲友支持**（事后回访）

### 4.5 特色服务
- **不限主题倾听** — 不限于自杀危机，任何情绪困扰都可以拨打
- **完全保密** — 不向警方/医院报告（除非明确自杀计划）
- **事后转介** — 主动向推荐方（如医院、警察）反馈
- **多元化语言** — 200+ 语言
- **残障人士** — BSL 手语服务、TypeTalk
- **企业 EAP 合作** — 雇主付费专项服务

### 4.6 优势 / 挑战

| 优势 | 挑战 |
| :--- | :--- |
| ✅ 70+ 年运营经验 | ⚠️ 募款压力（2020 后收入下降）|
| ✅ 严格保密（增加信任）| ⚠️ 与 NHS 衔接不够紧密 |
| ✅ 不限主题（更易被接受）| ⚠️ 后续转介薄弱 |
| ✅ 志愿者培训扎实 | ⚠️ 数字渠道（社交媒体、chatbot）转型慢 |
| ✅ 多元包容 | ⚠️ 现代化压力（年轻人更倾向聊天）|
| ✅ 国际网络（Samaritans International）| ⚠️ 志愿者老龄化（平均 60+）|
