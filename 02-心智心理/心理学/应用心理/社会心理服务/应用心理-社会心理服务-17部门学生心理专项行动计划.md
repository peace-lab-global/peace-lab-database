# 教育部等 17 部门《学生心理健康专项行动计划（2023-2025 年）》

> 2023-04-20 **教育部 + 最高检 + 中宣部 + 网信办 + 科技部 + 公安部 + 民政部 + 财政部 + 卫健委 + 广电总局 + 体育总局 + 中科院 + 妇儿工委 + 共青团 + 妇联 + 关工委 + 科协** 等 **17 部门** 联合印发《全面加强和改进新时代学生心理健康工作专项行动计划（2023-2025 年）》（**教体艺〔2023〕1 号**）。**4 位一体** 体系（健康教育 / 监测预警 / 咨询服务 / 干预处置），**八大任务**，**2025 目标**：配备专（兼）职心理健康教育教师的学校比例达 **95%**、家庭教育指导服务站点达 **60%**。

## 二、4 大基本原则

| 原则 | 内容 |
| :--- | :--- |
| **全面发展** | 教育评价改革 + 德智体美劳全面发展 |
| **健康第一** | 心理健康是全面发展的前提和基础 |
| **提升能力** | 统筹教师/教材/课程/学科/专业，强化监测预警机制 |
| **系统治理** | 多部门联动 + 学校/家庭/社会协同 |

## 三、八大重点任务

### 3.1 任务一：五育并举促进心理健康

| 维度 | 措施 |
| :--- | :--- |
| **以德育心** | 心理健康教育贯穿德育思政全过程 |
| **以智慧心** | 减轻义务教育阶段作业负担 + 教师学习心理学 |
| **以体强心** | **每天校内校外各 1 小时体育活动** + 熟练 1-2 项运动技能 |
| **以美润心** | 美育浸润行动，普及性美育实践 |
| **以劳健心** | 动手实践 + 出力流汗，磨炼意志 |

### 3.2 任务二：加强心理健康教育

- **课程设置**：高校心理健康必修课 **2 学分（32-36 学时）**
- 中职"心理健康与职业生涯"模块按规定开足
- 中小学结合相关课程开展
- 托幼机构遵循儿童生理心理特点
- 编写大中小学生心理健康读本
- 提供"服务包"：给家长、校长、班主任、辅导员

### 3.3 任务三：规范心理健康监测

- **研制符合中国儿童青少年特点的心理健康测评工具**
- **每学年至少 1 次**心理健康测评
- 小学高年级、初中、高中、中职全覆盖
- **建立"一生一策"心理健康档案**
- 高校新生入校后适时测评
- 国家义务教育质量监测每年监测学生心理健康

### 3.4 任务四：完善心理预警干预

> **重大创新**：建立**分级响应模式**

| 层级 | 主体 | 内容 |
| :--- | :--- | :--- |
| **学校-院系-班级-宿舍/个人** | 高校 | 四级预警网络 |
| **心理委员** | 高中/高校班级 | 探索设置 |
| **区域性中小学生心理辅导中心** | 县级 | 业务指导 + 技能培训 |
| **重点关注学生** | — | 学业就业压力、经济困难、情感危机、家庭变故、校园欺凌 |
| **转介通道** | 部门联动 | 教育+卫健+网信+公安+精神卫生机构 |

### 3.5 任务五：建强心理人才队伍（最关键）

> **17 部门政策的核心约束力指标**

| 配备对象 | 配备要求 |
| :--- | :--- |
| **高校专职心理教师** | **1:4000 师生比**，**每校至少 2 名** |
| **中小学心理教师** | **每校至少 1 名** 专（兼）职 |
| **县级教研员** | 配备心理教研员 |
| **专业背景** | 鼓励具有心理学专业背景 |
| **职称体系** | 心理健康教师职称可纳入思政、德育系列或单独评审 |
| **辅导员培训** | 高校辅导员攻读心理学/社会工作硕士支持 |

### 3.6 任务六：支持心理健康科研

- 汇聚**心理科学、脑科学、人工智能**等学科资源
- 支持全国/地方**重点实验室**开展学生心理健康研究
- 推动 AI 技术在心理健康**监测预警、教育、咨询、干预**应用

### 3.7 任务七：优化社会心理服务

- 加强**儿童医院 / 精神专科医院 / 妇幼保健机构** 儿童心理咨询门诊
- **社区心理服务平台**（民政 + 卫健 + 共青团 + 妇联）
- 12345（含 12320 公共卫生）+ **12355 青少年服务热线** + **12356 心理援助热线** 培训
- **家庭教育培训**（妇联 + 教育 + 关工委）
- **未成年人保护**（督促监护令、一站式办案区、五老工作室）

### 3.8 任务八：营造健康成长环境

- 广泛开展心理健康科普
- 监管网络游戏、直播、短视频
- 治理校园周边无底线营销
- 净化未成年人网络环境

## 四、2025 量化目标

| 指标 | 2025 目标 |
| :--- | :--- |
| **配备专（兼）职心理健康教育教师的学校比例** | **95%** |
| **开展心理健康教育的家庭教育指导服务站点比例** | **60%** |
| 高校专职心理教师师生比 | 1:4000 |
| 中小学每校心理教师 | ≥ 1 名 |
| 高校每校专职心理教师 | ≥ 2 名 |
| 心理健康课程学分（高校） | 2 学分 / 32-36 学时 |
| 学生心理健康测评频率 | 每学年 ≥ 1 次 |

## 五、2025-2026 配套延伸政策

### 5.1 教育部《进一步加强中小学生心理健康工作十条措施》（2026-01）

> 2026-01 教育部办公厅印发，**对 17 部门政策的"加强版"**

| 十条 | 核心 |
| :--- | :--- |
| 1. 缓解考试升学焦虑 | 每周"无作业日"+ 严控考试排名 |
| 2. 体育每天 2 小时 | 中小学综合体育活动 ≥ 2 小时 |
| 3. 保障充足睡眠 | 不要求提前到校 + 严控超时学习 |
| 4. 培养健康用网 | 严禁手机进课堂 + "息屏行动" |
| 5. 特殊学生群体关爱 | 留守/流动/孤儿"一生一策" |
| 6. 监测预警 | **全国学生心理健康监测预警系统** + 每名学生每学年测评 ≤ 1 次 |
| 7. 全员育心制度 | 班主任 + 专兼职心理教师 + 精神科医师 **三级体系** |
| 8. 校园心理环境 | "护苗行动" + 兴趣小组 + "生生有社团" |
| 9. 家庭和谐 | 每学期 ≥ 2 次家庭教育指导活动 |
| 10. 部门协同 | 12355 + 12356 联动 + 重大心理问题发现机制 |

### 5.2 教育部《关于全面推进健康学校建设的指导意见》（2026-02）

> 8 方面重点任务，与心理健康直接相关：
> - **深化心理健康教育**
> - 全体教师发现并有效处置心理健康问题
> - 中小学心理作为家长学校必讲内容
> - **落实中小学生每天综合体育活动 ≥ 2 小时**
> - 推行"课间 15 分钟"
> - 大学生每周 ≥ 3 次有强度课外体育锻炼

## 六、与 25 部委方案的关系

> 两者形成"**学生端 + 全人群端**"的政策呼应

| 维度 | 17 部门 2023-2025 | 25 部委 2026+ |

| **重点人群** | 学生（K-12 + 高校）| 全人群（学生/职业/老人/特殊）|
| **时间窗口** | 2023-2025 | 到 2030 |
| **执行部门** | 17 部门（教育牵头）| 25 部门（卫健委牵头）|
