# 12356 全国统一心理援助热线

## 一句话概述

> 12356 是 **国家卫生健康委协调工业和信息化部设置** 的全国统一心理援助热线电话号码，2024-12-25 公告，2025-05-01 前各地全部并轨运行。一号接通心理援助、自动联动 110/119/120、每设区市至少 2 个坐席、每日提供 ≥18 小时服务。截至 2025 年底，**全国已接通电话 70 余万通，成功实施危机干预近万起**。

## 关键事实

| 字段 | 内容 |
| :--- | :--- |
| **号码** | **12356** |
| **设置主体** | 国家卫生健康委 + 工业和信息化部 |
| **公告日期** | 2024-12-25（国家卫健委发布会） |
| **全国并轨时点** | 2025-05-01 0 时前 |
| **首批开通省份** | 北京、天津、上海、浙江、广西（2025-01-20 通报） |
| **全部省份开通** | 2025-05-01 前完成 |
| **服务时长** | 每日 **≥ 18 小时** |
| **坐席配置** | 每设区市 ≥ **1 条热线、≥ 2 个坐席** |
| **承担层级** | 设区市暂不具备条件时由 **省级热线** 承担 |
| **过渡安排** | 原号码 + 12356 双轨并行 |
| **服务内容** | 心理健康教育、心理咨询、心理疏导、**心理危机干预** |
| **接通情况** | 截至 2025 年底：70+ 万通来电，**近万起成功危机干预** |
| **性质** | 公益服务、匿名通话 |
| **联动** | 110 / 119 / 120 + 综治维稳 |

## 一、设立背景与历程

### 1.1 号码沿革

| 阶段 | 时间 | 状态 | 用途 |
| :--- | :--- | :--- | :--- |
| 阳光计生服务热线 | 2008 年 | 已废止 | 人口计生服务 |
| 卫健委延续 | 2018 年 | 已并轨 | 计划生育咨询 |
| **全国统一心理援助热线** | **2024-12-25 公告 / 2025-05-01 全国开通** | 当前 | 心理健康全人群服务 |

### 1.2 设立动因

- 此前全国心理援助热线已开通 **600+ 条**，设置 **1200+ 个座席**
- **号码类型多样**（各省/市自设号码）、**群众记忆不便**
- 设立统一短号码 → 提高可及性、规范性、专业性
- 配合 25 部委《健全社会心理服务体系和危机干预机制实施方案》中"省级 12356 心理援助平台"目标

## 二、覆盖范围与配置标准

### 2.1 行政覆盖

> **原则上每个设区的市（含直辖市、州、盟等）至少开通 1 条心理援助热线，每条心理援助热线至少设置 2 个心理援助热线坐席**，并配备足量符合要求的热线咨询员，每日提供不少于 18 小时心理援助服务。

| 行政层级 | 配置要求 | 兜底机制 |
| :--- | :--- | :--- |
| **设区市** | ≥1 条热线、≥2 个坐席、≥18 小时/日 | 暂不具备条件可由省级承担 |
| **省份** | 建成省级 12356 心理援助平台 | 统一调度 |
| **国家** | 制定规范、督导评估、组建专家巡讲团 | 顶层设计 |

### 2.2 服务团队

- 配备 **足量符合要求的热线咨询员**（专业资质 + 培训认证）
- **匿名通话** 制度 — 降低求助门槛
- 持续 **扩容**：根据接听量增加情况采取扩容保障措施
- 与 **110、119、120** 服务热线和综治维稳工作建立联动机制

## 六、配套政策与战略意义

### 6.1 政策抓手

- 2024-12《国家卫生健康委关于应用"12356"全国统一心理援助热线电话号码的通知》
- 2025 全国卫生健康工作会议 → 2025-2027 年为"儿科和精神卫生服务年"
- 2025 政府工作"为民服务八件实事"重点任务
- 2026-04 25 部委《健全社会心理服务体系和危机干预机制实施方案》

### 6.2 战略意义

1. **可及性革命**：一号通达全国，记忆成本归零
2. **专业性升级**：持证咨询员、统一培训、伦理规范
3. **危机响应网络**：与公安/医疗/消防联动，建立心理危机 24h 响应
4. **数据基础**：70+ 万通通话、近万起危机干预 → 为监测预警提供数据来源
5. **去污名化**：匿名通话、文化渗透、心理科普

## 七、对个人与机构的行动建议

### 7.1 对个人（求助者）

- 有心理困扰、情绪问题、想了解心理健康知识 → 直接拨打 **12356**
- **不需要怀疑自己有精神障碍** 才可以拨打
- 危机状态（自伤/伤人风险）可同时拨打 **110/120** 联动响应

### 7.2 对机构（学校/企业/社区）

- 将 12356 纳入 **新员工培训 / 学生入学教育** 必讲内容
- 在 EAP / 学校心理辅导手册中加入 12356 一键拨号
- 关注后续省级平台建设进展，配合基层心理服务阵地
