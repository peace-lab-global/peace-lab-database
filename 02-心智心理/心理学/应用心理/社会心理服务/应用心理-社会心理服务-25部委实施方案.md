# 健全社会心理服务体系和危机干预机制实施方案（25 部委）

## 一句话概述

> 2026 年 4 月 9 日，国家卫生健康委联合中央社会工作部、教育部、公安部、共青团中央等 **25 个部门** 印发《健全社会心理服务体系和危机干预机制实施方案》（以下简称《实施方案》），锚定 **到 2030 年建成覆盖全人群、全生命周期的社会心理服务体系和危机干预机制** 的总目标，从 5 个方面部署 18 项主要任务。

## 一、总体目标（到 2030 年）

### 1.1 量化指标体系

| 维度 | 2030 年量化目标 |
| :--- | :--- |
| **基层覆盖** | **80% 以上** 的行政村、城市社区设置心理咨询室或社会工作室，并提供心理服务 |
| **教育系统** | 各级各类学校具有心理服务场所（心理辅导室等），加强专（兼）职心理健康教育教师队伍建设 |
| **机关企事业单位** | 各级党政机关和国有企事业单位、各类非公经济组织创造条件为员工开展心理服务 |
| **医疗系统** | 各级公立精神专科医院、各县（区）至少有 1 所医院提供心理门诊服务 |
| **省级平台** | 各省（自治区、直辖市）建成 **省级 12356 心理援助平台** |
| **危机干预** | 各省份及市（地、州、盟）具有 **心理危机干预和心理援助队伍** |

### 1.2 八层次生态体系

> 方案构建"全域覆盖"的社会心理服务生态，覆盖以下 8 个层次：
> 1. **个体调适** 2. **家庭关爱** 3. **人际互助** 4. **社区服务**
> 5. **单位关怀** 6. **专业支撑** 7. **文化浸润** 8. **政策保障**

## 二、五大方面 / 18 项主要任务

### 方面一：健全建强社会心理服务阵地（夯实治理基础）

- 在 **基层**（村/社区综治中心、党群服务中心）开设心理咨询室或通过购买服务提高服务能力
- 在 **教育系统**（高校心理健康教育与咨询中心、中小幼心理辅导室）建设阵地
- 在 **机关和国有企事业单位** 设立心理健康辅导室或购买服务
- 推动 **综合医院** 开设心理门诊，强化精神专科医院心理门诊
- 鼓励 **中医医疗机构** 开设中医心理等科室（接续 2018 试点政策）

### 方面二：壮大社会心理服务人才队伍

- 加强 **心理服务相关专业人才培养**（高校学科、专业认证）
- 发展 **医疗卫生机构** 心理健康服务队伍（精神科医师、心理治疗师、心理咨询师）
- **规范社会心理咨询人员管理**（行业准入、伦理、督导）
- 培育 **社会工作专业人员** 和 **志愿者队伍**（社会心理服务志愿体系）

### 方面三：强化重点人群心理服务

- **儿童青少年**：学校心理辅导 + 12355 青少年综合服务平台
- **职业人群**：机关企事业单位 EAP / 心理健康服务
- **特定群体**：老年人、孕产妇、残疾人、流动人群、新型就业群体

### 方面四：拓展社会心理服务形式与内容

- **发挥 12356 心理援助热线作用**（一号接通、与 110/119/120 联动）
- **建强用好 12355 青少年综合服务平台**
- 加强 **心理健康促进与教育**（巡讲、科普、社会主义核心价值观融合）
- 强化 **精神文明建设** 与传统文化养心志功能

### 方面五：推进心理危机干预和心理援助工作

- 建强 **心理危机干预和心理援助队伍**（省/市/县三级）
- 做好 **日常服务**（常态化心理援助）
- 加强 **重大突发事件时** 的心理危机干预和心理援助（如自然灾害、群体性事件、校园重大危机等）

## 三、政策核心转变：从"危机干预"到"危机预警"

> **最大政策亮点**：重心从 **事后心理危机干预** 转向 **事前心理危机预防**。

- 强调 **提高心理韧性**、开展 **生命教育**、**挫折教育**
- 要求建立 **心理健康监测预警体系**（定期调查制度、预警指标体系）
- 学校要建立 **学生心理健康档案**；企事业单位关注员工心理状况；社区掌握居民心理健康基本情况
- 推动 **智能化、数字化工具** 应用于大规模心理普筛、动态情绪追踪

## 四、组织实施保障

| 保障维度 | 具体要求 |
| :--- | :--- |
| **组织领导** | 各地党委政府将工作纳入 **平安中国、健康中国建设总体规划** |
| **部门协同** | 卫健、社工、教育、公安、共青团 5 部门强化牵头；其余部门按职责落实 |
| **服务延伸** | 2026 年提出 **新增 110 个县** 提供心理门诊服务（5 月 1 日前所有地级市已实现） |
| **能力建设** | 精神科作为薄弱专科持续加强建设（纳入临床重点专科、省级精神卫生项目） |
| **资源保障** | 服务体系建设、编制、薪酬、价格、支付等方面加大支持 |
| **督导评估** | 定期督导与试点评估，确保 2030 目标实现 |

## 五、与 2018 试点方案的对比升级

| 维度 | 2018 试点方案（10 部门） | 2026 实施方案（25 部门） |
| :--- | :--- | :--- |
| **部门数** | 10 部门（卫健委、中央政法委、中宣部、教育部、公安部、民政部、司法部、财政部、信访局、残联） | **25 部门**（新增中央社工部、网信办、人社部、工会、妇联等） |
| **目标年** | 2021 年试点结束 | **2030 年** 全面建成 |
| **行政村/社区覆盖率** | 80% | 80%（保持，并强化服务供给） |
| **学校心理辅导室** | 高校普遍设立、中小学设立 | 各级各类学校 + 专（兼）职教师队伍 |
| **综合医院心理门诊** | 100% 精神专科医院、40% 二级以上综合医院 | 各级公立精神专科医院 + 县（区）至少 1 所 |
| **热线平台** | 24 小时公益心理援助平台 | **省级 12356 心理援助平台**（一号接通、联动 110/119/120） |
| **危机干预** | 组建心理危机干预队伍 | 重大突发事件 + 日常服务并重 |
| **特色** | 鼓励中医心理 | 强化科技赋能、智能化预警 |

## 六、关键启示与跨引用

- **政策性质**：从"试点探索"升级为"全国建设"，进入系统化、规范化、常态化新阶段
- **可及性提升**：打通热线（12356）、平台（12355）、阵地（心理咨询室）三位一体的服务入口
- **预防为主**：监测预警体系建立是关键创新，配合智能化心理测评工具需求增长
- **人才缺口**：心理服务专业人才、社会工作专业人员、志愿者队伍均为建设重点
