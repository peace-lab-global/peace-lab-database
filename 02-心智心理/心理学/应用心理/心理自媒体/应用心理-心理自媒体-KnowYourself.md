# KnowYourself（KY 知我探索）

## 一句话概述

> **KnowYourself（KY）** 是中国 **心理学科普自媒体现象级头部**，**2015-11-24** 创立，全网 **2000 万+ 粉丝**，覆盖微信公众号 / 知乎 / 微博 / 小红书 / 抖音。旗下有 **月食 App（心理测评/茶会/聊愈/冥想/共练营的社区型 App）** 和 **知我心理 App（专业心理咨询）**。**"做有审美、有态度、有先锋的心理学公众号"**，**89.6% 文章阅读量 10 万+**（2017 数据，2018-2026 仍头部）。

## 一、内容矩阵与传播策略

### 1.1 六大内容板块

| 板块 | 占比 | 典型选题 |
| :--- | :--- | :--- |
| **原生家庭** | 高 | 中国式家庭关系、原生家庭创伤、父母沟通 |
| **情绪管理** | 高 | 焦虑、抑郁、情绪内耗、情绪急救 |
| **自我发展** | 高 | 自我认同、自我价值、成人初显期（18-25）|
| **亲密关系** | 高 | 婚恋、依赖、回避、沟通 |
| **人际关系** | 中 | 边界、社交焦虑、职场关系 |
| **生涯规划** | 中 | 职业选择、内卷、空心病 |

### 1.2 传播策略核心

> KY 成功的本质：**不是做心理学科普，而是"提供社交货币"**——帮助人们用心理学视角表达感受和情绪，并用专业术语背书。

#### 三大策略（2017 学术研究总结）

| 策略 | 内容 | 效果 |
| :--- | :--- | :--- |
| **稀缺感** | 从日常现象提取专业关键词并综述 | 大众感到"高级" |
| **逼格路线** | 引用经典格言 + 高级配图 | 转发即"展示审美" |
| **背书机制** | 转发 = 表达情绪 + 专业术语背书 | 区别于纯鸡汤 |

#### 受众心理六维度

| 维度 | 满足方式 |
| :--- | :--- |
| **求知** | 提供冷门但专业的心理学知识 |
| **求新** | 结合新近热点（电影、节日、新闻）|
| **求同** | 80/90 后共情话题（春节、单生、回家）|
| **求异** | 逆向思维（"爱"之于"控制"）|
| **求趣** | 网络新词（备胎、好人卡、行走的教科书）|
| **求美** | 动人故事 + 人文情怀（殡葬师、临床社工）|

## 四、内容争议与边界

> KY 不是"治愈系"，是"科学认识自己" — 用户期望值管理

### 4.1 早期争议

- "把专业心理学讲成科普" 是否稀释严肃性
- 部分文章过于迎合"转发需求"导致深度不足
- 自媒体科普与专业咨询的边界

### 4.2 业务延伸

> 从内容 → 测评 → 课程 → 咨询 → 社区，KY 已建立完整心理服务生态

| 阶段 | 业务 | 形态 |
| :--- | :--- | :--- |
| 2015-2017 | 内容为王 | 微信公众号科普 |
| 2018-2020 | 测评 + 课程 | 月食 App 上线 |
| 2021-2023 | 心理咨询 | 知我心理 App |
| 2024-2026 | 品牌延伸 | 与央广合作微综艺《剧懂人心》|
