## 二、武志红思想体系

> 核心命题：**"自我"**（自恋 / 自我诞生 / 真实自我）

| 核心概念 | 含义 |
| :--- | :--- |
| **"自我的诞生"** | 人的大多数痛苦源于"自我"尚未形成 |
| **"真实自我 vs 虚假自我"** | 父母过度干预导致孩子形成虚假自我 |
| **"全能自恋"** | 追求完美是对自己的持续攻击 |
| **"讨好型人格"** | 满足别人需求大于自己的需求 |
| **"心流"** | 持续存在的愉悦体验，塑造人生差异 |
| **"自恋简单，自信很难"** | 自信源于被看见的真实 |
| **"成为更好的自己，不如更好地成为自己"** | 接受不完美 |
