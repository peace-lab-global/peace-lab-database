# 简单心理 + 好心情（互联网医院 + AI 风险筛查）

## 一句话概述

> **简单心理**（2014 年成立）走 **高端 APA 标准路线**，**70.77% 硕博 + 9% 通过率**，单次咨询 **500-1200 元**，擅长重度心理创伤、人格障碍、疑难案例；**好心情**（2015 年成立）走 **互联网医院 + AI 风险筛查路线**，自主研发 **AI 情绪识别 + AI 心理风险筛查 + AI 防自杀** 三大系统，覆盖北京、上海、天津、南京等城市。两个平台代表"专业纵深"与"医疗合规"两条互补路径。

## 一、简单心理（高端 APA 派代表）

### 1.1 平台特色

> **Slogan**：「只提供高质量的心理服务」

- **专业派** 标杆，对标美国心理学会（APA）标准
- 信息透明度高 — 咨询师信息高度公开
- 大部分咨询师为持证 + 接受过系统训练
- 严格筛选机制：**9%** 通过率（高于行业 5%）

### 1.2 核心数据

| 指标 | 数据 |
| :--- | :--- |
| **成立** | 2014 年 4 月 |
| **下载量** | 125 万+（近 30 天 1617） |
| **融资** | 数百万美元 A 轮 |
| **通过率** | 9% |
| **硕博比例** | 70.77%+ |
| **核心功能** | 课程 / 测评 / 心理咨询 / 热线 / 问答 |
| **特色服务** | 1 对 1 免费倾诉热线 |

### 1.3 产品功能结构

```
┌────────────────────────────────┐
│  首页   咨询   课程   我的        │
├────────────────────────────────┤
│  课程    测评    心理咨询   热线   问答   │
└────────────────────────────────┘
```

- **课程** — 基础心理学 + 咨询师培训（按等级、标签、形式多维筛选）
- **测评** — 专业量表
- **心理咨询** — 1V1 咨询（首页 + tab 双入口）
- **热线** — 免费倾诉（特色）
- **问答** — 心理社区

### 1.4 核心场景

| 场景 | 用户类型 |
| :--- | :--- |
| **预算充足** | 追求高质量、深度、长程治疗 |
| **看重资质** | 关注咨询师学历、隐私、伦理 |
| **疑难案例** | 重度心理创伤、人格障碍 |
| **严肃治疗** | 长期精神动力学 / CBT 等专业取向 |

## 二、好心情（互联网医院 + AI 风险筛查）

### 2.1 平台定位

> 国内最早一批 **互联网心理医院** 之一，**北京/上海/天津/南京** 等多城市覆盖，**医疗数字化 + AI** 路径代表

- **核心能力**：心理医疗 + 数字化 + AI
- **特色**：互联网医院资质 + 三大 AI 系统
- **目标**：从筛查 → 诊疗 → 用药全闭环

### 2.2 三大 AI 系统（自主研发）

| 系统 | 功能 | 价值 |
| :--- | :--- | :--- |
| **AI 人工智能人脸情绪识别** | 通过视频捕捉微表情，识别情绪状态 | 客观化情绪评估 |
| **AI 人工智能心理风险筛查** | 抑郁、焦虑、自杀风险量化 | 早期识别高危人群 |
| **AI 人工智能防自杀系统** | 实时识别高危语言 / 行为 | 危机干预辅助 |

### 2.3 业务覆盖

| 维度 | 内容 |
| :--- | :--- |
| **核心业务** | 抑郁 / 焦虑 / 失眠 / 心理危机 |
| **服务闭环** | 筛查 → 问诊 → 治疗 → 用药 → 随访 |
| **城市覆盖** | 北京 / 上海 / 天津 / 南京等 |
| **用户量** | 数十万级付费用户 |
| **专业团队** | 精神科医师 + 心理咨询师 + AI 工程师 |

### 2.4 与 25 部委方案对接价值

> **互联网医院资质** 是 25 部委《健全社会心理服务体系和危机干预机制实施方案》"省级 12356 平台"建设的关键合作对象。

- **合规性强** — 互联网医院牌照（医疗级）
- **AI 风险识别** — 符合方案"监测预警体系"要求
- **处方能力** — 配合精神专科医院 + 综合医院心理门诊
- **城市节点** — 与卫健委"心理门诊"覆盖目标契合

## 四、用户选择决策树

```
是否处于心理危机 / 自杀风险？
├─ 是 → 12356 全国统一心理援助热线
└─ 否 → 是否有医疗需求（药物 / 诊断）？
    ├─ 是 → 好心情（互联网医院）
    └─ 否 → 预算如何？
        ├─ 预算充足 + 疑难案例 → 简单心理
        ├─ 预算一般 + 深度需求 → 壹心理咨询
        ├─ 预算有限 + 轻度困扰 → 此刻心理
        └─ 临时倾诉 + 突发情绪 → 鲸鱼倾诉 / 鲸鱼 Alice-AI
```
