# 心理服务咨询平台第二阵营：昭阳医生 / 央心心理 / 泊恩医疗

## 一句话概述

> 国内心理咨询平台形成"第一阵营 + 第二阵营"格局：第一阵营以**壹心理（生态）/ 简单心理（专业派）/ 好心情（医疗派）**为代表，第二阵营以**昭阳医生（S2B2C 模式 10000+ 精神科医生）/ 央心心理（央视展播 性价比）/ 泊恩医疗（线下连锁诊所）**为典型。第二阵营在**精神科医生资源 / 测评量表 / 线下履约 / 价格亲民**等维度形成差异化优势。

## 关键事实速览

| 平台 | 核心定位 | 关键数据 | 价格参考 |
| :--- | :--- | :--- | :--- |
| **昭阳医生** | S2B2C 精神科医生平台 + 实体心晴门诊 | 10000+ 精神科医生 / 患者 50 万+ / 满意度 99.4% / 数亿元 B 轮 | 互联网医院诊费 50-300 元 |
| **央心心理** | 央视展播 / 奥运冠军代言 / 高性价比 | 2000 持证咨询师 / 200+ 测评量表 / 中国心理学会注册督导师 | 20 分钟 68 元 / 60 分钟 198 元 |
| **泊恩医疗** | 线下连锁精神心理诊所 | 全国多城市覆盖 / 精神心理全科 | 诊费 600-1500 元 / 次 |

## 一、昭阳医生 —— 精神科医生密度最高的线上平台

### 1.1 平台基础

| 字段 | 内容 |
| :--- | :--- |
| **运营主体** | 昭阳健康（广州）科技有限公司 / 昭阳健康（广州）互联网医院 |
| **APP 矩阵** | 昭阳医生（医生版）/ 昭阳医生（患者版）/ 心晴门诊药房 |
| **成立时间** | 2015 年 |
| **官网** | www.zhaoyang120.com |
| **商业模式** | S2B2C（Doctor Tools → Doctors → Patients） |
| **创始人** | 林昭宇（20 年临床经验精神科医生） |

### 1.2 关键数据

| 指标 | 数据 |
| :--- | :--- |
| 入驻医生数 | **10000+ 精神科医生及心理咨询师** |
| 主任级别医生入驻率 | **75%** |
| 服务患者数 | **50 万+** |
| 覆盖区域 | **30 个核心省/市三级医院** |
| 医生持续使用率 | **91%** |
| 处方咨询累计 | 数百万单 |
| 患者满意度 | **99.4%** |
| 累计融资 | 5 次（2018 A 轮 2000 万 / 2021-06 B 轮数亿元） |
| B 轮领投 | **经纬中国 + 千骥资本**（联合领投）/ 欧普家族办公室跟投 |

### 1.3 三大业务体系

1. **昭阳医生 APP**（互联网医院）
   - 医生管理患者、随访、复诊、在线处方
   - 诊前标准化问卷 / 诊后随访系统
   - 医生个人科研资料库

2. **心晴门诊**（实体诊所）
   - 专注精神心理诊疗
   - 一对一/二对一贴心诊疗
   - 携手三甲医院精神科医生

3. **心晴门诊药房**（自营药店）
   - 药品来源与公立医院相同（广东省药品交易中心采购）
   - 药品种类与省级精神专科医院匹配度 95%+
   - 与医药批发公司"共享库存"

### 1.4 三大业务模式对比

| 模式 | 优势 | 劣势 |
| :--- | :--- | :--- |
| **线上（昭阳 APP）** | 便利、隐私、可及性 | 不能做检查、不能面诊 |
| **线下（心晴门诊）** | 深度评估、用药精准 | 需要到店、需排队 |
| **O2O 闭环** | 完整 MDT 治疗 | 运营复杂 |

### 1.5 战略合作

- **聆心智能**（北大人工智能 + 精神心理团队）：数字化、智能化解决方案
- **强脑科技**（脑机接口 + 哈佛创新实验室华人团队）：FocusZen 正念舒压系统
- 已落地上海徐汇区（毗邻宛平南路 600 号上海市精神卫生中心）
- 2022-02 愈心心理咨询中心 + 昭阳健康大药房开业

### 1.6 核心壁垒

- **真实医生密度**：主任级 75% 入驻，10 年+ 临床经验
- **真实履约能力**：实体门诊 + 自营药房完整闭环
- **真实数据资产**：基于患者数据为药企提供真实世界研究（RWS）报告
- **真实合规资质**：广东省药品交易中心采购资质

### 1.7 行业认可

- 2019 未来医疗 100 强 · 中国榜 - 心理健康 TOP5
- 平台初心："对医学严谨，对生命敬畏"

### 1.8 行业评价（投资人说）

- **经纬中国**："精神心理线上化 + 政策支持 + 团队执行力"
- **千骥资本**："以诊疗为核心 + 数字化服务模式；看好精神心理产品和服务线上化潜力"
- **欧普家族办公室**："既深刻懂得客户需求，又能以最高效且温暖的方式提供服务"

### 2.2 价格参考（性价比优势明显）

| 服务 | 价格 |
| :--- | :--- |
| **20 分钟倾诉** | 68 元 |
| **60 分钟咨询** | 198 元 |
| 测评量表 | 200+ 免费/付费 |

### 2.3 三大核心优势

1. **权威背书强**：央视 + 奥运冠军 + 中国心理学会注册督导师
2. **价格亲民**：20 分钟 68 元，首次尝试门槛低
3. **测评量表全**：200+ 涵盖抑郁、焦虑、人格、亲子等全维度

### 2.4 适合人群

- 首次尝试咨询、预算有限
- 注重平台权威背书
- 喜欢先做测评再决定是否深度咨询
- 学生、职场新人、退休人群

## 五、用户选型决策树

```
你目前的状态？
├── 首次尝试、预算有限、想先测评
│   └── → 央心心理（20min 68 / 200+ 测评）
├── 已确诊抑郁/双相，需要长期复诊 + 用药
│   └── → 昭阳医生（互联网医院 + 心晴门诊）

│   └── → 壹点灵 / 好心情（医疗级）
├── 长程深度咨询，看重咨询师资质
│   └── → 简单心理（APA 标准 + 高通过率）
├── 预算非常有限 / 学生 / 职场新人
│   └── → 此刻心理（199/3 次）
├── 只想轻量级情绪宣泄
│   └── → 松果倾诉（9.9 元/30min）
└── 需要线下初诊 + 评估 + 检查
    └── → 泊恩医疗（实体连锁）
```

## 六、行业发展趋势

### 6.1 第二阵营崛起

- 精神科医生资源稀缺 → 谁能掌握医生资源谁就能做大
- 测评量表 + AI 心理评估 → 降低首次咨询门槛
- 线下连锁 + 实体履约 → 解决"线上无法做检查"痛点

### 6.2 整合与分化

- 第一阵营（壹心理、简单心理）向"生态"扩展
- 第二阵营向"专科 + 履约"分化
- **未来 3 年**：第二阵营头部公司可能被并购或上市

### 6.3 数字化升级

- 数字疗法（DTx）+ 心理咨询师深度协作
- 平台 → 不仅是"中介"而是"诊疗基础设施"
- 与 NMPA 数字疗法审批协同（参考 Flow FL-100 等）

### 6.4 政策驱动

- 25 部委 2026-04 实施方案：80% 行政村/社区设心理咨询室
- 各省 12356 心理援助平台全面建成
- 持证上岗硬门槛加速行业洗牌
