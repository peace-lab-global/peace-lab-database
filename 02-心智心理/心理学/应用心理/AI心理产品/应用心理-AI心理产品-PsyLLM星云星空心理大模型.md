# PsyLLM 星云星空心理大模型（健成星云）

## 一句话概述

> PsyLLM 是 **深圳健成星云科技有限公司** 自研的 **心理垂直领域大模型**，**国内首批通过国家网信办生成式人工智能服务备案** 的心理类大模型，**AAAI 2026 国际顶会论文入选**，在 **PsyEval 3 心理咨询能力评测体系** 中综合得分 **89.9**（共情/温暖/表达力核心指标领先）。其衍生的 **星云星空 App** 集成 AI 聊愈、心理测评、心灵百宝箱、心理课堂、记忆星球游戏化成长系统，覆盖 C 端个人、B 端企业/学校、G 端政府的全场景落地。

## 一、为什么需要"垂直"心理大模型

### 1.1 通用大模型的局限

> 国际 SOS 2026 报告 + WHO 数据：全球 **10 亿+** 心理健康问题人群，但通用大模型在心理咨询这种"高敏感、高风险、高情感卷入"场景存在显著短板。

| 维度 | 通用大模型（GPT/Claude/Gemini） | 垂直心理大模型（PsyLLM） |
| :--- | :--- | :--- |
| **核心训练目标** | 通用语言理解 | 心理咨询专业能力 |
| **语料构成** | 通用网页/书籍/代码 | 4000+ 万心理咨询专业语料 |
| **技法融合** | 不绑定咨询流派 | 300+ 咨询技术跨流派切换 |
| **共情深度** | 基础复述 + 情绪识别 | 长期记忆 + 正向引导 + 心理画像 |
| **长期陪伴** | 上下文窗口短 | 长期记忆存储 + 用户专属心理图谱 |
| **合规性** | 通用 AI 备案 | 国内首批心理类备案 + 临床验证 |
| **幻觉控制** | 通用价值对齐 | 医疗伦理 + 临床专家评分 |
| **典型问题** | "我理解你的感受"反复堆叠 | 主动引导识别深层问题 |

### 1.2 行业需求

- 中国 1.9 亿心理咨询需求人口，仅 **140 万** 持证咨询师、**10 万** 实际执业
- 精神科医师严重不足，候诊 2-4 周，专业咨询 300-800 元/次
- **国内每 10 万人** 拥有 **不足 3 名** 心理健康专业人员
- **84.3%** 有困扰者因病耻感、费用高、资源不均从未寻求专业帮助
- AI 原生应用月活用户已突破 **1.48 亿**

## 三、PsyEval 3 评测体系

> PsyLLM 在 **PsyEval 3** 心理咨询能力评估体系中取得 **89.9 综合得分**（全球榜单第 1）。PsyEval 3 是 15 维度专业评测体系，由临床心理专家依据专业标准参与评分。

| 维度类别 | 评测维度 | 备注 |
| :--- | :--- | :--- |
| **情感类** | 情感共鸣、应对阻抗、温暖表达 | PsyLLM 优势维度 |
| **逻辑类** | 逻辑一致性、表达力 | 高分 |
| **专业类** | 咨询技术应用、跨流派整合 | 高分 |
| **安全类** | 风险识别、伦理边界 | 合规背书 |

## 四、产品矩阵（B/C/G 三端全场景）

### 4.1 C 端：星云星空 App

**核心功能：**

| 功能 | 内容 |
| :--- | :--- |
| **南希聊愈** | 心理垂直大模型驱动的数字人对话；4 种交互方式（文本/语音/电话/视频） |
| **心灵百宝箱** | 轻量化自助工具（蝴蝶拍安抚、节奏呼吸、思维刹车等情绪急救） |
| **心理课堂** | 系统化科普课程（情绪管理/人际/成长等） |
| **心理测评** | 150+ SCI/SSCI/CSSCI 顶刊量表 |
| **记忆星球** | 游戏化成长系统，沉淀用户十维心理画像 + 心灵生态报告 |

### 4.2 线下终端：AI 心理师一体机 / AI 心灵小屋

- 部署在医院、学校、政企单位
- 多模态信息捕捉（语音语调 + 微表情 + 语义）
- 20 分钟半结构化访谈，**当场生成极具医疗参考价值的评估报告**
- 与医务人员联动：AI 预问诊 → 医生精准干预

### 4.3 B 端 / G 端：心理健康云平台

- 区域心理危机干预预警系统（深圳龙岗区慢性病防治院落地）
- 政企 EAP 整合（劲牌、华电煤业、邦彦等）
- 学校心理服务一体化（教育部"社会心理服务进校园"配套）
- 心理测评 + AI 评估 + 分层干预 + 持续追踪 全流程
