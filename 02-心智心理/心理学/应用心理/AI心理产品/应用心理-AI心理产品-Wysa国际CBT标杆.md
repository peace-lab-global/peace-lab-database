# Wysa（国际 AI 心理产品 CBT 标杆）

## 一句话概述

> **Wysa** 是总部位于伦敦的 **Touchkin eServices** 公司开发的 **国际 AI 心理支持应用**，以 **CBT（认知行为疗法）/ DBT（辩证行为疗法）/ 正念** 等循证心理学体系为核心，**全球评分 4.4/5**，**获得医疗器械相关认证**，符合 **HIPAA / GDPR** 隐私规范，已在 **700+** 企业 EAP、医疗机构、保险机构中部署，是国际"循证 + 合规"AI 心理产品的标杆。

## 关键事实

| 字段 | 内容 |
| :--- | :--- |
| **产品名** | Wysa |
| **厂商** | Touchkin eServices Ltd.（英国伦敦） |
| **创立** | 2015 年 |
| **核心方法** | CBT / DBT / 正念循证体系 |
| **合规认证** | HIPAA（美国健康隐私）/ GDPR（欧盟数据保护） |
| **医疗器械** | 医疗器械相关认证（具体等级按地区） |
| **临床合作** | 与 NHS（英国国民健康服务）、保险公司等合作 |
| **全球评分** | 4.4 / 5（应用商店） |
| **企业客户** | 700+ 全球企业 EAP 部署 |
| **核心用户群** | 长期焦虑、压力性失眠、轻中度情绪困扰 |
| **免费/付费** | 免费版：AI 文字聊天 + 基础情绪自测；付费版：全套调节工具 + 情绪趋势报表 |

## 一、产品定位

### 1.1 与 PsyLLM 路径对比

| 维度 | Wysa（国际） | PsyLLM（国内） |
| :--- | :--- | :--- |
| **核心方法** | CBT/DBT/正念循证 | 300+ 咨询技术跨流派 |
| **底层模型** | 标准化对话模型（不公开） | 心理垂直大模型（自研） |
| **认证重点** | 医疗器械 + HIPAA/GDPR | 国家备案 + 临床验证 |
| **商业模式** | B 端 EAP + B2C 双线 | B/C/G 三端全场景 |
| **强项** | 循证严谨、隐私合规、长期焦虑失眠干预 | 共情深度、临床准确率、跨流派整合 |
| **弱项** | 本土化弱、个性化深度有限 | 临床验证数据厂商自报 |

### 1.2 国际 AI 心理产品"四大流派"

| 流派 | 代表产品 | 特点 |
| :--- | :--- | :--- |
| **CBT 循证** | **Wysa**、Woebot | 标准化、循证、临床合作支撑 |
| **情绪陪伴/匿名** | Earkick | 隐私保护、即时情绪支持、状态追踪 |
| **情绪识别分析** | Youper | 引导式提问、可视化数据、ACT/CBT 整合 |
| **CBT 早期对话** | Woebot | 高频低门槛短对话、识别非理性思维 |

## 二、核心功能与循证方法

### 2.1 核心功能

| 功能 | 内容 |
| :--- | :--- |
| **AI 情绪对话** | 自然语言共情式回应 |
| **结构化心理工具库** | 内置 CBT/DBT/正念循证练习 |
| **情绪记录与追踪** | 心情打卡 + 趋势回顾 |
| **呼吸放松** | 引导式呼吸引导 |
| **压力疏导** | 思维重构 / 行为激活 |
| **情绪脱敏** | 暴露练习 / 认知重评 |
| **睡眠干预** | CBT-I（认知行为治疗失眠）方法 |

### 2.2 CBT/DBT/正念的方法论内核

| 方法 | 核心机制 | 适用场景 |
| :--- | :--- | :--- |
| **CBT 认知行为疗法** | 识别负性自动思维 → 检验证据 → 替代性思维 | 焦虑、抑郁、压力 |
| **DBT 辩证行为疗法** | 正念 + 情绪调节 + 人际效能 + 痛苦耐受 | 情绪失调、冲动行为 |
| **正念 Mindfulness** | 不评判的当下觉察 | 焦虑泛化、失眠、躯体化紧张 |
| **CBT-I** | 睡眠卫生 + 刺激控制 + 睡眠限制 | 压力性失眠 |

## 三、合规与临床支撑

### 3.1 隐私与合规

| 认证 | 范围 | 说明 |
| :--- | :--- | :--- |
| **HIPAA** | 美国健康隐私 | 适用于美国市场（雇主保险 + 医疗机构） |
| **GDPR** | 欧盟数据保护 | 适用于欧洲市场 |
| **医疗器械认证** | 特定地区 | 满足某些国家作为医疗器械销售的法规要求 |
| **数据加密** | 端到端 | 保护用户对话隐私 |

### 3.2 临床合作

- **NHS（英国国民健康服务）**：与 NHS 合作探索数字化心理服务路径
- **保险机构**：与多家保险公司合作，纳入心理健康保障
- **企业 EAP**：700+ 全球企业部署（包括金融/科技/制造/医疗）
- **学术研究**：与剑桥大学、UCL 等学术机构合作
