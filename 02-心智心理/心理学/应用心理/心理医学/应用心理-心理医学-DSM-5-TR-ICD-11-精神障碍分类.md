# DSM-5 / ICD-11 / CCMD-3 精神障碍分类系统

## 一句话概述

> 全球精神疾病诊断 **3 大系统**：(1) **DSM-5**（2013-05 美国 APA 发布，**北美主流**）；(2) **ICD-11**（**2018-06 发布 / 2022-01 正式生效**，WHO 全球使用，**2019-03 中国全面启用**）；(3) **CCMD-3**（2001，中国精神卫生本土化分类）。ICD-11 是 20 多年来首次重大修订，**加入游戏障碍、强迫性行为障碍、复杂 PTSD**，**取消急性应激**，**性别不一致去精神障碍化**。中国采用 ICD-11 + 本土 CCMD-3 双轨。

## 关键事实

| 系统 | 全称 | 发布主体 | 最新版 | 生效时间 | 覆盖范围 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **DSM-5** | 精神障碍诊断与统计手册（第 5 版）| 美国精神病学会（APA）| 2013-05 | 2013-05 | 北美 / 学术研究金标准 |
| **ICD-11** | 国际疾病分类（第 11 版）| 世界卫生组织（WHO）| 2018-06 发布 | **2022-01-01 正式生效** | 全球（**2019-03 中国全面启用**）|
| **CCMD-3** | 中国精神障碍分类与诊断标准（第 3 版）| 中国精神卫生专家 | 2001 | 2001 | 中国本土化 |

## 一、ICD-11（最新 / 全球）

### 1.1 ICD-11 关键变化（vs ICD-10）

| 变化 | 内容 |
| :--- | :--- |
| **游戏障碍（新增）** | 数字 / 视频游戏行为成瘾 |
| **强迫性行为障碍（新增）** | "性成瘾"概念医学化 |
| **复杂 PTSD（新增）** | 区别于经典 PTSD |
| **长时间悲伤障碍（新增）** | 长期病理性悲伤 |
| **性别不一致（去精神障碍化）** | 移至"性健康相关疾病"|
| **急性应激（去精神障碍化）** | 移至"健康影响因素"|
| **ADHD（首次正式纳入）** | ICD 历史上首次 |
| **人格障碍（彻底改革）** | 取消类别，改为维度评估 |
| **精神分裂症亚型（取消）** | 改用症状限定分类（6 维度）|
| **新的诊断代码** | 优化编码体系 |

### 1.2 ICD-11 章节结构（精神障碍部分）

| 章节 | 内容 |
| :--- | :--- |
| 6A00-6A02 | 神经发育障碍（含 ADHD、ASD）|
| 6A20-6A2Z | 精神分裂症及其他原发性精神病性障碍 |
| 6A60-6A6Z | 双相及相关障碍 |
| 6A70-6A7Z | 抑郁障碍 |
| 6B00-6B0Z | 焦虑及恐惧相关障碍 |
| 6B20-6B2Z | 强迫及相关障碍 |
| 6B40-6B4Z | 创伤及应激相关障碍（含 PTSD）|
| 6C00-6C0Z | 躯体症状及相关障碍 |
| 6C20-6C2Z | 进食障碍 |
| 6C50-6C5Z | 睡眠-觉醒障碍 |
| 6C70-6C7Z | 物质相关及成瘾障碍 |
| 6D10-6D9Z | 人格障碍（维度模型）|

### 1.3 精神分裂症 ICD-11 vs DSM-5

| 维度 | ICD-11 | DSM-5 |
| :--- | :--- | :--- |
| **编码** | 6A20 | 295.90 (F20.9) |
| **时间标准** | 4 周 | 6 个月 |
| **功能损害** | 不强制要求 | 强制性要求 |
| **亚型** | **取消**（改用症状限定分类 6 维度）| 保留部分（紧张型/紊乱型等）|
| **6 维度** | 阳性、阴性、抑郁、躁狂、精神运动性、认知 | 多维度心理病理评估 |
| **首次发作** | 强调纵向病程 | 强调功能损害 |

### 1.4 双相障碍 ICD-11 vs DSM-5

| 维度 | ICD-11 | DSM-5 |
| :--- | :--- | :--- |
| **躁狂核心症状** | 兴奋/易怒/膨胀 + 精力增加活动 | 异常心境高涨 + 活动/精力增加 |
| **附加症状数** | 7 项中满足"几种" | 7 项中满足 3+ |
| **轻躁狂时间** | 几天 | 4 天+ |
| **诊断频率** | 轻躁狂诊断频率 **2x** DSM-5 | 严格 |
| **共同点** | 躁狂/轻躁狂 + 抑郁发作模式 | 同左 |

## 二、DSM-5（北美 + 学术研究）

### 2.1 DSM-5 关键变化（vs DSM-IV-TR）

| 变化 | 内容 |
| :--- | :--- |
| **五轴系统取消** | 改用维度评估 |
| **孤独症谱系（ASD）** | 取消亚型（孤独症 / Asperger 等）|
| **"心境障碍"拆分** | 抑郁障碍 + 双相障碍 两个独立章节 |
| **破坏性情绪失调障碍（新增）** | 儿童青少年期 |
| **丧亲之痛 2 个月限制（取消）** | DSM-IV-TR 的排除标准取消 |
| **持续性抑郁障碍** | 合并"慢性抑郁"+"恶劣心境" |
| **月经前期烦闷障碍（新增）** | 正式分类 |
| **混合特征** | 取代"混合发作"（维度化）|
| **跨诊断症状量表** | 第 3 部分新增维度工具 |

### 2.2 DSM-5 章节结构

| 章节 | 内容 |
| :--- | :--- |
| — | 神经发育障碍 |
| — | 精神分裂症谱系及其他精神病性障碍 |
| — | **双相及相关障碍**（独立）|
| — | **抑郁障碍**（独立）|
| — | 焦虑障碍 |
| — | 强迫及相关障碍 |
| — | 创伤及应激相关障碍 |
| — | 躯体症状及相关障碍 |
| — | 进食障碍 |
| — | 睡眠-觉醒障碍 |
| — | 物质相关及成瘾障碍 |
| — | 人格障碍 |
| — | 性功能失调 |
| — | 性别烦躁 |
| — | 破坏性 / 冲动控制 / 品行障碍 |
| — | 神经认知障碍 |
| — | 人格因素影响的其他情况 |
| — | 药物引起的运动障碍 |
| — | 其他可能成为临床关注焦点的情况 |

## 三、CCMD-3（中国本土化）

### 3.1 CCMD-3 特点

| 维度 | 内容 |
| :--- | :--- |
| **发布时间** | 2001 年 |
| **编制** | 中国精神卫生专家 |
| **目标** | 接轨国际 + 保留中国特色 |
| **保留** | **神经衰弱**、**癔症**等中国常见诊断 |
| **融合** | 中医理论与现代精神医学 |

### 3.2 中国当前双轨使用

> 中国医疗机构 **2019-03-01 起全面使用 ICD-11 中文版**

| 场景 | 使用系统 |
| :--- | :--- |
| **医院病案编码** | ICD-11 |
| **临床诊断（中国医生）** | 倾向 CCMD-3 + DSM-5 |
| **学术研究** | 倾向 DSM-5 |
| **国际交流** | ICD-11 |
| **健康管理 / 政策** | ICD-11 |

## 四、DSM-5 vs ICD-11 核心差异

| 维度 | DSM-5 | ICD-11 |
| :--- | :--- | :--- |
| **编纂方** | 美国 APA | 国际 WHO |
| **使用范围** | 北美为主 | 全球 70% 医疗记录 |
| **代码体系** | 数字代码 | 字母数字代码 |
| **亚型** | 部分保留 | 取消（维度化）|
| **时间标准** | 严格（精神分裂 6 月）| 灵活（4 周）|
| **功能损害** | 强制要求 | 不强制 |
| **描述性 vs 标准化** | 标准化（criteria-based）| 描述性 + 临床判断 |
| **更新速度** | 较慢（DSM-5 至今 13 年未更新）| 持续更新 |
| **修订频率** | 10-20 年 | 20+ 年 |

## 五、临床应用关键

### 5.1 抑郁障碍诊断对比

| 维度 | DSM-5 | ICD-11 |
| :--- | :--- | :--- |
| **核心症状数** | 5+ 中至少 5 项（2 周）| 类似 DSM-5 |
| **包含自伤评估** | 必备 | 必备 |
| **丧亲排除** | 无（DSM-5 取消）| 无 |
| **持续性抑郁** | 独立诊断 | 独立诊断 |
| **围产期抑郁** | 标注 "with peripartum onset" | 独立诊断 |

### 5.2 焦虑障碍诊断对比

| 维度 | DSM-5 | ICD-11 |
| :--- | :--- | :--- |
| **GAD 时间** | 6 个月 | 数月 |
| **惊恐发作** | 1 个月 | 类似 |
| **社交焦虑** | 6 个月 | 数月 |
| **广泛性焦虑核心症状** | 6 项中 3+ | 肌紧张/坐立不安/交感/精神紧张/难集中/易激惹/睡眠紊乱 中 2+ |

### 5.3 ASD（自闭症谱系）对比

| 维度 | DSM-5 | ICD-11 |
| :--- | :--- | :--- |
| **亚型** | 取消 | 取消 |
| **诊断要点** | 社交沟通 + 限制性重复行为 | 类似 |
| **发病** | 发育早期 | 发育早期 |
| **新增分度** | 3 级（需帮助量）| 3 级 |
| **智商合并** | 可合并 IDD | 编码区分 |

## 六、CCMD-3 vs ICD-11 vs DSM-5 总体对比

| 维度 | CCMD-3 | DSM-5 | ICD-11 |
| :--- | :--- | :--- | :--- |
| **国际通用** | ✗ | 限北美 | ✅ 全球 |
| **法律效力（中国）** | 部分保留 | 限学术 | ✅ 法定 |
| **文化适应（中国）** | ✅ 最佳 | 中 | 中 |
| **持续更新** | 已停更 | 慢 | ✅ 持续 |
| **学术研究** | 较少 | ✅ 金标准 | 强 |
| **中医结合** | ✅ | ✗ | ✗ |
| **国际保险** | ✗ | 部分 | ✅ |

## 七、未来趋势

| 趋势 | 内容 |
| :--- | :--- |
| **2026 DSM-5-TR** | 2022-10 APA 发布修订版，**新增延长悲伤障碍 + 赌博障碍更新** |
| **ICD-11 中国落地** | 持续推进，**与 CCMD-3 双轨** |
| **数字化诊断** | AI 辅助诊断 / 数字化量表 |
| **维度化诊断** | RDoC（研究领域标准）兴起 |
| **精准诊断** | 生物标志物 + 基因检测辅助 |
| **跨文化** | WHO 全球适用性原则 |
| **去病耻化** | "性别不一致"等移出精神障碍 |
