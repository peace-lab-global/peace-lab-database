## 一、Cell 2026-05 双论文：aiTBS 机制突破

### 1.1 论文背景

2026-05-07 Cell 同期发表两篇论文，破解 **aiTBS（加速间歇性 θ 爆发式刺激）** 治疗抑郁症的神经机制。

| 维度 | 内容 |
| :--- | :--- |
| **期刊** | Cell（2026-05-07） |
| **类型** | 同期双论文 |
| **主题** | aiTBS 抗抑郁机制 |
| **意义** | 从"经验性使用"到"机制明确" |

### 1.2 aiTBS 临床优势

- 治疗时间从传统 rTMS 的 37 分钟 → 缩短至 3-9 分钟
- 等效性不劣于标准 rTMS
- 治疗依从性显著提升
- 2024 抑郁防治指南推荐为一线物理治疗

### 1.3 机制突破的意义

- **传统 rTMS/iTBS**：经验性使用，缺乏明确的神经环路机制
- **Cell 2026 突破**：揭示 aiTBS 通过特定神经环路（涉及前额叶皮层、海马等）发挥抗抑郁作用
- **临床价值**：个性化精准刺激 + 联合药物 / DTx

## 三、KDD 2026 灵犀诊断基准（上海交大 + EverMind AI）

### 3.1 论文背景

| 字段 | 内容 |
| :--- | :--- |
| **会议** | KDD 2026（第 32 届 ACM SIGKDD） |
| **地点** | 韩国济州岛 |
| **发表时间** | 2026-08 |
| **DOI** | 10.1145/3770855.3817539 |
| **arXiv** | 2602.09379 |
| **作者** | 上海交大精神卫生中心 + EverMind AI + 天桥脑科学研究院 |

### 3.2 灵犀诊断-16K 数据集

| 字段 | 内容 |
| :--- | :--- |
| **总规模** | 16,000 合成问诊对话 + 对应电子病历 |
| **真实数据** | 1,709 份（4500 门诊患者中筛选） |
| **伦理审批** | 上海精神卫生中心伦理委员会 |
| **知情同意** | 每位参与者或其监护人均签署 |
| **合成方法** | 知识图谱 + 7 环节生成（年龄/性别/科室/ICD-10 + 病史 + 主诉） |
| **JS 散度** | 各诊断类别主诉长度 0.03-0.07（合成与真实高度吻合） |

### 3.3 三角色多智能体框架

| 角色 | 功能 |
| :--- | :--- |
| **患者智能体** | 模拟真实患者，注入基本信息/主诉/病史 + 对话历史 |
| **医生智能体** | 主导问诊，四种策略：自由发挥/症状树/APA 引导/APA+MRD-RAG |
| **诊断智能体** | 接收完整对话，给出诊断结论 + 临床推理 |

### 3.4 两种评测范式

| 评测 | 内容 |
| :--- | :--- |
| **LingxiDiagBench-Static** | 固定对话，AI 直接判断；二/四/十二分类 + 医生下一问预测 |
| **LingxiDiagBench-Dynamic** | AI 医生主动问诊 + 端到端诊断 |

### 3.5 静态评测结果

| 任务 | 最佳模型 | 数据集 | 准确率 |
| :--- | :--- | :--- | :--- |
| **二分类（抑郁/焦虑）** | Gemini-3-Flash | 合成 | **85.4%** |
| 二分类（真实临床） | Qwen3-4B | 真实 | **88.7%** |
| **四分类**（含共病）| TF-IDF + 随机森林 | 合成 | 47.9% |
| 四分类（真实） | Qwen3-32B | 真实 | 52.4% |
| **十二分类** | GPT-5-Mini | 合成 | **40.9%** |
| 十二分类（真实） | Qwen3-32B | 真实 | 27.8% 宏 F1 |
| **综合 Clf-Ovl** | TF-IDF + LR | 合成 | **0.533**（意外） |
| 综合 Clf-Ovl | Qwen3-32B | 真实 | **0.548** |
| **Top-3 准确率** | Qwen3-4B | 真实 | **69.8%** |

### 3.6 动态评测结果

| 任务 | 最佳模型 | 准确率 |
| :--- | :--- | :--- |
| **二分类动态** | DeepSeek-V3.2（APA+MRD-RAG） | **92.3%** |
| **四分类动态** | Grok-4.1-Fast（APA+MRD-RAG） | 43.0% |
| **十二分类动态** | Grok-4.1-Fast（APA+MRD-RAG） | 28.5% |
| **真实临床动态** | 二分类最高 | 91.2% |
| 真实临床动态 | 十二分类最高 | **47.0%** |

### 3.7 关键发现

1. **AI 在最常见二分类（抑郁/焦虑）已超 90%**
2. **共病识别骤降至 40-50%**（AI 短板）
3. **十二分类（含罕见病）仅 27-40%**（挑战最大）
4. **问得好 ≠ 诊得对**（相关仅 0.43）
5. **APA 引导 + MRD-RAG** 策略平均提升 5 个百分点
6. **传统 TF-IDF + LR** 在综合评测中意外领先（精神科诊断不靠"大"）

### 3.8 患者智能体评估

| 模型 | 综合得分 |
| :--- | :--- |
| **灵犀患者（Qwen3-32B 骨干）** | **4.67 / 5.0** |
| 真实临床数据基准 | 4.30 / 5.0 |
| MDD-5K 患者（同骨干） | 3.05 / 5.0 |

### 3.9 跨评审一致性

- AI 评审团 vs 人类精神科医生：肯德尔一致性 **0.90**、斯皮尔曼 **0.80**
- 83.3% 两两比较方向一致
- **AI 评审团可替代人类专家进行大规模评测**

### 3.10 迁移学习验证

| 模型 | 训练 | 真实临床 12 分类精确 |
| :--- | :--- | :--- |
| **Qwen3-8B（无 LoRA）** | 无 | 4.1% |
| **Qwen3-8B（LoRA）** | 合成数据 | **41.4%**（+37.3 pp） |
| **Qwen3-32B（无 LoRA）** | 无 | 20.4% |
| **Qwen3-32B（LoRA）** | 合成数据 | 39.7%（+19.3 pp） |

**结论**：合成数据训练的模型**能真正泛化到真实精神科门诊场景**。

### 4.4 三大核心技术路径

1. **AI 大模型 + 心理垂类**
   - 望里科技：WonderLab 大模型（融合多种心理疗法）
   - 虚之实科技：基于千万级临床数据的 AI Agent
   - 京东：京医千询 + 聊愈小宇宙
   - 平安：医疗大模型 3.5（HealthBench 57.27 全球第一）

2. **数字疗法 + 脑机接口**
   - 感知 → 分析 → 干预 → 反馈闭环
   - 适合神经康复领域
   - 虚之实、博睿康、心景科技

3. **软硬件一体化协同**
   - "云-边-端"协同
   - 云：大模型训练 + 数据存储
   - 边：实时算力（虚之实 AI Agent）
   - 端：VR/AR/可穿戴设备

### 4.5 数字精神医疗 vs 传统精神医疗的不可替代痛点

| 痛点 | 数字精神医疗解决方案 |
| :--- | :--- |
| **数据客观性** | 多维数据驱动，居家化常态监测 |
| **病耻感** | 居家独立使用 + 数据加密 + 无公开场景 |
| **诊疗质量不均** | 已验证方案录入系统，基层可获 |
| **医务人员负担** | 一套系统服务数百人 |

### 4.6 三大误区澄清

| 误区 | 澄清 |
| :--- | :--- |
| 青少年数字干预只针对多动症 | 持证设备可改善抑郁、社交退缩（虚之实"心宁智境"） |
| 数字精神医疗只作用于情绪 | VR + 脑机接口可改变脑区活动（神经可塑性） |
| 家用 vs 医用差距巨大 | 合规家用二类设备核心算法与医用完全统一 |

## 五、DSM-5-TR + ICD-11/12 进展

### 5.1 DSM-5-TR（2022 实施）

- 修订主要变化：
  - 新增"延长时间悲伤障碍"（Prolonged Grief Disorder）
  - 更新自闭症谱系诊断标准
  - 重写"跨诊断症状"章节
- 中国使用情况：未官方引入，临床/学术使用中英文版

### 5.2 ICD-11（2022-01-01 全球生效，2019-03 中国启用）

- 22 章 / 72,000 编码
- 新增"游戏障碍"（Gaming Disorder）
- 强迫症从"焦虑障碍"独立为"强迫及相关障碍"
- 性别不一致不再视为精神障碍
- 中国 2019-03-01 全面启用，2022-01-01 全球生效

### 5.3 ICD-12 窗口（预计 2027-2030）

| 节点 | 预期 |
| :--- | :--- |
| **2027** | WHO 公布 ICD-12 草案 |
| **2028-2029** | 成员国讨论修订 |
| **2030** | 预计全球生效 |
| **中国 2031-2032** | 预计全面启用 |

### 5.4 ICD-12 潜在变化方向

- **AI 辅助诊断**：将 AI 辅助诊断正式纳入分类标准
- **数字行为相关障碍**：可能新增"数字行为成瘾"独立类别
- **跨文化敏感性**：增强非西方文化症状表述
- **基因组学整合**：可能增加生物标志物维度
- **神经发育**：细化自闭症 / ADHD / 智力障碍分类

## 六、致幻剂/精神益生菌/抗 IL-6 三大新兴疗法

### 6.1 致幻剂（Psilocybin / MDMA / Ketamine）

| 适应症 | 进展 |
| :--- | :--- |

| **酒精使用障碍** | Psilocybin Ⅲ期临床 |

### 6.2 精神益生菌（Psychobiotics）

| 维度 | 内容 |
| :--- | :--- |
| **机制** | 肠-脑轴（Gut-Brain Axis）→ 肠道菌群影响情绪 |
| **代表菌株** | Lactobacillus rhamnosus、Bifidobacterium longum |
| **临床证据** | 轻度抑郁 / 焦虑辅助治疗有初步证据 |
| **2025 进展** | Ⅱ-Ⅲ 期临床试验密集开展 |
| **市场** | 消费级（保健品）→ 医疗级（处方益生菌）分化 |

### 6.3 抗 IL-6 生物制剂

| 维度 | 内容 |
| :--- | :--- |
| **机制** | 炎症因子 IL-6 与抑郁相关；抑制 IL-6 可改善抑郁 |
| **代表药物** | Tocilizumab、Siltuximab |
| **临床证据** | 小样本研究显示改善难治性抑郁 |
| **2025 进展** | 大规模 RCT 进行中 |
| **⚠️ 局限** | 副作用（感染风险）、成本高 |

> ⚠️ 此三大新兴疗法均处于"早期临床证据"阶段，距大规模临床应用还有 3-5 年。
