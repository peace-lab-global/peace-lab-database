# 数字疗法监管对照 · FDA vs NMPA vs CE（2026-08）

> **目的**：数字疗法（DTx）3 大监管体系对照 — 美国 FDA / 中国 NMPA / 欧盟 CE
> **覆盖**：定义 / 分类 / 注册路径 / 心理 DTx 案例 / 2025-2026 政策动态
> **更新**：2026-08-05

---

## 一、3 大体系总览

| 维度 | 🇺🇸 **FDA**（美国）| 🇨🇳 **NMPA**（中国）| 🇪🇺 **CE**（欧盟）|
| :--- | :--- | :--- | :--- |
| **监管框架** | 21st Century Cures Act (2016) + FDA SaMD 框架 | 《医疗器械监督管理条例》+ 数字疗法分类指导原则（2023）| MDR 2017/745（2021-05 强制）+ MDCG 指南 |
| **DTx 定位** | **医疗器械**（Software as Medical Device, SaMD）| **医疗器械**（按风险二/三类）| **医疗器械**（按风险 Class I/IIa/IIb/III）|
| **核心文件** | FDA 数字健康创新行动计划 / Pre-Cert Pilot | 《数字疗法医疗器械分类界定指导原则》2023-06 | MDR Annex VIII + MDCG 2019-11 |
| **审批机构** | FDA CDRH（器械与放射健康中心）| 国家药监局医疗器械技术审评中心（CMDE）| 公告机构（Notified Body，如 TÜV / DEKRA / BSI）|
| **心理 DTx 已批** | 10+ 款 | 5+ 款（2023-2025）| 8+ 款 |
| **审批时长** | 6-18 个月 | 9-24 个月 | 12-18 个月 |
| **上市后监管** | 强（FDA 持续监督）| 强化中（2024 起）| 强（EUDAMED + 警戒系统）|

## 二、🇺🇸 FDA（最成熟体系）

### 2.1 监管基础
- **2016 21st Century Cures Act**：明确"不用于诊断治疗的一般健康产品"非器械
- **2017 FDA Digital Health Innovation Action Plan**
- **2019 FDA Pre-Cert Pilot**（预认证计划，软件公司层面）
- **2021 FDA AI/ML SaMD Action Plan**
- **2022-2024 多个 AI 医疗审批指引**

### 2.2 风险分级（基于 IMDRF SaMD 框架）

| 风险等级 | 描述 | 审批路径 |
| :--- | :--- | :--- |
| **Class I** | 低风险（如一般健康记录）| 多数免审批（510(k) exempt）|
| **Class II** | 中风险（多数 DTx）| **510(k) 或 De Novo** |
| **Class III** | 高风险（治疗严重疾病）| **PMA（上市前批准）**|

### 2.3 心理 / 神经 DTx 已批产品

| 产品 | 厂家 | 适应症 | 首次批准 | 类型 |
| :--- | :--- | :--- | :--- | :--- |
| **reSET** | Pear Therapeutics | 物质使用障碍（SUD）| **2017-09** | 处方类 |
| **reSET-O** | Pear Therapeutics | 阿片类使用障碍（OUD）| 2018-12 | 处方类 |
| **SleepioRx** | Big Health | 慢性失眠（CBT-I）| 2020 (Class II 510(k)) | 处方类 |
| **EndeavorRx** | Akili Interactive | 儿童 ADHD（8-12 岁）| 2020-06 | 处方类 |
| **Daylight** | Big Health | 焦虑 + GAD | 2022 (510(k)) | 处方类 |
| **Rejoyn** | Otsuka + Click Therapeutics | 难治性抑郁（MDD 辅助）| **2024-04** | 处方类 |
| **Flow FL-100** | Flow Neuroscience | 难治性抑郁（家用 TMS）| **2025-12-11** | 处方类（器械组合）|
| **CT-132** | Click Therapeutics | 偏头痛预防 | 2024-04 | 处方类 |
| **Parallel** | Mahana Therapeutics | IBS（肠易激综合征）| 2024-11 | 处方类 |
| **Freespira** | Freespira | PTSD / 惊恐发作 | 2018 | 处方类 |

> **关键**：Pear Therapeutics 2023-04 破产，是行业重要警示 — 商业化困难，2024-01 资产被卖

### 2.4 心理 DTx 审批流程

```
Pre-Submission（FDA 预沟通）
   ↓
性能测试（软件验证 / 可用性 / 临床）
   ↓
提交 510(k) 或 De Novo 或 PMA
   ↓
FDA 审评（180 天目标）
   ↓
批准 + 上市后监督
```

### 2.5 2024-2026 政策动态
- **2024-01 FDA 终止 Pear Therapeutics 资产** — 行业警示
- **2024-04 Rejoyn 批准** — 心理 DTx 复苏信号
- **2024-12 AI/ML SaMD 透明度新规** — 要求公布 AI 模型信息
- **2025-12 Flow FL-100 家用 TMS 批准** — 器械 + 软件组合新范式
- **2026-Q1 FDA 精神分裂症 DTx 工作组启动**

## 三、🇨🇳 NMPA（快速发展期）

### 3.1 监管基础
- **2014 《医疗器械监督管理条例》**
- **2017 修订** — 强化数字医疗
- **2021-06《人工智能医疗器械分类界定指导原则》**
- **2023-06《数字疗法医疗器械分类界定指导原则》** — **首部 DTx 专项文件**
- **2024 多省 DTx 试点**（海南先行）

### 3.2 心理 / 神经 DTx 已批产品（不完全统计）

| 产品 | 厂家 | 适应症 | 首次批准 |
| :--- | :--- | :--- | :--- |
| **术康** | 术康科技 | 运动康复 | 2021（二类）|
| **心情减压** | 镜象科技 | 焦虑 / 失眠 | 2022（二类）|
| **若水医生** | 暖哇科技 | 心理治疗辅助 | 2023（二类）|
| **微脉心理** | 微脉 | 心理评估 + 干预 | 2023（二类）|
| **心晴医生** | 晴空智能 | 抑郁 / 焦虑 | 2024（二类）|
| **BrainCo 赋思头环** | BrainCo | ADHD 辅助（医疗器械二类）| 2024 |

> **注**：中国心理 DTx 仍以二类居多，三类（治疗严重疾病）罕见

### 3.3 数字疗法分类界定

```
是否医疗器械？
   ├─ 否 → 普通软件（不需审批）
   └─ 是（治疗/诊断）→ 风险分级
         ├─ 二类（中风险，如 CBT-I 失眠）
         │     └─ 省局审批，9-12 个月
         └─ 三类（高风险，如治疗严重精神疾病）
               └─ 国家局审批，12-24 个月
```

### 3.4 心理 DTx 路径特殊性
- **特殊审批通道**：
  - 创新医疗器械（"绿色通道"）
  - 优先审批（儿童 / 罕见病）
  - 海南 / 上海 DTx 试点
- **2024-10《海南省数字疗法产品推广应用工作方案》** — 全国首个省级 DTx 专项
- **2025-Q1 上海 DTx 试点**启动

### 3.5 2024-2026 政策动态
- **2024-06 NMPA 明确"心理治疗类软件"按二类管理**
- **2024-10 海南《数字疗法产品推广应用工作方案》**
- **2025-Q1 上海 DTx 试点启动**
- **2025-12 数字疗法专业委员会（筹）成立**
- **2026-04 25 部委《实施方案》**首次将"心理数字疗法"纳入政策

### 3.6 优势 / 挑战

| 优势 | 挑战 |
| :--- | :--- |
| ✅ 政策强推动（25 部委 2026）| ⚠️ 心理 DTx 商业化路径不清 |
| ✅ 海南/上海试点先行 | ⚠️ 三类（治疗严重疾病）审批路径待明确 |
| ✅ 2023 专项文件 | ⚠️ 临床证据要求较高 |
| ✅ 创新医疗器械绿色通道 | ⚠️ 医保覆盖有限（2025 试点）|
| ✅ 与中医院 / 互联网医院联动 | ⚠️ 数据安全审查（尤其心理数据）|

## 四、🇪🇺 CE（MDR 框架，复杂严格）

### 4.1 监管基础
- **MDR 2017/745** — 2021-05-26 强制（替代 MDD）
- **IVDR 2017/746** — 体外诊断（2022-05 强制）
- **MDCG 指南** — 医疗器械协调小组发布的指南文件
- **EUDAMED 数据库** — 欧洲医疗器械数据库
- **GDPR** — 通用数据保护条例（数字健康重点）

### 4.2 风险分级（MDR Annex VIII）

| 风险等级 | 描述 | 公告机构介入 |
| :--- | :--- | :--- |
| **Class I** | 低风险 | 自我声明 |
| **Class IIa** | 中低风险 | 需要 |
| **Class IIb** | 中高风险 | 需要 |
| **Class III** | 高风险 | 需要 + 严格审查 |

### 4.3 心理 / 神经 DTx 已批产品（CE）

| 产品 | 厂家 | 适应症 | 首次 CE |
| :--- | :--- | :--- | :--- |
| **Deprexis** | GAIA Group | 抑郁 | 2017（Class IIa）|
| **VELIBRA** | GAIA Group | 焦虑 | 2018（Class IIa）|
| **myHealthyApple**（多种）| Selfapy | 抑郁 / 焦虑 / 失眠 | 2019-2022（Class I-IIa）|
| **SinNeb / Alfaith** | DeVilbiss | 呼吸治疗 | 多年 |
| **Flow FL-100**（CE）| Flow Neuroscience | 抑郁（家用 TMS）| 2020（Class IIa）|
| **Sleepio** | Big Health | 失眠（CBT-I）| 2018（Class I）|
| **Wysa** | Wysa | 心理健康（CBT chatbot）| 2021（Class IIa）|
| **DEKO / HiGHmed** | 多家 | 心理 / 神经 | 2022-2024 |

### 4.4 关键特征
- **临床证据要求高** — 需 CE 标识的临床评估报告（CER）
- **公告机构稀缺** — TÜV SÜD / TÜV Rheinland / DEKRA / BSI 等仅 50+ 家
- **MDR 过渡期长** — 2021-2027（部分产品）
- **GDPR 严格** — 数据本地化、用户同意、跨境传输
- **EUDAMED 数据库** — 2026-05 进入强制期

### 4.5 2024-2026 政策动态
- **2024 EU AI Act 生效**（2024-08 生效，2026-08 全面适用）— 心理 AI 须满足
- **2024-10 MDR 修订** — 简化部分 IIa/IIb 流程
- **2025-05 EUDAMED 强制使用** — 唯一器械标识（UDI）
- **2026-08 EU AI Act 高风险条款全面适用** — 心理 DTx 多数属"高风险"

### 4.6 优势 / 挑战

| 优势 | 挑战 |
| :--- | :--- |
| ✅ 27 国互认 | ⚠️ MDR 流程复杂、成本高 |
| ✅ GDPR 数据保护强 | ⚠️ 公告机构少，排队时间长 |
| ✅ EUDAMED 透明度高 | ⚠️ 临床证据要求高 |
| ✅ 心理 / 神经 DTx 接受度高 | ⚠️ EU AI Act 增加合规成本 |
| ✅ 跨境互认（瑞士 / 土耳其 / 英国）| ⚠️ 语言本地化要求高 |

## 六、关键心理 DTx 案例对照

### 6.1 reSET（Pear Therapeutics，2017 FDA）
- 适应症：物质使用障碍（SUD）
- 类型：处方类 DTx（联合 buprenorphine）
- **2023-04 Pear 破产** — 行业重要警示
- 失败原因：定价 $1200/月过高 + 医生不熟悉 + 保险覆盖难
- 后续：2024-01 资产被卖（reSET 继续运营）

### 6.2 SleepioRx（Big Health，2020 FDA Class II）
- 适应症：慢性失眠（CBT-I）
- 类型：处方类 DTx
- 商业化：B2B（雇主保险）+ 处方
- **2025 已覆盖 2000 万+ 美国人** — 行业成功案例
- 关键：临床证据扎实（CBT-I 1 类推荐）

### 6.3 Rejoyn（Otsuka + Click Therapeutics，2024-04 FDA）
- 适应症：难治性抑郁（MDD 辅助抗抑郁药）
- 类型：处方类 DTx
- 关键：与现有抗抑郁药联合使用
- 创新性：AI 个性化 + 神经科学训练

### 6.4 Flow FL-100（Flow Neuroscience，2025-12 FDA + 2020 CE）
- 适应症：难治性抑郁（家用 TMS）
- 类型：处方类 DTx（器械 + 软件组合）
- 创新性：**家用化**（无需去医院）
- **2025-12-11 FDA 批准后** — 抑郁治疗家用化里程碑

### 6.5 中国 心情减压（镜象科技，2022 NMPA 二类）
- 适应症：焦虑 / 失眠
- 类型：二类 DTx
- 商业化：互联网医院 + 心理平台

### 6.6 欧盟 Deprexis（GAIA Group，2017 CE）
- 适应症：抑郁
- 类型：Class IIa
- 商业化：德国 / 英国 / 瑞士国家医保覆盖

## 七、3 体系面临的共同挑战

| 挑战 | 含义 |
| :--- | :--- |
| **商业化难** | Pear 破产 + 多数 DTx 盈利难 |
| **临床证据要求高** | 大型 RCT 成本 $10M+ |
| **医生不熟悉** | 处方意愿低 |
| **医保 / 保险覆盖** | 定价与报销的拉锯 |
| **AI 透明度** | 黑盒 vs 监管要求 |
| **数据安全** | HIPAA / GDPR / 个保法 |
| **更新版本管理** | 持续软件更新的审批路径 |
| **跨境互认** | 3 体系不互认，重复申请 |
