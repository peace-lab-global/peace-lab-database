# 国内冥想/正念 App 格局（潮汐 / Now 冥想 / 小睡眠）

## 一句话概述

> 国内冥想 App 市场已形成 **"睡眠 + 冥想 + 专注"** 三角格局，**潮汐（Tide）以"睡眠+冥想+专注"综合体验领跑国内**（下载量 1 亿+），**Now 冥想**主打"全场景冥想课程"（安卓 8000 万下载），**小睡眠**专注"助眠"垂直场景（iOS 2200 万+ / OPPO 2500 万+ 下载）。**Keep 冥想模块**作为运动 App 的附加能力。**国内市场规模仍远小于健身瑜伽，正念正在从"玄学"变成"主流疗法"**（2026 JAMA 精神病学荟萃分析 187 项 RCT 验证）。

## 一、潮汐（Tide）— 国内综合冥想领跑

### 1.1 产品定位

> **Slogan**：「和大自然一起平静身心」

- 综合型 App：**睡眠 + 冥想 + 专注 + 放松** 四位一体
- 核心差异化：**番茄工作法 + 自然声音 + 极简设计美学**

### 1.2 核心功能

| 功能模块 | 内容 |
| :--- | :--- |
| **专注计时器** | 番茄工作法（25 min 专注 + 5 min 休息）|
| **睡眠与小憩** | 白天小憩、夜晚长睡、轻柔唤醒闹钟 |
| **放松呼吸引导** | 平衡呼吸、4-7-8 呼吸 |
| **自然声音** | 雨/海洋/雷雨/森林/流水/远山/林风/夜海/长路 |
| **放松冥想** | 呼吸练习、身体扫描、思维训练、情绪感知 |
| **场景冥想** | 快速入眠、学习压力、孤独、午休、减压、沮丧、晚安、通勤 |
| **潮汐日记** | 可视化数据 + 精美分享卡片 |

### 1.4 设计特色

- **极简设计** — 少即是多
- **随时间变化动效** — 时光流逝的问候语

- **平台** — iOS / Android / Mac / Windows / Chrome

## 六、国内 vs 国际对比

| 维度 | 国内（潮汐/Now/小睡眠）| 国际（Calm/Headspace）|
| :--- | :--- | :--- |
| **总下载量** | 1 亿+（小睡眠）| 1 亿+（Calm + Headspace）|
| **营收能力** | 较弱 | 年收入 1 亿+ 美元 |
| **生态成熟度** | 中等 | 高度成熟 |
| **中文支持** | 完美 | 弱（英文为主）|
| **本地化场景** | 强（通勤、午休、晚安）| 中等 |
| **品牌力** | 中等 | 强（Calm/Headspace 国际 IP）|
| **价格** | 免费 + 增值（亲民）| 订阅（较贵）|

> **关键差距**：国内冥想 App 营收远低于国际巨头。**主要原因是国内对冥想的接受程度仍比健身瑜伽小得多**，需要"心理服务 + 文化"双轮驱动。
