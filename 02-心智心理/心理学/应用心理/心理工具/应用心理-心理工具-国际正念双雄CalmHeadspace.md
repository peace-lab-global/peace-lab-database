# 国际正念双雄（Calm / Headspace）

## 一句话概述

> **Calm**（2012 创立）是全球 **睡眠 + 冥想 + 自然声音** 头部，下载量超 **1 亿**，年收入超 **1 亿美元**；**Headspace**（2010 创立）走 **专业冥想 + 心理健康 B2B** 路线，与企业 EAP 深度合作；**Insight Timer** 是全球 **最大免费冥想社区**。三者合计构成全球正念冥想 App 三大生态，**2026 年活跃用户均破 5000 万**，正念从"玄学"进入"主流疗法"。

## 关键事实

| App | 创立 | 总部 | 核心定位 | 用户量 | 商业模式 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Calm** | 2012 | 旧金山 | 睡眠+冥想+自然声音 | **1 亿+** | 订阅 + 企业 |
| **Headspace** | 2010 | 旧金山 | 专业冥想 + B2B | **5000 万+** | 订阅 + 企业 EAP |
| **Insight Timer** | 2010 | 悉尼 | **最大免费**冥想社区 | **3000 万+** | 免费 + 打赏教师 |
| **Brain.fm** | 2015 | 麻省 | AI 专注音乐 | 中等 | 订阅 |

## 一、Calm — 睡眠+冥想+自然声音龙头

### 1.1 产品定位

> **Slogan**：「Calm is the #1 app for sleep, meditation and relaxation」

- **三大场景**：睡眠、冥想、放松
- **明星 IP 优势**：邀请名人配音（Matthew McConaughey、Stephen Fry、Idris Elba 等）
- **内容生态**：冥想课程 + 睡前故事 + 自然声音 + 音乐 + 体操

### 1.2 核心功能

| 功能 | 内容 |
| :--- | :--- |
| **冥想课程** | 入门到高阶（7 天 / 10 天 / 21 天系列）|
| **睡眠故事** | 名人朗读的睡前故事（最受欢迎）|
| **自然声音** | 海浪、雨声、森林、火焰等 |
| **Calm Body** | 轻柔体操与伸展 |
| **Daily Calm** | 每日 10 分钟冥想 |
| **音乐库** | 专注 / 睡眠 / 放松场景音乐 |
| **SOS Sessions** | 紧急情绪急救 |
| **Masterclasses** | 名人 / 专家大师课 |

### 1.3 商业模式

| 维度 | 内容 |
| :--- | :--- |
| **订阅** | 月度 / 年度 / 终身 |
| **价格** | 月 $14.99 / 年 $69.99 / 终身 $399.99 |
| **企业版** | Calm Business / Calm Health（医疗方向）|
| **收入** | 年收入超 **1 亿美元** |
| **品牌合作** | 与航空公司、酒店、Spotify 等合作 |

### 1.4 优势与短板

| ✅ 优势 | ❌ 短板 |
| :--- | :--- |
| **内容精致**（明星配音）| 应用结构略乱 |
| **永久版选项**（lifetime）| 对初学者不友好 |
| **官方价格友好** | 不像 Headspace 一步步引导 |
| **3-17 岁儿童内容** | 内容分类较粗略 |
| **scenes 功能** | 部分内容冗长 |

## 二、Headspace — 专业冥想 + B2B

### 2.1 产品定位

> **Slogan**：「Be kind to your mind」

- **核心优势**：**引导性强、UI 友好、专业课程**
- 与企业 EAP、保险公司深度合作
- 创始人 Andy Puddicombe（前佛教僧侣）+ Rich Pierson

### 2.2 核心功能

| 功能 | 内容 |
| :--- | :--- |
| **冥想课程** | 入门到高阶（10 节基础课 + 进阶）|
| **SOS Sessions** | 恐慌、焦虑、压力时刻急救 |
| **2-3 分钟迷你冥想** | 快速 reset 心态 |
| **动画教学** | Headspace 动画教新技能 |
| **Motional Moments** | 全天清醒时刻 |
| **儿童内容** | 仁慈、平静、专注 |
| **运动 + 健康** | 心理与运动结合 |
| **睡眠** | 助眠冥想 + 睡前故事 |

### 2.3 B2B / 企业版

> Headspace 在 B2B 端比 Calm 强很多

| 客户 | 案例 |
| :--- | :--- |
| **Google** | 全球员工心理健康福利 |
| **LinkedIn** | 员工冥想福利 |
| **Adobe** | 全员心理健康计划 |
| **NHS（英国）** | NHS 员工 + 病患 |
| **Lyft** | 司机心理健康 |
| **大学** | 数百所大学的学生心理健康 |

### 2.4 商业模式

| 维度 | 内容 |
| :--- | :--- |
| **订阅** | 月度 / 年度 |
| **价格** | 月 $12.99 / 年 $69.99 |
| **企业 EAP** | 大量企业客户 |
| **医疗合作** | 与 NHS、Cigna 等合作 |
| **教育** | 高校学生折扣 |

### 2.5 优势与短板

| ✅ 优势 | ❌ 短板 |
| :--- | :--- |
| **引导性极强**（新手友好）| 不便宜，无终身版 |
| **快速冥想（busy 用户友好）** | 免费内容少 |
| **计划与进度追踪** | 内容太多，对老用户略杂 |
| **按主题/长度分类** | 订阅价格较高 |
| **企业 EAP 强** | — |

## 三、Insight Timer — 最大免费冥想社区

### 3.1 产品定位

> **Slogan**：「Free meditation app for everyone」

- **核心优势**：**100% 免费** + 全球最大冥想教师社区
- 商业模式：教师课程付费 + 用户打赏

### 3.2 核心功能

| 功能 | 内容 |
| :--- | :--- |
| **免费冥想定时器** | 基础功能完全免费 |
| **海量引导冥想** | 数万位教师上传课程 |
| **冥想音乐库** | 跨流派 |
| **社区功能** | 群组、讨论、关注 |
| **直播** | 教师实时冥想课 |
| **儿童冥想** | 家庭场景 |

### 3.3 商业模式

| 维度 | 内容 |
| :--- | :--- |
| **免费版** | 核心功能完全免费 |
| **教师课程付费** | 1V1 课程或系列课 |
| **Insight Timer Plus** | 订阅 $59.99/年 |
| **用户打赏** | 教师获得打赏分成 |

## 五、医学与文化定位

### 5.1 正念进入主流医学

> **2026 年正念已经被纳入英国 NHS、美国部分医保支付范围**

| 来源 | 数据 |
| :--- | :--- |
| **JAMA 精神病学 2026 荟萃分析** | 187 项 RCT，15000+ 受试者，正念 8 周后焦虑 ↓30-45%、抑郁复发风险 ↓40% |
| **自然杂志 2026 评论** | "正念从玄学变成具有严格循证支撑的主流疗法" |
| **英国 NHS** | 推荐正念作为抑郁焦虑一线干预 |
| **美国部分保险** | 报销 Headspace / Calm 订阅 |
