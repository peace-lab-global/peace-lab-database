# 心理学量表工具综述（PHQ-9 / GAD-7 / SCL-90 / MBTI / Big Five）

## 一句话概述

> 主流心理学量表工具**6 大类**：(1) **抑郁筛查**（PHQ-9 / SDS / HAMD）；(2) **焦虑筛查**（GAD-7 / SAS / HAMA）；(3) **综合症状**（SCL-90）；(4) **人格类型**（MBTI 16型 / 大五人格 Big Five / 16PF）；(5) **应激创伤**（PCL-5 / IES-R）；(6) **自伤/自杀**（SBQ-R / C-SSRS）。**WHO 建议每千人 1 名心理咨询师，但中国每 10 万人不足 3 名专业心理人员** —— 量表成为"心理服务可及性"的关键补充。**武志红心理 / KnowYourself 月食 / 壹心理** 等平台均提供 200+ 款在线测评。

## 关键事实

| 量表 | 用途 | 题目数 | 时间窗 | 评分 |
| :--- | :--- | :--- | :--- | :--- |
| **PHQ-9** | 抑郁筛查 | 9 | 2 周 | 0-27（0/5/10/15/20 分界）|
| **GAD-7** | 焦虑筛查 | 7 | 2 周 | 0-21（0/5/10/15 分界）|
| **SDS** | 抑郁自评 | 20 | 1 周 | 标准分 53/63/73 分界 |

| **SCL-90** | 综合症状 | 90 | 1 周 | 10 个因子 |
| **MBTI** | 人格类型 | 93 | — | 4 字母类型 |

| **SBQ-R** | 自杀风险 | 4 | — | 0-18 |
| **C-SSRS** | 自杀意念 | 6 项 | — | 风险等级 |

## 一、抑郁筛查量表

### 1.1 PHQ-9（Patient Health Questionnaire-9）

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 9 条目患者健康问卷 |
| **开发者** | Kroenke, Spitzer 等（2001）|
| **基础** | DSM-IV 诊断标准 |
| **时间窗** | 过去 **2 周** |
| **题目数** | **9** + 1 项功能影响（第 10 题）|
| **评分** | 0（完全不会）/ 1（几天）/ 2（一半以上天数）/ 3（几乎每天）|
| **总分** | 0-27 |
| **分级** | 0-4 无 / 5-9 轻 / 10-14 中 / 15-19 中重 / 20-27 重 |
| **特点** | 国际通用、**WHO 推荐**、自评快速（1-2 min）|
| **关键预警** | 第 9 题（自伤念头）> 1 分需高度警惕 |

### 1.2 SDS（Zung Self-Rating Depression Scale）

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 抑郁自评量表 |
| **开发者** | Zung（1965/1971）|
| **题目数** | 20 项（10 项正向 + 10 项反向）|
| **时间窗** | 过去 1 周 |
| **标准分** | 粗分 × 1.25 取整 |
| **分级** | 53-62 轻 / 63-72 中 / 73+ 重 |
| **特点** | 临床辅助诊断 + 疗效评估 |
| **优势** | 中文化成熟，**医院 / 社区**广泛使用 |

### 1.3 HAMD / HDRS（Hamilton Depression Rating Scale）

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 汉密尔顿抑郁量表 |
| **开发者** | Hamilton（1960）|
| **题目数** | 17 项 / 21 项 / 24 项版本 |
| **特点** | **他评量表**（医生评估）|
| **分级** | 8-19 轻 / 20-34 中 / ≥35 重 |
| **优势** | 临床研究金标准 |

## 二、焦虑筛查量表

### 2.1 GAD-7（Generalized Anxiety Disorder-7）

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 广泛性焦虑自评量表 |
| **开发者** | Spitzer, Kroenke 等（2006）|
| **时间窗** | 过去 2 周 |
| **题目数** | 7 |
| **评分** | 0/1/2/3（与 PHQ-9 相同）|
| **总分** | 0-21 |
| **分级** | 0-4 正常 / 5-9 轻 / 10-14 中 / 15-21 重 |
| **特点** | **WHO 推荐**、与 PHQ-9 组合使用 |

### 2.2 SAS（Zung Self-Rating Anxiety Scale）

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 焦虑自评量表 |
| **开发者** | Zung（1971）|
| **题目数** | 20 项 |
| **标准分** | 粗分 × 1.25 |
| **分级** | 50-59 轻 / 60-69 中 / ≥70 重 |
| **特点** | 中文化成熟 |

### 2.3 HAMA（Hamilton Anxiety Rating Scale）

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 汉密尔顿焦虑量表 |
| **题目数** | 14 项 |
| **特点** | 他评 / 躯体性 + 精神性双因子 |
| **分级** | ≥14 焦虑 / ≥21 明显 / ≥29 严重 |

## 三、综合症状量表

### 3.1 SCL-90（Symptom Checklist-90）

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 90 项症状清单 |
| **开发者** | Derogatis（1973/1977）|
| **题目数** | **90** |
| **时间窗** | 过去 1 周 |
| **因子** | **10 个**：躯体化、强迫、人际敏感、抑郁、焦虑、敌对、恐怖、偏执、精神病性、其他 |
| **指标** | 总分 / 总均分 / 阳性项目数 / 因子分 |
| **适用** | 综合心理健康筛查 + 临床评估 |
| **优势** | 覆盖广，识别多重共病 |

## 四、人格类型量表

### 4.1 MBTI（Myers-Briggs Type Indicator）

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 迈尔斯-布里格斯类型指标 |
| **基础** | 荣格心理类型理论 |
| **维度** | **4 个二选一** → 16 种类型 |
| **题目数** | 93 题（标准版）/ 144 题（完整版）|

| 维度 | 两端 |
| :--- | :--- |
| **能量倾向** | E（外向）vs I（内向）|
| **信息获取** | S（感觉）vs N（直觉）|
| **决策方式** | T（思考）vs F（情感）|
| **生活方式** | J（判断）vs P（知觉）|
| **结果** | 4 字母类型，如 **INTJ / ENFP** |

> **特点**：流行度最高，**16Personalities 等平台**免费测；但**学术界争议大**（信效度有限）

### 4.2 Big Five / OCEAN / 大五人格

| 字段 | 内容 |
| :--- | :--- |
| **全称** | 大五人格模型 / OCEAN |
| **学术地位** | **人格心理学金标准**（学术共识最高）|
| **维度** | **5 个**（每维两极）|

| 维度 | 两极 | 中文 |
| :--- | :--- | :--- |
| **O** | Openness | 开放性 |
| **C** | Conscientiousness | 尽责性 |
| **E** | Extraversion | 外向性 |
| **A** | Agreeableness | 宜人性 |
| **N** | Neuroticism | 神经质 |
| **工具** | NEO-PI-R / BFI / TIPI | 60-240 题 |
| **特点** | **学术研究首选** |

### 4.3 16PF / EPQ

| 量表 | 用途 |
| :--- | :--- |
| **16PF** | 卡特尔 16 种人格因素问卷 |
| **EPQ** | 艾森克人格问卷（精神质、外向性、神经质）|
| **MMPI** | 明尼苏达多项人格测验（精神病鉴定）|

## 五、应激 / 创伤 / 自伤量表

| 量表 | 用途 | 评分 |
| :--- | :--- | :--- |
| **PCL-5** | PTSD 检查表（DSM-5）| 0-80，≥33 阳性 |
| **IES-R** | 事件影响量表（修订版）| 0-88 |
| **SBQ-R** | 自杀行为问卷修订版 | 0-18 |
| **C-SSRS** | 哥伦比亚自杀严重程度量表 | 6 项分级 |
| **CD-RISC** | 心理韧性量表 | 0-100 |

## 六、量表使用决策树

```
主要诉求是什么？
├─ 抑郁筛查
│  ├─ 自评快速（1-2 min）→ PHQ-9
│  ├─ 自评详细（5-10 min）→ SDS
│  └─ 他评（医生评估）→ HAMD
├─ 焦虑筛查
│  ├─ 自评快速 → GAD-7
│  ├─ 自评详细 → SAS
│  └─ 他评 → HAMA
├─ 综合筛查
│  └─ 90 题全面 → SCL-90
├─ 人格评估
│  ├─ 类型化（通俗）→ MBTI
│  └─ 维度化（学术）→ Big Five
├─ PTSD 评估
│  └─ DSM-5 → PCL-5
└─ 自杀风险
   ├─ 快速筛查 → SBQ-R
   └─ 临床评估 → C-SSRS
```
