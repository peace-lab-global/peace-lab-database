# 数字疗法（DTx）全景与 FDA/NMPA 心理类审批图谱

## 一句话概述

> 数字疗法（Digital Therapeutics, DTx）是**基于循证医学、由软件程序驱动、用于预防/管理/治疗疾病的医疗干预** —— 本质是"数字药"，与传统药械一样受严格监管。心理类 DTx 已成为 DTx 行业最热门赛道（占全球 32% 临床试验），中国 NMPA 暂按二/三类医疗器械管理（2022 年底共 34 项 DTx 获批），FDA 已批准 reSET/SleepioRx/EndeavorRx/Flow FL-100/Rejoyn 等心理类 DTx。**2025 年中国心理 DTx 在心理健康服务市场占比将达 1.1%** —— 起步期但高速增长。

## 一、数字疗法 DTx 的定义与边界

### 1.1 DTA 十项基本原则

1. 预防、管理和治疗医学疾病或障碍
2. **由软件程序驱动的医疗干预**
3. 结合设计、制造和质量保证的最佳实践
4. 使用户参与产品开发和可用性过程
5. 结合患者隐私和安全保护
6. 应用产品部署、管理和维护的最佳实践
7. 在同行评审的期刊上发布临床试验结果
8. 收集、分析和应用现实世界证据
9. **由监管机构审查、清算或认证**
10. 根据临床评估和监管状况对产品做合理说明

### 1.2 DTx 与普通医疗软件 / 健康管理 App 的区别

| 维度 | DTx | 普通医疗软件（EMR 等） | 健康管理 App |
| :--- | :--- | :--- | :--- |
| **目的** | 治疗/管理/预防疾病 | 信息管理 | 健康生活方式引导 |
| **监管** | FDA / NMPA / CE 等 | 一般监管 | 几乎无 |
| **临床证据** | 必须 RCT 或 RWS | 通常不需要 | 不需要 |
| **医学属性** | 高 | 中 | 低 |
| **目标用户** | 患者（特定疾病） | 医疗机构 | 大众 |
| **使用方式** | 处方或医嘱 | 临床流程 | 自行下载 |

### 1.3 DTx 的四类分类

| 类别 | 风险 | 监管 | 用途 |
| :--- | :--- | :--- | :--- |
| **记录身体状况** | 低 | 无需医疗器械 | 单一使用或辅助 |
| **管理或预防疾病** | 中低 | 二类医疗器械 | 辅助或单一 |
| **优化药物治疗** | 中高 | 二/三类医疗器械 | 处方使用 |
| **疾病治疗** | 中高 | 二/三类医疗器械 | 处方使用，辅助/单一 |

### 4.2 重点产品深度解析

#### 4.2.1 reSET（Pear Therapeutics，2017-09）

- **意义**：全球首个 FDA 处方 DTx
- **机制**：认知行为治疗 + 应急管理
- **适应症**：物质使用障碍（SUD），与药物治疗联合
- **临床数据**：配合 buprenorphine 等药物可显著提升戒断率
- **状态**：Pear Therapeutics 2023 年破产，资产被拍卖，但产品仍流通

#### 4.2.2 EndeavorRx（Akili Interactive，2020-04）

- **意义**：首个 FDA 批准的游戏 DTx
- **机制**：动作类电子游戏改变大脑特定脑区和脑网络
- **适应症**：儿童多动症（8-12 岁）
- **临床数据**：与药物/教育项目联用可改善注意力和感觉运动能力
- **争议**：2024 Akili 宣布停止直接面向消费者销售，转为 B2B

#### 4.2.3 SleepioRx（Big Health，2024）

- **意义**：数字疗法首张睡眠类处方 DTx
- **机制**：CBT-I（失眠认知行为疗法）+ 移动应用
- **适应症**：慢性失眠症
- **市场策略**：**双数字健康产品战略**
  - 继续向雇主提供数字健康版 Sleepio
  - 医生通过处方提供处方版 DTx
- **支付**：通过新医保付费代码获得报销

#### 4.2.4 Flow FL-100（2025-12-11）

- **意义**：**首款可居家使用、非药物**的抑郁症治疗
- **机制**：经颅直流电刺激（tDCS）→ 前额叶皮层
- **适应症**：中度至重度抑郁症成人
- **使用**：每次 30 分钟，初期每周 5 次 × 3 周，随后减至每周 3 次
- **临床数据**：Nature Medicine 2024-12 发表 174 人 RCT
  - 临床医生评定量表显著改善
  - 患者自评问卷显著改善
  - **77% 使用者 3 周内看到改善**
- **历史覆盖**：英国、瑞士、中国香港（2025-12 之前已上市）
- **创新意义**：家用非药物治疗，绕开抗抑郁药副作用

#### 4.2.5 Otsuka × Click Therapeutics（2024）

- **意义**：重度抑郁症 DTx
- **机制**：认知情绪训练（识别和回忆不同情绪的面孔）
- **定位**：与抗抑郁药联合使用，针对仅部分反应的患者
- **市场背景**：美国 13% 成年人每天服用抗抑郁药，30% 效果不佳

### 4.3 FDA DTx 整体格局

- **认证类型**：Ⅱ类医疗器械占主流（510(k) 路径）
- **De Novo（首创）**：少数（如 reSET）
- **突破性创新设备**：少数（如 Freespira/NightWare/Cognoa）
- **紧急 EUA（疫情期间）**：2020-2021 加速
- **预认证计划（Pre-cert）**：FDA 探索，2017 起

## 五、中国 NMPA 心理 DTx 监管

### 5.1 监管路径

中国**暂未为 DTx 设立专门审批通道**，按医疗器械管理：

| 法规 | 关键内容 |
| :--- | :--- |
| **《医疗器械监督管理条例》** | 软件作为医疗器械的界定标准 |
| **《移动医疗器械注册技术审查指导原则》** | 安全性、有效性验证要求 |
| **《人工智能医疗器械审评要点》** | 算法可解释性、数据质量控制 |
| **《医疗器械分类目录》** | 数字疗法按二/三类医疗器械管理 |

### 5.2 三类软件分类

| 类别 | 风险 | 审批 | 心理 DTx 例子 |
| :--- | :--- | :--- | :--- |
| **一类** | 低 | 备案 | 简单心理监测工具 |
| **二类** | 中度 | 注册（省局） | 抑郁症 CBT 程序 |
| **三类** | 高 | 注册（NMPA） | 精神分裂症辅助治疗 |

### 5.3 注册关键步骤

1. 产品分类与路径确认（按《医疗器械分类目录》）
2. 注册资料准备与提交：
   - 技术报告（架构/算法/网络安全）
   - 临床评价资料（RCT 或 RWS）
   - 质量管理体系文件（ISO 13485）
3. 技术审评（CMDE 医疗器械技术审评中心）
4. 现场核查（生产体系）
5. 获得注册证

### 5.4 中国 DTx 获批情况（截至 2022 年底）

- **共 34 项** DTx 获批
- 大部分为二类医疗器械
- **适应症分布**：
  - 视觉功能治疗和训练 **47.1%**
  - 认知障碍辅助治疗和康复 **35.3%**
  - 乙肝 6.1%
  - 肺部康复 6.1%
  - 运动康复 2.9%
- **临床试验分布**：
  - 精神障碍 32.1%
  - 行为认知障碍 15.0%
  - 肿瘤 13.1%
  - 内分泌及代谢疾病 5.6%
  - 神经系统疾病 0.6%

## 六、心理 DTx 应用场景细分

### 6.1 睡眠障碍

- **金标准**：CBT-I（失眠认知行为治疗）
- **DTx 优势**：解决医生资源有限 + 依从性差
- **代表**：SleepioRx（FDA）、心景科技

### 6.2 儿童注意力训练

- **金标准**：药物（哌甲酯） + 行为治疗
- **DTx 优势**：避免药物副作用
- **代表**：EndeavorRx（FDA）、数药智能

### 6.3 物质使用障碍

- **金标准**：药物 + 行为治疗
- **DTx 优势**：远程 + 持续干预
- **代表**：reSET / reSET-O（FDA）

### 6.4 认知障碍

- **金标准**：胆碱酯酶抑制剂
- **DTx 优势**：早期干预
- **代表**：博斯腾、虚之实科技

### 6.5 焦虑 / 抑郁

- **金标准**：SSRI + CBT
- **DTx 优势**：辅助治疗、个性化
- **代表**：Otsuka + Click、Rejoyn、Flow FL-100

### 6.6 创伤后应激障碍（PTSD）

- **金标准**：暴露疗法
- **DTx 优势**：VR 暴露，避免真实创伤回忆
- **代表**：Freespira、Easyway

## 八、行业痛点与挑战

### 8.1 四大核心痛点

1. **行业标准缺乏**
   - 临床试验设计差异大（无统一标准）
   - 同一病种 DTx 部分做 RCT，部分单臂实验
   - 临床终点设置各不相同
   - 中国暂无专门 DTx 审批通道

2. **临床侧认知不足**
   - 大量市场教育需求
   - 医生对 DTx 接受度低
   - 患者对处方 DTx 接受度待培养

3. **精准化、个性化不足**
   - 产品推出时间短，数据积累不足
   - 难以针对某一临床症状进行精确服务
   - 缺乏多模态数据融合

4. **商业模式尚处雏形**
   - 2C 接受度低
   - 2B 雇主需求不稳定
   - 2G 医保支付路径未打通
   - 2I 商业保险未广泛覆盖

### 8.2 技术局限性

- 患者使用意愿与技能
- 数据获取的准确性和可重复性
- 实时/批量数据收集的可靠性
- 数据安全（隐私保护 + 软件漏洞 + 安全认证）
- 产品更新迭代（算法活性成分变化）
- 离线使用场景支持

### 8.3 监管挑战

- 技术发展速度 > 法规出台速度
- DTx 动态性 vs 传统器械静态审批
- 中国 DTx 软件特性和传统医疗器械差异极大

## 九、未来趋势（2025-2030）

### 9.1 技术趋势

1. **AI + DTx 深度融合**：个性化推荐 + 疗效预测
2. **VR/AR 应用普及**：疼痛管理 + 中风康复
3. **可穿戴 + 远程监控**：实时、动态监测
4. **DTx + 药物联合疗法**：综合治疗
5. **区块链保障数据安全**：可信度提升
6. **NLP 发展**：患者-系统互动智能化

### 9.2 商业模式

- **基于疗效的支付模式（Value-Based Care）**成主流
- 保险覆盖率提升 → 会员制服务模式
- 患者主动健康管理工具 + B2C 数字化产品
- 智能可穿戴设备衔接

### 9.3 政策趋势

- 美国 FDA、欧盟、中国监管机构**进一步完善 DTx 框架**
- 推动**法规全球统一化进程**
- 远程医疗 + 互联网医院**处方"数字药"**
- 行业集中度提升：初创被巨头收购

### 9.4 中国市场预测（2025-2027）

- 数字精神医疗年增 38.6%（2024-2025）
- 政策驱动（海南模式 + 25 部委 2026 实施方案）
- AI Agent 化（主动干预）
- 软硬件一体化协同
- 院内外无缝衔接

## 十、行动建议

### 10.1 创业/产品端

- **抓住 DTx 行业标准建立窗口期**（2025-2027）
- **优先 B 端市场**（医院 / EAP / 保险）而非纯 C 端
- **与医疗器械企业合作**（硬件 + 软件）
- **关注软硬件一体化**（虚之实模式）
- **重视循证医学**（临床数据是壁垒）

### 10.2 投资端

- **优先医疗级 DTx**（二/三类医疗器械路径）
- **关注脑机接口 + DTx**（虚之实、博睿康）
- **关注睡眠 / 抑郁 / 焦虑**三大主流适应症
- **关注儿童 / 老年**两大高潜适应症

### 10.3 政策端

- 推动中国 DTx 专门审批通道建立
- 推动 DTx 纳入医保
- 推动 DTx 进入医院处方流程
- 与海南 DTx 政策协同

### 10.4 用户端

- 失眠 / 焦虑 / 抑郁患者：可考虑 FDA 已批 DTx
- 儿童 ADHD：EndeavorRx
- PTSD：VR 暴露疗法（Freespira）
- 家用非药物治疗：Flow FL-100
- 国内可用产品：心景科技 / 京东健康 / 简单心理 / 壹心理 等
