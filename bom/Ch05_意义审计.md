# 第五章 · 意义审计

> 上一部你理解了意义，这一部回答更具体的问题：**你的**意义，缺在哪？
> 审计只需 15 分钟，但它会把后面十八章变成一份为你定制的地图。

---

## 5.1 四维意义审计

对以下四个维度逐一自评。每个维度 5 个信号，数一数你命中几条（凭最近两周的常态）。

### 维度一：澄清力（知道我在乎什么）

- [ ] 我说不清"我在乎什么"（价值模糊）
- [ ] 我做决定时不知道"该选什么"（没有罗盘）
- [ ] 我活在别人的期待里（父母/社会/同辈）
- [ ] 我不知道"什么对我是重要的"
- [ ] 我很少问自己"我在乎什么"

**命中 3 条以上** → 澄清力缺失，优先读：[第九章 价值澄清](Ch09_价值澄清.md)。

### 维度二：叙事力（我的故事是什么）

- [ ] 我说不清"我的故事是什么"（没有叙事）
- [ ] 我的故事是"受害者叙事"（为什么总是我）
- [ ] 我的故事是"别人写的"（活在别人的剧本里）
- [ ] 我无法把经历编织成有意义的故事
- [ ] 我很少反思"我的经历教会了我什么"

**命中 3 条以上** → 叙事力缺失，优先读：[第十一章 叙事重建](Ch11_叙事重建.md)。

### 维度三：超越力（与更大的东西连接）

- [ ] 我感到"我只是我，没有更大的我们"
- [ ] 我没有信仰/使命/超越性的东西
- [ ] 我感到与人类/自然/宇宙失联
- [ ] 我没有"为比自己更大的东西服务"的感觉
- [ ] 我感到孤独（存在孤独，[《孤独之书》](../bol/INDEX.md)）

**命中 3 条以上** → 超越力缺失，优先读：[第十五章 超越与连接](Ch15_超越与连接.md)。

### 维度四：日常力（在琐碎中找到意义）

- [ ] 我在日常中找不到意义（做饭/工作/陪伴）
- [ ] 我觉得"日常是琐碎的，意义在远方"
- [ ] 我无法在重复中找到意义
- [ ] 我觉得"只有大事才有意义"
- [ ] 我很少在日常中感到"这值得做"

**命中 3 条以上** → 日常力缺失，优先读：[第十九章 日常的意义](Ch19_日常的意义.md)。

## 5.2 六型意义缺失模式：你是哪一型？

四维找"哪里缺"，六型找"怎么缺"。圈出最像你的（允许选两型）。

### 🌫️ 空虚型
**体验**：什么都不缺，但什么都不够；有工作/有伴侣/有朋友，但仍感到空。
**底层**：超越力缺失——没有与比自己更大的东西连接。
**你的路线**：[第十五章 超越与连接](Ch15_超越与连接.md) → [第十四章 服务与贡献](Ch14_服务与贡献.md) → [第十九章 日常的意义](Ch19_日常的意义.md)。

### 🌀 迷茫型
**体验**：不知道该往哪走；每个选择都好像对，又好像不对；没有方向感。
**底层**：澄清力缺失——不知道自己在乎什么。
**你的路线**：[第九章 价值澄清](Ch09_价值澄清.md) → [第十章 使命陈述](Ch10_使命陈述.md) → [第十一章 叙事重建](Ch11_叙事重建.md)。

### 🔥 倦怠型
**体验**：曾经有意义，现在耗尽了；工作/关系/项目曾经有意义，现在只是负担。
**底层**：日常力缺失——在日常中找不到意义了。
**你的路线**：[第十九章 日常的意义](Ch19_日常的意义.md) → [第十二章 工作重构](Ch12_工作重构.md) → [第十三章 心流与投入](Ch13_心流与投入.md)。

### ⚖️ 比较型
**体验**：活在别人的剧本里；别人的意义成为你的标尺；你总在比较。
**底层**：叙事力缺失——你的故事是别人写的。
**你的路线**：[第十一章 叙事重建](Ch11_叙事重建.md) → [第九章 价值澄清](Ch09_价值澄清.md) → [《平静之书》第十二章](../bop/Ch12_Cognitive_Tools.md)（认知重构）。

### ⚙️ 功利型
**体验**：只做"有用"的事；不能变现的爱好、不能升职的学习、不能赚钱的创作，都是"浪费时间"。
**底层**：澄清力缺失——把意义等同于"有用"。
**你的路线**：[第九章 价值澄清](Ch09_价值澄清.md) → [第十四章 服务与贡献](Ch14_服务与贡献.md) → [第十九章 日常的意义](Ch19_日常的意义.md)。

### 🌊 存在型
**体验**：即使有人陪、有事做，仍感到一种说不出的空；"这一切有什么意义"。
**底层**：存在孤独（[《孤独之书》第一章](../bol/Ch01_What_Is_Loneliness.md)第三层）——人的本质，无法被"解决"，只能被"共处"。
**你的路线**：[第十五章 超越与连接](Ch15_超越与连接.md) → [第十六章 智慧传统的意义观](Ch16_智慧传统的意义观.md) → [《孤独之书》第十五章](../bol/Ch15_Belonging_And_Meaning.md)。

## 5.4 你的定制意义地图

```
我的意义审计（日期：____）
1. 最缺的维度：____ / 4（澄清/叙事/超越/日常）
2. 我的主导意义缺失模式：____ 型（次要：____ 型）
3. 未来四周的修炼路线：
   第一周读：第__章 ________
   第二周读：第__章 ________
   第三周读：第__章 ________
```

**两条使用规则：**

1. **一次只补一维。** 四维全开的计划存活率低；先补最痛的那一维。
2. **急救箱人人先学。** 无论哪型，[第六章 意义急救箱](Ch06_意义急救箱.md)都是所有人的第一课。

## 📌 本章速记

- 四维审计：**澄清/叙事/超越/日常**各 5 信号，命中 3+ 即缺失。
- 六型意义缺失模式：**空虚、迷茫、倦怠、比较、功利、存在**——每型自带修炼路线。
- 一次补一维；急救箱（第 6 章）人人先学。
- 若自检出现持续抑郁、自伤意念等信号——跳过计划，先读[第 22 章](Ch22_意义的阴影与求助.md)。
