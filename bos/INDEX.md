# 力量之书 (Book of Power)

> 现代职场人的力量提升指南。
> 一句话总纲：**力量不是压过别人，而是能扛住、能行动、能影响、能修复——它是可以被理解、被训练、被系统化重建的综合能力。**

---

## 这本书是什么

本书是 Peace Lab Database（平静实验室知识库，4,900+ 专业文档）的总纲与入口之一。它与[《平静之书》](../bop/INDEX.md)互为姊妹篇：

- **平静之书**回答"如何在风浪中站稳"——安定、恢复、守；
- **力量之书**回答"站稳之后，如何前进"——承受、行动、影响、攻。

《大学》说"定而后能静，静而后能安，**安而后能虑，虑而后能得**"——平静是力量的底座，力量是平静的用途。先读哪本都可以，但建议：**先用平静之书补底座，再用力量之书练前进；两本交替使用，效果最佳。**

本书同样回答四个问题：

1. **认知** —— 力量到底是什么？它和权力、强硬、控制有什么区别？
2. **诊断** —— 我的力量从哪里漏掉的？我属于哪种"无力模式"？
3. **方法** —— 从 10 分钟找回状态，到 28 天系统的力量建设，具体怎么做？
4. **建议** —— 力量如何不变成暴虐？如何与影响力、领导力、组织现实正面相处？

本书不贩卖鸡血、不做道德绑架、不承诺"三天变强"。它是教育与自我调节参考，不构成医学诊断；涉及红旗症状时，请直接阅读[第 22 章：力量的阴影与求助](Ch22_The_Shadow_Of_Power.md)。

## 力量四维模型（全书的坐标系）

本书把"力量"拆成四个可训练、可审计、可补强的维度：

```
力量 = 承受力 × 行动力 × 影响力 × 恢复力

┌─────────────────────────────────────────────┐
│  承受力  ← 扛住：压力、挫折、批评、不确定       │  ← 对应 平静之书 的安定技术
│  行动力  ← 做成：启动、执行、决策、坚持、达成    │
│  影响力  ← 影响：表达、立场、气场、领导、谈判    │
│  恢复力  ← 修复：休息、复盘、反弹、长期主义      │  ← 力量的后勤部，最容易被忽略
└─────────────────────────────────────────────┘
```

四个维度相乘——**任何一维接近零，总力量就接近零**。多数人的问题不是"没力量"，而是某一维漏成了短板：能扛不能动（空转）、能冲不能守（透支）、能想不能说（沉默）、能说不能扛（纸老虎）。[第 5 章：力量审计](Ch05_Power_Audit.md)就是来定位你的短板的。

你现在就处在一个需要"支棱起来"的时刻——发言前、谈判中、被挑战后、拖延瘫软中——直接去：

- [第 5 章：力量审计](Ch05_Power_Audit.md) —— 六维自检 + 六型无力模式，每型附专属章节地图

## 使用本书的两条约定

1. **每章只要求一个最小行动。** 读完不做，等于没读。每章末尾的「本章练习」，至少完成一个。
2. **力量必须练习，不是阅读。** 本章是地图，不是领土；每章末尾的「深潜」通向知识库对应专题的完整文档。
