# Peace Lab Database (平静实验室知识库)

一个专业的、多维度的身心疗愈与个人进化知识体系。项目通过 **"六大核心支柱 + 跨域聚合层"** 架构，整合了古代智慧传承、现代心理学、生命科学、人文艺术与行业前沿。

> 📊 **规模**: 4,900+ 专业文档 · 116 万+ 行 · 24 个 Agent Skills · 10 条跨支柱学习路径

---

## 🧭 知识架构 (Architecture)

六大核心支柱 + 两个跨域聚合层。所有支柱目录已中文化，便于本地化协作。

### 核心知识支柱

#### 1. [🏛️ 智慧传承 (Wisdom Traditions)](01-智慧传统/INDEX.md)
**核心领域**: 瑜伽哲学、禅宗/道家/佛教全体系、太极拳、黄帝内经养生、东西方古典哲学、全球灵性疗愈、南传/藏传/汉传佛教传承。

#### 2. [🧠 心智与心理学 (Mind & Psychology)](02-心智心理/INDEX.md)
**核心领域**: 现代心理流派（CBT/ACT/DBT/IFS/SE/CAT/MBCT/IPT/IPSRT/SFBT/叙事治疗/MDMA 辅助）、临床干预（焦虑/创伤/成瘾/强迫/抑郁）、冥想技术（坛城/直指/止观/大师传承）、自我调节、孤独与仇恨心理学、亲密关系、成瘾治疗。

#### 3. [🏃 生命科学与生物医学 (Bio-Science & Medicine)](03-生命科学/INDEX.md)
**核心领域**: 生物黑客（睡眠/断食/呼吸/血压调节）、神经科学（BCI/DMN/迷走神经/多迷走理论）、身心能量恢复、办公健康、性学研究、营养学与死亡教育。

#### 4. [🎨 人文与艺术疗愈 (Humanities & Arts)](04-人文艺术/INDEX.md)
**核心领域**: 艺术史与艺术疗法、芭蕾艺术全系、古典音乐疗愈（莫扎特/巴赫/肖邦/拉赫玛尼诺夫）、文学书评（中外经典 300+）、影音媒体与深度阅读、戏剧/书法/园艺/摄影治疗。

#### 5. [🌱 实践与个人增长 (Praxis & Growth)](05-实践成长/INDEX.md)
**核心领域**: 超级个体商业模式、效率与执行力、心力成长与稳定内核、高效沟通与结构化表达、心流与专注力、自媒体变现、创意/技术写作、TED/一席讲座知识框架、正念习惯。

#### 6. [🏥 临床专题 (Clinical Topics)](06-临床专题/INDEX.md)
**核心领域**: 跨支柱临床聚合层 —— 焦虑、抑郁、睡眠障碍、哀伤丧亲、拖延症、MBCT 正念认知疗法，按疾病/问题维度聚合。**仅保留原创临床深度内容**（药理/督导/安全/共病）。

## 🤖 Agent Skills — 智能体技能模块

本项目不仅提供知识文档，还包含可直接供 AI 智能体调用的 **结构化技能模块（Agent Skills）**。每个技能含决策树、评估模板、转介指征与使用示例。

### 设计原则

| 原则 | 说明 |
|:-----|:-----|
| **决策树驱动** | 清晰的判断流程，智能体可据此与用户交互 |
| **结构化输出** | 评估报告模板化，生成规范、一致的专业输出 |
| **技能链接** | 明确标注何时触发其他技能，支持多技能协同 |
| **转介指征** | 内置医疗/专业转介红线识别，防止延误就医 |

### 技能调用示例

```
用户: "我最近工作压力特别大，已经一个月了，睡不好白天很累"

智能体调用流程:
1. → Stress_Assessment_Skill
   收集信息 → 分类为亚慢性/慢性压力
2. → Cortisol_Management_Skill / Cortisol_Rhythm_Assessment_Skill
   判断皮质醇状态（可能存在节律紊乱）
3. → Chronic_Stress_Intervention_Skill
   根据严重程度选择干预层级
4. → Relaxation_Techniques_Guide_Skill
   提供具体放松技术方案
```

### 已上线模块概览（24 个技能，6 大模块）

完整注册表见 [skills-index.md](skills-index.md)。

| 模块 | 技能数 | 核心功能 |
|:-----|:------:|:---------|
| **压力与 HPA 轴** | 9 | 压力评估、皮质醇管理、慢性疲劳识别、放松技术 |
| **临床评估** | 4 | 抑郁(PHQ-9)、创伤(PCL-5)、失眠(ISI)、成瘾(AUDIT/DAST) |
| **自我调节** | 4 | 焦虑、强迫(OCD)、自尊(RSES/SCS)、韧性脆弱自我 |
| **积极心理** | 1 | 幸福感(PERMA/SWLS/VIA) |
| **应用心理** | 2 | 职业倦怠(MBI)、亲密关系(CSI/ECR-R) |
| **整合疗法** | 2 | IFS 部分工作、Somatic Experiencing 躯体干预 |
| **领导力** | 1 | 领导力与影响力(Goleman/Cialdini) |
| **冥想止观** | 1 | 止观模式识别（中观唯识框架） |

### 智能体使用注意事项

- Agent Skills 提供**方向性评估和建议**，不替代医学诊断
- 如识别到红旗症状（如严重疲劳、PEM、持续失眠、自杀意念），应建议用户寻求医疗专业人士帮助
- 干预强度和频率应根据用户反馈动态调整
- 所有建议应与用户的价值观和偏好协调
