# 第五章 · 自我观察与阅读导航

## 5.1 先不急着给自己分类

陈宁白天处理工作，晚上照顾家人。有一周连续几天睡得很晚，打开电脑却很难推进任务。陈宁想知道自己究竟是“过载型”还是“自我批评型”。但如果只选择一个标签，就可能漏掉更直接的信息：这几天到底睡了多久，谁能分担照护，有哪些任务可以重新协商。这是本书的虚构情境，不是人物测评结果。〔证1〕

本章邀请你作一次自我观察。下面六个角度由Sonus用于整理阅读路线，没有经过量表开发与验证。它们不诊断疾病，不划分人格，也没有“命中几条就说明什么”的阈值。任何一项都可以跳过，回答多并不意味着问题更严重。〔证2〕

如果此刻已经存在即时危险、严重急性躯体症状，或担心自己会伤害自己，请先获取现实中的帮助，不必填写。具体分流与核验后的资源见[第二十二章](Ch22_When_To_Seek_Help.md)。〔证3〕

## 5.2 六个观察角度

阅读时可以只选最贴近当下的一项。表里的提问是观察提示，不是疾病症状清单；章节对应关系是编排建议。〔证2〕

| 角度 | 可以问自己的问题 | 可能需要进一步了解什么 | 阅读入口 |
|---|---|---|---|
| 身体 | 最近睡眠、疲惫、疼痛或不适有什么变化？ | 是否需要休息、生活安排调整或医疗评估，而非先解释成心态问题？ | [第八章](Ch08_Evening_Offload.md)、[第九章](Ch09_Body_Foundation.md)、[第二十二章](Ch22_When_To_Seek_Help.md) |
| 注意与念头 | 哪件事反复占据我的注意？ | 是信息不足、任务未定、环境打断，还是重复思考没有带来新信息？ | [第十章](Ch10_Digital_Hygiene.md)、[第十二章](Ch12_Cognitive_Tools.md) |
| 情绪 | 我能否说出此刻的感受？ | 我需要理解、陪伴、暂时安顿，还是先处理引起它的事情？ | [第六章](Ch06_First_Aid_Toolkit.md)、[第十四章](Ch14_Emotional_Alchemy.md) |
| 关系 | 和谁相处时，我能够表达不同意见？ | 难处来自误解、权力差异、持续贬损，还是几个因素同时存在？ | [第十五章](Ch15_Values_And_Boundaries.md)、[第十九章](Ch19_Relationships_Peace.md) |
| 条件 | 日程、空间、设备和资源给我留下多少余地？ | 哪些条件可以调整，哪些需要别人参与，哪些暂时改变不了？ | [第七章](Ch07_Workplace_Playbook.md)、[第二十章](Ch20_Environment_Design.md) |
| 方向 | 我正在维护什么，又付出了什么？ | 是需要重新选择，还是需要承认两个重要价值暂时无法两全？ | [第十五章](Ch15_Values_And_Boundaries.md)、[第十八章](Ch18_Meaning_And_Work.md) |

同一个问题可能落在多个角度里。读者不必先找到唯一原因，也不必把不确定写成一个完整的解释。相比“我是怎样的人”，本章更关心“现在发生了什么，接下来还需要知道什么”。〔证2〕

## 5.3 把解释暂时写在事实旁边

Sonus建议用三栏代替总分：一栏写观察到的事，一栏写自己的解释，另一栏写尚不知道的部分。这个方法是本书的整理方式，不是标准化评估。〔证4〕

| 我观察到的事 | 我现在的解释 | 仍需了解什么 |
|---|---|---|
| 这周有三晚因照护很晚才睡 | “我是不是已经没有工作能力” | 工作状态在得到休息后有无变化？照护能否分担？ |
| 负责人连续两次临时改变要求 | “一定是我沟通得不够好” | 要求是否有书面记录？其他成员是否遇到同样问题？ |
| 发出边界请求后，对方没有回复 | “关系已经毁了” | 对方是否看到消息？是否需要改用别的沟通方式？ |

表中例子均为虚构，不表示这些解释一定错误。有时进一步了解后，我们会发现担忧有现实根据；有时会发现还有另一种解释。两种结果都值得认真对待。〔证1〕

## 5.4 从一个问题开始，不从一整套训练开始

陈宁最后没有选类型，只写下：“我这周最需要的是有人分担两次晚间照护。”家人的回应却是也没有余力。付费照护暂时负担不起，原先期待的办法到这里走不下去了。〔证1〕

故事里的陈宁最终向负责人提出，取消本周一次非必要汇报，交付日期保持不变。负责人同意了取消汇报，却要求当天补一份书面说明。陈宁没有把它当作协商成功，继续说明：口头汇报换成长文档，并没有减少工作。第二次讨论后，双方同意用已经存在的进度记录代替。这个安排省下了一段准备时间，也让陈宁失去了一次向更高层展示工作的机会。担心被忽视的感受仍在，陈宁决定这周先承担这个代价。〔证1〕

到了周末，照护困难还没有解决，但陈宁能够分开说两件事：一项工作已减量，晚间仍缺人分担。接下来需要继续讨论的，是照护资源，而非证明自己能用省下的时间练出更好的心态。这条故事线只呈现一次有限取舍；换一位负责人，得到的也可能是拒绝。〔证1〕

本书建议把行动分为三个方向来考虑：自己可以尝试的调整，需要与他人协商的条件，需要专业或制度支持的问题。它们可以同时存在，不能把第三类都转化成第一类练习。这个区分是Sonus的决策辅助，不是临床分诊算法。〔证4〕

如果你正在反复思考同一件事，可以先读第十二章；如果现实中仍有持续伤害，不宜只训练自己“不被触发”，应一并阅读第十八、十九章；如果主要需要休息，可以从第八、九章开始，不必先完成冥想课程。这些路线供选择，不排除其他合适路径。〔证2〕

## 5.5 一张可留白的记录

这张表可以抄在纸上，也可以只在心里回答。无需按日填写。〔证4〕

| 提问 | 我的记录 |
|---|---|
| 此刻最具体的困难是什么？ | |
| 我已经知道哪些事实？ | |
| 我还不确定什么？ | |
| 我希望先得到什么帮助或改变？ | |
| 一个我愿意尝试的动作是什么？也可以暂时不选 | |
| 谁或什么资源可以参与？ | |
| 什么时候值得重新看一眼？ | |

重新阅读记录时，不用比较分数。可以看看困难是否变了、条件是否变了、自己的理解是否需要修正。即使没有变好，记录也不应成为“我又失败了”的证据。这是本书的使用约定；它不宣称记录本身具有已验证的治疗效果。〔证4〕
