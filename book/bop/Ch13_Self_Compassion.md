# 第十三章 · 与内在批评者相处

## 13.1 那份报告确实写错了

在一个虚构情境里，林澄提交的报告出现一处数据错误，同事因此多花时间重新核对。林澄道歉后，仍然不断想：“这点事都能弄错，我根本不适合做这份工作。”朋友说不要自责，林澄却觉得，这样岂不是把错误轻轻放过了。

这个问题值得认真对待。关怀如果只剩“你已经很好”，确实可能绕过需要修正的事情。但承担责任也不必以羞辱整个人为条件。错误发生在哪一处、影响了谁、接下来如何补救，都可以说得具体；“我根本不行”却没有告诉任何人该改哪张表。〔证1〕

本书把“批评者”当作一类自我对话的称呼，不当作脑内实体或诊断。它有时包含需要核对的信息，有时带着过度概括，有时只是很熟悉的一种口气。我们不必先决定它来自谁，才开始分辨哪些话值得听、哪些话不必照单全收。〔证2〕

## 13.2 不急着替批评找到童年来源

自我批评一出现，就认定是父母、老师留下的声音，证据并不充分。当前的评价制度、一次具体失误、过去的经验，都是可以讨论的线索；一本书无法依据一句“我不配”判定它的来历。本章不提供追溯第一次创伤的自助任务，也不要求读者必须认可“它都是为了保护你”。〔证2〕

可以从当下这句话开始：它指出了什么事实？它扩大了哪些范围？它要求我做一件可执行的事，还是要求我成为永远不会失败的人？Sonus建议暂时保留具体信息，撤下人格判决。即使批评源于善意，其表达也仍然可以被质疑；即使找不到善意，也无需先原谅它才能改变回应。〔证3〕

例如，“这页引用没有核对”值得处理，“你不值得被信任”则需要更广的证据，不能由一处错误自动推出。我们要争取的是更准确的责任，不是把所有不舒服的话都改成赞美。〔证3〕

## 13.3 自我关怀：失败时仍然怎样对待自己

Neff的概念论文把自我关怀描述为三个相互联系的方面：善待自己、共同人性与正念觉察。这个框架关注的是面对痛苦和不足时的态度，不要求先证明自己优秀，也不等同于提高自我评价。〔证4〕

**善待自己**可以落实为不再追加贬损，同时照顾眼前需要。**共同人性**不是“别人更惨，所以你不该难过”，而是不把一次失败当作自己被排除在人群之外的证据。**正念觉察**则容许看见痛苦，不必完全被它代表，也不必假装它不存在。这些是对该概念框架的中文释义，不是三项必须全部完成的成绩。〔证4〕

关于效果，Kirby等人的慈悲干预元分析报告了部分心理指标的改善，同时指出小样本和研究质量的限制。本次取得的是摘要；不同干预和对象不能互换，更不能由完整训练的结果推出“一分钟对自己说好话必能提高动机”。本书不把更强、更能工作，设为关怀值得发生的理由。〔证5〕〔证6〕

也许林澄尚不相信“我值得被爱”，但可以先同意：“这份报告要修正，我今天也仍然需要吃饭。”这种朴素的照顾，不要求先完成一场关于自我价值的辩论。它是本书提出的实践立场，不是某一种情绪必须随之改变的保证。〔证6〕

## 13.4 一张同时留下责任与支持的记录

如果愿意，可以用一个近期的小事件试写下面几行。不必挑最痛苦的经验，也不必追问童年。安排几分钟即可；没有合适的私人空间，可以不写。〔证7〕

| 我想分清什么 | 林澄的虚构示例 |
|---|---|
| 批评原话 | “你连这点事都做不好。” |
| 能确认的事实 | 报告的一处口径错误，同事需要重新核对 |
| 应承担的责任 | 更正报告，说明影响，向同事道歉 |
| 不必一并接受的判决 | 一次错误不能概括全部能力，也不能决定是否配得到照顾 |
| 一句可以相信的支持 | “现在先把错误改清楚，之后一起检查流程。” |
| 我需要的实际帮助 | 请同事确认口径，调整下一次复核安排 |

这张表由Sonus编排，概念上借鉴自我关怀和事实检验。它不要求把错误归咎于制度，也不要求独自承担所有后果：如果工作量、分工或标准参与了问题，可以一并讨论，但需具体材料。若记录加重羞耻或使自己反复自责，就停止，转为普通休息或请求陪伴，不必填完。〔证7〕

对朋友会怎样说话，是一个可选的问题，不是所有人都现成拥有的答案。有些人对朋友同样苛刻，有些人当下没有可信任的人。可以改问：“怎样把这件事说明白，又不添加羞辱？”支持的语气也可以平实，不必甜美。〔证7〕

林澄更正后，同事仍然生气，没有立即回应道歉。自我关怀无法要求对方更快释怀。林澄能够做的是承担该承担的事，并在等待关系变化时不继续以失去照顾惩罚自己。故事在这里仍有尴尬，也仍然允许吃饭、休息和继续工作。〔证1〕

## 13.5 “不同部分”是一种可选语言

内在家庭系统（IFS）的教材介绍以不同内在“部分”及其关系理解心理冲突。本次只核对出版方和专业机构介绍，未核读治疗程序，因此本章只借用概念，不把下面的日常表达称为IFS治疗。部分语言也不证明一个人脑内存在多个独立人格。〔证8〕

有些读者愿意说：“我有一部分很怕犯错，另一部分已经很累。”这种说法可以用来表达冲突。也有人更喜欢直接写：“我担心被否定，同时需要休息。”两种语言都可以，Sonus不规定必须把批评者人格化、感谢它或给它换岗。〔证9〕

如果使用“部分”一词，可以只停在当前需要上：我在担心什么，眼下能处理哪一件事？不要求闭眼进入记忆，不通过想象推断曾发生的创伤，不与所谓内在角色长时间争辩。若这种练习让自己更恐惧、混乱或难以回到日常，就停止，不自行用教材介绍处理创伤；困扰严重或影响功能时寻求专业支持。〔证9〕〔证10〕

把心理冲突写成角色，只是表达选择。它不应成为读者又一件需要证明自己“做对了”的任务，也不能替代对现实中的不合理要求提出异议。〔证9〕

## 13.6 关怀有时表现为停止一件事

Sonus建议把关怀的检验从“我有没有感觉温暖”移到一个更具体的问题：我有没有继续要求自己接受不必要的羞辱？有时行动是一句比较公平的话，有时是结束深夜的反复复盘，有时是请求资源、拒绝新增任务，或承认独自处理已不够。这里讨论的是可以考虑的行动，不是证明关怀有效的指标。〔证11〕

也需要承认另一种困难：今天找不到支持性的说法，听见“对自己好一点”反而烦躁。可以把练习撤下，只处理喝水、用餐、联系一个人等眼前事项，或者什么也不额外安排。本书不要求连抵触也必须被温柔地解决。〔证11〕

如果“我不值得活着”或伤害自己的冲动出现，事情已超出练习自我对话的范围，应立即寻求帮助和安全评估；若有当前计划、意图、已经行动或无法保证安全，按[第二十二章](Ch22_When_To_Seek_Help.md)的紧急路径获得当地救援，不等到练习起效。〔证10〕

回到林澄的报告，错误并没有因为这一章变小，关系也没有被保证修复。值得保留的是一个区分：我可以有需要改正的地方，也可以在改正之前、之中、之后得到照顾。〔证6〕
