# 第十二章 · 认知工具的选择

## 12.1 有时，那个担忧是对的

在本书的虚构情境里，林澄收到一句“方案再想想”，担心自己的工作不被认可。若马上把担忧归类为读心，就跳过了关键问题：此前发生过什么？反馈是否一贯含糊？是否已经有正式的绩效意见？我们不能因为一句话令人难受，就宣布它一定不符合事实。〔证1〕

认知行为治疗教材包含识别、评价和回应自动思维，以及通过行为实验检验判断的方向。这里的重点是联系证据，不是强迫相信积极暗示。ACT则提供另一个角度：有时无须先解决念头的真伪争论，也可以改变与念头的关系，继续作出有价值的行动。两者不应被混成同一种“换个好想法”。〔证2〕〔证3〕

本章建议先问：我需要更多事实，还是正围着一个暂时无法证明的判断不断争辩？工具的选择由问题决定，不由某一种方法被叫作“最强”来决定。〔证4〕

## 12.2 查证：把事件与解释暂时分开

我们可以用林澄的处境试填一张表。以下记录和句式由Sonus编排，借鉴事实检验的方向；它不是完整CBT治疗，也不要求在情绪最强烈时完成。〔证5〕

| 要分开的部分 | 虚构示例 |
|---|---|
| 可观察的事情 | 负责人回复“方案再想想”，没有说明改哪一处 |
| 我作出的解释 | 对方已经认定我能力不行 |
| 支持这个解释的材料 | 前一次汇报也被退回；需要核对当时的具体意见 |
| 尚不符合这个解释的材料 | 本周仍让我负责另一项任务，但这不能单独证明对方满意 |
| 暂时不知道什么 | 反馈针对目标、数据，还是对能力的总体评价 |
| 可以怎样求证 | 询问最需要修改的一项，以及采用什么验收标准 |

不必让两边的证据数量相等，也不必为平衡而凭空补一个好消息。资料不足时，结论可以只是“现在无法确定”。新的说法要比原判断更贴近已知事实，未必更悦耳。〔证5〕

后来，林澄得到的答复确实包含对分析能力的质疑。先前担忧没有被推翻。接下来可以分辨质疑是否具体、标准是否一致，需要学习什么，又需要对不合理要求提出什么。这段虚构后续说明，查证并不总以“原来我想多了”收尾。〔证1〕

常见的概括也可以这样检查：“这次没有做好”描述一次结果，“我什么都做不好”扩大了范围；“对方没有回复”是观察，“对方故意羞辱我”还需要额外材料。这些是本书选取的推理例子，不是一套可据以识别他人人格的标签。面对真实羞辱，查证不意味着反复替施害者寻找善意。〔证5〕

## 12.3 解离：不必每个念头都辩到赢

ACT中的认知解离关心念头如何影响行为，而不只是念头内容真假。例如，“我肯定讲不好”仍然出现时，人可以看见这是一项预测，不把它直接当作取消发言的指令。概念上留出距离，不保证焦虑马上下降。〔证3〕

如果愿意，可以在一个念头前加上“我注意到自己正在想……”。说过之后，看看眼前有什么需要处理，不必反复念到相信为止。这是Sonus对解离概念的短式改编，不是来源教材的一套完整治疗步骤。若觉得句式矫揉造作，直接写下“这是我的预测，结果还没发生”也可以。〔证6〕

距离也有边界。正式的裁员通知、确实发生的骚扰和身体的不适，不能通过加上“我有一个想法”就降格为幻觉。解离针对的是与念头的关系，不取消核实事实、获得医疗或保护权益的需要。本书因此不建议把这句话用来打断他人讲述伤害。〔证6〕

有时反复执行工具本身也变成了负担：一定要说满几遍，才能确保念头不再影响自己。此时可以停用这段句式。是否值得保留，取决于它在实际生活里的用途，而不是读者能否熟练背出术语。〔证6〕

## 12.4 接纳：容纳感受，仍然可以反对事情

ACT把接纳置于心理灵活性的框架中，与价值和承诺行动相联系。这里谈的是对内在经验的开放，不是认定外部事件正当，也不是要求喜欢疼痛、羞辱或损失。它不同于忍着不说，更不能作为让别人继续忍耐的命令。〔证3〕

本书建议把两句话并列试读：“我现在确实害怕”和“我仍然需要获得一份清楚的说明”。害怕无需先被驳倒，事情也没有因此停止处理。可以承认自己暂时做不到，再找同行者或把行动缩小。情绪没有消失，不等于承诺被违背。〔证7〕

同样，接纳不承担处理急性症状的功能。严重或新出现的急性躯体症状应优先获得医疗评估；若有即时生命危险，先联系当地急救。不能因“练习与感觉待在一起”而耽误必要行动。〔证8〕

## 12.5 概率：不知道，就不要写一个安慰数字

面对“我会失业”这样的担忧，Sonus建议分开写：已经确认的迹象，尚未确认的消息，若发生时最先需要处理的事。没有可用数据，就写概率未知。本书不提供“通常低于5%”一类对所有人的保证，也不把主观估计伪装成客观概率。〔证9〕

若确有资料，还需问资料针对谁、哪一段时间、什么结果。一个行业的变化不能直接换算为某个人明天离职的概率。对个人而言，核实通知、了解职责变化、查看现有支出和可求助的人，也许比争论究竟是百分之几更能说明下一步。这里的“也许”是建议的开放性，不是效果数据。〔证9〕

准备到什么程度才够，也需要边界。预案不必覆盖所有坏结局，可以先处理最迫近、后果较大的一个。若写预案使自己不断添加越来越远的灾难，就暂停，把记录交给可信任的人一起看。该建议用于限定整理任务，不要求有担忧的人停止关心未来。〔证9〕

## 12.6 可以等的担忧，与不能等的事

有些事情暂时没有新信息，可以约定下一次查看的时点；另一些涉及就医、照护、截止日期或安全，不能一律推到所谓“担忧时间”。本书把推迟当作可选的日程安排，不当作担忧必定服从的心理规律。〔证10〕

例如，林澄可以决定下午收到新反馈后再修改方案，却不能因此错过当天的提交期限。陈宁可以把没有截止日期的职业设想留到周末，却仍需及时确认明天的照护安排。这些虚构例子所区分的是事情的时间要求，不是人的焦虑是否合理。〔证1〕

拉长时间看问题也只能提供一个角度。十年后可能不再重要的事，今天仍可能影响工资、尊严或一个孩子的需要。Sonus建议同时保留近处与远处：眼下谁会承担后果，未来的自己又可能希望现在保留什么？不靠贬低当下的不安来获得远见。〔证10〕

## 12.7 不把生活变成持续的思想审查

这一章不是要求每个念头出现后都填表。Sonus建议一次只选一个困扰：需要事实就查证，暂时无法证实就保留未知，争辩没有帮助就试着与念头拉开距离，确需保护就采取行动。也可以暂时什么工具都不用，只获得陪伴。〔证11〕

如果反复分析越来越占据生活，或自助后困扰仍严重、持续或影响功能，值得寻求专业评估。没有必要把整章练熟才求助，也不应从“没有反证成功”推断自己缺乏改变意愿。〔证12〕

林澄最终修改了方案，也提出了对模糊标准的异议。两件事都可能让人不舒服。这个故事想留下的，并非“想对了就能平静”，而是事实、解释、责任与行动终于能够分别讨论。〔证1〕
