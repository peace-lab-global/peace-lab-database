# 来源与可信度说明

本书的工作定义是：平静是在不确定、冲突和损失之中，仍能感受、判断，并选择怎样生活的能力。**来源：Sonus编写主张；可信度：不适用（工作定义，不是科学界共识或诊断标准）。**

## 怎样阅读标注

每章以〔证1〕、〔证2〕等编号标记实质性结论与理论，在章末“依据与可信度”表中逐项对应。一个编号只能覆盖同一论证范围，不能用一条广泛文献替整章背书。表中的来源链接指向本书来源台账，再由台账提供书目信息与可追溯的外部入口。

每个主要小节或独立论证段落都应有相关编号；同一段内若含性质不同的主张，分别编号。练习与假设故事也有来源说明，但不伪装成实证结论。纯粹的过渡语、问题、导航和人物对话不需要逐句标注；它们所在情境必须明确其性质。

## 五种可信度

| 标注 | 本书中的含义 | 不意味着什么 |
|---|---|---|
| 高 | 在限定范围内，明确指南、直接文本或可复算事实提供较强支持，且没有发现影响该表述的关键缺口 | 适用于所有人；所有相关干预都有效 |
| 中 | 存在相关研究或可靠理论依据，但设计、人群、异质性、外推或取证层级限制了结论 | 对个人结果有保证 |
| 低 | 证据间接、初步，或从原研究到本书场景存在明显距离 | 已证伪或毫无价值 |
| 未核实 | 本次没有取得足够材料确认具体主张；不作为操作建议的事实基础 | 可以先当作真的使用 |
| 不适用 | 工作定义、价值主张、编写建议、假设情境等不宜套用实证概率等级 | 免于解释理由或安全审查 |

这些等级是本书的编辑评估，不是正式GRADE评价，不表示经过系统检索与独立专家共识程序。遇到指南之间的差异或证据不足，优先收窄正文表述，而非通过降低标签继续传播高风险主张。

## 来源类型与结论性质

| 类型 | 标注方式 | 编写边界 |
|---|---|---|
| 指南或官方信息 | 机构、年份、编号；结论可信度及适用范围 | 保留适用人群与场景，不把一般建议当作个体处方 |
| 实证研究 | 作者、年份、研究类型；剂量与终点 | 区分相关与因果，不用长期方案证明即时见效 |
| 理论模型 | 理论提出者与文本；理论支持与适用边界 | 模型不是从单个症状直接推定生理状态的检测工具 |
| 传统原典 | 书名、篇章、版本或译者 | 文本出处的可靠性与现代诠释、疗效证据分开 |
| Sonus编写建议 | 明确署名；可信度不适用；指出参考来源和改编处 | 不声称已验证，不附虚构的成功率 |
| 假设情境 | 明确虚构；可信度不适用 | 不冒充病例、采访、亲历或疗效见证 |
| 条件计算 | 明确输入、公式与假设；算术可信度 | 计算正确不代表输入适用于每位读者 |

## 来源台账

- [科学、临床与公共健康来源](SOURCES_SCIENCE.md)：编号S01起。
- [心理实践、行为与关系来源](SOURCES_PRACTICE.md)：编号P01起。
- [传统思想与原典来源](SOURCES_TRADITIONS.md)：编号T01起。

每条台账至少包含：完整可识别的书目信息；来源类型；实际核验日期与层级；支持的具体命题；不能支持的推论；对本书使用范围的可信度评估。

“核验摘要”不等于“核验全文”。“官方介绍”不等于亲自复算研究数据。“政策要求开通”不等于实际拨通每个地区的热线。受访问限制的材料如实标注，不补造页码、DOI、样本量、效应值或原话。

## 全书共同边界

本书是教育与自我观察材料，不提供医学诊断或个体治疗处方。具体练习的时长由本书用于便于尝试的安排时，明确为Sonus建议；读者可缩短、改变或停止。无效、不适、无法完成，都不能用作人格评价。

若存在即时生命危险、严重或新出现的急性躯体症状，先联系当地急救或获得医疗评估，不等待完成练习。心理支持与紧急救援不同；具体分流与核验后的联系方式见[第二十二章](Ch22_When_To_Seek_Help.md)。这属于本书的安全编写原则；其临床与公共卫生依据逐项列在该章，不以本说明替代。

## 假设人物约定

全书可使用以下虚构人物以讨论选择的后果：林澄，承担交付任务但无完全排期权的项目成员；陈宁，同时承担照护与收入责任的工作者；周遥，经历重要关系或生活变化的人。人物没有研究样本身份，各章不凭故事推导疗效。没有明确引用真实来源的故事，均为Sonus构造的假设情境。
