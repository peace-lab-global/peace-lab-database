# 第十章 · 数字生活与注意边界

## 10.1 同一个屏幕，不同的需要

在本书的虚构情境里，陈宁晚上拿起手机，有时为了查看家人的消息，有时为了等工作答复，也有时只想看一段轻松的视频。如果把这三种使用都写成“又刷了半小时”，记录虽然整齐，却没有说明应该改变哪一部分。〔证1〕

本章不把屏幕视为共同敌人。线上联系可以是读者正在使用的工作、照护或交往方式；我们要讨论的是哪些连接值得保留，哪些安排可以修改。先辨认用途，再决定边界，是Sonus的编写建议，不是经验证的数字戒断方案。〔证2〕

本书不凭“停不下来”或屏幕时长作成瘾诊断和严重度分级。若使用行为持续影响睡眠、职责或关系，或者自己感到难以应对，可以与专业人员讨论；求助无需先完成本章。具体分流见[第二十二章](Ch22_When_To_Seek_Help.md)。〔证3〕

## 10.2 中断的代价，不是一条统一的生理公式

关于数字生活，有一种很容易流传的说法：每条通知都激活一次威胁系统，所有人都需要固定时长才能重新专注。这样的精确感超过了本书核验到的证据。〔证4〕

Mark等人在模拟办公实验中发现，中断条件下，参与者扣除中断时间后的任务用时较短，但部分自报压力、挫折与努力增加。这里值得注意的，是完成速度与体验可能不一致；并不能据此说打断使总体效率提高，也不能把有限任务结果变成所有职业的恢复时间定律。〔证4〕

Sonus建议观察一个更具体的问题：这一次提醒是否打断了我原来要做的事，返回时还需重新确认什么？它有时是无关推送，有时却是必须响应的协作。一个值班人员接到报警，与一个人无意点开推荐内容，不适合套用同一套“全部关闭”的答案。〔证2〕

产品界面也可以成为检查对象：是否有自动播放，是否容易退出，通知能否分别设置。这里列的是供读者核对的设计选项，不推断所有产品用了同一种奖赏机制，更不从红点的颜色诊断一次应激。〔证2〕

## 10.3 先保留必要联系，再减少一项干扰

陈宁第一次调整手机时，直接开启了长时间免打扰，结果漏看一次需要回复的照护安排。陈宁没有得出“我不适合自律”的结论，而是恢复必要联系人，只关闭一个与照护、工作都无关的推送。晚间仍然会看手机，却少了一类本来不想处理的消息。这段虚构故事只呈现一次修正，没有证明哪一种设置普遍最佳。〔证1〕

如果愿意，可以把当前提醒分成三栏。先确认用途和职责，再动设置；所有调整都是可撤回的试用。〔证2〕

| 提醒 | 先问什么 | 可选安排 |
|---|---|---|
| 安全、值班、医疗或照护联系 | 漏接会怎样，是否已有正式流程？ | 保留必要渠道，遵守职责与既有方案，不把它们当作一般推送关闭 |
| 需要处理但不总是即时的工作消息 | 对方预期何时回复，谁能同意改变？ | 先协商回应窗口与紧急替代渠道，再考虑批次查看 |
| 新闻、兴趣与产品推荐 | 我是否主动想收到，它是否还符合需要？ | 先减少一项；也可以保留，不要求一次清空 |

“只留真人”也不是足够完整的规则。自动报警可能很重要，真人发送的消息则未必紧急。判断需要回到用途，不能只看发送者是谁。这里是职责上的推理，不是对所有通知效果的研究结论。〔证2〕

如果组织明确要求随时响应，而工作量也没有调整，手机设置无法独自修复这个矛盾。WHO的工作场所资料支持讨论负荷、控制与组织支持；具体协商方向见[第七章](Ch07_Workplace_Playbook.md)。〔证5〕

## 10.4 新闻与比较：给一次查看说明目的

虚构故事中的周遥正在等待一项影响收入的政策消息。连续几次刷新只有评论，没有新增事实。可以试着先确定：下一次准备核对什么，哪个渠道有资格确认，什么时候确实需要知道。得到信息之后是否继续浏览，再单独作决定。〔证1〕〔证6〕

有时目的就是娱乐或与人分享，不必把它伪装成学习。Sonus建议保留这种诚实：想看一段视频，可以承认想看；看完之后不愿继续，也可以停下。无需为每一次使用辩护，也无需用“我被算法控制了”代替对具体选择的了解。〔证6〕

遇到公共安全事件或有时限的权益信息，及时查看可能十分必要。本章不规定每日只能看几次新闻，不把关注公共事务一概称作焦虑供养。若自己希望减少反复刷新，可以试着选一个合适的复查时点；事情发生变化时再调整。〔证6〕

## 10.5 休息不能只分成“松”与“空”

散步或读纸书不必被预先列作真休息，视频和游戏也不应一概列作假休息。本书不采用这种适用于所有人的二分，也不用“副交感接管”替某类娱乐背书。〔证7〕

可以问得更小一些：我当时想得到什么？这次使用有没有回应它？结束后是否愿意继续？有没有挤占一件自己更想保留的事？这些是Sonus的观察问题，不是用感受来判定神经状态。累的时候没有明显恢复，也不意味着休息不配发生。〔证7〕

假设陈宁与远方朋友在线玩了一会儿游戏，感觉获得陪伴；另一天读了纸书，却一直担心漏接电话。故事不能证明游戏优于读书，只提醒我们，工具形式之外还有关系与条件。将必要电话留出可达渠道，也许比换一本“更适合休息”的书更贴近那一天的问题。〔证1〕

## 10.6 为一段专注协商，而非宣布消失

需要集中处理任务时，可以试着说明工作内容、可用时段以及紧急联系办法。起点不必是两个九十分钟工作块，时段长短由任务与职责决定。需要频繁协作的岗位也可以只减少一种无关中断，或明确交接次序。〔证8〕

如果同事不同意，值得进一步问：对方需要的是立即收到答复，还是知道什么时候有答复？如果确实需要即时协作，也许应该调整的是任务安排，而非要求双方分别学会更好专注。并非每次争议都能解决，本书不把专注能力变成回避协作责任的理由。〔证8〕〔证5〕

## 10.7 一次小试用，也允许撤回

选择一项愿意调整的设置，先写清原来的用途以及不能漏掉的联系。改动之后，在自己认为合适的时候回看：少了什么，多了什么，是否遗漏了必要信息。没有必要按日统计分数，更不必把成功定义成屏幕时间持续下降。〔证9〕

| 我试改的一项安排 | 我必须保留的联系 | 我观察到的变化 | 保留、调整或恢复 |
|---|---|---|---|
| | | | |

这张表可以不用。若试用增加担心、妨碍职责，或没有带来想要的改变，可以恢复原设置再想别的办法。数字边界最终应服务于具体生活：有值得专注的事，也有值得保持连接的人；两者之间没有一本书能替你规定的永久比例。〔证9〕
