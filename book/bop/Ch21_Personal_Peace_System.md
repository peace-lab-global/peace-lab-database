# 第二十一章 · 个人平静实践

## 21.1 方法也应接受选择

以下情境是虚构的。林澄把几种练习写进日历：早起呼吸、午间散步、晚上记录。第一周完成了大半，第二周赶项目，第三周看到提醒就烦躁。原先用来帮助自己的安排，渐渐变成了另一组催促。

林澄删掉了其中两项，只留下下班前写清下一步工作的一张纸。这个决定不能证明两项练习无效，也不能证明留下的那项适合所有人。它只是这个故事里的一次取舍：有限的时间里，先保留目前愿意使用的方法。〔证1〕

本章不提供覆盖一天所有时段的标准日程。我们尝试让练习服务于生活，而不是让生活围着练习安排。这是Sonus的编写原则，不是经试验证明的最佳生活制度。〔证2〕

## 21.2 先保留一个入口

可以从过去尝试过的方法里选一个。选择理由尽量具体：“它让我知道明天先做什么”，比“它应该改变大脑”更接近你能观察的经验。也可以暂时不选，把获取休息或帮助作为当前安排。〔证2〕

对选中的方法，写清四件事：

1. 它准备回应什么需要？
2. 在什么情境下比较容易尝试？
3. 哪种不适、负担或现实变化会让我停止？
4. 如果不继续，是否还有替代方法或支持？

这四问由Sonus设计，不是处方，也没有规定最低有效剂量。方法原有的安全限制仍然适用；简化一个练习，不能据此声称它保留了完整临床方案的效果。〔证2〕

## 21.3 一个可改动的安排

下面展示同一需要的不同回应，不是要求全部执行的清单。它们属于本书的情境化建议，不附效果保证。〔证3〕

| 需要 | 可以尝试的安排 | 条件不足时 |
|---|---|---|
| 工作结束后仍惦记未完事项 | 在可行的交接时点写下下一步与需要谁回复 | 若必须值班，先明确值班范围，不假定下班后完全离线 |
| 想有一点安静时间 | 在不妨碍职责的时段短暂停留，或减少一项非必要输入 | 无独立空间时，可以不闭眼、不做内观，选择普通休息 |
| 希望有人参与 | 与可信任的人约定一次具体、可拒绝的联系 | 对方无余力时，再找其他资源，不把回复速度当关系证明 |
| 某种练习容易使自己更紧张 | 可以暂停；若只是轻微不适且仍愿尝试，再考虑缩短或改用外部注意对象 | 持续恶化或影响安全与功能时，获取专业评估，不继续加量〔证5〕 |

只需记录你选中的一项。日程本来就很满时，先讨论能否减少负担，比再增加一项“很小的练习”更值得考虑。这个优先顺序表达本书对负担与责任的取舍，不是对每个人的统一判断。〔证2〕

## 21.4 三种情况，三条不同的路

**中断了，但原先有帮助。** 可以在条件允许时重新开始，也可以先调整提醒方式。不必补做漏掉的天数，不必从第一章重读。这是本书的使用约定。〔证4〕

**一直在做，却没有帮助。** 先描述原本期待的帮助是什么，再看方法与需要是否匹配。没有明显不适也不意味着必须无限期坚持。可以更换方法、停止记录，或与专业人员讨论。我们不预先把无效归因于读者没有耐心。〔证4〕

**练习中或生活中明显变得更糟。** 这不应只被称为“掉线”或正常维护。停止可能加重不适的练习，查看[第二十二章](Ch22_When_To_Seek_Help.md)的求助入口；若出现即时危险或严重急性症状，优先紧急救援。冥想与情绪书写的具体调整边界见[第十一章](Ch11_Meditation_Practice.md)、[第十四章](Ch14_Emotional_Alchemy.md)。〔证5〕

这三条路不能合并成一句“回到最小剂量”。有时需要回来，有时需要换路，有时需要让别人接手。〔证4〕

## 21.5 回看生活，而非给自己评分

什么时候回看由你决定，可以是生活出现变化时，也可以是使用一段时间之后。不设置统一周期。看看方法是否仍服务于原来的需要，是否增加了不必要的负担，是否有某个一直被忽略的现实条件需要讨论。〔证4〕

在虚构的林澄故事里，下班记录留下来了，但临时改需求的情况没有减少。林澄后来发现，记录只能帮助交接，不能代替负责人明确优先级。于是，练习之外又出现一项工作：把多次改动列出来，讨论哪些任务需要延期。对方未必答应，问题也没有就此结束；至少，原来被称为“我总放不下”的一部分负担，有了可以共同讨论的形状。〔证1〕

个人实践不需要独自承担所有问题。它也可以帮助人辨认，哪些部分已经超出了一个人能够合理负责的范围。〔证2〕

## 21.6 我的实践与支持页

以下表格是Sonus设计的可选记录，没有评估分数，也不用于判断症状是否达到诊断标准。〔证3〕

| 项目 | 我的安排 |
|---|---|
| 我目前最希望回应的一个需要 | |
| 一个愿意保留的做法；也可以留空 | |
| 适合使用它的情境 | |
| 需要别人参与或改变的条件 | |
| 可以缩短、替换或停止的条件 | |
| 中断后，我愿意怎样重新选择 | |
| 没有帮助时，我可以找谁讨论 | |
| 明显恶化或危险时，去哪里获得帮助 | |

如果填表本身已经增加负担，可以只保留最后两行，或完全不用表格。求助不需要一份整理得很好的说明，更不需要交出完整练习记录才能开始。这里表达的是本书的支持立场，不承诺任何具体服务的接诊条件。〔证2〕
