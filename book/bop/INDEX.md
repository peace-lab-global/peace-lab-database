# 平静之书

> 在不确定、冲突和损失之中，仍能感受、判断，并选择怎样生活。

这是本书对平静的工作定义，也是贯穿全书的编写立场。它不是科学界统一的定义，不是要求读者随时保持清醒的标准，更不是一项新的绩效任务。〔证1〕

## 写给无法轻易退出压力的人

有些人正在等一个项目结束，有些人正在照顾家人，有些人刚失去一段关系。休息的建议未必错误，却可能不够：事情仍然需要处理，收入不能突然中断，已经发生的失去也无法撤回。本书从这些处境出发，把“怎样调整自己”与“怎样辨认并改变处境”放在一起讨论。这里描述的是本书选择的读者情境，不是对全部职场人的调查结论。〔证2〕

你不需要先成为一种更好的人，才有资格得到休息或帮助。练习无效时，可以换一种方法；情况恶化时，可以停止自助；需要离开时，也不必先证明自己已经足够平静。尊严与选择不以练习成绩为交换条件。〔证1〕

本书可以独立阅读。知识库链接是选读资料，不是理解正文所需补齐的课程。没有音频、量表或付费产品，也应能够看懂这里的思路与练习。〔证3〕

## 现在从哪里开始

| 你此刻需要什么 | 入口 | 本书不会要求什么 |
|---|---|---|
| 想先稳住当下 | [第六章：先给自己一点余地](Ch06_First_Aid_Toolkit.md) | 不要求在90秒内平静，不把身体症状一概当作焦虑 |
| 不知道问题在哪里 | [第五章：自我观察与阅读导航](Ch05_Peace_Audit.md) | 不打诊断分，不把人分成固定类型 |
| 工作或关系让你持续受伤 | [第十八章：意义、工作与退出](Ch18_Meaning_And_Work.md)、[第十九章：关系中的平静](Ch19_Relationships_Peace.md) | 不要求用修炼适应伤害 |
| 想辨认是否需要帮助 | [第二十二章：何时求助](Ch22_When_To_Seek_Help.md) | 不要求先坚持两周或完成本书 |
| 想慢慢尝试 | [第二十三章：四周试行](Ch23_Four_Week_Reset.md) | 不要求连续打卡，不承诺28天完成重建 |

这张表是Sonus编写的阅读导航，不是临床分诊工具。出现即时生命危险或严重急性躯体症状时，应优先联系当地急救或获得医疗评估，不等到阅读结束；具体依据与联系方式见第二十二章。〔证3〕
