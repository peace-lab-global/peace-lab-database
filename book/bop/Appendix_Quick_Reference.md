## ⚡ 急救卡（今天就能用）

**第一步永远是：呼气长于吸气。先安顿身体，再处理事情。**

| 状况 | 动作 | 章节 |
|:--|:--|:--|
| 情绪刚上头 | 生理叹息 ×3（双吸一长呼） | [Ch06](Ch06_First_Aid_Toolkit.md)① |
| 越想越怕、脑子空转 | 5-4-3-2-1 着地（看到5/听到4/触到3/闻到2/尝到1） | Ch06④ |
| 愤怒、坐不住 | 一分钟节律运动（快走/甩手/爬楼梯） | Ch06⑥ |
| 心跳快、发热 | 冷水洗脸 30 秒 / 握冰饮 | Ch06⑤ |
| 麻木、发空 | 温水洗手 + 轻运动，先温和激活 | Ch06⑤⑥ |
| 被批评后 | 手放胸口 60 秒 + "此刻很难，这很正常，我在" | Ch06⑧ |
| 深夜反刍睡不着 | 4-7-8 呼吸（吸4屏7呼8，可改4-4-6） | Ch06② |
| 想立刻回怼/辞职 | 90 秒冲浪：不行动、不对抗、不评判 | Ch06⑩ |

通用话术："我先记下了，想一下再给你完整回复。"（拖时间=救命时间）

- 《深度工作》：[第十章](Ch10_Digital_Hygiene.md)的完整版

传统/哲学
- 《沉思录》（马可·奥勒留）与《生活的哲学》（威廉·欧文）：斯多葛入门

- 《禅者的初心》：禅"平常心"的教科书
- 《当下的力量》之外的备选，《观呼吸》（德宝法师）：呼吸锚定的经典教材
