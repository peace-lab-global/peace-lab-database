# 第十七章 · 丧失与哀伤

> 原稿这一章从「丧失的种类」讲起，随后是哀悼的五个阶段、三条哀悼的实操（允许悲伤、保持连接、创造意义）、以及重建身份的三步。它的开篇第一句是：最痛的孤独，是失去后的孤独。
>
> 这一版改了三处顺序，也撤掉了一个框架。**哀伤不是孤独的一种，它有自己的一条路**；把两者混在一起谈，结果是丧亲的人被交给一本讲连接的书，而书里能用的东西一件都不适合他眼下的处境。所以本章先处理安全，再谈可以做的事，最后单独用17.7把哀伤与孤独分开。〔证1〕〔证9〕
>
> 原稿的比较级也撤了：本章无从判定哪一种孤独最痛。

---

## 17.1 先看安全：丧亲之后的头几天

下表中的情形，本章其余各节的动作一律不适用，先按右列处理。〔证2〕

| 情形 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或已有计划、意图、无法确保眼下安全 | 拨 **120**（急救、急诊），并请一个可信任的人陪同；心理援助拨 **12356**，它提供心理支持与危机干预，**不替代120**，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 涉及暴力或人身危险（包括失去的人曾是你的施暴者，而其家人此刻正在场） | 拨 **110** |
| 失去的人是自杀死亡 | 见17.6最后一条。这一类丧亲需要被单独对待，不是因为你更脆弱 |
| 持续两周以上情绪低落，对几乎所有事都提不起兴趣，伴睡眠或食欲改变 | 预约精神科或临床心理科评估。这条界线不该由你自己划，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2、22.3 |
| 已经过了很久，日常功能仍然没有回来 | 见17.6。本章不给月数，理由写在那里 |
| 需要酒精或药物才能过完一天 | 这是需要告诉医生的情况，不是一个可以用比喻处理的毛病，见[《平静之书》第九章](../bop/Ch09_Body_Foundation.md)9.6 |

三条限定，与本书导航页的约定一致。〔证1〕

1. 本章每一项都是可选的。不累计次数，不设时间表，不要求你在某个期限内「走出来」。
2. 本章不承诺任何做法能减轻哀伤。它给的是几件有人做过、且代价可控的事，不是疗效。
3. 本章不为丧失设定应有的收获。它不要求你在失去之后成长、找到意义，或变成一个更清楚什么重要的人，见17.3与〔证5〕。

**原稿说了什么，这一版怎么处置。**〔证6〕

| 原稿说法 | 处置 |
|---|---|
| 「最痛的孤独，是失去后的孤独」 | 撤除比较级。本章无从判定哪一种孤独最痛 |
| 「哀悼的五个阶段（Kübler-Ross，1969）」整节 | 撤除，理由见17.3与〔证3〕 |
| 「每一种丧失都需要哀悼」 | 撤除其通则地位。它使麻木、松一口气、以及长期消耗之后的安静都成为不合格，见17.5 |
| 「不哀悼的丧失，会变成慢性的孤独」 | 撤除因果断言。无来源，且把后果写成对读者的警告 |
| 「哭泣是健康的」「不要假装坚强」 | 撤除效果断言，保留许可。[《平静之书》第十四章](../bop/Ch14_Emotional_Alchemy.md)14.5已明写「哭与不哭，都不需要交出证明」，且是否哭泣不作为判断情绪处理是否完成的标准。本章沿用，见17.4第一项 |
| 「与逝去的人保持内在连接……哀悼不是忘记，是换一种方式记住」 | 做法保留为可选项，撤除其定义地位。临床文献中确有以持续联结为名的取向，本轮未核验，本章不借它作依据，见17.4第三项与〔证6〕 |
| 「创造意义：把丧失变成纪念」「丧失的意义，是你赋予的（Frankl，1959）」 | 降级为立场性表述，见〔证4〕。本章不要求任何人在丧失中寻找意义 |
| 「重建身份三步：承认变化、保留连续性、创造新意义」 | 撤除其步骤地位。第三步尤其：它把「更清楚什么重要」写成必经收获，见17.4与〔证5〕 |
| 「丧失后的成长是创伤后成长（PTG）（Tedeschi与Calhoun，2004）」 | 撤除来源归属与成长期待，见〔证5〕。所链接的[《力量之书》第十七章](../bos/Ch17_Resilience_And_Bounce_Back.md)17.2以创伤后成长为框架，该章尚未按本记录标准修订，本章不采用其框架 |

## 17.2 丧失不只一种

原稿的四类保留，因为它们确实描述得不同：关系的丧失（分手、离婚、友谊破裂）、身份的丧失（失业、退休、搬家）、梦想的丧失（未能成为的人、未能拥有的生活）、健康的丧失（疾病、衰老、身体功能的改变）。

这一版加一类，也改一句话。

**加的一类：还没有结束的丧失。** 一个人在重症中、一段关系正在解体、一个岗位即将不保、一个诊断刚下来。这一类困难在于它没有明确的时点，周围的人也常常不知道该说什么，因为「还没发生」。它同时消耗你照顾别人的力气和你哀悼的资格——许多人被告知「现在还不是难受的时候，先撑住」。撑住是需要的，难受也是同时存在的，两者不冲突。

**改的一句：** 原稿说「每一种丧失都需要哀悼」。这一版不说需要。**丧失之后会有什么反应，不由你决定，也不由这本书决定。** 有人哭，有人麻木，有人松一口气，有人先处理手续，有人在三个月后的一个下午突然撑不住。这些都不是「哀悼」与「不哀悼」的区别，它们是不同的人。把它们排成合格与不合格，是本章要避开的第一个错误，见17.5。

## 17.3 五个阶段：本章为什么不用它

原稿这一节列了否认、愤怒、讨价还价、抑郁、接受五项，注明顺序可变、可反复，并归给Kübler-Ross（1969）。

**先说来源状况。** 该书未列入[系列科学来源台账](../SOURCES_SCIENCE.md)或[系列实践来源台账](../SOURCES_PRACTICE.md)，本轮未取得原文核对。所以本章不评论它写了什么，只说这本书在这里被用来做了什么。〔证3〕

**它在这里被用来做了一件有害的事：给哀伤提供一份进度表。** 一旦有了五个阶段，读者就会拿自己对照——我在第几阶段，我是不是卡住了，我为什么还在愤怒。这份对照不产生任何有用的信息，它只产生一个新的失败感，叠加在原有的丧失之上。这与本书其他章节反复拆掉及格线的处置一致：[第二十三章](Ch23_Loneliness_28_Day_Program.md)撤除了每日保底与三条及格线，[第五章](Ch05_Loneliness_Audit.md)5.1明写不计分、不设阈值、不作类型分类。

**第四阶段的名称与本书另一处直接冲突。** 那一项在原稿里叫「抑郁：一切都没意义了」，并作为正常哀悼的一环被列出。而[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2的标题是：孤独不是抑郁，但这条界线不该由你自己划。同一个读者，在第十七章读到「抑郁是哀悼的第四阶段」，在第二十二章读到「这条界线不该由你自己划」——前一句恰好邀请他自行划那条线，并且划在「正常」的一侧。这一处冲突是书内可核对的，也是本章撤除该框架最直接的理由。〔证3〕

**另一件事：阶段这个词假定了终点。** 有阶段就有走完的时候。哀伤不是这样运作的——多数人的经验是它变轻、变稀、变成可以在某些日子突然回来的东西，而不是被完成、被关闭。本章不提供一个替代的框架。临床文献中确有以双过程、持续联结、意义重建为名的取向，仓库的《哀伤丧恸》专题有相应条目；本轮均未核验，本章不借用其中任何一个来组织建议，见章末深潜一节。〔证3〕

**这一版留下的说法，是一条编写观察，不是模型：** 哀伤更像一件你随身带着的东西，有时轻有时重。某些日子会突然变重——周年、节假日、他的生日、一首歌、一种气味、超市里他常买的那样东西。变重不代表你退步了，也不代表你练得不够。

## 17.4 可以做的事

下面几项都不是处方，也不构成一套应当按顺序完成的流程。挑一项，或者一项都不挑。每项写明现实前提，前提不成立时该项不适用，**不适用不是你的错**。〔证1〕

**一、不需要交出证明。**

原稿写「哭泣是健康的」，又写「不要假装坚强」。第一句是效果断言，本章不采用；第二句保留，但换个说法：**你不需要表演悲伤，也不需要表演不悲伤。**[《平静之书》第十四章](../bop/Ch14_Emotional_Alchemy.md)14.5已经写明，哭与不哭都不需要交出证明，是否哭泣不作为判断情绪处理是否完成的标准。有人劝你「痛快哭一场」而你没有哭，那不代表你冷漠，也不代表你压抑了什么。

现实前提：无。这一条不需要前提，它是一条许可。

**二、把事情说出来，或者写下来。**

对一个人说，或者写下来不给任何人看。做法对应[第六章](Ch06_Loneliness_First_Aid.md)6.12，本章不重复其内容。

现实前提：有一个不会打断你、也不会立刻给你建议的人。这样的人常常没有。没有时，写下来是同一条路的另一半，它不要求听众。

停止条件：如果写或说带上来的是恐慌、麻木，或一种比之前更强烈的空，停下来，不要继续，也不要在夜里独自继续。那不是练得不够。

**三、纪念的方式由你定。**

原稿建议写信、对话、纪念仪式。这些做法保留为可选项，本章不宣称它们是哀悼的正确形式，也不宣称哀悼的目标是「换一种方式记住」。

有人保留照片，有人收起来；有人过周年，有人不过；有人去墓地，有人从不去。**这些选择之间没有高下。** 家属之间对此常有分歧，你不被要求与任何人一致。

现实前提：你能够支配相关的物件与场合。遗物由他人整理、墓地远在他乡、你没有可以独处的时间——这些都会使这一项做不到。

**四、照顾好身体的那几件事。**

吃饭、睡觉、喝水、出门走一段。不是因为它们能减轻哀伤——本章没有这方面的数据——而是因为它们在头几周常常是最先垮掉的，而垮掉之后别的事更难做。成人规律睡眠的建议见[第八章](Ch08_Night_And_Weekend.md)8.8所引的共识；如果已经出现持续失眠，那不是这一项能处理的，需要评估，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3。

现实前提：你此刻有能力做这些。做不到时，这一项顺延，不计为失败。

**五、把手续、钱和假期分开处理。**

这一项与情绪无关，但常常是头几周真正压垮人的东西：死亡证明、销户、遗产、房租、贷款、保险、以及请假。

如果你的假期只有几天，或者你根本不在可以请假的亲属范围内，那么你要面对的不只是丧失，还有一个不承认你的制度。见17.5。本章不替你处理这些事务，也不把它们写成「坚强一点就好」；能拆开来一件一件办，就已经是在做事。

现实前提：相关文件与身份。缺少其中任何一样时，这一项会被卡住，卡住不是拖延。

**六、接受别人的帮助，包括拒绝它。**

头几周常有人送饭、接送、代接电话。接受不是软弱，拒绝也不是。如果你拒绝了几次之后他们不再问了，那通常不是他们冷淡——多数人不知道还能做什么，见17.7。

## 17.5 没有按预期感受

这一节是本章新增的，原稿没有。它处理三种常见而少被允许的反应。〔证7〕

**一、麻木。**

有人在得知消息之后异常平静，办完了所有手续，直到几周后的某一刻才塌下来。也有人在很长一段时间里都没有那种「强烈的悲伤」，并因此怀疑自己是不是不在乎。

麻木不等于没有哀伤，也不等于压抑了什么需要挖出来的东西。本章不给它一个机制解释——本轮没有取得可核对的来源。可以说的只有一句：**反应的强度与时点，都不是你能选择的，也不构成对你的评价。**

**二、松一口气。**

如果失去的人长期病重、长期痛苦，或者长期照顾他使你耗尽，那么在他死后感到松一口气，是常见的。如果失去的人曾经伤害你、控制你、贬低你，那么松一口气之外可能还有恐惧、内疚，或者一种说不清的空。

**这两种感受都不取消你对他的感情，也不证明你冷血。** 它们可以同时存在：你可以既希望他不再受苦，也希望他还在；你可以既为一段关系结束而松一口气，也为它曾经那样而哀伤。

这一条与[第十八章](Ch18_Loneliness_In_Relationships.md)18.1、[婚后孤独附录](Appendix_Loneliness_In_Marriage.md)A.1的立场相接：承受不是义务，一段关系结束（无论以哪种方式）不是失败。

**三、不被承认的哀伤。**

有些丧失在周围人眼里不成立。常见的几种：

| 你失去的 | 你听到的话 |
|---|---|
| 一段没有公开的关系、一个同性伴侣 | 「你们只是朋友吧」；对方家属的场合里没有你的位置 |
| 一个前任 | 「你们早就分开了」 |
| 一只动物 | 「它只是一只猫／狗」 |
| 一次流产、一个未能出生的孩子 | 「你还年轻」「下次会有」 |
| 一个你照顾过但没有亲属关系的人 | 「你又不是他家里人」 |
| 一段友谊 | 「再交一个就是了」 |
| 一个岗位、一座城市、一种身体状况 | 「这有什么好难受的」 |

**这一类哀伤之所以格外孤独，不是因为它更轻，而是因为它没有场合。** 多数被承认的丧失有一段社会承认的时期：葬礼、探望、假期、别人主动提起。不被承认的丧失连这些都没有——你要照常上班，照常应付，没有人知道你正在经历什么，而且你很可能会替他们保密，因为说出来只会得到上面那些回答。

**本书的立场：不为你排定谁有资格哀伤。你失去的就是你失去的。** 这一条是编写立场，不是研究结论；本章不声称这类反应的普遍程度，也不宣称任何一种丧失比另一种更重。〔证7〕

**一件实际的事：** 如果找不到承认它的人，写下来是可行的另一半——它不需要听众，也不需要对方的家属同意，见17.4第二项。

## 17.6 什么时候需要评估

**先说一条硬界线。** 出现伤害自己的念头，或有计划、意图、无法确保眼下安全：不要等，拨 **120** 并请人陪同，心理援助拨 **12356**（它不替代120）。丧亲之后的这一类念头需要被立即对待，不是「哀伤的一部分，会过去」。见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1、22.4。〔证2〕

**其余情形，本章只给方向，不给数字。**

需要专业评估的信号包括：日常功能长时间没有回来（无法进食、无法入睡、无法上班上学）；完全回避一切与逝者有关的东西，或相反，生活停在原地不再往前；需要酒精或药物才能过完一天；持续的空虚与无意义感已经不只是对那个人的思念。这些信号与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3列出的重叠，本章不重复。

**关于「多久算久」，本章故意不给月数。** 现行的两套分类系统中确有一类与哀伤相关的障碍，且两者所用的时间不同。本轮未取得这两套系统的原文核对，仓库《哀伤丧恸》专题载有相应条目但未经核验；本章不采用其中任何一个时间阈值，也不给读者一个可以拿来给自己计时的数字。〔证8〕

理由有两条。第一，一个未经核对的数字写进正文，就变成了读者自查的标准，而这条界线不该由你自己划，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2。第二，时间不是唯一的东西：一个在半年后仍然无法上班的人，与一个在两年后仍然会在某些日子难过、但生活已经回来的人，需要的是完全不同的回应，而月数区分不了他们。

**该做的是：** 把功能的变化告诉医生，让他来判断，而不是自己数日子。

**关于自杀遗族。** 如果失去的人是自杀死亡，遗族自身的风险需要被认真对待。这不是对你的判断，也不意味着你一定会怎样——它是这一类丧亲的已知特点。本章未取得可核对的数据，故标未核实；但立场是明确的：**请不要独自承担。** 这一类丧亲常伴随特有的困难：内疚、反复回想最后那段时间、以及一种不便对人说出口的处境，见17.5第三项。求助的分流见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.4、22.5，那里也写了不愿求助有时是在衡量真实代价。〔证10〕

## 17.7 哀伤与孤独的分界

这一节是本章与这本书其余部分的接口。〔证9〕

**哀伤指向一个具体的失去**：一个人、一段关系、一个身份、一种身体状况。**孤独指向连接的缺席。** 两者会重叠，但去处不同——把它们混在一起，是这本书原本最容易犯的错误：把丧亲的人交给一份连接清单。

**一个实际的时间线。** 丧失之后的头几周，人会来。之后他们会走。这不是因为他们冷淡——多数人是不知道还能做什么，或者担心提起会让你难受，于是选择了不提。剩下的那一段空，性质上更接近孤独，而不是哀伤，它由本书其他章节处理。

**这一条是编写观察，本章没有关于支持持续多久的数据。**

| 此刻你在经历的 | 更像 | 去哪里 |
|---|---|---|
| 想他，想具体的事，想他说话的样子 | 哀伤 | 17.4 |
| 想起他时是内疚、反复回想最后那段时间 | 哀伤，且可能需要评估 | 17.6 |
| 没有人可以说话，而这个状态已经扩到其他领域 | 孤独 | [第五章](Ch05_Loneliness_Audit.md)5.2、[第六章](Ch06_Loneliness_First_Aid.md)6.3 |
| 到了周年、节假日、生日突然变重 | 两者都有 | 17.3末段、[第八章](Ch08_Night_And_Weekend.md)8.7 |
| 觉得没人懂，连提起都不被允许 | 不被承认的哀伤 | 17.5 |
| 人来过了，又走了，剩下的空 | 孤独 | [第十章](Ch10_The_Art_Of_Connection.md)、[第二十章](Ch20_Community_And_Tribe.md) |
| 已经很久，功能没有回来 | 需要评估 | 17.6、[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3 |
| 失去的是一段伤害你的关系 | 两者都有，且承受不是义务 | [第十八章](Ch18_Loneliness_In_Relationships.md)18.1、[婚后孤独附录](Appendix_Loneliness_In_Marriage.md)A.1 |

**一句实话。** 哀伤不需要被解决，也不需要被完成。它多数时候是被带着继续过日子的。这本书能帮的是后半句——继续过日子的那部分，包括没有人可以说话的那部分。前半句它帮不上，也不假装能帮。

## 本章速记

- 先过分诊。有伤害自己的念头：拨120并请人陪同，12356提供心理支持但不替代120；涉及暴力拨110；失去的人是自杀死亡，见17.6最后一条。
- 丧失不只五种，还包括还没有结束的那种。丧失之后会有什么反应，不由你决定，也不由这本书决定。
- 五个阶段整节撤除：它给哀伤提供了一份进度表，而它的第四阶段名叫抑郁，恰好邀请读者自行划那条本书明写不该由自己划的线。本章不提供替代框架。
- 哀伤更像一件随身带着的东西，有时轻有时重。某些日子会突然变重，变重不代表退步。
- 六件可做的事都带现实前提：不需要交出证明、说出来或写下来、纪念方式由你定、照顾身体那几件事、把手续与钱和假期分开、接受或拒绝帮助。停止条件在第二项。
- 麻木不是压抑，松一口气不取消感情，两者可以同时存在。不被承认的哀伤格外孤独，不是因为它更轻，而是因为它没有场合。
- 需要评估时本章不给月数：两套分类系统的时间不同且本轮未核对，一个未经核对的数字会变成读者自查的标准。把功能的变化告诉医生，不要自己数日子。
- 哀伤指向一个具体的失去，孤独指向连接的缺席。头几周人会来，之后他们会走；剩下的那一段空由本书其他章节处理。
- 哀伤不需要被解决，也不需要被完成。本书不要求你在失去之后成长或找到意义。

下一章：[第十八章 · 亲密关系中的孤独](Ch18_Loneliness_In_Relationships.md)。有人在身边，心却隔着墙；承受不是义务。
