# 第十二章 · 数字时代的孤独

> 原稿这一章从[第二章](Ch02_Why_Loneliness_Hurts.md)的一句话接着讲：社交媒体给了你「连接」的幻觉。随后是三个机制、一张错误用法与正确用法的对照表、以及每周一次的无屏幕日。它引用了两次Cacioppo与Patrick（2008）。
>
> 这一版撤掉了「幻觉」这个词，也撤掉了那张对照表和那一天。理由里最要紧的一条可以在书内核对：[第六章](Ch06_Loneliness_First_Aid.md)6.5把线上语音社群与兴趣小组的语音房间列为门槛更低的替代路径，并明写「本书不把次优写成无效」；而这一章原稿把同一类东西称为幻觉与替代品。同一条线上联系，在第六章是可用的一条，在第十二章是不算数的一条。〔证5〕〔证6〕
>
> 还有一条：**有些读者的连接只在线上。** 对一个没有本地网络、独居、身体不便、上夜班、或家人都在外地的人，宣布线上联系不是真联系，等于告诉他手上唯一那样东西不算数。〔证1〕

## 12.1 先说清楚：这一章不做什么

下表中的情形，本章其余各节一律不适用，先按右列处理。〔证2〕

| 情形 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或已有计划、意图、无法确保眼下安全 | 拨 **120**（急救、急诊），并请一个可信任的人陪同；心理援助拨 **12356**，它提供心理支持与危机干预，**不替代120**，见[第六章](Ch06_Loneliness_First_Aid.md)6.1与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 涉及暴力或人身危险，包括线上威胁、跟踪与勒索 | 拨 **110**；保留截图与记录，见12.7 |
| 使用已经影响睡眠、吃饭、上班上学或照护职责 | 这是需要评估的情形。本书不以屏幕时长或使用「停不下来」作成瘾诊断与严重度分级，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3与[《平静之书》第十章](../bop/Ch10_Digital_Hygiene.md)10.1 |
| 你在网上被针对、被排挤或被持续贬低 | 那是处境，不是你的用法问题。见12.7与[第十九章](Ch19_Workplace_Loneliness.md)19.5 |
| 眼下确实一个人也联系不上 | 先看[第六章](Ch06_Loneliness_First_Aid.md)6.3，其中6.5的线上路径此刻是正当的，不是次等的 |

三条限定，与本书导航页的约定一致。〔证1〕

1. 本章每一项都是可选的，而且都是**可撤回的试用**，不是戒断方案。改回去不需要理由。
2. 本章不给使用时长的上限，不设无屏幕日，不把屏幕时间下降当作成功标准。
3. 本章不判断你的用法是对还是错。它给的是几个观察问题，不是一份合格线。

**原稿说了什么，这一版怎么处置。**〔证7〕

| 原稿说法 | 处置 |
|---|---|
| 「社交媒体给了你『连接』的幻觉」 | 「幻觉」撤除。它与[第六章](Ch06_Loneliness_First_Aid.md)6.5「本书不把次优写成无效」直接冲突；对只有线上联系的读者，这句话的实际效果是取消他手上唯一那样东西，见12.2 |
| 「三个机制：广度替代深度、表演替代真实、被动消费替代主动创造」 | 三条机制断言撤除。本书没有取得任何可支持它们的核验材料，见〔证3〕。三条都以「替代」为结构，而替代关系需要证据，不是修辞 |
| 「100 个点赞 ≠ 1 次深度对话……却不给『被看见』的满足（Cacioppo与Patrick，2008）」 | 撤除来源归属与效果断言。[S20](../SOURCES_SCIENCE.md#s20)为仅书目条目，台账明载**本书目条目不提供任何实质命题支持**，属来源类型错配，见〔证3〕 |
| 「研究结果：社交媒体使用时间越长，孤独感越强。相关性强，因果复杂：孤独的人更依赖社交媒体，社交媒体又加深孤独（同前）」 | 撤除「研究结果」的定性与来源归属。这是一个双向因果命题，本书本轮**未取得**任何关于社交媒体使用与孤独感的一手或综述材料，标未核实，且不据它给出任何建议，见12.3与〔证3〕 |
| 错误用法／正确用法四行对照表：被动刷屏对主动连接、点赞对评论私信、群聊对一对一、看别人的生活对分享自己的生活 | 整表撤除。它把用法分成道德上的对错，与[第十章](Ch10_The_Art_Of_Connection.md)10.1撤除的社交／连接对照表同类；其中「群聊＝没有深度」对很多人不成立——有些人的日常恰恰靠一个群里那几句撑着，见12.2 |
| 「提醒自己：『我看到的是精修版，不是全部』」 | 撤除。它是一个要求被相信的提醒句，与[第三章](Ch03_The_Physiology_Of_Loneliness.md)3.8「入口是行为，不是道理」、[第十章](Ch10_The_Art_Of_Connection.md)10.5、[《平静之书》第十二章](../bop/Ch12_Cognitive_Tools.md)「重点是联系证据，不是强迫相信积极暗示」冲突。精修是媒介的事实，不需要你先安装一句提醒，见12.4 |
| 「减少『被动刷屏』，增加『主动连接』（直接发消息／打电话）」 | 通则地位撤除。[第六章](Ch06_Loneliness_First_Aid.md)6.3明写「主动开口」对社交焦虑者、被拒绝经历较多的人、正处在关系破裂中的人不成立 |
| 「把『群聊』换成『一对一视频通话』」等三条实操 | 撤除。它们是替换处方，要求先有一个愿意接的人，而这个前提对最需要这一章的读者往往不成立 |
| 「数字断食：每周一次的『无屏幕日』」 | 撤除。[第九章](Ch09_The_Art_Of_Solitude.md)9.1已撤除「一个人过一天数字断食」的处方地位，并把屏幕使用一事交给本章处理；本章不接这个处方，理由见12.6 |
| 「观察：数字断食后，你的孤独感是增加还是减少？（多数人会感到『更充实』，因为他们终于『过了自己的生活』。）」 | 撤除。「多数人会」是对读者的集体预测，本书无数据；而括号里那句已经先给出了答案，一次「观察」在结果被写好之后就不再是观察 |
| 「刷手机是『看别人活』，不是『自己活』。你消费了别人的生活，却没有过自己的生活」 | 判定地位撤除。它把一种常见行为定性为不算生活。这一版改问它在替你做什么，见12.5 |

## 12.2 有些人的连接只在线上

这是本章必须先说的一件事，因为原稿把它反过来说了。

**线上联系不等于亲密关系，但它也不等于零。** [第六章](Ch06_Loneliness_First_Aid.md)6.5已经写定了这一条的边界：真人声音的播客、有声书、访谈节目是可及的替代；线上语音社群、兴趣小组的语音房间门槛更低；「它们不等于亲密关系，但在凌晨两点，它们比空白好。本书不把次优写成无效」。本章沿用，不加宽也不收窄。〔证5〕

**下面几种情形里，线上不是替代，是唯一的一条。**〔证1〕

| 情形 | 为什么线下那条此刻不成立 |
|---|---|
| 你在一个小地方，周围没有能说这类话的人 | 不是你不愿意找，是找不到。距离是事实 |
| 你身体不便、慢性病或行动受限 | 出门这件事本身有代价，而这个代价每天不一样 |
| 你上夜班或轮班，作息和身边所有人错开 | 你醒着的时候，能联系的人都在睡，见[第十九章](Ch19_Workplace_Loneliness.md)19.4 |
| 你在照顾一个人，走不开 | 「见朋友」需要有人替你照护，而这通常没有 |
| 你的家人与旧朋友都在外地或外国 | 线上是唯一能保持的那一条，撤掉它就是断掉 |
| 你的性取向、性别认同、信仰或处境在本地说出来有代价 | 线上有时是唯一可以不用说谎的场合 |

**对这些情形，本章不说「减少线上、增加线下」。** 那句话预设了线下那一条是可用的。它不可用时，那句话的实际含义是：你现在拥有的不算数，而你没法拥有别的。〔证1〕

**关于群聊。** 原稿把群聊写成「99+ 消息，没有深度」，把一对一写成正确用法。有些人的日常确实靠一个群里那几句撑着：一个病友群、一个同乡群、一个游戏里的固定队伍、一个只有三个人的老同学群。这些话没有一句是深度对话，但它们每天都在，而且那里有人知道你在。本章不把这种情况判为不合格的用法。〔证1〕

**这一节也不否认线上会伤人。** 被针对、被排挤、被持续比较、被晾着不回，这些在线上发生得更快也更公开。区分的方法不是看媒介，是看具体那一段：它结束之后你是多一点还是少一点，见12.5与12.6。〔证1〕

## 12.3 关于「刷得越多越孤独」这句话

原稿把它写成「研究结果」，并归给一本仅书目的科普读物。这一版把它放回它实际的位置：**本书本轮未取得任何关于社交媒体使用与孤独感的一手研究或综述材料。**〔证3〕

能说的与不能说的：

| 可以说 | 不可以说 |
|---|---|
| 这是一个被广泛讨论的问题，本书没有回避它 | 不能说「使用时间越长，孤独感越强」是已证结论——本书无此数据 |
| 很多人报告刷完之后更空。这是自述，是编写观察，值得被当真 | 不能把它当成对所有人的预测，也不能推出因果方向 |
| 相关与因果是两件事，方向可能是双向的，也可能有第三变量 | 不能因为方向不明就说这件事不重要；也不能因为重要就假定方向已知 |
| 本书因此不给使用时长上限，也不设无屏幕日 | 不能反过来用「证据不足」为任何一种用法背书 |

**为什么这件事要在正文里写清楚。** 因为一个未核实的因果命题一旦写进正文，就会变成读者自我审查的标准：他会开始用时长衡量自己，而这本书并没有资格给出那个数字。〔证1〕〔证3〕

**关于机制。** 原稿给了三个机制（广度替代深度、表演替代真实、被动消费替代主动创造）。它们读起来合理，这也是它们流传的原因。本书没有核验它们，因此不把它们当作解释使用，只把它们降级为三个可以自己去观察的问题，见12.5。〔证3〕〔证7〕

**一条相关但不相同的已核验材料。** [《平静之书》第十章](../bop/Ch10_Digital_Hygiene.md)10.2引Mark等（2008）的模拟办公实验：四十八名参与者完成邮件任务，中断条件下扣除中断时间后的任务用时较短，部分自报压力、挫折与努力增加。[P08](../SOURCES_PRACTICE.md#p08)的边界明写：样本多为大学生，任务与指标有限；扣除中断时间不等于总工作效率提高；本研究不建立人人需要二十三分钟恢复注意的定律，也不能推导所有中断都有同一成本。它是关于**中断**的，不是关于**孤独**的，本章不据它推出任何孤独相关的结论。〔证4〕

## 12.4 比较：本书不在这里重讲

原稿用一节讲「你拿自己的幕后对比别人的成片」，并给出一条提醒句。[第二章](Ch02_Why_Loneliness_Hurts.md)2.4已经说明：这一问题与[《平静之书》第二章](../bop/Ch02_Why_We_Lose_Peace.md)2.4「比较：不必用贬低别人来安慰自己」是同一个问题，那本书处理得更完整。本章不重复，只保留三句话。〔证4〕

**第一句：精修是这个媒介的事实，不是一件需要你反复提醒自己才能记住的事。** 你不需要安装一句「我看到的是精修版」。你已经知道。知道之后仍然难受，是因为难受不来自不知道。〔证1〕

**第二句：所以处置在行为，不在提醒。** [第三章](Ch03_The_Physiology_Of_Loneliness.md)3.8明写，修改负面解读的入口是行为，不是道理，认识到「我在负面解读」通常不足以改变解读。可用的不是默念一句，是改变看到的内容：取消关注、静音、把某个时段的第一屏换掉。这些是可撤回的设置调整，不是自我说服。〔证4〕〔证6〕

**第三句：有时比较的对象不是别人，是你自己的另一个时段。** 看自己几年前发的东西，比看别人的更难承受。这一种原稿没有提，而它很常见。处置同上：那是可以不看的东西，不看它不需要理由。〔证1〕

## 12.5 刷屏在替你做什么

[第五章](Ch05_Loneliness_Audit.md)5.1有一行观察提示是「用刷屏、社交或工作填满所有空隙，不敢留空白」。原稿这一章把它当成一个要戒掉的习惯。这一版先问它在做什么。〔证9〕

**因为多数时候它在做一件有用的事。** 它让一段没有结构的时间有了结构；它让你不必面对安静；它给你一些不需要回应也不会被拒绝的东西；它让你在难受的时候有一个地方可以去。这些都不是缺点。〔证1〕

**[《平静之书》第十章](../bop/Ch10_Digital_Hygiene.md)10.5给了四个问题，本章沿用，不另编：**〔证4〕

1. 我当时想得到什么？
2. 这次使用有没有回应它？
3. 结束后是否愿意继续？
4. 有没有挤占一件自己更想保留的事？

这四个问题里没有一个是「用了多久」。也没有一个的答案是「不该用」。该书10.5同时明写：散步或读纸书不必被预先列作真休息，视频和游戏也不应一概列作假休息；累的时候没有明显恢复，也不意味着休息不配发生。〔证4〕

**什么时候它不再是有用的事。** 不是看时长，是看代价。四个可以核对的情形：〔证1〕

| 情形 | 它说明的是 |
|---|---|
| 你已经开始用它推后睡觉，而第二天要上班或照护 | 代价落在了睡眠与职责上，见[第八章](Ch08_Night_And_Weekend.md)8.4与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3 |
| 结束之后你比开始之前更空，而且这一点已经重复很多次 | 它没有回应当初那个需要。要换的不是意志力，是做法 |
| 它替代了一件你本来想做的事，而那件事你已经很久没做 | 第四个问题的答案是「有」 |
| 你在等一个不会来的回复，反复刷新 | 那是在处理一段具体的关系，不是在刷屏，见[第十章](Ch10_The_Art_Of_Connection.md)10.6 |

**这一章不把「停不下来」写成你的性格缺陷。** 界面上有自动播放、无限下拉、红点与推送，这些是设计选项，不是你的自制力问题。[《平静之书》第十章](../bop/Ch10_Digital_Hygiene.md)10.2把界面本身列为可以核对的对象，本章沿用；同时照录它的边界：不推断所有产品用了同一种奖赏机制，更不从红点的颜色诊断一次应激。〔证4〕

## 12.6 可以试的方向

每一项都是可撤回的试用，不是戒断方案。改回去不需要理由，也不需要说明。〔证1〕〔证4〕

| 方向 | 现实前提 | 停止条件 |
|---|---|---|
| **改看到的内容，不改自己。** 取消关注、静音几个让你难受的账号，把某个时段打开的第一屏换掉 | 你能进设置。有些内容来自工作群或家人，静音不等于退出 | 如果这样做让你担心错过必要信息，先保留必要渠道，见[《平静之书》第十章](../bop/Ch10_Digital_Hygiene.md)10.3 |
| **只减少一项干扰，不一次清空。** 关掉一个与照护、工作都无关的推送 | 你先确认过哪些渠道不能漏 | 漏接了必要联系就恢复原设置。这不是失败，是这一次试用提供的信息 |
| **给一次查看说明目的。** 打开之前先想：我这次要核对什么，哪个渠道有资格确认 | 无。娱乐也可以是目的，不必伪装成学习 | 无。看完不愿继续就停下，无需为每一次使用辩护 |
| **把等待回复的刷新换成一件事。** 见[第六章](Ch06_Loneliness_First_Aid.md)6.12或6.11 | 有力气做其中一件 | 反复无人回应时，要处理的是关系网络的现状，见[第十章](Ch10_The_Art_Of_Connection.md)10.6，不是你的刷新次数 |
| **保留一段线上的时间，并且不为此道歉。** 那个群、那个语音房间、那个游戏里的固定队伍 | 无 | 只在12.5那四种代价出现时才需要动它 |
| **一次小试用，允许撤回。** 选一项，记下原来的用途与不能漏掉的联系，过后回看少了什么多了什么 | 有一个可以写下来的地方 | 试用增加担心、妨碍职责、或没有带来想要的改变时恢复原设置。**不按日统计分数，不把成功定义成屏幕时间持续下降** |

**关于「无屏幕日」。** 原稿要求每周一天完全不看社交媒体、不看群消息。这一版不设。第一条理由可以在书内核对：[第九章](Ch09_The_Art_Of_Solitude.md)9.1已撤除「一个人过一天数字断食」的处方地位，并把屏幕使用一事交给本章；本章如果反过来把它设成每周作业，两章就会各说一套。〔证6〕

后三条是Sonus的编写理由，不是研究结论。其一，它在屏幕上工作的人那里不是一项练习，是一天不能工作。其二，「不看群消息（除非紧急）」预设了你分得清什么是紧急，而这条线常常是由别人划的：值班群、家人群、照护安排，漏一条的代价不由你定。其三，一整天的要求交给的可能是一个连十五分钟都难安排的人；本书其他各章的做法是先给一项可以撤回的小调整，见12.6第一行。〔证1〕〔证8〕

**如果一次试用让你更难受。** 停下来。依[S03](../SOURCES_SCIENCE.md#s03)与[S05](../SOURCES_SCIENCE.md#s05)，身心与行为类练习存在不良体验报告，无既往问题者也可能出现，自行加强或加时可能起反作用。〔证8〕

## 本章速记

- 「社交媒体给了你连接的幻觉」已撤除。它与第六章6.5「本书不把次优写成无效」冲突，而对只有线上联系的读者，它的实际效果是取消他手上唯一那样东西。
- 六种情形里线上不是替代而是唯一的一条：小地方、身体不便、夜班轮班、照护中、家人在外地、本地说出来有代价。对这些情形本章不说「减少线上、增加线下」。
- 群聊不等于没有深度。有些人的日常靠一个群里那几句撑着，那里有人知道你在。
- 三个机制与「使用时间越长孤独感越强」都标未核实：本轮未取得任何关于社交媒体使用与孤独感的一手或综述材料，两处 Cacioppo 与 Patrick（2008）属来源类型错配，该台账条目明载不提供任何实质命题支持。
- 因此本章不给时长上限、不设无屏幕日、不以屏幕时间下降为成功标准。
- 错误用法与正确用法的四行对照表撤除；「提醒自己看到的是精修版」撤除，处置在行为不在提醒。
- 每周一次的无屏幕日撤除，三条理由：第九章9.3已撤除同类处方、对在屏幕上工作的人那不是练习、「除非紧急」那条线常常由别人划。
- 刷屏先问它在替你做什么，再用四个问题与四种代价核对，不看时长。
- 每一项都是可撤回的试用。改回去不需要理由。

下一章：[第十三章 · 孤独与创造](Ch13_Loneliness_And_Creativity.md)。原稿称孤独是创造的温床，那一章已把这句话连同三个机制一并撤除；做法归第六章6.7，它只处理说法。
