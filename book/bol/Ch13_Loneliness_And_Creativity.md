# 第十三章 · 孤独与创造

> 原稿这一章用两句话开篇：孤独不只是痛苦，也是创造的温床；多数伟大的作品诞生于独处，因为孤独给了创作者「听见自己」的空间。随后给三个机制、一份四人名单、三种创造形式，以及一句结尾——你的孤独，可能正是别人需要的药。
>
> 这一版把两个部分拆开。**做法不在本章**：写、画、做、出声的做法在[第六章](Ch06_Loneliness_First_Aid.md)6.7，一个人待着时用手做一件事在[第九章](Ch09_The_Art_Of_Solitude.md)9.3，两处都已按修订标准写明现实前提与停止条件，本章不重复也不另编。**说法在本章**：原稿那两句话、三个机制与那句结尾，是这一章真正要处理的东西。〔证1〕
>
> 拆开的理由里有一条可以在书内核对：[第九章](Ch09_The_Art_Of_Solitude.md)9.1已经撤除「多数伟大的作品诞生于独处」，理由是这是一个关于历史事实的量化断言而该章没有任何数据；同一份材料Long与Averill（2003）也未列入本系列任何台账。而原稿第十三章把同一句话放在开篇当作前提，并据它推出三个机制。一处撤了，一处还留着，读者会读到两套。〔证3〕〔证9〕
>
> 还有一条更要紧：**这句结尾把转化写成了任务。** 一个正在孤独里的人，没有义务为任何人把孤独变成东西。13.5单写这一节。〔证1〕

## 13.1 先说清楚：这一章不做什么

下表中的情形，本章其余各节一律不适用，先按右列处理。〔证2〕

| 情形 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或已有计划、意图、无法确保眼下安全 | 拨 **120**（急救、急诊），并请一个可信任的人陪同；心理援助拨 **12356**，它提供心理支持与危机干预，**不替代120**，见[第六章](Ch06_Loneliness_First_Aid.md)6.1与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 你此刻只有痛苦，没有任何别的东西 | 那不是缺少一种能力，也不是一件该被送去转化的材料。先看[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2；本章13.5说明为什么这一条根本不该被指向一章讲创造的地方 |
| 你已经完全不想动，一件小事也启动不了 | 这是需要评估的情形，不是创造的障碍，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3。[第六章](Ch06_Loneliness_First_Aid.md)6.7明写：对已经无力启动的时刻，创造转移可能变成又一项未完成的任务，此时用6.11或6.13 |
| 创作过程带出了你收不住的情绪 | 停下来，做[第六章](Ch06_Loneliness_First_Aid.md)6.11，必要时联系支持。该处已写明表达性活动可能带出预期之外的内容 |
| 有人在要求你把痛苦、创伤或身份变成可展示的内容 | 那是处境，不是你的心态。见13.6与[第十九章](Ch19_Workplace_Loneliness.md)19.5 |
| 涉及人身威胁、跟踪、骚扰或勒索 | 保留记录与截图，向平台或单位举报；有人身危险拨 **110** |

三条限定，与本书导航页的约定一致。〔证1〕

1. **本章不教创造。** 具体做法在[第六章](Ch06_Loneliness_First_Aid.md)6.7与[第九章](Ch09_The_Art_Of_Solitude.md)9.3第二项。本章处理的是关于孤独与创造的那些说法。
2. **本章不承诺任何结果。** 不承诺作品，不承诺创造力提升，不承诺疗愈。[第九章](Ch09_The_Art_Of_Solitude.md)9.3已明写不承诺它会带来任何作品或任何创造力的提升；[第六章](Ch06_Loneliness_First_Aid.md)6.7已明写独处是否必然带来创造收益，本书未取证，不作断言。
3. **本章每一条都可以不做。** 不做不是失败，也不是「还没准备好」。约定一写明每一项练习都是可选的、不累积；读完这一章什么也不做，是一个完整的用法。

原稿说了什么，这一版怎么处置：

| 原稿的说法 | 处置 |
|---|---|
| 「孤独不只是痛苦，也是创造的温床」「多数伟大的作品诞生于独处」 | 两句一并撤除。后一句[第九章](Ch09_The_Art_Of_Solitude.md)9.1已撤除，本章13.2说明「多数」这个词为什么无法由一份四人名单支持 |
| 「因为孤独给了创作者『听见自己』的空间」 | 撤除。这是一个因果说明，本书无材料；可以说的版本见13.3 |
| 机制一「独处让人听见自己（Long与Averill，2003）」 | 撤除来源归属。该文未列入本系列任何台账，本轮未取得，标未核实 |
| 机制二「孤独是能量的积累……需要出口」 | 撤除其机制地位。「能量需要出口」是隐喻，可以描述体验，不能当机制用，见13.3 |
| 「创造是最健康的出口（比酒精／暴食／刷屏健康）」 | 撤除。这是一个比较级，本书无数据；它还把三种不同情形排成一个优劣序列，其中两种本书不作诊断，见[第十二章](Ch12_Digital_Loneliness.md)12.1与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3 |
| 机制三「孤独提供深度的时间（心流）」 | 保留构念，撤除操作结论。[P30](../SOURCES_PRACTICE.md#p30)载明「心流」是Csikszentmihalyi提出的既有构念，归属可信度高；同一条载明不能推出「给限制就更容易进入心流」这类操作结论 |
| 「历史上的孤独创作者：卡夫卡、梵高、艾米莉·狄金森、梭罗。他们的作品诞生于孤独，又治愈了无数人的孤独」 | 名单不作为证据，见13.2。「治愈了无数人的孤独」撤除——这是对读者的效果断言，本书无任何材料。关于梵高另有一段，见13.2末 |
| 「写作（最低门槛）」「艺术（无需技巧）」 | 两个括注撤除。写要识字、要有力气、要有一处能写的地方；画与手工要材料与体力，[第九章](Ch09_The_Art_Of_Solitude.md)9.3第二项明写一项需要花钱的材料在预算紧张时不是可选项 |
| 「开始一个『孤独项目』（写一本书／做一个播客／拍一组照片）」 | 撤除。这是一个长期作业，与约定一「每一项练习都是可选的、不累积」冲突。本章不给项目、不给进度、不给完成标准 |
| 「你的孤独，可能正是别人需要的药」 | 整句撤除，理由单独成节，见13.5 |
| 心态三条「解法」：质量是副产品／过程比结果重要，创造时的专注与投入本身就是治愈／创造不需要观众，为自己创造 | 三条撤除其断言地位。第二条是效果主张，本书无材料；第一与第三条是要求被相信的句子，与[第三章](Ch03_The_Physiology_Of_Loneliness.md)3.8「修改它们的入口是行为，不是道理」、[第十章](Ch10_The_Art_Of_Connection.md)10.5、[《平静之书》第十二章](../bop/Ch12_Cognitive_Tools.md)「重点是联系证据，不是强迫相信积极暗示」冲突。其中可用的部分见13.4 |
| 「创造的障碍：『我做不好』／『我没有天赋』／『别人会怎么看』」 | 前两句撤除其普遍地位——它们是原稿替读者列出的心态清单。第三句「别人会怎么看」有时确实成立，而且那不是心态问题，见13.6 |
| 表情符号小标题、ASCII引号与末尾的作者文献列表 | 撤除，改为依据编号与台账链接，格式见[系列来源与可信度说明](../EVIDENCE_GUIDE.md) |

## 13.2 「温床」这句话错在哪里

三条问题，前两条关于这句话本身，第三条关于它对读它的人做了什么。

**第一，这份名单是从有作品的那一边挑出来的。**

原稿列了四个人：卡夫卡、梵高、艾米莉·狄金森、梭罗。你之所以知道这四个人的孤独，是因为他们留下了作品，作品留下来，孤独才被记录。同样孤独而没有留下作品的人，你看不到——他们没有东西可看。

所以这份名单实际支持的不是「多数伟大的作品诞生于独处」，甚至不是「有些伟大的作品诞生于独处」。它支持的是：有四个人。要从四个人推到「多数」，需要一个分母：历史上有多少人在同样的孤独里什么也没有留下。那个数字没有人统计过，也不可能统计，因为没有留下的东西不会进入任何档案。〔证1〕〔证3〕

**第二，这句话把顺序写反了也读得通，这说明它没有提供信息。**

原稿说：孤独给了创造空间。换一个方向说：创造需要长时间不被打断，而这四个人恰好没有别的选择。狄金森不出门，可能不是因为不出门让她写得好，而是因为写是她剩下的不多的事。梭罗去瓦尔登湖住了两年多，之后回去了，并且写了那本书——那段独处是他自己安排的，不是他被迫的。

本书没有材料裁定哪个方向对。但两个方向都读得通、都无法由这份名单区分，就说明「孤独是温床」这句话没有告诉读者任何可以据此行动的事。它可以被任何结果证实：孤独的人写出了东西，是温床；孤独的人什么也没写，是还没到时候。一个不可能被反驳的说法，不是一条知识。〔证1〕〔证3〕

**第三，也是本章最在意的一条：它对正在孤独的人是有代价的。**

如果「孤独是创造的温床」成立，它就同时变成一条要求：你既然孤独，就该做出点什么来。做不到的人于是多了一层失败——他不只是孤独，他还浪费了自己的孤独。

这与[第五章](Ch05_Loneliness_Audit.md)5.1撤除「转化力」这个维度名是同一件事。那一处写明：把「没有从孤独中学到东西」写成一种缺失，等于在痛之上再加一条考核。这一章不重新发一次那样的考核。〔证9〕

**关于梵高，要单说一句。**

他的名字被反复用来连接精神痛苦与天才。本书不采用这个连接。一个人有精神疾病，与他做出了什么作品，是两件事。把两件事连起来讲，对正在生病的人是双重坏处：它暗示病是才华的代价，于是看病像放弃什么；又暗示没有才华的人不配生病，于是难受需要先证明自己有价值。

广为流传的说法是，他生前卖出的画极少，死后却成为最著名的画家之一。本书本轮未核验这一说法，因此不把它当作事实使用，只用它说明一件事：同一段生平可以被读成「孤独的天才终将被承认」，也可以被读成「一个人在世时没有得到支持，而这本来是可以的」。本书采用后一种读法，并标明这是读法，不是关于他的研究结论，也不是对他生平的核验。〔证1〕

## 13.3 三个机制，逐条放回原位

原稿的三个机制读起来都合理，这也是它们流传的原因。逐条处置：

| 原稿的机制 | 可以说的 | 不可以说的 |
|---|---|---|
| 独处让人听见自己：人群中你听到的是别人怎么想，独处时才听得到我怎么想（Long与Averill，2003） | 很多从事写作、作曲、研究的人自述需要不被打断的时间。这是自述，值得被当真 | 不能据此推出独处产生创造，更不能推出孤独的人因此占优。该文未列入台账，本轮未取得，标未核实 |
| 孤独是能量的积累：痛苦、渴望、空虚需要出口，创造是最健康的出口 | 「憋着」「需要出口」是有用的日常语言，它能描述一种真实的体验 | 不能把隐喻当机制。「最健康」是一个比较级，本书无数据；把酒精、暴食与刷屏排在一起比优劣，其中两项本书不作诊断，也不作严重度分级 |
| 孤独提供深度的时间：创造需要长时间的高度专注，独处给了你这个时间 | 「心流」是Csikszentmihalyi提出的既有构念，指目标清晰、反馈即时、挑战与技能匹配时的深度投入状态。构念归属可信度高 | 台账明载不能推出「给限制就更容易进入心流」这类操作结论，且本轮仅取得书目、未核读原文。孤独是不是那样的限制，本书无材料 |

〔证3〕〔证4〕

**一条相关的假说，用来把一件事放回处境。** Amabile主张内在动机有利于创造性表现，而某些外在约束——例如被评价的预期、被限定完成方式——可能削弱它。这是一个存在边界条件与后续争议的假说，不是无条件定论；本轮仅取得书目。〔证5〕

它在本书里的用处很窄，但很具体：**如果你本来喜欢做一件事，后来一做就难受，可能不是你变了，是安排变了。** 有人开始看、开始评、开始规定怎么做，那是一件关于安排的事。原稿把「别人会怎么看」列成一条创造的心理障碍，交给读者自己解决；这一版把它交给13.6，因为那里有可以问的人和可以改的条件。

**关于写下来。** 台账里有一条与本章直接相关的已核验材料：Frattaroli（2006）的实验性表达元分析，汇总一百四十六项随机研究，随机效应模型下的平均收益较小，并识别到调节因素。它可以支持「表达性活动可能有有限帮助」。它的边界同样要照录：实验性表达不等于所有日记，结果不能直接代表本书的短时书写；不支持「排毒」「一定释放情绪」或越痛苦越有效。〔证7〕

[第六章](Ch06_Loneliness_First_Aid.md)6.12已经按这个尺度写过书写，并把话说得更窄：现有证据支持的是在特定实验任务中用词语标注情绪伴随脑活动变化，由此外推到「日常孤独一旦写下就会缓解」，可信度低。本章沿用，不加宽。〔证6〕

## 13.4 做法不在这一章

这一节不列做法，只指路。理由是书内的：[第六章](Ch06_Loneliness_First_Aid.md)6.7是本书唯一逐项写了现实前提、跳过条件与停止条件的那一项，另编一份就会分叉。〔证6〕

| 你想要的 | 去哪里 |
|---|---|
| 具体做法：写、画、做、出声 | [第六章](Ch06_Loneliness_First_Aid.md)6.7 |
| 一个人待着时用手做一件事，以及它的现实前提 | [第九章](Ch09_The_Art_Of_Solitude.md)9.3第二项 |
| 写下来这件事的边界与反刍之分 | [第六章](Ch06_Loneliness_First_Aid.md)6.12 |
| 创作中情绪收不住 | [第六章](Ch06_Loneliness_First_Aid.md)6.7停止条件、6.11 |
| 需要长时间不被打断 | [《平静之书》第十章](../bop/Ch10_Digital_Hygiene.md)10.6 |
| 想做一件长期作品，需要时间与钱 | 本章不给项目，见13.5末与13.7 |

只补三句，都是6.7没有展开的。

**一、「不求质量」不是一句安慰，是一个安排。** 6.7把完成标准写成「做了」而不是「做好了」。它这样写，是因为一旦设了质量标准，这件事就多出一个可以失败的地方，而这个人今天已经有一个了。这句话对习惯被评价的人最难，难点不在理解它。〔证6〕

**二、什么都不想做的时候，跳过。** 6.7已明写这一条：创造转移对「有空虚感但还有行动力」的时刻有用；对已经无力启动的时刻，它可能变成又一项未完成的任务。本章加一句：**什么都不想做，不意味着你缺了什么能力。** 它常常意味着你已经用完了。〔证6〕〔证8〕

**三、原稿的心态三条里，有一句可以留下，但要换个身份。** 「创造不需要观众」作为一句要求你相信的话，与本书三处已写定的表述冲突，撤除；作为一个具体的安排，它可以是真的——你可以做一件不发给任何人的事，不设发布，不给期限，做完就放着。这是Sonus的编写建议，不是从任何效果研究推出的做法，也不保证它比发出去更好。〔证1〕〔证10〕〔证11〕

## 13.5 「你的孤独，可能正是别人需要的药」

原稿用这句话结尾。这一版把它整句撤除，并说明为什么它值得单列一节。

**这句话同时做了两件事。** 它告诉你你的痛苦有用，然后把这个用处设成你的事。第一件听起来是安慰，第二件是任务，而它们写在同一个句子里，读者很难只接住前一半。〔证1〕

**「药」是一个医学词。** 你的经历确实可能让别人觉得不那么孤单。有人因此开始写，有人因此开始讲，也有人因此找到了自己的用处，这些都是真的。但那不是药——它不治疗任何人的任何病；也不是任务，因为没有人在有资格派这个任务的位置上。〔证1〕〔证11〕

**顺序不能倒过来。** 有些人后来确实把孤独做成了东西，而且做得好。他们是在有了力气之后做的，不是在最难受的时候被要求做的。把结果讲给正在难受的人听，并暗示那是他此刻该走的路，是拿别人的后半段催促别人的前半段。〔证1〕

**本书的一条立场，在这一章必须写明。** 本书不把「学会独处」「把孤独转化成创造」「把孤独转化成意义」写成继续留在忽视你的关系、孤立你的岗位或排挤你的环境里的义务。有些孤独是处境造成的，处境造成的孤独只能由处境处理。把它写成个人的能力缺口，结果是双重的：条件没有变，而多了一条自我指控。这一章讲的是一件你可以做的事，它讲的不是：你之所以还没有从这段孤独里得到什么，是因为你还没有开始创造。〔证1〕

**如果你此刻只有痛苦，没有任何别的东西。** [第五章](Ch05_Loneliness_Audit.md)5.1把这一条的阅读入口指向本章，这个指向本身需要修正：一个只有痛苦的人，不需要一章关于创造的内容，他需要的是[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2那条界线不由你自己划的说明，以及[第六章](Ch06_Loneliness_First_Aid.md)6.11、6.13那种不要求产出的照顾。本章不接这个入口，只在13.7留一行指回去。〔证9〕

## 13.6 被要求产出的时候

这一节处理一个原稿没有考虑的情形：孤独不只是你一个人的事，有时别人需要它是可展示的。

它可能长这样：一个岗位要你把经历讲成故事；一门课要你用创伤做课堂作业；一个平台告诉你你的痛苦有流量；一次分享之后有人说「你的故事很励志」；或者家里人说，你写下来就好了，写完就过去了。

这些情形里，创造是形式，工作是实质，而且常常是没有报酬、也没有下班时间的工作。可以问的是三件事：**谁受益，我得到什么，我能不能不做。** 第三个问题最容易被跳过，而它常常是唯一要紧的那个。〔证1〕

13.3提到的那条假说在这里有一个具体用处：被评价的预期可能削弱内在动机。所以「明明喜欢写，现在一写就难受」这件事，可能不是你变了，也不是你不够真诚，是这件事的条件变了。条件变了要改的是条件。〔证5〕

**一个边界。** 本章不主张所有分享都是剥削，也不主张你不要讲。有人讲出来之后确实好过一些，也有人因此找到了同行的人。本章只主张一件事：那应该是你的选择，不是别人对你的期待落成的义务；而且你随时可以停，停下不需要理由。〔证1〕〔证8〕

如果要求来自岗位、上级或一个组织，见[第十九章](Ch19_Workplace_Loneliness.md)19.5；如果来自一段关系或婚姻，见[第十八章](Ch18_Loneliness_In_Relationships.md)18.7与[婚后孤独附录](Appendix_Loneliness_In_Marriage.md)A.1。第十八章18.1也是本书伦理红线的成文处之一。

## 本章速记

- 「孤独是创造的温床」撤除。三条理由：那份四人名单是从有作品的一边挑出来的，支持不了「多数」；把顺序反过来说也读得通，说明这句话没有提供可以据此行动的信息；而它一旦成立就变成一条要求，做不到的人多一层失败。
- 梵高不用于连接精神痛苦与天才。把两件事连起来讲，暗示病是才华的代价，又暗示没有才华的人不配生病。
- 三个机制逐条降级：Long与Averill（2003）未列入台账，标未核实；「能量需要出口」是隐喻不是机制，「最健康的出口」是无数据的比较级；「心流」构念归属可信度高，但台账明载不能推出操作结论。
- 「你的孤独，可能正是别人需要的药」整句撤除。它先说你的痛苦有用，再把用处设成你的任务。
- 做法不在本章：第六章6.7与第九章9.3已写实现实前提、跳过条件与停止条件，本章不另编。
- 什么都不想做，不意味着你缺了什么能力。约定一：每一项都可以不做，不累积。
- 被要求把痛苦变成可展示的内容时，问三件事：谁受益，我得到什么，我能不能不做。
- 本章不承诺作品，不承诺创造力提升，不承诺疗愈。

下一章：[第十四章 · 孤独的转化](Ch14_Transforming_Loneliness.md)。那一章已按本记录标准重写，它处理的正是「转化」这一框架：14.2写明本书撤除了什么、保留了什么，14.4处理「这件事要我学会什么」，14.5处理那些要求你从痛苦里找出意义的话。本章13.5撤除的那一句，那一章一并撤除，见其14.1。
