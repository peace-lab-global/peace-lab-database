# 第十八章 · 亲密关系中的孤独

> 有人在身边，心却隔着墙。
> 本章的顺序是：先分清哪些情形不属于本章，再看它长什么样、从哪来，最后才是三步路线。婚姻场景的行动版本见[附录小册子 · 婚后孤独](Appendix_Loneliness_In_Marriage.md)。

---

## 18.1 先分清：哪些不属于本章

以下情形请先获取现实中的帮助，不要从本章的路线开始。本章的所有做法都以「你还处在一个可以说话的关系里」为前提，这个前提不成立时，它们不只是无效，还会延误该做的事。〔证1〕〔证2〕

| 你正在经历的 | 先做什么 |
|---|---|
| 有伤害自己的念头，或觉得活着没有意思 | 立即拨打12356心理援助热线，或前往就近医院急诊。这一条优先于本章其余全部内容，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 处于暴力、控制或被限制自由的处境 | **110**。**离开该处境优先于任何情绪调节**，也优先于本章的全部三步，见[第六章](Ch06_Loneliness_First_Aid.md)6.1 |
| 长期被羞辱、贬低，或被切断与朋友家人的联系 | 这是情感虐待，不是沟通问题。它不会因为你把话说得更好而停止，见18.7与[危机资源清单](../../规范/CRISIS_RESOURCES.md) |
| 持续两周以上情绪低落、兴趣丧失、睡眠或食欲明显改变 | 先做精神科或临床心理科评估。这可能是抑郁的表现，不是关系技巧能处理的，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2与22.3 |
| 即使有人陪、有事做，仍有一种说不出的空 | 先读[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2。这一条[第五章](Ch05_Loneliness_Audit.md)5.2第六种明确写着不能自己认领 |

三条限制。本表不是诊断标准，不能用来判断你或你的伴侣有没有问题，也不能排除风险。12356提供心理支持与危机干预，不替代120；政策要求每日不少于十八小时，不等于全国24小时，实时可用性本书未经拨测。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证1〕

**本章的一条立场，先写在这里。** 本书不把「在关系里安顿自己」写成继续承受忽视、贬低、控制或长期不平等的义务。有些关系可以修，有些不能；对不能修的那一部分，设立边界或离开是正确的动作，不是失败的选项。这句话在下面每一节都适用，尤其在18.6与18.7。〔证2〕

## 18.2 它为什么更痛

| 单身时的孤独 | 关系里的孤独 |
|:--|:--|
| 有期待：找到那个人就好了 | 期待已经落空：就是这个人，还这样 |
| 可以归因于环境（「我该多社交」） | 无处归因，于是开始怀疑自己 |
| 说出来不丢人 | 说出来像背叛（「TA 对我很好啊」） |
| 孤独是处境，看得见边界 | 孤独是日常，看不见尽头 |

这张表描述的是主观经验，不是一组可以比较严重程度的事实。「关系里的孤独比单身的孤独更痛」这句话，本书没有为它取得可核验的比较研究，它在这里作为一句被许多人认可的描述保留，不作为结论。〔证3〕

真正让它更难的，是第三行：向朋友倾诉，得到的常常是「TA 不是挺好的吗」，于是闭嘴。这一条把出口也堵上了，所以18.7把「找一个不受这段关系影响的人说出来」单列为一步，不是可选项。〔证2〕

需要指出本章自己的一处矛盾。原稿在这里写「亲密关系本该是孤独的解药」，而这一句正是18.4第一条要拆的预设——把婚姻当成孤独的解药，落差才格外锋利。本书保留这一句作为对常见期待的描述，不保留它作为前提。〔证2〕

## 18.3 几种常见的画面

下面是几种常被描述的画面。**它们不是六种人，也不是六种类型。** 同一段关系里常常同时有几种，也可能一种都不像；这一年像第一种、那一段像第四种，都很正常。它们由Sonus整理，没有经过量表开发与验证，不用于分类，不表示严重程度，也没有「你主要是哪一种」的正确答案。〔证8〕

| 画面 | 常见的样子 |
|---|---|
| 各过各的 | 分工明确、账单清晰、孩子共管，什么都好，就是不像伴侣。对话里只剩事务 |
| 只演角色 | 只做好丈夫、好妻子、好爸爸、好妈妈，不再做一个有需要、有脆弱、有梦想的人。对方也在演，于是两个演员互相对台词 |
| 屋檐下的沉默 | 吵过几次无效的架之后，学会了多一事不如少一事。冲突减少了，话也一起少了 |
| 人在，注意力不在 | 饭各吃各的，床各刷各的。物理距离很近，注意力没有交集 |
| 节奏错位 | 一方渴望深谈，一方觉得过日子想那么多干嘛。想要的不一样，而且都没有错 |
| 用外面的热闹填家里的安静 | 应酬、加班、球局、朋友，人也回家，只是不与你独处 |

原稿在这一节要求读者「找到主型再去做自检」。本书撤除这个安排，理由有两条：一是把处境做成类型，会让人开始 维护一个标签，而不是看自己的关系；二是它接着通向一张二十条的勾选量表，而那张量表本身没有信度与效度依据。18.8说明它被换成了什么。〔证2〕〔证8〕

## 18.4 它从哪来：几种常见的来路

原稿把这一节叫「五个机制」。本书改名，因为下面没有一条取得了可以作为机制的证据。它们是Sonus对常见模式的观察整理，写成观察，不写成因果链。〔证8〕

**一、期望落差。** 社会脚本说「结了婚就不孤独了」，于是人带着「TA 应该懂我」的默认设置进入关系。期望越具体、越没有说出口，落差越锋利。这一条与[第四章](Ch04_Myths_Of_Loneliness.md)迷思六是同一个预设的两面。〔证2〕

**二、话变浅了。** 关系初期的「你最近在想什么」，被日复一日的事务性沟通替换。原稿在这里引用一项婚姻研究，说「婚姻前五年对话深度的衰减，与婚姻满意度的下降几乎同步」。该引用连完整的书目信息都不具备，本轮未取得任何材料，整条撤除。可以保留的只是一句描述：让许多人为难的常常是话浅，而不是话少。〔证5〕

**三、角色盖住了人。** 结了婚，人多了伴侣、父母、子女、同事、房东、司机的角色。角色负责做对的事，不负责做自己。长期只演角色的人，连自己都陌生了，就很难让对方遇到你。〔证2〕

**四、把激情的回落当成爱的结束。** 原稿写「热恋期的多巴胺会自然回落」，以此解释为什么人会误判。多巴胺在这里是一个通俗比喻，本书本轮未取得可核验的一手测量研究，不作机制断言。保留的是那条误判本身：一段关系的强度会变化，变化不等于结束；把它读成结束，会让人提前放弃，也可能让人向外去寻找重新上头的感觉。〔证4〕

**五、一方先冷，另一方跟着冷。** 一方抱怨多了、看手机多了，另一方读成「TA 不要我了」，于是保护性退缩，然后更冷。两个人在用孤独互相回应。原稿称这是「最好打破的一个循环，一个人停止传染，另一个人就容易跟着停」。这个说法有一个必须补上的边界：它只在双方都还愿意留在关系里时成立。如果对方已经长期不回应，「你先停止传染」就变成要求被忽视的一方继续单方面维持，那不是打破循环，是把它固定下来。见18.6。〔证2〕

**关于依恋风格。** 原稿在这一节引用了依恋类型研究，说回避型的人紧张时想逃离、焦虑型的人紧张时想抓住。该材料本轮未取得原文，也未列入系列台账，本书标为**未核实**，不作为解释任何一方行为的依据。它作为一个可以在专业评估中讨论的角度保留，不作为一种可以自行贴给伴侣的标签。〔证5〕

## 18.5 路线一：先安顿自己（不需要对方参与）

关系中孤独的人最容易掉进「我必须改变 TA」的死胡同。这一步只做一件事：把注意力从对方身上，收回到你自己可以决定的部分。

1. **先做一次观察，不是一次自检。** [第五章](Ch05_Loneliness_Audit.md)5.1的四组观察提示（理解、独处、连接、共处）可以用来看这段关系里的孤独，但要带上一条限定——[第五章](Ch05_Loneliness_Audit.md)5.2第四种明确写着：这一种情形**常常指向关系本身，不指向你的连接能力**。所以不要从「我哪一维最差」开始，那会把一个关系问题改写成你的能力问题。从「这段关系里，哪一部分是我可以决定的」开始。〔证2〕
2. **恢复一个只属于你的身份。** 进入这段关系之前你是谁？捡回一个不依赖伴侣身份的活动、朋友或兴趣。原稿把这一条归给一部关于独处能力的专著，该书本轮仅取得书目，未核读，本书把它改为编写建议。〔证5〕
3. **把孤独感从对方的判决书里摘出来。** 孤独是一种信号，不是对方的罪证，也不是你的失败。你可以爱着一个人，同时感到孤独，这两件事不矛盾。这一条不承担让谁免责的作用，见18.7。〔证2〕
4. **写下你的关系愿望单。** 不写「TA 应该……」，写「在这段关系里，我最需要的是____」。最多三条，具体到可以执行，比如「每周有一个晚上，两个人都不看手机，说半小时话」。它是18.6那场对话的材料，不是要求对方签字的清单。〔证2〕

原稿给这一步定了「1–2 周」的期限。本书撤除这个期限：它没有依据，而且会把安顿自己变成又一项有截止日期的任务。做到哪一步算哪一步。〔证2〕

## 18.6 路线二：重建连接（一次只做一个动作）

下面五件事，从你开始，不需要等对方先动。**一次只做一件，做完就停。** 它们是Sonus编排的低成本建议，不是验证过的方案，本书不声称任何一项有效，也不给它们排先后优劣。〔证2〕

1. **每周一次真话时间。** 固定一段一到两小时，手机放到另一个房间。前半小时不谈孩子、家务、钱、工作，只谈感受。推进的方式见[第十章](Ch10_The_Art_Of_Connection.md)10.2：从事到人、从好到真、从说到听。
2. **说一次真实的需要。** 「我最近觉得我们说话变少了，我有点慌」，而不是「你都不理我」。前一句说的是你的状态，后一句说的是对方的过错；在已经冷了一段时间的关系里，第二句通常只换来防御。原稿把这一条概括为「脆弱是入口，指责是出口」并归给一部大众著作，该书本轮仅取得书目；而且这个概括有一个本书必须写出的例外——**在不对等的关系里，先暴露脆弱的一方常常承担更多风险。** 如果你说出来之后得到的是嘲笑、翻旧账或长时间的沉默，那不是你说得不够好，见18.7。〔证5〕
3. **恢复与性无关的身体接触。** 牵手、并肩坐、一个拥抱。原稿在这一条写「催产素不靠说，靠碰」并归给一部大众科普读物。本书撤除这个说法：催产素的通俗表述存在公认迷思，其测量也有方法学限制，那部读物本身不是催产素研究，用它为一手机制主张背书属来源类型错配，详见[第三章](Ch03_The_Physiology_Of_Loneliness.md)3.4。〔证3〕〔证4〕保留下来的是行为本身，以及一条你可以自己检验的经验：对许多人来说，被触碰是安慰性的。**它有一个前提——双方都愿意。** 不愿意被触碰不是关系的失败，也不是需要克服的障碍；对方躲开时不要坚持，见[第六章](Ch06_Loneliness_First_Aid.md)6.4。**停止条件**：接触让你僵硬、屏息、想逃、麻木，或引出创伤回忆，立即停止。〔证6〕
4. **一起做一件没做过的事。** 一道新菜、一条没走过的路、一个从没聊过的话题。新鲜感靠换体验，不靠换人。这一条是编排建议，本书没有为「共同创造优于共同消耗」取得依据。〔证2〕
5. **把感谢说具体。** 「谢谢你今天洗碗」比「你怎么又在看手机」更接近你想说的话。具体不是修辞要求，是因为具体的感谢对方能接住，笼统的表扬接不住。〔证2〕

**如果对方不接，这一节最重要的一段在这里。**

原稿写：「如果对方全程不接：先别下结论，给 4–6 周，改变习惯需要时间。期间你只做第一、二步，不吵、不逼、不撤回。你稳定，本身就是关系里最强的一个变量。」

**本书撤除这一段，理由是它把承受写成了方法。** 它要求一个人在完全没有回应的关系里，连续四到六周不表达不满、不施压、也不后退，并把这个姿态命名为「稳定」。三处问题：第一，四到六周这个数字没有任何依据；第二，「不吵不逼不撤回」取消的正是被忽视一方唯一剩下的表达渠道；第三，它把关系是否改善的责任，全部放在已经先开口的那一方身上。这与18.1的立场直接冲突。〔证2〕

替换成下面这三条：

- **说出口一次，就说出口一次。** 你已经把需要说清楚了，对方听见了而没有动，这是一个事实，不需要再重复四周来确认它。
- **给不给时间，看的是对方的行为，不是日历。** 如果对方说「我知道了，我在想办法」，那么一段时间是合理的；如果对方的回应是沉默、「你想太多了」、或者两天之后一切照旧，那么该做的不是等，是18.7。
- **被长期忽视、贬低、控制时，正确的动作不是提升自己的连接力。** 这句话是[第五章](Ch05_Loneliness_Audit.md)5.2第四种的原话，本章不修改它。〔证2〕

**任何一项让你更难受，就停下来。** 停下来不是做错了，是这一项此刻不适合你。〔证6〕

## 18.7 路线三：接受与边界

这一节分三种情形，它们的处理方式完全不同，不要混用。

**第一种：对方给不了，但也没有伤害你。** 比如对方确实不擅长深谈，也不打算学。这种情况下，把深度对话放到别处——朋友、书、一个团体、一位咨询师——是可以的，婚姻负责安稳，不必负责你的一切。调整期望在这里是合理的。〔证2〕

**第二种：对方在伤害你。** 长期忽视、羞辱、贬低、切断你的人际、经济控制、任何形式的暴力。**这一种不适用「调整期望」，也不适用「给时间」。** 期望调整不了伤害。要做的第一件事是安全，第二件事是找一个不受这段关系影响的人说出来，第三件事是专业支持：〔证2〕〔证9〕

- 有人身危险或身处暴力、控制、被限制自由的处境：**110**，离开该处境优先于任何情绪调节；
- 找一位受过训练的治疗师。伴侣咨询不一定要两个人一起去，你自己去也可以，它不是「我们完了」的判决书；
- 见[危机资源清单](../../规范/CRISIS_RESOURCES.md)与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.6。

**第三种：你还没法判断是哪一种。** 这很常见，而且它本身就是一个信号：如果你需要反复论证对方到底有没有伤害你，那么这段关系里至少缺了一样东西。这种情况下，最有用的一步不是继续分析，是找一个外人说一遍——朋友、家人、咨询师都可以。说出来之后，事情通常比你一个人在夜里想的清楚。〔证2〕

**关于「继续还是离开」。** 这不是本书能替你决定的，本书也不打算给一个判断标准。可以说的只有两条：这个决定不需要以「对方先改」为前提；做出这个决定的人不必先证明自己已经忍够了。〔证2〕

**关于用另一段关系来止住孤独。** 原稿写「向外求的解药会让所有人在孤独里再转一圈」。这是一句道德劝告，本书没有为它取得依据，撤除。可以说的是一件更实际的事：它通常不解决18.1到18.7里的任何问题，而且会增加几个新的、有时限的、涉及他人的问题。是否要面对它，以及怎样面对，属于你和可能被影响到的那些人，不属于本书。〔证2〕

## 18.8 本章不处理的事

| 你真正的问题 | 该去哪 |
|---|---|
| 暴力、控制、人身危险 | 18.1与110；离开该处境优先于任何情绪调节 |
| 持续低落、兴趣丧失、有伤害自己的念头 | [第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1与22.3 |

一个虚构的情境。周遥的难受有明确的时间表：只发生在伴侣连续加班的那几个晚上，其余时间独处并无困难。周遥原本的结论是自己独处能力太差，打算按周加码练习。要处理的不是能力，是关系里的时间结构，以及一个可以说出口的请求。三周之后，那个请求说出口了，加班没有减少，但周遥不再独自把它解释成「TA 不要我了」。这不是一个关系被修复的故事——加班一点没变；发生的只是一件事：周遥停止把对方的处境当成自己的失败来惩罚自己。换一段关系、换一个对方，结果可能完全不同。〔证7〕

## 本章速记

- 先分诊：暴力与控制走110，情感虐待走18.7第二种，持续低落走评估。这三类都不属于本章的三步路线。
- 让你孤独的是关系质量，不是有没有人；但这句话不能反过来用——它不等于「关系不好是你的连接能力不好」。
- 六种画面是处境不是类型，不选主型，不打分。
- 五条来路是观察不是机制，其中婚姻研究、依恋类型、独处能力专著三项本轮均无材料，已降级或撤除。
- 三步路线：安顿自己（不设期限）→ 重建连接（一次一件，说完一次就算说完）→ 接受与边界（三种情形分开处理）。
- 原稿的「给 4–6 周、不吵不逼不撤回」已撤除：它把承受写成了方法。
- 设立边界或离开，是正确的动作，不是失败的选项。
