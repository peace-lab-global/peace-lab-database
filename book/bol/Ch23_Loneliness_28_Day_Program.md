# 第二十三章 · 四周试行

> 这一章是前面二十二章的落地版：每天一个可选动作，四周走完。四周不是四个台阶，也不是疗程。你可以只用其中一周，重复一项，或者完全不用；选择不用不等于放弃照顾自己。〔证1〕
>
> 四周的顺序借自[第五章](Ch05_Loneliness_Audit.md)5.1的四组观察——理解、独处、连接、共处。原稿这一章叫「28天孤独转化」，本书撤除了「转化」这个词，理由见23.1。〔证5〕

---

## 23.1 先说清楚：这份计划在做什么，不做什么

以下五种情形请跳过整份计划，先联系专业支持。它们不是四周能处理的事，多练独处也不会让它们好转。〔证2〕

| 情形 | 联系 |
|---|---|
| 有伤害自己的念头、计划或准备 | **12356**（全国心理援助热线）；已有立即生命危险或已采取行动，拨 **120** |
| 觉得活着没有意义、不想醒来、在安排后事 | **12356** |
| 已经很久无法进食、睡眠、工作或照顾自己 | 精神科或临床心理专业评估 |
| 伴随幻觉、被监视感、思维混乱 | 精神科急诊或 **120** |
| 处于暴力、控制或被限制自由的处境 | **110**；离开该处境优先于任何情绪调节 |

三条限定与[第六章](Ch06_Loneliness_First_Aid.md)6.1一致，一起读：心理热线不是急救；本书不对12356各地实时可用性作保证，未做拨测；不要等到「足够严重」才求助。求助的路径、方式与阻力处理见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)。其他地区资源见[危机资源清单](../../规范/CRISIS_RESOURCES.md)。〔证2〕

**这份计划撤除了原稿的六样东西。** 撤除的理由都写在下面，因为它们决定了这份计划怎么用。〔证5〕

| 原稿写了什么 | 这一版怎么处理 |
|---|---|
| 章名「28天孤独转化」，并承诺「四周后你会看到一个能与孤独共处的自己」 | 章名改为「四周试行」，承诺撤除。第五章已把维度四从「转化力」改名为「共处」，理由是把「没有从孤独里长出什么」写成一种缺失，等于在痛之上再加一条考核。一份计划不该承诺它交付不了的结果 |
| 「每日保底」「必做」「星号项」与三条「及格线」 | 全部撤除。表里没有必做项，只有可选项；不设及格线，不比较完成天数。本书导航页的第一条约定写着每章练习都是可选的，这一章不能例外 |
| D4「区分你的孤独类型（亲密／关系／存在）」、D5「写下你的主导孤独模式」 | 撤除。[第一章](Ch01_What_Is_Loneliness.md)1.3保留了三种常被分开的说法，那是帮助说话的词汇，不是要求你先归好类才配难受；其中第三种不能自己认领，它可能需要评估，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2 |
| D2「学两个急救技术并各练3次」 | 撤除次数。[第六章](Ch06_Loneliness_First_Aid.md)6.2写明十项是可选清单，不累计次数，不设完成标准 |
| 独处从十分钟排到三十分钟，再排到一小时，逐级加码 | 撤除时长阶梯，改为每天一项、时长自定、随时可停。理由见23.4 |
| D27「重做一遍孤独审计，对比四周前」，并「记录变化最大的一维」 | 撤除对比与排名。第五章的四组观察不计分、不设阈值，没有分数可以对比，也没有维度可以排名。理由见23.6 |

原稿第一周的目标行还引了Cacioppo与Patrick（2008）。那是一部大众科普读物，本轮仅取得书目，台账明确写着该条目不提供任何实质命题支持。这一版不引它：第一、三周改引两份本轮已核读的材料，见依据表〔证6〕〔证7〕。

## 23.2 使用说明

**每天最多选一项。** 表中时间是额外投入的建议预算，不是有效剂量——本书没有对任何时长做过验证。前一天的动作不自动累加到后一天。普通睡眠、通勤、上班、照护和生活活动不计入，也不会被包装成额外的训练任务。〔证1〕

**断了几天，从当天开始。** 不补课、不清零、不比较完成天数、不设及格线。原稿的三条「及格线」已撤除：一份用来陪伴的计划里不该有不及格。掉线之后怎么重启，[第二十一章](Ch21_Personal_Loneliness_System.md)21.5写了四步。〔证5〕

**任何一项让你更难受，就停下来。** 停下来不是做错了，是这一项此刻不适合你。身心类练习的不良体验在文献中确有报告，而且不需要既往心理问题这个前提。〔证3〕

**五种现实约束。** 下面五条都不是「先克服再回来」的门槛，它们直接改写这份计划的用法。〔证4〕

| 你的处境 | 这份计划怎么改 |
|---|---|
| 身边没有一个可以联系的人 | 第三周的前提不成立。跳过整周，改走[第六章](Ch06_Loneliness_First_Aid.md)6.3；那里的替代项与主项同等正当，不是次等方案 |
| 孤独只发生在某段关系里 | 这是关系的时间结构问题，不是独处或连接能力问题。改读[第十八章](Ch18_Loneliness_In_Relationships.md)18.1；第二、三周帮不上这种孤独 |
| 岗位、轮班或环境在孤立你 | 处境造成的孤独只能由处境处理。[第十九章](Ch19_Workplace_Loneliness.md)19.3谈位置带来的没人可说，19.5谈排挤、欺凌与歧视；本书不把它写成你的调节任务 |
| 社交焦虑已经影响上学、上班或出门 | 这可能需要评估，不是练习量不够。先读[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3；第三周涉及开口的动作全部暂缓 |
| 没有可自由支配的时间 | 表里的预算做不到就跳过。把睡眠和照护算成练习任务，是这份计划明确不做的事 |

**本书的一条立场，在这一章同样适用。** 本书不把「学会独处」「主动连接」写成继续留在忽视你的关系、孤立你的岗位或排挤你的环境里的义务。有些孤独是处境造成的，处境造成的孤独只能由处境处理。四周走完之后关系或岗位没有任何改变，那不是这份计划的失败，也不是你的失败——它说明要动的是别的东西。〔证4〕

## 23.3 第一周：理解

这一周不追求想通，也不要求你给孤独归类。所有动作都是Sonus的建议，不是经过验证的疗程。〔证1〕

| 日 | 一个可选动作 | 额外预算 | 做不到时 |
|---|---|---|---|
| D1 | 写下这周的孤独出现在哪个具体时段或场合；也可以只写「说不清」 | 2—5分钟 | 留空，或明天再写 |
| D2 | 读[第一章](Ch01_What_Is_Loneliness.md)1.2与1.4，只看哪一句让你停下来 | 5—10分钟 | 不摘录，不总结 |
| D3 | 在那一句旁边写下一件可以核对的事实（不是「我很孤立」，是「上周有三次我想说话，最后没有发出去」） | 3—5分钟 | 写不出就记「没有」 |
| D4 | 读[第四章](Ch04_Myths_Of_Loneliness.md)七条迷思，看哪一条你其实相信 | 5—10分钟 | 一条也不像，同样允许 |
| D5 | 读[第五章](Ch05_Loneliness_Audit.md)5.1四组观察；也可以整章跳过 | 5—10分钟 | 清点孤独让你更难受就跳过，5.1第二件事写的就是这个 |
| D6 | 自选：重复本周有帮助的一项，或休息 | 0—5分钟 | 两者同样允许 |
| D7 | 回看三问（见23.7） | 3—5分钟 | 只回答其中一问 |

第一周唯一的产出是一件可以核对的事实。它比一个类型有用：类型指向「你是哪一种人」，事实指向下一步能做什么。〔证1〕

「孤独在现代社会里相当普遍」这句话，原稿归给了一部科普读物，本书已撤除这个归属。这一版能说的是：本轮核读的一份综述把孤独界定为**感知到的社会隔离**，并指出威胁警觉与重新连接的愿望会同时提高。这解释了为什么孤独的时候既想靠近人，又容易把靠近读成威胁。它是框架性论述，不是因果已经证明的机制；该综述提到的具体炎症指标效应本轮未核实，本书不引用。〔证6〕

## 23.4 第二周：独处

| 日 | 一个可选动作 | 额外预算 | 做不到时 |
|---|---|---|---|
| D8 | 一个人待五分钟，不带手机；也可以只读[第九章](Ch09_The_Art_Of_Solitude.md)不试 | 5分钟以内 | 提前结束不算没做 |
| D9 | 留意你独处时对自己说话的语气，写下一句原话 | 2—5分钟 | 不分析，不找原因 |
| D10 | 把那句原话改写一次，或写下「我先不改」 | 2—5分钟 | 不必相信改后的说法 |
| D11 | 一个人做一件本来会同别人做的事：吃饭、散步、看展，时长自定 | 自定 | 中途难受就回家，这不是没做完 |
| D12 | 做点什么：写、画、修一样东西，十五分钟以内 | 0—15分钟 | 不求质量，也不求它带来意义 |
| D13 | 停一天屏幕，或不停 | 自定 | 停了更难受，说明这一天不适合停 |
| D14 | 回看三问 | 3—5分钟 | 只回答其中一问 |

**本周不设时长阶梯。** 原稿把独处从十分钟排到三十分钟再排到一小时，并要求逐级加码。这个安排撤除了：身心类练习有焦虑、抑郁等不良体验报告，没有既往心理问题的人也可能出现；而对社交焦虑较重的人，自行加量的暴露练习可能起反作用。任何一天出现心慌、发冷、想逃、麻木或情绪明显变差，当天停止，不补做，也不必向自己解释。〔证3〕

独处的好处也常被讲得过多。本书第九章所依据的独处益处材料本轮未核读，因此这一版不承诺「学会独处就能缓解孤独」，也不声称这七天必然带来任何收益；原稿把一篇本轮未取得原文的精神分析文章当作「独处能力缺失」的底层机制，本书同样不采用这个归因。独处练习的价值可能只是让你知道，难受的时候还有别的去处。那已经够了。〔证8〕

## 23.5 第三周：连接

这一周有一个前提：身边至少有一个可以联系的人。前提不成立的时候不要硬做，见23.2的现实约束第一行。

**「主动开口，不等别人来找你」在本书里不是通则。** 对社交焦虑较重、被拒绝经历较多或正处在关系破裂中的人，它可能带来又一次被忽视。[第六章](Ch06_Loneliness_First_Aid.md)6.2为此保留了失败之后的处置：一次没有回应，不说明你不值得回应，它可能只说明对方那天没有余力。表里所有涉及开口的动作都写着可以不做，这不是排版上的客气，是这一章的立场。〔证4〕

| 日 | 一个可选动作 | 额外预算 | 做不到时 |
|---|---|---|---|
| D15 | 想一个久未联系的人，写下名字；不必发消息 | 1—3分钟 | 想不出来，说明这一周可以跳过 |
| D16 | 若愿意，发一句短消息（「最近想起你」就够） | 1—3分钟 | 写好不发，也算做了一次 |
| D17 | 帮一个小忙，或接受别人帮的一个小忙 | 自定 | 两者都不必勉强 |
| D18 | 在一次日常对话里多说一句真话，或只多问一句 | 0—2分钟 | 说完后悔了，不必撤回，也不必再解释 |
| D19 | 想一想有没有一个固定的场合可以去：同一个时间、同一个地方 | 3—5分钟 | 没有这样的场合，不是你的问题 |
| D20 | 若愿意，约一个人；先问对方是否方便 | 1—5分钟准备 | 对方没有余力，不视为关系失败 |
| D21 | 回看三问 | 3—5分钟 | 只回答其中一问 |

「社会关系较强的人生存可能性更高」是本轮核读过的一份荟萃分析的方向性结论：148项研究、308,849人，比值比1.50（95%置信区间1.42—1.59）。但同一份分析里，测量方式的差异极显著——复杂的社会整合测量得到1.91（1.63—2.23），而「是否独居」这一项只有1.19（0.99—1.44），区间跨越1。也就是说，本书不能对独居的人说，你的处境已经被证明是危险的；这个群体层面的数字也不能用来预测任何一个人。它是观察性研究，不证明因果。第三周值得试，理由不在这里，而在你自己的处境里。〔证7〕

## 23.6 第四周：共处

原稿这一周叫「整合系统」，目标是「把前三周的经验凝结成你的系统」。这一版改叫「共处」，与[第五章](Ch05_Loneliness_Audit.md)5.1的维度四同名。最后一周要决定的不是留下多少，而是哪些部分本来就不该由你处理。〔证1〕

| 日 | 一个可选动作 | 额外预算 | 做不到时 |
|---|---|---|---|
| D22 | 写下这四周里两件都重要、却可能冲突的事 | 3—5分钟 | 不强迫排序，也不选出「真价值」 |
| D23 | 分开写：哪些是你能动的，哪些是处境造成的 | 3—5分钟 | 分不清就都留在纸上 |
| D24 | 在[第二十一章](Ch21_Personal_Loneliness_System.md)记下想保留的一项 | 3—5分钟 | 可以写「一项也不保留」 |
| D25 | 写下两个去向：没有用怎么办，变得更难承受怎么办 | 3—5分钟 | 直接收藏第二十二章也可以 |
| D26 | 写下一件你不再承受的事，或一件你要设立的边界 | 3—5分钟 | 暂时写不出来，不等于边界不存在 |
| D27 | 重读第五章的四组观察，只看现在哪几条让你停下来 | 5—10分钟 | 不对比四周前，不打分，不排名 |
| D28 | 决定继续、换法、停止或寻求支持 | 3—5分钟 | 可以请一个信任的人协助梳理 |

**D27为什么不许对比。** 原稿要求「重做一遍孤独审计，对比四周前」，并「记录变化最大的一维」。第五章的四组观察不计分、不设阈值、不作分类，所以没有分数可以对比，也没有维度可以排名；它同时写明，命中几条不说明任何问题，让你停下来的那一条才有信息量。把一份不计分的观察做成前后测，会造出一个本书拒绝给出的东西：一份进步或退步的判决。〔证5〕

**关于第二十一章21.6那张表。** 该章已按本记录标准重写，原模板里的「主导孤独模式」与「最缺维度／4（理解／独处／连接／转化）」两行已撤除，现为九行，没有分数、分母与保底。D24要记下的那一项就写在那里；写「一项也不保留」同样是填完。〔证5〕

**边界不是失败的选项。** 有些关系可以修，有些不能；对不能修的那一部分，设立边界或离开是正确的动作。这句话是本书伦理红线的一部分。红线的完整成文句、它在全书的两种形式与全部位置见[修订记录](SONUS_RECOMMENDATIONS.md)，本书不修改它。〔证4〕

周遥在这四周里只做了六天，其中有用的一项是「夜里给一个朋友发一句话」，其余都跳过了，D26那一行空着。这不是一份不及格的日历：一项能留下的东西已经找到，而空着的那一行说明周遥此刻还没有要设立的边界，或者还没有力气设立，两种都可以。这是本书的虚构情境，不是访谈、病例报告或测评结果，也不表示所有人的四周都该长这样。〔证9〕

## 23.7 每周回看三问

原稿把它固定在「每周日20分钟」。这一版不固定日子，也不固定时长——固定的日程往往是这份计划最先断掉的部分。任何一天都可以，三分钟也可以。〔证1〕

1. 这周哪一项有用？（留下，不必加码）
2. 哪一项没用，或者让你更难受？（删掉它，不重试）
3. 下周只想做一件，是哪一件？（只写一件）

第三问只写一件，是因为写三件的结果通常是做零件。回看不判断是否「进步」：如果发现自己最需要的是休息、分担或一次评估，那已经说明原先设想的方法未必是第一优先，也可以就此结束这份计划。〔证1〕

## 23.8 第29天，并不只有一种答案

**有帮助，也愿意继续。** 把一项留在生活里，不必立刻加长、加难或加频。〔证1〕

**没有用，也没有更糟。** 可以停止这份计划，回头看看D3写下的那件可核对的事实和现实条件，换一种方法，或找专业人员谈。不要因为已经投入四周，就继续投入来证明之前值得。〔证1〕

**变得更难承受，或出现安全与功能方面的担忧。** 不再用「再坚持一周」作为默认答案。按[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.4的说明获取支持；有即时危险时拨120，需要紧急医疗时不要先打心理热线。身心类练习引起明显不适时可以停止，不把继续完成当作勇敢的证明。〔证2〕〔证3〕

**中间没有继续。** 不需要补写缺失的记录。生活并不欠这张日历一个完整结尾。可以挑一个仍有意义的问题，也可以把它合上。〔证1〕

**四周之后一切照旧。** 这也是一个答案。它可能说明要动的是关系、岗位、城市，或一段没有结束的哀伤，而不是你的练习量。本书不把这种情况写成计划失败，也不写成你的失败。〔证4〕

## 本章速记

- 四周对应第五章的四组观察：理解、独处、连接、共处。不是四个台阶，任何一周可以单独用，也可以不用。
- 每天最多一项可选动作；不打卡、不累加、不设及格线、不比较完成天数。断了从当天开始。
- 这一章撤除了：「转化」这个章名与它的承诺、保底与必做项、三条及格线、孤独类型区分、练习次数、独处时长阶梯、前后对比与维度排名。
- 独处不设加码。心慌、发冷、想逃、麻木或情绪明显变差，当天停止，不补做。
- 第三周有一个前提：身边有一个可以联系的人。前提不成立时走第六章6.3，那里的替代项同等正当。
- 五种现实约束直接改写计划用法，都不是「先克服再回来」的门槛。
- 出现自伤念头、持续低落、无法进食睡眠或上班、幻觉或被监视感、暴力处境：跳过整份计划，先读第二十二章22.1。
- 本书不把自我调节写成留在忽视你的关系或孤立你的岗位里的义务。

读完这一章之后：[随身卡与练习记录](Appendix_Quick_Reference.md)可以存进手机或贴墙；婚内孤独另见[附录小册子 · 婚后孤独](Appendix_Loneliness_In_Marriage.md)。
