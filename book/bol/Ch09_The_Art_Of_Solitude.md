# 第九章 · 独处的能力

> 原稿这一章从「独处的三个层次」讲起：忍受、接受、享受，目标是从忍受走到享受；随后是四条独处的价值（各带一处作者与年份）、一份从5分钟到一天的练习清单（分入门、进阶、高阶）、三条常见问题的回答，以及三条「独处变孤独的信号」加一句推论。
>
> 这一版把重心挪了位置。原稿回答的是「怎么练」，而多数翻开这一章的人先要回答的是另一个问题：**眼下这个难受，是不是练独处能处理的。** 如果它来自一段忽视你的关系、一个排挤你的岗位，或一种需要评估的情绪状况，练独处不会改变它，只会改变你对它的耐受度。所以本章把分流放在第一节，把伦理边界单独写成9.6。〔证1〕〔证9〕
>
> 章名里的「能力」两个字，本章要限定它：独处是一件可以安排的事，不是一项人人必须取得、未取得即为缺陷的资格。

## 9.1 先说清楚：这一章不做什么

下表中的情形，本章其余各节的动作一律不适用，先按右列处理。〔证2〕

| 情形 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或已有计划、意图、无法确保眼下安全 | 拨 **120**（急救、急诊），并请一个可信任的人陪同；心理援助拨 **12356**，它提供心理支持与危机干预，**不替代120**，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 涉及暴力或人身危险 | 拨 **110** |
| 持续两周以上情绪低落，对几乎所有事都提不起兴趣，伴睡眠或食欲改变 | 预约精神科或临床心理科评估。这条界线不该由你自己划，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2、22.3 |
| 一个人待着时涌上来的是恐慌、麻木，或一种比之前更强烈的空 | 停下来，不要加码，也不要在夜里独自继续，见9.4 |
| 独处是为了不去面对一件具体的事（一次冲突、一个决定、一段关系） | 那不是本章这些方向的适应证。先把那件事写下来，见[第六章](Ch06_Loneliness_First_Aid.md)6.12；需要评估的情形见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md) |
| 你独处的处境本身不合理：被排挤的岗位、长期冷漠的关系、无人过问的家庭位置 | 见9.6。这一类不能靠练独处解决 |

三条限定，与本书导航页的约定一致。〔证1〕

1. 本章每一个方向都是可选的。不累计次数，不设时长阶梯，不设完成标准，不要求每天做到。
2. 本章不承诺独处的效果。它不说独处会带来创造、自我发现或更好的关系，因为这些命题本轮都没有取得可核对的支持，见9.2与〔证4〕〔证5〕。
3. 不喜欢一个人待着，不需要被治好。本章不把它写成缺陷。

**原稿说了什么，这一版怎么处置。**〔证10〕

| 原稿说法 | 处置 |
|---|---|
| 「目标：从忍受到接受再到享受。独处是可以练出来的能力」 | 阶梯撤除。三层描述的差异是真的，把它们排成一条必须向上走的线不是，见9.2与〔证6〕 |
| 练习清单分「入门级5–15分钟」「进阶级30–60分钟」「高阶级半天–一天」，并注明「从易到难」 | 时长阶梯整组撤除，与[第二十三章](Ch23_Loneliness_28_Day_Program.md)撤除时长阶梯的处置一致，见〔证6〕 |
| 「自我发现：独处时你才能听到我真正想要什么（Long与Averill，2003）」 | 撤除来源归属。该文未列入本系列任何台账，本轮未取得原文核对，见〔证4〕 |
| 「创造力：多数伟大的作品诞生于独处（Long与Averill，2003）」 | 撤除。「多数伟大的作品」是一个关于历史事实的量化断言，本章没有任何数据，见〔证4〕 |
| 「情绪调节：独处时你学会自己安抚自己（Nguyen、Ryan与Deci，2018）」 | 撤除来源归属。该文未列入本系列任何台账，本轮未取得原文核对，见〔证4〕 |
| 「关系质量：会独处的人社交时更真实（Winnicott，1958）」 | 撤除来源归属与其因果地位，同上，见〔证4〕 |
| 「独处是关系的预习。你先学会和自己相处，才能和别人相处」 | 撤除。它把连接设成一场需要先取得资格的考试，见〔证5〕 |
| 「会独处的人，反而更会社交」 | 已在[第四章](Ch04_Myths_Of_Loneliness.md)迷思二撤除，本章沿用，见〔证5〕 |
| 「焦虑是信号，不是敌人。它在说我还没学会独处」 | 撤除。它把一个可能需要评估、或需要处境处理的反应，解释成个人能力不足，见〔证10〕 |
| 「无聊说明你还没找到自己的节奏」 | 撤除，理由同上 |
| 「刷手机是被动消费，不算独处。独处是主动在场」 | 撤除这条定义门槛。它使多数人实际在做的事一律不合格，见9.3第四项 |
| 「一个人过一天数字断食（不看手机电脑）」 | 撤除其处方地位。屏幕使用的处理属[第十二章](Ch12_Digital_Loneliness.md)，该章亦不设无屏幕日，理由见其12.6 |
| 「独处变孤独的信号」并推出「你需要的是连接，不是独处」 | 信号保留为描述，推论撤除。三条都可以由处境造成，见9.5 |

## 9.2 三个层次：一把被撤掉的尺子

原稿的三层是这样的：忍受（被迫独处、煎熬、想逃）、接受（可以独处、不痛苦）、享受（主动选择、充实、滋养、创造、成长）。

**这三层描述的差异是真的。** 一个人被迫独处时煎熬，与他安排了一段时间独处时平静，这两种经验确实不同。把它们分开说，有帮助。

**但把它们排成一条向上的阶梯，会产生三个具体的坏处。**〔证6〕

其一，它给独处设了一条及格线。停在「忍受」的人不再只是难受，而是多了一项未完成的任务。这本书的其他章节已经反复拆掉这种线：[第二十三章](Ch23_Loneliness_28_Day_Program.md)撤除了每日保底与三条及格线，[第五章](Ch05_Loneliness_Audit.md)5.1的四组观察明写不计分、不设阈值、不作类型分类。

其二，它把处境写成了阶段。一个照护者没有属于自己的时间，一个被架空的员工在工位上无处可去，一个与家人同住而没有独立房间的人连关门都做不到。这三种人的独处是「忍受」，原因不在他们的修养进度上。让他们从忍受练到享受，等于把条件的问题转成个人的问题。

其三，它假定享受是终点，而这个终点普遍可及。有些人一生不喜欢一个人待着。这不是需要修复的地方。

**这一版留下两个问题，代替那把尺子。** 它们与[第四章](Ch04_Myths_Of_Loneliness.md)迷思二用的是同一组：

| 问什么 | 怎么看 |
|---|---|
| 是你选的，还是你退到那里的 | 主动的独处是你安排的；退缩是你取消了三件事之后剩下的 |
| 一个人待着之后，是充实还是更空 | 这一条比上一条更可靠，因为它看的是结果不是动机 |

两个问题都不打分，也不产生等级。它们只用来决定下一步该做什么，见9.5。

**原稿那句「独处是关系的预习」也要撤掉。** 它的意思是：先学会和自己相处，才能和别人相处。这句话把连接设成一场需要资格证的考试，而资格证由独处颁发。[第四章](Ch04_Myths_Of_Loneliness.md)迷思二已经处理过同一句话的另一半（「会独处的人反而更会社交」），当时的处置是：这是一条没有来源的因果断言；可以说的是一件更弱也更实用的事——当社交是你唯一的出口时，社交会变得很难，因为你没有别的地方可退。本章沿用那一条，不再加码。〔证5〕

## 9.3 可以试的方向

下面几项都不是处方，也不构成一套应当按顺序完成的课程。挑一项，或者一项都不挑。每项写明现实前提，前提不成立时该项不适用，**不适用不是你的错**。〔证1〕

**一、一段没有任务的安静。**

坐在一个地方，什么都不安排。不要求时长；两分钟也可以，中途起身也可以。

现实前提：你有一处可以不被打断的地方。这一条比它看起来重要。与家人同住而没有独立房间的人、住宿舍的人、在开放工位上的人，这个前提常常不成立。它不成立时这一项做不到，原因在空间，不在你。

停止条件见9.4。

**二、用手做一件事。**

写、画、做饭、修理、种植、缝补、拼装。做法对应[第六章](Ch06_Loneliness_First_Aid.md)6.7的创造转移，本章不重复其内容，也不承诺它会带来任何作品，或任何创造力的提升。

现实前提：材料与体力。一项需要花钱的材料，在预算紧张时不是可选项。

**三、走路。**

现实前提：一处可以走的地方，以及身体条件允许。夜间不适用：[第八章](Ch08_Night_And_Weekend.md)8.4明写6.8出门在夜里的前提常常不成立，这一条沿用。

**四、背景音。**

这一项是为[第五章](Ch05_Loneliness_Audit.md)5.1维度二里那一行写的：「需要持续的背景音才能忍受一个人」。

原稿对这类做法的态度是否定的——它说刷手机是被动消费、不算独处，独处是主动在场。这一版不这样写，理由有三。〔证7〕

第一，那条定义把门槛设在动机的纯度上，而动机无法自查。一个开着电视吃饭的人，没有办法判定自己是在被动消费，还是在过日子。

第二，对独居的人，一间屋子里的另一个声音确实改变了房间的性质。收音机、播客、电视、楼下的人声，都不是同一件事，但都使房间不再是完全空的。把它算作作弊，等于宣布一种很多人赖以过日子的安排是无效的。

第三，这条定义与本书其他章节的立场冲突。[第六章](Ch06_Loneliness_First_Aid.md)6.5把声音连接列为可选项，并没有要求它是双向的。

**要不要减少背景音，取决于它之后你更空还是更平静，不取决于它算不算真正的独处。**

诚实的另一面：如果背景音是为了盖住某种你不想听见的东西——一件具体的事、一段关系、一个念头——那么要处理的不是背景音，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)。

**五、一个人去做一件本来以为需要别人的事。**

吃饭、看展、看电影、坐一趟车去一个没去过的地方。

现实前提：可负担；地点对你安全；一个人去不会因此被为难。第三条不是想象——一个人在餐厅感到被注视，是真实的社会评价，不是你想多了。

**六、不安排独处的许可。**

这一条不是方向，是许可：你不需要学会享受独处，本书也不把不享受独处记作你的一个问题。

## 9.4 什么时候停下来

**停止条件（这一条比方向重要）。** 身心类练习存在焦虑、抑郁等不良体验的报告，没有既往心理问题的人也可能出现。如果独处时涌上来的是恐慌、麻木、发冷、心慌，或者一种比之前更强烈的空，停下来，不要加码，也不要在夜里独自继续。那不是练得不够。事后长时间耗竭，同样算。〔证3〕

**不要自行加量。** 原稿的清单是一条递增线：5分钟、30分钟、半天、一天，并建议「从5分钟开始，逐渐延长」。这类把练习时长当作剂量、由读者自行递增的做法，台账给出的判断是它可能起反作用；[第四章](Ch04_Myths_Of_Loneliness.md)迷思二的停止条件与此一致。〔证3〕

**一个区分。** 独处时反复出现的，如果是同一件具体的事——某段关系、某个岗位、某次没有说出口的话——那是信息，不是练习不到位。去处在[第五章](Ch05_Loneliness_Audit.md)5.2与[第十九章](Ch19_Workplace_Loneliness.md)19.5。

**「用别的东西填满空隙」这件事怎么看。** 原稿把刷屏、购物、加班列为需要纠正的逃避。[第十九章](Ch19_Workplace_Loneliness.md)19.3也提到过一种相关情形：用工作填满所有空隙，以免面对安静。本章换一个问法：不问它是不是逃避，问它有没有代价。

| 问什么 | 如果答案是「有」 |
|---|---|
| 停下来之后，是不是有一件具体的事会浮上来 | 那件事才是要处理的对象，见上面「一个区分」 |
| 它是不是已经花掉了钱、睡眠或健康 | 这属于成瘾与睡眠问题的范围，见[《平静之书》第九章](../bop/Ch09_Body_Foundation.md)与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md) |
| 它是不是让你错过了本来想做的事 | 这是一个安排问题，不是一个意志问题 |
| 三个都答「没有」 | 那么它可能只是你在过日子。本书不把它记为缺陷 |

**原稿那三条常见问题的回答，本章重写。**〔证10〕

「我一个人就焦虑。」原稿说：从5分钟开始逐渐延长，焦虑时用急救技术，并记住焦虑在说「我还没学会独处」。前一半保留——急救技术见[《平静之书》第六章](../bop/Ch06_First_Aid_Toolkit.md)；后一半撤除。焦虑不是在报告一项技能的缺失。它可能来自需要评估的状况，可能来自处境，也可能没有可归的原因。递增时长是一个未经支持的处方，见上。

「我一个人就无聊。」原稿说：无聊说明你还没找到自己的节奏，试创造类活动，别用消费类打发。前一句撤除，理由同上。后一句降为一个可能：9.3第二项是用手做一件事。它不是无聊的解法，本书没有它有效的数据。

「我一个人就想刷手机。」原稿说：设一个无手机独处时段，手机放另一个房间。本章不这样开处方。屏幕使用的处理属[第十二章](Ch12_Digital_Loneliness.md)，本章不代替它，也不引用它的具体做法。那一章12.5问的是刷屏在替你做什么，而不是它算不算真正的独处，与本章9.3第四项同一条路：动机无法自查，所以不按动机判优劣。

## 9.5 该补的是连接，还是该留的是独处

[第五章](Ch05_Loneliness_Audit.md)5.1把这一节列为兜底入口：先看两件事——它是否只在某个特定处境里出现，是否已持续两周以上或影响到吃饭、睡觉、上班；两问都答否，才轮到这里。

原稿给的答案是三条信号加一句推论：独处后感到空虚而不是充实、独处时反复想「没人陪我」、独处变成逃避社交的借口；出现这些，你需要的是连接，不是独处。**推论太硬。** 三条信号都可以由处境造成，也可以由需要评估的状况造成，本章无法区分。

这一版的问法只有一条。它不判定类型，只决定下一步。〔证1〕

**这两周里，有没有任何一次「一个人在场」的时刻，是你自己安排的？**

| 答案 | 说明什么 | 去哪里 |
|---|---|---|
| 一次都没有 | 缺的不是独处的技巧，也不是连接的技巧，是选择权。先处理选择权：空间、时间，以及不必向谁交代 | 9.3第一项的现实前提；[第十八章](Ch18_Loneliness_In_Relationships.md)18.7、[第十九章](Ch19_Workplace_Loneliness.md)19.5 |
| 有，且之后更空 | 这不是独处的问题。它更接近[第五章](Ch05_Loneliness_Audit.md)5.2第六种「有人陪仍然空」 | [第十一章](Ch11_Self_Companionship.md)、[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2 |
| 有，且之后平静 | 你不需要这一章 | —— |
| 有过，但想不起来之后是什么感觉 | 常态。下一次留意一下就够了，不需要补做记录 | 9.3 |

**连接与独处不是二选一。** 原稿把它们写成一条岔路，走到哪一边取决于三条信号。实际情况是：多数人的问题不是选错了方向，而是两边都缺，或者两边都不可选——想连接时没有可联系的人，想独处时没有一扇可以关上的门。这两件事都不是方向错误。

**为什么「想连接却又退缩」不是矛盾。** 本轮核读的[S24](../SOURCES_SCIENCE.md#s24)摘要把孤独界定为「感知到的社会隔离」，并指出威胁警觉与重连的意愿会同时提高。据此可以说的是一件描述性的事：一个人可能同时很想有人在场，又在有人的场合里更紧张。这不是想不清楚，也不是不够真诚。这一条是综述级的概括，不构成因果，不能用来预测任何一个具体的人会怎样，也不支持任何练习的效果。〔证8〕

## 9.6 独处不能练成对处境的适应

这是本章最需要写清楚的一节，因为整章的形式都在朝相反的方向推：一份清单、几个方向、几段练习，读起来像是「你只要开始做就会好转」。〔证9〕

**本书的一条立场，在这一章同样适用。** 本书不把「学会独处」「主动连接」「把孤独转化成意义」写成继续留在忽视你的关系、孤立你的岗位或排挤你的环境里的义务。有些孤独是处境造成的，处境造成的孤独只能由处境处理。

把它写成个人的能力缺口，结果是双重的：条件没有变，而多了一条自我指控。

**练独处不能改变条件，它只改变你对条件的耐受度。** 耐受度提高有时候是好事——它使你在一段暂时无法离开的处境里少受一点伤。有时候它是坏事——它使人继续留在本不该留的地方，并且因为「我已经能适应」而不再觉得需要改变什么。本书不替你判断眼下是哪一种，但拒绝把它写成义务。

| 你的处境 | 要处理的是什么 | 去哪里 |
|---|---|---|
| 伴侣或家人长期冷漠、贬低、控制 | 关系本身。承受不是义务 | [第十八章](Ch18_Loneliness_In_Relationships.md)18.1、[婚后孤独附录](Appendix_Loneliness_In_Marriage.md)A.1 |
| 岗位上被排挤、架空、欺凌或区别对待 | 处境本身，走记录与外部渠道 | [第十九章](Ch19_Workplace_Loneliness.md)19.5 |
| 家庭里没有人问你、没有你的位置 | 不是练独处。那是位置的问题 | [第五章](Ch05_Loneliness_Audit.md)5.2、[第十八章](Ch18_Loneliness_In_Relationships.md)18.3 |
| 长期超时、责任超出授权，没有时间属于自己 | 时间与边界，不是耐受度 | [《力量之书》第六章](../bos/Ch06_Power_First_Aid.md)6.2 |
| 独处的困难来自没有空间、没有可负担的去处 | 条件。9.3的现实前提就是为此写的 | 9.3 |

**一句实话。** 如果读完这一章你的感受是「原来我还没学会独处」，那不是这一章的目的，也不是一个应当留下的结论。

## 本章速记

- 先过分诊。有伤害自己的念头：拨120并请人陪同，12356提供心理支持但不替代120；涉及暴力拨110；持续两周以上的情绪低落与功能受损需要评估。
- 「忍受／接受／享受」三层描述的差异是真的，把它们排成必须向上走的阶梯不是。阶梯会给独处设及格线，把处境写成阶段，并假定享受是普遍可及的终点。
- 代替那把尺子的是两个问题：是你选的，还是你退到那里的；一个人待着之后，是充实还是更空。它们不打分。
- 六个方向都带现实前提：一处不被打断的地方、材料与体力、可以走的地点、可负担且不被为难的去处。前提不成立时该项不适用，不适用不是你的错。第六项是许可——你不需要学会享受独处。
- 背景音不算作弊。要不要减少，看它之后你更空还是更平静，不看它算不算真正的独处。唯一的例外是：它被用来盖住某件你不想听见的事。
- 停止条件比方向重要：恐慌、麻木、发冷、心慌，或比之前更强烈的空，停下来，不加码，不在夜里独自继续；事后长时间耗竭同样算。不要自行递增时长。
- 三处作者与年份（Long与Averill、Nguyen与Ryan与Deci、Winnicott）本轮均未列入台账、未取得原文核对，来源归属全部撤除；「多数伟大的作品诞生于独处」「独处是关系的预习」「会独处的人反而更会社交」三条一并撤除。
- 该补连接还是该留独处，只问一条：这两周里有没有一次一个人在场的时刻是你自己安排的。一次都没有，缺的是选择权，不是技巧。
- 练独处不改变条件，只改变耐受度。本书不把学会独处写成留在忽视你的关系、孤立你的岗位或排挤你的环境里的义务。
