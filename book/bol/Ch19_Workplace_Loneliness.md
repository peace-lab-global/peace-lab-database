# 第十九章 · 职场孤独

> 原稿这一章的第一句是「职场是成年人最主要的社交场所，也是孤独的高发地」。这句话本书不作断言：它是一个方向上合理的观察，但本轮没有核读到支持它的数据，「最主要」与「高发」都是程度词。这一版把它降级为编写立场。〔证6〕
>
> 这一章先处理一件更重要的事：**分清哪些职场孤独是处境造成的。** 处境造成的孤独只能由处境处理。

---

## 19.1 先分清：哪些不是这一章能处理的

下表中的情形，本章的动作一律不适用，先按右列处理。〔证1〕〔证2〕

| 情形 | 去哪里 |
|---|---|
| 被系统性地排挤：被移出沟通渠道、被架空、被分配不可能完成的任务、被集体忽视 | 用人单位的合规与申诉渠道；工会；劳动保障监察或法律途径。**这是处境问题，不是你的连接能力问题** |
| 遭遇欺凌、骚扰、威胁、贬低或人身不安全 | **110**；同时走合规与申诉渠道、工会或法律途径。状态调节不解决伤害，有时还会因为「我能扛」而延长伤害 |
| 因性别、户籍、地域、年龄、身体状况、婚育状况或派遣身份被区别对待 | 这是歧视，走申诉与法律途径；本书不为它提供任何情绪调节方案 |
| 被要求长期超时、无休息，或承担超出授权与能力的责任 | 拒绝、协商、上报或离开，见[《力量之书》第六章](../bos/Ch06_Power_First_Aid.md)6.2。不需要把自己调到能承受 |
| 出现自伤念头、觉得活着没有意义 | **12356**；已有立即生命危险或已采取行动，拨 **120**。不等本章读完 |
| 持续数周无法进食、睡眠或上班，情绪低落到对平时在意的事也提不起劲 | 精神科或临床心理专业评估，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3 |

三条限定与[第六章](Ch06_Loneliness_First_Aid.md)6.1一致：心理热线不是急救；本书不对12356各地实时可用性作保证，未做拨测；不要等到「足够严重」才求助。其他地区资源见[危机资源清单](../../规范/CRISIS_RESOURCES.md)。〔证2〕

**本章撤除了原稿的四样东西。** 撤除的理由写在下面，因为它们决定了这一章怎么用。〔证5〕

| 原稿写了什么 | 这一版怎么处理 |
|---|---|
| 「职场是成年人最主要的社交场所，也是孤独的高发地」作为开篇断言 | 降级为编写立场。本轮未核读到支持这一程度表述的数据，本章不用它推出任何结论 |
| 「面对面的时间不可替代（Cacioppo与Patrick，2008）」 | 撤除来源归属。那是一部大众科普读物，本轮仅取得书目，台账明确写着该条目不提供任何实质命题支持；方向性的表述保留为Sonus整理，标为未核实 |
| 「主动约人：不等别人邀请你」作为通则 | 撤除通则地位。[第五章](Ch05_Loneliness_Audit.md)5.1维度三写明这一条在本书里不是通则；[第六章](Ch06_Loneliness_First_Aid.md)6.2保留了失败之后的处置 |
| 「示弱是强者的特权」 | 撤除。这是一句修辞，而且它对下位者不成立：在权力不对等的场合，先暴露脆弱的一方常常承担更多风险 |

## 19.2 新到一处：一切从零开始

**画面。** 搬家、换城市、换工作，一切从零开始；老朋友渐远，新朋友未建；周末不知道去哪。

**先说归因。** 这是流动性的代价，不是你的社交能力出了问题。[第二章](Ch02_Why_Loneliness_Hurts.md)2.5写明「典型轨迹」这个说法有它的适用范围：它预设了受过高等教育、有能力跨城市迁移、收入随年龄增长。它没有覆盖留在家乡的人，因照护、身体或经济原因不能搬的人，关系被冲突而不是被距离打断的人，以及在一个地方住了三十年、看着周围的关系一样样消失的人。后面几种的孤独与搬家的孤独不是同一件事，本章不用同一段话解释它们。〔证7〕

**可以说的：** 深度关系需要时间，而时间不能压缩。搬家之后旧关系变淡、新关系还没长起来的那一段，是一个真实的空档，不是你不会交朋友。这句话方向上可信，但本书所依据的相关材料本轮仅取得书目、未核读原文，因此不作为已证结论。〔证8〕

**几个可选的方向，不是清单。** 挑一个，做一半，或者读完什么也不做，都是允许的。〔证3〕

- **有一个固定去处。** 一家咖啡店、一个健身房、一个图书馆，固定时间去。这一项有三个前提：有可支配的钱，有一个你能安全进入的公共场所，有可以自由支配的时间。缺任何一条它就不适用，不是你没做对。
- **保持旧连接。** 新关系需要时间，旧关系需要维护。给一个老朋友发一句话就够，不必约见面。
- **进入一个已有结构的场合。** 有固定成员和固定活动的场合，比一次性聚会更容易长出关系，因为你不需要每次都重新开口。见[第二十章](Ch20_Community_And_Tribe.md)。
- **关于「主动约人」。** 这一项写在最后，因为它不是通则。对社交焦虑较重、被拒绝经历较多的人，主动开口可能带来又一次被忽视。愿意时可以试；一次没有回应有多种解释，其中最常见的一种是对方那天没有余力，它不说明你不值得回应。〔证4〕

**停止条件。** 如果这些尝试让你更难受——每次出门前都要做很久的心理准备，或者事后反复回想自己说错了什么——停下来说明这一项此刻不适合你。已经影响上学、上班或出门的社交焦虑是需要评估的情形，不是性格；自行加量的暴露练习对它可能起反作用，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3。〔证9〕

## 19.3 位置越高，越没人可说

**画面。** 不能对下属示弱，不能对同级交心，不能对上司暴露；决策只能自己扛。

**先说归因。** 这多数是角色结构造成的隔离，不是你不会交朋友。[第五章](Ch05_Loneliness_Audit.md)5.2第五种已经写下这一点，也要说诚实的另一半：结构并不总能改变，有时「不能对下属示弱」确实是制度安排。〔证10〕

**这一节要做的不是改变自己，是另建一条线。** 与工作角色无关、也不随职位变动而失效的关系，需要单独建立。〔证3〕

- **找一个不在你权力结构内的人。** 教练、咨询师、圈外朋友都可以。前两项要花钱，这是真实的门槛，本书不假装它不存在；付不起的时候，圈外的老朋友与本行以外的人是同样正当的选项。
- **同侪场合。** 其他带团队的人处境相近，不需要解释前提。这一项的前提是你能接触到这样的场合；接触不到时，它不是一项你没做到的作业。
- **保持非工作身份。** 你也是朋友、家人、某个爱好的人。这一条不是心灵安慰，它有一个具体作用：当职业角色出问题的时候，还有别的地方可以站。
- **关于「示弱」。** 原稿写「示弱是强者的特权」，本章撤除这句话。对下位者它不成立：在权力不对等的场合，先暴露脆弱的一方常常承担更多风险。要说真话的时候，先判断这个场合说了会不会有代价——这不是怯懦，是必要的评估。〔证5〕

**停止条件。** 如果「找一个局外人」这件事本身让你更焦虑，或者你发现自己开始用工作填满所有空隙以免面对安静，这两条都不是本章能处理的：前者见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)，后者见[第九章](Ch09_The_Art_Of_Solitude.md)与[第十二章](Ch12_Digital_Loneliness.md)。〔证9〕

## 19.4 远程与轮班：一天没说话

**画面。** 在家办公，一整天没有说过话，收工时感到被世界遗忘；或者轮班、夜班，作息与身边的人错开。

**先说归因。** 这两种都是岗位安排造成的隔离。远程与轮班减少了偶发接触的机会——那些不在日程里、却构成关系大部分内容的照面。这不是你不会主动，是结构里没有留给主动的位置。〔证10〕

原稿在这一节写「面对面的时间不可替代」，并把它归给一部科普读物。归属已撤除；方向性的表述保留为Sonus整理：偶发接触减少会削弱关系，这与[第二章](Ch02_Why_Loneliness_Hurts.md)2.3的结构性来源一致，但本书未核读到可直接支持它的一手研究，标为未核实。〔证8〕

**几个可选的方向。**〔证3〕

- **把一次工作会议换成一次能看到脸的通话。** 前提是这样的同事存在，且对方愿意。对方不愿意的时候不要坚持，那不是关系失败。
- **换一次工作的地点。** 咖啡店、共享办公空间、图书馆。有人在场本身是一种低压力的连接：不需要说话，也不需要被回应。这一项同样有金钱与时间的门槛。
- **固定一天到岗。** 原稿写「每周固定一天去办公室（如果可能）」。「如果可能」这四个字要当真：很多岗位没有这个选项，包括远程合同、跨时区团队与轮班制。没有这个选项时，它不是一项你放弃了的作业。
- **非工作话题。** 原稿写「关系是在非工作话题中建立的」，那是一个因果断言。本章把它降级为观察：多数人说，关系里确实有一些内容只出现在非工作话题中。愿意时可以试一句，试了没有回应也不是你的错。〔证5〕
- **轮班与夜班。** 作息错开是这一类岗位最难的部分，因为它同时动到睡眠与关系。睡眠本身的处理见[《身体之书》](../bob/INDEX.md)；本书不把它写成心态问题。

**停止条件。** 如果「每天约一个同事视频通话」这类安排让你更紧张，或者你发现自己开始为了填满时间而接受本来不想接受的邀约，停下来。原稿把这一项写成每天一次的固定剂量，本章撤除剂量：本书没有对任何频率做过验证。〔证5〕〔证9〕

## 19.5 处境造成的隔离：排挤、欺凌与歧视

原稿这一章没有这一节。它是本章最重要的一节，因为前面三节讲的都是可以调节的部分，而这一节讲的是不能。

**被安排的孤立长这样：** 被移出沟通渠道，会议不再叫你，信息到你这里就断掉；被分配不可能完成的任务，然后以未完成为由评价你；被集体忽视，说话没有人接；因为性别、户籍、地域、年龄、身体状况、婚育状况或派遣身份被区别对待。

**这些不是社交技巧问题，本书不为它们提供任何调节方案。**〔证1〕

**路径，按通常的代价从低到高。** 编号不是优先级：有即时危险时，最后一条是第一条。

1. **留下记录。** 时间、场合、涉及的人、说了什么做了什么。这一步不需要告诉任何人，它的作用是让后面每一步都有可核对的东西，而不是只有你的感受。
2. **用人单位的合规与申诉渠道。** 有些单位有，有些没有，有些有但不运转。这一条的真实代价本书不掩盖：申诉可能带来报复，尤其在权力不对等而你又没有退路的时候。
3. **工会或职工代表。** 没有工会的单位，这一项不成立。
4. **劳动保障监察与法律途径。** 涉及歧视、骚扰、违法解除劳动合同或长期超时的，这一条是正式渠道。本书不提供法律意见，具体权利与时效请咨询执业律师或当地劳动部门。
5. **人身不安全时拨110。**

**关于「离开」。** 本书把离开列为一个正确的动作，不是失败的选项。这句话与[第十八章](Ch18_Loneliness_In_Relationships.md)18.1、[第四章](Ch04_Myths_Of_Loneliness.md)迷思六、[婚后孤独附录](Appendix_Loneliness_In_Marriage.md)A.1与[第二十三章](Ch23_Loneliness_28_Day_Program.md)23.6措辞一致，本书不修改它；[第五章](Ch05_Loneliness_Audit.md)5.1载的是同一立场的自我调节版，两种形式的分别见[修订记录](SONUS_RECOMMENDATIONS.md)。同时要说诚实的另一半：离开有真实代价，包括收入、签证与合同、照护责任和再就业的时间。这些代价由你自己衡量，本书不替你决定，也不把「留下来继续调节」写成更成熟的选择。〔证5〕

**如果你暂时不能离开。** 这时状态层面的动作有它真正的位置——不是代替改变，而是在无法立刻改变时让你不至于崩溃。即便如此，本书也不承诺你能长期扛住：能扛多久取决于处境，不取决于你练得够不够。这一句与[《力量之书》第六章](../bos/Ch06_Power_First_Aid.md)6.2完全相同。〔证5〕

## 本章速记

- 先过分诊：被排挤、被欺凌、被歧视、长期超时无休、自伤念头、无法上班，都不在本章范围内，走外部渠道或专业评估。
- 三种常见画面：新到一处、位置越高越没人可说、远程与轮班。前两种多数由流动性与角色结构造成，第三种由岗位安排造成，都不是社交能力问题。
- 本章撤除了：开篇的程度断言、「面对面不可替代」的来源归属、「主动约人」的通则地位、「示弱是强者的特权」、「每天一次视频通话」的固定剂量。
- 每一项都写了现实前提。缺钱、缺时间、缺一个能安全进入的公共场所、缺一个愿意的对方，都让那一项不适用，不是你没做对。
- 被安排的孤立走记录、申诉、工会、劳动监察与法律途径；人身不安全时拨110。申诉有真实代价，本书不掩盖。
- 离开是正确的动作，不是失败的选项；但离开的代价由你自己衡量，本书不替你决定。
- 暂时不能离开时，状态层面的动作有它的位置，本书不承诺你能长期扛住。
