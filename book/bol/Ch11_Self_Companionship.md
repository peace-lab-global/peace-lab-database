# 第十一章 · 自我陪伴

> 原稿这一章从一句话开始：孤独的最深层解药，是「我是自己最好的朋友」。随后五节：模板、自我对话审计、自我关怀三要素、自我接纳、日常练习。
>
> 这一版撤掉了「解药」，也撤掉了另一句更要紧的话——「你如何对待自己，就如何对待别人，也就允许别人如何对待你」。后半句把别人怎样对待你，写成了你自己造成的。这与第十八章18.1、第十九章19.5的立场相反，也不是一个有数据的结论。〔证1〕〔证6〕
>
> 这一版把原稿混在一起的三件事分开：你对自己说话的**语气**、那句话说的**内容**是不是真的、以及那句话**是谁的**。三件事的处置完全不同，混在一起时最容易发生的错，是让一个人去修正一句本来不属于他的话。

## 11.1 先说清楚：这一章不做什么

下表中的情形，本章其余各节一律不适用，先按右列处理。〔证2〕

| 情形 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或已有计划、意图、无法确保眼下安全 | 拨 **120**（急救、急诊），并请一个可信任的人陪同；心理援助拨 **12356**，它提供心理支持与危机干预，**不替代120**，见[第六章](Ch06_Loneliness_First_Aid.md)6.1与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 涉及暴力或人身危险 | 拨 **110**；离开该处境优先于任何情绪调节 |
| 对自己的贬低已持续数周，并影响进食、睡眠、上班上学 | 这是需要评估的情形，不是语气问题。语气调不回来不代表你练得不够，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3 |
| 你在一段长期被贬低、被控制的关系里，并且已经开始相信「我确实不够好」 | 那是对方的话，不是你的评估。要处理的是关系，见11.4与[第十八章](Ch18_Loneliness_In_Relationships.md)18.1、18.7 |
| 眼下确实一个人也联系不上 | 先看[第六章](Ch06_Loneliness_First_Aid.md)6.3 |
| 「和自己相处」这件事本身让你更难受 | 见11.5的停止条件与[第九章](Ch09_The_Art_Of_Solitude.md)9.4 |

三条限定，与本书导航页的约定一致。〔证1〕

1. 本章每一项都是可选的。不累计次数，不设阶梯，不设完成标准，不要求每天做到。
2. 本章不承诺对自己好一点会带来连接、情绪改善或任何可测的结果。理由见11.3关于[P03](../SOURCES_PRACTICE.md#p03)的说明。
3. 本章不评估你「够不够爱自己」，不给这一项打分，也不设及格线。

**原稿说了什么，这一版怎么处置。**〔证7〕

| 原稿说法 | 处置 |
|---|---|
| 「孤独的最深层解药，是『我是自己最好的朋友』」 | 「解药」与最高级撤除。本书已在第八章、第十章、第二十章等处撤除同一表述；它把一个复杂过程压成一个可以达成的状态，达不成时只多一层失败 |
| 「你如何对待自己，就如何对待别人，也就允许别人如何对待你」 | 整句撤除。后半句把他人行为归因于你自己，与[第十八章](Ch18_Loneliness_In_Relationships.md)18.7、[第十九章](Ch19_Workplace_Loneliness.md)19.5「处境造成的只能由处境处理」直接冲突，见〔证6〕 |
| 「对自己苛刻的人，对别人也苛刻（或允许别人对自己苛刻）」；「对自己温柔的人，对别人也温柔」；「不爱自己的人，很难相信别人爱自己」 | 三条通则一并撤除，本书无数据。第一条自身就给了两个相反的方向（苛刻对人，或允许被苛刻），这使它无法被任何观察反驳——一个不会被反驳的命题不该用来解释读者的处境 |
| 「自我对话审计（10 分钟）：回想最近一次你犯错／失败／出丑的时刻」 | 撤除。[第五章](Ch05_Loneliness_Audit.md)5.1已写明「清点自己」这件事对很多人会在原有难受之上再加一层；而让一个正在自我贬低的人从回忆自己最出丑的时刻开始，是把最难的入口放在最前面 |
| 「孤独的一个深层燃料是自我拒绝：『我不够好，所以没人喜欢我』」 | 因果归因撤除。这句话有时是自己的判断，有时是别人的话留下来的，有时是对一个处境的描述被误当成对自己的评价，三者处置不同，见11.4 |
| 「列出你的『不够好』清单」 | 撤除。这是要求读者枚举并保存自己的缺陷。本书不设这样的作业 |
| 「改写：『我不完美，但我值得被爱，不是因为我的成就，而是因为我是我』」 | 撤除。它是一个要求被相信的积极断言，与[第三章](Ch03_The_Physiology_Of_Loneliness.md)3.8「入口是行为，不是道理」、[第十章](Ch10_The_Art_Of_Connection.md)10.5、[《平静之书》第十二章](../bop/Ch12_Cognitive_Tools.md)「重点是联系证据，不是强迫相信积极暗示」三处已写定的表述冲突 |
| 「自我接纳不是『我很好』，而是『我有缺点，但我仍然值得被爱』」 | 定义地位撤除。它把接纳设成一个必须先赢下的辩论，而[《平静之书》第十三章](../bop/Ch13_Self_Compassion.md)13.3明写这种朴素的照顾「不要求先完成一场关于自我价值的辩论」 |
| 「每日练习（选一个）」四项：晨间自我对话、自我关怀 Break、睡前感恩、自我约会 | 打卡结构撤除。改列11.5的可选方向，各带现实前提与停止条件。「睡前感恩：写今天我感谢自己做的三件事」另撤除——它要求每天找出三条，找不到时那一天就是一次失败 |
| 「自我约会：每周安排一次」 | 剂量撤除。第九章9.3已撤除同类时长与频次安排 |
| 「自我关怀三要素（Neff，2003）」 | 概念保留，改依[P02](../SOURCES_PRACTICE.md#p02)并照录其边界，见11.3 |
| 「一分钟自我关怀练习」 | 保留，但降级为编排，并明写它不是从效果研究里推出来的，见11.3 |
| 「孤独的人以为自己是孤岛，其实整个群岛都在孤独」 | 修辞与事实分离，沿用[第四章](Ch04_Myths_Of_Loneliness.md)4.2的处置：这句话可以让人不那么孤立，但它不是一个关于人数的结论 |

## 11.2 语气、内容、出处：三件被混在一起的事

原稿把自我对话当成一个问题：语气不对，所以改写它。这一版分成三件，因为它们能分开处理，而且分开之后才知道哪一件不归你管。〔证1〕

| 这是哪一件 | 它是什么 | 能做什么 | 归谁 |
|---|---|---|---|
| **语气** | 你在难受的时候，是否对自己追加贬损。「我又搞砸了」之外再加一句「我就是这样的人」 | 可以调，而且不需要先改变任何信念：停止加句就够了。见11.5第一项 | 你 |
| **内容** | 那句话说的事情是不是真的。「我这次没有做好」与「我做不好任何事」是两个不同的命题 | 查证据，不改语气。[《平静之书》第十三章](../bop/Ch13_Self_Compassion.md)13.4那张表做的就是这件事：把批评原话与可核对的事实并排写下来 | 你 |
| **出处** | 这句话最初是谁说的。有些「我不够好」不是评估，是某个人的话被说过很多次之后留下来的 | 把它还原成一句有人在某个时刻说过的话，见11.4 | **不一定归你** |

**为什么必须分开。** 如果它是语气，调语气有用；如果它是内容，调语气只是给一句错的判断换了个柔和的声调，判断还在；如果它是出处，那么修正你自己是完全走错的方向——要处理的是把那句话放回说它的人那里。〔证1〕

原稿的改写练习之所以不成立，正是因为它把三件事当成一件：用「我犯了一个错误，这很正常」去替换「我真蠢」。如果那句「我真蠢」本来是你自己的判断，这个替换是在用一句未经查证的话盖掉另一句，与[第十章](Ch10_The_Art_Of_Connection.md)10.5撤除认知重构句的理由相同。〔证6〕

## 11.3 自我关怀：一个概念，不是一套成绩

Neff的概念论文把自我关怀描述为三个相互联系的方面：**善待自己、共同人性、正念觉察**。它关注的是面对痛苦和不足时的态度，不要求先证明自己优秀，也不等同于提高自我评价。〔证3〕

照录台账的边界，因为它们决定了本章能用这个概念做什么：[P02](../SOURCES_PRACTICE.md#p02)载明，概念定义与区分为**高**，但未通读全文，不据理论证明个体改变；**不能把自尊、成就感或积极自我评价直接改名为自我关怀**；论文的理论预期不是干预效果检验，也不证明一句安慰语能治疗抑郁。〔证3〕

孤独版的中文释义沿用[《平静之书》第十三章](../bop/Ch13_Self_Compassion.md)13.3，本章不另立新说：〔证5〕

| 方面 | 在孤独里它是什么 | 它不是什么 |
|---|---|---|
| 善待自己 | 不再追加贬损，同时照顾眼前需要（吃饭、喝水、睡觉） | 不是对自己说好话，也不是先让自己高兴起来 |
| 共同人性 | 不把这一次的孤独当作自己被排除在人群之外的证据 | 不是「别人更惨，所以你不该难过」 |
| 正念觉察 | 容许看见「我现在很孤独」，不必被它完全代表，也不必假装它不存在 | 不是接纳它、放下它，或与它和解 |

**这三项不是三项必须全部完成的成绩。**〔证5〕

**关于效果，本章说的话是收窄的。** Kirby等（2017）的慈悲干预元分析汇总二十一项试验，报告部分自报慈悲、抑郁、焦虑及幸福感指标改善，摘要称纳入主动对照后仍有结果，同时强调基础研究多为小样本、须提高方法质量。本轮取得的是摘要，未取得原文，未核查各试验或复算合并效应。[P03](../SOURCES_PRACTICE.md#p03)的边界明写：不同干预、对象与终点不可互换；不能推断人人有效或效果持久；**不能把完整训练的结果移给本书一次自我安慰、短句和呼吸练习**。〔证4〕

**一分钟练习（编排，不是从上述研究推出的做法）。** 手放胸口，说三句话：「这是孤独的时刻；孤独是人之常情；愿我此刻善待自己。」手部接触取自[第六章](Ch06_Loneliness_First_Aid.md)6.4，不愿意被触碰时只做后两句。〔证1〕〔证8〕

**如果这三句话你说不出口，跳过它不是失败。** 说不出口通常意味着此刻你不相信它，而11.2已经说明：让一个人相信一句他查过之后认为不真的话，不是自我关怀。这一项对某些人可用，对另一些人此刻不可用，两种都正常。〔证1〕

## 11.4 那句「我不够好」是谁的

这一节原稿没有。它补的是三件事里最难分的那一件：出处。〔证1〕

三种常见来路，处置不同：

| 来路 | 怎么认出它 | 处置在哪 |
|---|---|---|
| **某个人的话** | 那句话有一个具体的声调、具体的场合，你能想起是谁在什么情形下说的。家人、伴侣、上司、老师、同学 | 本节下面那一个动作 |
| **一次具体的失败被推广成人格结论** | 「我这次没做好」变成了「我做不好任何事」。前者有日期，后者没有 | 11.2第二件；[《平静之书》第十三章](../bop/Ch13_Self_Compassion.md)13.4 |
| **一个处境的描述被当成对自己的评价** | 「在这个岗位上没人听我说话」被写成「我说的话没有价值」；「在这段关系里我做什么都不对」被写成「我做什么都不对」 | **不在本章。** 处境造成的只能由处境处理，见[第十九章](Ch19_Workplace_Loneliness.md)19.5与[第十八章](Ch18_Loneliness_In_Relationships.md)18.7 |

第三种最需要先排除，因为它最容易被误当成第一种。一个人如果被反复告知他做的每件事都不对，他最后得出的关于自己的结论，看起来和他自己想的完全一样。〔证1〕

**一个可以做的动作。** 把那句话写成引号，在它旁边写下：它最初是谁说的，在什么情形下说的，那时你几岁或者你当时的处境是什么。

这不是追责练习，也不要求你去对质或原谅谁。它做的事只有一件：把一句你当成事实的话，还原成一句有人在某个时刻说过的话。还原之后，那句话可能仍然有几分道理，也可能完全没有——两种结果都比原来那句无出处的断言好处理。〔证1〕

**这个动作的边界。** 本章不据它推断任何人的童年经历、动机或保护意图，也不给「内在批评者」设定一个来源。[《平静之书》第十三章](../bop/Ch13_Self_Compassion.md)13.2明写不急着替批评找到童年来源，本章沿用。〔证5〕〔证9〕

**停止条件。** 如果做这件事让你更难受，或者你发现自己开始反复回放那些情形，停下来。书写有可能强化反刍而不是中断它，反刍与表达的区别是：表达之后你能做别的事，反刍之后你还在同一个地方（[第六章](Ch06_Loneliness_First_Aid.md)6.12）。如果写出来的是自我伤害的念头，那不是这一项的失败，是分诊信号，按[第六章](Ch06_Loneliness_First_Aid.md)6.1处理。〔证2〕〔证8〕

## 11.5 可以试的方向

每一项都可以只做一次，也可以一项都不做。〔证1〕

| 方向 | 现实前提 | 停止条件 |
|---|---|---|
| **不再追加贬损。** 不需要说好话，只需要停止加那一句 | 无。这一项不需要力气、时间或任何人在场 | 无。它没有做错的方式——做不到时你只是回到了原来的语气，没有变得更糟 |
| **照顾眼前需要。** 吃饭、喝水、睡觉、洗一次澡 | 有力气做其中一件。这项与[第六章](Ch06_Loneliness_First_Aid.md)6.11重叠，本章不另编 | 连续数日无法进食或照顾自己时，那是需要评估的情形，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3 |
| **三句话练习**（11.3） | 你此刻说得出口。说不出口就跳过 | 说完更难受时不重复。依[S03](../SOURCES_SCIENCE.md#s03)与[S05](../SOURCES_SCIENCE.md#s05)，身心类练习存在不良体验报告，自行加强或加时可能起反作用 |
| **把那句话还原成引号**（11.4） | 有一个可以写的地方；不涉及正在发生的暴力或控制 | 越写越沉、开始重复同一句、或出现自我攻击的句子时停下 |
| **写下来**（[第六章](Ch06_Loneliness_First_Aid.md)6.12） | 同上 | 同上；该项已写明「关于命名情绪的作用，本书的说法是收窄的」，本章不另行加宽 |
| **一个人待着的时候**（[第九章](Ch09_The_Art_Of_Solitude.md)9.3） | 独处不等于自我陪伴：一个人待着可以安静，也可以只是没有人 | 独处后是空虚不是安静时，该补的是连接，见[第九章](Ch09_The_Art_Of_Solitude.md)9.5 |

**你不需要成为自己最好的朋友。** 原稿把这句话设成本章的目标，这一版不设。「最好的朋友」是一个很高的标准：它要求你在最难受的时刻，对自己表现出你此刻未必有的能力，而这个要求本身就是一次新的考核。这一章能给的只有两件小事——不再追加贬损，以及照顾眼前的需要。它们不要求先完成一场关于自我价值的辩论。〔证1〕〔证5〕

## 本章速记

- 三件事分开：语气（是否追加贬损）、内容（那句话是不是真的）、出处（这句话是谁的）。三件处置不同，混在一起时最常见的错，是让一个人去修正一句本来不属于他的话。
- 「也就允许别人如何对待你」已撤除。它把他人行为归因于你自己，与第十八章18.7、第十九章19.5相反。
- 三条通则已撤除：对自己苛刻的人对别人也苛刻、对自己温柔的人对别人也温柔、不爱自己的人很难相信别人爱自己。本书无数据，且第一条自身给了两个相反方向。
- 自我对话审计撤除。让一个正在自我贬低的人从回忆自己最出丑的时刻开始，是把最难的入口放在最前面。
- 自我关怀三要素依 P02 保留为概念，边界照录：概念区分高，不据理论证明个体改变，不能把自尊改名为自我关怀。效果方面依 P03 收窄：完整训练的元分析结果不能移给一次短句练习。
- 「列不够好清单」与「我不完美但我值得被爱」的改写句都撤除：前者要求枚举并保存自己的缺陷，后者是一个要求被相信的积极断言。
- 「我不够好」的第三种来路是一个处境的描述被当成对自己的评价，处置在第十九章19.5，不在本章。
- 你不需要成为自己最好的朋友。这一章只给两件小事：不再追加贬损，照顾眼前的需要。

下一章：[第十二章 · 数字时代的孤独](Ch12_Digital_Loneliness.md)。那一章先处理一件事：有些人的连接只在线上，本书不把它判为不算数。
