# 第二十一章 · 个人孤独系统

> 原稿这一章的开头写着：前二十章全是「技术」，是词；本章把它们编织成「系统」，是句子；技术会被忘掉，系统替你记得。随后给出两个设计原则（最小剂量、习惯叠加）、三张表（日、周、季）、一套掉线重启四步，以及一张一页纸模板。
>
> 这一版把三张表逐行退回各章。理由不是它们不好，而是每一行都已经有一章写过它，而那些章在这一轮里都改了：日表里的「睡前感恩：写今天我感谢自己做的三件事」，第十一章11.5已撤除；周表里的「一次数字断食：半天不看社交媒体」，第十二章12.6明写不设无屏幕日；季表里的「四维重新打分」，第五章5.1明写不计分、不设阈值。一份总表如果留着这些行，读者就会在同一本书里读到两套。〔证5〕
>
> 新增三节：21.2处理「系统替你记得」这句话本身，21.3给一张逐行退回表并说明这一版用什么代替，21.4处理两个设计原则与它们引用的那本书。21.5与21.6的节号保留——第二十三章23.2按节号引21.5的四步，23.6按节号引21.6的那张表。〔证1〕

## 21.1 先说清楚：这一章不做什么

下表中的情形，本章其余各节一律不适用，先按右列处理。〔证2〕

| 情形 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或已有计划、意图、无法确保眼下安全 | 拨 **120**（急救、急诊），并请一个可信任的人陪同；心理援助拨 **12356**，它提供心理支持与危机干预，**不替代120**，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 涉及暴力或人身危险 | 拨 **110** |
| 持续两周以上情绪低落，对几乎所有事都提不起兴趣，伴睡眠或食欲改变 | 这一章的三张表全部不适用。预约精神科或临床心理科评估，这条界线不该由你自己划，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2、22.3 |
| 已经很久无法进食、睡眠、工作或照顾自己 | 同上，见22.3。不要先给自己排一份日程 |
| 你的孤独只在某段关系里 | 一份日程改不了它的时间结构。见[第十八章](Ch18_Loneliness_In_Relationships.md)18.1，婚内另见[婚后孤独附录](Appendix_Loneliness_In_Marriage.md)A.1 |
| 你的孤独来自岗位、轮班或环境 | 见[第十九章](Ch19_Workplace_Loneliness.md)19.3与19.5。本章不为这类孤独提供任何日程 |
| 你读到「系统」两个字就已经觉得累 | 这是本章最常见的反应，21.2处理它。你可以只用21.6那张表，或者什么也不用 |

2. 本章不判定你有没有「系统」，也不把断掉解释成失败或缺陷。
3. 本章每一项都可以不做。21.6那张表可以不填，填一半也算填完。

## 21.2 「系统替你记得」：一句承诺的三处问题

先说这句话为什么有吸引力，因为它说的是一件真事：人确实会忘，而且常常在最难受的时候想不起自己读过什么。这一章也确实要处理长期。问题不在「长期」，在它给出的解法。〔证1〕

**第一，它把断掉解释成记忆问题。** 一份日程断掉，通常不是因为你忘了，而是因为那一段时间条件变了：项目上线、家里有人病、搬到一个新城市、一段关系结束、开始上夜班。把这类断掉叫做「忘了」，解决它的办法就是提醒；而实际需要的往往是减掉一件事，或者承认那一段时间本来就没有余地。《平静之书》第二十一章21.3把这条写在明处：日程本来就很满时，先讨论能否减少负担，比再增加一项「很小的练习」更值得考虑。〔证7〕

**第二，它把记住设成系统的工作，于是你从这件事里退出去了。** 听起来是减负，实际效果相反：一份替你记得的安排，也就是一份可以替你判定你的安排。原稿的一页纸模板里有版本号与日期，季节奏里有每90天复盘，周节奏里有保底——这三样合起来就是一份考卷，而判卷人是三个月后的你自己。〔证1〕

**第三，也是最要紧的，「系统」这个词是从别的地方借来的。** 它借自工程：有输入、有产出、有正常运转与故障两种状态。原稿这一章另外两个词属于同一套——「留存退弹」说的是子弹，「下次提前打补丁」说的是软件。这套语言用来讲机器是准确的，用来讲一个人身上发生的事情有一个后果：故障归因于系统，而系统是你搭的。所以掉线最后总会回到你身上。〔证1〕

**这一版保留什么。** 长期这件事仍然要处理，但它要处理的不是记不记得，而是三件别的事：哪一项你愿意留着（21.6）、掉线之后怎么办（21.5）、哪些部分根本不是你能动的（21.7）。三件都不需要一份日程。〔证1〕

**这一版用什么代替三张表：一个入口，五个问题。**

前四问沿用《平静之书》第二十一章21.2，第三问是本书加的。〔证7〕

1. 它准备回应什么需要？
2. 在什么情形下比较容易做到？
3. **它需要什么条件，而这些条件现在有没有？**
4. 什么情况下你会缩短、替换或停止它？
5. 如果不继续，还有别的做法或别人可以找吗？

第三问是本书加的，理由在这本书里：孤独的各章反复写明一项动作有现实前提——需不需要另一个人在场（6.3）、有没有一处不被打断的地方、有没有材料与体力（9.3）、有没有可负担且不被为难的去处（9.3）。前两问假设你能做，第三问问的是你能不能做。少了它，做不到就会被记成不想做。〔证5〕

五问都是Sonus的编排，不是处方，不设最低有效剂量。各项做法原有的停止条件仍然适用；把一项做法简化之后，不能声称它保留了完整做法的效果。〔证1〕

**本书的一条立场，在这一章同样适用。** 本书不把「学会独处」「主动连接」「把孤独转化成意义」写成继续留在忽视你的关系、孤立你的岗位或排挤你的环境里的义务。有些孤独是处境造成的，处境造成的孤独只能由处境处理。把它写成个人的能力缺口，结果是双重的：条件没有变，而多了一条自我指控。〔证4〕

这句话在这一章有一个具体的落点。原稿的三张表里有一行叫「一次社群活动」，有一行叫「一次真实连接」。如果你的孤独来自一个排挤你的科室、一段长期冷漠的关系，或者一个没有人过问的家庭位置，这两行不会改变任何条件——它们只会给你一周一次的新任务，以及一份新的未完成记录。关系版红线见[第十八章](Ch18_Loneliness_In_Relationships.md)18.1与[第十九章](Ch19_Workplace_Loneliness.md)19.5「关于离开」。〔证4〕

## 21.4 两个设计原则

### 原则一：最小剂量（宁小勿断）

原稿写「任何练习的设置，都必须小到『今天状态最差时也能完成』」，并给三组对照。这句话听起来温和，它做的事是把量调小。但调小剂量不等于取消剂量：5分钟仍然是一个必须达到的量，只是门槛低了。而「宁小勿断」这四个字里，「断」被设成了唯一需要避免的结果——它没有留出「这一项本来就不该做」的位置。〔证1〕

三处具体问题：

**一、「必须小到今天状态最差时也能完成」是一个无法核对的标准。** 今天状态最差时是什么样子，只有当天的你知道，而原稿把三组数字先写好了：5分钟、一条消息、三行。这不是让你自己找，是给了一个已经填好的答案，然后要求你在最差的一天也达到它。〔证1〕

**二、「差状态时发一条消息也算」把最难的那一项放在最差的日子里。** 第六章6.3整节处理身边没有一个可以联系的人；第十章10.1写明「主动开口，不等别人来找你」在本书里不是通则，对社交焦虑较重、被拒绝经历较多或正处在关系破裂中的人，它可能带来又一次被忽视。让一个人在状态最差的一天去发一条可能没有回音的消息，再把没有回音记进这一天的成绩，这是本书反复避开的一个安排。〔证5〕

**三、「创造30分钟／差状态写三行」与第十三章13.4的分工冲突。** 那一章明写做法不在本章，具体做法在第六章6.7与第九章9.3第二项，两处都写了现实前提（材料与体力；需要花钱的材料在预算紧张时不是可选项）。总表里另写一个数字，就会与那两处各说一套。〔证5〕

### 原则二：习惯叠加（挂在已有的钉子上）

**来源处置。** Clear（2018）未列入本系列任何台账——科学、实践、传统三份都没有——本轮未取得原文核对，标未核实。本章不采用它的任何命题，来源归属撤除，末尾文献列表一并撤除。这与第九章9.1对Long与Averill（2003）、Nguyen、Ryan与Deci（2018）、Winnicott（1958）三处的处置一致，也与第十五章15.8对Yalom（1980）的处置一致。台账中列有Ryan与Deci（2000）的自我决定理论[P10](../SOURCES_PRACTICE.md#p10)，与2018年那篇不是同一材料，不得互相顶替；同样，本书也没有任何一条与「习惯叠加」相关的已核验材料可以顶替它。〔证6〕

「习惯叠加」这个说法指的是把一件新的事挂在一件已经在做的事后面。这个观察本身平常，不需要归属；问题在原稿用它的方式。

**「挂在已有的钉子上」预设你有一枚钉子**：一件每天都在做的、稳定的、由你自己安排的事。原稿给的三个例子是倒好咖啡、午饭后、睡前。本书的很多读者没有这三枚钉子中的任何一枚——上夜班或轮班的人没有固定的午饭后；正在照护别人的人，睡前那段时间属于被照护的那个人；刚搬到一个新城市的人，连咖啡在哪买都还在找；一段关系刚结束的人，家里那些旧钩子上挂的全是别人。钉子不在的时候，「习惯叠加」不能执行，而原稿没有写明这时该怎么办。〔证1〕

**可以留下的部分。** 如果你确实有一件每天都在做的事，把它当一个提醒用是可以的。这是Sonus的编写建议，不是从任何研究推出的做法。两句限定：提醒不是剂量，它提示你此刻可以选，不提示你今天还欠一件；提醒失效时说明的是安排变了，不是你松了。〔证1〕

### 关于「日／周／季」这个三层结构

这一版不给周期。《平静之书》第二十一章21.5把同一件事写成「回看生活，而非给自己评分」，并明写什么时候回看由你决定，不设置统一周期。理由在本书也成立：90天这个数字没有来源；「每季一个孤独主题」使一年变成四次考核；「复盘」预设了前三个月有一份可以被评的成绩。〔证7〕〔证8〕

回看什么时候有用：生活出现变化的时候（搬家、换岗、一段关系结束、开始照护），或者一项做法你已经做了一段时间、想知道它还回应不回应原来那个需要的时候。两种都不需要日历。〔证1〕

## 21.5 掉线之后：四步

节号与「四步」保持不变，第二十三章23.2按节号引这一节。四步的内容改了。〔证1〕

**第一步：先分清是哪一种掉线。** 这一步是这一版加的，因为原稿把三种情形合并成一种。《平静之书》第二十一章21.4给了三条路，并明写「这三条路不能合并成一句『回到最小剂量』」。〔证7〕

| 你的情形 | 它可能说明什么 | 去处 |
|---|---|---|
| 中断了，但原先那一项确实有帮助 | 条件变了：项目、病程、搬家、照护、一段关系结束 | 下面三步 |
| 一直在做，却没有帮助 | 方法与需要不匹配。原稿把这种情形也叫「掉线」，其实你没有掉线，你在做一件没有用的事 | 换一项，或停止。见[第二十三章](Ch23_Loneliness_28_Day_Program.md)23.8「没有用，也没有更糟」那一段 |
| 做着做着明显更难受，或情绪、睡眠、功能在变差 | 这不该被叫做掉线，也不该被叫做正常维护 | 停下来，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3、22.4；有即时危险时拨120 |

只有第一行走下面三步。把后两种也叫「掉线」，结果是一个正在变差的人被建议从更小的剂量重新开始。身心与行为类练习存在焦虑、抑郁等不良体验报告，无既往心理问题者也可能出现，自行加强或加时可能起反作用。〔证3〕

**第二步：停止补刀。** 这一步原稿的措辞可以留下：不说「我又失败了」，只描述「我这周没有联系任何人」。两句的区别不在语气，在内容——第一句是一个评价，第二句是一件可以核对的事。第一章1.7与第二十三章D3要的都是后者。〔证5〕

补一句原稿没有的：描述完不需要接一个动作。「我这周没有联系任何人」这句话本身已经完整，它不必以「所以我要……」结尾。〔证1〕

**第三步：从当天开始，不补课。** 沿用第二十三章23.2的原句：不补课、不清零、不比较完成天数、不设及格线。这一版把原稿的「重启最小剂量」换掉，理由在21.4：最小剂量仍然是一个量，而重启一个量的时候，你手上多出来的是从断掉那天到今天的一段欠账。那段欠账不存在。〔证5〕

**第四步：记下这一次是怎么掉的，然后看它指向哪里。** 原稿这一步叫「留存退弹」，说明是「记下这次是怎么掉的（搬家？分手？工作忙？），下次提前打补丁」。记下来这件事可以留，两个词不行：它们说的是子弹和软件，而掉线的是一个人。〔证1〕

记下来之后要看的是方向，不是补丁：

| 它指向 | 那是什么 | 去处 |
|---|---|---|
| 一段时间（项目、考试、病程、照护） | 一段时间，它会过去 | 第二十三章23.2的现实约束第五行处理没有可自由支配时间的情形：把睡眠和照护算成练习任务，是那章明确不做的事 |
| 一个地方（搬家、离职、开始轮班） | 一件处境的事 | [第十九章](Ch19_Workplace_Loneliness.md)19.2、19.4 |
| 一个人或一段关系（分手、丧亲、被疏远） | 不是一份日程能接的 | [第十七章](Ch17_Loss_And_Grief.md)、[第十八章](Ch18_Loneliness_In_Relationships.md) |
| 这一项本身（做了也没有用、做的时候更难受） | 要动的不是你的坚持，是这一项 | 换掉它。第二十三章23.7第二问就是「哪一项没用，或者让你更难受」，答案是删掉它，不重试 |

记不下来也可以。这一条不是作业，第二十三章D24那一行写着「可以写『一项也不保留』」。〔证5〕

**关于原稿的「必然事件」。** 原稿写「必然事件：孤独感反复、练习断掉、又回到『孤立模式』」。这一版不写必然。孤独确实会反复——这一点本书从第一章就在说，它是信号不是缺陷；但「练习断掉」不必然是孤独反复的结果，它常常是生活里别的事情发生了。「必然」这个词把两件事绑在一起，绑住之后有一个后果：既然掉线是必然的，那么此刻的掉线就不需要被看懂，只需要被重启。第一步就是为此加的。〔证1〕

「又回到『孤立模式』」一并撤除。「模式」是定型，第五章5.1不作类型分类，第二十三章D4与D5也已撤除「区分你的孤独类型」与「写下你的主导孤独模式」。一个人这周没有联系任何人，这是一件事；他「又回到了某种模式」，这是对他的一个判定，而这个判定本书没有材料下。〔证5〕

## 21.6 一页纸：可以填，也可以不填

节号保留，第二十三章23.6按节号引这一节。表换了。〔证1〕

以下表格是Sonus设计的可选记录。没有分数，不设阈值，不用于判断你的孤独属于哪一类，也不用于判断它是否达到任何诊断标准。〔证1〕

| 项目 | 我的安排 |
|---|---|
| 我此刻最想回应的一件事（可以写「说不清」） | |
| 我愿意保留的一项做法；也可以留空 | |
| 它在什么情形下比较容易做到 | |
| 它需要什么条件，而这些条件现在有没有 | |
| 什么情况下我会缩短、替换或停止它 | |
| 掉线之后，我愿意怎样重新选择 | |
| 这一项没有用，或变得更难承受时，我可以找谁 | |
| 出现危险或功能受损时，去哪里获得帮助 | |
| 哪些部分不是我能动的（关系、岗位、环境） | |

三点说明。

**第一行可以从第一章拿。** 第一章1.7的末尾写着，那里写下来的东西在第二十一章用得上。指的就是这张表的第一行。1.7是孤独时刻考古，它记的是具体时段与场合；第一行要的也是具体的，不是「我的孤独」。写不出来就写「说不清」，这与第五章5.1维度一的说法一致：说不清是哪一种是常态，不是缺陷。〔证5〕

**最后三行是这张表里最容易被跳过的，而它们常常最要紧。** 第七行问的是人，第八行问的是去处，第九行问的是边界。一个人如果只填前六行，他填的是一份自我调节的计划；填了后三行，他填的才是一张有出口的纸。第二十二章22.5写明不愿求助有时是在衡量真实代价，所以第七行可以写「暂时不找任何人」——但请把它写出来，不要留空。留空与写下「暂时不找」是两件不同的事：前者是一个没答的题，后者是一个已经做出的决定。〔证4〕

**如果填表本身已经增加负担。** 可以只填最后三行，或者完全不用这张表。求助不需要一份整理得很好的说明，也不需要先交出完整的练习记录才有资格开始。这是本书的支持立场，不承诺任何具体服务的接诊条件。〔证4〕

## 本章速记

- 这一章撤除了日、周、季三张表、两个设计原则的处方地位，以及一页纸模板里的六行。逐行去向在21.3。
- 「系统替你记得」把断掉解释成记忆问题；断掉通常说明条件变了，而条件变了要改的是条件。
- 「系统」「留存退弹」「打补丁」是从工程借来的一套词。它们用来讲机器是准确的，用在人身上有一个后果：故障归因于系统，而系统是你搭的。
- 代替三张表的只有五个问题，其中第三个是本书加的：它需要什么条件，而这些条件现在有没有。
- Clear（2018）未列入任何台账，「习惯叠加」的来源归属撤除，标未核实。「挂在已有的钉子上」预设你有一枚钉子，而本书很多读者没有。
- 掉线之后四步：先分清是哪一种（只有「中断了但原先有帮助」走后面三步）、停止补刀、从当天开始不补课、记下这一次是怎么掉的然后看它指向哪里。
- 「必然事件」撤除：孤独会反复，练习断掉不必然是它的结果。「孤立模式」一并撤除，那是定型。
- 一页纸九行，可以不填；最后三行问的是人、去处与边界，最容易被跳过，也常常最要紧。
- 本章不给周期、不给剂量、不给主题、不给及格线。90天没有来源。
- 出现自伤念头、持续低落、无法进食睡眠或上班、幻觉或被监视感、暴力处境：这一章的三张表全部不适用，先读[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1。
- 本书不把自我调节写成留在忽视你的关系或孤立你的岗位里的义务。
