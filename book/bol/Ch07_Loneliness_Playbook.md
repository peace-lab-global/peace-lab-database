# 第七章 · 孤独场景剧本

> 第六章给了十项可以做的事。这一章原本要把它们放进八个具体场景里，每个场景排成三段：现场十分钟、今天内、本周内。
>
> 这一版把它改成了一张分流表。理由有三条，都能在书内核对。第一，三段式里只有「现场十分钟」那一段是有筛选的，另外两段是新建议，没有现实前提也没有停止条件。第二，八套剧本的内容与第八、九、十、十七、十八、十九、二十章重复，而那些章已按修订标准重写并附依据；同一件事在两处各写一遍，两处就会分叉，原稿正是这样分叉的——它保留了那些章已经撤除的比较级、通则与剂量。第三，「深夜」「周末」「节假日」三套与第八章整章重叠，而第八章把安全判断放在最前面，原稿这一章没有。〔证1〕〔证8〕
>
> 这一章的用处不是给出新做法，是让一个人在难受的当下不必读完八章，就知道眼下能做什么、完整的处理在哪里。所以它应当短。

## 7.1 先说清楚：这一章不做什么

下表中的情形，本章其余各节一律不适用，先按右列处理。〔证2〕

| 情形 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或已有计划、意图、无法确保眼下安全 | 拨 **120**（急救、急诊），并请一个可信任的人陪同；心理援助拨 **12356**，它提供心理支持与危机干预，**不替代120**，见[第六章](Ch06_Loneliness_First_Aid.md)6.1与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 涉及暴力或人身危险 | 拨 **110**；离开该处境优先于任何情绪调节 |
| 已持续数周，并影响进食、睡眠、上班上学 | 这是需要评估的情形，不是一套剧本能处理的，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3 |
| 你刚失去一个人 | 那是哀伤，不是场景问题。本章不为它设一行剧本，见[第十七章](Ch17_Loss_And_Grief.md)17.1 |
| 你的孤独来自岗位、关系或环境本身 | 处境造成的孤独只能由处境处理，见7.5与[第十九章](Ch19_Workplace_Loneliness.md)19.5 |
| 眼下确实一个人也联系不上 | 先看[第六章](Ch06_Loneliness_First_Aid.md)6.3；如果是夜里，看[第八章](Ch08_Night_And_Weekend.md)8.2 |

三条限定，与本书导航页的约定一致。〔证1〕

1. 本章每一行都是可选的。不累计次数，不设阶梯，不设完成标准，不要求每周做到。
2. 本章不承诺任何一行见效，也不给见效时间。它给的是入口，不是疗法。
3. 本章不判断你的处境属于哪一类。分流表由你自己看，看错了也不构成伤害——它只会把你带到另一章。

**原稿说了什么，这一版怎么处置。**〔证7〕

| 原稿说法 | 处置 |
|---|---|
| 每套剧本统一结构：现场（10 分钟内）、行动（今天内）、长期（本周内） | 三段式撤除，只保留第一段。后两段是新增建议，没有现实前提，也没有停止条件；「本周内」那一段尤其容易变成一周一次的失败记录，与约定一「每一项练习都是可选的、不累积」直接冲突。理由见7.4 |
| 「典型失控点：睡前孤独感爆发，刷手机到凌晨，更空虚，更睡不着」 | 因果链撤除。本书没有这个链条的数据。第八章8.3据本轮核读的[S24](../SOURCES_SCIENCE.md#s24)摘要只保留一条较弱表述：孤独与睡眠质量下降**相关**，不是因果，见〔证4〕 |
| 「深度对话比群体寒暄更治愈（Cacioppo与Patrick，2008）」 | 撤除比较级与来源归属。[S20](../SOURCES_SCIENCE.md#s20)仅书目，台账明载该条目不提供任何实质命题支持；「更治愈」是一个效果比较，本书无数据，见〔证4〕 |
| 「固定的社交节奏，比随机的社交更有效」 | 撤除比较级。本轮核读的[S26](../SOURCES_SCIENCE.md#s26)完整摘要比较的是社会整合测量的复杂度（复杂测量 OR=1.91，独居二元指标 OR=1.19 且区间跨越1），不是「固定优于随机」；观察性数据也不证因果，见〔证5〕 |
| 「主动约同事午餐／咖啡（不等别人邀请你）」 | 通则地位撤除。[第六章](Ch06_Loneliness_First_Aid.md)6.3明写它对社交焦虑者、被拒绝经历较多的人、正处在关系破裂中的人不成立，主动开口可能带来的是又一次被忽视；[第十九章](Ch19_Workplace_Loneliness.md)已作同样处置 |
| 「加入一个『同侪社群』（其他管理者／领导者，他们懂你的孤独）」 | 「他们懂你的孤独」撤除。这是把归属定义成读心，与[第二十章](Ch20_Community_And_Tribe.md)20.1撤除的「你们不聊也懂」同类。同侪社群可以试，但它不承诺被懂 |
| 「建立『你的传统』（不一定回家，但有自己的仪式）」 | 承诺地位撤除。[第八章](Ch08_Night_And_Weekend.md)8.7明写不团圆是合法选择、不需要理由，同时不承诺建立自己的传统就能抵掉节日的孤独 |
| 「6.9给予（做一件志愿性质的事）」作为节假日处方 | 处方地位撤除，改列第六章6.9并写明现实前提：已经透支时该项不适用 |
| 场景八「升职后，不能对下属示弱，不能对同级交心」 | 改写。「不能对下属示弱」把位置带来的沉默写成个人的选择，而[第十九章](Ch19_Workplace_Loneliness.md)19.3处理的是位置本身；19.5并已撤除「示弱是强者的特权」（对下位者不成立） |
| 「在聚会／团建／婚礼上，周围都是人，你却感到孤独（Cacioppo与Patrick，2008）」 | 来源归属撤除，同[S20](../SOURCES_SCIENCE.md#s20)；现象本身保留，它是常见经验，不需要一本书来批准 |
| 「建立『深夜不独处』的备选：约一个『深夜可以打电话』的朋友」 | 撤除。它预设你有这样一个朋友，而这恰恰是[第八章](Ch08_Night_And_Weekend.md)8.2要处理的情形——深夜确实无人可联系。给一个前提不成立的建议，等于在原有的孤独上再加一层「连这个都没有」 |
| 「重建『一个人的生活』（[第九章](Ch09_The_Art_Of_Solitude.md)）」 | 目标地位撤除。第九章9.2已撤除三层阶梯，9.3明写你不需要学会享受独处 |
| 「审视你的社交：是『被动参加』还是『主动选择』？」 | 二元判定撤除。多数人的社交不是选出来的，是岗位、家庭、城市与钱决定的；把它写成一次审视就能改的选择，与7.5的立场冲突 |

## 7.2 一张表怎么用

三步，不需要按顺序，也不需要做完。

**第一步，找到你的处境那一行。** 7.3的表按处境排，不按严重程度排。处境可以同时命中好几行——夜班加新城市加一段关系刚结束，这是常见的，不是你把表用错了。同时命中时先按更靠上的那行处理，安全永远在最上面。〔证1〕

**第二步，看中间那一列。** 那是十分钟里可以先做的一件事，全部取自第六章。它不是「先做这个再做那个」的第一步，是一个可以只做一次的入口。做了没用，按[第六章](Ch06_Loneliness_First_Aid.md)6.2，无效不是失败。〔证3〕

**第三步，看右边那一列，或者不看。** 右列是完整的处理在哪一章哪一节。此刻有力气读就读，没有力气就留着。本章不要求你从十分钟走到一整章。〔证1〕

**关于「剧本」这个词。** 原稿用它，这一版保留在章名里，因为它已经被全书其他章和四本姊妹篇按这个名字引用。但这一章不是剧本：剧本有台词、有顺序、有演完的时刻。这里有的是一张表和几个入口。

## 7.3 你的处境在哪一行

| 周末，两天没有和人说话 | 6.8出门（走十分钟即可）；出不了门时6.7创造转移 | [第八章](Ch08_Night_And_Weekend.md)8.6周末：结构消失之后 |
| 节假日，别人团圆 | 6.5声音连接（打电话，不只是发消息）；6.6意义锚点 | [第八章](Ch08_Night_And_Weekend.md)8.7节假日：允许不团圆。不回家不需要理由 |

| 远程办公，一天没说话 | 6.5声音连接；6.8出门 | [第十九章](Ch19_Workplace_Loneliness.md)19.4远程与轮班 |

| 升职之后没人可说 | 6.10回忆（职位之外的关系与时刻，注意该项的适用边界） | [第十九章](Ch19_Workplace_Loneliness.md)19.3位置越高，越没人可说 |

## 7.4 「十分钟」那一列，为什么只从第六章取

**因为第六章是本书唯一一处逐项写了现实前提与停止条件的清单。** 十项里每一项都写明它在什么条件下不适用、做到什么时候该停下。6.3还按「需不需要另一个人在场」把十项重新分过一次类，给出五项可以独自完成的，和五项附替代路径的。〔证3〕

**本章不新编动作。** 新编一套，就要重新核一遍每一项的前提与停止条件，而这一章的用处不在于此。它的用处是让一个人在难受的当下不必读完八章。〔证1〕

**原稿的三段式里，只有第一段有这种筛选。** 「今天内」与「本周内」两段是新的建议，没有前提，没有停止条件，其中数条与已修订章节的说法相反——「不等别人邀请你」「固定的比随机的更有效」「深度对话更治愈」都在那两段里，处置见7.1的表。〔证7〕

**一句实话。** 砍掉两段，这一章比原稿短了一半的篇幅。它本来就该短。一个人深夜坐在床边，不会读三段作业；他需要的是眼下能做什么，以及明天有力气的时候去哪里读。这两件事一张表就够了。〔证1〕

**这一版也不给次数与时长。** 原稿写过「深度聊 10 分钟」「走十分钟」。这一版保留「走十分钟」，因为它是在说这件事可以很小，不是在给剂量；「深度聊 10 分钟」撤除，因为它把一次对话变成了有指标的任务，而对方说多少不在你的控制里，见[第十章](Ch10_The_Art_Of_Connection.md)10.6。〔证9〕

## 7.5 处境不在表里，或者照做了没有用

**表里没有你的处境。** 从[第五章](Ch05_Loneliness_Audit.md)5.1的四组观察开始（理解、独处、连接、共处），或者用[第六章](Ch06_Loneliness_First_Aid.md)6.14那张按此刻状态选项的表。两张表都不要求你先归类才配难受。〔证3〕

**同时命中好几行。** 先按更靠上的那行。这不是排序游戏，是因为上面几行涉及安全与需要评估的情形，那些有先后，其余没有。〔证2〕

**照做了，没有用。** [第六章](Ch06_Loneliness_First_Aid.md)6.2明写：无效不是失败，把无效解释成练得不够，等于让你为自己的孤独再负一次责。本章十一行里没有一行承诺见效。〔证3〕〔证9〕

**一项都不想做。** 那是允许的，也是约定一。读完这一章什么也不做，是一个完整的用法。〔证1〕

**越做越难受。** 停下来。依[S03](../SOURCES_SCIENCE.md#s03)与[S05](../SOURCES_SCIENCE.md#s05)，身心类练习存在焦虑、抑郁等不良体验报告，无既往心理问题者也可能出现，个体风险不可预测。停下来不是做错了，是这一项此刻不适合你。不要自行加强度或加时长。〔证6〕

**你的孤独来自处境。** 这是本章必须写清楚的一条，因为原稿把八个场景全部写成了个人的应对问题。

**本书的一条立场。** 本书不把「学会独处」「主动连接」「把孤独转化成意义」写成继续留在忽视你的关系、孤立你的岗位或排挤你的环境里的义务。有些孤独是处境造成的，处境造成的孤独只能由处境处理。把它写成个人的能力缺口，结果是双重的：条件没有变，而多了一条自我指控。〔证1〕

这一条落在三个方向上：

| 如果孤独来自 | 要处理的是 | 不要去 |
|---|---|---|
| 一段长期忽视你、贬低你或控制你的关系 | 边界或离开。承受不是义务 | [第十八章](Ch18_Loneliness_In_Relationships.md)18.1、18.7；[婚后孤独附录](Appendix_Loneliness_In_Marriage.md)A.1 |
| 排挤你、架空你或超时用你的岗位 | 记录、合规与申诉渠道、工会或职工代表、劳动保障监察与法律途径；人身不安全时拨110 | [第十九章](Ch19_Workplace_Loneliness.md)19.5 |
| 一个不允许你独处的环境（没有自己的房间、没有不被打断的时间） | 环境。练独处不改变条件，只改变你对条件的耐受度 | [第九章](Ch09_The_Art_Of_Solitude.md)9.6 |

**本书不替你判断眼下是哪一种。** 有些难受确实是应对方式带来的，有些确实是处境带来的，多数时候两者掺在一起。这一章能做的只是不把后一种写成前一种。〔证1〕

## 本章速记

- 这一章不再是八套剧本，是一张分流表：处境、十分钟里可以先做的一件事、完整的处理在哪一章哪一节。
- 中间那一列全部取自第六章，因为那是本书唯一逐项写了现实前提与停止条件、并按「需不需要另一个人在场」筛过的清单。本章不新编动作。
- 三段式撤除，只留「现场十分钟」。「今天内」与「本周内」两段没有前提与停止条件，其中数条与已修订章节的说法相反。
- 撤除的比较级与通则：深度对话比群体寒暄更治愈、固定的社交节奏比随机的社交更有效、主动约人不等别人邀请你、同侪社群他们懂你的孤独、建立你的传统就能抵掉节日的孤独。
- 撤除的因果链：睡前孤独感爆发、刷手机到凌晨、更空虚、更睡不着。本书没有这个链条的数据，能说的只有孤独与睡眠质量下降相关。
- 表由八行加到十一行：加了深夜无人可联系、夜班与轮班、有人在身边仍然空。丧亲不设行，它走第十七章。
- 同时命中好几行时，先按更靠上的那行；安全永远在最上面。
- 照做了没有用不是失败，一项都不想做也是完整的用法。
- 本书不把主动连接写成留在忽视你的关系、孤立你的岗位或排挤你的环境里的义务。处境造成的孤独只能由处境处理。

下一章：[第八章 · 深夜与周末的孤独](Ch08_Night_And_Weekend.md)，最难熬的时段，专门的策略。
