# 第二十章 · 社群与部落

> 原稿这一章的开头是「孤独的解药是『我属于这里』」，正文把部落定义为「一群『同频』的人……你们不聊也懂」。这一版把这两句都改了。原因写在20.1的撤除表里，一句话概括：那样定义归属，等于设一个大多数人达不到的标准；达不到时，读者得到的不是方法，而是「连这个都找不到」的又一层孤立。〔证5〕
>
> 这一章要处理两件事，第二件原稿完全没有：**归属可以从哪里长出来，以及一个社群什么时候在伤害你。**

---

## 20.1 先说清楚：这一章不做什么

下表中的情形，本章的方向一律不适用，先按右列处理。〔证2〕

| 情形 | 去哪里 |
|---|---|
| 出现自伤念头，或觉得活着没有意义 | **12356**；已有立即生命危险或已采取行动，拨 **120**。不等本章读完，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 正在一个团体里承受控制、羞辱、经济盘剥、被限制与外界接触或人身不安全 | 这不是归属问题。见本章20.5；涉及人身危险拨 **110** |
| 社交场合让你心慌、发冷、想逃，且已经影响上学、上班或出门 | 这是需要评估的情形，不是性格。自行加量的暴露练习可能起反作用，见[第五章](Ch05_Loneliness_Audit.md)5.2第二种与[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3〔证3〕 |
| 持续数周无法进食、睡眠，或对几乎所有事都提不起兴趣 | 精神科或临床心理专业评估，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2 |
| 孤独来自岗位安排、轮班、远程结构或被排挤 | 处境问题，见[第十九章](Ch19_Workplace_Loneliness.md)19.5 |
| 刚丧亲、刚分手或刚失去一段长期关系 | 这是哀伤，不是缺少部落，见[第十七章](Ch17_Loss_And_Grief.md) |

三条限定，与本书导航页的约定一致。〔证1〕

1. 本章每一个方向都是可选的。不累计次数，不设完成标准，不排优先级。
2. 归属层缺什么，不能靠自评打分认定。[第五章](Ch05_Loneliness_Audit.md)5.1不给分、不设阈值，本章也不给。
3. 找不到「同频的人」不是一种失败，也不需要你先变成一个更开朗的人。

**原稿说了什么，这一版怎么处置。**〔证5〕

| 原稿说法 | 处置 |
|---|---|
| 「孤独的解药是『我属于这里』」 | 撤除「解药」。归属是一种需要，不是一种治疗；它也不能保证缓解孤独，见20.6 |
| 「部落是一群『同频』的人……你们不聊也懂。同类是『我不需要解释』的人」 | 撤除。这把归属定义成读心，是一个达不到的标准。它在正文里作为修辞保留过一次，但不作事实地位，见20.2 |
| 「归属感来自『我贡献了价值』，不只来自『被接纳』」 | 撤除因果句。它对正在耗竭的人是一句要求。角色确实能给你一个不必开口的理由，但那是方便，不是换取归属的代价，见20.4 |
| 「创造一个部落，比加入一个部落更有归属感，因为它是『你的』」 | 撤除比较级。无来源；且发起与组织需要时间、精力和一定的社交位置，不是人人可得 |
| 「时间：共同经历的积累（Baumeister与Leary，1995）」 | 撤除来源归属。[P29](../SOURCES_PRACTICE.md#p29)是理论综述，本轮仅取得书目，不承担技巧效果、起效时间与剂量〔证6〕 |
| 「脆弱：暴露真实的自己」 | 动作保留，通则地位撤除。在不对等的关系与团体里，先暴露的一方常承担更多风险，处置与本书附录术语表一致 |
| 「固定的时间出现（每周六上午的瑜伽课）」 | 保留为例子，撤除隐含的门槛：它预设了周末自由、可支配收入与能到达的场所，见20.4的现实前提 |

## 20.2 「部落」是一个比喻，不是一份标准

先把原稿的定义写清楚，因为它很有吸引力：一群人，在乎同样的事，说同样的语言，懂彼此的梗，你在里面不需要解释自己。

**这不是一个可以去找的东西。** 三个理由：

第一，它把「不需要解释」当成入场条件，等于要求一段关系在开始之前就已经完成。真实的长期关系里，误解、解释和重新理解是常态，不是故障。

第二，它无法被检验。你怎么知道一个群体是不是「你的部落」？原稿给的答案是「你们不聊也懂」。这条标准在实践中只有一个可观察的结果：你还没找到。

第三，也是最要紧的，它把没有找到的责任留给了读者。当「一群懂你的人」被写成归属的正常形态，那么没有它的人就自动落进「缺了什么」的框里。这与[第一章](Ch01_What_Is_Loneliness.md)1.3、[第五章](Ch05_Loneliness_Audit.md)5.2第六种「不能自己认领」的立场相反。〔证5〕

**归属的最小单位不是一群懂你的人。** 它可以更小，而且常常就是更小：

- 一个知道你名字的店员；
- 一个每周同一时间出现在同一个地方的人；
- 一个你不需要解释前提的场合；
- 一项你参与其中的重复活动；
- 一个你被算进人数的群体——哪怕你几乎不说话。

这一版把「部落」当比喻使用：它指的是「有一个地方算你一份」，不指「有一群人懂你的一切」。前者可以有，后者不常有，且不是前者的必要条件。这是Sonus的编写立场，不是研究结论。〔证1〕

**研究实际支持的是什么。** 本轮核读了Holt-Lunstad等（2010）荟萃分析的完整摘要：148项研究、308,849名参与者，社会关系更强者生存可能性的比值比为1.50（95%CI 1.42–1.59）。摘要特别指出测量方式差异显著（p<0.001）：复杂的社会整合测量关联最强（OR=1.91；95%CI 1.63–2.23），而二元的居住状态指标——独居与合居相比——最弱（OR=1.19；95%CI 0.99–1.44），置信区间跨越1，不具统计学意义。〔证4〕

这组数字支持两件与本章有关的事，也否定两件流传很广的事。

支持：研究里被测量的「社会整合」是多元的——关系的种类、数量与参与面，而不是「有没有一个灵魂部落」。方向上，多样的、有结构的关系比单一的居住状态更被数据支持。

否定其一：**不能对独居的人说他的死亡风险已被证明升高。** 那一项的区间跨越1。

否定其二：**不能把1.50换算成「相当于每天多少支烟」。** 该摘要中没有这个换算，它是作者在其他场合的通俗表述。

三条限制必须同时说：这是观察性荟萃分析，社会关系与死亡之间可能受健康状态、社会经济地位与反向因果影响，不构成因果证明；它不能用于个体层面的风险预测；因此它也**不能**被写成「加入一个社群就能延寿」的建议。本章引它，是为了说明「多样而有结构的关系」比「身边有没有人」更接近研究实际测量的东西，不是为了给任何动作背书。〔证4〕

## 20.3 归属长在结构里

归属感不是一个可以直接去追的感觉。你很难通过「我要有归属感」这个念头得到它。它通常长在一组外部条件里，Sonus把它们整理为四项：〔证1〕

| 结构要素 | 它解决什么 | 最容易改吗 |
|---|---|---|
| 固定的时间 | 让相遇可以重复，不必每次重新约定 | 相对容易 |
| 固定的地点 | 让面孔可以重复，熟悉感由此产生 | 取决于住处、交通与钱 |
| 重复出现的同一批人 | 让「不用解释前提」成为可能 | 取决于场合的性质 |
| 你在其中有一个位置 | 让你不必靠开口来证明自己在场 | 取决于场合是否给角色 |

四项不必齐全。四项全无的场合——一次性聚会、每次成员都不同的活动、以陌生人为对象的场合——最难长出关系，原因不在你身上。

**这里要说清楚它不是什么。** 结构不是保证。一个固定时间、固定地点、同一批人的场合，也可能三年之后仍然只是点头之交。结构提高的是可能性，不是产出。本书不承诺任何时间长度之后会发生什么。〔证1〕

**关于「想连接却退缩」。** 这一条常见到值得单独写：明明想去，到了门口又回来；发出去的消息删掉；答应了再取消。Hawkley与Cacioppo（2010）的综述把孤独界定为「感知到的社会隔离」，并指出在这种状态下，对社会威胁的警觉与重新连接的愿望会**同时**提高。〔证9〕

如果这个描述符合你的经验，它说明的不是你不想要关系，而是想要与戒备在同一时间发生。这是本章所有方向都必须配停止条件的原因，见20.4。原稿这一章没有停止条件。〔证9〕

## 20.4 可以试的方向

每一条都带现实前提。**前提不成立时，那一条不适用，不是你没做对。** 〔证1〕

**一、成为常客。** 选一个你能到达的地方，固定时间去。熟悉感是归属感的前身——这句话是Sonus的编写观察，不是已证结论。
现实前提：有一个你能到达、且不需要花钱或花很少钱的公共场所。到不了时（身体活动范围、照护责任、住处偏远、没有安全的户外场所），这一条不适用。

**二、进入一个已有结构的场合。** 有固定成员和固定活动的场合，比一次性聚会更容易长出关系，因为你不需要每次都重新开口。运动课、读书会、志愿者组织、信仰团体、线上社群是例子，不是推荐清单。
现实前提：这样的场合在你可及范围内，且你付得起它的代价。其中不少要收费、要预先熟识、要固定周末、要长期承诺。这些是门槛，不是你的问题。

**三、承担一个很小的角色。** 搬椅子、记名单、带一次水、在群里回答一个你刚好知道的问题。
这一条不是「贡献才有归属」——那句因果话已在20.1撤除。它的作用更实际：一个角色给你一个不必开口的理由，也给你一个固定的位置。〔证6〕
现实前提：你有余力。耗竭到只能维持基本生活时，这一条要往后放。

**四、线上关系不是次等关系。** 本书不把「必须见面」写成通则，[第十九章](Ch19_Workplace_Loneliness.md)已撤除同类表述。线上社群可以是长期的、真实的、有位置的，尤其对不能出门、语言不通或身处偏远的人。
现实前提：无。这一条不需要前提，它是一条许可。
一个提醒：把线上关系转到线下涉及安全，见面安排、身份核实与选择公共场所这些常规判断由你自己作，本书不代替。

**五、维护已经有的两三个人。** 归属层与亲密层不是一回事，见[第一章](Ch01_What_Is_Loneliness.md)1.3，但它们会互相托底。一个还记得你的老朋友，抵得上二十个新认识的点头之交——这句比较是修辞，不是数据。
现实前提：还有这样的人。没有了，也不代表这条路线永远关闭，见20.6。

**停止条件（原稿没有）。** 任何一个场合让你持续紧张、心慌、失眠，或事后耗竭数小时，减少次数或退出，不需要坚持到「适应」。「坚持就会好」不是一条有证据的规律，而身心类与暴露类练习都有不良体验报告，自行加量可能起反作用。〔证3〕退出一个不适合你的场合，是一个正确的动作，不是失败。

## 20.5 一个社群可能伤害你

**原稿这一章没有这一节。它与20.4同等重要，因为「找到你的部落」这句话本身不区分好的团体和坏的团体。**

人在孤独的时候，对接纳的辨别力会下降——这不是道德缺陷，是处境。一个团体在你最缺归属的时候出现，给了你位置、语言和被理解的感觉，这可以是一件好事，也可以是一个入口。下面五条是Sonus整理的信号，它们是编写整理，未经量表开发与验证，不能用来给任何具体团体定性，也不构成对任何信仰或组织的判断。〔证7〕

| 信号 | 它看起来像什么 |
|---|---|
| 离开被定义为背叛 | 「外面的人不理解我们」「你走了会后悔」「你走了就是放弃你自己」 |
| 你的疑问被解释成你的问题 | 信心不够、心不诚、业障重、想太多、被外面的思想污染了 |
| 边界被要求让渡且不可协商 | 时间、金钱、与家人的联系、身体边界、隐私，一旦提出就被视为不投入 |
| 有一个人不可被质疑 | 一切围绕一个人的说法组织，对该人的批评被等同于对全体的攻击 |
| 你在里面比在外面更紧张 | 需要不断确认自己的说法是否安全，需要预先想好每一句话 |

**如果符合，退出是正确的动作。** 你不需要向任何人证明理由，也不需要先想清楚「是不是我的问题」。这句话与[第五章](Ch05_Loneliness_Audit.md)5.1、[第十八章](Ch18_Loneliness_In_Relationships.md)18.1、[第十九章](Ch19_Workplace_Loneliness.md)19.5、[第四章](Ch04_Myths_Of_Loneliness.md)迷思六与[婚后孤独附录](Appendix_Loneliness_In_Marriage.md)措辞一致，本书不修改它。〔证5〕

涉及经济盘剥、人身控制、被限制与外界接触或暴力：拨 **110**，并走法律途径。本书不为这类处境提供任何情绪调节方案，也不把「再观察一段时间」写成前置条件。具体权利与途径请咨询执业律师、当地公安或妇联等正式渠道。〔证2〕

**诚实的另一半。** 退出有代价，尤其当这个团体是你唯一的关系来源、包含你的家人、或提供了你的住处与收入。本书不承诺退出之后你立刻不孤独——很可能相反，你会先经历一段更空的时期。这个代价由你自己衡量，本书不替你决定，也不把「留下来慢慢看清」写成更软弱或更不明智的选择。〔证7〕

**如果你不确定要不要退。** 可以先做一件代价最小的事：减少一次参与，看看缺席是否被允许。一个不能容纳你缺席的场合，本身就在回答你的问题。〔证7〕

## 20.6 找不到，或找到了又退出

这一节写给大多数读者，因为20.4那五条不是对每个人都成立。

**找不到，常常是处境。** 地点、时间、语言、身体活动范围、照护责任、收入、轮班、疫情后的场合缩减、一个城市里没有你所需要的任何一种群体——这些都是真实的限制。[第六章](Ch06_Loneliness_First_Aid.md)6.3整节处理「现实约束」，本章沿用它的立场：把处境造成的缺失记成个人的社交失败，是这本书最不愿意做的一件事。〔证1〕

**试过几个场合都退出了。** 这值得看一看，但不必由此得出「我有问题」。可以先看这些场合有什么共同点：时间不合适、需要预先熟识、以饮酒为中心、竞争性强、成员流动太快、你始终是里面唯一的新人。共同点常常是场合的属性，不是你的属性。这是Sonus的编写建议，不是诊断。〔证1〕

**「有人陪、有事做，仍然空」。** 这是[第五章](Ch05_Loneliness_Audit.md)5.2第六种情形，那一节写明**不能自己认领**：它可能需要评估，也可能指向一种与社交数量无关的状态，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2。本章不给它任何自助方案。〔证5〕

**没有部落的人，也可以有归属。** 这是本章最想留下的一句，也是一条立场，不是研究结论：归属的最小规模可以是一个人、一只动物、一个地方、一项重复的工作、一个你被算进人数的群体。它不等同于「一群懂你的人」，也不因此就不算数。本书不把它写成安慰性的替代，也不把独处浪漫化——[第九章](Ch09_The_Art_Of_Solitude.md)已按[修订记录](SONUS_RECOMMENDATIONS.md)重写，它同样不承诺独处的效果，并在9.6写明练独处不能改变条件，只改变耐受度。〔证8〕

**归属不是终点。** 就算你有了一个群体，孤独仍可能在其中出现：能聊日常，不能聊心事。那是[第十八章](Ch18_Loneliness_In_Relationships.md)与[第十章](Ch10_The_Art_Of_Connection.md)处理的问题，不是本章能解决的。这一句原稿没有说，而它是必要的——否则读者会把找到群体当成一个终点，然后在终点之后仍然孤独时，认为自己又失败了一次。〔证1〕

## 本章速记

- 先过分诊：自伤念头、团体内的控制与盘剥、已影响生活的社交焦虑、持续功能受损、处境造成的孤立、哀伤，都不在本章范围内。
- 「部落」由一份标准降回一个比喻：它指「有一个地方算你一份」，不指「有一群人懂你的一切」。后者不常有，也不是前者的必要条件。
- 研究实际测量的是多样而有结构的社会整合（复杂测量OR=1.91），不是居住状态（独居OR=1.19，区间跨越1）；观察性、不证因果、不作个体预测、不等于「加入社群可延寿」。
- 归属长在结构里：固定的时间、固定的地点、重复的同一批人、你在其中有一个位置。四项不必齐全，但结构只提高可能性，不保证产出。
- 五条方向各带现实前提。前提不成立时那一条不适用，不是你没做对。线上关系不是次等关系。
- 停止条件：持续紧张、心慌、失眠或事后耗竭数小时，就减少次数或退出，不需要坚持到「适应」。
- 社群可能伤害你。五条信号、退出是正确的动作、涉及盘剥与控制拨110；同时承认退出有真实代价，尤其在它是你唯一的关系来源时。
- 找不到常常是处境。归属的最小规模可以是一个人、一只动物、一个地方、一项重复的工作。归属也不是终点。

下一步：最后一部把前面各章整合成你自己的安排：[第二十一章 · 个人孤独系统](Ch21_Personal_Loneliness_System.md)。该章已按本记录标准重写：撤除了日、周、季三张表与两个设计原则的处方地位，改用五个问题，其中第三个问的是条件而不是意愿。掉线之后的四步在21.5，那张九行的纸在21.6。
