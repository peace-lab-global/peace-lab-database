# 附录小册子 · 婚后孤独

本册是[第十八章](Ch18_Loneliness_In_Relationships.md)的婚姻场景行动版本。道理与边界都在那一章，这里只放具体做法和两页可选记录。各表格是Sonus为本书制作的使用工具，不是量表，也不是经验证的治疗方案。〔证1〕

**这一版撤除了原稿的四样东西**：二十条信号自检表连同它的三档阈值（0–4 项、5–10 项、11 项以上）与「慢性情感疏离」这个判定；六种形态里的「找到主型」要求；「如果 TA 全程不接，给 4–6 周，不吵不逼不撤回」这一段；以及四条无来源的机制断言（催产素、多巴胺回落、一项连书目都不完整的婚姻研究、一句被当成研究结论的格言）。撤除理由见[第十八章](Ch18_Loneliness_In_Relationships.md)18.3、18.6与本章〔证6〕〔证7〕。

<a id="quick-card"></a>
## A.1 先看安全，再看方法

> **有人身危险，或身处暴力、控制、被限制自由的处境，拨 110。离开该处境优先于任何情绪调节，也优先于本册的全部三步。** 这一条优先于本附录其余所有内容。〔证2〕
>
> **有伤害自己的念头，或觉得活着没有意思**，立即拨打12356心理援助热线，或前往就近医院急诊，并请可信任的人陪同，不要独处。12356提供心理支持与危机干预，不替代120；政策要求每日不少于十八小时，不等于全国24小时，实时可用性本书未经拨测，占线时改拨当地精神卫生中心电话。见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1。〔证2〕
>
> **长期被羞辱、贬低，或被切断与朋友家人的联系，这是情感虐待，不是沟通问题。** 它不会因为你把话说得更好而停止。本册 A.4 的做法不适用，请直接看[第十八章](Ch18_Loneliness_In_Relationships.md)18.7第二种情形。〔证2〕〔证8〕
>
> **持续两周以上情绪低落、兴趣丧失、睡眠或食欲明显改变**，先做精神科或临床心理科评估。这可能是抑郁的表现，不是关系技巧能处理的。持续时间只是评估的一部分，不是求助资格；严重或迅速恶化时不必等满两周。见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3。〔证2〕
>
> **即使有人陪、有事做，仍有一种说不出的空**，先读[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2。[第五章](Ch05_Loneliness_Audit.md)5.2第六种明确写着这一条不能自己认领：同一组描述既可能是一种可以共处的处境，也可能是抑郁的表现，两者方向相反，本书无法替你区分。〔证3〕
>
> **本册的一条立场。** 本书不把「在婚姻里安顿自己」写成继续承受忽视、贬低、控制或长期不平等的义务。有些关系可以修，有些不能；对不能修的那一部分，设立边界或离开是正确的动作，不是失败的选项。〔证4〕
>
> **可以停，也可以求助。** A.4 的五件事没有一件是必须的，任何一件让你更难受就跳过它。困扰严重、持续或影响生活时可以主动求助，不必先证明自助失败，也不必两个人一起去——你自己去找一位治疗师也可以。〔证4〕

**这一册没有自评量表。** 原稿在这里放了二十条勾选题，按勾中数量分成三档，11 项以上判定为「慢性情感疏离」。本章撤除它，理由有两条：那些条目与三档阈值都没有经过任何信度与效度检验，「勾中 11 条」不代表任何临床事实；更要紧的是，它把「如果重来一次，我不确定还会选 TA」「有时候我觉得一个人过比现在这样更轻松」这类念头计成了症状分数——而这两句话常常是一个人在关系里最诚实的判断，把它们算成病征，等于要求读者先否定自己的判断，才有资格继续读下去。〔证6〕

替换它的是 A.5 与 A.6 两页记录：不打分、不分档、不设阈值，空着也可以。

## A.2 它长什么样

下面是几种常被描述的画面。**它们不是六种人，也不是六种类型**，同一段婚姻里常常同时有几种，也可能一种都不像。它们由Sonus整理，没有经过量表开发与验证，不用于分类，不表示严重程度，也没有「你主要是哪一种」的正确答案。原稿要求「找到主型再去做自检」，本书撤除这个安排，理由见[第十八章](Ch18_Loneliness_In_Relationships.md)18.3。〔证7〕

| 画面 | 常见的样子 |
|---|---|
| 各过各的 | 分工明确、账单清晰、孩子共管，什么都好，就是不像夫妻。对话里只剩「水电费交了」「明天谁接孩子」 |
| 只演角色 | 只做好丈夫、好妻子、好爸爸、好妈妈，不再做一个有需要、有脆弱、有梦想的人。对方也在演，于是两个演员互相对台词 |
| 屋檐下的沉默 | 吵过几次无效的架之后，学会了多一事不如少一事。冲突减少了，话也一起少了 |
| 人在，注意力不在 | 饭各吃各的，床各刷各的。物理距离很近，注意力没有交集 |
| 节奏错位 | 一方渴望深谈，一方觉得过日子想那么多干嘛。想要的不一样，而且都没有错 |
| 用外面的热闹填家里的安静 | 应酬、加班、球局、朋友，人也回家，只是不与你独处 |

婚姻场景比一般亲密关系多出三样东西，它们不是心态问题：

1. **事务性对话有真实的来源。** 「水电费」「谁接孩子」不是感情的替代品，是必须有人做的事。婚姻里的事务量通常比恋爱大得多，尤其有孩子、有老人、有房贷之后。所以「话变浅了」在婚姻里常常不是两个人变懒了，是可供说话的空闲被结构性地占掉了。这一点与[《时间之书》第六章](../bot/Ch06_时间急救箱.md)6.2处理的是同一类问题：先分清是状态问题还是处境问题。〔证4〕
2. **说出口像背叛。** 「TA 对我很好啊」——向朋友倾诉时最常听到的一句反驳。婚姻有对外的形象，这层形象会让求救无门，所以 A.4 第三步把「找一个不受这段婚姻影响的人说出来」单列，不是可选项。〔证4〕
3. **离开的代价是具体的。** 孩子、住房、收入、双方老人、社会评价。所以本册不写「勇敢离开」这类话，也不写「一定要守住」这类话。这个决定不需要以对方先改为前提，做出这个决定的人也不必先证明自己已经忍够了，但它确实需要现实条件，那部分本书无法替你安排。〔证4〕

## A.3 它从哪来

[第十八章](Ch18_Loneliness_In_Relationships.md)18.4列了五条常见的来路（期望落差、话变浅了、角色盖住了人、把激情的回落当成爱的结束、一方先冷另一方跟着冷）。原稿把它们叫「五个机制」，本章改称来路，因为其中没有一条取得了可以作为机制的证据；它们是Sonus对常见模式的观察整理，写成观察，不写成因果链。〔证7〕

婚姻场景里最值得单说的一条是第五条。**一方先冷、另一方跟着冷，只在双方都还愿意留在婚姻里时才可能靠单方面停止来打破。** 如果对方已经长期不回应，「你先停止传染」就变成要求被忽视的一方继续单方面维持，那不是打破循环，是把它固定下来。原稿在这一条写「一个人停止传染，另一个人就容易跟着停」，本章保留它作为一种可能，同时补上这个边界。〔证4〕

## A.4 三步走

### 第一步 · 安顿自己（不需要对方参与）

1. **先做一次观察，不是一次自检。** [第五章](Ch05_Loneliness_Audit.md)5.1的四组观察提示是**理解、独处、连接、共处**（原稿的第四维叫「转化力」，本书已改名，理由见该章 5.1 维度四）。要用它们，必须带上[第五章](Ch05_Loneliness_Audit.md)5.2第四种的那句限定：这一种情形**常常指向关系本身，不指向你的连接能力**。所以不要从「我哪一维最差」开始——那会把一个婚姻问题改写成你的能力问题。原稿在这里写「多数婚后孤独的人，独处力没坏，连接力报废，那就从连接力修起」，本章撤除这句话：它正好是该章警告的那个错位。从「这段婚姻里，哪一部分是我可以决定的」开始。〔证3〕
2. **恢复一个只属于你的身份。** 结婚之前你是谁？捡回一个不依赖「丈夫」「妻子」身份的活动、朋友或兴趣。原稿把这一条归给一部关于独处能力的专著，该书本轮仅取得书目、未核读，本章改为编写建议，见[第十八章](Ch18_Loneliness_In_Relationships.md)18.5。〔证5〕
3. **把孤独感从对方的判决书里摘出来。** 孤独是一种信号，不是对方的罪证，也不是你的失败。你可以在爱着一个人的同时感到孤独，这两件事不矛盾。这一条不承担让谁免责的作用——它只负责让你不必先证明自己没错，才有资格难受。〔证4〕
4. **写下你的关系愿望单。** 不写「TA 应该……」，写「在这段婚姻里，我最需要的是____」。最多三条，具体到可以执行：「每周有一个晚上，两个人都不看手机，说半小时话」是可以执行的，「多关心我」不是。它是第二步那场对话的材料，不是要求对方签字的清单。〔证4〕

原稿给这一步定了「1–2 周」的期限。本章撤除：它没有依据，而且会把安顿自己变成又一项有截止日期的任务。做到哪一步算哪一步。〔证4〕

### 第二步 · 重建连接（一次只做一个动作）

五件事，从你开始，不需要等对方先动。**一次只做一件，做完就停。** 它们是Sonus编排的低成本建议，不是验证过的方案，本章不声称任何一项有效，也不给它们排先后优劣。〔证4〕

| 动作 | 具体做法 | 边界与停止条件 |
|---|---|---|
| 每周一次真话时间 | 固定一到两小时，手机放到另一个房间。前半小时不谈孩子、家务、钱、工作，只谈感受。推进方式见[第十章](Ch10_The_Art_Of_Connection.md)10.2：从事到人、从好到真、从说到听 | 对方连续几次拒绝或全程看手机时，不要加时长、不要换成恳求。这是一个事实，去 A.4 第三步 |
| 说一次真实的需要 | 「我最近觉得我们说话变少了，我有点慌」，而不是「你都不理我」。前一句说的是你的状态，后一句说的是对方的过错 | 说出来之后得到的是嘲笑、翻旧账或长时间的沉默，那不是你说得不够好。**在不对等的关系里，先暴露脆弱的一方常常承担更多风险**，见[第十八章](Ch18_Loneliness_In_Relationships.md)18.6 |
| 恢复与性无关的身体接触 | 牵手、并肩坐、一个拥抱 | **前提是双方都愿意。** 不愿意被触碰不是婚姻的失败，也不是需要克服的障碍；对方躲开时不要坚持。出现僵硬、屏息、想逃、麻木，或引出创伤回忆，立即停止，见[第六章](Ch06_Loneliness_First_Aid.md)6.4。本章不作任何激素层面的解释，理由见[第三章](Ch03_The_Physiology_Of_Loneliness.md)3.4〔证9〕 |
| 一起做一件没做过的事 | 一道新菜、一条没走过的路、一个从没聊过的话题 | 这一条需要双方都有空闲与余力。长期照护、轮班、耗竭状态下不适用，见[第六章](Ch06_Loneliness_First_Aid.md)6.3 |
| 把感谢说具体 | 「谢谢你今天洗碗」，而不是「你怎么又在看手机」 | 具体不是修辞要求，是因为具体的感谢对方能接住，笼统的表扬接不住。如果你发现自己已经在用感谢换取回应，那要处理的是关系模式，不是措辞 |

**如果对方不接，这一段最重要。**

原稿写：「如果 TA 全程不接：先别下结论，给 4–6 周，改变习惯需要时间。期间你只做第一步＋第二步，不吵不逼不撤回。你稳定，本身就是关系里最强的一个变量。」

**本章撤除这一段，理由是它把承受写成了方法。** 它要求一个人在完全没有回应的婚姻里，连续四到六周不表达不满、不施压、也不后退，并把这个姿态命名为「稳定」。三处问题：四到六周这个数字没有任何依据；「不吵不逼不撤回」取消的正是被忽视一方唯一剩下的表达渠道；它把婚姻是否改善的责任，全部放在已经先开口的那一方身上。这与 A.1 的立场直接冲突。〔证4〕〔证6〕

替换成三条：

- **说出口一次，就算说出口一次。** 你已经把需要说清楚了，对方听见了而没有动，这是一个事实，不需要再重复四周来确认它。
- **给不给时间，看的是对方的行为，不是日历。** 「我知道了，我在想办法」之后有实际的变化，那么一段时间是合理的；沉默、「你想太多了」、或者两天之后一切照旧，那么该做的不是等，是第三步。
- **被长期忽视、贬低、控制时，正确的动作不是提升自己的连接力。** 这句话是[第五章](Ch05_Loneliness_Audit.md)5.2第四种的原话，本章不修改它。〔证3〕

### 第三步 · 接受与边界

三种情形，处理方式完全不同，不要混用。完整论述见[第十八章](Ch18_Loneliness_In_Relationships.md)18.7。

**第一种：对方给不了，但也没有伤害你。** 比如对方确实不擅长深谈，也不打算学。这种情况下，把深度对话放到别处——朋友、书、一个团体、一位咨询师——是可以的，婚姻负责安稳，不必负责你的一切。调整期望在这里是合理的。〔证4〕

**第二种：对方在伤害你。** 长期忽视、羞辱、贬低、切断你的人际、经济控制、任何形式的暴力。**这一种不适用「调整期望」，也不适用「给时间」。期望调整不了伤害。** 第一件事是安全，第二件事是找一个不受这段婚姻影响的人说出来，第三件事是专业支持。有人身危险时拨 **110**。伴侣咨询不一定要两个人一起去。〔证2〕〔证8〕

**第三种：你还没法判断是哪一种。** 这很常见，而且它本身就是一个信号：如果你需要反复论证对方到底有没有伤害你，那么这段婚姻里至少缺了一样东西。最有用的一步不是继续分析，是找一个外人说一遍。说出来之后，事情通常比你一个人在夜里想的清楚。〔证4〕

**关于「继续还是离开」。** 这不是本书能替你决定的，本书也不给判断标准。可以说的只有两条：这个决定不需要以「对方先改」为前提；做出这个决定的人不必先证明自己已经忍够了。婚姻场景里的现实代价（孩子、住房、收入、双方老人）是真实的，本书不假装它们不存在，也不据此要求任何人留下。〔证4〕

**关于用另一段关系来止住孤独。** 原稿写「向外求的解药会让所有人在孤独里再转一圈」。这是一句道德劝告，本章没有为它取得依据，撤除。可以说的是一件更实际的事：它通常不解决本册的任何问题，而且会增加几个新的、有时限的、涉及他人的问题。是否要面对它，以及怎样面对，属于你和可能被影响到的那些人，不属于本书。〔证4〕

## A.5 记录页一：这段婚姻里，哪些是事实，哪些是我的解释

把事实、解释和未知分开放，不要求作出积极解释，也不要求为对方找出理由。此表由Sonus设计，没有独立效果验证。〔证10〕

| 我能够描述的事实（对方做了什么、说了什么、几次、多久） | 我目前的解释 | 还需要了解什么 |
|---|---|---|
| | | |
| | | |

**这一页有禁忌。** 第一栏只写可观察的事实，不写「TA 不爱我了」——那是第二栏。如果你发现自己写不出第一栏，或者第一栏写出来的全是「TA 又加班了」这类无法改变的事，那么要处理的可能是 A.2 里那三样结构性条件，或 A.4 第三步，而不是这一页。如果填写让你更难受、更反复，停下来，不必填完，表格空着也可以。如果事情涉及安全、医疗或有时限的权益（分居、抚养、财产），记录不能延误实际求助与法律咨询。〔证2〕〔证10〕

## A.6 记录页二：留下、换掉、说出口、交给支持

此表不评价人格、婚姻成败或练习成绩，也不要求每日填写。**中断时可以重选，不补做；没有帮助时可以换法或停止。** 不要把漏做和方法无效混为一谈。〔证10〕

| 需要考虑的事 | 我的记录 |
|---|---|
| 我目前最需要的三件事（具体、可执行） | |
| 其中我已经说出口的一件 | |
| 对方对那一次的实际回应（不是我对回应的期待） | |
| 一个有帮助而且我愿意继续的做法 | |
| 一个我做过了、没有帮助、想停掉的做法 | |
| 我可以自己决定、不需要对方同意的一件事 | |
| 需要对方参与才能改的一件事，和我准备什么时候说 | |
| 我目前无法改变、只能承认代价的一件处境 | |
| 我为那件处境设定的复查条件与复查日期 | |
| 一个不受这段婚姻影响、我可以说真话的人 | |
| 可以联系的专业资源 | |
| 明显恶化时，我准备去哪里获得帮助 | |

**明显恶化时，停止相关做法并及时获得专业评估。** 「我现在就是走不了，而且这不公平」比「我要在婚姻里修好自己的连接力」更接近事实；把承受重新命名为成长，只是给同一副担子换个说法。承认之后要做的最小一件事，是给那件处境设一个复查条件和复查日期，写下来，到期回来看一眼。这段时间里你要保护的不是这段婚姻的评价，是你自己不要垮掉。〔证4〕
