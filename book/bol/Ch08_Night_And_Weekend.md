# 第八章 · 深夜与周末的孤独

> 原稿这一章从机制讲起：防御下降、意义真空、生理脆弱，然后是四步现场处置。它把分诊放在最后一行，只有一句「如果深夜孤独伴随『活着没意思』的念头，去第二十二章」。
>
> 这个顺序反了。**深夜是本书所有时段里风险最高的一个**，不是因为孤独在夜里更深，而是因为夜里没有人在场、没有机构开门、判断力下降、而求助的动作比白天更难发起。所以这一版把安全放在第一节，机制放在第三节。〔证2〕〔证6〕

---

## 8.1 先看安全：深夜不是「缓一缓」的时段

下表中的情形，本章其余各节的动作一律不适用，先按右列处理。〔证2〕

| 情形 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或已有计划、意图、无法确保眼下安全 | 拨 **120**（急救、急诊），并请一个可信任的人陪同；心理援助拨 **12356**，它提供心理支持与危机干预，**不替代120**。**夜里出现念头时，不要等到天亮，也不要等到「足够严重」**，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.1 |
| 涉及暴力或人身危险 | 拨 **110** |
| 今夜已经饮酒或服了药，并且担心自己控制不住 | 拨 **120**，同时联系一个能过来的人。不要在独处中等待它自己过去 |
| 持续两周以上情绪低落，对几乎所有事都提不起兴趣，伴睡眠或食欲改变 | 今夜先按上面第一条处理安全；白天预约精神科或临床心理科评估。这条界线不该由你自己划，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.2 |
| 连续多日难以入睡，或整夜清醒已成常态 | 睡眠问题本身需要评估，见本章8.8。本章的睡前安排不是失眠治疗，也不能替代它 |
| 深夜的清醒来自夜班、轮班或照护安排 | 这不是「深夜孤独」，是岗位与生活结构问题，见[第十九章](Ch19_Workplace_Loneliness.md)19.4 |

三条限定，与本书导航页的约定一致。〔证1〕

1. 本章每一个动作都是可选的。不累计次数，不设完成标准，不要求每天做到。
2. 本章所说的「深夜」，指你醒着而周围没有人的时段，不指钟点。对夜班的人，那可能是下午三点。
3. 夜里的判断力会下降，这一点本身就是先处理安全的理由，不是「你太累了明天就好」的理由。

**原稿说了什么，这一版怎么处置。**〔证6〕

| 原稿说法 | 处置 |
|---|---|
| 「孤独有两个高发时段：深夜和周末」 | 「高发」的程度地位撤除，保留为编写观察。本轮未取得孤独感的时段分布数据〔证10〕 |
| 「深夜孤独的本质：白天的忙碌是麻醉剂，夜晚的安静是清醒剂。孤独一直在，只是白天你没听见」 | 撤除。它把白天的正常功能说成麻醉，等于告诉读者他白天的生活是假的；「孤独一直在」是一个无来源的断言。安静时注意力没有别处可去，这一条保留为编写观察 |
| 「防御下降：白天被工作／社交填满，夜晚的安静让『被压抑的孤独』浮上来」 | 撤除「压抑」机制。本轮无来源支持 |
| 「白天的连接是深夜的疫苗」 | 撤除。疫苗是有剂量与效力的医学比喻，本章没有任何效果数据 |
| 「疲惫时情绪调节能力下降，孤独感被放大（Hawkley与Cacioppo，2010）」 | 撤除来源归属。[S24](../SOURCES_SCIENCE.md#s24)摘要核读的支持范围是另一件事，见8.3与〔证4〕 |
| 「酒精是 GABA 抵押贷款，明天会更孤独」 | 撤除机制与断言。[《平静之书》第九章](../bop/Ch09_Body_Foundation.md)9.6明写「不用简化的神经递质故事替代评估」，本章不与之矛盾，见8.5与〔证7〕 |
| 「周日傍晚综合征」 | 撤除「综合征」命名。它不是临床实体，本书不为非临床现象起临床名字，见8.6 |
| 「被需要感是孤独的解药」 | 撤除「解药」，与[第二十章](Ch20_Community_And_Tribe.md)20.1的处置一致 |
| 8.5「孤独预防针」周表（每天白天一次真实连接、每天睡前仪式、每周五安排锚点、每周日收尾） | 撤除整张表。它是一张打卡日历，与本书导航页约定一「每章练习都是可选的」直接冲突，理由见8.8 |
| 「节假日做志愿者（敬老院／流浪动物收容所）」 | 保留为一个可能的方向，撤除其处方地位，并补现实前提，见8.7 |

## 8.2 深夜无人可联系时

这一节是原稿没有的，而它是本章最需要的一节。

**没有人可以联系，不是一种失败。** 深夜无人可联系是一种真实处境：朋友都在睡、时差不允许、关系已经疏远、或者从来就没有这样一个可以半夜打电话的人。[第六章](Ch06_Loneliness_First_Aid.md)6.3整节处理它，本节不重复它的内容，只补夜里特有的三件事。〔证1〕

**第一，把号码先存好，而不是在需要时找。** 12356是全国统一心理援助热线，提供心理支持与危机干预，不替代120；每日不少于十八小时，不等于全国24小时，实时可用性本书未经拨测。因此存两个：12356，和一个你所在地的号码（当地精神卫生中心、医院急诊或你信任的人）。这件事白天做，五分钟。〔证2〕

**第二，夜里的求助门槛更高，所以门槛要提前拆。** 拨一个电话在白天是动作，在凌晨三点常常要先跨过「会不会吵到人」「是不是太夸张」「明天还要见面」这三道。这三道都不是安全问题，但它们确实拦人。[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.5整节处理「不愿求助，有时是在衡量真实代价」，22.4写明入口不是一级一级过关。**如果念头涉及安全，这三道全部作废，直接拨120。**〔证2〕

**第三，夜里不做决定。** 这一条与8.5合并说明。

**如果今夜确实一个人都联系不上，而且不涉及安全：** 这时可用的不是「联系谁」，而是「让今夜过去」。[第六章](Ch06_Loneliness_First_Aid.md)6.3给了几条不需要对方在场的动作，其中最适合夜里的是6.5（听到真人的声音）与6.11（身体安抚：温度与压力感）。这两项的共同点是它们不要求任何人回应你。〔证1〕

**这不等于「忍过去就好」。** 如果这种情况一周发生好几次，需要处理的不是今夜，而是关系网络的现状与白天的结构，见[第十章](Ch10_The_Art_Of_Connection.md)10.3、[第二十章](Ch20_Community_And_Tribe.md)20.4，以及[第十九章](Ch19_Workplace_Loneliness.md)19.4如果它与岗位安排有关。〔证1〕

## 8.3 深夜为什么更难：能说的与不能说的

原稿给了三条机制。这一版把它们拆开，分成台账能支持的、和不能支持的。

**可以说的一条，有来源。** 本轮核读了Hawkley与Cacioppo（2010）综述的摘要：该文把孤独界定为「感知到的社会隔离」，提出它提高对威胁的警觉与脆弱感、同时提高重连的愿望；并述及这种隐性社会威胁警觉会改变影响生理功能的心理过程、**降低睡眠质量**、增加疾病与死亡风险。〔证4〕

与本章有关的是加粗那半句：**孤独与睡眠质量下降相关**，这是一个综述级概括，台账给它**中**。方向很重要——是孤独与睡眠变差相关，不是「睡不好所以孤独」，也不是「疲惫放大孤独」。〔证4〕

**不能说的三条。**

其一，**不能说「孤独者CRP、IL-6显著升高」。** 台账明写：该文是综述，不提供这两项的一手测量数据；以此文为据属来源类型错配；具体炎症标志物的命题须改引一手研究或标为未核实。本章不作该陈述。〔证4〕

其二，**不能说「疲惫时情绪调节能力下降，孤独感被放大」并把它归给这篇综述。** 原稿正是这样做的。S24的摘要里没有这个方向的命题。疲惫与情绪调节的关系另有研究传统，本轮未取得，标未核实。〔证4〕

其三，**不能把「降低睡眠质量」当作因果。** 台账明写：摘要的机制表述是框架性论述，不等于因果已证。〔证4〕

**剩下的部分是编写观察，不是机制。** 夜里更难受，可观察的理由有三个，都不需要神经科学：周围没有人，所以没有东西把注意力从自己身上移开；一天里该做的事做完了，所以没有下一个动作可以接上；以及，如果明天还要上班，那么今夜的时间是被挤压过的。这三条是Sonus的整理，标不适用，不声称已证。〔证1〕

**还有一件更实际的事：夜里睡不着，第二天更难。** [S08](../SOURCES_SCIENCE.md#s08)是AASM与SRS的2015年成人睡眠共识，建议18至60岁成人规律地每晚至少睡7小时。这是一条共识建议，不是关于孤独的结论，也不构成「你必须睡够7小时否则会更孤独」的推理。它在本章的用途只有一个：如果你的夜里长期睡不够，那是一个值得单独处理的问题，见8.8。〔证5〕

## 8.4 深夜可以做什么

原稿给了一条四步SOP：身体安抚、允许、声音连接、写下来，按这个顺序。这一版撤除顺序与「四步」的形式，理由有两条：一是[第六章](Ch06_Loneliness_First_Aid.md)6.2已把十项写成可选清单、不排序、不累计；二是固定的四步在凌晨三点会变成第五道门槛——做完第三步没有好转时，人会认为自己又失败了。〔证1〕

下面从第六章的十项里挑出夜里最可能可用的几项。**挑一项就够，也可以什么都不做。**〔证1〕

| 选项 | 为什么适合夜里 | 现实前提 |
|---|---|---|
| [6.5](Ch06_Loneliness_First_Aid.md) 声音连接：听到真人的声音 | 不要求对方回应你，也不需要你说话 | 有可用的设备与网络；深夜音量要考虑同处的人 |
| [6.11](Ch06_Loneliness_First_Aid.md) 身体安抚：温度与压力感 | 不涉及语言，不涉及判断，在很累时仍能做 | 有热水、热饮或毯子；该项自身有禁忌，见第六章 |
| [6.13](Ch06_Loneliness_First_Aid.md) 允许：不对抗，不评判 | 它不要求你改变感受，只要求你停止与它较劲 | 无。但允许不等于忍受处境，见第六章该项的限定 |
| [6.12](Ch06_Loneliness_First_Aid.md) 写下来 | 把在脑子里转的东西放到纸上 | 越写越沉时按该项的停止条件停下，不要写完整篇 |
| [6.7](Ch06_Loneliness_First_Aid.md) 创造转移 | 给注意力一个去处 | 需要一点余力；已经耗竭时不适用 |

**夜里通常不适合的两项。** 6.8（出门，换一个有人的地方）——深夜可去且安全的公共场所很少，这一项在夜里的现实前提常常不成立。6.4（接触，如果你有并且愿意）——它需要一个在场的、愿意的人，而8.2整节处理的正是没有这个人的情况。〔证1〕

**停止条件（原稿没有）。** 任何一项让你更心慌、更冷、更想逃，或使念头变差，停下，换一项或什么都不做。身心类练习有焦虑、抑郁等不良体验报告，无既往心理问题者也可能出现，自行加量可能起反作用——夜里尤其如此，因为没有人能看到你。〔证3〕

**如果做完更难受。** 这不是你做错了。回到8.1的分流表；涉及安全时拨120，不等到天亮。〔证2〕

## 8.5 夜里不要做的三件事

这一节的三条都是原稿的红线，其中一条被改写了。

**一、不在夜里做决定。** 不辞职、不断绝关系、不发那条长消息、不做重大财务或医疗决定。理由不是「夜里判断力差」这句俗语，而是更具体的一条：夜里做的决定通常无法在夜里撤回，而第二天你还要面对它的后果。这一条不是禁令，本书不设「28天不得作重大决定」这类规则；它是一个默认建议，涉及安全、医疗需要或有时限的权益时不适用。〔证1〕

**二、不自行加量。** 不把一项练习从五分钟做到半小时，不连着做三项，不用更长的独处来「练」。理由见8.4的停止条件。〔证3〕

**三、不用酒精。** 原稿的理由是「酒精是GABA抵押贷款，明天会更孤独」。**这个机制说法被撤除。** 撤除的依据不在本章，而在[《平静之书》第九章](../bop/Ch09_Body_Foundation.md)9.6，那里写着：本书不推荐用酒精助眠，也不把饮酒包装成情绪调节方法；如果已经依靠酒精入睡、难以减少饮酒，或担心饮酒与用药、身体状况有关，请如实告诉医生，讨论安全的下一步；该章不编写戒酒配方，**不用简化的神经递质故事替代评估**。〔证7〕

所以这一条在本章的表述是：不推荐用酒精度过今夜。它不是一个神经化学结论，本书也没有「明天会更孤独」的数据。如果你已经在依靠酒精入睡，这是一个需要告诉医生的情况，不是一个需要靠意志力解决的毛病，也不该由本书的一句比喻来处理。〔证7〕

## 8.6 周末：结构消失之后

原稿把周日下午的低落命名为「周日傍晚综合征」，并给了三步SOP。**「综合征」这个命名被撤除**——它不是临床实体，本书不为非临床现象起临床名字。〔证6〕

撤掉命名之后，剩下的东西其实更清楚：**工作日提供了一整套外部结构——固定的时间、固定的地点、固定出现的人、以及一件件必须做的事。周末把这套结构收走。** 收走之后，一个人要自己造出时间、地点、人和事。对关系网络薄的人，这四样都缺，于是周末比工作日更难。〔证9〕

这个归因是Sonus的整理，标不适用，不是研究结论。它有一个实际用处：**它把问题从「我为什么一到周末就难受」换成「周末的哪一样结构我没有」。** 前者指向人格，后者指向可核对的清单。〔证9〕

**四样结构，各自的前提。**〔证1〕

| 缺的是 | 可能的方向 | 现实前提 |
|---|---|---|
| 固定的时间 | 给周末的一个时段安排一件重复的事，任何事 | 你有权支配那个时段；轮班与照护责任会让这条不成立 |
| 固定的地点 | 一个你能到达且不需要花钱或花很少钱的公共场所 | 这样的地方存在且安全，见[第二十章](Ch20_Community_And_Tribe.md)20.4 |
| 固定出现的人 | 进入一个已有结构的场合，而不是一次性聚会 | 见[第二十章](Ch20_Community_And_Tribe.md)20.3与20.4 |
| 必须做的事 | 一件小而确定能完成的事 | 它不能是「让自己快乐起来」这类无法核对的目标 |

**关于「明天又要上班了」。** 这一部分不属于孤独，属于工作。如果周日的难受主要是对工作的预期，那么要处理的是工作，见[《力量之书》第六章](../bos/Ch06_Power_First_Aid.md)6.2（要求不合理时，需要的是拒绝、协商、上报或离开，不是更多自我调节）与[第十九章](Ch19_Workplace_Loneliness.md)19.5。**本书不把对一份不合理工作的抗拒写成需要调节的情绪。**〔证9〕

**关于「周末又浪费了」。** 这句话预设了周末必须被有效使用。休息不是浪费，什么都不做也不是。这一条是编写立场，不是研究结论。〔证1〕

**原稿的三步SOP怎么了。** 「周日早晨就布局锚点」「周日下午做收尾仪式」「周日傍晚做切换仪式」——三条都保留为可能的方向，但撤除它们的处方地位与顺序，并各加前提：锚点需要有一个你能进入的场合；写「本周三个完成、下周三个期待」对正在耗竭的人是一份额外作业，做不到时不必做；「做一顿好饭、看一部好电影、给朋友打电话」三件事都需要余力和人，缺任一项时那条不适用。〔证1〕

## 8.7 节假日：允许不团圆

这一节原稿写得比其余各节好，尤其是第四条「允许不团圆」。这一版保留它，并把它放在最前面。

**先说不团圆是合法的。** 春节、中秋这类节日把团圆设成默认值，于是不回家需要一个理由，回家不需要。但有些情形下回家会更痛：家庭冲突、催婚、比较、被追问、以及你已经离开但没有人承认你离开的那个位置。这些情形下不回家是一个正确的选择，不是逃避，也不需要向任何人证明。这句话与本书的伦理红线一致：本书不把自我调节写成对伤害或不合理处境的忍耐义务。〔证8〕

**同时要说诚实的另一半。** 不回家也会孤独，而且在节日里更明显，因为周围的团圆是被安排好的、可见的。本书不承诺「建立你自己的传统」就能抵掉它。〔证8〕

**可以试的方向，各带前提。**〔证1〕

- **约同样不回家的人。** 前提是这样的人存在，而且你先开口。这一步常常最难，见[第六章](Ch06_Loneliness_First_Aid.md)6.2的失败分支：打了没人接、约了没人应，是常见结果，不是你的失败。
- **给自己一个仪式。** 一顿特别的饭、一个特别的地方、一本书。前提是它不变成一份必须完成的作业。原稿把它写成「建立你的传统」，听起来像一项工程；它可以小到只是那天的晚饭换一样菜。
- **参与一个节日里的公共场合。** 前提是这样的场所在节日里开着，且你能到达。
- **做志愿者。** 原稿把这条写成处方，并加上「被需要感是孤独的解药」。**「解药」已撤除。** 这条保留为一个可能的方向，同时要写清它的现实前提与风险：节日期间不少机构人手安排不同、不一定接收临时志愿者；而在自己很空的时候去照顾更需要照顾的人，有时会让人回来之后更空。这条不是对每个人合适，本书不推荐它作为通用方案。〔证8〕
- **和家里联系，但控制时长与话题。** 前提是这样做对你更安全，而不是更痛。如果一通电话之后你总是更难受，那么这一条不适用，这不是你不孝。〔证8〕

**节日之外的部分。** 节假日的孤独常常只是把一个平时就在的结构问题放大到可见：一年里你也没有多少可支配的关系与时间，只是平时被工作盖住了。如果是这样，要处理的是平时，见[第二十章](Ch20_Community_And_Tribe.md)20.3与20.4。这一条是编写观察，不是研究结论。〔证1〕

## 8.8 关于「预防针」：本章撤除了一张表

原稿有一张周表：每天白天一次真实连接、每天睡前一套仪式、每周五安排一个锚点、每周日做收尾与切换。它被称为「孤独预防针」。

**整张表被撤除。** 三个理由。〔证6〕

第一，它是一张打卡日历。本书导航页的第一条约定写着每章练习都是可选的，[第六章](Ch06_Loneliness_First_Aid.md)6.2写明十项是可选清单、不累计次数、不设完成标准。一张规定「每天」的表与这两处直接冲突，本章不能例外。

第二，「预防针」是一个有剂量与效力的医学比喻，而本章没有任何效果数据。本书不为它编造效力。

第三，也是最少被想到的一条：**它把一项每天都做不到的事，变成了每天一次的失败。** 对一个关系网络薄、时间被工作与照护占满的人，「每天白天一次真实连接」不是方案，是又一件做不到的事。这与[第六章](Ch06_Loneliness_First_Aid.md)6.3的现实约束立场相反。

**表里的睡前安排也要单独说一句。** 「调暗灯光、手机出卧室、身体扫描」属于通常所说的睡眠卫生。[S07](../SOURCES_SCIENCE.md#s07)是AASM的2021年慢性失眠指南，它强推荐多组分CBT-I，并明确**睡眠卫生不宜单独作为治疗**。〔证5〕

所以：如果你有慢性失眠，一张睡前安排表不是治疗，本书也不把它当治疗提供。需要的是评估与CBT-I，见[第二十二章](Ch22_The_Shadow_Of_Loneliness.md)22.3。如果你没有失眠，只是想在睡前少看一会儿手机，那是一件普通的事，不需要被称为预防针，也不需要每天做到。〔证5〕

**撤掉这张表之后，本章剩下什么。** 8.1的分流、8.2的号码与路径、8.4的可选项与停止条件、8.5的三条、8.6的四样结构、8.7的前提。它们都不要求你每天做任何事。〔证1〕

## 本章速记

- 先看安全。有伤害自己的念头、已有计划或无法确保眼下安全：拨120并请人陪同，12356提供心理支持但不替代120；涉及暴力拨110；已饮酒或服药且担心控制不住，拨120。**夜里出现念头时不等天亮，也不等「足够严重」。**
- 深夜无人可联系不是失败。白天先把12356和一个本地号码存进手机；夜里求助门槛更高，所以门槛要提前拆；涉及安全时那三道门槛全部作废。
- 台账能支持的一条是：孤独与睡眠质量下降相关（综述级概括，中）。不能说CRP与IL-6升高（来源类型错配），不能说「疲惫放大孤独」并归给同一篇综述，不能把它当因果。
- 夜里可用的几项都不要求对方回应你：6.5声音连接、6.11身体安抚、6.13允许。6.8出门与6.4接触在夜里的前提常常不成立。挑一项就够，也可以什么都不做。
- 夜里不做决定、不自行加量、不用酒精。酒精那一条的理由已改写：本书不用简化的神经递质故事替代评估；已经依靠酒精入睡，是需要告诉医生的情况。
- 「周日傍晚综合征」的命名已撤除。周末难，是因为工作日提供的四样结构被收走了：固定的时间、固定的地点、固定出现的人、必须做的事。
- 对工作的预期造成的周日难受，要处理的是工作，不是情绪。本书不把它写成需要你调节的东西。
- 节假日：不团圆是合法的，不需要理由；同时承认不回家也会孤独。做志愿者不是处方，「被需要感是解药」已撤除。
- 「孤独预防针」周表整张撤除：它与本书「每章练习都是可选的」冲突，「预防针」是没有数据的医学比喻，而每天做不到的事会变成每天一次的失败。睡眠卫生不能单独作为失眠治疗。

下一章：[第九章 · 独处的能力](Ch09_The_Art_Of_Solitude.md)。第九章已按[修订记录](SONUS_RECOMMENDATIONS.md)重写：撤除三层阶梯与时长阶梯，六个方向各带现实前提与停止条件；夜间不适用的一项在9.3第三项，本章8.4的处置与之衔接。
