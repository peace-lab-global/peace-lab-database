# 第二十三章 · 四周试行

> 这一章是前面二十二章的落地版：每天一个可选动作，四周走完。四周不是四个台阶，也不是疗程。你可以只用其中一周，重复一项，或者完全不用；选择不用不等于放弃照顾自己的时间。〔证1〕
>
> 四周的顺序就是本书的主线：审计（看清）、节律（托底）、深度（增值）、意义（定向），分别通向[第五章](Ch05_时间审计.md)、[第十八章](Ch18_时间与日常.md)、[第十三章](Ch13_时间与心流.md)与[第十五章](Ch15_时间与死亡.md)。原稿这一章叫「28天时间重建」，本书撤除了这个天数，章名改为「四周试行」，文件名不动。理由见23.1。〔证2〕

## 23.1 先说清楚：这份计划在做什么，不做什么

以下七种情形请跳过整份计划，先处理表里指的那一件事。它们不是四周能处理的事，多排一天日程也不会让它们好转。〔证3〕

| 情形 | 去哪里 |
|---|---|
| 有伤害自己的念头、计划或准备 | **120**（急救）或医院急诊，请可信任的人陪同，不要独处；人身安全受威胁拨 **110**；心理援助拨 **12356**。顺序与理由见[第二十二章](Ch22_时间的阴影与求助.md)22.1 |
| 「来不及了」的绝望感持续存在，伴随兴趣丧失、情绪低落或功能下降 | [第二十二章](Ch22_时间的阴影与求助.md)22.3。此时读一份逐日安排的计划，通常只会多一份做不到的清单 |
| 时间焦虑几乎每天占据思绪，影响工作或学习 | [第二十二章](Ch22_时间的阴影与求助.md)22.3 |
| 停不下来的检查、反复确认，或必须跟进每一个正在被讨论的话题 | [第二十二章](Ch22_时间的阴影与求助.md)22.2第二种与22.3。这可能属于需要评估的情形，不是自律问题 |
| 入睡困难、早醒或白天嗜睡已持续一个月以上 | 睡眠问题的评估优先于任何时间安排，见[《身体之书》第六章](../bob/Ch06_身体急救箱.md)。[第十八章](Ch18_时间与日常.md)18.4已写明关闭仪式不等于治疗失眠，也不宜据此自行实施睡眠限制 |
| 一直回避体检结果、复查通知或身体上的变化 | [第二十二章](Ch22_时间的阴影与求助.md)22.6。回避时间信息有时是在回避健康，它可以延误诊断 |
| 时间稀缺来自工时超限、不可转移的照护、通勤与居住位置、时间与收入直接挂钩，或日程不由自己排 | 这份计划帮不上。它是处境，见[第六章](Ch06_时间急救箱.md)6.2与[第二十章](Ch20_时间的伦理.md)20.2；本章23.2把这一条直接写进了用法 |

三条限定与[第二十二章](Ch22_时间的阴影与求助.md)22.7一致，一起读：心理热线不是急救，有当前生命危险时优先120与急诊；本书不对12356各地实时可用性作保证，本轮未拨测，国家卫生健康委的要求是每日不少于十八小时，这不等于全国二十四小时；不要等到「足够严重」才求助。其他地区资源见[危机资源清单](../../规范/CRISIS_RESOURCES.md)，该文件创建于本系列核验标准之前，其中的号码与网址本轮未逐一核对。〔证3〕

**这份计划撤除了原稿的八样东西。** 撤除的理由都写在下面，因为它们决定了这份计划怎么用。〔证2〕

| 原稿写了什么 | 这一版怎么处理 |
|---|---|
| 章名「28天时间重建」，并把二十八天当作一个形成周期 | 章名改为「四周试行」。二十八天这一周期**无任何研究支持**，[第十二章](Ch12_复利与积累.md)证11早已记录在案；本章按编排装置处理，声明见本节末 |
| 「每天一个不超过15分钟的动作」，写在章首格言、使用说明与四张表的表头 | 全部撤除，四张表不再设预算列。本书已在[第八章](Ch08_忙碌与空虚的时间.md)8.6、[第十二章](Ch12_复利与积累.md)12.6、[第十八章](Ch18_时间与日常.md)18.3与[第二十章](Ch20_时间的伦理.md)20.4分别撤除分钟数，理由是同一个：分钟数读起来是剂量，而本书没有对任何时长做过验证 |
| 第18天「布置一次90分钟心流块」「留15分钟坡道」，第24天「每月一次，约15分钟」，第27天「每周一次30分钟规划」，第28天「约30分钟」 | 全部撤除。这四个数字分别来自[第十三章](Ch13_时间与心流.md)13.4、[第十七章](Ch17_时间与遗产.md)17.4与[第二十一章](Ch21_个人时间系统.md)原稿的21.3与21.4。第二十一章现已修订，其最低配、「约30分钟」与「把这页贴在桌前或存为手机首屏」三处一并撤除，与本章同项；第十七章亦已修订，其「每月一次，约15分钟」与练习标题里的三个数字一并撤除，与本章同项；第十三章现已整章重写，其原稿13.4的九十分钟与十五分钟坡道连同另外三处数字、一处频次与一处疗程一并自行撤除，五个步骤的形状由本章23.5借用并保留。三章均已修订，本章不代它们设剂量，也不采用它们的剂量 |
| 第13天「固定20分钟」与第14天「各执行了几天」 | 两处已在前几轮分别改为时长自定与两端难易的回看，本版沿用，见23.4 |
| 第20天「列10件事，删掉1条C类」 | 撤除计数与ABC定型。[第八章](Ch08_忙碌与空虚的时间.md)8.6已把ABC三个字母改为第六章6.2的三类，并写明不要求列满十件；[第五章](Ch05_时间审计.md)5.3已撤除打分表 |
| 23.6「想再走一轮28天？可以。第二轮你会自动升级动作（心流块从一次到三次、放弃清单从两条到四条）」，以及第28天「毕业复盘」「并定下一个28天」 | 全部撤除。它们是阶梯：先给一条及格线，再给一条升级路径。本书导航页约定一写的是每章只建议一个最小行动、练习可选、不累积、跳过不构成失败 |
| 23.6「现在写下来，贴在Day 1的记录表旁边」 | 撤除。「贴在什么地方」是[第十四章](Ch14_时间与衰老.md)14.6已明确不要求的动作；「这张表的最后一格」还预设了一份有终点的表格，而这份计划没有终点，第四周也不产生一张填满的表 |
| 章末「参考文献」段：Clear（2018）、Vanderkam（2016）、Burkeman（2021）、Newport（2016） | 整段撤除，改为本章末的依据表。四条的性质见本节末的说明 |

**二十八天是一个编排装置，不是一个形成周期。** 它是一个帮助记忆与排优先级的编排装置，不是一个经过测量或验证的数学关系。这句措辞与[第十二章](Ch12_复利与积累.md)12.2对「每天百分之一」的声明、[《力量之书》第一章](../bos/Ch01_What_Is_Power.md)对四维乘积的声明、[《创造之书》第一章](../boc/Ch01_创造是什么.md)同一。现实中不存在一个必须走完的天数，也没有任何研究给出过「四周」与「时间感改善」之间的函数形式。〔证4〕

有一个具体的裁定可以直接用。[系列实践来源台账](../SOURCES_PRACTICE.md)P06记录的是Lally等（2010）的习惯形成研究：志愿者在固定情境重复自选行为并逐日报告自动化程度，结果是自动化增长与达到平台的时间存在明显个体差异。该条目的核验层级是**摘要**——本轮取得出版方存入Crossref的摘要，未取得全文；在线发表为2009，期刊卷期引用为2010。它的边界原文写着：这不是神经成像，也非直接观测神经回路形成；模型估算天数不能冒充每人实测期限，**不支持二十八天必成习惯，更不能以未达期限评价意志或人格**。本章据它撤除天数承诺，但不据它给出任何新的天数。〔证5〕

**四条参考文献为什么整段撤除。** 原稿章末列了Clear（2018）、Vanderkam（2016）、Burkeman（2021）与Newport（2016）。四条都是大众读物，本轮**仅取得书目**、未核读，也**未列入本系列任何台账**，见[系列实践来源台账](../SOURCES_PRACTICE.md)的待核验清单。更要紧的是：**原稿正文没有一处引用它们**——这份日程不是从这四本书来的。这类问题的性质不同于误引，它造成的伤害是让读者以为本章的安排出自那四本书。[第十四章](Ch14_时间与衰老.md)与[第二十章](Ch20_时间的伦理.md)章末的孤儿条目同一处置。〔证6〕

## 23.2 使用说明

**每天最多选一项。** 表里没有必做项，只有可选项；不设及格线，不比较完成天数。前一天的动作不自动累加到后一天。普通睡眠、通勤、上班、照护和日常活动不计入，也不会被包装成额外的训练任务。〔证1〕

**断了几天，从当天开始。** 不补课、不清零、不设连漏上限。原稿这里写的是「不允许连漏两天」，与本书[附录速查](Appendix_Quick_Reference.md)「漏一天不补，不设连漏上限」的既有处置相反，已在[第十二章](Ch12_复利与积累.md)12.6修订时改正：一份用来陪伴的计划里不该有不及格，而连续漏掉几天通常由处境决定，不由意志决定。〔证2〕

**任何一项让你更难受，就停下来。** 依[S03](../SOURCES_SCIENCE.md#s03)与[S05](../SOURCES_SCIENCE.md#s05)，身心类练习存在焦虑、抑郁等不良体验报告，无既往心理问题者也可能出现，个体风险不可预测。停下来不是做错了，是这一项此刻不适合你，不要自行加强度或加时长。这份计划里最容易引起不适的是第四周的两项想象练习，见23.6。〔证7〕

**五种现实约束。** 下面五条都不是「先克服再回来」的门槛，它们直接改写这份计划的用法。分类与[第六章](Ch06_时间急救箱.md)6.2逐字相同。〔证8〕

| 你的处境 | 这份计划怎么改 |
|---|---|
| 工时本身超了，或岗位随叫随到 | 第一周会照实记下这一点，然后就没有然后了。第二周的晨型锚点与第三周的整块时间都以你可以离线为前提，前提不成立就跳过整周。要动的是[第二十章](Ch20_时间的伦理.md)20.2的协商，不是这张表 |
| 照护责任不可转移 | 第三周与第四周的多项动作预设了一段无人打断的时间。没有就跳过，不改成「挤一挤」。照护轮值本身属[第六章](Ch06_时间急救箱.md)6.2的第三类 |
| 通勤与居住位置占掉了可支配时间 | 通勤时段不能被排成练习时间。第一周的记录会把它记在第三类，那就是它的正确位置，不需要为它另找用途 |
| 时间与收入直接挂钩 | 少做一小时就是少赚一小时的钱。这份计划的每一项都有机会成本，跳过是合理的经济判断，不是意志问题 |
| 日程不由自己排 | 第二周整周不适用：锚点、关闭仪式与整块防守都预设你可以决定自己的一天。改走[第二十章](Ch20_时间的伦理.md)20.2与[《力量之书》第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md) |

**本书的一条立场，在这一章同样适用。** 本书不把「找回时间感」写成在挤压你的工时、照护负担与不平等安排里继续自我调节的义务。呼吸练习不能把六十小时的工作周变成四十小时，一份二十八天的表也不能。四周走完之后工时、排班与照护分工一项也没有改变，那不是这份计划的失败，也不是你的失败——它说明要动的是别的东西。〔证8〕

## 23.3 第一周 · 审计：看清时间去哪了

这一周的全部内容就是[第五章](Ch05_时间审计.md)5.2的三天记录与三类划分。所有动作都是Sonus的建议，不是经过验证的疗程。〔证1〕

| 日 | 一个可选动作 | 做不到时 |
|---|---|---|
| 第1天 | 开始[三天的时间记录](Ch05_时间审计.md)：颗粒度自定，三十分钟一格或一小时一格都够，每两三小时补一次即可，不靠睡前回忆 | 今天记不下来，明天再开始，不算漏 |
| 第2天 | 继续记录；睡前写下今天最长的那一段是被谁定的 | 只写「不知道」也可以 |
| 第3天 | 记录第三天。三天到此为止；想继续记可以继续，不记也不影响后面的判断 | 只记了两天就停，那两天的记录同样可用 |
| 第4天 | 回看记录，找出你的「黄金时段」候选：哪一段时间你比较做得动难事 | 找不出来，说明这段日子没有可比的时间，不是你没观察 |
| 第5天 | 把三天的记录分成三类：我自己能改／需要别人参与才能改／暂时改不了 | 分不清，就都留在第一张纸上 |
| 第6天 | 只对第一类挑一件下周要改的事；第二类写下一个协商对象，第三类写下一个复查条件与复查日期 | 第一类一件也挑不出来，是这一周最重要的发现，不是没做完 |
| 第7天 | 回看三问（见23.7） | 只回答其中一问 |

**本周不设短板维度，也不判型。** [第五章](Ch05_时间审计.md)5.3已撤除原稿的打分表：四组观察不计分、不设阈值、不作类型分类，「任何一维低于满分的一半，那一维就是你的短板」这一规则随之作废。所以这一周没有分数可以算，也没有类型可以归；命中几条不说明任何问题，让你停下来的那一条才有信息量。〔证9〕

**「黄金时段」是编排用语。** [第三章](Ch03_时间的生理学.md)3.4写明它指你观察到自己头脑比较清楚、比较做得动难事的那一段时间，不是一个可测量的生理量，没有标准长度，也没有标准时刻；原稿「黄金两小时」里的「两小时」已撤除。第4天要写下的就是这个观察结果，[第十章](Ch10_规划与目标.md)与[第二十一章](Ch21_个人时间系统.md)用的是同一个意思。〔证9〕

**本周唯一的产出是一张三类清单。** 如果第二类与第三类占了绝大部分，那么后面三周的大多数动作对你只是止痛。止痛不等于无效，但也不该被说成解决。这时候更接近事实的说法是「我现在就是没有时间，而且这不公平」，可以做的最小一件事是给这个处境设一个复查条件和一个复查日期，写下来，到期回来看一眼。这一段照录[第五章](Ch05_时间审计.md)5.2第三步，本章不加码。〔证9〕

## 23.4 第二周 · 节律：托住一天的骨架

这一周按[第十八章](Ch18_时间与日常.md)18.3、18.4与18.5安排，三节的节号与内容都不动。整周有一个前提：你的早晨与晚上属于你。前提不成立时见23.2的第五行，跳过整周是正当用法。

| 日 | 一个可选动作 | 做不到时 |
|---|---|---|
| 第8天 | 设计并写下你的晨型锚点：起床后的一个固定动作，长度由你定，判断标准只有一条——状态差的日子你也能做 | 写不出来就先不写。第十八章18.6写明「本章到这里为止，也是完整的」 |
| 第9天 | 执行晨型锚点；起床后第一小时尽量不进消息流 | 早上第一件事是回一条必须回的消息，那是工作，不是失控 |
| 第10天 | 执行晨型锚点，并把今天的要事放进你观察到的黄金时段 | 今天没有这样的时段，就不用放 |
| 第11天 | 设计晚间关闭仪式，按[第十八章](Ch18_时间与日常.md)18.4的三步：收尾三行、物理关闭、一个低刺激过渡 | 只做其中一步也算做了。第十八章18.6写明可以只保留一端 |
| 第12天 | 执行关闭仪式；顺手看一眼今天的要事有没有一个动词开头的下一步 | 写不出下一步，说明这件事还太大，不是你没执行 |
| 第13天 | 选一处整块时间，做一次批量接线：消息与零散请求集中到一个固定时段处理，时段与长度由你定 | 要求实时响应的岗位不适用批量，那属第二类，去协商不是去自律 |
| 第14天 | 回看：晨型锚点与关闭仪式，哪一端比较容易做到、哪一端一直做不到？留下做得动的那一版，并把它改短 | 两端都做不到，先怀疑条件，再怀疑自己 |

**本周不给分钟数。** 原稿四张表的表头都写着「动作（≤15分钟）」，[第十八章](Ch18_时间与日常.md)18.3已把锚点长度改为「由你定，本书不给分钟数」，18.5已把整块时间改为「长度不设下限，你能守住的四十分钟就是合格的整块时间」。本章沿用，不另设数字。〔证9〕

**第13天的「固定20分钟」与第14天的「各执行了几天」已在前一轮撤除**，改为时长自定与两端难易的回看。本版沿用现行处置：回看的问题不是「我坚持了几天」，而是「哪一端比较容易做到，哪一端一直做不到」。〔证2〕

**「一直做不到的那一端」先怀疑条件。** 早晨做不到，先看看早晨是不是你的；晚上做不到，先看看晚上是不是还在工作。这两个问题的答案常常在[第六章](Ch06_时间急救箱.md)6.2那张表里，不在你的性格里。这句照录第十八章18.6。〔证9〕

**两端都稳定了之后，也不必再往前接一个「日节奏」。** 约定一同样管着这一句：不累积。第十八章18.6的原话，本章照录。〔证9〕

## 23.5 第三周 · 深度：让时间增值

这一周有一个前提：你有一段可以不被打断的时间。前提不成立时跳过整周，改读[第八章](Ch08_忙碌与空虚的时间.md)8.2那张「哪一种忙」的表——日程不由你排的那一种，要做的不是把碎片排得更满，而是去协商或去承认。

**第18天为什么不给九十分钟。** [第十三章](Ch13_时间与心流.md)13.4的练习标题是「设计一次90分钟心流块」，其中还有「前15分钟的坡道」，结尾写着「连续做三周，你会发现心流块开始认得你：入流越来越快，坡道越来越短」。九十分钟与十五分钟是剂量，「连续做三周」是时间疗程，「越来越快、越来越短」是效果主张，三样都没有来源，而[第三章](Ch03_时间的生理学.md)3.3已把所谓「专注周期」的具体长度标为未核实。本章只借用13.4那五个步骤的形状（选事、定产出、护场、写坡道、收尾），不采用它的数字、疗程与效果承诺。**该章现已整章重写，与此处口径一致：三样均已自行撤除，五个步骤的形状保留，「写坡道」改名「起步」，其13.6并照录本段。**〔证9〕

**第20天为什么不列十件事、不删C类。** 见23.1的处置表。补一句[第八章](Ch08_忙碌与空虚的时间.md)8.6已有的前提：**删不掉不是你不够果断。** 若那一条属第二类，动作是一次协商；若属第三类，动作是承认并写下复查日期。清扫出来的空档也不要急着填新任务，留给什么由你定，长度也由你定。〔证9〕

## 23.6 第四周 · 意义：给时间定向

最后一周要决定的不是留下多少，而是哪些部分本来就不该由这份计划处理。

**两项想象练习不能在同一天做。** 第22天与第26天分别通向[第十五章](Ch15_时间与死亡.md)15.5与[第十四章](Ch14_时间与衰老.md)14.6。两章已写明它们是同一类练习、暴露程度不同，不要在同一天做。这份计划可以乱序用，所以把这条写在这里：**如果其中一项已经让你不适，另一项不要做。** 出现心慌、发冷、想哭又哭不出来，或「来不及了」的紧迫感，就停下，把纸放下，去做一件手上的具体事，不需要补做。〔证7〕

| 日 | 一个可选动作 | 做不到时 |
|---|---|---|
| 第22天 | 先读[第十五章](Ch15_时间与死亡.md)15.1的章首不适用清单与15.5的停止条件。不适合做格纸时，改为写下三件你愿意放弃的事，不画格子、不涂黑 | 整项跳过也是完整的用法 |
| 第23天 | 写下你的放弃清单：本周起明确不做的一两类事 | 这一条预设了你有得选。没有可放弃的事，说明日程不是你的，见23.2 |
| 第24天 | 先读[第十七章](Ch17_时间与遗产.md)17.1的章首分诊：正在丧亲或刚拿到严重诊断的人这一天整项跳过。其余的人在17.3的三个账户里，写下已经在那里的东西：作品、他人、习惯。三栏可以都写，也可以只写一栏。写名字，不写「关心家人」这类抽象词 | 三个账户里有一个是空的，那是一个信息，不是一项扣分；整项跳过也是完整的用法 |

林澄也走了这四周。第一周的三天记录做完，三类清单上第一类只有二十五分钟；第二周做了三天，第四天开始上夜班，整周停在那里；第三周整周跳过，因为没有一个可以不被打断的时段；第四周只做了第25天那一笔。四周之后，林澄的工时、排期与通勤一项也没有变。这不是一份不及格的日历：记录照实记下了二十五分钟，那正是[第五章](Ch05_时间审计.md)5.2第三步要看的数字，而要动的东西从头到尾都在[第二十章](Ch20_时间的伦理.md)20.2那一边，不在这张表里。这是本书的虚构情境，与第五章5.2的林澄是同一个人，不是访谈、病例报告或测评结果，也不表示所有人的四周都该长这样。〔证10〕

## 23.7 每周回看三问

原稿把它固定在第7天、第14天、第21天与第28天。这一版不固定日子——固定的日程往往是这份计划最先断掉的部分。任何一天都可以。〔证1〕

1. 这周哪一项有用？（留下，不必加码）
2. 哪一项没用，或者让你更难受？（删掉它，不重试）
3. 下周只想做一件，是哪一件？（只写一件）

第三问只写一件，是因为写三件的结果通常是做零件。回看不判断是否「进步」：如果发现自己最需要的是休息、分担或一次评估，那已经说明原先设想的方法未必是第一优先，也可以就此结束这份计划。〔证1〕

## 23.8 第29天，并不只有一种答案

**有帮助，也愿意继续。** 把一项留在生活里，不必立刻加长、加难或加频。原稿在这里写「第二轮你会自动升级动作（心流块从一次到三次、放弃清单从两条到四条）」，已撤除：升级是阶梯，而这份计划没有二级。〔证2〕

**没有用，也没有更糟。** 可以停止这份计划，回头看看第一周那张三类清单，换一种方法，或找专业人员谈。不要因为已经走了四周，就继续走来证明之前值得。〔证1〕

**变得更难承受，或出现安全与功能方面的担忧。** 不再用「再坚持一周」作为默认答案。按[第二十二章](Ch22_时间的阴影与求助.md)22.4的说明获取支持，那一节写明入口不是一级一级过关，也不需要先证明自助失败；有当前生命危险时拨120，需要紧急医疗时不要先打心理热线。身心类练习引起明显不适时可以停止，不把继续完成当作勇敢的证明。〔证3〕〔证7〕

**中间没有继续。** 不需要补写缺失的记录。生活并不欠这张表一个完整结尾。可以挑一个仍有意义的问题，也可以把它合上。〔证1〕

**四周之后时间还是不够。** 这也是一个答案，而且是这本书最常说的那一个。它可能说明要动的是工时、排班、照护分工、通勤距离，或一段没有结束的哀伤，而不是你的日程表。本书不把这种情况写成计划失败，也不写成你的失败。〔证8〕

## 本章速记

- 四周是审计、节律、深度、意义，分别通向第五章、第十八章、第十三章与第十五章。不是四个台阶，任何一周可以单独用，也可以不用。
- 二十八天是一个编排装置，不是一个形成周期。台账P06的边界写着：不支持二十八天必成习惯，更不能以未达期限评价意志或人格。
- 每天最多一项可选动作；不设分钟数，不打卡，不累加，不设及格线，不比较完成天数，不设连漏上限。断了从当天开始。
- 这一章撤除了：章名里的天数与周期承诺、每日不超过十五分钟的剂量与四张表的预算列、九十分钟心流块与十五分钟坡道、每周三十分钟规划与第三十分钟的一页纸、十件事与C类、毕业复盘与「定下一个二十八天」、第二轮自动升级的阶梯、把纸贴在什么地方的要求，以及章末四条大众读物参考文献。
- 第二周以你的早晨和晚上属于你为前提，第三周以你有一段不被打断的时间为前提。前提不成立就跳过整周，那是正当用法。
- 第22天与第26天是两项想象练习，不要在同一天做；其中一项已经让你不适，另一项不要做。
- 五种现实约束直接改写计划用法，都不是「先克服再回来」的门槛。
- 第一周的产出是一张三类清单。第二类与第三类占绝大部分时，后面三周的大多数动作只是止痛——止痛不等于无效，但也不该被说成解决。
- 出现自伤念头、持续绝望、停不下来的检查、睡眠紊乱一个月以上、一直回避体检：跳过整份计划，先读第二十二章22.1、22.3与22.6。
- 本书不把找回时间感写成在挤压你的工时、照护负担与不平等安排里继续自我调节的义务。
