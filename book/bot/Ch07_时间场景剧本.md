# 第七章 · 时间场景剧本

> 原稿这一章是八套剧本，每套三步：承认、处理、收尾，全部由第六章的技术组合而成。它的好处很明显——一个人难受的当下不必读完六章，找到对应的那一套就行。
>
> 这一版保留这个好处，改三处。第一，**三步式撤除。** 原稿把第六章的三项动作连起来做，却没有继承其中任何一项的停止条件，而第六章逐项都写了。第二，**八套剧本一律预设你的日程由你排。** 原稿没有另一种可能，于是工时超限、照护不可转移、日程由别人定的人，在每一种状态里得到的处方都是呼吸与允许。本版新增7.4。第三，**四项来源归属撤除**，其中一处把全书唯一标明有反作用风险的动作交给了「恐惧时刻」，且不带停止条件。

## 7.1 先说清楚：这一章不做什么

下表中的情形，本章其余各节一律不适用，先按右列处理。〔证2〕

| 你正在经历的 | 现在做什么 |
|---|---|
| 有伤害自己的念头，或觉得活着没有意思 | 立即拨打12356心理援助热线，或前往就近医院急诊；如有人身危险，拨打110。这一条优先于本章全部内容 |
| 突发胸痛、心悸、呼吸困难、晕厥、一侧无力 | 拨打120。这类症状要先排除躯体急症，不要先做呼吸练习 |
| 两周以上情绪低落、兴趣丧失、睡眠或食欲明显改变 | 先做精神科或心理科评估。此时本章八套剧本一套都不适用，尤其是空虚与恐惧两套，见[第二十二章](Ch22_时间的阴影与求助.md)22.3 |
| 停不下来的担忧，或必须反复检查、必须按固定顺序做完否则极度不安 | 先评估焦虑或强迫相关的情形，见[第二十二章](Ch22_时间的阴影与求助.md)22.3 |
| 长期超时工作、没有休假、日程不由自己排定之后的疲惫与麻木 | 这是职业倦怠的处境。世界卫生组织把它列为一种职业现象，不是医疗疾病分类，且限于职业情境。本章解决不了，见7.4与[第二十章](Ch20_时间的伦理.md) |
| 入睡困难、早醒、白天嗜睡已持续一个月以上 | 睡眠问题优先于时间安排，见《身体之书》[第六章](../bob/Ch06_身体急救箱.md) |
| 刚刚失去一个人，或自己、家人刚拿到一个严重诊断 | 那是哀伤，不是场景问题。本章不为它设一行剧本，见《孤独之书》[第十七章](../bol/Ch17_Loss_And_Grief.md)与[第十五章](Ch15_时间与死亡.md)15.1 |

〔证2〕〔证8〕

三条限制。本表不是诊断标准，不能用来判断你或别人有没有病，也不能排除风险。12356的实时可用性本轮未拨测，若无法接通，请前往医院急诊或拨打120。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证2〕

三条限定，与本书导航页的约定一致。〔证1〕

1. **本章每一套都是可选的。** 不累计次数，不设阶梯，不设完成标准，不要求八套都试。
2. **本章不承诺任何一套见效，也不给见效时间。** 它给的是入口，不是疗法。
3. **状态由你自己认，但有三行不能只由你自己认。** 空虚、麻木、恐惧三行既可能是一种可以共处的处境，也可能是需要评估的表现，两者方向相反，本书无法替你区分，理由在7.3与7.4。

## 7.2 一张表怎么用

三步，不需要按顺序，也不需要做完。

**第一步，找到你的状态那一行。** 7.3的表按你此刻说得出的一句话排，不按严重程度排。同时命中好几行是常见的——又忙又累又开不了工，这不是你把表用错了。同时命中时先按更靠上的那行处理，安全永远在最上面。〔证1〕

**第二步，看中间那一列。** 那是可以先做的一件事，全部取自第六章的八项。它不是「先做这个再做那个」的第一步，是一个可以只做一次的入口。做了没用，按第六章6.2，无效不是失败。〔证3〕

**第三步，看7.4，或者不看。** 7.4问的是另一件事：这个状态有没有处境的那一半。此刻有力气想就想，没有力气就留着。本章不要求你从一次呼吸走到一场协商。〔证1〕

**关于「剧本」这个词。** 原稿用它，这一版保留在章名里，因为它已经被本书其他章和四本姊妹篇按这个名字引用。但这一章不是剧本：剧本有台词、有顺序、有演完的时刻。这里有的是一张表、几个入口，和一个关于处境的问题。〔证1〕

## 7.3 八个状态：可以先做的一件事

中间一列全部取自[第六章](Ch06_时间急救箱.md)6.4至6.11，理由见7.5。每项的停止条件在第六章原文里，本章不重抄，但**做之前请先读那一项的停止条件**。〔证3〕〔证7〕

| 你此刻的状态 | 可以先做的一件事 | 完整的处理在哪 |
|---|---|---|
| 忙碌，一天被切成几十段 | 6.4三次慢呼吸；6.9离开屏幕十分钟 | [第八章](Ch08_忙碌与空虚的时间.md)8.2先看日程是谁排的、8.3八条常见的样子；[第十九章](Ch19_日常的时间.md)19.3 |
| 焦虑，来不及 | 6.4；6.5允许它来不及（注意其停止条件：涌上来的是羞耻而不是松一口气，就停，改做6.4）；等水开、等电梯时可用6.8 | [第十一章](Ch11_耐心与等待.md)11.4对「快」与「急」的分辨；若担忧停不下来，先[第二十二章](Ch22_时间的阴影与求助.md)22.3 |
| 拖延，明知要紧就是开不了工 | 6.6定一件明天的事（只写一件）；6.7专注一段，长度由你定，二十五分钟不是标准值 | [第十章](Ch10_规划与目标.md)；若已长期影响收入、学业或健康，先[第二十二章](Ch22_时间的阴影与求助.md)22.3 |

| 恐惧，一想到未来就僵住 | **这一行不能只由你自己认领，也不要用6.11。** 只做6.4 | 先[第二十二章](Ch22_时间的阴影与求助.md)22.3；排除需评估的情形之后，[第十五章](Ch15_时间与死亡.md)15.1的不适用清单与15.5 |
| 麻木，日子连成一片，记不出区别 | **这一行不能只由你自己认领。** 6.4；6.9（走动引起不适时改成坐着看窗外） | [第二十二章](Ch22_时间的阴影与求助.md)22.3；7.1第五行的职业倦怠处境；[第十九章](Ch19_日常的时间.md) |
| 疲惫 | 6.5允许今天到此为止；6.9 | [第三章](Ch03_时间的生理学.md)3.2；若是长期的，7.4与[第二十二章](Ch22_时间的阴影与求助.md)22.6 |
| 迷茫，不知道该干什么 | 6.6只写「明天第一件事是＿＿」，不必回答人生方向；6.4 | [第十章](Ch10_规划与目标.md)；若是「不知道为什么做这些事」，《意义之书》[第五章](../bom/Ch05_意义审计.md) |

三行标了「不能只由你自己认领」，理由是同一条：同样的描述既可能是一种可以慢慢相处的处境，也可能是抑郁或焦虑的表现，还可能与刚刚发生的丧失、诊断或年龄变化有关。[第五章](Ch05_时间审计.md)5.4的第四种与第五种已经作同样处置，《孤独之书》第七章的「有人在身边，仍然空」一行也是。本书不替你区分，也不该由你自己在夜里区分。〔证11〕

**不知道自己是哪一种状态时**，不要用这张表。第六章6.12的决策表按「你现在的状况」排，其中四行直接指向分诊与处境判断；[第五章](Ch05_时间审计.md)5.3的四组观察提示不计分、不设阈值。两张表都不要求你先归类才配难受。〔证3〕

## 7.4 每个状态都有处境的那一半

**原稿没有这一节，而它是本章最需要补的一节。** 八套剧本全部预设一件事：你的日程由你排，所以你的忙、你的空、你的开不了工，都是你可以调节的状态。对第六章6.2列出的五类处境，这个预设不成立。〔证10〕

| 五类处境（照录第六章6.2） | 它最常被误认成哪一种状态 | 于是得到的处方是什么 |
|---|---|---|
| 工时本身超了 | 忙碌、疲惫 | 呼吸与休息，而工时没有变 |
| 照护责任不可转移 | 拖延、迷茫 | 「定一件明天的事」，而没有一段完整时间可以给它 |
| 通勤与居住位置 | 空虚 | 「找一件想做的事」，而一天里有两个小时不属于你，剩下的太碎 |
| 时间与收入直接挂钩 | 焦虑 | 「允许它来不及」，而停下来就没有钱 |
| 日程不由自己排 | 麻木 | 「用五感做一件小事」，而日子的边界不是你画的 |

〔证8〕

右列不是错的。呼吸与休息确实有价值，第六章逐项写了它们的停止条件，本章7.3也确实指向它们。问题在于**它们被当成了全部**：一个六十小时工作周的人做完三次慢呼吸，工作周还是六十小时。第六章6.2把这句话写在了正文里，本章照录：**本书不把「找回时间感」写成在挤压你的工时、照护负担与不平等安排里继续自我调节的义务。** 把这两件事混在一起，是让承受的一方替安排负责。〔证8〕

### 三个不是练习的动作

| 动作 | 属于哪一类 | 什么时候用 | 去哪里 |
|---|---|---|---|
| 协商排期 | 第二类：需要别人参与才能改 | 优先级由别人决定、随叫随到、排期冲突 | [第二十章](Ch20_时间的伦理.md)；《力量之书》[第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md) |
| 拒绝一件事 | 第二类 | 加派、代做本该由对方做的事、「顺便」参加的会 | 《力量之书》[第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md)；[第八章](Ch08_忙碌与空虚的时间.md)8.3的第二列 |
| 承认这一季做不了 | 第三类：暂时改不了 | 通勤距离、家人病情、合同期、轮班表 | [第六章](Ch06_时间急救箱.md)6.5与6.2「诚实的对价」；[第十五章](Ch15_时间与死亡.md)15.3 |

〔证8〕

第三条有一个必要的动作，否则它会变成另一种自责：**给它设一个复查条件和一个复查日期**——「项目交付后」「孩子上小学后」「三个月后」——写下来，到期回来看一眼。承认不是终点，是把它从每天都要重新说服自己一遍的负担，变成一个有日期的事项。这段时间里，你要保护的不是效率，是不要垮掉。〔证8〕

**第二类的一个前提。** 协商与拒绝都预设了你可以开口而不失去什么。对计件、零工、试用期、以及拒绝就会被记下的人，这个前提不成立。此时更接近事实的说法是第六章6.2那一句：「我现在就是没有时间，而且这不公平。」它比「我要学会与时间和解」更难听，也更可持续。〔证8〕

**本章不替你判断眼下是哪一种。** 有些难受确实是应对方式带来的，有些确实是处境带来的，多数时候两者掺在一起。7.3与7.4要做的只是不把后一种写成前一种。〔证10〕

## 7.5 中间那一列，为什么只从第六章取

**因为第六章是本书唯一逐项写了现实前提与停止条件的清单。** 八项里每一项都写明它做到什么时候该停下、什么情况下会起反作用：6.4在出现头晕、憋气感或反而更慌时停，有呼吸系统疾病的人不要屏息；6.5在涌上来的是羞耻而不是松一口气时停；6.6在躺下以后不停想起清单时停；6.7在被打断两次以上时停，并回到6.2判断类别；6.8在照看孩子、看着炉子或守着设备时停；6.9在走动引起疼痛或不适时改成坐着看窗外；6.10在心里一直反驳「那也叫事？」时停；6.11在拉长时间轴让你更绝望时停，并且低落期不用。〔证7〕

**本章不新编动作。** 新编一套，就要重新核一遍每一项的前提与停止条件，而这一章的用处不在于此。它的用处是让一个人在难受的当下不必读完六章。〔证3〕

**原稿的三步式恰恰丢掉了这些。** 它写「承认焦虑 → 耐心练习 → 允许练习」，把两项动作连起来，却没有提其中任何一项的停止条件；而其中6.5与6.10两项都明写它们在自我批评强的人身上可能起反作用，都要求改做6.4。一个连做三项的人，比一个只做一项的人更容易在中间某一项上被反作用击中，而剧本没有告诉他哪两项有风险、击中之后改做哪一项。〔证7〕

**这一版也不给次数与时长。** 理由见7.1的最后一行：数字在剧本里看起来像处方，而第六章明写长度是任意的、每项可以只做一到五分钟。〔证1〕

**一句实话。** 砍掉三步式，这一章比原稿短。它本来就该短。一个人夜里坐在桌前，不会读三段作业；他需要的是眼下能做什么、这件事什么时候该停，以及明天有力气的时候去哪里读。这三件事，一张表加一节处境判断就够了。〔证1〕

## 7.6 状态不在表里，或者照做了没有用

**表里没有你的状态。** 用第六章6.12的决策表，或[第五章](Ch05_时间审计.md)5.3的四组观察提示（觉察、规划、沉浸、接纳）。两者都不计分、不设阈值、不作类型分类，也不要求你先归类。〔证3〕

**同时命中好几行。** 先按更靠上的那行。这不是排序游戏，是因为7.1与7.3靠上的几行涉及安全与需要评估的情形，那些有先后，其余没有。〔证2〕

**照做了，没有用。** 第六章6.2明写：如果记录下来的时间绝大部分属第二类与第三类，那么本章的大多数动作对你只是止痛。**止痛不等于无效，但也不该被说成解决。** 八套里没有一套承诺见效。这时候该做的是7.4，不是把6.4再做一遍。〔证8〕

**一套都不想做。** 那是允许的，也是约定一。读完这一章什么也不做，是一个完整的用法。〔证1〕

**越做越难受。** 停下来。依[S03](../SOURCES_SCIENCE.md#s03)与[S05](../SOURCES_SCIENCE.md#s05)，身心类练习存在焦虑、抑郁等不良体验报告，无既往心理问题者也可能出现，个体风险不可预测。停下来不是做错了，是这一项此刻不适合你。不要自行加强度或加时长。〔证9〕

**你的时间不够来自处境。** 见7.4。这是本章必须写清楚的一条，因为原稿把八个状态全部写成了个人的应对问题。〔证10〕

## 本章速记

- 先分诊（7.1），再找状态（7.3），再问处境（7.4）。顺序错了，练习会变成新的自责材料。
- 三步式撤除：原稿把第六章的三项动作连起来做，却没有继承其中任何一项的停止条件；本版一次只给一项，并请你先读那一项的停止条件。
- 中间一列全部取自第六章6.4至6.11，本章不新编动作；「十个技术」的计数已过期，第六章现为八项。
- **6.11「换一把尺子」不用于恐惧时刻。** 该项自带「拉长时间轴让你更绝望就马上停」与「不适合在情绪低落期使用」两条限制，6.12并标注「低落期不用」；原稿把它连同「多数恐惧会缩水」这一无来源的效果主张一起处方给恐惧时刻，已整句撤除。
- 空虚、麻木、恐惧三行不能只由你自己认领：同样的描述既可能是处境，也可能是需要评估的表现，方向相反。
- 「写下感谢时间的三件事」撤除：第六章6.10明写它不是感恩练习，也不要求你感激谁。
- Steel（2007）、Csikszentmihalyi（1990）、Burkeman（2021）、Clear（2018）四项归属全部撤除；前两项分别为层级错配与台账已记的误引，后两项本轮仅书目、未列入任何台账。
- 分钟数的剂量含义撤除：每项可只做一到五分钟，二十五分钟来自番茄工作法、不是研究算出的最优值。
- **每个状态都有处境的那一半。** 五类时间稀缺会被误认成忙碌、拖延、空虚、焦虑与麻木，于是处方变成呼吸与允许，而条件没有变。要处理的是协商排期、拒绝一件事、承认这一季做不了，并给第三类设一个复查条件与复查日期。
- 照做了没有用，多半是因为它是第二类或第三类。止痛不等于无效，但也不该被说成解决。

下一步：[第八章 · 忙碌与空虚的时间](Ch08_忙碌与空虚的时间.md)，八个状态里最常见的两种，各值得写一整章。
