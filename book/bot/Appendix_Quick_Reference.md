# 附录 · 随身卡与练习记录

本附录分为短卡、导航、术语和记录页。只需要随身提示时，可以仅保存下面的「随身卡」，不必把整页打印。各表格是Sonus为本书制作的使用工具，不是量表，也不是经验证的治疗方案。〔证1〕

**这一版撤除了原稿的五样东西**：六型时间模式速查表，其中「恐惧型」与「空虚型」两行把可能需要评估的情形做成了可以自我认领的类型；一周最小计划，它与[第五章](Ch05_时间审计.md)5.6「一次只走一条线，不排四周计划」直接冲突，且其中连续三天的记账要求沿用的是已撤除的七天审计；场景索引里「七天审计」一行；术语表里「时间审计＝七天记录→四类分类→定位泄漏点」与「四维自检＝觉察力 × 规划力 × 沉浸力 × 接纳力」两条；以及一份十一本的推荐书单，其中两本在[第六章](Ch06_时间急救箱.md)已被认定为误引。撤除理由见[第五章](Ch05_时间审计.md)5.2与5.4、[第二十二章](Ch22_时间的阴影与求助.md)22.1与本章〔证7〕。

## 随身卡：此刻先做什么

> **先看安全，尤其是夜里。** 有伤害自己的念头，或已有计划、意图、无法确保眼下安全，立即联系急救并请可信任的人陪同，不要独处。中国大陆医疗急救为120；全国统一心理援助热线为12356，它提供心理支持与危机干预，不替代120；政策要求每日不少于十八小时，不等于全国24小时，实时可用性本书未经拨测，占线时改拨当地精神卫生中心电话。涉及暴力或人身危险拨110。[第二十二章](Ch22_时间的阴影与求助.md)22.1已撤除原稿的「两分钟自评」计分表——**求助不需要先打分，也不需要达标。**〔证2〕〔证3〕
>
> **突发胸痛、心悸、呼吸困难、晕厥、一侧无力，拨120。** 这类症状要先排除躯体急症，不要先做呼吸练习。练习不能排除疾病。〔证2〕
>
> **「来不及」伴随两周以上情绪低落、兴趣丧失、睡眠或食欲明显改变**，先做精神科或临床心理科评估。这可能是抑郁的表现，不是时间管理问题；此时再排更多任务，通常只会让自责加重。这条界线不该由你自己划，见[第二十二章](Ch22_时间的阴影与求助.md)22.3。〔证3〕
>
> **持续时间不是求助资格。** 两周是一个常被引用的参考，不是门槛。出现「我消失了也没关系」这类念头时不用等两周，现在就联系专业支持；严重或迅速恶化时同样不必等满。〔证3〕
>
> **停不下来的担忧，或必须反复检查、必须按固定顺序做完否则极度不安**，先评估焦虑或强迫相关的情形。这不是自律问题，排更多清单只会加重它，见[第二十二章](Ch22_时间的阴影与求助.md)22.3。〔证3〕
>
> **长期超时工作、没有休假、日程不由自己排定之后的疲惫与麻木，更像职业倦怠。** 世界卫生组织把它列为一种职业现象，不是医疗疾病分类，且限于职业情境。这同时意味着两件事：它确实与工作条件有关，而且不能凭「发生在工作里」就排除抑郁或躯体疾病。要改的是安排，不是更多的时间技巧，见[第六章](Ch06_时间急救箱.md)6.2与[第二十章](Ch20_时间的伦理.md)。〔证4〕
>
> **入睡困难、早醒、白天嗜睡已持续一个月以上**，睡眠问题优先于时间安排，见《身体之书》[第六章](../bob/Ch06_身体急救箱.md)。**一直回避体检结果、复查通知或身体上的变化**，见[第二十二章](Ch22_时间的阴影与求助.md)22.6——回避时间信息有时是在回避健康，它可以延误诊断。〔证3〕
>
> **先过前置判断，再谈动作。** 「我没有时间」有两种：状态问题和处境问题。工时超了、照护责任不可转移、通勤占掉两小时、时间与收入直接挂钩、日程不由自己排，这五类是真实的处境，不是心态。本书不把「找回时间感」写成在挤压你的工时、照护负担与不平等安排里继续自我调节的义务；呼吸练习不能把一个六十小时的工作周变成四十小时。三步判断见[第六章](Ch06_时间急救箱.md)6.2。〔证5〕
>
> **已排除以上情形时，可以试一个动作。** 八个里挑一个就够，做完就停；不累计次数，不设完成标准，也不承诺见效。状态很差时只做6.4和6.5，其余等有力气再说。〔证5〕〔证9〕
>
> **可以停，也可以求助。** 任何一项让你更难受就跳过它，每项都写了停止条件。困扰严重、持续或影响生活时可以主动求助，不必先证明自助失败，也不必先做咨询才有资格看精神科。〔证5〕〔证3〕

这张卡不承诺几分钟内见效，不要求把八个动作做完。各动作的做法、调整与停止条件见[第六章](Ch06_时间急救箱.md)6.4至6.11，选择依据见6.12，进一步求助说明见[第二十二章](Ch22_时间的阴影与求助.md)。〔证5〕

**这一版从术语表里删掉了十四条**，分三种情况。

第一种，所据材料本轮仅取得书目或未核读，术语表不以确定语气重复它们：帕金森定律、计划谬误、霍夫施塔特定律、时型、昼夜节律、心流。其中前三项的出处章是[第二章](Ch02_时间去哪儿了.md)2.4，该章现已整章重写：三条「定律」不再称定律，「被反复验证」四字撤除，三项归属全部标未核实；余量一项转[第十章](Ch10_规划与目标.md)处理，该章现已整章重写：「建议不少于两成」的比例已自行撤除，重写后的10.5给出余量的三种形式而不给比例，并补上一条前提——余量以你对那段时间有安排权为前提；三条「定律」的归属在该章10.2逐条标未核实，其中霍夫施塔特定律一条并按台账裁定记明它是自指的，一个说「你的修正也仍然不够」的陈述不能用来决定修正多少。[第四章](Ch04_时间的七个迷思.md)4.5是其中两项（帕金森定律与计划谬误，霍夫施塔特定律不在该章）在本书的第二处出现，该章现已整章重写：两项归属与「所有」「永远」两个全称词一并撤除，其4.12同样记明不采用「不少于两成」这个比例。「心流」的出处章是[第十三章](Ch13_时间与心流.md)，该章现已整章重写：构念归属照台账P30保留（可信度高），核验层级为仅书目这一件事写进正文，由它推出的操作结论一律标未核实；原稿13.2「太易就加约束（限时、加规格）」一行整句撤除，那正是台账点名不能推出的「给限制就更容易进入心流」那条推论；三个条件改以一个编排装置的身份保留，与[第十二章](Ch12_复利与积累.md)12.2、[第十章](Ch10_规划与目标.md)10.4同形；原稿13.4那五处数字、一处频次与一处疗程全部撤除，五个步骤的形状保留并与[第二十三章](Ch23_28_天时间重建.md)23.5对齐。术语表不以确定语气重复它，理由与本条其余五项同。其中「时型有生理基础」与「光是生物钟最强的校准器」两句所据的大众睡眠著作，已在[第三章](Ch03_时间的生理学.md)依台账撤除，与《身体之书》第三章同项处置、口径一致，不再构成跨书矛盾；相关主张现均标未核实，该书不得作为本书任何事实性主张的依据。〔证6〕

第二种，本书自己已认定为假说或造词，不该以术语的身份出现在速查表里：比例假说（三种主观时间加速的解释均无可核验来源，只作假说保留）、时间黑洞、复利三前提、孵化期、晨型锚点与关闭仪式、注意力经济。其中「时间黑洞」的出处章是[第二章](Ch02_时间去哪儿了.md)，该章现已整章重写：原稿十一处（正文十处，含节标题与表头）一并撤除，且没有换一个新名字顶替，其2.7写明改法不是换一个新名字，是不给名字；「注意力经济」已由[第二十章](Ch20_时间的伦理.md)20.3撤出正文，改以一件可查证的商业事实承担；「孵化期」的出处章是[第十一章](Ch11_耐心与等待.md)原稿11.2，该章现已整章重写：这个词降为本书的编排用语，原稿所称的机制（难题「多半」在搁置后被「撞通」、搁置时「后台仍在加工」）一并撤除，只留下一个不担保的「有时」，并补上该说法在心理学史里的出处Wallas（1926）——台账只有书目一行、核验层级为仅书目，该章只用它说一段历史，不用它担保任何做法。〔证6〕

第三种，放进随身卡会造成实际伤害：memento mori与绵延（durée）。前者的问题不在概念，在位置——[第五章](Ch05_时间审计.md)5.4第五种明确指出，「一想到未来就动弹不得」既可能是一种可以慢慢相处的处境，也可能是焦虑或抑郁的表现，两者方向相反，本书无法替你区分；把它做成一条可以随手调用的术语，等于让最需要评估的人在夜里自己给自己开方。后者出自一部本轮仅书目、未取得译本与页码的哲学专著，而它的定义就是不可分割、不可计数——一个不可计数的东西一旦成为随手可调用的术语，最先被拿来做的就是把体验换算成分数，原稿第十六章的练习第五项正是如此。该章已修订并整节撤除该练习，删除照旧，理由更新。〔证6〕〔证7〕

**这一页有禁忌。** 如果「整理自己的时间」让你开始反复计算还剩多少年、并且更慌，不要使用这一页，改为休息或请人陪伴，不必填完。表格空着也可以。如果事情涉及安全、医疗或有时限的权益，记录不能延误实际求助与行动。〔证2〕〔证8〕

## 记录页二：留下、换掉、交给支持

此表不评价人格、症状严重度或练习成绩，也不要求每日填写。**中断时可以重选，不补做；没有帮助时可以换法或停止。** 不要把漏做和方法无效混为一谈。〔证8〕

| 需要考虑的事 | 我的记录 |
|---|---|
| 我目前希望回应的一个需要 | |
| 一个有帮助而且愿意继续的做法 | |
| 若只是中断，我愿意从哪里重新选起 | |
| 若没有帮助，我想暂停或更换什么 | |
| 第一类（我自己能改）里，下周愿意动的一件小事 | |
| 第二类（需要别人参与）里，我准备找谁协商哪一件事 | |
| 第三类（暂时改不了）里，我承认代价的一件处境 | |
| 我为那件处境设定的复查条件与复查日期 | |
| 可以联系的人或专业资源 | |
| 明显恶化时，我准备去哪里获得帮助 | |

**明显恶化时，停止相关练习并及时获得专业评估。** 「我现在就是没有时间，而且这不公平」比「我要学会与时间和解」更接近事实，也更可持续，因为它不需要你每天先说服自己一遍。承认之后要做的最小一件事，是给那件处境设一个复查条件和复查日期，写下来，到期回来看一眼。这段时间里你要保护的不是效率，是不要垮掉。〔证5〕

## 阅读来源的三个提示

**看主张，而不只看书名。** 引用一项研究，必须看它是否研究了相同的人群、方法与结果。一本大众时间管理读物不能承担机制结论，一本回忆录不能承担相关性主张，一门数周课程不能证明本书的单个动作有同等效果。〔证6〕

**看标注的性质。** 「理论模型」提供理解角度，「原典」说明思想出处，「Sonus编写建议」说明本书作了怎样的取舍，它们都不自动等于经验证疗效。〔证6〕

**看未完成的核验。** 台账说明实际获得了全文、摘要还是出版介绍。注明「仅书目」或「未核实」的材料不能承担操作建议的事实基础。本书正文尚有多章未完成这一轮标注，读到带作者与年份的断言时，请回到台账确认它的核验层级。〔证6〕

完整说明见[来源与可信度](../EVIDENCE_GUIDE.md)，原始入口分别见[科学与临床来源](../SOURCES_SCIENCE.md)与[心理实践来源](../SOURCES_PRACTICE.md)。
