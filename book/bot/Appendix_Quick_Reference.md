| 拖延卡死启动不了 | 规划练习（写下动词开头的下一步）+ 专注练习 | [Ch06](Ch06_时间急救箱.md)②⑥ + [Ch07](Ch07_时间场景剧本.md)7.3 |

| 忙了一天没成就感 | 伪工作清扫（列 10 件事，删 1 条） | [Ch08](Ch08_忙碌与空虚的时间.md) |
| 空虚刷了一下午 | 感恩练习 + 创造练习（30 分钟做一件小事） | [Ch06](Ch06_时间急救箱.md)⑤⑧ |

## 📚 推荐延伸阅读

科学/方法
- 《思考，快与慢》（Daniel Kahneman）：决策疲劳与计划谬误
- 《心流》（Mihaly Csikszentmihalyi）：时间感消失的状态
- 《深度工作》（Cal Newport）：整块时间的守护
- 《掌控习惯》（James Clear）：让重要的事自动发生
- 《我们为什么要睡觉》（Matthew Walker）：生物钟与精力节律
- 《168 Hours》（Laura Vanderkam）：时间审计的经典

传统/哲学
- 《道德经》：静胜热，水不争
- 《庄子》：时间长短在体验不在刻度
- 《忏悔录》（奥古斯丁）：时间之问
- 《四千周》（Oliver Burkeman）：与有限性和解
- 《The Time Paradox》（Zimbardo & Boyd）：时间观心理学

## 🗓️ 一周最小计划（读完全书后，先跑这一周）

| 天 | 动作（≤15 分钟） |
|:--|:--|
| 周一 | 定下"本周最重要的一件事"，写动词开头的下一步 |
| 周二 | 记录今天时间（30 分钟颗粒度） |
| 周三 | 记录 + 找出今天最大泄漏时段 |
| 周四 | 记录 + 把要事挪进你的黄金时段 |
| 周五 | 做一次伪工作清扫（删 1 条） |
| 周六 | 半天有结构的闲暇：一段整块投入 + 一段理直气壮的休息 |
| 周日 | 30 分钟周规划：回顾 → 挑下周 1-3 件要事 → 落进日历 + 留缓冲区 |

跑完一周后，进入 [28 天时间重建](Ch23_28_天时间重建.md)。
