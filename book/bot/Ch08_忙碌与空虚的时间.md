# 第八章 · 忙碌与空虚的时间

> 原稿这一章有一种整齐的对称：两种时间病、两张典型一天、一张被动休闲与主动休闲的对照表、一份八条的伪工作清单要你数一数命中几条、一次ABC打标的清扫练习，末尾三部参考文献。它读起来很顺，因为每一半都在指责同一个人：忙的人在做低价值的事，空的人在做假休息。
>
> 这一版拆开三处。第一，**「忙」有两种来源，一种是你的日程里塞满了可以删掉的事，另一种是日程根本不由你排。** 原稿只写了第一种，于是把第二种人的处境记成了他们的判断失误。第二，**真休息与假休息的二分，本书不采用**，《平静之书》10.5已经写明这一立场，本章与它一致；原稿对照表里那个「回血」的格子连同整张表一起撤除。第三，**八条清单不再数**，数出来的是一个分数，而本书第五章、第二十二章都已把计分与阈值撤除。
>
> 三处引用一并撤除：Newport（2016）、Csikszentmihalyi（1990）、Vanderkam（2016）本轮均仅取得书目，其中一部甚至不在原稿正文出现。

## 8.1 先分清：有些「空」不是时间安排问题

下面这些情形请先获取现实中的帮助，不要从本章的清单与练习开始。清单不替代评估，也不替代一次协商。〔证1〕〔证2〕

| 你正在经历的 | 先做什么 |
|---|---|
| 有伤害自己的念头，或觉得活着没有意思 | 立即拨打12356心理援助热线，或前往就近医院急诊；如有人身危险，拨打110。这一条优先于本章其余全部内容 |
| 对什么都没兴趣已经两周以上，伴情绪低落、睡眠或食欲明显改变 | 这是兴趣丧失，可能是抑郁的表现，不是一种可以用日程解决的「空」。先做精神科或心理科评估，见[第二十二章](Ch22_时间的阴影与求助.md)22.3。此时给自己排更多有意义的活动，通常只会让自责加重 |
| 忙碌之后长期麻木、没有休假、日程不由自己排定 | 这是职业倦怠的处境。世界卫生组织把它列为一种职业现象，不是医疗疾病分类，且限于职业情境；它同时意味着不能凭「发生在工作里」就排除抑郁或躯体疾病。本章解决不了，见[第六章](Ch06_时间急救箱.md)6.2与[第二十章](Ch20_时间的伦理.md) |
| 明知该停却停不下来地刷，或必须按固定顺序做完否则极度不安 | 这里有一个分岔：**可以停下来但选择不停**，是习惯问题，本章与[第十章](Ch10_规划与目标.md)能帮上忙；**停不下来**，可能是需要评估的焦虑或强迫相关情形，见[第二十二章](Ch22_时间的阴影与求助.md) |
| 突发胸痛、心悸、呼吸困难、晕厥、一侧无力 | 拨打120，先排除躯体急症 |
| 入睡困难、早醒、白天嗜睡已持续一个月以上 | 睡眠问题优先于时间安排，见[《身体之书》第六章](../bob/Ch06_身体急救箱.md) |

三条限制：本表不是诊断标准，不能用来判断你或别人有没有病，也不能排除风险。12356的实时可用性本轮未拨测，若无法接通，请前往医院急诊或拨打120。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证2〕

**本章的清单与练习都要花时间填，成本不为零。** 对一个每天剩下四十分钟可支配时间的人，让他列出上周十件事再逐条打标，是把一个处境问题改写成一个自律考验。本章因此不设时长、不要求填完，8.6也给了只做一条的版本。〔证3〕

## 8.2 忙而不充实：先问日程是谁排的

原稿这样描写忙碌者的一天：从睁眼忙到闭眼，被消息、会议、临时请求切成几十段，深夜复盘时却说不出今天做成了什么。这个描写是准确的，很多人会在里面认出自己。〔证3〕

它接下来给了一个解释：「浅层工作天然会膨胀并挤掉深层工作，而真正产生价值与成就感的，恰恰是深层工作（Newport, 2016）。」**这条引用撤除。** 该书本轮仅取得书目、未核读，也未列入系列任何台账，因此不承担这个关于工作如何膨胀的机制主张。〔证4〕

撤除引用之后，剩下的观察仍然成立，但它只是观察：**很多人的日程里确实塞满了短、碎、可替代、做完也不留下什么的事，而这些事确实会占掉那些需要铺垫的事的位置。** 这一句不需要来源，你自己的三天记录就能验证——[第五章](Ch05_时间审计.md)5.2的「记录三天，不要估计」正是为此。〔证3〕

真正要补的是原稿缺的那一半：**忙碌有两种来源，处理方式相反。**

| 哪一种忙 | 具体样子 | 能做什么 |
|---|---|---|
| 日程大体由你排，但被低价值的事填满 | 你自己接受的会议、你自己秒回的消息、你自己不肯降级的标准 | 属第六章6.2的第一类，本章8.3与8.6可用 |
| 日程不由你排 | 优先级由别人定、随叫随到、轮班、会议是别人召集的、消息是客户要求秒回的 | 属第二类与第三类，去协商或去承认，见[第二十章](Ch20_时间的伦理.md)与[《力量之书》第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md) |

**原稿只写了第一种。** 于是第二种人读完这一章得到的信息是：你的忙是你自己选的浅层工作。这不是描述，是错判。第六章6.2已经写明本书的立场——不把「找回时间感」写成在挤压你的工时、照护负担与不平等安排里继续自我调节的义务。本章沿用同一句。〔证5〕

原稿还有一句：「忙碌因此成为一种麻醉剂：它让你感到『在努力』，从而免于回答『努力在朝哪里』。」这句话对一部分人是准确的，而且很有用。但它是一个**动机归因**，而动机归因在两种情形下会伤人：一个为了保住工作而加班到十点的人，他的忙碌不是回避，是必需；一个照护者的一天被切碎，不是因为她不愿回答「努力在朝哪里」，是因为她没有完整的时段可以用来回答。〔证5〕

保留它，但改成可自查的形式，而不是对人的判定：**你上一次停下来问「这些忙是在朝哪里」，是什么时候？如果想不起来，是因为不想问，还是因为从来没有一个不被打断的时段可以问？** 后一种答案指向第六章6.2的第二类与第三类，不指向你的动机。〔证3〕〔证5〕

## 8.3 八条常见的样子：看一遍，不要数

原稿列了八条「伪工作」，并要求你「数一数你上周的日程里出现了几条」。**数出来的是一个分数。** 本书第五章5.3已经把0／2／4的打分表撤除，第二十二章已经把「两分钟自评」的计分与阈值撤除，理由都一样：未经量表开发与验证的条目，一旦计分，就把一个人在特定处境下的状态写成了一个可以不及格的位置。〔证6〕

八条本身是有用的，因为它们具体。保留为**描述**，不数、不设阈值、不打分。读一遍，看哪几条让你停下来——让你停下来的那一条才有信息量。〔证6〕

| 常见的样子 | 它是不是你能删的 |
|---|---|
| 可以用一条消息回复，却开成了三十分钟的会 | 若会是你召集的，属第一类；若你是被叫去的，属第二类 |
| 「顺便」参加的、与你无关决策的会议 | 同上。退出一个会议常常需要一次协商，不是一次决定 |
| 反复整理笔记、清单、文件夹，作为「开始工作」的仪式 | 多属第一类，见[第十章](Ch10_规划与目标.md)与[第六章](Ch06_时间急救箱.md)6.7 |
| 过度准备：查第五篇参考资料，而第一篇已经够用 | 多属第一类；若标准是别人定的，属第二类 |
| 秒回所有消息，把它当成责任心 | 分岔：可以停但选择不停，属第一类；岗位或客户要求秒回，属第二类，见[第二十章](Ch20_时间的伦理.md)20.2 |
| 帮别人做本该他自己做的事，做完再抱怨没时间 | 属第一类与第二类之间，见[《力量之书》第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md) |
| 把一天切给十个任务，每个都只推进一步 | 多属第一类，见[第十章](Ch10_规划与目标.md) |
| 用加班时长代替产出 | **若加班是被安排的，这一条不适用。** 它描述的是一种自我安慰，不是一种处境 |

第二列是本章补的，原稿没有。它的用处是：八条里至少有四条通常不是你能单方面删掉的，而原稿把它们一并列在「伪工作」名下，等于把协商问题记成了判断问题。〔证5〕〔证6〕

**原稿的一句排序，本书撤除。** 那句话是：「它比摸鱼更危险，因为它自带正当性。」本书附录速查的术语表对「伪工作」的解释是「看上去在产出、实际在避开要事的忙碌；这是描述用词，不是道德判断」。**正文与术语表在这一处相互矛盾，本章按术语表的口径处理。** 一种活动是不是「危险」，取决于它挤掉了什么，而不取决于它看起来体面不体面；把它排在一个道德序列里，只会让本来就在自责的人多一条自责。〔证7〕

## 8.4 空虚而无事：撤除真休息与假休息

原稿这样写：「终于有了周末，躺着刷了八小时手机，晚上比周五更累。这算不上休息。」接着引 Csikszentmihalyi（1990）说明「低挑战、高刺激的活动不产生充实感，结束后只留下空洞与自责」，并给出一张对照表：被动休闲是刷视频与无目的浏览，挑战几乎为零，当下麻木，结束后更空；主动休闲是做饭、运动、读书、见朋友，挑战略高于舒适区，当下投入，结束后回血。〔证8〕

**这张表整表撤除，理由有三层。**

第一层是引用。Csikszentmihalyi（1990）在系列实践来源台账里是[P30](../SOURCES_PRACTICE.md#p30)，本轮**仅书目、未核读**；台账同时记录本书未取得心流理论的测量学批评、复制研究或系统评价材料。它的构念归属是清楚的，但「被动娱乐不产生充实感、结束后只留下空洞与自责」不在该书的论述范围内，也不能由它推出。〔证8〕

第二层是跨书一致。**《平静之书》10.5「休息不能只分成『松』与『空』」已经写明本书系列的立场**：散步或读纸书不必被预先列作真休息，视频和游戏也不应一概列作假休息；本书不采用这种适用于所有人的二分，也不用「副交感接管」替某类娱乐背书。《孤独之书》第十二章引用了同一节。本章与它们一致。〔证9〕

第三层是这句话本身的伤害。「这算不上休息」是对一个已经很累的人说的。同一节里还有半句更重：「空虚也是时间的清醒剂：正因为无事可做，你才被迫直面『这些时间我本来可以怎么过』。」在一个人的空是失业、病休、退休、或者照护的间隙时，这句话不是清醒剂，是指控。第五章5.4第四种已经处理过同一个错位：原稿在那里给出一条通往心流与沉浸的路线，等于把一个可能需要评估的信号，解释成一种能力不足。本章沿用同一处置。〔证9〕〔证10〕

**替换它的不是另一张表，是四个问题。** 这四问出自《平静之书》10.5，是Sonus的观察问题，不是用感受来判定神经状态：〔证9〕

- 我当时想得到什么？
- 这次使用有没有回应它？
- 结束后是否愿意继续？
- 有没有挤占一件自己更想保留的事？

四个问题里没有一个是「用了多久」，也没有一个的答案是「不该用」。同一节还有一句本章照录：**累的时候没有明显恢复，也不意味着休息不配发生。**〔证9〕

至于本书能确认的部分，第三章3.5与第六章6.9已经写清：离开工位与继续刷手机，两种活动的主观恢复感通常不同；差异有多大、机制是什么，本轮未取得可核验的材料，本书不作解释，也不把它们分成「真的」与「假的」两类。〔证9〕

**还有一个归因需要搬走。** 原稿说「空的人被算法的事填满」，这句话把一件设计出来的事记在了使用者的意志上。[第二十章](Ch20_时间的伦理.md)20.3「注意力商品化：你的时间是别人的生意」处理它，那里的说法更接近事实：刷了三小时不是意志薄弱，而是与一支专业团队对抗了一整个下午。本章不重复该章的论证，只把归因指向它。〔证11〕

## 8.5 共同的缺口，以及它不总是缺口

原稿的论点是本章最好的一处，保留：**忙碌与空虚看似相反，根源相同——日程里没有「我自己选的、要紧的、做得进去的事」。忙的人被别人的事填满，空的人被推送的事填满，都轮不到自己的事。**〔证3〕

中间道路是「有结构的闲暇」：既有全然放松的时间，也有整块的、需要铺垫的时间。原稿写的是「理直气壮地休息，理直气壮地推进」，这个说法保留——它针对的正是8.4那种「这算不上休息」的自我否决。〔证3〕

但要补一句原稿没有的：**对一部分人，这不是根源，是结果。** 当第一类时间只有二十五分钟，「没有自己选的事」不是一个选择失误，是那道算术的结果。对这部分读者，「有结构的闲暇」这个说法预设了闲暇的存在，而它不存在。诚实的版本是第五章5.2第三步与第六章6.2的那一个动作：承认这一季就是这样，给它设一个复查条件和一个复查日期，写下来，到期回来看一眼。这段时间里，你要保护的不是结构，是不要垮掉。〔证5〕

三条入口，与前面各节对应：

- 把要紧的事放进日程：[第十章](Ch10_规划与目标.md)
- 让事做得进去：[第十三章](Ch13_时间与心流.md)（该章现已整章重写，其13.3先分清「很久没有忘了时间」可能是哪几种不同的事，再谈条件与做法，与本章8.4同一处置）
- 让休息是你选的，而不是被判定的：[第十九章](Ch19_日常的时间.md)19.3（该章三用法原带「真休息」这一标签，已按本章8.4与《平静之书》10.5改为「休息」；该章现已整章重写，原稿「唯一不推荐的用法是第四种：无意识填充」一句已按本章8.4的同一理由撤除，改为一条描述，判据沿用第五章5.1留下的那两句）

## 8.6 一个可选的尝试

原稿的练习是「本周任务清扫」，约十五分钟：列出上周实际做过的十件事，逐条打标 A（必须我做且必须做）、B（可以批量、降级或委托）、C（其实可以不做）；选一条C今天就删掉，并观察删掉后世界是否依然运转；选一条B，指定它的批量时段，例如所有消息集中在午饭后二十分钟回。〔证12〕

这个练习的骨架是好的，尤其「观察删掉后世界是否依然运转」这一步——它把一次删除变成一次可撤销的试验，而不是一次决心。保留它。四处改动：

1. **不设时长，不要求列满十件。** 列三件也可以。列不出来，说明这一周你没有可支配的观察余裕，那不是练习失败。〔证3〕
2. **ABC三个字母撤除，改用第六章6.2已有的三类。** 两套分类法并存只会让你多做一次归位。第一类（我自己能改）、第二类（需要别人参与才能改）、第三类（暂时改不了），与第五章5.2第二步逐字相同。〔证5〕〔证12〕
3. **「选一条C今天就删掉」补一个前提：这条得是你能删的。** 若它属第二类，动作是一次协商，不是一次删除，见[第二十章](Ch20_时间的伦理.md)与[《力量之书》第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md)；若属第三类，动作是承认并写下复查日期。**删不掉不是你不够果断。**〔证5〕
4. **「午饭后二十分钟」这个数字撤除。** 批量时段是多长由你定，与第十八章18.5撤除「各二十分钟」同理；实时响应岗位不适用批量，那属第二类。〔证12〕

**停止条件**：如果列清单的过程让你更焦虑，或者你开始在每一条后面写辩解，停下来。这个练习的产出是一条可以删的事，不是一份对自己的起诉书。〔证3〕

清扫出来的空档，不要急着填新任务——这一句原稿写得对，保留。但「先留给第十三章的深度块」改为：**留给什么由你定，长度也由你定。** 第三章3.3已把「专注周期」的具体长度标为未核实，本书不给整块时间的下限；你能守住的四十分钟，就是合格的整块时间。〔证12〕

按约定一，这个练习可以完全跳过，跳过不等于没读，也不构成失败。不累积次数，不设完成标准。〔证13〕

## 本章速记

- 先分诊：两周以上的兴趣丧失是可能需要评估的信号，不是可以用日程解决的空；职业倦怠属职业现象而非医疗疾病分类。
- 忙有两种来源：日程由你排而被低价值的事填满，与日程不由你排。只有第一种能用本章的清单，第二种要协商或承认。
- 「忙碌是麻醉剂」是动机归因。保留为可自查的提问，不用来判定一个人为什么忙。
- 八条常见的样子保留为描述，不数、不打分、不设阈值；补一列「它是不是你能删的」，其中至少四条通常不是。
- 「它比摸鱼更危险」这一道德排序撤除；本章按附录术语表的口径——伪工作是描述用词，不是道德判断。
- 真休息与假休息的二分撤除，与《平静之书》10.5一致；被动休闲与主动休闲的对照表连同「回血」一格整表撤除。
- 「这算不上休息」与「空虚是时间的清醒剂」两句撤除：累的时候没有明显恢复，也不意味着休息不配发生。
- 替换它的是四个观察问题，其中没有一个是「用了多久」。
- 「空的人被算法的事填满」的归因搬到第二十章20.3：那是设计，不是意志薄弱。
- 共同的缺口——日程里没有自己选的、要紧的、做得进去的事——保留；但对第一类时间只有几十分钟的人，这是结果不是根源。
- 清扫练习保留骨架，撤除十五分钟与ABC三字母，补上「这条得是你能删的」与停止条件；空档留给什么、留多长，由你定。
