# 第五章 · 时间审计

> 上一部说清了「时间是什么、为什么会觉得不够」。这一部回答一个更具体的问题：你的时间实际去了哪里，其中哪些是你能改的？
> 这一章给一套记录方法，不给分数。它也不给你定型。「来不及」有三种完全不同的来源，把它们混在一起，是时间之书最容易犯、也最伤人的一个错。

---

## 5.1 先分清：有些「来不及」不是时间问题

下面这些情形请先获取现实中的帮助，不要从本章的记录与观察开始。记录不替代评估，也不替代一次协商。

| 此刻的情形 | 先做什么 |
|---|---|
| 有伤害自己的念头，或觉得活着没有意思 | 立即拨打12356心理援助热线，或前往就近医院急诊；如有人身危险，拨打110。这一条优先于本章其余全部内容 |
| 突发胸痛、心悸、呼吸困难、晕厥、一侧无力 | 拨打120。这类症状要先排除躯体急症，不要先做记录或呼吸练习 |
| 「来不及」的感觉伴随两周以上情绪低落、兴趣丧失、睡眠或食欲明显改变 | 这可能是抑郁的表现，不是时间管理问题。先做精神科或心理科评估，见[第二十二章](Ch22_时间的阴影与求助.md)22.3 |
| 停不下来的担忧，或必须反复检查、必须按固定顺序做完否则极度不安 | 先评估焦虑或强迫相关的情形，见[第二十二章](Ch22_时间的阴影与求助.md)22.3 |
| 长期超时工作、没有休假、日程不由自己排定之后的疲惫与麻木 | 这是职业倦怠的处境。世界卫生组织把它列为一种职业现象，不是医疗疾病分类，且限于职业情境；它同时意味着不能凭「发生在工作里」就排除抑郁或躯体疾病 |
| 入睡困难、早醒、白天嗜睡已持续一个月以上 | 睡眠问题优先于时间安排，见[《身体之书》第六章](../bob/Ch06_身体急救箱.md) |
| 一直回避体检结果、复查通知或身体上的变化 | 见[第二十二章](Ch22_时间的阴影与求助.md)22.6。回避时间信息有时是在回避健康，它可以延误诊断 |

〔证1〕〔证7〕

三条限制：本表不是诊断标准，不能用来判断你或别人有没有病，也不能排除风险。12356的实时可用性本轮未拨测，若无法接通，请前往医院急诊或拨打120。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证1〕

**还有一条边界，它属于本书自己。** 时间记录本身要花掉时间，也会变成一件新任务。对一个每天剩下四十分钟可支配时间的人，要求连续七天、每半小时一格地记账，是把一个处境问题改写成一个自律考验——而它注定完不成，完不成就成了新的自责来源。本章因此把记录缩短为三天，并允许你只记粗颗粒。如果连三天也做不到，那不是这一章失败，直接读[第六章](Ch06_时间急救箱.md)6.2与6.5。〔证2〕

**本书的一条立场。** 本书不把「找回时间感」写成在挤压你的工时、照护负担与不平等安排里继续自我调节的义务。呼吸练习不能把一个六十小时的工作周变成四十小时，「允许自己慢下来」也不能替代有人替你分担两次晚间照护。这两件事都有价值，但它们不在同一个层面上；把它们混在一起，是让承受的一方替安排负责。〔证2〕

## 5.2 记录三天，不要估计

在记录之前，几乎所有人对「我的时间花在哪」的回答都不准。回忆会把一天总结成一个叙事，而叙事丢掉真实的花费：它记得住那次开了一小时的会，记不住中间十七次各三分钟的打断。这是本章要求记录而不是估计的编写理由，它可自查，不来自某项研究。原稿在此引用一本大众时间管理读物，说「人们普遍高估工作时长、低估被碎片吞掉的时段」——该书本轮仅取得书目，未核读，本书不把这句话作为已证结论。〔证2〕〔证4〕

### 第一步：记录（三天，每天几分钟）

四条规则：

1. **颗粒度自定。** 三十分钟一格看得清，一小时一格也够用。更细坚持不下来，那就用更粗的。
2. **当天记，不靠回忆。** 隔几小时补一次即可。睡前一次性回忆一整天，一定会失真。
3. **不评价，只记录。** 这三天你不是来当裁判的。写下实际发生的事，包括你不想承认的那些。
4. **三天就够。** 原稿要求七天，本书改为三天，理由在5.1的最后一条边界里。三天之后想继续记，可以继续；不继续也不影响后面的判断。

〔证2〕

### 第二步：分成三类

这一步与[第六章](Ch06_时间急救箱.md)6.2用的是同一套划分，因为它们要回答同一个问题。

| 类别 | 判断 | 该做什么 |
|---|---|---|
| 第一类：我自己能改 | 只涉及你的选择，不需要别人同意 | 用[第六章](Ch06_时间急救箱.md)6.4至6.11，以及[第十章](Ch10_规划与目标.md)、[第十九章](Ch19_日常的时间.md)19.3 |
| 第二类：需要别人参与才能改 | 涉及工时、分工、照护、委托方 | 去协商，见[第二十章](Ch20_时间的伦理.md)与[《力量之书》第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md) |
| 第三类：暂时改不了 | 通勤距离、家人病情、合同期、轮班表 | 去承认，见[第六章](Ch06_时间急救箱.md)6.5与[第十五章](Ch15_时间与死亡.md) |

〔证2〕

**原稿的四类记账法，本书撤除。** 原稿把每一段时间归入投资、维护、消耗、泄漏四类，并要求算出「今日泄漏合计」。这套命名有两处问题。第一，「泄漏」在任何一个人身上都指向同一个意思：你漏掉了本该属于你的东西。它先给出了道德判断，再去看那个人当天有没有选择余地——一个连续十二小时交付之后在凌晨刷手机的人，在这套记账里记的是泄漏，而他真正需要的可能是睡觉。第二，「投资」把时间当成资本，于是每一段没有产出的时间都自动成为亏损。本书不采用这个前提。〔证2〕

原稿有一条判断标准值得保留，但换了位置：**同样一件事，是经过选择的还是没得选的，结束之后是回血还是更空，这两点比活动本身更重要。** 睡前主动看二十分钟喜欢的视频，与「再刷一条」到一点半，在前一套记账里可能都记作消耗或泄漏，在三类划分里却分别落在第一类与第三类。〔证2〕

### 第三步：只对第一类使用技巧

这是全部三步里最重要的一步，也是原稿缺的一步。

如果三天记录下来，第二类与第三类占了绝大部分，那么本书大多数技术对你只是止痛。止痛不等于无效，但也不该被说成解决。这时候更接近事实的说法是：「我现在就是没有时间，而且这不公平。」它比「我要学会与时间和解」更难听，也更可持续，因为它不需要你每天先说服自己一遍。可以做的最小一件事，是给这个处境设一个复查条件和一个复查日期——「项目交付后」「孩子上小学后」「三个月后」——写下来，到期回来看一眼。这段时间里，你要保护的不是效率，是不要垮掉。〔证2〕

**原稿在第三步放了一句话，本书撤除它。** 那句话是：「如果这七天就是你一生的缩影，哪一类的时间占比最让你不安？」在一个已经让人逐格清点自己的练习里插入死亡提示，没有任何安全边界，也没有任何来源支持它带来好处。它更可能产生的效果是：一个刚记下「今晚刷了两小时手机」的人，紧接着被告知这两小时是他一生的缩影。本书第十五章处理死亡与时间，那一章有自己的前提与不适用清单，见[第二十二章](Ch22_时间的阴影与求助.md)22.3；它不是一份记账练习的结尾提问。〔证2〕

### 一个常见的错位

林澄照着记录三天，算出第一类只有二十五分钟，第二类与第三类合起来占了醒着时间的绝大部分。林澄原本的结论是自己觉察力与规划力都不行，打算从[第九章](Ch09_当下与正念.md)的正念练习和[第十章](Ch10_规划与目标.md)的周计划开始补。但记录里写得很清楚：两个项目并行，排期由别人定，晚间要回消息，通勤单程五十分钟。这四项没有一项属于第一类。要处理的是[第二十章](Ch20_时间的伦理.md)的边界与一次排期协商，不是把二十五分钟排得更满。这是本书的虚构情境，不是测评结果，也不表示所有人的处境都能这样谈。〔证9〕

## 5.3 四维观察提示

记录给出事实，这一节给出模式。

下面四组是**观察提示，不是量表**。它们不计分、不设阈值、不作类型分类，也不承担诊断或疗效测量——本书没有对它们做过任何验证。用法是：读一遍，看哪几条让你停下来，然后去对应的章节。命中几条不说明任何问题，让你停下来的那一条才有信息量。〔证3〕

**原稿在这里放了一份打分表，本书把它撤除。** 原稿要求每题按0分（从不是）、2分（有时是）、4分（总是）打分，四维各算总分，并规定「任何一维低于满分的一半，那一维就是你的短板」。这个安排把一个人在特定处境下的状态，写成了一个可以比较、可以不及格的位置。而它的四组题目全部预设了时间与自主权——「我每周有不被打扰的整块时间吗」对一个日程不由自己排的人来说，答案早已在记录里写着，它测量的不是能力。〔证3〕

## 5.4 六种常见的情形

记录与四维找「哪里断」，这一节找「在什么处境里断」。

下面是六种常见的情形，**不是六种人**。同一个人身上常常同时有几种，也可能一种都不像；这个项目期间像第三种、那段时间像第六种，都很正常。它们由Sonus整理，没有经过量表开发与验证，不用于分类，不表示严重程度，也没有「你是哪一型」的正确答案。〔证3〕

**一、日程全满，却说不出上周做了什么**
常见体验：很忙、很累、很满，复盘时一片空白；一天里有很多事，但没有一件是自己的。
容易忽略的一点：先看日程是谁排的。如果优先级由别人决定、随叫随到、轮班，那这一条属第二类，处理它是去协商，不是去练觉察。「忙碌会带来我在努力的安心」这句判断，本书第六章已说明它出自一本大众管理著作，本轮未取得原文，不作为已证结论。〔证2〕
阅读入口：5.2的记录 → [第八章](Ch08_忙碌与空虚的时间.md) → [第二十章](Ch20_时间的伦理.md) → [第十章](Ch10_规划与目标.md)。

**二、总觉得来不及**
常见体验：越急越做不动，越做不动越急；一件事没做完，已经在想下一件。
容易忽略的一点：这一条有两种可能，处理方式相反。一种是可理解的紧迫感，靠缩小任务与留出余量能缓解；另一种是已经持续两周以上、伴情绪低落或兴趣丧失、或表现为停不下来的担忧与反复检查，那是需要评估的情形，不是效率问题。此时再排更多任务，通常只会让自责加重。〔证1〕
阅读入口：[第二十二章](Ch22_时间的阴影与求助.md)22.3 → [第六章](Ch06_时间急救箱.md)6.4与6.5 → [第十一章](Ch11_耐心与等待.md)11.4 → [第四章](Ch04_时间的七个迷思.md)。

**三、明知要紧，就是启动不了**
常见体验：一再推迟，用忙别的事避开真正该做的那件；拖到截止前才动。
容易忽略的一点：不启动就不会失败，这个安排在短期确实有效，所以它很难自己消失。要处理的不是懒，是它在替你挡住什么。原稿在此引用一项关于拖延的元分析，说它与冲动性及任务情绪相关，而非「懒」——该文是关于拖延的相关因素与理论模型的元分析，本轮未取得原文，本书把它标为未核实，且它不能支持任何具体技术的效果。如果拖延已长期影响收入、学业或健康，先读[第二十二章](Ch22_时间的阴影与求助.md)。〔证1〕〔证5〕
阅读入口：[第二十二章](Ch22_时间的阴影与求助.md)22.3 → [第十章](Ch10_规划与目标.md) → [第六章](Ch06_时间急救箱.md)6.6 → [《力量之书》第十章](../bos/Ch10_Action_And_Execution.md)。

**四、有大把时间，却什么都没剩下**
常见体验：一整天没有人安排，结束时却觉得空；有时间，但没有一件想做的事。
容易忽略的一点：这一条要小心，不要急着认领。「有大把时间」在不同人身上是不同的事——它可能是失业、病休、退休，也可能是照护的间隙。而「什么都没剩下」既可能是缺少投入的对象，也可能是抑郁的表现，两者需要的东西完全不同。原稿在这里给出一条通往心流与沉浸的路线，等于把一个可能需要评估的信号，解释成一种能力不足。〔证1〕〔证10〕
阅读入口：[第二十二章](Ch22_时间的阴影与求助.md)22.2与22.3 → [第八章](Ch08_忙碌与空虚的时间.md) → [第十三章](Ch13_时间与心流.md)。

**五、一想到未来就动弹不得**
常见体验：想到明年、想到十年后、想到老去，就僵住；计划做不下去，也不敢想。
容易忽略的一点：**这一种不能自己认领。** 原稿把它命名为「恐惧型」，并给出一条通往死亡与智慧传统的路线。这个安排有一处必须纠正的错：同样的描述既可能是一种可以慢慢相处的处境，也可能是焦虑或抑郁的表现，还可能与刚刚发生的丧失、诊断或年龄变化有关。本书无法替你区分，也不该由你自己在夜里区分。第十五章处理死亡与时间，那一章有自己的前提与不适用清单；把它当成一种人格类型的入口，是原稿最需要改的一处。〔证1〕
阅读入口：先[第二十二章](Ch22_时间的阴影与求助.md)22.3 → 排除需评估的情形之后，[第十五章](Ch15_时间与死亡.md) → [第十四章](Ch14_时间与衰老.md) → [第十七章](Ch17_时间与遗产.md)。

**六、每天一样，时间像被静音**
常见体验：日子连成一片，记不出区别；一个月和一周差不多长。
容易忽略的一点：这一种最常是处境，不是心态。轮班、重复劳动、长期照护、独自通勤，都会让日子失去可标记的边界。它也可能是耗竭或抑郁的表现。原稿在这里给出一条通往正念与日常的路线——正念练习对部分人可能有帮助，但它改不了轮班表，而对另一部分人还可能带来不良体验。先分清哪一部分属第一类。〔证7〕〔证8〕
阅读入口：5.2的三类划分 → [第十九章](Ch19_日常的时间.md)19.3、[第十八章](Ch18_时间与日常.md)18.3至18.5 → [第九章](Ch09_当下与正念.md)9.5与9.6（练习的情境前提与停止条件）；伴持续低落或功能下滑时，[第二十二章](Ch22_时间的阴影与求助.md)。

关于[第十六章](Ch16_智慧传统的时间观.md)的一句提醒：该章已修订，五段传统文本里核到目标段的只有两段——《老子·道德经》第8章与《无门关》第19则；其余（《道德经》第四十五章、《庄子·齐物论》、《忏悔录》卷十一、Bergson的具体措辞）一律标未核实，不据以给任何建议。原稿参考文献里列有一部时间心理学大众著作，其时间观类型学本轮未取得原文，本书不用它作为任何分类依据；第十六章16.5已同步撤除对该类型学的一切印证性引用。〔证3〕〔证6〕

## 5.6 你的阅读路线

不必打分，也不必排出「最低的那一维」。写下记录里让你停下来的一条，和它指向的入口：

```
我的阅读路线（日期：____）

记录三天之后：
1. 第一类（我自己能改）大约占：________
2. 第二类与第三类合起来占：________
3. 让我停下来的一条：____________________
4. 它有没有 5.1 里的任何一项情形：________
5. 我先读的入口：第__章 ____________
6. 读完之后我愿意试的一个动作：____________
7. 给这个处境设的复查条件与日期：____________
```

两条使用规则：

1. **只对第一类使用技巧。** 这是本章唯一一条硬规则。第二类去协商，第三类去承认，并给它设一个复查日期。把第三类的问题记在第一类的账上，是时间之书最常见、也最伤人的错误。〔证2〕
2. **一次只走一条线，不排四周计划，不重测分数。** 记录与观察全开的安排很难维持，而时间类练习一旦变成清单，最容易长出一种新的考核：每天检查自己有没有漏。先处理让你停下来的那一条。〔证3〕

写下来的意义不在于承诺，在于它把「我为什么总是来不及」这个此刻无法回答的问题，换成「这三天里哪一段是我能改的」这个可以回答的问题。〔证2〕

## 本章速记

- 先分诊：自伤念头、急性躯体症状、持续两周以上的低落、停不下来的担忧、长期超时之后的麻木、持续一个月以上的睡眠问题、对健康信息的长期回避，都不属于本章的记录对象。
- 记录三天，不要估计。颗粒度自定，三天做不到就直接读[第六章](Ch06_时间急救箱.md)6.2。
- 分成三类：我能改的、需要别人参与的、暂时改不了的。**只对第一类使用技巧。**
- 原稿的七天四类记账（投资、维护、消耗、泄漏）、0—2—4打分、「低于满分一半即短板」、以及「这七天是你一生的缩影」那句提问，均已撤除。
- 六种情形是常见的处境，不是六种人；其中第四种与第五种不能自己认领，先走评估。
- 本书不把「找回时间感」写成在挤压你的工时与照护负担里继续自我调节的义务。
