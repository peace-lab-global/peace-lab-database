# 第二十一章 · 个人时间系统

> 原稿这一章给的是四步（审计、分级、节奏、复盘）、三张表（日、周、季）、三条底线和一页纸模板，章首写着「技巧是零散的招式，系统是每天的呼吸」。
>
> 这一版把三张表逐行退回各章。理由不是它们不好，而是每一行都已经有一章写过它，而那些章在这一轮里都改了：日表里的「锚点10分钟＋关闭5分钟」，第十八章18.3明写「长度由你定，本书不给分钟数」；周表里的「一次168盘点微调」，第五章5.2已把记录缩短为三天；季表里的「每季度重做一次」，第十四章14.6明写「不设回看日期」。一份总表如果留着这些行，读者就会在同一本书里读到两套。〔证1〕
>
> 章名保留「系统」二字，是为了不打断本书导航页与附录速查里已经写好的路标；这个词的承诺地位在21.2撤除。21.4的节号也保留——第二十三章第28天按节号引这一页。〔证1〕

## 21.2 「系统」这个词：一处可以留的比喻，三处问题

先说这句话为什么有吸引力，因为它说的是一件真事：零散的动作在忙起来的时候最先掉，而一件有固定位置的事掉得慢一些。这一章也确实要处理长期。问题不在「长期」，在原稿给它的解法。〔证1〕

**章首那句「系统是每天的呼吸」，说的是自动性。** 呼吸不需要提醒，不需要意志力，也不会在你状态差的那天缺席。本轮取得的关于习惯自动化的一手材料是[P06](../SOURCES_PRACTICE.md#p06)：Lally等（2010），核验层级为**摘要**——取得出版方存入Crossref的摘要，未取得全文。它的边界写着：这不是神经成像，也非直接观测神经回路形成；模型估算的天数不能冒充每人的实测期限，不支持二十八天必成习惯，更不能以未达期限评价意志或人格。〔证7〕

据此，「每天的呼吸」是一个可能的结果，不是一个可以承诺的安排，也不是一条期限。它更不是「系统」这个装置自带的属性——一份日程不会自己变成呼吸。〔证7〕

**林澄在第二十三章走完四周之后来读这一章。** 第四周第28天那一行要求「只写下你四周里真正留下的一两项」。林澄写下两件：下班前把下一步写清楚，通勤路上不打开工作软件。原稿的三张表里，日节奏四项留了一项，周节奏三项留了半项，季节奏三项一项也没留。第二周上夜班，第三周整周跳过。〔证8〕

这不是不及格。三张表里的多数行本来就要求一件林澄没有的东西：一段由自己排的时间。要动的东西从头到尾都在[第二十章](Ch20_时间的伦理.md)20.2那一边，不在这张表里。这是本书的虚构情境，与[第五章](Ch05_时间审计.md)5.2、[第二十三章](Ch23_28_天时间重建.md)23.6的林澄是同一个人，不是访谈、病例报告或测评结果，也不表示所有人的取舍都该长这样。〔证8〕

**第一处问题：「忘了做也会被节奏找回来」是一句承诺，而它没有来源。** 同系列的两本书已经处理过同一句：[《平静之书》第二十一章](../bop/Ch21_Personal_Peace_System.md)21.4明写「这三条路不能合并成一句『回到最小剂量』」；[《孤独之书》第二十一章](../bol/Ch21_Personal_Loneliness_System.md)21.2把「技术会被忘掉，系统替你记得」整句撤除，理由是它把断掉解释成记忆问题，而断掉通常说明条件变了。〔证9〕

**第二处问题：「系统」这个词是从工程借来的。** 有输入、有产出、有正常运转与故障两种状态。原稿这一章另外两处属于同一套语言：底线一的「不弃系统」，练习结尾的「一个活着的系统」。这套词用来讲机器是准确的，用来讲一个人身上发生的事情有一个后果：故障归因于系统，而系统是你搭的。所以断掉最后总会回到你身上。〔证1〕

**第三处问题：这一章的三张表与本书前面各章各说一套。** 不是措辞不同，是内容冲突：

| 三张表里的一行 | 冲突的那一章 |
|---|---|
| 日：晨锚点「10分钟」 | [第十八章](Ch18_时间与日常.md)18.3「长度由你定，本书不给分钟数」 |
| 日：晚间关闭「5分钟」 | 同上，且18.4不给「睡前一小时」这类时长 |
| 日：一个心流块 | [第十三章](Ch13_时间与心流.md)原稿13.4的90分钟已随该章重写自行撤除，其13.5照录第十八章那三条；[第十八章](Ch18_时间与日常.md)18.5明写「整块时间长度不设下限」 |
| 周：周规划30分钟 | [第十章](Ch10_规划与目标.md)原稿10.3同一个数字，该章现已整章重写，重写后的10.6已自行撤除它，且重排不设周期 |
| 周：一次168盘点微调 | [第五章](Ch05_时间审计.md)5.2已把记录缩短为三天，原稿的七天已撤除 |
| 季：每季度重做一次 | [第十四章](Ch14_时间与衰老.md)14.6「不设时长，不设回看日期」 |

〔证3〕

**这一版保留什么。** 「招式／呼吸」这个比喻可以留，留下的只是那个观察，不是它后面的承诺。长期这件事仍然要处理，但它要处理的不是记不记得，而是三件别的事：哪一项你愿意留着（21.4）、断掉之后怎么办（21.5）、什么时候回看、回看什么（21.6）。三件都不需要一份日程。〔证1〕

〔证3〕〔证4〕

**这一版用什么代替三张表：一个入口，五个问题。** 前四问沿用[《平静之书》第二十一章](../bop/Ch21_Personal_Peace_System.md)21.2，第三问与[《孤独之书》第二十一章](../bol/Ch21_Personal_Loneliness_System.md)21.3的第三问同。〔证9〕

1. 它准备回应什么需要？
2. 在什么情形下比较容易做到？
3. **它需要什么条件，而这些条件现在有没有？**
4. 什么情况下你会缩短、替换或停止它？
5. 如果不继续，还有别的做法或别人可以找吗？

第三问在本书有一个具体的落点。这本书反复写明一项动作有现实前提：整块时间需要一段不被打断的时段（第十八章18.5），关闭仪式需要有一个「下班」的动作可以放在那里（18.4），三账户的「人」那一栏需要还有一个人在（第十七章17.4的末段，该章已修订并把这一前提写进正文；其练习见17.7）。前两问假设你能做，第三问问的是你能不能做。少了它，做不到就会被记成不想做。〔证3〕

五问都是Sonus的编排，不是处方，不设最低有效剂量。各项做法原有的停止条件仍然适用；把一项做法简化之后，不能声称它保留了完整做法的效果。〔证1〕

**本书的一条立场，在这一章同样适用。**〔证10〕

本书不把「找回时间感」写成在挤压你的工时、不可转移的照护负担、通勤与居住位置、时间与收入直接挂钩、日程不由自己排这五类处境里继续自我调节的义务。有些时间稀缺是处境造成的，处境造成的稀缺只能由处境处理。把它写成个人的能力缺口，结果是双重的：条件没有变，而多了一条自我指控。

下表是[第六章](Ch06_时间急救箱.md)6.2的五类处境。它们不适用本章任何一项安排：

| 处境 | 它长什么样 | 去处 |
|---|---|---|
| 工时本身超了 | 加班常态化，没有完整的休息日，下班后仍要回消息 | 第六章6.2第二类、[第二十章](Ch20_时间的伦理.md)20.2 |
| 照护责任不可转移 | 幼儿、失能老人、慢性病家人，没有人可以替你 | 第六章6.2第三类、第二十章20.2 |
| 通勤与居住位置 | 单程一小时以上，一天里有两个小时不属于你 | 第六章6.2第三类 |
| 时间与收入直接挂钩 | 计件、零工、个体经营，停下来就没有钱 | 第六章6.2第二类与第三类、第二十章20.2 |
| 日程不由自己排 | 轮班、随叫随到、优先级由别人决定 | 第六章6.2第二类，去协商。协商与拒绝都预设你可以开口而不失去什么，这个前提不成立时见[第七章](Ch07_时间场景剧本.md)7.4 |

**诚实的对价。** [第五章](Ch05_时间审计.md)5.2与第六章6.2都写过，这里再说一次：如果记录下来第二类和第三类占了绝大部分，那么本书大多数技术对你只是止痛。止痛不等于无效，但也不该被说成解决。这时候更接近事实的说法是「我现在就是没有时间，而且这不公平」，它比「我要学会与时间和解」更难听，也更可持续，因为它不需要你每天先说服自己一遍。可以做的最小一件事，是给这个处境设一个复查条件和一个复查日期，写下来，到期回来看一眼。这段时间里，你要保护的不是效率，是不要垮掉。〔证10〕

## 21.4 一页纸：可以填，也可以不填

节号保留，[第二十三章](Ch23_28_天时间重建.md)第28天按节号引这一页。表换了。〔证3〕

以下表格是Sonus设计的可选记录。没有分数，不设阈值，不用于判断你的时间安排属于哪一类，也不用于判断它是否达到任何标准。〔证1〕

| 项目 | 我的安排 |
|---|---|
| 我此刻最想回应的一件事（可以写「说不清」） | |
| 我愿意保留的一两项做法；也可以留空 | |
| 它在什么情形下比较容易做到 | |
| 它需要什么条件，而这些条件现在有没有 | |
| 什么情况下我会缩短、替换或停止它 | |
| 断掉之后，我愿意怎样重新选择 | |
| 这一项没有用，或变得更难承受时，我可以找谁 | |
| 出现危险或功能受损时，去哪里获得帮助 | |
| 哪些部分不是我能动的（工时、照护、通勤、排班） | |

三点说明。

**第一行可以从第五章拿。** 第五章5.6要求写下记录里让你停下来的一条，和它指向的入口。那一行就是这张表的第一行。写不出来就写「说不清」——第五章5.3写明四维是帮助说话的编排，说不清是哪一维不是缺陷。〔证3〕

**最后三行是这张表里最容易被跳过的，而它们常常最要紧。** 第七行问的是人，第八行问的是去处，第九行问的是边界。一个人如果只填前六行，他填的是一份自我调节的计划；填了后三行，他填的才是一张有出口的纸。[第二十二章](Ch22_时间的阴影与求助.md)22.5写明不愿求助有时是在衡量真实代价，所以第七行可以写「暂时不找任何人」——但请把它写出来，不要留空。留空与写下「暂时不找」是两件不同的事：前者是一个没答的题，后者是一个已经做出的决定。〔证10〕

**如果填表本身已经增加负担。** 可以只填最后三行，或者完全不用这张表。第二十三章第28天写的是「只写下你四周里真正留下的一两项，其余留空」，并写明「可以写『一项也不留下』，那也是填完」。这张纸不需要贴在任何地方：第十四章14.6已明写不要求把纸贴在什么地方，原稿「把这页贴在桌前或存为手机首屏」一句已撤除。〔证3〕

## 21.5 断掉之后：三条不同的路

原稿没有这一节。它把断掉放在底线一里处理：「忙乱时期只跑最低配，不弃系统」。这一版按[《平静之书》第二十一章](../bop/Ch21_Personal_Peace_System.md)21.4的三条路写。〔证9〕

**一，中断了，但原先那一项确实有帮助。** 可以在条件允许时重新开始，也可以先调整提醒的方式。不补做漏掉的天数，不从头重读，不比较完成天数，不设及格线。这是[第二十三章](Ch23_28_天时间重建.md)23.2的用法，本章沿用。〔证3〕

**二，一直在做，却没有帮助。** 先描述原本期待的帮助是什么，再看方法与需要是否匹配。没有明显不适也不意味着必须无限期坚持。可以换一项、停止记录，或与专业人员讨论。本书不预先把无效归因于读者没有耐心。〔证1〕

**三，做着做着明显更难受，或睡眠、情绪、功能在变差。** 这不该被叫做「掉线」，也不该被叫做系统的正常维护。停下来，见[第二十二章](Ch22_时间的阴影与求助.md)22.3、22.4；有即时危险时拨120。依[S03](../SOURCES_SCIENCE.md#s03)与[S05](../SOURCES_SCIENCE.md#s05)，身心与行为类练习存在焦虑、抑郁等不良体验报告，无既往心理问题者也可能出现，自行加强或加时可能起反作用。〔证11〕

**这三条路不能合并成一句「回到最小剂量」。** 有时需要回来，有时需要换路，有时需要让别人接手。原稿的最低配把三条合并成了一条，代价是：一个正在变差的人被建议从更小的剂量重新开始。〔证9〕

**断掉通常说明条件变了。** 项目上线、家里有人病、搬到一个新城市、一段关系结束、开始上夜班。把这类断掉叫做「忘了」，解决它的办法就是提醒；而实际需要的往往是减掉一件事，或者承认那一段时间本来就没有余地。《平静之书》第二十一章21.3把这条写在明处：日程本来就很满时，先讨论能否减少负担，比再增加一项「很小的练习」更值得考虑。〔证9〕

## 21.6 什么时候回看，回看什么

原稿给的是「每周三个问题（放进周规划）」与「每季度重做一次」。这一版不给周期。九十天没有来源，「每周」也没有；两者都是编排，而它们一旦写进日历，就变成了两份新的未完成记录。〔证1〕

回看什么时候有用：生活出现变化的时候（换岗、搬家、一段关系结束、开始照护、开始轮班），或者一项做法你已经做了一段时间、想知道它还回应不回应原来那个需要的时候。两种都不需要日历。〔证1〕

回看什么，沿用原稿的三问，去掉「每周」：

1. 什么有效？（留下，不必加码）
2. 什么失效，或者让你更难受？（删掉它，不重试）
3. 只想留一件，是哪一件？（只写一件）

第三问只写一件，是因为写三件的结果通常是做零件。原稿的「大多数人的选择是三天记录、周规划、晚间关闭」已撤除——本书没有分母，也没有做过调查。这三项本身可以留，但它们是三项做法，不是一份人群统计。回看不判断是否「进步」：如果发现自己最需要的是休息、分担或一次评估，那已经说明原先设想的方法未必是第一优先，也可以就此结束这一页。〔证1〕

**本章唯一一条硬规则，是原稿的底线三。** 系统为生活服务，不是生活为系统服务。当一份安排开始伤害关系与睡眠，先修那份安排，不修你。这条规则优先于本章其余全部内容：它与21.4那张表冲突时，按这条处理；它与你想留下的某一项冲突时，也按这条处理。什么时候这件事已经不由一本书处理，见[第二十二章](Ch22_时间的阴影与求助.md)22.3、22.4。〔证10〕

**关于「最低配」，两条撤除理由。** 原稿底线一写「系统崩溃时退守的最低配要提前定好……忙乱时期只跑最低配，不弃系统」。

一是那两个数字是剂量。「每天一件要事＋每周一次30分钟规划」与21.4的「约30分钟」，同属本书已经在[第八章](Ch08_忙碌与空虚的时间.md)8.6、[第十二章](Ch12_复利与积累.md)12.6、[第十八章](Ch18_时间与日常.md)18.3与[第二十章](Ch20_时间的伦理.md)20.4分别撤除的那一类分钟数。〔证3〕

二是「不弃系统」与底线三直接冲突。底线三说人比系统重要，底线一说不许弃系统——而忙乱时期恰恰是人最需要被放在前面的时候。两条同时写在同一节里，读者只能挑一条执行，而原稿没有告诉他挑哪一条。〔证3〕

## 本章速记

- 这一章撤除了日、周、季三张表、三条底线里的两条、一页纸模板的六行，以及「约30分钟」「每周一次30分钟规划」「10分钟＋5分钟」「30-40分钟」「一个下午的一半」六个数字。逐行去向在21.3。
- 「忘了做也会被节奏找回来」是一句没有来源的承诺；「系统是每天的呼吸」说的是自动性，而习惯自动化本轮只有摘要级材料，且该材料的边界明写不能以未达期限评价意志或人格。
- 「系统」「不弃系统」「一个活着的系统」是从工程借来的一套词。它们用来讲机器是准确的，用在人身上有一个后果：故障归因于系统，而系统是你搭的。
- 代替三张表的只有五个问题，其中第三个是本书加的：它需要什么条件，而这些条件现在有没有。
- Clear（2018）与Vanderkam（2016）均未列入任何台账，来源归属撤除，标未核实；Newport（2016）在本章是孤儿参考文献，章末整段撤除。
- 断掉之后三条路：中断了但有帮助、一直在做却没有帮助、做着做着明显更难受。三条不能合并成一句「回到最小剂量」。
- 最低配撤除，两条理由：那两个数字是剂量；「不弃系统」与「人比系统重要」直接冲突。
- 回看不设周期。九十天没有来源，「每周」也没有。三问保留，「大多数人的选择」撤除——本书没有分母。
- 一页纸九行，可以不填；最后三行问的是人、去处与边界，最容易被跳过，也常常最要紧。这张纸不需要贴在任何地方。
- 本章唯一一条硬规则是原稿的底线三：当一份安排开始伤害关系与睡眠，先修那份安排，不修你。
- 出现自伤念头、持续绝望感、时间焦虑占据思绪、一个月以上的睡眠问题、无法进食睡眠或上班：这一章的全部内容不适用，先读[第二十二章](Ch22_时间的阴影与求助.md)22.1。
- 本书不把自我调节写成留在挤压你的工时、不可转移的照护与不由你排的日程里的义务。
