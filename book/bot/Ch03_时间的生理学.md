# 第三章 · 时间的生理学

> 原稿在这一章给出了一套完整的生理叙事：昼夜节律、超日节律、时型、多巴胺与时间知觉，四处引用同一本大众睡眠著作（正文三处、参考文献一条），末尾附一张「典型时段—身体状态—适合安排」的对照表，以及一份连续五天、每天五个固定时间点、按一到十分打分再求平均并画出曲线的作业。这一版把四处引用全部撤除，把那张表退回为常见描述，把作业改成一次不设天数、不打分、不画曲线的可选观察，并在章首补一条原则：机制解释不是诊断工具。〔证1〕

撤除的理由不是那本书写得差，而是它已被记录存在事实错误。中文读者最常遇到的一本睡眠科普是Walker（2017）《我们为什么要睡觉》。2019年出现一份公开、逐页、未被撤回的批评文献，指其把睡眠时长缩短与死亡率及癌症发病率不当关联、否定急性睡眠限制在重度情绪障碍中的临床用途、向国际机构归入一条伪造的公共卫生声明、歪曲官方睡眠指南、改动已发表图表并引用数学上不可能的统计增幅。该批评由个人撰写，本轮未经第三方逐条复核，因此列为**已公开指控**，而不是已证实的错误；但仅凭它存在且未被撤回这一点，就足以要求本书改引可核验的一手材料。台账对此的结论只有一句：该书不得作为本书任何事实性主张的依据。〔证2〕

这一章因此变得比原稿短气了：它不再解释你身体里发生了什么，只说明哪些说法有已核读的材料支持、哪些是通行但未取证的常识、哪些是本书的编排。这份短气是有意的。一本讲时间的书，如果在第一处生理叙事上就用一本已被逐条批评的科普作担保，那么它后面所有的日程建议都建立在借来的确定性上。〔证1〕

## 3.1 先说清楚：机制解释不是诊断工具

这一条与《身体之书》第三章3.1一致，是本章其余各节的前提。

- **不能凭主观时间感推断生理状态。**「今天时间过得特别快」不说明你的节律对齐了；「这一小时像十分钟」不说明你缺觉，也不说明任何神经递质偏高或偏低。这类对应在个体层面不可靠，本书不提供任何换算。〔证3〕
- **不能凭状态给自己归因。** 上午写不动，可能是没睡好，也可能是这件事本来难、你不想做、或者你从早上六点起就在回消息。本章给的是几个观察角度，不是一套可以套在自己身上的病因学。〔证1〕
- **不能把时段表当成参考区间。** 3.4那张「典型时段」表是常见描述，不是你的身体，也不是一份体检报告后面的正常值。你真正头脑清楚的时段只能由你自己观察得出，不能由一本书告诉你。〔证4〕
- **需要排查疾病时，先做医疗评估。** 成人慢性失眠的一线治疗是多组分睡眠认知行为治疗（CBT-I），不是本章的节律建议；睡眠卫生教育不宜单独作为治疗。关屏幕、放松与作息调整不等于治疗失眠。〔证5〕

如果你此刻有伤害自己的念头，或者「来不及」的感觉伴随两周以上情绪低落、兴趣丧失、睡眠或食欲明显改变，本章不适用，请先去[第六章](Ch06_时间急救箱.md)6.1或[第二十二章](Ch22_时间的阴影与求助.md)。中国境内突发紧急医疗情况拨120，心理援助可拨12356（每日不少于十八小时，不等于全国24小时；实时可用性本书未经拨测），涉及人身危险拨110。〔证6〕

## 3.2 昼夜节律：共识说了什么，没说什么

人体有一套以大约二十四小时为周期的作息调度，睡眠与觉醒、警觉与困倦、体温与激素的涨落都随它起伏。这个说法在中文科普里出现得极多，本轮却没有为它取得可核验的一手来源，本书把它作为通行生理学常识使用，并标**未核实**。〔证8〕能负责任引用的，是下面这份共识。

**已核验的部分。** 美国睡眠医学会与睡眠研究学会2015年的联合共识针对18至60岁成人建议：规律地每晚睡至少7小时；睡眠健康不仅涉及时长，也涉及质量、时间安排与规律性；年轻成人、补偿睡眠不足者及患病者可能适合超过9小时。〔证7〕

由此能推出的只有三条：

1. **规律性本身是共识明确纳入的维度。** 这一条对时间安排的用处最大，而且它比原稿的要求低得多：它不要求你早睡，也不要求你五点起床，它只说每天的作息大致对齐是一件被写进共识的事。〔证7〕
2. **不存在人人适用的唯一时长。** 不能要求恰好8小时，也不能把超过9小时一概判为疾病或认为越多越好。〔证7〕
3. **共识给的是群体健康关联，不是个人必然结局。** 少睡一晚不等于第二天必定出错，长期不足也不等于必定生病。把群体数据读成个人命运，是这类共识最常被误用的方式。〔证7〕

**原稿写了三条，都依赖已撤除的那本书。**

| 原稿表述 | 处置 |
|---|---|
| 「光是生物钟最强的校准器」 | 标未核实。本轮未取得可核验的一手来源支持「最强」这个比较级，本书也不给任何照度数字〔证8〕 |
| 「早晨接触自然光帮身体上调，晚上屏幕光则不断把时钟往后推」 | 标未核实。方向看似合理，但「往后推」的幅度与时机本轮没有取证，本书不给时长规定，也不把它写成一条因果〔证8〕 |
| 「熬夜不会多出时间，只会透支第二天：睡眠不足同时损害注意力、情绪与记忆巩固」 | 前半句是算术，保留；后半句标未核实。它是通行说法，本轮未取得可核验的一手来源，本书不给任何量化〔证8〕 |

保留的那半句不需要生理学担保：夜里多出来的三个小时，是从第二天的清醒时间里借的。这一点由时钟保证，不由激素保证，也不需要任何研究替它作证。〔证1〕

原稿在这一节还写过「皮质醇清晨升高帮你醒来、褪黑素夜间升高的前提是黑暗」。这属通行生理学常识，本轮同样未取证，标为未核实；本书不据它规定你几点该关灯。〔证8〕

## 3.3 超日节律：存在与长度是两件事

原稿写「研究者在一天中观察到多个以小时计的起伏循环」，并据此推出「专注约一小时后效率明显下降，需要短暂恢复」。

这里必须把两件事分开。

**第一件：人的警觉与精力在一天中确实有起伏。** 这一点连3.2那份共识也间接承认，它把「时间安排」列为睡眠健康的一个维度。〔证7〕

**第二件：起伏的周期有多长、专注能维持多久，本轮没有取得可核验的来源。**「一小时」这个数字不在任何已核读的材料里，本书标为未核实，并且不用它规定任何事。〔证9〕

分档的直接后果是，原稿由此推出的两条都不再成立：

- **「一鼓作气干8小时基本不成立。」** 作为经验观察可以保留，但它不需要一个周期长度来支持，也不该反过来被用作「所以你每小时都必须停一次」的依据。〔证1〕
- **「波谷硬撑，只会用双倍时间完成一半质量。」** 这是一个带倍数的量化主张，没有任何来源。撤除。你能说的只有「我硬撑的那两个小时，产出比前面差」，那是你自己的观察，不是一条可以引用的定律。〔证9〕

所以本书后面各章讲时间块设计时，长度由你定，不由生理周期定。[第十三章](Ch13_时间与心流.md)讲整块时间，[第二十一章](Ch21_个人时间系统.md)讲长期安排，两处都不引用一个「专注周期」的下限，也不声称某个分钟数是进入状态的门槛；第二十一章已按本记录修订，其原稿日节奏里的「锚点10分钟」已随整表撤除。〔证1〕

原稿在这一节还写过一句「休息属于专注本身」。这句的立场本书保留，但依据换了：不是因为你的注意力周期到点了，而是因为一直不停的人最后往往什么也没做完，这一条由经验支持，由[第六章](Ch06_时间急救箱.md)6.2的处境判断兜底。〔证10〕

## 3.4 时型：早鸟与夜猫，以及本书为什么不给结论

有人清晨头脑清醒，有人深夜效率惊人。这种稳定的偏好通常被叫作时型（chronotype）。

原稿写「时型有明显的生理基础，并受年龄影响（比如青少年普遍偏晚型，这是生理现象而非懒惰）」，引的还是那本已撤除的书。处置分两半：

- **「时型有生理基础」与「青少年普遍偏晚型」：** 本轮仅取得书目，未核读原文，标**未核实**。本书不据此作任何断言，不给你分型，也不把它当成对谁的辩护或指控。〔证9〕
- **「这是生理现象而非懒惰」：** 这句的立场保留，但依据换了。保留它的理由不是生理学，而是本书的伦理红线：一个人能支配的时间和作息，很大程度上由工时、轮班、照护与通勤决定；把这些写成自律问题，是让承受的一方替安排负责。〔证10〕

**「黄金时段」这个词，本书这样用。** 它指你观察到自己头脑比较清楚、比较做得动难事的那一段时间。它是本书的编排用语，不是一个可测量的生理量，没有标准长度，也没有标准时刻。原稿「黄金两小时」里的「两小时」已撤除。[第十章](Ch10_规划与目标.md)、[第二十一章](Ch21_个人时间系统.md)与[第二十三章](Ch23_28_天时间重建.md)都用这个词，指的都是同一件事：你自己的观察结果。〔证4〕

下面这张表原来排在原稿里，看起来像一份参考区间。这一版保留它的内容，但把它标为**常见描述**：本轮未取得可核验来源，不能用来判断你应该在几点做什么。〔证4〕

| 时段 | 常听到的说法 | 本书的态度 |
|---|---|---|
| 起床后一到三小时 | 渐入状态，适合最难的事 | 未核实。对一部分人成立，对刚下夜班的人不成立〔证4〕 |
| 上午中段 | 一天的高峰 | 未核实。而且它假设你的日程由你排；[第六章](Ch06_时间急救箱.md)6.2的第五类处境正是日程不由自己排〔证10〕 |
| 午后 | 明显的低谷 | 未核实。午后困倦是常见报告，但把它当成必须安排小憩的生理窗口，本书不作主张〔证4〕 |
| 傍晚 | 第二个高峰 | 未核实〔证4〕 |
| 夜晚 | 状态下降，适合收尾 | 未核实。对夜班者与照护者，这一段可能是一天里唯一属于自己的时间〔证10〕 |

一个可以自己回答的问题：你真正头脑最清楚的时段是几点？过去一周，你把最难的事放在了那个时段，还是放在了刚好有空的时段？这两个时段不是同一个的时候，原因也常常不在你。〔证10〕

## 3.5 时间感：当下的速度与回望的长度

为什么假期结束时回头看「怎么就过完了」，而度假当时并不觉得快？

原稿在这里给了一个解释框架，说它「被广泛接受」，并把多巴胺系统写进来：「多巴胺系统在奖赏与新鲜刺激中高度参与，也深刻影响人对时间间隔的估计」，再用它解释「刷手机一小时像十分钟，专注创作一小时像三分钟、回忆却很厚」。

**机制解释已撤除。** 关于多巴胺与时间知觉的研究多在动物与实验室条件下进行，把它们外推到「日常刷屏为什么觉得快」，中间隔着剂量、任务、情境与物种，本书没有材料走完这段距离。「被广泛接受」这个说法也一并撤除：本书不能凭印象替一个研究领域宣布共识。〔证11〕

**保留下来的是两种可以自查的主观经验。**

- **当下的速度感，与是否在盼着结束有关。** 无聊或煎熬的时候，注意力反复回去看时间，于是时间走得很慢；投入的时候不去看，于是过得快。这是每个人都能核对的描述，不需要神经递质作担保。〔证4〕
- **回望的长度，与记住了多少有关。** 新鲜而密集的经历留下更多可以被回忆的落点，回望时占据更长的主观时间；雷同的日子留下的落点稀少，回望时被压缩成一瞬。〔证4〕

**第二条是假说，不是结论。** 本书把它标为假说：本轮未取得可核验的一手来源。[第十四章](Ch14_时间与衰老.md)已经把它写作「记忆密度假说」，本章与它一致；[第九章](Ch09_当下与正念.md)也用到这个说法，该章现已整章重写，两处表述移入其9.3与9.4，假说标注照旧，并另补一条本章没有写的区分：原稿9.2那个「正念拉长时间感知」的说法里，当下的时间过得慢与回望时觉得那段时间长是两种不同的判断，本章的说法只涉及回望这一种。[第十四章](Ch14_时间与衰老.md)14.2已就三种假说作完整处置，并补上本章没有说的一件事：回望已经过去的十年与预估接下来的十天是两种不同的判断，本书的说法只针对回望这一种。〔证11〕

由这条假说推出的那句话，因此也要降级。「想让人生显得长，办法是增加新鲜经历与全然在场的时刻」是**本书的编写立场**，不是一条被证明的因果。它还有一个原稿没写的边界：增加新鲜经历需要可支配的时间与可支配的钱。对一个工时超限或照护责任无法转移的人，这句话不是出路，是又一条做不到的要求。〔证10〕

**关于「真休息」。**「真休息才回血，刷手机只是换一种消耗」这一因果对比已从本书撤除，与《身体之书》同项处置一致。能说的只有一句：离开工位与继续刷手机，两种活动的主观恢复感通常不同；差异有多大、机制是什么，本轮未取得可核验材料。本书不把它们分成「真的」与「假的」两类，也不用它规定你该怎么休息。〔证1〕

至于「刷手机一小时像十分钟」，[第六章](Ch06_时间急救箱.md)6.9已经处理过同一件事，它的说法就是上面那一句。本章不在它之上再加解释。〔证1〕

## 3.6 一个可选的观察（不是作业）

原稿在这一节留了一份作业：连续五天，每天在五个固定时间点给当下的精力打一到十分，第五天晚上把五天的分数按时间点平均，画出你的精力曲线，找出最高分时段，然后「明天开始，把每天最难的一件事挪进这个时段，其他事务让路」；末尾还加了一句预测：「大多数人第一次做这个练习都会发现：自己最难的事，恰恰一直排在精力低谷。」

这一版把它改掉，四条理由：

1. **它是计分的。** 本书导航页的约定一写着，每章末尾的练习都是可选的，跳过不等于没读，也不构成失败。一份连续五天、每天五次、要求求平均并画出曲线的作业，正好是那条约定要挡掉的东西：它交出一张可以被评的成绩单，而判卷人是第五天晚上的你。〔证12〕
2. **「大多数人第一次都会发现」是一个群体预测，没有任何数据。** 撤除。它的实际作用是让还没做的人先接受一个结论，再去做那个练习，那样记录就变成了替结论找证据。〔证9〕
3. **「其他事务让路」假定了日程由你排。** 对[第六章](Ch06_时间急救箱.md)6.2列出的五类处境，这句话不成立；写下来只是多一条做不到。〔证10〕
4. **分数容易被误读成诊断。** 3.1第一条说的就是这件事：精力打分不能反推生理状态。〔证3〕

**替代的做法：一次可选的观察。** 不设天数，不设时间点，不打分，不画曲线，也没有做完的标准。

- 在接下来几天里，当你偶然注意到自己头脑清楚、或者明显不清楚的时候，记一行：几点，在做什么。就一行。
- 记三行也算，一行不记也算。中间忘了几天，想起来接着记，不用补。
- 记完不需要得出任何结论。如果哪一天你发现自己反复在同一个时段做得动难事，那可以成为[第十章](Ch10_规划与目标.md)排日历时的一个参考；如果始终没有出现这样的时段，那也是结果，不是失败。

三条规则，与《身体之书》第三章的自我观察练习一致：

- **这是观察，不是评估。** 记下来的东西不构成成绩，也不构成对自己的判断。〔证4〕
- **不解读，不诊断。** 记到「下午三点写不动」就停在那里，不要顺着本章往下推成「我的节律错位了」或「我是晚型人」。3.1已经说明这条路不通。〔证3〕
- **无效不是失败。** 觉得这个练习很傻、记了两天就放下、或者记完什么也没看出来，都是允许的结果，不构成毅力或自律的评价。〔证4〕

## 本章速记

- 原稿四处引用同一本大众睡眠著作，全部撤除：该书已被记录存在事实错误，不得作为本书任何事实性主张的依据；批评文所列错误属已公开指控，未经第三方复核。
- 能说的是共识：18至60岁成人规律地每晚至少7小时；睡眠健康含质量、时间安排与规律性；部分人群可能适合超过9小时。
- 不能说的是数字：不要求恰好8小时，不把超过9小时一概判为疾病，群体关联不等于个人必然结局。
- 光照、屏幕光、皮质醇与褪黑素节律、睡眠不足的具体损害：标未核实，本书不给照度、时长、时机或损害程度。
- 昼夜节律起伏的存在可说，长度不可说。「一小时」无来源，本书不用它规定休息间隔，也不给整块时间设下限。
- 「波谷硬撑会用双倍时间完成一半质量」已撤除：那是一个没有来源的倍数。
- 时型标未核实，本书不分型。「这不是懒惰」的立场保留，但依据是伦理红线，不是生理学。
- 「黄金时段」是你的观察结果，不是可测量的生理量；「两小时」已撤除。
- 时段对照表是常见描述，不是参考区间，不能用来判断你应该几点做什么。
- 多巴胺与时间知觉的机制解释已撤除；保留两种可自查的主观经验，其中「记忆密度」标为假说。
- 「真休息才回血」已撤除；能说的只有两种活动的主观恢复感通常不同，差异与机制未取得材料。
- 机制解释不是诊断工具：不能凭主观时间感或精力分数推断生理状态。
- 五天计分的精力作业改为一次不设天数、不打分、不画曲线的可选观察；「大多数人都会发现」已撤除。
