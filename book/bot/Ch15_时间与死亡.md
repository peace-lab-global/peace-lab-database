# 第十五章 · 时间与死亡

> 原稿这一章从一句格言开始：「死亡不是时间的敌人，它是时间的定价器。」接着是一段死亡默想的传统叙述、一句效果断言（「直面死亡的人，反而更少被死亡焦虑追着跑」）、一个以八十岁计的四千周算术，最后一张要涂黑已过周数的五十二格表。它的安全边界写在15.3的末尾，也就是全章倒数第二节。
>
> 这一版把顺序倒过来：**先说这一章对谁不安全，再谈它能给什么。** 一本谈论死亡的书，其读者里一定有人正在经历死亡念头、刚刚失去一个人、或刚拿到一个诊断。对这些人，本章的练习不是帮助，是暴露。原稿把这句话放在章末，等于让他们先读完整章的死亡默想，才被告知「如果已经影响功能，请看第22章」。
>
> 另外三处改动：那句效果断言本轮未取得任何研究，标为未核实；四千周是一个条件性计算，不是一个发现，Burkeman（2021）本轮仅取得书目，不承担它；「庄子谈生死如昼夜之交替」与「斯多亚学派把死亡默想当作日常练习」两处归属，本轮未取得可核验的篇章与版本，本书不作原文引用。

## 15.1 先说清楚：这一章对谁不适用

下面这些情形请跳过本章。跳过不影响你读这本书的其余部分——第五章、第六章、第十八章都不依赖这一章。〔证1〕

| 你此刻的情形 | 该去哪里 |
|---|---|
| 有伤害自己的念头，或觉得活着没有意思 | 本章完全不适用。立即拨打12356心理援助热线，或前往就近医院急诊；如有人身危险，拨打110。这一条优先于本书全部内容〔证2〕 |
| 正在经历丧亲，尤其是未满一年 | 本章不是给留下的人写的。见[《孤独之书》第十七章](../bol/Ch17_Loss_And_Grief.md)；哀伤期的时间感改变是一种处境，不是练习对象〔证3〕 |
| 自己或家人刚拿到一个严重诊断 | 这属于预期性哀伤与医疗决策，需要的是医疗与哀伤支持，不是时间练习。见[《孤独之书》第十七章](../bol/Ch17_Loss_And_Grief.md)与[第二十二章](Ch22_时间的阴影与求助.md)22.6〔证3〕 |
| 死亡念头已经持续影响睡眠、进食或日常功能 | 这需要一次评估，不是哲学练习。原稿把这句话放在15.3末尾，本版移到章首。见[第二十二章](Ch22_时间的阴影与求助.md)22.3〔证2〕 |
| 一想到未来、衰老或死亡就僵住，动弹不得 | 同样的描述既可能是一种可以慢慢相处的处境，也可能是焦虑或抑郁的表现，两者方向相反，本书无法替你区分。先[第二十二章](Ch22_时间的阴影与求助.md)22.3，排除需评估的情形之后再回来。理由见[第五章](Ch05_时间审计.md)5.4第五种〔证2〕 |
| 正处于重度抑郁发作期 | 本章的筛选器与格纸都可能加重反刍。先处理评估与治疗，见[第二十二章](Ch22_时间的阴影与求助.md)〔证2〕 |

三条限制。本表不是诊断标准，不能用来判断你或别人有没有病，也不能排除风险。12356的实时可用性本轮未拨测，若无法接通，请前往医院急诊或拨打120。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证2〕

**这一章的全部练习都可以跳过。** 本书导航页约定一写明每章只建议一个最小行动、练习都是可选的。在一章谈论死亡的内容里，这条约定不是礼貌用语：对正在经历丧失的人，「画一张五十二格的表」不是低成本的尝试，是一次没有保护的暴露。〔证4〕

## 15.2 一句格言，不是一项已验证的练习

「memento mori」是拉丁语，意为「记住你终有一死」。它流传很久，从斯多亚学派的晨间默想到修道院里的骷髅摆件，这是常见的叙述方式。〔证5〕

原稿在这一节写了一句效果断言：

> 直面死亡的人，反而更少被死亡焦虑追着跑。

**这句话本轮未取得任何研究支持，标为未核实。** 它是一个关于心理后果的因果主张，需要的是对照研究与效应量，而本书拿到的只有它自身的说服力。它读起来很对，这正是它危险的地方——一个正在犹豫要不要做死亡默想的人，会把它当成一句承诺：只要我直面，焦虑就会减少。〔证5〕

实际可能发生的有两种，方向相反。一部分人做完之后清单变短、心里变定；另一部分人做完之后更慌，夜里睡不好，或者被一种「来不及了」的感觉追着跑。第六章6.11的「换一把尺子」记录过同一件事的两种反应，那里写的是：两种反应都正常，第二种不是你没做对。本章沿用同一句。〔证5〕

所以本书保留这个练习的方向，不保留它的承诺。**它可能带来清晰，也可能带来恐惧，本书不知道哪一种会发生在你身上。**

关于斯多亚学派，本轮能核读的只有[爱比克泰德《手册》第1节](../SOURCES_TRADITIONS.md#t01)。它支持的是另一件事，而且比死亡默想更有用：文本把判断、欲求、趋避这些自身活动，与身体、财产、声誉、职位区分开，并要求人在面对表象时先检验它属于哪一类。〔证6〕

死亡属于「不取决于我们」的那一类。这个区分能做的，是让你把力气从「能不能不死」挪到「这一周怎么过」；它不能做的，是让你靠意志停止恐惧。台账对这一节写了一条明确的诠释限制：「取决于我们」不宜解释成任何想法、情绪都能随意立即控制，不能要求受苦者凭意志停止症状，或因此归咎本人。〔证6〕

这条限制正好卡住本章最容易滑向的地方。如果「直面死亡」被写成一种能力，那么做不到的人就成了能力不足的人。原稿的「Stoic 的实践者把死亡默想当作日常练习而非悲情仪式」这句中英混排已改为中文，而它所暗示的那个意思——这是一件练得会的事——本书不采用。〔证6〕

至于「修道院桌面上的骷髅摆件」，这是一段常见的历史叙述，本轮未取得可核验来源，本书不把它当作史实引用。〔证5〕

## 15.3 四千周：一个条件性计算

以八十岁计，一年五十二周，八十乘五十二等于四千一百六十。约数就是「四千周」。〔证7〕

**这是一个条件性计算，不是一个发现。** 它的全部力量来自一个前提：你能活到八十岁。而这个前提对任何一个具体的人都不成立——有人活到九十五，有人在四十岁这一年读这本书。它也不是一个测量：它没有告诉你已经用掉了多少，因为已经用掉的那些周里，有童年、有睡眠、有你不记得的部分，把它们折算成「还剩多少格」是一种编排，不是一笔账。〔证7〕

原稿在这里引用 Burkeman（2021）《四千周》，并用它支持一整套对照：传统时间管理问「如何做更多」，四千周框架问「既然做不完，选择做什么、放弃什么」。〔证8〕

**该书本轮仅取得书目，未核读，也未列入系列台账，因此不承担上述任何主张。** 下表保留，但它是本书的编排对照，不是对该书的转述，也不是研究结论：〔证8〕

| 一种常见的问法 | 本书换的问法 |
|:--|:--|
| 如何做更多 | 既然做不完，先做什么、放弃什么 |
| 目标是清空清单 | 目标是把有限的时间花在你确实在乎的事上 |
| 底色是永远来不及的追赶 | 底色是承认有限之后的取舍 |
| 与死亡的关系是回避 | 与死亡的关系是把它当作一个提醒 |

这张表里有一行是承诺，必须点出来：「承认有限之后的取舍」被写成一种情绪结果，仿佛承认了就会平静。**不会自动发生。** 对一部分人，承认有限带来的第一反应是恐慌而不是平静，这不是他们没读懂，是这条路本来就有两个出口。〔证8〕

表里真正站得住的只有一句，而且它不需要任何来源：**你不可能做完所有事。** 这是算术，不是心理学。它成立的证据就是你的日程本身，你不需要一本书来告诉你。第五章的三类划分、第十章的目标与下一步、第二十章的守时与拒绝，全都从这一句出发。〔证9〕

**还有一条边界，原稿没有写。** 「选择放弃什么」这个说法预设了你有得选。对一个日程由别人排、随叫随到、轮班表每周变、照护责任无法转移的人，可放弃的清单本来就短得可怜，让他「明确写下你选择放弃什么」，是把一个处境问题重新包装成一次决断练习。第六章6.2列出的五类处境——工时本身超了、照护责任不可转移、通勤与居住位置、时间与收入直接挂钩、日程不由自己排——在这里同样适用。〔证10〕

对这部分读者，本章更诚实的版本不是「选择放弃」，而是「承认这一季做不了」，并给它设一个复查条件和一个复查日期：项目交付后、孩子上小学后、三个月后。写下来，到期回来看一眼。这与第五章5.2第三步是同一个动作。〔证10〕

## 15.4 筛选器与恐惧源：两支箭

原稿这一节的想法是本章最好的一处，保留：**死亡意识当筛选器用，它带来简化；当恐惧源用，它变成焦虑本身。** 区分的信号是行动变简单了还是动不了了。〔证11〕

但原稿没有给这个区分任何依据，只是断言。这一版把它接到一段已核读的原典上。

[《相应部》SN36.6《箭经》](../SOURCES_TRADITIONS.md#t05)用的是一个比喻：一个人身中一箭，未受教者又忧悲抗拒，于是如同中了一箭之后再中一箭。第一箭指身体的苦受，第二箭指伴随它的心理苦受。有闻圣弟子仍然感到身体痛，却不再以同样的方式增添心苦。〔证11〕

把它放到本章：有限性、衰老、丧失，这些是第一箭。它们是真的，本章不劝你不要痛。反复想象丧失、失控、虚无，在夜里把还没发生的事过一遍又一遍，这是第二箭。**筛选器与恐惧源的区别，就是有没有在放第二箭。**〔证11〕

台账对这一节写了三条诠释限制，本章照录，因为它们正好卡住这个比喻最容易被滥用的三个方向：〔证11〕

- 不能把第一箭扩大成人生绝对、永不可根除的一切痛苦。本章不用它来说「所有难受都是你自找的」。
- 不能把箭数换算成痛苦「减半」或「减少一半以上」。本章不给任何数量承诺。
- 不得以仍有心苦责备读者。**如果你读了这一节，仍然在夜里恐慌，那不是你没修好。**

需要说清的是：《箭经》是一段宗教文本，它提供的是一种看待痛苦的框架，不是一项干预的效果证据。台账对它的可信度评级是「文本出处高，限二箭比喻及修行语境；现代应用不适用，不是疼痛治疗效果量」。本章用它来给一个区分提供说法，不用它来证明任何练习有效。〔证11〕

原稿在这一节末尾提到庄子与禅宗：「庄子谈生死如昼夜之交替，禅宗在『今日事今日毕』的平常心中安放无常。」**这两处归属本轮均撤除。** 系列传统来源台账里已核读的庄子条目是[《养生主》庖丁解牛](../SOURCES_TRADITIONS.md#t04)，其台账范围是「依乎天理的技术与余裕」，不处理生死命题；用它来支持一句关于生死的表述，属于范围外引用。道家与禅宗经典里确实有把生死视为自然变化的说法，但本书本轮未取得可核验的篇章与版本，因此不作原文引用。[第十六章](Ch16_智慧传统的时间观.md)已修订并集中处理智慧传统，其16.4与16.10写明同一分工：无常归本章且不引原文，平常心归该章且只引已核的《无门关》第19则，不涉及生死命题。〔证12〕

## 15.5 一个可选的尝试

原稿的练习是一张五十二格表：画七列八行，每格代表一周，把已经过掉的周涂黑，再给不可协商项上色，然后做三个决定——放弃什么、保护什么、等什么。约二十分钟。〔证13〕

这个练习的问题不在设计，在剂量与位置。涂黑已过的周，是把一个人一生的过去做成一张视觉上不断缩小的图。对一个状态平稳的人，这可能是一次有效的取舍提示；对一个正在经历丧亲、刚拿到诊断、或有死亡念头的人，这是一次没有保护的暴露。原稿没有给任何不适用清单，也没有停止条件。〔证13〕

本章保留这张表，并补上原稿缺的两样东西。

**不适用清单。** 15.1表里的任何一行成立时，不要做这个练习。此外：最近一年内有丧亲；正在接受重病治疗或等待检查结果；睡眠已经紊乱；做完类似的想象练习之后曾经整夜睡不着。〔证13〕

**停止条件。** 涂黑的过程中如果出现心慌、发冷、想哭又哭不出来、或者一种「来不及了」的紧迫感，停下来，把纸放下，去做一件手上的具体事。这不是练得不对，是这个练习此刻不适合你。停下来之后不需要补做。〔证13〕

如果这张表对你成本太高，有一个更小的版本，效果不保证更好，但暴露更小：**写下三件你愿意放弃的事。** 不画格子，不涂黑，不计算还剩多少周。三件写完就停。写不出三件，写一件也算完。〔证13〕

**「把这张表贴在书桌前」这一句，本书撤除。** 它把一次练习变成一件长期挂着的东西，于是每天都是一次提醒。导航页约定一写明练习不累积、不设完成标准；一张贴在墙上的倒计时表，是这条约定最直接的违反。你可以贴，也可以做完就收起来，也可以只做那三件放弃的事。〔证4〕

## 本章速记

- 分诊在前：有死亡念头、正在丧亲、刚拿到诊断、念头已影响睡眠与功能、想到未来就僵住、重度抑郁发作期，六种情形跳过本章。
- 「直面死亡的人反而更少被死亡焦虑追着跑」是效果断言，本轮未取得研究，标未核实。它可能带来清晰，也可能带来恐惧，本书不知道哪一种会发生在你身上。
- 斯多亚学派能核读的只有《手册》第1节，它支持的是可控与不可控的区分，不是「死亡默想练得会」；台账明确禁止要求受苦者凭意志停止症状。
- 四千周是条件性计算：八十乘五十二等于四千一百六十，前提是活到八十岁。它是编排，不是账。
- Burkeman（2021）本轮仅书目、未列入台账，不承担「四千周框架」的任何主张；那张对照表是本书的编排。
- 站得住的只有一句，且不需要来源：你不可能做完所有事。
- 「选择放弃什么」预设了你有得选。对第六章6.2的五类处境，诚实的版本是「承认这一季做不了」并设复查日期。
- 筛选器与恐惧源之别，接在《箭经》二箭的比喻上；台账三条诠释限制照录，其中一条是不得以仍有心苦责备读者。
- 庄子与禅宗两处归属撤除：已核读的《养生主》条目不处理生死命题，属范围外引用。
- 五十二格表补了不适用清单与停止条件；「贴在书桌前」撤除；更小的版本是写下三件愿意放弃的事。
