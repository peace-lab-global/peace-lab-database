# 第十二章 · 复利与积累

> 一道可以自己按计算器验证的算术，和它不能替你回答的三件事。

原稿这一章写得比本书多数章节诚实。它先给了那个演示，然后立刻自己按住：「这个算术是真实的，但它描述的是理想条件。」这句话保留，本章从它开始。〔证1〕

改了三处。

**第一，那个演示的地位要写明。** 它是算术，不是测量。把它套在一个人的成长上，就从一个可验证的式子变成了一个不可验证的模型，而原稿在两者之间没有画线。这一版补上，措辞与《力量之书》第一章对「相乘」的处置一致。〔证1〕〔证2〕

**第二，三个前提降级。** 它们是本书的编排，不是发现。其中「低中断」这一条对[第六章](Ch06_时间急救箱.md)6.2列出的五类处境全部不成立，却排在第一位——排在第一位的那个前提，恰恰是最多人无法满足的那一个。〔证1〕〔证7〕

**第三，撤除一句话：**「这个平坦期淘汰了绝大多数人。他们不缺能力，缺的是对曲线哪天起飞的预览。」它没有来源，而且它把放弃解释成信息不足。于是坚持不下去仍然是你的问题，只是换了一个更好听的名字。〔证1〕〔证9〕

## 12.1 先分清：有些「坚持不下去」不是复利问题

下面这些情形请先获取现实中的帮助，不要从本章的表格与练习开始。记录表不替代评估，也不替代一次协商。〔证3〕〔证4〕

| 你正在经历的 | 先做什么 |
|---|---|
| 有伤害自己的念头，或觉得活着没有意思 | 立即拨打12356心理援助热线，或前往就近医院急诊；如有人身危险，拨打110。这一条优先于本章其余全部内容 |
| 对什么都没兴趣已经两周以上，连以前想做的那件事也不想碰，伴情绪低落、睡眠或食欲明显改变 | 这是兴趣丧失，可能是抑郁的表现，不是一种可以用记录表解决的「坚持不下去」。先做精神科或心理科评估，见[第二十二章](Ch22_时间的阴影与求助.md)22.3。此时给自己加一张每日记录表，通常只会多一份自责材料 |
| 你不是不想做，是一坐下就必须先把另一件事做完才安心，反复检查、停不下来 | 这可能是需要评估的焦虑或强迫相关情形，不是纪律问题，见[第二十二章](Ch22_时间的阴影与求助.md)22.3 |
| 长期超时、没有休假、日程不由自己排定 | 这是职业倦怠的处境。世界卫生组织把它列为一种职业现象，不是医疗疾病分类，且限于职业情境；它同时意味着不能凭「发生在工作里」就排除抑郁或躯体疾病。本章解决不了，见[第六章](Ch06_时间急救箱.md)6.2 |
| 你的日子被照护、轮班或通勤切碎，根本没有一段完整时间 | 这是处境，不是中断。本章12.4专门处理它，请先读那一节，再决定要不要看12.6的练习 |
| 入睡困难、早醒、白天嗜睡已持续一个月以上 | 睡眠问题优先于任何习惯安排，见[《身体之书》第六章](../bob/Ch06_身体急救箱.md) |

三条限制：本表不是诊断标准，不能用来判断你或别人有没有病，也不能排除风险。12356的实时可用性本轮未拨测，若无法接通，请前往医院急诊或拨打120。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证3〕

**本章的练习要每天写一行，成本不为零。** 对一个每天只剩下四十分钟可支配时间的人，让他先选一件事、再定一个最小剂量、再每天记录，是把一个处境问题改写成一个自律考验。本章因此不设天数、不给分钟数，12.6也写了只做一行的版本。〔证5〕

## 12.2 一道算术，和它不能承担的事

一个可以自己按计算器验证的算术：

- 1.01 的 365 次方 ≈ 37.78；
- 0.99 的 365 次方 ≈ 0.0255。

**到这一步为止，它是算术。** 你可以自己验证，不需要任何来源，也不需要相信谁。〔证2〕

**从下一步开始，它不是了。** 把它读成「每天进步百分之一，一年后是原来的三十八倍」，就悄悄加进了三个前提：存在一个可以按百分比相乘的量；它每天都乘一次；乘的顺序不影响结果。一个人身上没有这样的量。「进步单位」不是一个可以相乘的东西，也没有任何研究给出过「每日百分之一」与一年之后能力水平之间的函数形式。〔证2〕

所以这里的处置与《力量之书》第一章对「相乘」的处置相同：**它是一个帮助记忆与排优先级的编排装置，不是一个经过测量或验证的数学关系。** 它在这个身份下能说的，比原稿说的少，但都还站得住。〔证2〕

| 它能说的 | 为什么 |
|---|---|
| 在这个式子里，微小的差异会被时间放大 | 这是式子的性质，不是人的性质。它说的是指数函数，不是你 |
| 在这个式子里，方向比幅度重要 | 把365天里的某一天从百分之一换成百分之三，年末结果从约37.78变成约38.53，差百分之二。单日的大幅确实改不了整体走向 |

| 它不能说的 | 原稿让读者自己补上了什么 |
|---|---|
| 一个人每天差一点，一年之后就只剩百分之三 | 0.99³⁶⁵≈0.03 套在人身上是假的，而且是有害的。没有人是这样消失的。人会有坏的一年，然后有普通的一年。这个式子给了一个数字，让「我最近状态不好」听起来像「我已经在归零的路上」 |
| 曲线会在某一天起飞 | 式子里没有起飞日，只有一条平滑的指数曲线。把「后半段陡然上升」讲成积累的形状，是叙事，不是算术 |
| 中断等于归零 | 式子里的中断是一次乘以0.99，人生里的中断通常只是没有乘 |

原稿在这里引了一句：「你不会被一次大行动改变，你会被每天重复的小动作塑造（Clear, 2018）。」**撤除来源归属。** 该书本轮仅取得书目、未核读，也未列入本系列任何台账——科学、实践、传统三份都没有。〔证6〕

这句话本身也太绝对。一次事故、一次诊断、一次搬家，确实会改变一个人。保留下来的只是一个弱得多的观察：**重复做的事会留下痕迹。** 这一句不需要来源，你自己的记录就能看出来。原稿紧接着的「目标决定方向，系统决定终点」同样撤除归属，它是一个口号，本书不据它给出任何做法。〔证6〕

## 12.3 三个前提：它们是编排，不是发现

原稿说，复利不是自动发生的，它成立需要三个前提，缺一个就退化为「简单的重复」。三个把手保留，但它们的地位要重新写一遍。〔证8〕

| 前提 | 原稿怎么说 | 本章的处置 |
|---|---|---|
| 低中断 | 链条可以偶尔松，但不能常断；不允许连续两天中断 | **「不允许连续两天中断」撤除。** 它没有来源，而且它把一件常常由处境决定的事写成一条由你执行的规则，见12.4 |
| 可叠加 | 今天的进步能叠在昨天之上，而不是每次清零 | 保留，但改成一个问句：你做的这件事，今天的版本比上个月多了什么？答不上来不一定说明没叠上，也可能说明这件事本来就不以叠加的方式长 |
| 有记录 | 看得见的进度本身是燃料，也是纠错依据 | **「进度是燃料」撤除**，它是一个没有来源的动机主张。记录的作用小得多：它是你唯一能看到的那条线。而在低落期，它也可能变成一份罪证清单，见12.6的停止条件 |

三条都不是研究结论。它们是本书为了让「积累」这件事可以被讨论而设的三个把手，本书[附录速查](Appendix_Quick_Reference.md)的术语表已把「复利三前提」从术语里删掉，理由相同。〔证8〕

**原稿还留了一个排序问题。**「低中断」排在第一位，意思是：中断是复利最大的敌人。可是[第六章](Ch06_时间急救箱.md)6.2列出的五类处境，全部会造成中断，而且全部不由你决定。于是排在第一位的那个前提，恰恰是最多人无法满足的那一个。下一节处理这件事。〔证7〕

## 12.4 每个前提都有处境的那一半

[第六章](Ch06_时间急救箱.md)6.2列了五类时间稀缺，写明它们是真实的处境，不是心态。这一节把它们对着三个前提排一遍。〔证7〕

| 处境 | 具体样子 | 它让哪个前提不成立 | 于是「坚持不下去」实际是什么 |
|---|---|---|---|
| 工时本身超了 | 加班常态化，没有完整的休息日，下班后仍要回消息 | 低中断 | 中断由排班决定 |
| 照护责任不可转移 | 幼儿、失能老人、慢性病家人，没有人可以替你 | 低中断 | 夜里被叫醒不是漏了一天，是这一天的形状不由你画 |
| 通勤与居住位置 | 单程一小时以上，一天里有两个小时不属于你 | 可叠加 | 剩下的是碎片。碎片不容易叠，但这不等于你没有在积累 |
| 时间与收入直接挂钩 | 计件、零工、个体经营，停下来就没有钱 | 可叠加 | 你今天做的事明天不一定还归你，因为它被卖掉了 |
| 日程不由自己排 | 轮班、随叫随到、优先级由别人决定 | 低中断 | 中断是常态，不是意外 |

**本书不把「让时间产生复利」写成在挤压你的工时、照护负担与不平等安排里继续自我调节的义务。**[第六章](Ch06_时间急救箱.md)6.2的原话是：呼吸练习不能把一个六十小时的工作周变成四十小时。本章沿用同一句——一张记录表也不能。〔证7〕

按第六章6.2的三步判断，把你要坚持的那件事分成三类，**只对第一类使用本章的做法**。这是全书唯一一条硬规则。

| 类别 | 判断 | 该做什么 |
|---|---|---|
| 第一类：我自己能改 | 只涉及你的选择，不需要别人同意 | 用12.6那张表 |
| 第二类：需要别人参与才能改 | 涉及工时、分工、照护、委托方 | 去协商，见第六章6.13与[《力量之书》第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md) |
| 第三类：暂时改不了 | 通勤距离、家人病情、合同期 | 去承认，见第六章6.5与[第十五章](Ch15_时间与死亡.md) |

这不是为了让你少做事，而是为了不让第三类的问题被记在第一类的账上。如果三天记录下来，第二类和第三类占了绝大部分，那么本章对你只是止痛。**止痛不等于无效，但也不该被说成解决。**〔证7〕

### 三个不是练习的动作

第二类和第三类不靠记录表处理。它们靠三件事，都不在本章的练习里。〔证7〕

| 动作 | 它改的是什么 | 复查条件与复查日期 |
|---|---|---|
| 协商排期 | 第二类的中断频率 | 项目交付后回来看一眼 |
| 拒绝一件事 | 第二类里的一个具体项 | 一个月后看它有没有被别的事悄悄补回来 |
| 承认这一季做不了 | 第三类的那笔账 | 写下一个日期，到期回来看，不到期不检查自己 |

**这三件事都预设了你可以开口而不失去什么。** 对计件、零工、试用期，以及拒绝就会被记下的人，这个前提不成立。对这些人，本章能给的只有一句：这不是你的中断，是这份工作没有给积累留位置。〔证7〕

## 12.5 平坦期：撤除的那句话

原稿这一段是这样的：每天写作的前三个月，看不出任何差别；每天锻炼的前六周，镜子毫无变化。这个「平坦期」淘汰了绝大多数人。他们不缺能力，缺的是对「曲线哪天起飞」的预览。

**前两句保留。** 它们是常见经验，不需要一本书来批准，而且它们不需要复利曲线也成立。〔证9〕

**后两句撤除，四个理由。**〔证9〕

1. **「淘汰了绝大多数人」是一个人群主张。** 本书没有分母，没有研究，没有任何一份材料数过有多少人在这条曲线上停下。
2. **它把中断解释成信息不足。** 如果你知道哪天起飞，你就会留下。这个解释把责任从处境和运气那里收回来，放回你头上，只是换了一个更好听的名字：你缺的不是能力，是预览。
3. **它与「不允许连续两天中断」合起来是一套双重标准。** 你不能连漏两天；而如果你还是停了，那是因为你没有预览。两条都没有来源，两条都指向你。
4. **「曲线哪天起飞」这个说法预设了它一定会起飞。** 有些事确实会，有些事到了平台就停在那里，有些事有阈值、有些事会退。本章没有材料说明你要做的那一件属于哪一种。

原稿还有一句：「你在错误的坐标系里评估一条正确的曲线。」同样撤除。它预设了曲线是正确的，而这个前提恰恰是需要证据的那一个。〔证9〕

撤除之后，剩下的东西比原稿少，但都还站得住：

- **在开头那段看不到效果的时间里，「有没有效果」不是你现在能回答的问题。** 这不是因为你站错了坐标系，而是因为回答它需要的时间你还没有花完。
- **不要在最低的那个星期决定是否放弃。** 这一条不需要复利曲线支持，它只需要一句常识：判断的质量取决于你做判断时的状态。
- **你可能确实在做一件没有用的事，也可能在做一件还没有到时候的事。本章无法替你区分。** 能区分的只有继续做，或者停下来换一件。两个都合法。

原稿在这里给的第一条建议是「在平坦期，唯一可信的指标是今天做了没有，而不是有没有效果」。保留，但去掉「唯一」：在你拿不到结果反馈的那段时间里，「今天做了没有」是**你手上有的**那个指标，不是唯一可信的那个。有些事的效果不由你判定：它会不会被谁用到、用多久、会不会散失，要等你不在场之后才知道，见[第十七章](Ch17_时间与遗产.md)17.3。〔证9〕

## 12.6 一个可选的尝试：一张不设天数的表

原稿的练习叫「单事件复利记录，每天1分钟，坚持30天」，含一条「允许漏一天，不允许连漏两天」的规则和一个30天后的回看。这一版改了四处。〔证5〕〔证10〕

**保留的：** 只选一件事（写作、单词、拉伸、代码，一件）；每天完成后写一行，日期，加上今天比昨天多懂或多做的一点，哪怕只多懂一个词。

**撤除的：**

| 原稿 | 处置 |
|---|---|
| 坚持30天 | 撤除。本书导航页约定一写明每章只建议一个最小行动、练习可选、不累积、跳过不构成失败。30天是一个完成标准，这本书不该有〔证5〕 |
| 每天1分钟、15分钟以内的最小剂量 | 撤除两个数字。最小剂量的长度由你定，本章不给分钟数，理由与[第十八章](Ch18_时间与日常.md)相同〔证5〕 |
| 允许漏一天，不允许连漏两天 | 撤除。漏掉的日子写一行「漏」，不解释，不自责。这张表不是一条不能断的链子；如果它开始像一条链子，它就变成了又一份考核〔证10〕 |
| 30天后回看 | 撤除固定回看日期。什么时候回看由你定，也可以不回看〔证5〕 |

**只做一行的版本：** 今天写完那一行就停，明天不写也不算漏。这是一个完整的用法，不是没做完的版本。〔证5〕

**停止条件：** 如果这张表开始变成你指责自己的材料——连续几天只写得出「漏」，或者写完比写之前更沉——停下，不要改成补写。这与[第六章](Ch06_时间急救箱.md)6.10的停止条件同一类：在自我批评很强的人身上，一份看得见的记录容易变成新的自责材料。停下来不是做错了，是这一项此刻不适合你，不要自行加天数或加剂量。〔证10〕

一句实话：撤掉天数之后，这个练习变得很轻，轻到可能有人只写一行就不再写。那也是一个完整的用法。

**一处下游引用已经更正。**[第二十三章](Ch23_28_天时间重建.md)23.1原写「唯一规则与第十二章相同：不允许连漏两天」，与本书[附录速查](Appendix_Quick_Reference.md)「漏一天不补，不设连漏上限」的既有处置相反，已按本章改为不设连漏上限，并写明撤除理由。这是单行更正，当时不构成第二十三章的修订。**该章现已整章重写**：二十八天周期已按编排装置声明并引台账P06的边界（不支持二十八天必成习惯，更不能以未达期限评价意志或人格），每日不超过十五分钟的剂量连同四张表的预算列一并撤除，章末四条大众读物参考文献整段撤除，「1%记录表」改称「第十二章12.6那张不设天数的表」——本章当初不改称呼所等的那次重排已经完成。〔证11〕

## 12.7 本章不处理的事

| 不处理 | 去哪里 |

## 本章速记

- 1.01³⁶⁵≈37.78，0.99³⁶⁵≈0.0255：算术是真的，可以自己验证。把它套在人的成长上则是编排装置，不是测量关系。
- 那个式子说「每天差一点，一年只剩百分之三」。这句话套在人身上是假的，而且有害——人会有坏的一年，然后有普通的一年。
- 复利三前提是本书的编排，不是发现，附录术语表已把它们从术语中删除。
- 「不允许连续两天中断」撤除：它没有来源，而且把一件常由处境决定的事写成一条由你执行的规则。
- 「进度是燃料」撤除；记录的作用小得多，它是你唯一能看到的那条线，而在低落期也可能变成一份罪证清单。
- 「平坦期淘汰了绝大多数人，他们缺的是对曲线哪天起飞的预览」撤除：没有分母，而且把中断解释成信息不足，等于换了一个名字把责任放回你头上。
- 三个前提里，「低中断」对第六章6.2的五类处境全部不成立，而它排在第一位。
- 只对第一类处境使用本章做法。第二类去协商，第三类去承认，并给它设一个复查日期。
- 协商与拒绝都预设你可以开口而不失去什么；对计件、零工、试用期的人这个前提不成立。
- 练习不设天数、不给分钟数。表变成自责材料就停下，不要改成补写。
