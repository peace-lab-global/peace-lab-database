# 第十七章 · 时间与遗产

> 原稿的题辞是：「遗产不是死后的纪念碑，是每天的时间流向。流向哪里，哪里就是你留下的东西。」
>
> 前半句保留为编写立场。它把「遗产」从墓碑搬回日程，这一步有用，本书也确实要这样做。后半句撤除。「流向哪里，哪里就是你留下的东西」有两处不成立。第一处，时间流向的大部分东西不留下任何痕迹：通勤、排队、等人回消息、夜里刷掉的那两个小时，它们流向哪里，哪里就什么也没有。第二处更要紧——一个人的时间流向哪里，有相当一部分不是他决定的。[第六章](Ch06_时间急救箱.md)6.2列的五类处境（工时本身超了、照护责任不可转移、通勤与居住位置、时间与收入直接挂钩、日程不由自己排）里，流向是别人安排的。把这句话原样交给一个上夜班、单程通勤一小时、夜里要起来两次的人，它读起来不是提醒，是判决。〔证1〕
>
> 除题辞外，本版处理原稿的七类问题：三账户被写成「框架」而不是编排，且带一列没有来源的量级；「存钱」这一族隐喻被当成可以计数、加总与比较的关系；「临终关怀研究中被反复报告的观察」是一句没有来源的研究主张，而它承担着全章最重的那一步推理；习惯账户预设读者有孩子，作品账户用一百与一作比较；「遗产思维是对抗即时满足的最好工具之一」是无来源的效果主张，其后紧跟一条关于注意力的机制陈述；练习标着「每月一次，约15 分钟」，标题写月度而第三问写本周，末尾还有一次十年的推算；章末参考文献段两条均为大众读物、仅书目、未列入任何台账，且都不在正文被引用。〔证1〕
>
> 另补齐本章作为一章讲死亡与留下的内容缺少的四件事：分诊、停止条件、路由表与依据表。三账户保留，但改标为编排，并去掉排名与计数。〔证1〕

## 17.1 先分清：有些「想留下点什么」不是遗产问题

这一章讲的是遗产。它直接挨着死亡，也直接挨着「你做得够不够」，所以先把不适用的情形放在最前面。跳过本章不影响你读这本书的其余部分——第五章、第六章、第十八章都不依赖它。〔证1〕

| 你此刻的情形 | 该去哪里 |
|---|---|
| 有伤害自己的念头，或觉得活着没有意思 | 本章完全不适用。立即拨打12356心理援助热线，或前往就近医院急诊；如有人身危险，拨打110。这一条优先于本书全部内容〔证2〕 |
| 正在经历丧亲，或自己、家人刚拿到一个严重诊断 | 本章完全不适用。「遗产」这个词在丧亲期读起来像一份账单，而盘点三账户会把哀伤变成一项未完成的任务。需要的是医疗与哀伤支持，见[《孤独之书》第十七章](../bol/Ch17_Loss_And_Grief.md)与[第二十二章](Ch22_时间的阴影与求助.md)22.6〔证2〕 |
| 一想到死亡或有限就僵住，动弹不得 | 同样的描述既可能是一种可以慢慢相处的处境，也可能是焦虑或抑郁的表现，两者方向相反，本书无法替你区分。先[第二十二章](Ch22_时间的阴影与求助.md)22.3，排除需评估的情形之后再读[第十五章](Ch15_时间与死亡.md)15.1，再回到本章。这个顺序不能倒，[附录速查](Appendix_Quick_Reference.md)已经这样规定〔证2〕 |
| 「来不及了」的绝望感已经占据思绪，排不开 | 那不是遗产问题。见[第二十二章](Ch22_时间的阴影与求助.md)22.2与22.3〔证2〕 |
| 对什么都没兴趣已两周以上，并伴情绪低落、睡眠或食欲改变 | 这可能是抑郁的表现。此时读一章讲「你留下了什么」的内容，通常只会多一份做不到的清单。先做精神科或临床心理科评估，见[第二十二章](Ch22_时间的阴影与求助.md)22.3〔证2〕 |
| 时间稀缺来自工时、照护、通勤、收入结构或排班 | 本章17.3与[第六章](Ch06_时间急救箱.md)6.2。一张遗产盘点表改不了它的时间结构，本书不把它写成心态问题〔证3〕 |
| 你读到「遗产」这个词就已经觉得累，或者觉得被审判 | 那是允许的。可以只读17.7那一件最小行动，或者什么也不做，见[本书导航页](INDEX.md)约定一〔证4〕 |

三条限制。本表不是诊断标准，不能用来判断你或别人有没有病，也不能排除风险。12356的实时可用性本轮未拨测，若无法接通，请前往医院急诊或拨打120。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证2〕

三条来自导航页的约定。每章只建议一个最小行动，本章的最小行动是17.7那一句。练习可选，跳过不等于失败。不累积、不设完成标准。〔证4〕

## 17.2 原稿逐条处置

原稿九十一行。下表按原稿顺序逐条给出处置，形式类改动（去表情符号、去圈号、去ASCII引号、撤除参考文献段）合并计入相应行。〔证1〕

| 原稿的一句 | 处置 | 理由 |
|---|---|---|
| 题辞后半句「流向哪里，哪里就是你留下的东西」 | 撤除 | 两处不成立，见章首。它把一个描述变成一份判决，而对日程不由自己排的人，判决的对象不是他〔证1〕 |
| 「那样的遗产属于极少数人，于是多数人干脆不想」 | 撤除群体预测 | 「多数人」是一个没有来源的群体断言，本书未取得任何关于人们是否思考遗产的调查。同[第一章](Ch01_时间是什么.md)1.7对「大多数人写完会发现」的处置〔证5〕 |
| 「这是把遗产概念错装在了错误的尺度上」 | 改为编写选择 | 「错装」是对读者概念的诊断。本版写明它是本书选的尺度，不是发现人们装错了〔证5〕 |
| 「更可用的是三账户框架」 | 「框架」改为「编排」 | 「框架」暗示一个已有的、外部的结构。三账户是本书的编排，两处术语表已如此标注，见17.3〔证6〕 |
| 「你一生的时间，正在往三个账户里存钱」 | 隐喻降级 | 「存钱」带来三件它承担不了的事：可以计数、可以加总、可以比较。三个账户之间没有共同单位，见17.3第二处问题〔证7〕 |
| 「死后它们继续生效」 | 撤除 | 这是一个关于世界的事实主张，而它不总成立：作品会散失，被帮过的人会被别人伤到，被示范的活法会被拒绝。三个账户都不保证生效〔证7〕 |
| 表格「时间尺度」一列（可以很长远／一代到数代／最隐蔽，也最深远） | 整列撤除 | 三个都是没有来源的量级，其中第三个还是一个排名。「最深远」把三项变成三档，读者接着会去查自己落在哪一档〔证5〕 |
| 表格「谁在『支取』」一列 | 改写 | 沿用存钱隐喻，且预设了支取的人一定存在。改为一列「它不保证什么」，见17.3〔证7〕 |
| 表格三行的三个圈号 | 撤除圈号 | 体例。本书不用圈号，且圈号本身就带顺序，与撤除排名同项〔证1〕 |
| 「都以『重复的小额存入』为主，而非一次性巨款」 | 保留观察，撤除「存入」 | 「重复做的事会留下痕迹」是[第十二章](Ch12_复利与积累.md)12.2保留下来的那句弱观察，不需要来源；「小额存入」把它重新变成一笔账〔证7〕 |
| 「所以说，遗产就藏在你现在的日程表里」 | 保留，加处境边界 | 这是全章压力最大的一句，而它默认日程表是你的。对五类处境里的人，日程表是别人排的，见17.3第三处问题〔证3〕 |
| 「他人账户最容易被低估」（原稿序号二） | 撤除排名 | 三个「最容易被…」构成一个排名，本书系统撤除排名与打分，见17.5〔证8〕 |

| 「习惯账户最容易被错装」（原稿序号三） | 撤除排名 | 同上〔证8〕 |
| 「你留给孩子的，是你的作息」 | 撤除 | 两处问题：它预设读者有孩子；它是一条关于模仿如何代际传递的机制主张，而本书不给机制。见17.5〔证10〕 |
| 「你如何刷手机、如何对服务员说话、如何对待自己的疲惫」 | 保留前两项为可自查的观察，撤除第三项的指认语气 | 前两项是一次普通相处就能核对的；第三项落在读者最容易被指认的地方，而它没有来源〔证10〕 |

## 17.3 三账户：一个编排，和它的三处问题

一谈遗产就容易想得太重：传世之作、巨额财富、丰功伟绩。原稿接着说，那样的遗产属于极少数人，于是多数人干脆不想。**这句话撤除**——「多数人」是一个没有来源的群体断言，本书没有取得任何关于人们是否思考遗产的调查。剩下的那半句是一个编写判断：把遗产放在名人的尺度上，多数人就无从下手，所以本书换一个尺度。〔证5〕

原稿把换过来的这个东西叫「三账户框架」。**「框架」二字撤除。** 两处术语表其实已经写清楚了：[本书附录速查](Appendix_Quick_Reference.md)的术语表把它标为「Sonus编排的盘点分类，不是测量」，[《意义之书》附录速查](../bom/Appendix_Quick_Reference.md)同一行也是这个措辞。章内却叫它框架，于是两处术语表的标注被正文自己抵消了。〔证6〕

按房规声明：**它是本书用来分类与排优先级的编排装置，不是一个经过测量或验证的分类，也不是一种账户。** 措辞与[第十二章](Ch12_复利与积累.md)12.2对复利式子的处置同型。〔证7〕

| 账户 | 它指什么 | 它不保证什么 |
|---|---|---|
| 作品 | 你做出的东西：文章、代码、菜谱、花园、整理好的知识 | 它会被谁用到、用多久、会不会散失。一份没有人拿得到的东西不起作用，但拿得到也不等于被用 |
| 他人 | 你给过的人：教过的人、帮过的人、养育的人、真心相待的人 | 这一栏里有没有人可以写，以及写下的那个人会不会记得。两个都不由你决定 |
| 习惯 | 你示范的活法：你怎么对待时间、身体、承诺与别人 | 别人会不会照着做。示范与传递之间没有一条本书能核验的通道 |

第三列是这一版加的。原稿的第三列叫「时间尺度」，写的是「可以很长远」「一代到数代」「最隐蔽，也最深远」。三个都没有来源，第三个还是一个排名——它把三项排成三档，而读者读到排名之后的下一个动作，通常是去查自己落在哪一档。〔证5〕

### 第一处问题：「死后它们继续生效」

原稿写「你一生的时间，正在往三个账户里存钱，死后它们继续生效」。后半句是一个关于世界的事实主张，而它不总成立。作品会散失：一份整理好的知识可能没有人再打开。他人会变化：你帮过的人后来可能被别人伤到，你养育的人可能与你断绝来往。习惯会被拒绝：你示范的活法，别人可以看着长大然后决定不要。

三个账户都不保证生效。这一版把「不保证什么」写进表里，不是为了让这一章变得悲观，是因为一个承诺了回报的框架，会把没有回报记成你的存入不够。〔证7〕

### 第二处问题：「存钱」这一族隐喻

原稿在四处用了它：三账户「存钱」、共同点是「重复的小额存入」、练习叫「月度存款表」、[第二十三章](Ch23_28_天时间重建.md)第24天叫「各写一笔这段时间存下的东西」。

钱这个比喻带来三件它承担不了的事：

- **可以计数。** 三笔比两笔多。可是作品的一笔是一篇文章，他人的一笔是一个名字，习惯的一笔是一种做法，三笔不是同一种东西的三次。
- **可以加总。** 于是「遗产总额」听起来像一个可以算出来的数。三个账户之间没有共同单位，加不起来。
- **可以比较。** 你的账户比别人的多或少，比上个月的多或少。而这一章没有任何一处能支持这种比较。

第十二章12.2已经对同族的一个式子作过处置，房规措辞照录：**它是一个帮助记忆与排优先级的编排装置，不是一个经过测量或验证的数学关系。** 三个账户在这个身份下能做的，是帮你把「留下什么」这个太大的问题分成三个可以说得出口的方向。它不能做的，是给你余额。〔证7〕

原稿还有一句：「遗产就藏在你现在的日程表里。」这一句保留，但要加上它的边界。

### 第三处问题：日程表是谁的

这句话默认日程表是你的。**本书不把「留下什么」写成在挤压你的工时、不可转移的照护负担、通勤与居住位置、时间与收入直接挂钩、日程不由自己排这五类处境里继续自我调节的义务。** 对处在这五类里的人，「遗产就藏在你现在的日程表里」读出来是另一句话：你留下的东西，正在被别人的安排决定。这不是他的失职，是成本本来就放在他这边。〔证3〕

下表是[第六章](Ch06_时间急救箱.md)6.2的五类处境，分类逐字相同：

| 处境 | 它让哪一栏不成立 | 去处 |
|---|---|---|
| 工时本身超了 | 作品与他人两栏都只剩碎片；能开始的时段很多，能做完的整块时间没有 | [第二十章](Ch20_时间的伦理.md)20.2的协商 |
| 照护责任不可转移 | 他人那一栏其实满着，只是里面的人是你照护的人，不是你「给过」的人；这一栏不需要再存 | 6.2第三类，去承认 |
| 通勤与居住位置 | 一天里有两个小时不属于你，那两个小时不会进任何一栏 | 6.2第三类 |
| 时间与收入直接挂钩 | 作品那一栏的东西可能今天就卖掉了，明天不归你 | [第十二章](Ch12_复利与积累.md)12.4同一行 |
| 日程不由自己排 | 三栏都以你能决定自己的一天为前提 | [《力量之书》第十九章](../bos/Ch19_Assertiveness_And_Negotiation.md) |

按第六章6.2的三步判断分成三类，**只对第一类使用本章的做法**。这是全书唯一一条硬规则。如果三天记录下来第二类和第三类占了绝大部分，那么这一章对你只是止痛。止痛不等于无效，但也不该被说成解决。〔证3〕

### 三账户不是三个可以并列盘点的栏目

原稿的练习让读者一次写完三栏，仿佛三栏是同一类东西的三个格子。它们不是。作品那一栏需要一段不被打断的时间（[第十八章](Ch18_时间与日常.md)18.5）；他人那一栏需要还有一个人在（17.4）；习惯那一栏不需要额外时间，因为它就是你已经在做的事。三栏的条件不一样，所以三栏空着的原因也不一样：一栏空着可能是没做，也可能是没有条件做，两者在纸上长得一模一样。

第二十一章21.3的第三问问的正是这件事：**它需要什么条件，而这些条件现在有没有？** 前两问假设你能做，第三问问的是你能不能做。少了它，做不到就会被记成不想做。〔证4〕

## 17.4 他人账户：一句没有来源的研究，和一个前提

原稿这一节的第一条是全章最重的一步：

> 他人账户最容易被低估：临终关怀研究中被反复报告的观察是，人们最后在意的多是关系而非成就，但日常日程里，他人账户往往排在最后一个。

这句话有三层，逐层处置。〔证9〕

### 第一层：那句研究不存在于本书能核对的范围里

它断言了三件事：存在临终关怀研究；这些研究反复报告某个观察；该观察的内容是「人们最后在意的多是关系而非成就」。本轮没有取得任何一项。原稿没有给出作者、年份、期刊或样本，章末的参考文献段里也没有——那两条是Burkeman（2021）与Clear（2018），都是大众读物，都与临终关怀无关。系列三份台账（科学、实践、传统）都没有这一条。

**处置：撤除研究归属，标未核实，不由它承担本章任何主张。** 这与本书对大众读物的处置规则一致，也与[第十六章](Ch16_智慧传统的时间观.md)对未取得原文的传统文本的处置一致：核不到的材料不给建议，也不用它支持结论。〔证9〕

这句话在中文与英文的自助读物里流通很广，常见形态是把一位临终照护从业者的个人观察列成一张清单。本轮同样没有取得任何此类材料的原文，因此本书不指名、不转述，也不拿它去替代那句研究主张——一次替换只会把一个没有来源的说法换成另一个没有来源的说法。〔证9〕

### 第二层：即使那句观察成立，它也不是一个排日程的依据

第十四章14.2补过一条区分：**回望已经过去的十年，与预估接下来的十天，是两种不同的判断。** 同一条区分在这里适用。一个人临终回望时报告什么，与一个正在上班、通勤、照护的人在周三下午怎么排他的两个小时，是两个位置上的两件事。用前一个位置上的报告去规定后一个位置上的排法，中间那一步没有人做过，本书也不代它做。

第十五章15.3对同型的一步给过处置：那张「一种常见的问法／本书换的问法」的对照表里，「承认有限之后的取舍」被原稿写成一种情绪结果，仿佛承认了就会平静，那一章写明**不会自动发生**，因为这条路本来就有两个出口。这里也一样：读到「人们最后在意的是关系」，有人被提醒，有人被压垮——后一种人听到的不是提醒，是「你排错了，而且现在已经来不及改」。〔证9〕

### 第三层：这句话里的「人们」是经过筛选的

在临终照护情境里被问到这个问题的人，本身已经过了一层筛选：有人在身边，有关系可以回望。这一层筛选意味着什么，本书没有材料可以判断，所以不推断。只写明一条边界：**这句话不能被读成「所有人在最后都会这样想」，也不能被读成「如果你最后不这样想，你就想错了」。**〔证9〕

### 保留下来的、不需要来源的那部分

「日常日程里，他人账户往往排在最后一个」——这一句你不需要任何研究就能核对。[第五章](Ch05_时间审计.md)5.2的三天记录会照实写下来：谁的名字出现过，出现了几次，是在日程里还是在日程的缝里。原稿的观察如果是真的，它真的地方在这里，不在那句研究里。〔证9〕

### 一个前提：这一栏需要还有一个人在

他人账户的条件是：有一个人，且你与他之间还有一段可以放进去的时间。这个条件对一部分读者不成立——独居、异地、丧偶、关系断裂，或者社交本身已经是负担。第二十一章21.3的第三问正是为此而设。〔证4〕

第二十三章第25天已经写明：「想不出名字，说明这一项此刻不属于你，跳过。」本章照录，并加一句：**这一栏空着不是三个账户里的一项失败，它是一条关于你此刻处境的信息。** 一个把空栏记成扣分的人，接下来做的事通常是自责，而自责不会让任何人出现。〔证4〕

## 17.5 习惯账户与作品账户：两处排名、两处预设、一处计数

### 三个「最容易被」构成一个排名

原稿的三条各带一个「最容易被」：他人账户最容易被低估，习惯账户最容易被错装，作品账户最容易被神化。这不是三个并列的观察，是一个三档的排序，而且三档都是负面的——低估、错装、神化，读者无论落在哪一档，落下的都是一个毛病。

本书系统撤除排名与打分：[第一章](Ch01_时间是什么.md)1.6撤除了把读者分成三种人的时间观类型学，[第五章](Ch05_时间审计.md)5.3写明四维是观察角度、不打分不相加不判型，[第八章](Ch08_忙碌与空虚的时间.md)撤除伪工作的道德判断，[第十二章](Ch12_复利与积累.md)12.6的表不设天数，[第十六章](Ch16_智慧传统的时间观.md)16.6写明不能给绵延打分，[第二十二章](Ch22_时间的阴影与求助.md)撤除自评表。排名的问题不在它说得对不对，在它一旦写下就把三项变成三档，读者接着会去查自己落在哪一档，而这一章接着要他盘点自己留下了什么。两个动作叠在一起，产出的是一份自评。〔证8〕

### 习惯账户：两处预设

原稿写：「习惯账户最容易被错装：你留给孩子的，是你的作息。你如何刷手机、如何对服务员说话、如何对待自己的疲惫。」

**第一处预设：读者有孩子。** 这一句把习惯账户的传递路径直接接到孩子身上，原稿表格里「家人、孩子、合作者」也是同一个顺序。没有孩子的人在这一栏里被排除在外，而这一章并没有别的理由要求读者有孩子。本书其他章不这样预设：第十八章18.3的晨型锚点是给你自己的，第二十章20.1的守时是对任何人的。〔证10〕

**第二处预设：作息会被学走。** 这是一条关于模仿如何代际传递的机制主张，而本书不给机制。第三章3.5已撤除同类主张；第十八章18.3甚至把「晨间光照是校准节律的最强信号」这样一句都标为未核实，理由是没有取得可核验的一手来源。一句没有来源的机制主张，被放在读者最容易被指认的地方，代价是具体的：一个夜里要起来喂两次奶的人读到「你如何对待自己的疲惫」会被孩子学走，他得到的不是一条信息，是一条指控。〔证10〕

**保留下来的：** 别人看见的是你的做法，不是你的说法。这一句不需要来源，是一次普通相处就能核对的观察——你怎么对服务员说话，坐在对面的人看得见。它不保证被学走，也不指定学走的人是谁。〔证10〕

### 作品账户：一处计数比较

原稿写：「作品账户最容易被神化：作品不必伟大，但需要完成。一百个开了头的项目，不如一个做完并放在别人够得着的地方的。」

「作品不必伟大」保留。这是这一章里最实用的一句，它把门槛从传世之作降到一份能被第二个人用的东西。

「一百个开了头的项目，不如一个做完的」撤除。三个理由：

1. 它是一次计数比较。第十二章12.4已写明中断通常由处境决定，不由意志决定；第二十三章23.2写明不补课、不清零、不比较完成天数、不设及格线。同一本书不能在一章里不设及格线，在另一章里用一百与一排名次。〔证11〕
2. 一百个开了头的项目，正是一个碎片化日程的产物。第六章6.2的第三类处境里，能开始的时段很多，能做完的整块时间没有。这不是选择，是排班。〔证3〕
3. 「需要完成」把完成设成门槛，于是所有没做完的东西都变成欠账。而这一章讲的是留下什么，不是讲欠了什么。〔证11〕

**保留下来的那半句：「放在别人够得着的地方」。** 这半句与完成无关，它说的是另一件事——一份没有人拿得到的东西不起作用。它不需要计数，也不需要伟大，而且它对碎片化日程同样成立：一份写在便条上交给同事的说明，就够得着。〔证11〕

## 17.6 遗产与「自我中心」：一处已撤除的反转

原稿这一节的标题是「遗产与『自我中心』的和解」，第一句是：「有人担心：总想着『留下什么』，是不是太自我中心？其实相反。」

**「其实相反」撤除。** 这个动作本书已处置过多次：先立一个担心，再用一句没有来源的反转把它取消。第十五章15.3对同型动作的处置是写明那条路有两个出口，不会自动通向平静。这里也一样——总想着留下什么，对一部分人确实会变成一种自我中心：它把每一段时间都换算成将来能不能记功，于是此刻没有人真的在场。原稿的「其实相反」把这个可能一笔勾销了。〔证13〕

撤除的三项：

| 原稿的一句 | 处置 | 理由 |
|---|---|---|
| 「遗产思维是对抗即时满足的最好工具之一」 | 撤除 | 「最好工具之一」是比较级的效果主张，没有来源；「即时满足」是本书未核验的构念；「对抗」把描述改成了处方〔证13〕 |
| 「这些动作都在把你的注意力从『此刻的刺激』拉向『此后的世界』」 | 撤除 | 一条关于注意力的机制陈述。第三章3.5写明本书不给机制〔证10〕 |
| 三个例子（一百年后的文档、十年后成年的孩子的从容早晨、明年接手工作的同事） | 撤除三处预设 | 分别预设一份文档能存一百年、预设有孩子且早晨可以从容、预设有一份会被接手的工作。第三处对计件、零工、合同到期与裁员都不成立〔证10〕 |

**保留下来的动作，换掉它的理由。** 为一份文档多写一段「为什么」，这个动作可以留。它的好处不在一百年后——一份文档存不存得到那时候，本书没有材料可以判断——而在下一个接手的人身上，而那个人常常就是三个月后的你自己。这一句不需要来源，你自己的经历就能核对。〔证10〕

**与第十五章的衔接保留。** 原稿写：「它与第十五章15.3衔接：正因为一生有限，你才需要决定把哪一部分延续出去；也正因为大部分延续靠的是人与习惯，你才不必执着于『宏大作品』。」前半句与第十五章的实际内容一致，保留。后半句里的「大部分」是一个没有来源的比例，改为「延续靠的多是人与习惯」这一编写观察，不作比例主张。〔证3〕

原稿在这里并列两部大众读物，上一轮已撤除归属并写明「本轮均仅取得书目、未核读，本书不由它们承担这一主张」。本轮进一步核对：两条在正文均无一处引用，属孤儿条目，与[第二十章](Ch20_时间的伦理.md)20.5对Newport（2016）的处置同类。章末参考文献段整段撤除。〔证14〕

## 17.7 练习：三账户盘点（可以不做）

原稿的练习标题是「三账户月度存款表（每月一次，约 15 分钟）」，正文三步：写三栏本月存款、给每个账户写一句下月打算存入的一笔、最后做一次十年推算。〔证12〕

### 撤除的部分

| 原稿的安排 | 处置 | 理由 |
|---|---|---|
| 每月一次 | 撤除 | 「每月」没有来源。第二十一章21.6写明九十天没有来源、「每周」也没有，两者都是编排，而它们一旦写进日历就变成两份新的未完成记录〔证12〕 |
| 约 15 分钟 | 撤除 | 分钟数在练习里看起来像处方，本书不给剂量。同第二十章20.4对「约十五分钟」的处置〔证12〕 |
| 「存款表」 | 撤除 | 沿用17.3第二处问题里那族隐喻，它把三栏变成三笔账〔证7〕 |
| 三步阶梯 | 撤除阶梯 | 三笔承诺是一个阶梯。第二十章20.4已对「三个改进各一条」撤除阶梯；导航页约定一写明每章只建议一个最小行动，不累积〔证4〕 |
| 标题写「月度」而第一栏第三问写「本周」 | 撤除，并记明 | 一个月与一周在同一步里换了，原稿没有说明。本版不设周期，不一致随之消失〔证1〕 |
| 「下月打算存入的一笔」 | 撤除 | 一个带周期的承诺装置，与21.6「不给周期」相反〔证12〕 |
| 「如果这个比例保持十年，我留下的会是什么」 | 撤除 | 见下〔证15〕 |

第二十一章21.3与第二十三章23.6都已经写明不采用这两个数字，也不代它设新的。本章自己也不设。第二十三章第168行原写「该章尚未按本记录修订，其练习小节另带三个圆圈序号」，本轮已修订，该行已同步更新。〔证12〕

### 十年推算的三处问题

原稿第三步要求读者问：「如果这个比例保持十年，我留下的会是什么？满意就继续，不满意就调下月的存款方向。」

1. **「比例」预设三个账户可以换算成一个份额。** 它们没有共同单位，见17.3第二处问题。换算不出来，「保持十年」就没有可以保持的对象。〔证7〕
2. **「保持十年」预设你此刻的处境会延续十年。** 第二十一章21.5写明断掉通常说明条件变了：项目上线、家里有人病、搬到新城市、一段关系结束、开始上夜班。十年里这类变化不是意外，是常态。〔证3〕
3. **「我留下的会是什么」是一个只有别人能回答、而且要在你不在场之后才能回答的问题。** 让一个正在读这本书的人自己回答它，是把一件不可知的事写成一次自评。它给出的不会是答案，是一种提前到来的、无从核对的失望。〔证15〕

第三问的原稿位置在本章，第二十三章第24天与第27天都指向它，两处的「做不到时」一栏已经写明了正确处置（空着是一条信息不是扣分；定不下来就不定）。本章与那两行口径一致。〔证15〕

### 保留下来的最小行动，一件

> 在三个账户里，只挑一个，写下已经在那里的东西。

不写下月打算，不写比例，不写十年。挑哪一个由你定，也可以三个都不挑。〔证4〕

- **三栏可以写，也可以只写一栏。** 第二十三章第24天写明「三个账户里有一个是空的，那是一个信息，不是一项扣分」，本章照录。
- **写名字，不写「关心家人」这类抽象词。** 这一句原稿就有，保留。它是这个练习里唯一一条真正提高信息量的要求：一个名字是一个具体的人，一类抽象词什么也没有说。
- **什么时候做由你定。** 不设周期，不设回看日期。第二十一章21.6写明回看什么时候有用：生活出现变化的时候，或者一项做法你已经做了一段时间、想知道它还回应不回应原来那个需要的时候。两种都不需要日历。〔证12〕
- **如果三栏都写不出来。** 那不是一个结果，是一条信息。它可能说明此刻的条件不在你手上，见17.3第三处问题那张表；也可能说明这一章此刻不属于你，见17.1最后一行。两种都可以，都不需要补做。〔证4〕

### 停止条件

**任何一项让你更难受，就停下来。** 依[S03](../SOURCES_SCIENCE.md#s03)与[S05](../SOURCES_SCIENCE.md#s05)，身心类练习存在焦虑、抑郁等不良体验报告，无既往心理问题者也可能出现，个体风险不可预测。停下来不是做错了，是这一项此刻不适合你，不要自行加强度或加时长。〔证16〕

本章的练习是书写，不是身心类练习的核心形态，所以严格说S03与S05不直接覆盖它。仍然给出停止条件，理由有三处具体的：他人那一栏可能空着，而空着容易被读成失败；习惯那一栏最容易读起来像指认，原稿正是把它写在孩子身上的；这一章挨着死亡，而[第十五章](Ch15_时间与死亡.md)15.5与[第十四章](Ch14_时间与衰老.md)14.6都写明同类想象练习有停止条件。〔证16〕

如果写着写着变成一条对自己的指控，停下来，去看[第六章](Ch06_时间急救箱.md)6.2那张表，分清它属第一类还是第三类。分不清就按第三类处理，那意味着要动的是处境，不是这一栏。〔证3〕

**一个都不想做，也是允许的。** 导航页约定一写明：练习可选，跳过不等于没读，也不构成失败。〔证4〕

## 本章速记

- 题辞后半句「流向哪里，哪里就是你留下的东西」撤除：时间流向的大部分东西不留下痕迹，而对日程不由自己排的人，流向是别人安排的。
- 三账户保留，但由「框架」改标为编排装置，措辞与第十二章12.2对复利式子的处置同型；两处术语表本来就这样标，是正文自己抵消了标注。
- 表格第三列由「时间尺度」换成「它不保证什么」：原稿那三个量级都没有来源，第三个还是一个排名。
- 「死后它们继续生效」撤除。作品会散失，被帮过的人会被别人伤到，被示范的活法会被拒绝。
- 「存钱」这一族隐喻不支持计数、加总与比较：三个账户之间没有共同单位，所以给不出余额，也给不出比例。
- 「临终关怀研究中被反复报告的观察」整句撤除归属、标未核实。三份台账都没有这一条，原稿也没有作者、年份或期刊；而它是全章最重那一步推理的唯一支撑。
- 即使那句观察成立，它也是关于回望的报告，不是关于此刻怎么排日程的处方——第十四章14.2的那条区分在这里同样适用。
- 他人那一栏需要还有一个人在。空着是一条关于处境的信息，不是一项扣分。
- 三个「最容易被…」构成一个三档的负面排序，随本书系统撤除排名与打分一并撤除。
- 习惯账户撤除两处预设：读者有孩子，以及作息会被学走。作品账户撤除一百与一的计数比较，保留「放在别人够得着的地方」。
- 「遗产思维是对抗即时满足的最好工具之一」与「把注意力拉向此后的世界」撤除：一个是无来源的比较级效果主张，一个是机制陈述。
- 练习撤除「每月一次」「约15分钟」、三步阶梯与十年推算，只留一件最小行动：挑一个账户，写下已经在那里的东西。写名字，不写抽象词。
- 章末两条文献（Burkeman 2021、Clear 2018）均为大众读物、仅书目、未列入任何台账，且均为孤儿条目，整段撤除。
