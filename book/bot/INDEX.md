# 时间之书 (Book of Time)

> 现代职场人的时间重建指南。
> 一句话总纲：与时间相处是一种可被理解、被练习、被系统化重建的能力。这本书教你看清时间去哪了、拿回方向、深度投入、与不可控的部分共处。

---

## 这本书是什么

本书是 Peace Lab Database（平静实验室知识库）的总纲与入口之一。它与[《平静之书》](../bop/INDEX.md)、[《力量之书》](../bos/INDEX.md)、[《孤独之书》](../bol/INDEX.md)互为姊妹篇：

- 平静之书回答"如何在风浪中站稳"：安定、恢复、守；
- 力量之书回答"站稳之后如何前进"：承受、行动、影响、攻；
- 孤独之书回答"一个人时怎么办"：理解、独处、连接、化；
- 时间之书回答"时间怎么办"：看清、安排、沉浸、接纳。

时间是现代人最普遍的焦虑源：日程永远排满，回头却说不出做成了什么；收藏夹永远读不完，深夜总觉得"来不及了"。本书不教你"征服时间"，而是教你看清时间、安排时间、深度投入，并与它不可控的部分共处。

---

## 时间四力模型（全书的坐标系）

本书把"与时间相处的能力"拆成四个可理解、可练习、可重建的维度：

```
时间力 = 觉察力 × 规划力 × 沉浸力 × 接纳力

┌──────────────────────────────────────────────────┐
│  觉察力  ← 看清：时间去哪了，此刻在发生什么（Ch01-05、09） │
│  规划力  ← 安排：把时间投给要事，而非被事务牵着走（Ch10、18-21）│
│  沉浸力  ← 深入：在整块时间里做成事，让时间产生复利（Ch12-13）  │
│  接纳力  ← 共处：等待、衰老、死亡——不由你说了算的部分（Ch11、14-17）│
└──────────────────────────────────────────────────┘
```

四个维度相乘，任何一维趋近于零，时间就变成焦虑。多数人的问题不是"没时间"，而是某一维缺失：看不清（时间黑洞）、安排不了（计划总落空）、沉不进去（永远在浅层切换）、放不下（和有限性较劲）。本书第二部的[时间审计](Ch05_时间审计.md)会帮你定位自己的短板维度。

## 使用本书的两条约定

1. 每章只要求一个最小行动。读完不做，等于没读。
2. 时间焦虑是正常的，不必羞耻。本书教你与时间相处，包括与它不可控的部分共处。
