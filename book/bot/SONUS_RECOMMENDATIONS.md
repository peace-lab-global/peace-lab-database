# Sonus 建议：时间之书修订记录

## 性质与依据

标注协议、可信度分级与安全边界沿用[系列来源与可信度说明](../EVIDENCE_GUIDE.md)。撤除决定记录在本文，正文只保留成稿散文与依据表，不作为修订日志阅读。

## 一、总体判断

时间之书的原稿在七本书中篇幅最短（第六章约一千字），却是引用最密的一本：第六章十个技术，每个后面都跟一句「为什么有效」，各带一部书。十句话里有十部来源，没有一条取得过原文。这构成一个可复核的事实：**本书原稿的说服力主要来自引用密度，而这份密度是虚的。**

比这更值得注意的是它的立场问题。原稿把「时间不够」一律处理为感知与心态问题：焦虑是「注意力提前透支了还没发生的时间」，忙碌是「没有把注意力放回此刻」，来不及是「用错了尺子」。对应解法全部指向读者自己——深呼吸、写清单、专注二十五分钟、想象十年后的自己、对自己说「我有时间，我不着急」。

但很多人的时间不够不是感知问题。**工时本身超了**、**照护责任不可转移**、**通勤与居住位置**、**时间与收入直接挂钩**、**日程不由自己排**，这五类处境里的时间短缺是算术结果，不是心态结果。对这些读者，原稿的十个技术不但无效，还附带一条伤害：它把结构性的挤压转写为个人的调节失败，读者练完仍然没时间，于是多了一条「连这个都做不好」的自责。第六章的「允许练习」教人对自己说「我有时间，我不着急」——对一个每天剩四十分钟可支配时间的人，这句话不是安抚，是与事实相反的要求。

**因此本书的第一条修订原则是：不把「找回时间感」写成在挤压你的工时、照护负担与不平等安排里继续自我调节的义务。** 第二条原则针对第二十二章：**求助不是一项要达标的作业。** 原稿在该章开头放了一张「两分钟自评」，五个条目各计 0 至 3 分，并规定达到某个分数才走某一级求助——这既没有量表依据，也把「我需不需要帮助」变成了一道要先做对的题。

第三条是本书特有的写作风险：它谈论衰老与死亡（第十四、十五章），而谈论死亡的内容天然会碰到正在经历死亡念头的读者。原稿第十五章已经写了一条边界（「若死亡念头已经持续影响睡眠与日常功能，这不是哲学练习能解决的」），这条边界是对的，保留；但它出现在章末速记附近，而不在章首。

## 二、第六章：分诊前置、处境判断与引用清理

章名保留「时间急救箱」，文件名保留 `Ch06_时间急救箱.md`，以免破坏本书导航、兄弟章节与仓库总索引中既有的链接。原稿约一千字、十项技术、零条依据标注、带装饰性表情符号，实质重写为分诊在前、判断居中、动作在后。

1. 新增 6.1 分诊，前置于全部技术：自伤念头→12356／急诊／110；突发胸痛、心悸、呼吸困难、晕厥、一侧肢体无力→120，并写明**不要先做呼吸练习**；持续两周以上低落伴兴趣丧失与睡眠食欲改变→抑郁症状，此时再排更多任务通常只会让自责加重；停不下来的担忧与反复检查→第二十二章；长期超时、无休假、无自主权→职业倦怠（世界卫生组织列为职业现象而非医疗疾病分类，且限于职业情境）；失眠、早醒、嗜睡持续一个月以上→《身体之书》第六章。依据 [S11](../SOURCES_SCIENCE.md#s11)、[S12](../SOURCES_SCIENCE.md#s12)、[S02](../SOURCES_SCIENCE.md#s02)。
2. 新增 6.2「是状态问题，还是处境问题」，列出上述五类处境，写明伦理红线，并给出三步判断：**记录三天，不要估计**（人对时间使用的回忆系统性失真）→ 把记录分成「不可动的」「可协商的」「可自己决定的」三类 → **只对第三类使用本章动作**。第一步是本章最重要的一句：多数人在没有记录时以为自己有四个小时可用，记录后发现是四十分钟。
3. 给出一个诚实的对价：第三类很小时，要处理的不是心态而是条件——协商工时、把照护分出去、缩短通勤、拒绝一件事、或承认这一季就是这样并设定复查日期。
4. 新增虚构的陈宁情境：陈宁记录三天后可支配时间是四十分钟。变化不是他获得了更多时间——他没有——而是他停止了为「只有四十分钟」惩罚自己。正文明确写上：**这不是一个时间管理的成功故事。**
5. 十项技术并为八项可独立选择的尝试（6.4 至 6.11），每项附**停止条件**；不累计次数，不设完成标准。原「创造练习」与「连接练习」移出本章，分别转介《创造之书》与《孤独之书》——它们不是分钟级的急救，放在这里只是凑数。
6. 撤除原稿全部六条误引与两条无据断言，逐条见第四节。二十五分钟分段改为归属番茄工作法（Cirillo），并写明该长度是任意设定，没有研究显示它优于其他长度。
7. 6.13「本章不处理的事」列十二行转介，覆盖六本姊妹书的第六章、本书第二十二与二十一章、第十、八、十五章与第三章。

## 三、第二十二章：撤除计分，把回避接到体检

本章实质重写，结构以[平静之书第二十二章](../bop/Ch22_When_To_Seek_Help.md)为骨架。

1. 撤除「两分钟自评」的五条目 0 至 3 分计分表，并写明两条理由：**一是计分没有依据**，五个条目与阈值的划分未经任何量表开发与验证；**二是它把求助变成了一项要达标的作业**——一个正在犹豫要不要求助的人，先要判断自己够不够分数，这个设计本身就在推迟求助。
2. 撤除求助阶梯。本书改为：不需要先做咨询才有资格看精神科，也不用先证明自助失败；持续时间只是评估的一部分，不是求助资格。依据 [S12](../SOURCES_SCIENCE.md#s12)。
3. 撤除原稿列出的六个热线号码（含五个境外号码）。本轮未取得官方来源核读；正文只保留 120、110、12356，并写明 12356 的政策依据与「每日不少于十八小时不等于全国 24 小时、实时可用性未拨测」。在中国大陆以外，本章不罗列未经本轮核验的号码。依据 [S11](../SOURCES_SCIENCE.md#s11)。
4. 22.2 把原稿的三种困境保留为**描述**，但逐条去掉机制外衣：「稀缺错觉」由机制降为比喻；「三重自我实现」由因果链降为观察；「时间抑郁」是**本书的造词，不是精神疾病分类中的诊断名称**，改称「与时间有关的绝望感」。Burkeman（2021）的引用撤除——它是一句修辞，不是实证结论。
5. 「停不下来的信息追踪」一节补一个原稿没有的临床分岔：**可以停下来但选择不停**，是习惯问题（转第五、十章）；**停不下来**，可能是需要评估的焦虑或强迫相关情形（转第二十二章求助渠道）。原稿把两者合成一项「注意力被劫持」，于是给同一个表现开了同一个药方。
6. 新增 22.6「回避时间信息，有时是在回避体检」。这是本书特有的安全议题：一本教人管理时间的书，其读者中最常见的拖延对象不是任务而是**预约**——挂号、复查、体检、活检结果。回避它可以延误诊断。最小的一步不是「不再回避」，是**挂上一个号**。同节补处境版本：如果不去体检的原因是费用、排班、或没有医疗保险覆盖，那么该处理的是这些条件，而不是你的回避心理。
7. 新增虚构的陈宁情境：陈宁把「预约评估」写进清单，排在星期四下午；四个星期四各有一个理由。转折不是他更有纪律了，而是他把预约这件事交给了一位家人——它把一件需要自己安排的事变成了一件有人一起做的事。该情境明确标为虚构，不作疗效证据。
