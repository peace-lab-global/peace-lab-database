# 系列来源与可信度说明

本说明适用于 `book/` 下七本书。它规定结论怎样标注、可信度怎样分级、不同性质的来源怎样区分，以及在书稿尚未完成修订时读者应当怎样使用其中的建议。

各书的工作定义与编写立场由该书首页自行交代，本说明不代替。

## 修订状态决定读法

| 书 | 状态 | 读者应当怎样对待 |
|---|---|---|
| [平静之书](bop/INDEX.md)、[孤独之书](bol/INDEX.md)、[时间之书](bot/INDEX.md) | 已按本说明完成全部章节修订（2026-09-28 更正：此前误记六书均未修订） | 每章有紧邻标注与依据表，可按标注判断结论性质 |
| [创造之书](boc/INDEX.md)（9/23 章）、[身体之书](bob/INDEX.md)（4/23）、[力量之书](bos/INDEX.md)（4/23）、[意义之书](bom/INDEX.md)（3/23） | 修订进行中 | **已修订章**按标注判断；**未修订章**尚无证据标注，其中的原理说明、剂量与话术应视为待核验的编写意见 |

初稿中出现的书名年份式引用只说明作者参考过什么，不说明该参考支持了哪一句结论，也不说明参考材料被核读到什么层级。修订完成前，不要据初稿的机制解释或精确数字调整医疗、法律或重大职业决定。

## 怎样阅读标注

修订后的章节以〔证1〕〔证2〕等编号标记实质性结论与理论，章末「依据与可信度」表逐项对应。一个编号只覆盖同一论证范围，不能用一条宽泛文献替整章背书。表中来源链接指向来源台账，台账提供书目、核验层级与可追溯入口。

每个主要小节或独立论证段落都应有相关编号；同一段内若含性质不同的主张，分别编号。练习与虚构故事也有来源说明，但不伪装成实证结论。过渡语、提问、导航与人物对话不需要逐句标注，但其所在情境必须明确性质。

## 五种可信度

| 标注 | 含义 | 不意味着 |
|---|---|---|
| 高 | 在限定范围内，明确指南、直接文本或可复算事实提供较强支持，且未发现影响该表述的关键缺口 | 适用于所有人；所有相关干预都有效 |
| 中 | 存在相关研究或可靠理论依据，但设计、人群、异质性、外推或取证层级限制了结论 | 对个人结果有保证 |
| 低 | 证据间接、初步，或从原研究到本书场景存在明显距离 | 已证伪或毫无价值 |
| 未核实 | 本次没有取得足够材料确认具体主张；不作为操作建议的事实基础 | 可以先当作真的使用 |
| 不适用 | 工作定义、价值主张、编写建议、虚构情境等不宜套用实证概率等级 | 免于解释理由或安全审查 |

这些等级是编辑评估，不是正式GRADE评价，不表示经过系统检索与独立专家共识程序。遇到指南之间冲突或证据不足，优先收窄正文表述，而不是通过降低标签继续传播高风险主张。

## 来源类型与结论性质

| 类型 | 标注方式 | 编写边界 |
|---|---|---|
| 指南或官方信息 | 机构、年份、编号；结论可信度与适用范围 | 保留适用人群与场景，不把一般建议当个体处方 |
| 实证研究 | 作者、年份、研究类型；剂量与终点 | 区分相关与因果，不用长期方案证明即时见效 |
| 理论模型 | 提出者与文本；理论支持与适用边界 | 模型不是从单个症状推定生理状态的检测工具 |
| 争议中的理论 | 同时列支持与质疑文献 | 不得当作定论，不得据以推导操作步骤 |
| 传统原典 | 书名、篇章、版本或译者 | 文本出处可靠性与现代诠释、疗效证据分开 |
| 大众科普读物 | 书名、出版方；标明非一手研究 | 不能作为机制或疗效主张的事实基础 |
| 回忆录与个案观察 | 作者、年份；标明非研究设计 | 不能表述为预测因子或发生率 |
| Sonus编写建议 | 明确署名；可信度不适用；指出参考来源与改编处 | 不声称已验证，不附虚构成功率 |
| 虚构情境 | 明确虚构；可信度不适用 | 不冒充病例、采访、亲历或疗效见证 |
| 条件计算 | 明确输入、公式与假设；算术可信度 | 计算正确不代表输入适用于每位读者 |

## 来源台账

- [科学、临床与公共健康来源](SOURCES_SCIENCE.md)：编号 S 起。
- [心理实践、行为与关系来源](SOURCES_PRACTICE.md)：编号 P 起。
- [传统思想与原典来源](SOURCES_TRADITIONS.md)：编号 T 起。

S01—S16、P01—P14、T01—T09 的完整核验记录原载于[平静之书来源台账](bop/SOURCES_SCIENCE.md)，核验日期 2026-09-23；系列台账以摘要形式继承并保留原链接，避免同一来源出现两份可能漂移的核验记录。系列新增条目自 S17 起，核验日期 2026-09-24。

每条台账至少包含：完整可识别的书目信息；来源类型；实际核验日期与层级；支持的具体命题；不能支持的推论；对本书使用范围的可信度评估。

「核验摘要」不等于「核验全文」。「官方介绍」不等于亲自复算研究数据。「政策要求开通」不等于实际拨通热线。受访问限制的材料如实标注，不补造页码、DOI、样本量、效应值或原话。

## 全系列共同边界

七本书都是教育与自我观察材料，不提供医学诊断、个体治疗处方或法律意见。练习时长若为便于尝试而设定，明确为Sonus建议；读者可缩短、改变或停止。无效、不适、无法完成，都不能用作人格评价。

存在即时生命危险、严重或新出现的急性躯体症状，或有自伤计划与意图时，先联系当地急救或获得医疗与心理专业帮助，不等待完成练习。心理支持与紧急救援不同。中国大陆医疗急救为120，全国统一心理援助热线为12356；实时可用性未实测，各地区可能不同。

身体类主题不得用书中练习排除疾病。任何书稿都不因标注了来源而获得真人专家认证，也不因机器检查通过而等于疗效已经验证。

## 虚构人物约定

七书共用以下虚构人物，以便跨书讨论同一些处境：

| 人物 | 处境 | 常用于讨论 |
|---|---|---|
| 林澄 | 承担交付任务但无完全排期权的项目成员 | 工作条件、回应速度、边界协商 |
| 陈宁 | 同时承担照护与收入责任的工作者 | 时间冲突、晚间待命、无法退出的责任 |
| 周遥 | 经历重要关系或生活变化的人 | 失去、比较、等待不确定的消息 |

各书可在需要时增加人物，但须在本书首页或依据表中说明其虚构性质。人物没有研究样本身份，任何一章都不得凭故事推导疗效，也不得把人物结局写成方法有效的证据。没有明确引用真实来源的故事，均为Sonus构造的虚构情境，在依据表中标为「不适用；不是访谈、病例或疗效见证」。
