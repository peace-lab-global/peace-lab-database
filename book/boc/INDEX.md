# 创造之书 (Book of Creation)

> 现代职场人的创造重建指南。
> 一句话总纲：创造是可被理解、可练习、可系统化重建的能力，这本书教你接住它、诊断它、重建它。

---

## 这本书是什么

本书是 Peace Lab Database（平静实验室知识库）的总纲与入口之一。它与[《平静之书》](../bop/INDEX.md)、[《力量之书》](../bos/INDEX.md)、[《孤独之书》](../bol/INDEX.md)互为姊妹篇：

- 平静之书回答"如何在风浪中站稳"：安定、恢复、守；
- 力量之书回答"站稳之后如何前进"：承受、行动、影响、攻；
- 孤独之书回答"一个人时怎么办"：理解、独处、连接、化；
- 创造之书回答"我能创造什么"：理解、诊断、修炼、成。

四本书的关系：
```
平静（内在稳定）→ 力量（外在行动）→ 孤独（人与己）→ 创造（人与作品）
```

"我不会创造"是现代人最普遍的自我误判。本书不教你"成为天才"（天才与否无关方法），教你的是：拆掉错误信念、认清自己卡在哪一维、用最小成本把创造循环重新转起来。从"我大概不行"到"我在做"。

---

## 创造四维模型（全书的坐标系）

本书把"创造力"拆成四个维度：感知力、想象力、执行力、分享力。它们都可以被理解、被练习、被建设。

```
创造 = 感知力 × 想象力 × 执行力 × 分享力

┌─────────────────────────────────────────────┐
│  感知力  ← 输入：看见素材，喂饱创造            │
│  想象力  ← 处理：联想组合，想象可能            │
│  执行力  ← 输出：动手完成，粗糙也没关系         │
│  分享力  ← 反馈：分享迭代，让作品抵达他人       │
└─────────────────────────────────────────────┘
```

四个维度相乘，任何一维趋近于零，创造就中断。多数人的问题往往出在某一维缺失：看不见素材（麻木）、想不出可能（空转）、做不下去（拖延）、不敢给人看（完美）。每一维都有专章修炼（Ch09-12），先做[第 5 章审计](Ch05_创造审计.md)定位你的短板。

## 三种读法

### ⚡ 急救模式（我卡住了/没灵感/想拖延）
你现在正被空白文档、死线或"我果然不行"困住。直接去：

- [第 6 章：创造急救箱](Ch06_创造急救箱.md)：十个分钟级练习
- [第 7 章：创造场景剧本](Ch07_创造场景剧本.md)：按你正在经历的情境查找剧本
- [第 8 章：创作瓶颈与拖延](Ch08_创作瓶颈与拖延.md)：瓶颈分型与拖延机制

### 🩺 体检模式（我想知道我的创造力卡在哪）
- [第 5 章：创造审计](Ch05_创造审计.md)：输入/处理/输出三段审计 + 四维自检 + 六型缺失模式，每型附主攻章节

### 🏗️ 系统模式（我想彻底重建创造力）
按顺序通读全书（一、二部建立认知，四、五部分维修炼），跟着[第 23 章：28 天创造建设](Ch23_28_天创造建设.md)落地（每天 ≤30 分钟），最终产出你自己的[个人创造系统](Ch21_个人创造系统.md)。

## 使用本书的两条约定

1. 每章只要求一个最小行动。读完不做，等于没读。
2. 创造不是少数人的特权。本书不教你"成为天才"，只教你"把循环转起来"。转起来的人，就是创作者。
