# 第五章 · 创造审计

> 上一部说清了「创造是什么、为什么会断」。这一部回答一个更具体的问题：你卡在哪里？
> 这一章不给分数，也不给你定型。「我没有创造力」是一个没有用处的结论，但它也不是靠一份十二题打分表来替换的——打分表只会把那个结论变成一个数字，而数字更难反驳。

---

## 5.1 先分清：哪些不是「卡住」

下面这些情形需要先走别的通道。用创作技巧处理它们会延误。

| 此刻的情形 | 先做什么 |
|---|---|
| 有伤害自己的念头 | 立即求助。心理援助拨12356，或直接前往最近的急诊；涉及人身危险拨110。这一条优先于本章其余全部内容 |
| 持续两周以上情绪低落，对几乎所有事——包括以前喜欢的创作——都提不起兴趣，伴睡眠或食欲改变 | 精神科或临床心理科评估。创作能力下降可以是抑郁的表现，不是灵感问题，见[第二十二章](Ch22_创造的阴影与求助.md)22.5 |
| 突发胸痛、呼吸困难、晕厥 | 拨120 |
| 长期超时交付、没有休息、没有自主权之后的「做不动」 | 更像创作耗竭。世界卫生组织把职业倦怠列为一种职业现象，不是医疗疾病分类，且限于职业情境；它同时意味着不能凭「发生在工作里」就排除抑郁或躯体疾病，见[第二十二章](Ch22_创造的阴影与求助.md)22.3 |
| 停不下来的担忧、反复检查、某些念头占满注意力而无法投入 | 需要评估，见[第二十二章](Ch22_创造的阴影与求助.md)22.5 |
| 拖延已长期影响收入、学业或健康 | 它可能不是意志力问题，先读[第二十二章](Ch22_创造的阴影与求助.md)，再看[第八章](Ch08_创作瓶颈与拖延.md) |
| 卡住只发生在某个特定项目、特定委托方、特定评审面前 | 更可能是处境问题，见5.2 |

〔证1〕〔证7〕

三条限制：本章的观察提示不能排除疾病，也不能替代评估与治疗。12356的实时可用性本书未经拨测，如遇占线请改拨当地精神卫生中心电话或前往急诊。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证1〕

**还有一条边界，它属于本书自己。** 如果「清点自己卡在哪里」这件事本身就让你更难受——它常常如此，尤其对已经在反复自我怀疑的人——那就不要做本章。一份创造审计最容易产生的效果，是在原有的卡住之上再加一条「我连自己卡在哪都说不清」。这不是练习做得不对。跳过本章，直接从[第六章](Ch06_创造急救箱.md)6.1或[第二十二章](Ch22_创造的阴影与求助.md)开始，同样走得通。〔证2〕

**本书的一条立场。** 本书不把「找回创造力」写成在挤压你的条件里继续产出的义务。如果卡住来自工时、委托关系、评价环境或材料与工具的缺失，正确的回应是争取条件、改变关系、把验收标准写清楚，或者承认这个项目此刻做不了——不是练更多启动技巧。〔证2〕

## 5.2 一个前置判断：是状态问题，还是处境问题

这一节没有观察提示。它是本章最重要的一节。

[第六章](Ch06_创造急救箱.md)6.2把卡住分成两种：一种来自状态，条件都在、时间也有，坐下去之后什么都不出来；另一种来自处境——没有时间、没有授权、评价环境敌意、被要求做违心的东西、材料与工具缺失。两者的处理方式相反。本章的全部观察，都只在第一种情形里适用。

**原稿在这里放了一份十二题打分表，本书把它撤除。** 撤除的理由不是它太长，是它的每一题都预设了时间与自主权。举两题：「我每周主动看、读、听自己领域之外的东西」，「我能在当天把一个想法变成第一步动作」。一个每天剩下四十分钟可支配时间、且随时会被打断的人，这两题都得零分。表格随后告诉他：你的感知力与执行力是四维里最低的两项，那是你的施工面。〔证3〕

这个安排有三处错。第一，它把工时与照护负担改写成了个人能力的位置。第二，它给这个改写配了一个数字，而数字比标签更难反驳——标签你可以争，分数你会留着。第三，它还规定四周之后重测一次，「看分数移动」，并写下「创造力的证据在于分数在动，而不在于分数高低」。这句话没有任何测量学依据：一份未经信度与效度检验的自评表，其分数变动既可能反映状态变化，也可能反映当时的心情、题目顺序与对自己宽严的程度。本书不把它当作可以追踪的指标。〔证9〕

原稿还写「四维相乘，最低维决定你的创造总量」。这一说法没有任何来源，也不是它标注的那部著作的内容；「创造总量」不是一个可以相乘得出的量。本章撤除。〔证4〕

**三步判断，各问一次。** 这三问与[第六章](Ch06_创造急救箱.md)6.2相同，因为它们要回答的是同一个问题：

1. **卡住是否只在某一类条件下发生？** 换一个委托方、换一个时段、换一个没有人在背后看的环境就不卡，那要处理的是条件。
2. **如果给你两天完整的时间和完全的自主权，它还卡吗？** 这一问能相当干净地把状态与处境分开。
3. **这个作品的验收标准是谁定的，能不能协商？** 说不清楚「做到什么算完」的项目，任何人都做不动，见[第十一章](Ch11_执行与完成.md)。

如果三问都指向状态，往下读5.3。

**一个诚实的对价。** 处境并不总能改变：合同、生计、学业期限、无法转手的照护责任。这时候要做的不是要求自己在挤压中产出好作品，而是把创作降级为维持——每天一小段时间，不评价，不产出成品，只为保持手不生——并设定一个复查日期，到时候重新判断条件有没有变。承认「现在做不了」并保住一点点接触，比硬撑出一个自己都不信的东西更可持续。这一判断由Sonus确立，属立场性主张，不是从任何研究中推出的结论。〔证2〕

**一个常见的错位。** 林澄照着原稿的十二题打了一遍，最低两题是「当天把想法变成第一步动作」和「把做完的东西给至少一个人看」，于是认定自己执行力与分享力双低，准备从第十一章与第十二章开始按周补。但林澄那三个月同时带着两个项目，每天可支配的整块时间是早上通勤前的二十分钟，而「给一个人看」之所以做不到，是因为团队里上一次交出未完成版本的人被当众批过。第一问与第三问都指向处境：要处理的是排期与评价环境，不是执行力。这是本书的虚构情境，不是测评结果，也不表示所有人的处境都能这样谈。〔证6〕

## 5.3 三段定位与四维观察

### 先分三段：输入、处理、输出

这是一个帮助说话的框架，不是一个经过验证的模型。「卡住」这个词太笼统，把它拆成三段，至少能说清楚是哪一段断了。

| 阶段 | 在做什么 | 常见的断法 | 阅读入口 |
|:--|:--|:--|:--|
| 输入 | 素材、观察、经验进入你的库 | 没东西可想，库里是空的 | [第九章](Ch09_感知与输入.md) |
| 处理 | 联想、组合、孵化成想法 | 有素材却连不起来，想法不冒头 | [第十章](Ch10_想象与联想.md)；「孵化」是编排用语，见其10.4 |
| 输出 | 动手做、完成、修改、给人看 | 有想法却做不出来，做完不敢见人 | [第十一章](Ch11_执行与完成.md)、[第十二章](Ch12_分享与反馈.md) |

给空库的人讲想象力技巧，给不敢交初稿的人讲输入技巧，都是开错方向。三段之后，再用四维往细里看。〔证3〕

要说明一点：流水线这个比喻本身带着一个预设——创造是一种产出。对某些人，卡住恰恰是因为一切都被折算成了产出。这一章用它是为了定位，不是为了催促。〔证2〕

### 四维观察提示

下面四组是**观察提示，不是量表**。它们不计分、不设阈值、不作类型分类，也不承担诊断或疗效测量——本书没有对它们做过任何验证。用法是：读一遍，看哪几条让你停下来，然后去对应的章节。命中几条不说明任何问题，让你停下来的那一条才有信息量。〔证3〕

**感知（输入端）**

| 观察提示 | 阅读入口 |
|---|---|
| 觉得自己的生活很平淡，没东西可写 | [第九章](Ch09_感知与输入.md)、[第六章](Ch06_创造急救箱.md)6.4 |
| 从不随手记，想到的东西留不下来 | [第九章](Ch09_感知与输入.md)、[第二十一章](Ch21_个人创造系统.md) |
| 对熟悉的东西已经看不出新细节 | [第九章](Ch09_感知与输入.md)、[第六章](Ch06_创造急救箱.md)6.4 |
| 只看自己领域内的东西 | [第九章](Ch09_感知与输入.md)、[第十章](Ch10_想象与联想.md) |

| 观察提示 | 阅读入口 |

**执行（输出端）**

| 观察提示 | 阅读入口 |

| 大项目切不成小步骤 | [第十一章](Ch11_执行与完成.md) |
| 无法接受初稿很烂，于是一直不写第一版 | [第六章](Ch06_创造急救箱.md)6.10、[第十一章](Ch11_执行与完成.md) |

| 收到反馈之后不知道改什么 | [第十二章](Ch12_分享与反馈.md)、[第十一章](Ch11_执行与完成.md) |
| 做了很久，没有人知道 | 先看这一条是分发问题还是关系问题，见5.4第五种 |

关于「接不住批评」与「无法接受初稿很烂」：原稿在这一带引用了内在动机假说，并把「审判式自评是创造的头号毒药」写成结论。该假说的归属可以确认，但它是一个存在边界条件与后续争议的假说，不是无条件定论，本轮亦未取得其复制研究或元分析材料；「头号毒药」这一说法没有任何来源。本章不采用其中任何一种表述，只保留观察提示本身。〔证5〕

关于心流与长时间沉浸：[第十三章](Ch13_创造与心流.md)13.3处理这一主题，该章现已整章重写，其13.3照录了这一段。要提前说明的是，心流是一种描述，不是一项指标；追求它的过程本身可能变成新的考核。身心类练习存在焦虑与不适的不良体验报告，长时间沉浸也不例外，出现难受就停下，不是练得不够。重写之前的第十三章对这一段的回应是一份以体验次数为分母的「心流考古」记录页，与本段相反；该章重写后已把那份练习降为一次不设要求的留意，并写明不新增第三页记录，见其13.7。〔证4〕〔证8〕

## 5.4 六种常见的情形

三段与四维找「哪里断」，这一节找「在什么处境里断」。

下面是六种常见的情形，**不是六种人**。同一个人身上常常同时有几种，也可能一种都不像；这个项目上像第三种、下个项目上像第五种，都很正常。它们由Sonus整理，没有经过量表开发与验证，不用于分类，不表示严重程度，也没有「你是哪一型」的正确答案。〔证3〕

**一、感知不到素材**
常见体验：「我生活很平淡，没东西可写。」
容易忽略的一点：这一条最常见的成因不是感知迟钝，是生活里确实没有余量。一个把全部清醒时间用于通勤、工时与照护的人，不是看不见素材，是没有可以停下来看的时刻。先做5.2的三问，再决定要不要练感知。〔证2〕
阅读入口：[第六章](Ch06_创造急救箱.md)6.2 → [第九章](Ch09_感知与输入.md) → [第十五章](Ch15_创造与日常.md)。

**二、想不出可能**
常见体验：「想了一晚上，一个方案都没有。」
容易忽略的一点：想不出来的时候继续想，往往只是在延长同一状态。「放一放，想法会自己冒出来」这类孵化说法，在本书里没有取得可核验的一手材料，因此不作为已证机制引用。可自查的部分是：把任务从「想出好答案」换成「写三个答案，荒谬也算数」，后者此刻可以做。〔证4〕
阅读入口：[第六章](Ch06_创造急救箱.md)6.5 → [第十章](Ch10_想象与联想.md)。

**三、计划完美，就是没开始**
常见体验：一再推迟，用忙别的事避开真正该做的那件。
容易忽略的一点：不启动就不会失败，这个安排在短期确实有效，所以它很难自己消失。要处理的不是懒，是它在替你挡住什么。如果拖延已长期影响收入、学业或健康，它可能不是意志力问题，先走[第二十二章](Ch22_创造的阴影与求助.md)。〔证1〕
阅读入口：[第八章](Ch08_创作瓶颈与拖延.md) → [第十一章](Ch11_执行与完成.md) → [第六章](Ch06_创造急救箱.md)6.6。

**四、再改改，还没到能见人的程度**
常见体验：初稿永远交不出去；反复修改同一个局部；一想到被人看到就僵住。
容易忽略的一点：这一条要先分清是内在的标准，还是外在的评价环境。在一个提什么都被否、反馈只有「不行」而没有「哪里不行」的环境里，不敢交初稿是一种保护，不是完美主义的病。先做5.2的第三问。〔证2〕
阅读入口：[第六章](Ch06_创造急救箱.md)6.2 → 6.10 → [第十一章](Ch11_执行与完成.md) → [第十二章](Ch12_分享与反馈.md)。

**五、做了很久，没有人知道**
常见体验：作品攒了不少，反馈很少；不知道给谁看；也怀疑给谁看都没用。
容易忽略的一点：这一条里「没人知道」常常是分发与渠道的事实，不是你不会分享。平台规则、圈子的进入门槛、你所在的领域有没有可投的去处，这些都是环境条件。把它们写成分享力不足，等于要求一个人先解决行业结构问题才能开始发作品。另一件要诚实说明的事：长期独自创作最容易出现的不一定是水平下降，而是判断力失灵——没有人可以对齐，就只能反复自我怀疑。〔证10〕
阅读入口：[第十二章](Ch12_分享与反馈.md) → [第十八章](Ch18_创造与职业.md) → [第十四章](Ch14_创造与孤独.md)、[《孤独之书》第五章](../bol/Ch05_Loneliness_Audit.md)。

**六、这个能变现吗，不能就不做**
常见体验：只做有用的事；不能带来回报的题材、风格与练习都被算成浪费；停不下来，也玩不动。
容易忽略的一点：这一种要小心，不要急着认领。把一切折算成能否变现，常常是经济压力下的适应，不是价值观的缺陷——一个人放弃不能带来回报的题材，可能只是因为房租。先分清哪些是选择，哪些是没有选择；前者可以改，后者要处理的是条件。本书也不把「为艺术而艺术」写成一种更高贵的姿态，那只是另一种要求。〔证10〕
阅读入口：[第六章](Ch06_创造急救箱.md)6.2 → [第十八章](Ch18_创造与职业.md) → [第二十章](Ch20_创造的伦理.md) → [第二章](Ch02_创造去哪儿了.md)。

关于[第十六章](Ch16_智慧传统的创造观.md)的一句提醒：该章的智慧传统内容本轮尚未补齐原典的篇章与版本，读它时请把其中的传统表述当作待核验的转述，不要当作某部经典的原文。〔证3〕

## 5.6 你的阅读路线

不必打分，也不必排出「最低的那一维」。写下让你停下来的那一条，和它指向的入口：

```
我的阅读路线（日期：____）

1. 让我停下来的一条：____________________
2. 它有没有 5.1 里的任何一项情形：________
3. 5.2 的三问，它更像状态问题、处境问题，还是我说不清：________
4. 我先读的入口：第__章 ____________
5. 读完之后我愿意试的一个动作：____________
6. 什么时候回来看一眼：________
```

两条使用规则：

1. **一次只走一条线。** 三段、四维、六种情形全开的计划很难维持，而创造类练习一旦变成清单，最容易长出一种新的考核：反复检查自己今天有没有产出。先处理让你停下来的那一条，不设进度，不排四周计划，不重测分数。〔证3〕〔证9〕
2. **先读第六章的6.1与6.2。** 无论走哪条线，[第六章](Ch06_创造急救箱.md)都建议先看两节：6.1分清哪些情形需要先求助，6.2判断你面对的是状态问题还是处境问题。这两节决定后面所有技术对你是否适用。

写下来的意义不在于承诺，在于它把「我是不是没有创造力」这个无法回答的问题，换成「我这周先读哪一章」这个可以回答的问题。〔证2〕

## 本章速记

- 先分诊：自伤念头、持续低落、耗竭、停不下来的担忧、影响收入与健康的拖延，都不属于本章的观察对象。
- 5.2的三问决定后面所有技术是否适用。原稿的十二题打分表、「四维相乘」与「四周后重测看分数移动」均已撤除。
- 三段（输入、处理、输出）是帮助说话的框架，不是经过验证的模型；四维是观察提示，不计分、不设阈值、不作分类。
- 六种情形是常见的处境，不是六种人；其中第五种的「没人知道」常常是分发条件，第六种的「只看变现」常常是经济压力。
- 创造审计本身可能加重自我怀疑。这一章可以整章跳过，不影响后面的阅读。
- 本书不把「找回创造力」写成在挤压你的条件里继续产出的义务。
