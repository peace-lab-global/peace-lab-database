# 第七章 · 创造场景剧本

> 原稿在这一章给八种卡壳场景各配一套三步剧本——承认、急救、转入——题辞担保「每套 10 分钟以内」，速记担保「几乎对每种场景都有缓解作用」，章末一份六条的参考文献。这一版保留八套剧本的形状与「承认是第一步」的次序，把急救一步改指[第六章](Ch06_创造急救箱.md)的七个选项而不重述做法；撤除的有一处时长承诺、一处效果承诺、一处时限、两处把处境问题写成个人问题的句子，并为每一套补上原稿没有的分支：**要求本身不合理时，出路是把验收标准谈清楚，或承认这个项目此刻做不了**，不是更努力地执行剧本。〔证1〕

本章引用的材料共六种，在实践与传统两份来源台账及待核验清单里各有行可查。学术或准学术两种（Steel 2007、Sawyer 2012）本轮均**仅书目**、未核读原文；实务读物两种（Pressfield 2002、Lamott 1994）按本书修订原则改标为编写建议来源，不承担事实或效果主张；Amabile（1996）见[实践台账P31](../SOURCES_PRACTICE.md#p31)，它是一个存在边界条件与后续争议的假说，不是无条件定论；Wallas（1926）在[传统来源台账](../SOURCES_TRADITIONS.md)另有条目，同为仅书目。六条在原稿正文各有对应引用，**均不属孤儿条目**。〔证2〕

这一版因此比原稿安静。八套剧本留下的判断只有三类：承认是第一步（编排次序，可自查）；急救一步该用第六章的哪一个选项（书内指向）；卡住的另一类来源是处境，那一类的出路在剧本之外（[第六章](Ch06_创造急救箱.md)6.2）。其余各句，要么标明属谁，要么标未核实，要么撤除。〔证1〕

节号有变动。原稿的八节（7.1至7.8）就是八套剧本，本版改为新7.3至7.10，前置7.1（这一章不做什么）与7.2（原稿逐条处置），后置7.11（本章不处理的事）。〔证1〕

## 7.1 这一章不做什么

三条限定。

第一，**这一章不把卡住写成你的失败。** 剧本这个体裁自带一个预设：给对了剧本，事情就能推进。可卡住有两个来源（[第六章](Ch06_创造急救箱.md)6.2）：状态与处境。处境造成的卡住——没有时间、没有授权、评价环境敌意、被要求做违心的东西、材料与工具缺失——不是任何一套剧本能「救」的，剧本给得再顺，也只是在挤压的条件里练启动。本章为每一套剧本补一个原稿没有的分支，写在各节第三段：**要求本身不合理时，出路是把验收标准谈清楚，或承认这个项目此刻做不了。**〔证3〕

第二，**这一章不承诺任何一套剧本会有效。** 原稿题辞「每套 10 分钟以内」是时长承诺，速记「几乎对每种场景都有缓解作用」是效果承诺；本轮没有任何材料支持这两个承诺，一并撤除。剧本是编排装置：把「下一步做什么」从临场决定变成照单取用，这个便利本身可自查，不构成疗效——第六章对它的七个动作用了同一口径，本章沿用。〔证1〕

第三，**这一章不重述第六章的做法。** 八套剧本的急救一步，全部改指[第六章](Ch06_创造急救箱.md)6.4至6.10的七个选项，本章只说「是哪一步、为什么是它」，不复述怎么做。同一份做法写两处，读者就要在两处核对口径是否一致；本轮逐处核对过的重复，都是负担。〔证1〕

导航页约定一写的是「每章只建议一个最小行动」，本章的最小行动是这一件：**卡住的时候，先对照7.11的路由表看一眼你的情形在哪一行，只打开那一行的去处，看完就停。** 不必做任何练习，也不必把八套剧本读完。〔证4〕

如果你此刻属于下面某一行，本章所有剧本对你不适用，先照那一行去。跳过本章不影响你读这本书的其余部分——第六章是急救，第十一章是执行，都不以本章为前提。

## 7.2 原稿逐条处置

| 原稿的一句 | 处置 | 理由 |
|---|---|---|
| 题辞「八套剧本，对应八种卡壳场景，每套三步：承认 → 急救 → 转入。每套 10 分钟以内，按你正在经历的情境取用」 | 三步形状与「按情境取用」保留，「每套 10 分钟以内」撤除 | 时长承诺无来源；第六章的动作不设分钟数，两章口径须一致。「承认是第一步」的次序本身可自查，保留。〔证1〕 |
| 7.1「先承认『我卡住了』，不必羞耻化，瓶颈是信号」 | 承认一步保留；「信号」的读表语气撤除 | 承认作为第一步是编排次序，「不必羞耻化」与全书对品行归因的处置同向；但「是信号」把一种状态写成仪表读数，预设它有单一原因、且原因可从状态本身读出——[第六章](Ch06_创造急救箱.md)6.1开篇那句「有些卡住不是技巧的适应症」说的正是这件事的反面。保留的写法见7.3。〔证1〕 |
| 7.1「用限制练习降低自由度（『只用三段话讲完』），最后完成一个小件收尾」 | 做法改指第六章6.8，不重述；「降低自由度」不作为效果解释；「完成一个小件」保留为可选的收尾方向 | 限制动作的理由由第六章6.8承担（「随便做做」是无法开始的任务，「用三段话讲完」是可以开始的任务）；「降低自由度」是把动作写成了机制。〔证8〕 |
| 7.1「瓶颈常在提示输入断供，今天之后给第9章排个日程」 | 「常在」的规律语气撤除，降为一种可能的情形；「排个日程」补安排权前提 | 机制断言需要测量，本轮一份没有；排日程要有可支配的时间，对[第六章](Ch06_创造急救箱.md)6.2五类处境里的第一类直接不成立，补上「时间由你支配时」的前提。〔证1〕 |
| 7.1「阻力越大的项目越重要 (Pressfield, 2002)」 | **整句撤除** | 双重问题：其一，它是因果主张——把「阻力」（对这件事的抗拒感）当作「重要性」（这件事的价值）的信号，需要同时测量两者的研究，本轮一份也没有；其二，该书是实务读物、仅书目，改标编写建议来源、不承担事实主张。这句的反向伤害直接：对被要求做违心的东西的人（6.2第四类），阻力大恰恰可能因为要求本身不合理——把它读成「越重要」，等于把处境问题读成价值信号。〔证9〕 |
| 7.2「拖延是自我调节失败，与人品无关 (Steel, 2007)」 | 构念归属保留；「与人品无关」改标本书伦理立场，不归于该文 | 「自我调节失败」确属该元分析的对象（其题名即如此），归属成立；「与人品无关」是本书的伦理立场——该文不研究人品评价，本书也不让一份拖延研究承担反污名的任务，这句话的身份是立场，不是引文。〔证10〕 |
| 7.2「执行练习只做 2 分钟，然后把 2 分钟顺势变成『完成一个小件』」 | 做法改指第六章6.6；「顺势变成」的效果预期撤除 | 两分钟动作的理由由第六章承担（它是一个几乎不可能失败的量）；「顺势就会变成小件」是操作效果主张，第六章6.6已裁定Steel（2007）不能支持任何这类效果，本章不再让做法自带疗效。〔证10〕 |
| 7.3「允许练习把评委请出初稿现场 (Amabile, 1996)」 | 归属撤除，动作改指第六章6.10 | 「把评委请出初稿现场」是第六章对允许粗糙的比喻，不是Amabile的表述；内在动机假说见P31，是一个存在边界条件与后续争议的假说，本书不让它担保任何具体动作的效果。〔证11〕 |
| 7.3「焦虑的出口是行动：把做出来的东西发给一个人，让分享代替反刍」 | 「出口是行动」的规律语气与「让分享代替反刍」的因果撤除，方向保留为可选动作 | 分享与反刍的关系需要测量；分享是可选的，[第十二章](Ch12_分享与反馈.md)的分享梯度从「不给任何人看」那一档开始，不上桌不欠账。保留的方向见7.5。〔证12〕 |
| 7.4「空虚是输入池见底的信号」 | 「信号」的读表语气撤除，保留为编写判断 | 「输入池」是本书比喻；把它写成「信号」与上一行同病：预设空虚有单一原因、且可从状态本身读出。空虚也可以是抑郁的表现（7.1分诊表第三行），那一类先评估。〔证13〕 |
| 7.4「把创造全押在『有用』上，意义就会漏光」 | 「就会」的因果撤除，保留为提醒 | 因果主张无来源；「漏光」是比喻。意义的处置在《意义之书》，本章不代它。〔证1〕 |
| 7.5「注意区分独处与孤独：独处滋养创造，孤独侵蚀创造（第14章）」 | 「滋养」「侵蚀」的因果对仗撤除，两分保留为编写表述 | 对仗把两个方向都写成了因果，两处都需要本轮没有的测量；独处与孤独可以分开对待，这个两分保留，出处照旧标第十四章（该章尚未修订）。〔证14〕 |
| 7.5「约一位同好、发一条同好群消息」 | 保留为可选动作，补安全边界 | 给一个人看的前提在[第六章](Ch06_创造急救箱.md)6.9：只发给一个此刻会让你安全的人；发出去得到的是贬低，那不是动作失灵，是关系选错了。〔证12〕 |
| 7.6「完成练习强制收口，今天必须宣布『完成』」 | 「强制」「必须」的义务化措辞撤除 | 导航页约定一：练习可选、不累积、跳过不构成失败。「今天必须」把一个可选动作写成了当天的义务，与约定一正面相反。〔证4〕 |
| 7.6「允许练习巩固『完成的粗糙版胜过完美的空白页』 (Lamott, 1994)」 | 归属撤除，「巩固」撤除，比较句降为流传的写作经验 | 该书是实务读物、仅书目，改标编写建议来源；「巩固」暗示重复会强化效果，无来源；「粗糙版胜过空白页」的比较降为写作教育里流传的说法，不归于作者——[第六章](Ch06_创造急救箱.md)6.10对同一方向的写法是「这一版可以是烂的」，不含比较级。〔证15〕 |
| 7.7「失败是创造的工序 (Sawyer, 2012)」 | 归属降级，句子改标本书的编写表述 | 该书本轮仅书目、未核读；「工序」是本书的比喻，不归于该作者、不承担事实主张。失败与提取的关系在本书的既有口径是[第十七章](Ch17_失败与创造.md)17.1那句「失败本身不产生进步，提取出的信息才产生」——那是书内的编写判断，同样不由该书承担，该章亦尚未修订。〔证16〕 |
| 7.7「48 小时内把失败写进失败档案（第17章）」 | 时限撤除，去处保留 | 「48小时内」是无来源的时限，与全书撤除天数与时限的口径同族（[《时间之书》第二十三章](../bot/Ch23_28_天时间重建.md)对二十八天的处置同项：周期长度无任何研究支持）；失败档案的写法归第十七章。〔证1〕 |
| 7.8 原稿「迷茫是酝酿期缺了准备阶段（Wallas, 1926）」，现行文本已在此前一轮单行更正 | 照录其处置：该解释不作断言，保留的只是「先收集材料，再提问」的顺序 | 该书本轮仅取得书目，一个思想史著作的过程顺序读不成对「迷茫」的解释；顺序标编写建议、不是验证过的流程。〔证17〕 |
| 速记「对症状取剧本，别乱吃药」 | 前半保留，比喻后半撤除 | 「乱吃药」的比喻把剧本当药，与「不承诺有效」的口径相反：药有适应症与疗效，剧本两样都没有。〔证1〕 |
| 速记「两个通用兜底：2 分钟执行与允许练习，几乎对每种场景都有缓解作用」 | 「缓解作用」的效果主张撤除 | 两个动作的可自查理由在[第六章](Ch06_创造急救箱.md)6.6与6.10，都不含「对每种场景缓解」的人群主张。〔证1〕 |
| 章末参考文献段（原稿标题在中英文之间带一条竖线）六条 | 整段撤除，改为「依据与可信度」表 | 六条在原稿正文各有对应引用，**均不属孤儿条目**；撤除的是那个把学术研究与实务读物混排、全部读作同一级别依据的形式。〔证2〕 |
| 两处装饰性表情符号小节标题、正文十余处ASCII双引号 | 全部清除，引号改为「」与『』 | 本书体例。表格单元格里不能出现裸的竖线，故上一行以文字描述原稿标题格式，不照录原标记。〔证1〕 |

## 7.3 剧本一：瓶颈

原稿的三步：承认瓶颈 → 限制练习 → 完成练习。

**保留的。** 承认（「我卡住了」，不必羞耻化）→ 急救：[第六章](Ch06_创造急救箱.md)6.8，给当前这件事加一个能开始的限制 → 转入：补输入。瓶颈的一种可能的情形是输入断了——不是每次都是，这一句不构成规律——手边没有新材料时，[第九章](Ch09_感知与输入.md)的感知与素材库是去处（该章尚未修订）。收尾一件小事的方向保留为可选：做完一段就停在一个说得完的地方。〔证8〕

**撤除的。**「阻力越大的项目越重要」整句撤除，见7.2表；「瓶颈常在提示输入断供」的规律语气撤除，只留上面那句情形描述。

**处境分支。** 如果瓶颈只出现在某个特定项目、特定委托方或特定评审面前，先过[第六章](Ch06_创造急救箱.md)6.2的三问——那更可能是处境问题。验收标准说不清的项目谁都做不动；出路是把标准谈清楚，或承认这个项目此刻做不了，不是换一套更用力的剧本。〔证3〕

**去处。** 输入与素材见[第九章](Ch09_感知与输入.md)（尚未修订）；拖延与完美分别见7.4与7.8；处境判断见[第六章](Ch06_创造急救箱.md)6.2。

## 7.4 剧本二：拖延

原稿的三步：承认拖延 → 执行练习 → 完成练习。

**保留的。** 承认（「我在拖」——它不是品行问题，这一句的身份是本书伦理立场，见7.2表）→ 急救：[第六章](Ch06_创造急救箱.md)6.6，只做两分钟，两分钟后想停就停 → 转入：连环拖延见[第八章](Ch08_创作瓶颈与拖延.md)的拖延与完美的循环。〔证8〕

**撤除的。**「顺势变成完成一个小件」的效果预期撤除——两分钟的全部要点是它允许停，不担保停不下来；Steel的归属处置见7.2表。〔证10〕

**处境分支。** 连环拖延常有一个成分不是状态，是任务本身有问题：标准飘、没人拍板、做了也白做。这一类用启动技巧绕不过去——绕过去一次，下一次还在。出路在[第六章](Ch06_创造急救箱.md)6.2第三问与[第十八章](Ch18_创造与职业.md)（该章尚未修订）：把验收标准谈清楚，或者承认这件事此刻不该由你这样去做。〔证3〕

**去处。** 长期拖延见[第八章](Ch08_创作瓶颈与拖延.md)；执行与完成见[第十一章](Ch11_执行与完成.md)（尚未修订）。

## 7.5 剧本三：焦虑

原稿的三步：承认焦虑 → 允许练习 → 分享练习。

**保留的。** 承认（「我很怕做不好」）→ 急救：[第六章](Ch06_创造急救箱.md)6.10，允许它粗糙——初稿阶段最大的干扰是一个还没被邀请进来的评委 → 转入：如果之后想做点什么，6.9给一个人看（可选）。〔证8〕

**撤除的。**「出口是行动」的规律语气与「让分享代替反刍」的因果撤除；Amabile的归属撤除，见7.2表。焦虑不必然有出口，有的焦虑需要的是评估而不是行动。〔证11〕

**处境分支。** 与具体项目难度无关的焦虑、持续两周以上的焦虑、或伴随情绪低落与睡眠食欲改变的焦虑，不是初稿评委问题，是7.1分诊表第二、三、五行的情形——先评估，见[第二十二章](Ch22_创造的阴影与求助.md)22.5。〔证13〕

**去处。** 分享梯度与反馈筛选见[第十二章](Ch12_分享与反馈.md)（尚未修订）。

## 7.6 剧本四：空虚

原稿的三步：承认空虚 → 感知练习 → 想象练习。

**保留的。** 承认（「我现在心里没东西」）→ 急救：[第六章](Ch06_创造急救箱.md)6.4，只看一样东西五分钟，看完往素材库记一条 → 转入：让接回来的东西发生关系，[第十章](Ch10_想象与联想.md)的可选配对（该章已重写，配对不设个数、不计分）。〔证8〕

**撤除的。**「空虚是输入池见底的信号」的读表语气撤除；「把创造全押在『有用』上，意义就会漏光」的因果撤除，见7.2表。空虚的一种可能确实与输入有关，但它不是唯一的可能，本书不把它写成读数。〔证1〕

**处境分支。** 长期空虚、对以前喜欢的事都提不起兴趣，是7.1分诊表第三行的情形——先评估，不是素材问题。〔证13〕

**去处。** 输入见[第九章](Ch09_感知与输入.md)（尚未修订）；意义的处置见[《意义之书》](../bom/INDEX.md)。

## 7.7 剧本五：孤独

原稿的三步：承认孤独 → 分享练习 → 连接练习。

**保留的。** 承认（「一个人做太久了」）→ 急救：[第六章](Ch06_创造急救箱.md)6.9，给一个人看——只发给一个此刻会让你安全的人，不求反馈，只求发出 → 转入：约一位同好，或发一条同好群消息，同为可选。〔证8〕

**撤除的。**「独处滋养创造，孤独侵蚀创造」的因果对仗撤除，两分保留为编写表述，见7.2表。〔证14〕

**处境分支。** 被排挤、被孤立、身处歧视性环境造成的孤独，是处境问题，处置路径在[《孤独之书》第十九章](../bol/Ch19_Workplace_Loneliness.md)的处境判断里，不在「多约人」里；把处境写成个人调节任务，是本书不做的事。〔证14〕

**去处。** 独处与孤独的两分见[第十四章](Ch14_创造与孤独.md)（尚未修订）；分享梯度见[第十二章](Ch12_分享与反馈.md)（尚未修订）。

## 7.8 剧本六：完美

原稿的三步：承认完美 → 完成练习 → 允许练习。

**保留的。** 承认（「我又在无限修改了」）→ 急救：[第六章](Ch06_创造急救箱.md)6.10，允许它粗糙——注意它的边界：适用于初稿阶段，不适用于交付阶段，两者是不同的工作 → 转入：[第十一章](Ch11_执行与完成.md)的粗糙初稿权与最小完成单元（该章尚未修订）。〔证8〕

**撤除的。**「强制收口」「今天必须宣布完成」两处义务化措辞撤除；「巩固」与Lamott的归属撤除，见7.2表。完成的宣布可以是今天，也可以不是；它是一个可选动作，不是限期任务。〔证4〕

**处境分支。** 委托作品、协作件、有明确规格的东西有验收标准，达不到标准不是完美主义，是任务要求（[第六章](Ch06_创造急救箱.md)6.2「没有授权」一类：方案是别人定的，你只负责执行）。此时该谈的是标准，不是心态；标准本身不合理时，出路见本章每节共有的那条分支。〔证3〕

**去处。** 长期拖延与瓶颈见[第八章](Ch08_创作瓶颈与拖延.md)；完成与收尾见[第十一章](Ch11_执行与完成.md)（尚未修订）。

## 7.9 剧本七：失败

原稿的三步：承认失败 → 允许练习 → 执行练习。

**保留的。** 承认（「这次搞砸了」）→ 急救：[第六章](Ch06_创造急救箱.md)6.10，先把「这一版可以是烂的」说出来——它先接住情绪，再谈别的 → 重启：6.6只做两分钟，用一个动作结束回味 → 转入：失败档案的写法见[第十七章](Ch17_失败与创造.md)（该章尚未修订）。〔证8〕

**撤除的。**「失败是创造的工序」不再归于Sawyer，降为本书编写表述；「48小时内」的时限撤除，见7.2表。失败之后什么时候提取、要不要提取，由你定；档案是工具，不是限期任务。〔证16〕

**处境分支。** 反复自我怀疑、无法判断好坏，并伴睡眠、食欲或情绪改变，不是「失败的正常回味」，是7.1分诊表的情形；[第六章](Ch06_创造急救箱.md)6.11决策表的末行同此。〔证13〕

**去处。** 失败与提取见[第十七章](Ch17_失败与创造.md)（尚未修订）；反馈与被批评见[第十二章](Ch12_分享与反馈.md)（尚未修订）。

## 7.10 剧本八：迷茫

原稿的三步：承认迷茫 → 感知练习 → 想象练习。

**保留的与已处置的。** 承认（「我不知道该做什么」）。原稿在这里把迷茫解释成「酝酿期缺了准备阶段」，并把它归给一部 1926 年的思想史著作；该书本轮仅取得书目，这个解释本书不作断言。可以保留的只是顺序：先收集材料（[第九章](Ch09_感知与输入.md)），再提问「如果……会怎样」（[第十章](Ch10_想象与联想.md)），让材料自己长出方向。这是编写建议，不是验证过的流程。〔证17〕

**处境分支。** 迷茫超过两周，或同时有情绪低落、兴趣丧失、睡眠或食欲改变，先读[第二十二章](Ch22_创造的阴影与求助.md)22.5，不要靠[第五章](Ch05_创造审计.md)5.3 的观察提示自己判断——那一节明确写着它们不计分、不设阈值、不承担诊断。〔证13〕

**这一套与前七套的不同。** 前七套的急救一步都指向第六章的一个具体选项；这一套没有。迷茫的处理是顺序而非动作：硬给它配一个「五分钟急救」，等于把「不知道做什么」误当成「知道做什么但动不了」——前者的出路是让材料长出方向，后者的出路才是第六章的动作。两种情形的处理相反，误配会互相失效。〔证1〕

## 本章速记

- 八套剧本留下的只有形状：承认 → 急救（[第六章](Ch06_创造急救箱.md)6.4至6.10中的一个选项）→ 转入。急救与转入的具体做法都在第六章与各去处，本章不重述。
- 「每套 10 分钟以内」「几乎对每种场景都有缓解作用」「48 小时内」三处承诺与时限撤除；「阻力越大的项目越重要」整句撤除。
- 每一套都补了原稿没有的分支：要求本身不合理时，出路是把验收标准谈清楚，或承认这个项目此刻做不了，不是更努力地执行剧本。
- 迷茫这一套没有急救动作：它的处理是顺序，不是动作，与前七套相反。
