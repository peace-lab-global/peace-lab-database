## ⚡ 急救卡（今天就能用）

**第一步永远是：先动起来，再谈好坏。**

| 状况 | 动作 | 章节 |
|:--|:--|:--|
| 没灵感/脑子空 | 五感扫描 5 分钟 + 往素材库存 1 条 | [Ch06](Ch06_创造急救箱.md)① / [Ch09](Ch09_感知与输入.md) |
| 不想开始 | 2 分钟规则：只做 2 分钟就允许停 | [Ch06](Ch06_创造急救箱.md)③ / [Ch11](Ch11_执行与完成.md) |
| 怕写得烂 | 丑陋开场 + 对自己说"我可以创造，即使不完美" | [Ch06](Ch06_创造急救箱.md)⑨⑩ / [Ch11](Ch11_执行与完成.md) |
| 想法很乱 | 组合练习：把两个不相关的东西强行配对 | [Ch06](Ch06_创造急救箱.md)⑤ / [Ch10](Ch10_想象与联想.md) |
| 项目太大动不了 | 切出最小完成单元，今天只做它 | [Ch06](Ch06_创造急救箱.md)⑨ / [Ch11](Ch11_执行与完成.md) |
| 做完不敢给人看 | 分享给一个人，只问"哪里没看懂" | [Ch06](Ch06_创造急救箱.md)④ / [Ch12](Ch12_分享与反馈.md) |
| 拖延自责发作 | 执行练习（先做 2 分钟）+ 允许练习 | [Ch06](Ch06_创造急救箱.md)③⑩ |

通用话术："我在做个小东西，能帮我看看哪里没看懂吗？"（说出来，比憋着快十倍）

## 📚 推荐延伸阅读

科学/方法
- 《创造力》（Mihaly Csikszentmihalyi）：创造的系统模型与创造者访谈
- 《像艺术家一样偷窃》（Austin Kleon）：组合与影响
- 《艺术之战》（Steven Pressfield）：与阻力作战

习惯/实践
- 《创造的习惯》（Twyla Tharp）：仪式与日常
- 《艺术家之路》（Julia Cameron）：晨间页与艺术家约会
- 《深度工作》（Cal Newport）：无干扰时间块

传统/人文
- 《庄子》：庖丁解牛，技进乎道
- 陆机《文赋》、刘勰《文心雕龙》：创作过程的中国古典白描

## 📅 一周最小计划（比 28 天更小的起步版）

时间不够？先跑这一周（每天 ≤15 分钟，完成即赢）：

| 天 | 15 分钟做什么 | 对应 |
|:--|:--|:--|
| 周一 | 五感扫描一个场景，写 3 句入素材库 | [Ch09](Ch09_感知与输入.md) |
| 周二 | 写 3 行 / 画 1 张速写（丑陋开场） | [Ch11](Ch11_执行与完成.md) |
| 周三 | 随机联想十连，选 1 个想法记下 | [Ch10](Ch10_想象与联想.md) |
| 周四 | 继续周二的小东西，目标是"完成" | [Ch11](Ch11_执行与完成.md) |
| 周五 | 发给一位朋友，只问"哪里没看懂" | [Ch12](Ch12_分享与反馈.md) |
| 周六 | 自由：做最想做的，或休息 | [Ch19](Ch19_日常的创造.md) |
| 周日 | 5 分钟复盘 + 定下周一个焦点 | [Ch21](Ch21_个人创造系统.md) |

跑顺这一周，随时可以升级为 [28 天计划](Ch23_28_天创造建设.md)。
