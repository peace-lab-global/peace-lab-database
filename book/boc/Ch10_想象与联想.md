# 第十章 · 想象与联想

> 原稿在这一章给出了一套完整的联想叙事：远距离联想的定义与一条「距离越远，组合越新」的定量关系、孵化效应与它的三条使用要点、一个「新 = A × B」的组合公式与一张距离表、五个假设句式、一段关于空隙的劝说，以及一份随机联想十连作业。这一版把定义句与定量关系撤除，把「孵化」降为本书的编排用语，把组合公式退回算术装置，把假设句式与第六章6.5去重，把十连作业改为一次不设个数的可选配对，并在空隙一节补上原稿漏掉的安排权前提。〔证1〕

撤除的理由不是这些说法没用，而是它们各自在本轮没有取得材料。Mednick（1962）与Kleon（2012）在实践来源台账的待核验清单里各有一行，均仅书目、未核读原文；Wallas（1926）在传统来源台账另有条目，同样仅书目。三份材料在这一章里共同担保三件事——创造力就是远距离联想、放下问题后大脑在后台继续检索、组合的力度取决于两个元素的距离——三件事都不在任一份材料的已核验范围之内。〔证2〕

这一章因此比原稿安静：它不再解释想法是怎么冒出来的，只保留不需要材料就能成立的部分——想不出来，通常不是你的联想力不够；两个东西放在一起，有时能得到一个新东西；散步也是创作过程的一部分。这三句就是本章保留的全部判断，其中没有一句是机制陈述。〔证1〕

节号有变动。原10.1（远距离联想）改为新10.3，原10.2（孵化效应）改为新10.4，原10.3（组合公式）改为新10.5，原10.4（如果……会怎样）改为新10.6，原10.5（给想象留空隙）改为新10.7并补安排权前提，原10.6（随机联想十连）改为新10.8并降为一次可选配对；前置10.1与10.2，后置10.9。原10.4的内容与[第六章](Ch06_创造急救箱.md)6.5大面积重合，新10.6只保留第六章没有的部分。〔证1〕

## 10.1 先说清楚：这一章不做什么

三条限定。

第一，**这一章不解释想法是怎么冒出来的。** 原稿给了三个机制：远距离联想的检索、大脑后台的加工、组合力度与元素距离的关系。三个都撤除或降级。「远距离联想」只保留一个构念名。〔证2〕

第二，**这一章不给公式、不给分数、不给天数。** 原稿有两个公式（联想力＝库的广度×连接的练习；新东西＝已有的东西A×已有的东西B）、一个天数（连续做一周）与两个时长（十连约十分钟、空隙哪怕十五分钟）。两个公式全部撤除，三个数字全部撤除，理由分别写在10.5、10.7与10.8。〔证3〕

第三，**这一章不给你分型，也不把「想不出来」写成能力缺陷。** 原稿从「普通人从盐想到咸，创造者能从盐想到雪花」开篇，这个分法没有分母也没有来源，本书不据此把人分成两类，也不提供把你自己归入哪一类的办法。想不出来可以是处境（[第六章](Ch06_创造急救箱.md)6.2的五类），可以是疲惫（[第三章](Ch03_创造的生理学.md)3.5），可以只是此刻没有可配的材料（[第九章](Ch09_感知与输入.md)9.2）；它是哪一种，本章不下结论。〔证2〕

导航页约定一写的是「每章只建议一个最小行动」，本章的最小行动是这一件：**在接下来几天里，如果你偶然发现自己把两件不相干的事想到了一起，不必记下来，也不必让它变成什么。** 看见一次算一次，没看见也算，不需要得出任何结论。它也不构成第三套记录制度——附录已有两页可选记录，这个留意不需要另建一份表。练习可选，跳过不等于没读，也不构成失败。〔证4〕

如果你此刻属于下面某一行，本章其余各节一律不适用，先照那一行去。跳过本章不影响你读这本书的其余部分——第十一章讲执行，第十二章讲分享，两章都不以本章为前提。

三条限制。本表不是诊断标准，不能用来判断你或别人有没有病，也不能排除风险。12356的实时可用性本轮未拨测，若无法接通，请前往医院急诊或拨打120。如果你不确定自己属于哪一行，按更靠上的那一行处理。〔证5〕

**本书的一条立场，在本章不是引用，是使用限制。**〔证7〕

照录[第六章](Ch06_创造急救箱.md)6.2与[本书导航页](INDEX.md)约定三：本书不把「找回创造力」写成在挤压你的条件里继续产出的义务。没有时间的（工时、通勤、照护、第二份工作）、没有授权的（方案是别人定的，你只负责执行）、评价环境敌意的（提什么都被否，或反馈只有「不行」而没有「哪里不行」）、被要求做违心的东西的、材料与工具缺失的，这五类处境造成的连不起来，不是你的联想力不够，也不是没留够空隙。本章讲的所有练习，都以你此刻有可支配的注意力为前提；没有这个前提的时候，先读10.7。

**还有一句原稿没写的话，本章补上。** 原稿题辞说「连接是可以练的」，这句听起来是好消息，但它把训练量、训练周期与训练效果全部留给了你的想象——本书不承诺任何一种练习会让你「更会联想」，包括本章自己的。〔证1〕

## 10.2 原稿逐条处置

| 原稿的一句 | 处置 | 理由 |
|---|---|---|
| 题辞「想象力是把已有的东西连成没有的形状。这是好消息：连接是可以练的」 | 前半句保留，后半句撤除，并补一句原稿没写的话 | 前半句是本章立场，它不需要来源。后半句预设了本章并不拥有的材料：训练能否改变联想、以什么为指标、多快见效，本轮一项也没有取得。补上的那一句是「想不出来，通常不是你的联想力不够」，它与第六章6.2的处境前提一致。〔证1〕 |
| 10.1「经典理论把创造力定义为形成远距离联想的能力……距离越远，组合出的东西越新 (Mednick, 1962)」 | 定义句与定量关系撤除，只保留「远距离联想」构念名及归属 | 本轮仅书目，未核读原文。「创造力就是……」把一个研究取向的构念写成充分必要定义；「距离越远组合越新」是一条定量关系，需要同时测量联想距离与新颖度的研究，本轮一份也没有。〔证2〕 |
| 10.1「普通人从盐想到咸，创造者能从盐想到雪花再到流泪」 | 整句撤除，那组例子降为示意 | 人群分型没有分母、没有来源，也没有把一个真实的人归入某一类的操作办法；它还把「想不出来」从处境问题改写成类别问题，与第六章6.2相反。〔证2〕 |
| 10.1「这解释了为什么跨领域的人容易出新：领域之间的距离天然是远的」 | 方向保留，「天然」与「这解释了」撤除 | 库里门类多、能配对的东西多，这是算术；「天然」属「自动」家族，第三章3.4与《时间之书》第十二章同项。「这解释了」把一条算术当成机制结论的推导姿态，一并撤除。〔证1〕 |
| 10.1「你的素材库里厨房、财报、地铁、天文各占一格，碰撞半径就大」 | 「碰撞半径」撤除，句子改写 | 物理比喻让一条算术看起来像被测过的定律。改写后只剩：「库里门类多的时候，能配对的东西多。」〔证1〕 |
| 10.1「联想力 = 库的广度（第九章）× 连接的练习（本章）。两手都要抓」 | 整句撤除 | 乘法装置在本书已有裁定：附录术语表移出了「四维模型＝四力相乘」条，第五章5.2对十二题打分表的处置同项；两个因子都没有测量办法，它们的乘积更没有。〔证3〕 |
| 10.2「放下问题，答案反而出现 (Wallas, 1926)。这就是孵化效应」 | 前半句降为经验描述，「这就是」的等号与归属撤除 | 「放下之后有时有答案」不需要材料担保，本书只承诺「有时」；等号把一句经验描述写成了机制身份。四阶段出自一部1926年的思想史著作，讲的是过程顺序，不是实验结论。〔证8〕 |
| 10.2「大脑在后台继续做远距离检索，直到某个时机『啊哈』一下接通」 | 整句撤除 | 机制陈述，本轮没有任何材料支持；「后台检索」与「接通」都是把隐喻当事实来写。〔证9〕 |
| 10.2要点一「孵化前必须先有准备。没啃过问题就放下，那叫放弃，不叫酝酿」 | 顺序保留，「那叫放弃」撤除 | 先啃过问题再放下，这个顺序本身有用：它防止把「搁置」变成一直没有开始的另一个名字。但它不能反过来把一个人的放下写成品行判定，第三章3.3对同一族问题已有裁定。放下不构成品行问题，放下也不保证有结果。〔证8〕 |
| 10.2要点二「选低刺激活动。散步、洗澡、洗碗是理想孵化器」 | 动作保留，「理想的」撤除 | 最高级没有比较对象也没有来源，第三章3.3同项。能说的是：低刺激、无任务的活动里，有时会有想法冒出来。〔证9〕 |
| 10.2要点二「刷短视频是孵化杀手，因为新刺激会不断劫持后台」 | **整句撤除** | 「劫持后台」给一个本章已撤除的机制当解释；「是杀手」是没有分母的全称断言。能留下的只有弱得多的一句：刷的时候新内容一个接一个，想法通常没有机会接上——这是很多人报告过的经验，不是定律，也不是因果证明。〔证10〕 |
| 10.2要点三「随身带捕获工具。明朗常常出现在没有纸笔的地方」 | 保留，术语身份调整 | 有地方放东西确实有用，第九章9.2的素材库是其中一个办法；「明朗」是四阶段的阶段名，这一句作为经验描述保留，不预设任何后台机制。〔证1〕 |
| 10.2「散步也是创作过程的一部分」 | **一字不改保留** | 原稿在本节里最干净的句子。它不是从机制推出来的结论，它本来就成立，不需要「孵化」替它背书。〔证1〕 |
| 10.2「从今天起，把你『啊哈时刻』最常出现的场景变成固定的孵化时段，而不是等它随机发生」 | **整句撤除** | 其一，「最常出现」需要先有记录才能知道，原稿没有给任何记录办法，这句话只能让人凭感觉认定一个场景；其二，「变成固定的」假定那个场景可以固定安排，对通勤由班次决定、洗澡由照护对象决定的人不成立，这是第三章3.5与第六章6.2的同一个前提。〔证7〕 |
| 10.3「所有联想练习背后是同一个公式：新东西 = 已有的东西 A × 已有的东西 B」 | 退回算术装置 | 它能说的只有「两个东西放在一起，可能得到一个新东西」。《时间之书》第十二章对复利式子的处置同族：一道自己能按计算器验证的算术，从被读成人生定律的那一步起，就不再是算术。〔证11〕 |
| 10.3「Kleon 说得更彻底，你以为的原创，都是把 influences 重新组合 (Kleon, 2012)」 | 归属撤除，原稿夹带的英文词不照录 | 台账记明该书是大众读物、仅书目。原稿这一处夹着一个英文词，属中英混排，本书以中译转述、不照录原词。这句话降级为流传很广的编写表述，不作为任何一方的实证结论，与第六章6.7同项。〔证2〕 |
| 10.3「组合的力度取决于 A 与 B 的距离」与那张「近／中／远」表 | 「力度」「取决于」与距离分级撤除，三行退回例子 | 「力度」没有测量，「取决于」没有来源，「近／中／远」没有分级标准；第三行「远 → 白噪音专辑」把一个还没被做出来的想法写成了与拿铁并列的成果，这不符合它自己的身份。〔证11〕 |
| 10.3「想不出也没关系，拉伸的就是那根联想的肌肉」 | 前半句一字不改保留，比喻撤除 | 肌肉比喻把一个未取证的训练效果写成了生理事实：联想没有可以被增大的肌纤维，本书也没有材料说明反复配对会改变什么。前半句与全书口径一致：想不出不是失败。〔证1〕 |
| 10.4五个假设句式 | 保留为编写建议，依据改由第六章6.5承担，本章不重复那一段 | 第六章6.5已写明做法、停止条件与依据处置：原稿以Mednick（1962）支持这一动作，本轮未取得该文原文，不作为已证机制引用；保留动作的理由可自查。第五句与6.5「给一个八岁的人做」同形，不另列。〔证12〕 |
| 10.4「每天挑一个你正在想的问题」 | 「每天」撤除 | 导航页约定一：每章只建议一个最小行动。把一个句式变成每日任务，是原稿自己的加码。想用的时候用，不想用就不用。〔证4〕 |
| 10.4「荒谬是联想热身时的正常现象，先求多，后求好。判断留给验证阶段」 | **一字不改保留** | 原稿在本章里最干净的一句：它不承诺结果，只描述练习时会发生什么，并把判断推到它该在的位置。第六章6.5的停止条件与它同向。〔证1〕 |
| 10.5「连轴转的大脑没有后台进程，孵化无从发生」 | **整句撤除** | 「后台进程」是计算机隐喻，本章已不保留任何机制陈述，隐喻不能替它作担保；「没有空隙就没有想象」是排除性定律，建立它需要同时测量空隙与想象产出的研究，本轮一份也没有。〔证10〕 |
| 10.5「碎片化的注意力连『捧住一个问题』都做不到」 | 全称断言撤除，改程度描述并指回第二章 | 第二章2.4讲的是处境对注意力的影响；「连……都做不到」把「变难」写成了「不可能」。改后的版本：注意力被切成碎片的时候，捧住一个问题会变难。〔证10〕 |
| 10.5「每天留出一段『无输入、无屏幕、无任务』的空隙，哪怕 15 分钟」 | 前提补上，「哪怕 15 分钟」撤除 | 原稿漏了「空隙从哪里来」这一问：先问空隙在谁手里，再谈怎么用，与第三章3.5、第六章6.2同项。本书不给任何时长的规定，有空隙的人不需要被告知要多久，没空隙的人给了数字也用不上。〔证7〕 |

## 10.3 远距离联想：一个构念名，不是一条定律

**先说构念名。「远距离联想」这个说法可以保留。** 台账能确认的只有一件事：这个名称与Mednick（1962）相关，属于一个把创造过程与联想距离联系起来的理论传统。本轮仅取得书目与二手转述，未核读原文，因此本书不写卷期页码，不写「创造力就是形成远距离联想的能力」这一定义句，也不写「距离越远，组合出的东西越新」这条定量关系。构念名归属**高**，其余一律**未核实**。〔证2〕

这与附录术语表的裁定一致。术语表「远距离联想」条写的是：「从相距很远的事物间建立连接。这是描述，不是可以打分的指标。」本章全文遵守这一句：它是描述，不是指标，不提供测量，也不提供把你自己放到这根轴上某个位置的办法。〔证2〕

**「普通人／创造者」的分法整句撤除。** 原稿用它引入定义，代价是把一个研究取向的构念写成了人群分类：一边是「普通人」，一边是「创造者」，中间没有过渡。这一分法没有分母，没有来源，也没有任何把一个真实的人归入某一类的操作办法。更要紧的是它悄悄改写了问题的归属：「想不出来」从此不再是处境问题（你的时间、你的授权、你的环境），而是类别问题（你属于哪一类）。这与第六章6.2的前提相反，本书不采用。〔证2〕

**那组例子留下，身份降级。** 盐与咸、盐与雪花、盐与泪，这一串可以作为联想距离的示意。示意的作用是让「远近」这个词有画面，它不证明任何人的联想力处在哪个位置，也不证明距离与新颖之间有可以依赖的数量关系。〔证1〕

这一节删掉的东西，比留下的多。删掉之后还站着的只有两句：库里门类多的时候，能配对的东西多，这是算术；想不出来的时候，先看看是处境、疲惫还是没有材料，再决定要不要怪自己的联想力。〔证1〕

## 10.4 孵化：本书的编排用语

**先照录裁定。** 「放一放，想法会自己冒出来」这类说法，在本书没有取得可核验的一手材料，不作为已证机制引用。这句话在书内与跨书已有三处同项裁定：[第五章](Ch05_创造审计.md)5.4、[附录](Appendix_Quick_Reference.md)对「孵化效应」条目的移出、《时间之书》[第十一章](../bot/Ch11_耐心与等待.md)11.5。本章沿用，做法还在，机制解释不给。〔证9〕

**原稿那一整句因此拆开处置。** 「放下问题，答案反而出现」的前半句是经验描述，可以保留——放下之后有时有答案，有时没有，本书只承诺「有时」。「这就是孵化效应」的等号撤除：一句经验描述不因为与一个术语同形，就获得了机制身份。归属也跟着改：四阶段出自Wallas（1926），那是一部1926年的思想史著作，讲的是过程顺序，不是实验结论，书内出处见第一章1.4与附录术语表「四阶段」条；「大脑在后台继续做远距离检索」是一句机制陈述，本轮没有任何材料支持它，整句撤除。〔证8〕

**三条使用要点，逐条处置如下。**

要点一「孵化前必须先有准备」，顺序保留，定性撤除。先啃过问题再放下，这个顺序本身有用：它防止把「搁置」变成一直没有开始的另一个名字。但「那叫放弃，不叫酝酿」这半句撤除——它把一个顺序建议写成了品行判定，而过程顺序不能用来指控一个人此刻的放下是品行问题，第三章3.3对同一族问题已有裁定。放下不构成品行问题，放下也不保证有结果。〔证8〕

要点二「选低刺激活动」，保留；「散步、洗澡、洗碗是理想孵化器」的「理想的」撤除——最高级没有比较对象也没有来源，第三章3.3同项。能说的是：低刺激、无任务的活动里，有时会有想法冒出来。〔证9〕

要点二的后半句「刷短视频是孵化杀手，因为新刺激会不断劫持后台」整句撤除。两层问题。其一，「劫持后台」把一个本章已经撤除的机制当成了事实来解释；其二，「是杀手」是一个没有分母的全称断言。能留下的只有弱得多的一句：刷短视频的时候，新内容一个接一个，想法通常没有机会接上——这是很多人报告过的经验，不是定律，也不是因果证明。本书不把「少刷手机」写成一条创造力处方；如果刷本身停不下来并且影响生活，那是另一件事，去处见10.1的分诊表。〔证10〕

要点三「随身带捕获工具」，保留。想法常常出现在没有纸笔的地方，这一句作为经验描述留下；有地方放东西确实有用，[第九章](Ch09_感知与输入.md)9.2的素材库是其中一个办法，术语表对它的界定照录：是否需要它，取决于你有没有地方放东西。〔证1〕

**「散步也是创作过程的一部分」一字不改保留。** 这是原稿在这一节里最干净的一句。它不是从机制推出来的结论，它本来就成立，不需要「孵化」替它背书。〔证1〕

**「从今天起，把你的『啊哈时刻』最常出现的场景变成固定的孵化时段」整句撤除。** 两层理由。其一，「最常出现」需要先有记录才能知道，而本章不新增记录制度（10.8），原稿也没有提供任何记录办法——没有记录，这句话就只是让你凭感觉认定一个场景。其二，「变成固定的」假定那个场景可以固定安排，对通勤由班次决定、洗澡由照护对象决定的人不成立，这是第三章3.5与第六章6.2的同一个前提。〔证7〕

## 10.5 组合公式：一个算术装置，不是一条关系

**「新东西 = 已有的东西 A × 已有的东西 B」退回算术装置。** 它能说的是：两个东西放在一起，可能得到一个新东西。它不能说的是：创造可以按乘法计算，新东西与旧东西之间存在可测的比例，或者力度随距离增减。《时间之书》[第十二章](../bot/Ch12_复利与积累.md)12.2对复利式子作过同族处置：一道自己可以按计算器验证的算术，从被读成人生定律的那一步开始，就不是算术了。本章的处置与它相同。〔证11〕

**「联想力 = 库的广度 × 连接的练习」整个公式撤除。** 乘法装置在本书已有明确裁定：附录术语表移出了「四维模型＝感知力×想象力×执行力×分享力」那条，理由是四个观察角度不是可以相乘的分数；[第五章](Ch05_创造审计.md)5.2对十二题打分表的处置同项。两个量（库的广度、连接的练习）都没有测量办法，它们的乘积更没有。〔证3〕

**「跨领域的人容易出新」方向保留，「天然」撤除，「碰撞半径」撤除。** 方向可以自查：库里门类多的时候，能配对的东西多；库里只有工作文档，配对就只能在工作的范围里打转。这是算术，不是心理学——它说的是组合的可能数量，不是你的能力。「领域之间的距离天然是远的」这句里，「天然」属于「自动」家族：一个不需要条件就成立的过程被写成了世界的性质，第三章3.4与《时间之书》第十二章对这一族已有同项处置。「碰撞半径」这个物理比喻撤除，它让上面那条算术看起来像一条被测过的定律。〔证1〕

**那张距离表退回例子。** 「组合的力度取决于 A 与 B 的距离」里，「力度」没有测量，「取决于」没有来源，「近／中／远」的分级没有标准。三行内容保留，作为配对的三个样子，不再承担任何关于距离的论证。〔证11〕

| 两个东西 | 放在一起能得到什么 |
|---|---|
| 咖啡、牛奶 | 拿铁，早就有了 |
| 咖啡、便签 | 咖啡渍纹理的设计，有人做过 |
| 咖啡、地铁报站 | 用报站节奏做的白噪音，能不能成立要做了才知道 |

三行都改成了中性表述：第一行是既成事实，第二行是有人做过的东西，第三行只是一个想法。原稿的「远 → 白噪音专辑」把第三行写成了与前两行并列的成果，这不符合它自己的身份——它还没被做出来。〔证11〕

**「拉伸的就是那根联想的肌肉」撤除，「想不出也没关系」一字不改保留。** 肌肉比喻把一个未取证的训练效果写成了生理事实：联想没有可以被增大的肌纤维，本书也没有任何材料说明反复配对会改变什么。前半句留下，它与全书口径一致——想不出不是失败，跳过也不构成失败。〔证1〕

## 10.6 假设句式：与第六章6.5去重之后还剩什么

**动作以第六章为准，本章不重复。** [第六章](Ch06_创造急救箱.md)6.5已经写明做法（把你的问题装进一个假设句式，写三个答案，荒谬也算数）与停止条件（三个答案写完就停，不要当场评判哪一个可用）。它对依据的处置也照录于此：原稿以Mednick（1962）的远距联想理论支持这一动作，本轮未取得该文原文，不作为已证机制引用；保留动作的理由可自查——它绕开了「什么是好答案」这个此刻无法回答的问题，把任务换成「写三个答案」，而后者可以做。〔证12〕

**原稿多出的四个句式保留为编写建议，不附加任何机制解释。**

- 如果倒过来会怎样？（顾客找服务员 → 服务员找顾客）
- 如果放大或缩小一百倍会怎样？（一天写一行 → 一行写一天）
- 如果换一个完全不同的领域来做会怎样？（医院怎么借鉴航空业的核对清单）
- 如果去掉最贵的那个环节会怎样？

原稿第五句「如果必须让小孩子也能用会怎样」与第六章6.5的「如果是给一个八岁的人做会怎样」同形，不另列。四个例子保留：它们各自是一个现成的换向示范，不需要「远距离联想」作担保。〔证12〕

**「每天挑一个你正在想的问题」的「每天」撤除。** 每章只建议一个最小行动，这是导航页约定一；把一个句式变成每日任务，是原稿自己的加码。想用的时候用，不想用就不用。〔证4〕

**「荒谬是联想热身时的正常现象，先求多，后求好。判断留给验证阶段，见[第十一章](Ch11_执行与完成.md)」一字不改保留。** 这是原稿在本章里最干净的一句：它不承诺结果，只描述练习时会发生什么，并把判断推到它该在的位置。第六章6.5的停止条件与它同向。〔证1〕

## 10.7 空隙：这一节的前提是安排权

**先补原稿漏掉的前提。** 原稿说「每天留出一段『无输入、无屏幕、无任务』的空隙，哪怕 15 分钟」，直接跳到了做法。这段空隙从哪里来，原稿没有问。对日程由自己排的人，这是一句可用的提醒；对工时、通勤、照护、第二份工作占满一天的人，这是一句做不到的指令——写下来只是多一条做不到。与第三章3.5、第六章6.2同项：先问空隙在谁手里，再谈怎么用。「哪怕 15 分钟」这个数字一并撤除：本书不给任何时长的规定，有空隙的人不需要被告知要多久，没空隙的人给了数字也用不上。〔证7〕

**「连轴转的大脑没有后台进程，孵化无从发生」整句撤除。** 两层问题。其一，「后台进程」是计算机隐喻，本章已经不保留任何机制陈述，隐喻不能替它作担保；其二，这是一个排除性定律——「没有空隙就没有想象」——建立它需要同时测量空隙与想象产出的研究，本轮一份也没有。能留下的只有弱得多的版本：忙到没有空隙的时候，连不起来不是你的联想力问题。〔证10〕

**「碎片化的注意力连『捧住一个问题』都做不到」改为程度描述，并指回第二章。** [第二章](Ch02_创造去哪儿了.md)2.4把注意力碎片化列为埋葬者之一，讲的是处境对注意力的影响；原稿这一句把「捧住一个问题」写成了不可能的事，全称断言撤除。改后的版本：注意力被切成碎片的时候，捧住一个问题会变难——难，不是不可能。〔证10〕

**林澄的那三个月，这一节对她说的是另一句话。**〔证14〕她同时带着两个项目，每天可支配的整块时间是早上通勤前的二十分钟，而那二十分钟还要用于当天最要紧的一件事。原稿开给她的方子是每天一段空隙、外加一次约十分钟的十连——两样都出在她没有的那本账上。她的问题不是联想力不够，是空隙不在她手里。对这样的人，本章能说的只有：有空隙的时候，不必让它变成什么；没空隙的时候，不补课，也不把它记成欠账。

**「它看起来最像浪费时间，实际上是想象力的工作时间」降为编写立场。** 「实际上是」把一个功能认定写成了事实判定，本书没有测量空隙期间发生了什么的任何办法。保留下来的方向是原稿同句的前一半：不因为「没在产出」而自责。这一立场与「散步也是创作过程的一部分」同向，它不需要机制，也不提供机制。〔证1〕

## 10.8 一次可选的配对（不是十连作业）

**原稿的十连整项降级。** 取十个名词、两两接龙、约十分钟、回头选出最荒谬的和最可用的各写一句展开——这套流程撤掉四个部件：个数（十个）、时长（约十分钟）、指定动作（两两接龙）与指定产出（各写一句展开）。撤除理由与《时间之书》第三章3.6对那份五天精力打分作业的处置同项：本书的练习不设个数、不设时长、不指定产出；「回头选出」还把评判编进了练习内部，与第六章6.5的停止条件相反。〔证13〕

剩下的是这一件，做不做都算读过了这一节：

**在接下来几天里，如果你偶然想把两件不相干的东西放在一起，可以放一下，看看会出来什么。** 不必取十个，不必接龙，不必计时，不必写一句话展开。放出来的是废的，这符合预期——[第六章](Ch06_创造急救箱.md)6.7的停止条件照录于此：配对练习写出来的东西大多数是废的，留一条有用的就够。〔证12〕

三条规则：

- **配对不是考试。** 放出来什么就是什么，它不构成对你的联想力的测量——术语表那一行写明，这不是可以打分的指标。〔证2〕
- **不解读。** 配出来的东西不拿去推断你的心理状态、你的潜力或者你的阶段，本章不做任何这类推断。〔证1〕

## 本章速记

- 原稿三处引用全部降级：Mednick（1962）只保留「远距离联想」构念名及归属，Kleon（2012）的归属撤除（大众读物承担不了「组合力度取决于距离」），Wallas（1926）只作为四阶段的过程顺序出处。
- 「创造力就是形成远距离联想的能力」与「距离越远，组合出的东西越新」撤除；「远距离联想」是描述，不是可以打分的指标。
- 「普通人从盐想到咸，创造者能从盐想到雪花」的人群分型撤除；想不出来可以是处境、疲惫或没有材料，本章不下结论。
- 「孵化」是编排用语，不是已证机制；第五章5.4、附录与《时间之书》第十一章11.5三处已有同项裁定，本章沿用，能说的只有「有时会」。
- 「大脑在后台继续做远距离检索」「刷短视频是孵化杀手」「连轴转的大脑没有后台进程」三句机制陈述全部撤除；留下的经验描述只有一句：低刺激、无任务的时候，有时会有想法冒出来。
- 「那叫放弃，不叫酝酿」撤除：放下不构成品行问题，放下也不保证有结果。
- 两个公式（联想力＝库的广度×连接的练习；新东西＝A×B）撤除或退回算术装置；「碰撞半径」「联想的肌肉」两个比喻撤除。
- 假设句式的做法与停止条件以第六章6.5为准，本章只留四个原稿多出的句式；「每天挑一个问题」的「每天」撤除。
- 「荒谬是联想热身时的正常现象，先求多，后求好。判断留给验证阶段」一字不改保留。
- 「散步也是创作过程的一部分」一字不改保留。
- 「固定的孵化时段」撤除：最常出现的场景需要记录才知道，「固定」假定场景可以安排。
- 空隙一节补上安排权前提：先问空隙在谁手里，再谈怎么用；「哪怕 15 分钟」撤除。
- 随机联想十连降级为一次可选配对：不设个数、不设时长、不指定产出、不计分；「连续做一周……那就对了」的群体预测撤除。
- 本章不新增记录制度；附录两页可选记录之外，本章的配对不写进任何一张表。
