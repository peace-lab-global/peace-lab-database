# 附录 · 随身卡与练习记录

本附录分为短卡、导航、术语和记录页。只需要随身提示时，可以仅保存下面的「随身卡」，不必把整页打印。各表格是Sonus为本书制作的使用工具，不是量表，也不是经验证的治疗方案。〔证1〕

**这一版撤除了原稿的四样东西**：六型意义缺失模式速查表，其中「存在型」一行把一种可能需要评估的情形做成了可以自我认领的类型；术语表里「澄清力 × 叙事力 × 超越力 × 日常力」那条相乘公式；术语表里八条把未核实的机制或价值预设写成事实的条目；以及一份未经核验的推荐书单。撤除理由见[第五章](Ch05_意义审计.md)5.1与5.2、[第一章](Ch01_意义是什么.md)1.3与本章〔证7〕。

## 随身卡：此刻先做什么

> **先看安全。** 有伤害自己的念头，或觉得活着没意思到不想活，立即求助。中国大陆全国统一心理援助热线为12356，或直接前往最近的急诊；涉及暴力或人身危险拨110；突发胸痛、呼吸困难、晕厥拨120。这一条优先于本附录其余全部内容。12356提供心理支持与危机干预，不替代120；政策要求每日不少于十八小时，不等于全国24小时，实时可用性本书未经拨测，占线时改拨当地精神卫生中心电话。〔证2〕
>
> **持续两周以上情绪低落，对几乎所有事都提不起兴趣**，伴睡眠或食欲改变，先做精神科或临床心理科评估。空虚可以是抑郁的核心表现，不是意义技巧能处理的。这条界线不该由你自己划，见[第二十二章](Ch22_意义的阴影与求助.md)22.2与22.3。〔证2〕
>
> **丧亲、失恋、失业、确诊重病之后的空是哀伤。** 它不需要被「找回」，需要被陪着走完，见[第十八章](Ch18_苦难与意义.md)。〔证3〕
>
> **长期超时工作、没有休息、没有自主权之后的空，更像职业倦怠。** 世界卫生组织把它列为一种职业现象，不是医疗疾病分类，且限于职业情境。这同时意味着两件事：它确实与工作条件有关，而且不能凭「发生在职业情境里」就排除抑郁或躯体疾病。要处理的是交付量与自主权，不是更多的意义解释，见[第六章](Ch06_意义急救箱.md)6.1与[第十二章](Ch12_工作重构.md)。〔证4〕
>
> **先过前置判断，再谈动作。** 如果空虚来自你无法认同的处境——被安排在与自己价值无关的工作上、长期没有自主权、照护没有支援、被要求做违心的事——本书不把「找回意义」写成继续承受不合理处境、伤害或不平等的义务。三步判断见[第六章](Ch06_意义急救箱.md)6.2。〔证5〕
>
> **已排除以上情形时，可以试一个动作。** 七个里挑一个就够，做完就停；不累计次数，不设完成标准，也不承诺见效。〔证5〕
>
> **可以停，也可以求助。** 任何一项让你更难受就跳过它，本章没有任何一项是必须的。困扰严重、持续或影响生活时可以主动求助，不必先练满两周。〔证5〕

这张卡不承诺几分钟内见效，不要求把七个动作做完。各动作的做法、调整与停止条件见[第六章](Ch06_意义急救箱.md)，进一步求助说明见[第二十二章](Ch22_意义的阴影与求助.md)。〔证5〕

**这一版从术语表里删掉了八条**，因为它们把未核实的机制或价值预设写成了事实：「四维模型」的相乘公式（现实中不存在可相乘的意义单位，也没有来源）；「超越力」（第三维已改名为「连接」，且「没有信仰」不计为缺失）；「敬畏」那条「广大之物 + 图式更新 → 小我效应」（所据大众著作本轮仅书目，未核读）；「心流」原写法里的操作性推论；「自我超越」那条「意义总是指向自身之外」（价值预设）；「意义应对」那条「事件不能改，解释可以重建」（它容易变成继续承受不合理处境的要求，与本书的伦理红线冲突）；「存在空虚」那条「意义供给松动后的结构性空位」（无来源的因果断言）；以及「工作重构三杠杆」（所据材料本轮未核读）。删掉不等于这些说法在别处不成立，只等于本书这一轮没有为它们取证。〔证7〕

**这一页有禁忌。** 如果「整理自己的空虚」让你开始反复追问「我到底为什么活着」并且更难受，不要使用这一页，改为休息或请人陪伴，不必填完。表格空着也可以。如果事情涉及安全、医疗或有时限的权益，记录不能延误实际求助与行动。〔证2〕〔证8〕

## 记录页二：留下、换掉、交给支持

此表不评价人格、症状严重度或练习成绩，也不要求每日填写。**中断时可以重选，不补做；没有帮助时可以换法或停止。** 不要把漏做和方法无效混为一谈。〔证8〕

|---|---|
| 我目前希望回应的一个需要 | |
| 一个有帮助而且愿意继续的做法 | |
| 若只是中断，我愿意从哪里重新选起 | |
| 若没有帮助，我想暂停或更换什么 | |
| 我目前无法改变、只能承认代价的一件处境 | |
| 我为那件处境设定的复查日期或退出条件 | |
| 需要他人共同改变的条件 | |
| 可以联系的人或专业资源 | |
| 明显恶化时，我准备去哪里获得帮助 | |

**明显恶化时，停止相关练习并及时获得专业评估。** 「承认我现在走不了，而且这不值得」比「我要在其中找到意义」更接近事实；把承受重新命名为意义，只是给同一副担子换个说法。〔证5〕

## 阅读来源的三个提示

**看主张，而不只看书名。** 引用一项研究，必须看它是否研究了相同的人群、方法与结果。一本回忆录不能承担相关性主张，一门数周课程不能证明本书的单个动作有同等效果。〔证6〕

**看标注的性质。** 「理论模型」提供理解角度，「原典」说明思想出处，「Sonus编写建议」说明本书作了怎样的取舍，它们都不自动等于经验证疗效。〔证6〕

**看未完成的核验。** 台账说明实际获得了全文、摘要还是出版介绍。注明「仅书目」或「未核实」的材料不能承担操作建议的事实基础。〔证6〕

完整说明见[来源与可信度](../EVIDENCE_GUIDE.md)，原始入口分别见[科学与临床来源](../SOURCES_SCIENCE.md)与[心理实践来源](../SOURCES_PRACTICE.md)。
