# 身体之书 (Book of Body)

> 现代职场人的身体重建指南。
> 一句话总纲：**身体不是工具，是家。如何与身体相处，是可以被理解、被练习、被系统化重建的能力。**

---

## 这本书是什么

本书是 Peace Lab Database（平静实验室知识库）的总纲与入口之一。它与[《平静之书》](../bop/INDEX.md)、[《力量之书》](../bos/INDEX.md)、[《孤独之书》](../bol/INDEX.md)互为姊妹篇：

- 平静之书回答"如何在风浪中站稳"：安定、恢复、守；
- 力量之书回答"站稳之后如何前进"：承受、行动、影响、攻；
- 孤独之书回答"一个人时怎么办"：理解、独处、连接、化；
- 身体之书回答"如何与自己最基本的现实相处"：感知、接纳、养护、表达。

四本书的关系：
```
平静（内在稳定）→ 力量（外在行动）→ 孤独（人与人的关系）→ 身体（人与己的容器）
```

你只有一副身体，且从出生到死亡从未离场。它同时是感知世界的器官、情绪发生的现场、生活被执行的载体。现代人常把它用成"通勤工具"：透支、久坐、屏幕化，直到它以疲惫与疼痛说话。本书不承诺"四周完美身材"，而是教你重新听见身体、与它和解、把它养好、让它表达。

## 身体四维模型（全书的坐标系）

本书把「与身体相处」拆成四个可以分开来看的维度：

```
┌─────────────────────────────────────────────┐
│  感知  ← 听见：身体的信号（饿、困、紧、痛）    │
│  接纳  ← 和解：与不完美、变化中的身体共处      │
│  养护  ← 供养：睡眠、运动、营养与恢复          │
│  表达  ← 说出：用呼吸、动作、声音表达自己      │
└─────────────────────────────────────────────┘
```

四维是四个观察角度，不是四个可以相乘的分数，也不是四种人格。它们用来分辨此刻值得先做哪一件小事，不用来给身体打分——**「哪一维最低」既不能诊断，也不等于「你的身体力有多差」**。[第 5 章](Ch05_身体审计.md)会说明这一点，并先把需要就医的情形排在自我观察之前。

## 三种读法

### 急救模式（此刻身体很难受）
你现在正处在紧张、疼痛、麻木、分离或莫名不适里，直接去：

- [第 6 章：身体急救箱](Ch06_身体急救箱.md)：六个可选的分钟级动作，附 6.1 就医分诊
- [第 7 章：身体场景剧本](Ch07_身体场景剧本.md)：按你此刻的状态查找对应剧本
- [第 8 章：疲惫与疼痛的身体](Ch08_疲惫与疼痛的身体.md)：两种最响的信号怎么读、何时就医

### 观察模式（我想知道我与身体的关系怎么了）
- [第 5 章：身体审计](Ch05_身体审计.md)：不计分的四维观察提示 + 六种常见的失联情形，先划就医边界，再选阅读入口

### 系统模式（我想重建与身体的关系）
按顺序通读全书，跟着[第 23 章：28 天身体重建](Ch23_28_天身体重建.md)落地（每天一个十分钟内动作），最终产出你自己的[个人身体系统](Ch21_个人身体系统.md)。

## 使用本书的三条约定

1. **每章只建议一个最小行动。** 每章末尾的练习都是可选的；跳过不等于没读，也不构成失败。原稿写过「读完不做，等于没读」，本书撤除这句话——它把一本用来陪伴的书变成了一次考核。
2. **本书是地图，不是领土。** 每章末尾的「深潜」通向知识库对应专题的完整文档。本书不教你「获得完美身材」，讲的是听见、接纳、养护、表达，从不完美开始。
3. **不把自我调节写成忍受的义务。** 若你的疲惫来自工时超限、无法转移的照护责任、排班不由自己定，那是处境，不是你不重视身体。本书的回应是先分清状态问题与处境问题（[第 5 章](Ch05_身体审计.md)5.2第三种），再谈身体边界与拒绝（[第 20 章](Ch20_身体的伦理.md)20.4），而不是更多练习。
