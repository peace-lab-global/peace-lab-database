# 身体之书 (Book of Body)

> 现代职场人的身体重建指南。
> 一句话总纲：**身体不是工具，是家。如何与身体相处，是可以被理解、被练习、被系统化重建的能力。**

---

## 这本书是什么

本书是 Peace Lab Database（平静实验室知识库）的总纲与入口之一。它与[《平静之书》](../bop/INDEX.md)、[《力量之书》](../bos/INDEX.md)、[《孤独之书》](../bol/INDEX.md)互为姊妹篇：

- 平静之书回答"如何在风浪中站稳"：安定、恢复、守；
- 力量之书回答"站稳之后如何前进"：承受、行动、影响、攻；
- 孤独之书回答"一个人时怎么办"：理解、独处、连接、化；
- 身体之书回答"如何与自己最基本的现实相处"：感知、接纳、养护、表达。

四本书的关系：
```
平静（内在稳定）→ 力量（外在行动）→ 孤独（人与人的关系）→ 身体（人与己的容器）
```

你只有一副身体，且从出生到死亡从未离场。它同时是感知世界的器官、情绪发生的现场、生活被执行的载体。现代人常把它用成"通勤工具"：透支、久坐、屏幕化，直到它以疲惫与疼痛说话。本书不承诺"四周完美身材"，而是教你重新听见身体、与它和解、把它养好、让它表达。

---

## 身体四维模型（全书的坐标系）

本书把"与身体相处"拆成四个可理解、可练习、可评估的维度：

```
身体力 = 感知力 × 接纳力 × 养护力 × 表达力

┌─────────────────────────────────────────────┐
│  感知力  ← 听见：身体的信号（饿、困、紧、痛）  │
│  接纳力  ← 和解：与不完美、变化中的身体共处    │
│  养护力  ← 供养：睡眠、运动、营养与恢复        │
│  表达力  ← 说出：用呼吸、动作、声音表达自己    │
└─────────────────────────────────────────────┘
```

四个维度相乘：**任何一维趋近于零，与身体的关系就会出问题**。听不见信号的人无从养护（麻木）；不肯接纳的人无心养护（羞耻）；只养护不表达的身体会积累张力（静音）；只表达不养护的身体是透支的喇叭（宣泄）。

## 使用本书的两条约定

1. 每章只要求一个最小行动。读完不做，等于没读。
2. 身体是伙伴，不是敌人。本书不教你"获得完美身材"，而是教你"听见、接纳、养护、表达"，从不完美开始。
