## ⚡ 急救卡（今天就能用）

**第一步永远是：先安抚身体，再处理事情。**

| 状况 | 动作 | 章节 |
|:--|:--|:--|
| 紧张上头 | 延长呼气 ×6 + 双脚踩实 | [Ch06](Ch06_身体急救箱.md)②③ |
| 疲惫袭来 | 休息 10 分钟 + 喝水进食 | Ch06⑧⑨ |
| 疼痛打扰 | 允许 + 定位描述 + 分流 | Ch06⑩① + Ch08 |
| 麻木无感 | 起身活动 5 分钟 + 快速扫描 | Ch06⑤① |
| 感觉分离 | 着地三触点 + 五感着地 | Ch06③ + Ch14 |
| 孤独想被碰 | 自我拥抱 30 秒 + 哼一首歌 | Ch06⑥⑦ |
| 莫名不适 | 允许 + 养护四件套（水/食/休/通风） | Ch06⑩⑧⑨ |
| 睡不着 | 调暗 + 身体扫描快速版 | Ch06①⑧ + Ch11 |

**通用话术**："我的身体现在需要____。"（说出来，注意力就回到了身体）

## 📅 一周最小计划（读完本书先做这个）

每天 ≤10 分钟，做完即勾选：

| 天 | 动作 |
|:--|:--|
| 一 | 四维打分（感知/接纳/养护/表达各 1–10） |
| 二 | 快速身体扫描 3 分钟 |
| 三 | 20 分钟中等强度活动（快走即可） |
| 四 | 睡前身体日记一行 + 一句身体感谢 |
| 五 | 三次延长呼气 + 镜前三句话 |
| 六 | 一首歌的自由舞动或认真洗个热水澡 |
| 日 | 周审计 5 分钟：四维打分，最低维下周加码 |

觉得可行 → 升级为 [Ch23 的 28 天计划](Ch23_28_天身体重建.md) → 稳定后交给 [Ch21 的个人系统](Ch21_个人身体系统.md)。
