# 第二十二章 · 身体的阴影与求助

> 本书教的所有自我调节都有边界。承认边界是对身体的诚实，不是失败。有些信号属于医生，有些痛苦属于专业人士，求助本身就是身体养护的一部分。

---

## 22.1 身体的阴影区

四个常被误解、需要认真对待的区域：

| 区域 | 它是什么 | 常见误解 |
|:--|:--|:--|
| 躯体化 | 心理痛苦以身体症状表达，真实的难受，检查却常无对应病变 | "没查出问题 = 装病/想多了" |
| 慢性疼痛 | 持续数月的疼痛，警报系统可能卡在报警模式 | "忍着"或"只查片子" |
| 进食障碍 | 与食物和体重的关系失调（节食失控、暴食、催吐等） | "只是意志力问题" |
| 身体意象障碍 | 对外貌的负面关注强烈到影响生活 | "爱美之心人皆有之" |

这些区域的共同点是：不是"想开点"就能解决，通常同时需要医学评估与心理支持。

---

## 22.2 求助信号：三级分诊

**第一级：可以先用本书自我调节**

- 压力相关的紧绷、轻度睡眠问题、情绪波动；
- 症状与压力周期明显相关，且不影响基本生活。

**第二级：请尽快就医（先排除身体疾病）**

- 症状持续超过两周不缓解，或持续加重；
- 新出现的疼痛、明显体重变化、长期失眠；
- 与食物的关系开始失控（反复催吐、极端节食、暴食）；
- 对身体的担忧已经影响工作、社交或情绪的日常运转。

**第三级：请立即求助（不要等待）**

- 自伤或伤害自己的念头；
- 进食障碍伴随脱水、晕厥、电解质问题信号；
- 闪回、解离反复出现，无法完成日常功能。

> 🧭 **自问**：你身上有没有一个"拖了很久、总说再看看"的症状？它属于第几级？

---

## 22.3 转介路径：向谁求助

```
第一步：全科/内科医生
  → 排除器质性问题，获得转诊建议
第二步：相关专科（疼痛科 / 消化科 / 妇科 / 内分泌科…）
第三步：心理与精神科
  → 心理治疗（躯体化、进食障碍、身体意象的核心手段之一）
  → 精神科评估（必要时药物）
第四步：危机资源（第三级信号，或任何"撑不住"的时刻）
  → [危机资源清单](../../规范/CRISIS_RESOURCES.md)
```

实用提示：就诊前把症状写下来，包括什么时候开始、什么加重、什么缓解、伴随什么情绪事件。这份清单能让医生更快帮到你。

---

## 22.4 求助不是失败

关于求助，三个需要说出口的事实：

1. 求助是能力，不是弱点：识别"这超出我的工具箱"本身就是高水平的自我评估；
2. 身心不是二选一：躯体化与慢性疼痛的痛苦是真实的，心理治疗不是"暗示你没病"，而是针对疼痛与情绪交互机制的有效干预（van der Kolk, 2014）；
3. 进食与身体意象问题越早介入越好：它们有成熟的循证治疗路径，拖延会让恢复更难（Cash, 2008）。

---

## 22.5 练习：我的求助预案

现在花五分钟，写下你的预案（希望永远用不上）：

```
1. 若身体症状持续两周不缓解 → 我会预约：____（医生/医院）
2. 若情绪或与食物的关系失控 → 我会联系：____（心理咨询/精神科）
3. 若出现"撑不住"的时刻 → 我会使用：[危机资源清单](../../规范/CRISIS_RESOURCES.md)
4. 可以陪我去的人：____
```

预案的意义：在平静时定好路线，痛苦来临时就不必独自导航。

---

## 📌 本章速记

- 阴影区四问题：躯体化、慢性疼痛、进食障碍、身体意象障碍，都不是"想开点"能解决的。
- 三级分诊：自我调节 / 尽快就医 / 立即求助，以"持续时间、加重趋势、功能影响"判断。
- 转介路径：全科 → 专科 → 心理/精神科 → 危机资源；就诊前先写症状清单。
- 求助是能力不是弱点；心理治疗针对的是真实的机制，不是"暗示你没病"。
- 平静时写好求助预案，痛苦时不必独自导航。

> ⚠️ **若症状持续或加重，请及时就医；心理危机请见[危机资源](../../规范/CRISIS_RESOURCES.md)。**
