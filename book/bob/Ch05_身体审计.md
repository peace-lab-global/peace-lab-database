# 第五章 · 身体审计

> 上一部你了解了身体，这一部回答一个更具体的问题：你与身体的关系，卡在哪里？
> 这一章不计分，也不给你定一个型。它审计的对象是处境与选择，不是你的身体好不好，更不是你这个人行不行。读完你会得到一份只属于你的阅读路线，以及一条更重要的东西：哪些情形不该由这一章处理。

---

## 5.1 四维自我观察

下面四组是**观察提示，不是量表**。它们不计分、不设阈值、不作类型划分，也不承担诊断或疗效测量——本书没有对它们做过任何验证。用法是：读一遍，看哪几条让你停下来，然后去对应的章节。命中几条不说明任何问题，让你停下来的那一条才有信息量。〔证1〕

**先做两件事，再往下读。**

第一件，**排除需要医疗的情形**。以下任何一项，都不属于本章的处理范围：新发的或性质改变的疼痛；不明原因的体重变化；持续两周以上的失眠、早醒或嗜睡；月经、排尿、排便的明显改变；已经影响吃饭、走路、呼吸或日常自理的症状。这些需要的是检查，不是自我观察。一本讲身体自我调节的书，没有资格判断哪些症状你可以自己处理。入口见[第六章](Ch06_身体急救箱.md)6.1与[第二十二章](Ch22_身体的阴影与求助.md)22.3。〔证2〕

第二件，**排除需要评估的心理信号**。如果最近两周你有以下任何一项，请先读[第二十二章](Ch22_身体的阴影与求助.md)，不要做下面的观察：情绪低落到对平时在意的事也提不起劲；出现伤害自己的念头；对体重、体型或进食的想法已经占据大量注意力，或伴随催吐、严格限制、暴食；工作与生活功能明显下滑。这些是需要专业评估的信号，不是某一维的短板，多练感知不会让它们好转。若有立即的危险或自伤念头，中国大陆拨120或12356，涉及人身危险拨110。〔证2〕

**还有一条边界，它属于本书自己。** 如果「清点自己身体的问题」这件事本身就让你难受——它常常如此，尤其对已经有身体羞耻或进食困扰的人——那么不要做本章。这一章的形式是一张清单，而清单可以被用来做两件相反的事：辨认需要处理的事，或者收集新一轮自我批评的材料。如果你读到第二条已经开始挑剔自己，合上它，去[第十章](Ch10_身体接纳.md)或[《平静之书》第十三章](../bop/Ch13_Self_Compassion.md)。身体审计不该变成又一张缺陷表。〔证3〕

**本书的一条立场。** 下面四维里的多数条目，都可能是处境的结果而不是你的态度问题：夜班与通勤决定了你几点睡，收入与食品环境决定了你吃什么，照护责任决定了你有没有一小时可以动，评价你外貌的环境决定了你照镜子时的感受。**本书不把「感知身体」「接纳身体」「养护身体」写成在伤害你的工作条件、饮食环境与照护负担里继续自我调节的义务。** 能改的走协商与条件，不能改的走承认代价与设定复查日期，两者都不叫「你不够重视自己的身体」。〔证3〕

### 维度一：感知（听见身体的信号）

这一维里有一条和其他几条不是一类，先看它：

| 观察提示 | 它可能在说什么 | 阅读入口 |
|---|---|---|
| 我听不见饥饿、疲惫、疼痛或紧张 | 听不见有时不是能力缺失，而是一次有效的保护——在长期疼痛、创伤或高压环境里，把信号调低是能撑下去的方式。先弄清它在替你挡什么，再决定要不要调回来 | [第九章](Ch09_身体感知.md)，若有创伤史或长期疼痛，先读[第十四章](Ch14_身体与创伤.md)与[第八章](Ch08_疲惫与疼痛的身体.md) |

把它直接写成「感知力缺失」是本章要避开的错误：它会把一种曾经有用的适应，改写成一项待修复的缺陷。〔证1〕

其余四条是常见的困扰描述。它们可能来自你的注意习惯，可能来自你所处的环境，也可能来自需要医疗或心理评估的状况。本章无法区分，也不尝试区分：

| 观察提示 | 先问两件事 |
|---|---|
| 经常「忘记」吃饭、喝水、上厕所 | 一、处境是否可以改变？排班、通勤、照护、工作强度决定了你有没有条件停下来——可以→[第二十章](Ch20_身体的伦理.md)、[第十九章](Ch19_日常的身体.md) |
| 说不清自己身体现在感觉如何 | 二、是否已持续两周以上，或影响到吃饭、睡觉、上班？是→[第二十二章](Ch22_身体的阴影与求助.md) |
| 需要别人提醒才去休息 | 两问都答否，才轮到[第九章](Ch09_身体感知.md) |
| 很少把注意放在身体上 | ——顺序不要颠倒：先排除处境与需要评估的状况，再谈练习 |

内感受指大脑对身体内部状态的感知，这一构念在神经科学中有明确的研究传统；但「内感受迟钝的人也更难识别自己的情绪」这一命题，所引综述的摘要并不涉及，本轮标未核实。本章不据它给出任何训练处方。〔证4〕

### 维度二：接纳（与身体相处）

| 观察提示 | 阅读入口 |
|---|---|
| 对自己的外貌、体重或身体状况感到羞耻 | [第十章](Ch10_身体接纳.md)、[第十五章](Ch15_身体与衰老.md) |
| 经常批评自己的身体 | [第十章](Ch10_身体接纳.md)、[《平静之书》第十三章](../bop/Ch13_Self_Compassion.md) |
| 难以接受身体的变化（衰老、疾病、受伤） | [第十五章](Ch15_身体与衰老.md)、[第十七章](Ch17_疾病与身体.md) |
| 很少对自己的身体有感谢或中立的感觉 | [第十章](Ch10_身体接纳.md) |
| 照镜子或拍照时主要是回避 | [第十章](Ch10_身体接纳.md) |

这一维有一条不可绕过的分流：**如果对体重、体型或进食的想法已经占据大量注意力，或伴随催吐、严格限制、暴食、过度运动补偿，那不是接纳力不足，是需要专业评估的情形**，请直接读[第二十二章](Ch22_身体的阴影与求助.md)，不要从本章的练习开始。进食障碍的自助练习可能加重它。〔证2〕

「负面身体意象比实际外貌更影响生活」是一个流传很广的说法，其常被归引的实务手册本轮仅取得书目、未核读，本章标未核实，不据它作任何效果陈述。〔证5〕

### 维度三：养护（照顾身体）

| 观察提示 | 阅读入口 |
|---|---|
| 经常熬夜或睡眠不足 | [第十一章](Ch11_身体养护.md)、[第三章](Ch03_身体的生理学.md)3.6 |
| 久坐不动，或长期体力消耗过大 | [第十一章](Ch11_身体养护.md)、[第十九章](Ch19_日常的身体.md) |
| 饮食不规律 | [第十一章](Ch11_身体养护.md) |
| 几乎没有让自己完全关机的时段 | [第八章](Ch08_疲惫与疼痛的身体.md)、[第十九章](Ch19_日常的身体.md) |
| 把身体当成要压榨的工具 | [第二十章](Ch20_身体的伦理.md) |

这一维最容易被写成个人责任，也最需要分清处境。关于睡眠与活动量，本书引的是群体层面的一般健康建议：成人规律每晚至少七小时睡眠；每周150至300分钟中等强度有氧活动，另有至少两天力量活动，少量优于没有，疾病与残障情况须按能力调整。**这些是公共卫生推荐，不是「你今晚就该睡够七小时」的处方，也不保证任何一次改动会带来某种结果。** 轮班、通勤、照护、收入与工作强度都会决定它们对你是否可行；不可行时要处理的是条件，不是你的自律。〔证6〕

### 维度四：表达（用身体表达自己）

| 观察提示 | 阅读入口 |
|---|---|
| 很少用身体表达情绪（动作、声音、姿态） | [第十二章](Ch12_身体表达.md)、[第十三章](Ch13_身体与情绪.md) |
| 对身体表达感到羞耻或不适 | [第十二章](Ch12_身体表达.md)、[第十章](Ch10_身体接纳.md) |
| 很少与人有身体接触，或很怕被触碰 | [第十二章](Ch12_身体表达.md)、[第十八章](Ch18_身体与性.md) |
| 把身体表达当成不必要的 | [第十二章](Ch12_身体表达.md) |

这一维有一条**拒绝权**，它优先于全部条目：不喜欢用身体表达、不喜欢被触碰、不喜欢舞蹈或任何形式的身体展示，都不是缺陷，也不需要被纠正。你不欠任何练习一个拥抱，也不必接受他人的触碰来表示信任或开放。第六章把「温度与接触」写成可以完全拒绝的一项，本章沿用同一立场。涉及性的部分一律走[第十八章](Ch18_身体与性.md)，本章不处理。〔证3〕

**一个常见的错位。** 虚构的陈宁在四组观察里停下来最多的是维度一和维度三：听不见饿，也记不得上一次完整休息是什么时候。陈宁原本的结论是自己不重视身体，打算从第九章的感知练习开始，并把早睡写进日程。记录三天之后发现：陈宁每天可支配的时间是四十分钟，其中二十五分钟在通勤；吃饭时间由排班决定，不由自己决定。需要的不是更敏锐的感知，是[第二十章](Ch20_身体的伦理.md)的条件判断，以及一次关于排班的协商。这是本书的虚构情境，不是测评结果，也不代表所有人的处境都能改变。〔证7〕

## 5.2 六种常见的失联方式

四维找「哪里卡住」，这一节找「怎样卡住」。

下面是六种常见的方式，**不是六种人**。同一个人身上常常同时有几种，也可能一种都不像；这个月像第二种、下个月像第四种，都很正常。它们由Sonus整理，没有经过量表开发与验证，不用于分类，不表示严重程度，也没有「你是哪一型」的正确答案。〔证8〕

其中**后两种不是可以自己认领的类型**。它们是需要专业评估的信号。本书把它们列在这里只有一个目的：让你认出该往哪走，而不是让你给自己贴一个标签。

**一、听不见**
常见体验：身体的信号被调到很低，饿、累、疼都要到很强才注意到；常靠别人的提醒才停下来。
容易忽略的一点：这可能是保护，不是故障。在长期疼痛、创伤或高压环境里，把信号调低是能撑下去的方式。先弄清它在替你挡什么，再决定要不要调回来；调回来太快，可能一下子接到很多以前接不住的东西。
阅读入口：[第九章](Ch09_身体感知.md) → [第六章](Ch06_身体急救箱.md) → [第十九章](Ch19_日常的身体.md)。有创伤史或长期疼痛时，先读[第十四章](Ch14_身体与创伤.md)与[第八章](Ch08_疲惫与疼痛的身体.md)。

**二、只看得见缺点**
常见体验：注意力自动落在身体的某几处；照镜子主要是挑剔；批评的话很熟练。
容易忽略的一点：这些标准大多不是你自己定的，它们来自评价你外貌的环境。把它整个当成个人的心态问题来处理，等于让你一个人去对抗一整套外部标准。
阅读入口：[第十章](Ch10_身体接纳.md) → [第二十章](Ch20_身体的伦理.md) → [《平静之书》第十三章](../bop/Ch13_Self_Compassion.md)。伴随进食或体重的强迫性想法时，改走[第二十二章](Ch22_身体的阴影与求助.md)。

**三、把身体当工具**
常见体验：身体是用来完成任务的；休息要有理由，累不需要理由；「忙完这阵就好了」说了很久，「这阵」从没结束。
容易忽略的一点：这一种最常不是态度问题，而是工时、排班与照护安排的结果。先分清是状态问题还是处境问题：处境问题要处理的是条件，不是你对身体的态度。
阅读入口：[第十一章](Ch11_身体养护.md) → [第二十章](Ch20_身体的伦理.md) → [第十九章](Ch19_日常的身体.md)。

**四、盯着每一个信号**
常见体验：身体一有变化就警觉；反复检查、反复搜索、反复求证；医生的「没有问题」只能让人安心几小时。
容易忽略的一点：这不是「感知力过度」，也不是感知训练做多了。**反复担心自己患重病、反复检查身体、且这种担心已经难以自行停下，可能是需要评估的焦虑或躯体症状相关情形。** 它需要的不是更精细的自我观察，是一次评估；而把注意力长时间放在体内的练习，对这一类人常常起反作用。〔证10〕
阅读入口：[第二十二章](Ch22_身体的阴影与求助.md) → [第十七章](Ch17_疾病与身体.md) → [《平静之书》第十二章](../bop/Ch12_Cognitive_Tools.md)。

**五、觉得这不是我的身体**
常见体验：身体像一件在远处的东西；照镜子时觉得陌生；有「我只是在住在这个身体里」的感觉。
容易忽略的一点：**这一种不能自己认领，也不能靠练习处理。** 持续或反复的不真实感、与身体或环境分离的感觉，可能是需要评估的解离相关情形，也可能与创伤、严重睡眠不足、物质使用或某些躯体疾病有关。它同时意味着一件很具体的事：身体扫描、把注意力长时间放在体内、以及任何要求你「回到身体里」的练习，都可能让这种感觉加重。第六章 6.4 为此保留了出口——把注意力放到身体之外，或什么也不做。〔证10〕
阅读入口：[第二十二章](Ch22_身体的阴影与求助.md)。不要从[第九章](Ch09_身体感知.md)开始。

**六、身体在某些时刻回到过去**
常见体验：某些触碰、气味、声音或场景会引发远超当下情形的反应；身体长期紧绷、疼痛或麻木，查不出对应的原因。
容易忽略的一点：**创伤不能自我诊断，本书也不提供创伤的自助路径。** 「身体记得创伤」是一本书的书名与一种影响很大的表述，它出自临床著作而非对照研究，本轮未取得该领域的系统评价，本书不把它当作已证的生理机制陈述。〔证9〕可以确认的只有两件事：创伤相关的躯体反应是真实存在的困扰；它需要的是受过训练的专业人员，不是一份阅读路线。
阅读入口：[第二十二章](Ch22_身体的阴影与求助.md)，以及[第十四章](Ch14_身体与创伤.md)——第十四章只提供理解与陪伴自己就诊的语言，不提供处理方法。

## 5.3 速查

| 常见方式 | 一句话识别 | 先读 |
|:--|:--|:--|
| 听不见 | 饿和累都要很强才注意到 | 第九章；有创伤史先读第十四章 |
| 只看得见缺点 | 照镜子主要是挑剔 | 第十章 |
| 把身体当工具 | 休息要有理由，累不需要 | 第十一章 → 第二十章 |
| 盯着每一个信号 | 「没有问题」只安心几小时 | 第二十二章 |
| 觉得这不是我的身体 | 身体像远处的东西 | 第二十二章，不要从第九章开始 |
| 身体在某些时刻回到过去 | 反应远超当下的情形 | 第二十二章 |

同一件事可以同时落在几行里。选一行开始就够了，不需要先确定自己「主要是哪一种」。后三种的入口都是[第二十二章](Ch22_身体的阴影与求助.md)，这不是巧合：本书能陪你辨认需要，不能替你评估。〔证8〕

## 5.4 你的阅读路线

不必打分，也不必排出「最弱的一维」，更不必给自己定一个型。写下让你停下来的那一条，和它指向的入口：

```
我的阅读路线（日期：____）

1. 让我停下来的一条：____________________
2. 它有没有 5.1「先做两件事」里的任何一项：________
   （有→先读第二十二章或先就医，本章暂停）
3. 它更像处境问题、习惯问题，还是我说不清：________
4. 我先读的入口：第__章 ____________
5. 读完之后我愿意试的一个动作：____________
6. 什么时候回来看一眼：________
```

两条使用规则：

1. **一次只走一条线。** 四组观察全开的计划很难维持，而对身体来说更难——它会变成又一份要达标的项目。先处理让你停下来的那一条。〔证1〕
2. **先读第六章的 6.1 与 6.2。** 无论走哪条线，[第六章](Ch06_身体急救箱.md)都建议先看两节：6.1 分清哪些情形需要医疗，6.2 说明这些选项不必逐项做完、任何一项都可以拒绝。这两节决定后面所有练习对你是否适用，也决定它们是否安全。〔证3〕

写下来的意义不在于承诺，在于它把「我的身体是不是很差」这个无法回答的问题，换成「我这周先读哪一章」这个可以回答的问题。〔证1〕

## 本章速记

- 四组观察是提示，不是量表：不计分、不设阈值、不作分类，命中几条不说明任何问题。
- 先排除需要医疗的症状，再排除需要评估的心理信号，然后才轮到本章。
- 如果清点身体的问题这件事本身让你难受，不要做本章——它不该变成又一张缺陷表。
- 六种失联方式是常见的方式，不是六种人；后三种的入口是第二十二章，不是练习。
- 顺序不要颠倒：先排除处境与需要评估的状况，再谈练习。
- 任何一项都可以拒绝。你不欠任何练习一个拥抱。
