# Sonus 建议：身体之书修订记录

## 性质与依据

本文保存 Sonus 对《身体之书》的编辑判断与本轮修订的撤除记录。「Sonus」是本次审读与编写建议的署名，不代表临床专家资格、独立研究机构或医学认证。评价属 **Sonus 编辑判断，可信度不适用（审美与产品取舍）**；可复核的稿内错误另行列明，并注明依据编号与台账链接。

标注协议、可信度分级与安全边界沿用[系列来源与可信度说明](../EVIDENCE_GUIDE.md)与[平静之书编写说明](../bop/EVIDENCE_GUIDE.md)。撤除决定记录在本文，正文只保留成稿散文与依据表，不作为修订日志阅读。

## 一、总体判断

原稿与其余五书同出一套模板：23章、框架—步骤—速记、每章一个四维模型。身体之书在这套模板上额外承担了一类特殊风险——它的主题是身体，而它的读者会带着真实躯体症状来读。原稿把「先安抚身体，再处理事情」作为全书的操作顺序，却没有在任何位置告诉读者哪些症状需要先就医。一本身体之书缺少医疗分诊，是本书最高优先级的问题。

第二类问题是机制断言密度。原稿在生理章节中大量使用确定语气陈述有争议或未取证的机制，并据此给出操作步骤，形成「机制—处方」的直接链条。这条链条在多数情况下没有证据支撑。

## 二、第六章：改名与分诊前置

章名由「身体急救箱」改为「身体难受时，先做什么」。文件名保留 `Ch06_身体急救箱.md`，以免破坏本书导航、兄弟章节与仓库总索引中既有的链接。改名的理由是「急救」在中文里首先指医疗急救，而本章只能提供舒适层面的安排。

原稿的核心操作顺序「先安抚身体，再处理事情」已撤除，改为「先排除需要医疗的情形，再谈怎样让自己舒服一点」。相应地：

1. 新增急症清单与120／12356分流，前置于全部技术。依据 [S11](../SOURCES_SCIENCE.md#s11)、[S12](../SOURCES_SCIENCE.md#s12)。
2. 明确「练习不能排除疾病」。良性结果只能由检查告知，不能由呼吸练习告知。
3. 十项技术改为六项可独立选择的尝试，每项附停止条件与不适用情形；不累计次数，不设完成标准。
4. 撤除「温度直接改善情绪」「身体呼吸直接刺激副交感神经」等机制断言，改为可自查的主观经验描述。依据 [S17](../SOURCES_SCIENCE.md#s17)、[S18](../SOURCES_SCIENCE.md#s18)。
5. 撤除 Levine（1997）作为「着地是创伤疗法第一步」的依据；本轮未取得身体经验疗法的系统评价，其证据状态未核实。依据 [P17](../SOURCES_PRACTICE.md#p17)。
6. 新增烫伤与体温调节风险边界，覆盖感觉减退、糖尿病周围神经病变、脊髓损伤、认知障碍与相关用药人群。

## 三、第三章：机制分档

第三章的任务由「解释所有练习为什么有效」改为「分清哪些机制有可靠证据、哪些仍在争论、哪些我们并不知道」。原稿首段那句承诺已撤除：练习是否有效只能由对练习本身的研究回答，机制叙事不能替它作证。

逐条撤除与降级：

| 原稿表述 | 处置 | 依据 |
|---|---|---|
| 多层迷走神经理论作为定论，含「迷走刹车在线／离线」 | 降级为有实质争议的框架；本书不采用任何 PVT 机制解释或操作步骤 | [S17](../SOURCES_SCIENCE.md#s17) |
| 「呼气激活副交感，吸气唤醒，所以呼吸练习直接作用在神经上」 | 撤除机制断言，改为报告试验实际测到与未测到的结果 | [S06](../SOURCES_SCIENCE.md#s06)、[S15](../SOURCES_SCIENCE.md#s15) |
| 「延长呼气是最简单的手动开关」 | 撤除；「副交感」不是可整体打开的开关，该比喻本身造成错觉 | [S17](../SOURCES_SCIENCE.md#s17) |
| 「白天靠咖啡维持交感兴奋」 | 撤除机制断言，改为半衰期与睡眠干扰的可核验事实 | [S10](../SOURCES_SCIENCE.md#s10) |
| 昼夜节律全部内容依据 Walker（2017） | 撤除该引用；改引已核读全文的 AASM 共识，光照主张标未核实 | [P19](../SOURCES_PRACTICE.md#p19)、[S08](../SOURCES_SCIENCE.md#s08) |
| 「大脑先接收身体信号，再建构为情绪」写作神经科学结论 | 降级为假说与争议中的理论模型 | [S27](../SOURCES_SCIENCE.md#s27)、[P20](../SOURCES_PRACTICE.md#p20) |
| 「内感受迟钝的人也更难识别自己的情绪」 | 标未核实；所引综述摘要不涉及该命题 | [S27](../SOURCES_SCIENCE.md#s27) |
| 「非稳态负荷」用于个人自判 | 保留机制框架，补「不能凭症状反推激素水平」的边界 | [S14](../SOURCES_SCIENCE.md#s14) |

新增 3.1「机制解释不是诊断工具」，明确三条不可反向使用：不能凭症状推断激素水平、不能凭身体感觉判断病因、不能把机制解释当治疗方案。

## 四、待处理章节

以下章节尚未按本记录标准修订，其中列出的问题在修订前保持有效：

- 第七章场景剧本、第十二章身体表达、第十四章身体与创伤：延续 PVT 表述，须依 [S17](../SOURCES_SCIENCE.md#s17) 一并处理。
- 第八章疲惫与疼痛、第十七章疾病与身体：涉及症状归因，须补医疗分诊与「不自行归因为情绪」的边界。
- 第十五章身体与衰老、第十八章身体与性、第二十章身体的伦理：须补现实约束、无障碍与拒绝权。
- 第十六章智慧传统的身体观：《黄帝内经》《庄子》《瑜伽经》引用缺篇章与版本，见[系列传统来源台账](../SOURCES_TRADITIONS.md)。
- 第二十二章身体的阴影与求助：须核补已核验的紧急联系方式。

## 五、验收方式

| 项目 | 方式 |
|---|---|
| 依据编号连号闭合 | 只读脚本逐章检查〔证N〕正文与依据表一一对应 |
| 链接与锚点 | 逐链接解析相对路径，逐个锚点在目标台账中确认存在 |
| 体例一致 | 与平静之书比对：无装饰性表情符号、无中英混排残留、依据表为末节 |
| 危险措辞 | 检查是否残留「练习排除疾病」「必须」「一定」「最有效」等表述 |
| 篇幅 | 与平静之书各章同量级，不以篇幅增长证明质量 |

机器检查只检验形式。思想深度、真实读者体验与临床适用性不能由机器宣布通过。真人医疗与心理健康专业人士审读、目标读者试读需另行安排，本轮不声称完成。
