# 第三章 · 身体的生理学

> 这一章要分开的不是「身体的秘密」，而是四件不同的事：哪些机制有可靠证据，哪些是有争议的框架，哪些是合理但未经检验的说法，哪些我们其实并不知道。把它们分开，比把它们串成一个漂亮的故事更重要。〔证1〕

一个练习有合理的机制解释，与它被证明有效，是两件事。本书里绝大多数练习属于前者。练习是否有效，只能由对练习本身的研究来回答；机制叙事不能替它作证。〔证1〕

---

## 3.1 先说清楚：机制解释不是诊断工具

生理机制可以帮你理解「为什么压力会带来身体感觉」。它不能反过来用：

- **不能凭症状推断激素水平。** 心慌、失眠、疲惫不等于皮质醇偏高；感到放松也不等于皮质醇偏低。这类对应关系在个体层面不可靠，本书不提供任何自测换算。〔证3〕
- **不能凭身体感觉判断病因。** 胸闷可能是紧张，也可能是心肺问题；持续头痛可能是压力，也可能需要影像检查。身体感觉提示「值得关注」，不提示「是什么」。需要排查时先做医疗评估，顺序见[第六章](Ch06_身体急救箱.md)6.1。〔证2〕
- **不能把机制解释当成治疗方案。** 即使某个机制被证实，从机制到「该做什么」之间还隔着剂量、人群、对照与随访。本书跳过这段距离的地方，会明确标为编写建议。〔证1〕

下面每一节都会说明自己站在哪一档。

## 3.2 油门与刹车：自主神经的两个分支

自主神经系统有交感与副交感两个分支，教科书常用油门与刹车作比：

| | 交感（油门） | 副交感（刹车） |
|:--|:--|:--|
| 功能 | 动员、战斗、逃跑 | 修复、消化、休息 |
| 心率呼吸 | 加快、变浅 | 减慢、变深 |
| 消化 | 暂停 | 恢复 |
| 主观感受 | 警觉、焦躁、坐立不安 | 平静、松弛、困倦 |

这是基础生理学的通行描述。自主神经系统与下丘脑—垂体—肾上腺轴同属身体的应激介质。〔证3〕

两点限定要一起读。第一，这个二分法是**教学用的简化**。真实的自主神经调节是分器官、分情境、彼此交错的，不是全身同时踩油门或同时踩刹车；把「副交感」当作一个可以整体打开的开关，是比喻带来的错觉，不是生理事实。第二，主观感受一栏是**常见对应，不是判据**。有人在心率很快时感到兴奋而非焦躁，也有人在平静外表下心率偏高。〔证3〕

关于咖啡因，已核验的官方材料支持的是一个朴素也更有用的事实：健康成人体内咖啡因半衰期平均约4小时、范围2—8小时，受年龄、孕期、用药与肝脏健康影响；临睡前摄入约100毫克也可能影响部分成人的睡眠。〔证4〕你不需要知道它作用在哪条通路上，只需要知道它在你体内大约停留多久。半衰期不等于完全清除，也不构成人人统一的停用时刻。〔证4〕

## 3.3 应激反应的链条与异稳态负荷

面对威胁时，身体启动一条经典通路：下丘脑 → 垂体 → 肾上腺（HPA轴），释放皮质醇等应激激素，把能量调往四肢，同时压低消化与免疫等「非紧急项目」。短期看，这套系统救命。〔证3〕

问题出在长期。McEwen（1998）的综述提出：应激介质本身是适应性的，但反复激活、恢复不足或调节失衡，会让同一套系统从保护转为损害，这种累积代价被称为**异稳态负荷**（allostatic load）。该综述同时使用人类与动物资料，并承认机制解释与跨物种外推的限制。〔证3〕

可信度**中**。这是一个被广泛引用的机制性框架，不是一条可以套在个人身上的定律。它最有用的地方是解释「为什么长期压力会牵动多个系统」，最不该被用来做的是给个人下判断——你无法通过疲惫程度反推自己的异稳态负荷。〔证3〕

现代压力的一个特点是：威胁多半不是老虎，而是消息、绩效与人际冲突。身体动员起来了，却没有「打完就跑」的出口。〔证5〕这是编写性的类比，不是实验结论。它指向一件可操作的事——如果动员无法通过行动释放，那么让自己「完成」某件事的替代路径（起身走动、把话说完、写下待办）就有其位置。这些做法的价值来自经验与可尝试性，不来自本节的机制叙事。〔证5〕

## 3.4 迷走神经：一个存在实质争议的框架

迷走神经确实是副交感系统的重要通路，从脑干延伸到心脏与内脏，这一点没有争议。〔证6〕

有争议的是围绕它建立的那套解释，尤其是多层迷走神经理论（polyvagal theory）及其「迷走刹车」「神经感知安全」一类表述。2023年，Grossman在《Biological Psychology》发表长文，系统性质疑该理论的五项基本前提。〔证6〕

- 这一条**能**支持的是：该理论存在实质性的学术争议，且质疑针对其基础前提，不是细枝末节。可信度**高**。
- 这一条**不能**支持的是：争议双方孰是孰非。本书不作判断，也不借某一方的名义给读者一个确定答案。
- 因此本书**不采用**任何以该理论为基础的机制解释，也不据此设计操作步骤。〔证6〕

这不意味着该理论毫无价值——它在临床与身体工作中影响很大，许多人报告从中获益。但「影响大」与「机制成立」是两回事，而本书能对你负责的只有后者。当一套机制解释存在针对其前提的公开质疑时，把它当定论来教，是把学术争议的风险转嫁给读者。〔证6〕

## 3.5 延长呼气：证据说了什么，以及没说什么

**证据支持的部分。** Balban等（2023）在《Cell Reports Medicine》发表了一项远程随机对照试验：受试者每天做5分钟结构化呼吸练习、持续约1个月，比较不同呼吸方式与正念。周期性叹息（cyclic sighing）组在积极情绪改善和呼吸频率下降上优于正念组。〔证7〕

**同一项试验没找到的东西。** 该试验**未发现静息心率或心率变异性（HRV）的显著改变**。〔证7〕这一点很关键：如果「延长呼气通过副交感起效」是对的，最该出现的生理指标恰恰没有出现。这不能证明该机制不存在，但足以说明它没有被这项研究证实。〔证7〕

**HRV本身还有一层限制。** Shaffer与Ginsberg（2017）的综述指出：记录时长、呼吸频率与深度、姿势、活动状态、心率以及伪差都会影响结果；不同时间尺度和指标的参照值不能随意互换；LF/HF比值并非无争议的交感—迷走平衡量尺。〔证8〕即便你想用生理指标验证这类说法，现有的手表读数也不是合适的工具。本书不把任何HRV阈值当作操作或分流依据。〔证8〕

**所以本书怎样写呼吸练习。** 保留行为，不主张机制。你可以做让呼气略长于吸气的呼吸，理由不是「它打开了迷走开关」，而是：一项随机试验中，数周的每日练习伴随主观情绪改善；NHS的公众建议强调选择舒适姿势、让呼吸在舒适范围内进行、不强迫，计数有帮助但不要求起初数到五。〔证7〕〔证9〕

三条边界随之确定：试验用的是每日5分钟、持续约1个月，**不能**为本书更短的剂量背书；呼吸练习**不保证**在数十秒内见效；出现头晕、胸闷或不适时立即停止并恢复正常呼吸——这不是练得不对，是身体在告诉你到此为止。〔证7〕〔证9〕

## 3.6 昼夜节律：确定的与不确定的

谈睡眠，中文读者最常遇到的一本大众读物是Walker（2017）《我们为什么要睡觉》。本书不以它为事实依据：2019年有一份公开、逐页、未被撤回的批评文献，指其向国际机构归入一条伪造的公共卫生声明、把睡眠时长与死亡率及癌症发病率不当关联、改动已发表图表。该批评由个人撰写，本轮未经第三方复核，故列为已公开指控而非已证实错误；但仅凭它存在，就足以要求本书改引可核验的一手材料。〔证10〕

**已核验的部分。** AASM与睡眠研究学会2015年的联合共识针对18—60岁成人建议：规律地每晚睡至少7小时；睡眠健康不仅涉及时长，也涉及质量、时间安排与规律性；年轻成人、补偿睡眠不足者及患病者可能适合超过9小时。〔证11〕

由此能负责任说出的推论只有两条：**规律性本身是共识明确纳入的维度**；**不存在人人适用的唯一时长**——不能要求恰好8小时，也不能把超过9小时一概判为异常。〔证11〕

**未核实的部分。** 早晨见光、晚上调暗、固定起床时间比固定入睡时间更可靠，这三条流行且看似合理，但本轮没有取得可核验的一手来源支持其中的具体主张，包括「晨间光照是校准节律的最强信号」与「睡前一小时远离亮屏」的时长规定。〔证12〕它们在本书中标为**编写建议，未核实**。你可以按它们安排生活，代价很低；本书不声称它们已被证明，也不给照度、时长或时机的精确数字。〔证12〕

「皮质醇清晨升高帮你醒来、褪黑素夜间升高的前提是黑暗」属通行生理学常识，本轮同样未取证，标为未核实。〔证12〕

需要睡眠方面的诊断或治疗时，成人慢性失眠的一线治疗是多组分CBT-I，不是本节的节律建议。〔证11〕

## 3.7 内感受：一个仍在成形的问题

内感受（interoception）指大脑对身体内部状态的感知：心跳、呼吸、饱胀、体温。这个构念本身是心理学与神经科学的既有概念。〔证13〕

Craig（2009）在《Nature Reviews Neuroscience》的综述中讨论了前脑岛皮层（AIC）与内感受再表征的关系。**摘要的措辞值得原样注意**：AIC对内感受的再表征功能「offers one possible basis」——提供了一种可能的基础；新发现「suggest」——提示AIC在意识中具有重要作用；因此它「needs to be considered as a potential neural correlate」——需要被当作意识的潜在神经关联来考虑。〔证13〕

这是假设性语言，它没有确立「身体信号在前、情绪建构在后」的因果顺序。那个顺序来自情绪建构论，其系统阐述见Barrett（2017）《情绪》。〔证13〕〔证14〕情绪建构论是一个有影响力、也有实质争议的理论模型，与基本情绪理论等传统立场分歧明显，本轮未取得裁定性证据。〔证14〕

「内感受迟钝的人也更难识别自己的情绪」这一命题，Craig的摘要不涉及，本轮也未取得支持它的一手研究，标为**未核实**。〔证13〕

本章对内感受的立场是：它是一个有用的观察视角，不是一套已确立的机制。它支持你做一件事——注意身体内部的信号并尝试描述它们。它不支持你做的事——据此推断自己的情绪加工方式是否正常，或推断别人是否「感觉不到身体」。〔证13〕〔证15〕

## 3.8 练习：六十秒生理天气报告（Sonus编写建议）

以下安排为Sonus编写建议，可信度**不适用**：没有经过对照试验验证，不承诺任何效果，时长与频次均为便于尝试而设，你可以缩短、改变或跳过。〔证15〕

每天一到两次（例如午后与睡前），像看天气预报一样读自己的身体：

1. **唤醒水平**：我现在更像「油门」还是「刹车」？（1—10分）
2. **体感定位**：身体哪里最紧、最沉、最热？位置在哪？
3. **需求判断**：此刻身体最可能需要什么——活动、休息、水、食物，还是安静？
4. **一个微回应**：做一件5分钟内能完成的小事（起身走1分钟、喝口水、换姿势）。呼吸练习可选项见[第六章](Ch06_身体急救箱.md)6.3。

三条规则：

- **这是观察，不是评估。** 打分是为了让你注意到变化，不是为了给自己一个成绩。分数高低不构成好坏判断。〔证15〕
- **不解读，不诊断。** 记录到「胸口紧」就停在记录。不要顺着本章的机制解释往下推成「我的交感太活跃」或「我异稳态负荷高」——3.1已经说明这条路不通。〔证15〕
- **出现异常就转医疗。** 如果记录中反复出现胸痛、呼吸困难、心悸伴头晕、不明原因体重变化、夜间痛醒，或任何新出现且持续的症状，需要的是一次医疗评估，不是更多记录。清单与分流见[第六章](Ch06_身体急救箱.md)6.1与[第二十二章](Ch22_身体的阴影与求助.md)。〔证2〕

无效不是失败。连续几天没有变化、觉得这个练习很傻、或者干脆做不下去，都是允许的结果，不构成人格或毅力的评价。〔证15〕

## 3.9 本章不处理的事

| 情形 | 应去哪里 |
|---|---|
| 需要鉴别病因的躯体症状 | 医疗评估；不要用本章的机制解释先行归因 |
| 自主神经功能、内分泌或免疫相关疾病 | 相应专科；本章不是病理生理学教材 |
| 失眠的诊断与治疗 | 睡眠医学评估；一线治疗是多组分CBT-I |
| 创伤反应与解离 | 创伤取向的专业心理治疗 |
| HRV与可穿戴设备数据的解读 | 3.5已说明其限制；医疗用途须经专业评估 |
| 情绪障碍的诊断 | 精神科或临床心理专业评估 |

本章是教育与自我观察材料，不提供诊断、治疗方案或个体处方。求助的分流与联系方式见[第二十二章](Ch22_身体的阴影与求助.md)。〔证2〕
