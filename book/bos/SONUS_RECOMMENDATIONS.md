# Sonus 建议：力量之书修订记录

## 性质与依据

本文保存 Sonus 对《力量之书》的编辑判断与本轮修订的撤除记录。「Sonus」是本次审读与编写建议的署名，不代表临床专家资格、独立研究机构或医学认证。评价属 **Sonus 编辑判断，可信度不适用（审美与产品取舍）**；可复核的稿内错误另行列明，并注明依据编号与台账链接。

标注协议、可信度分级与安全边界沿用[系列来源与可信度说明](../EVIDENCE_GUIDE.md)。撤除决定记录在本文，正文只保留成稿散文与依据表，不作为修订日志阅读。

## 一、总体判断

力量之书的问题与其余五书共有两类：机制断言密度过高，急救章缺少医疗与危机分诊。这两类问题在第六章已处理。但本书还有一类**它独有的结构性问题**，优先级高于前两类，因为它不在某一章，而在本书对其核心概念的定义里。

原稿把「承受力」列为力量的第一维度，定义为「扛住外部压力而不变形」，其反面是「一点风吹草动就崩，不战自溃」；本书总纲第一句即「力量是能扛住、能行动、能影响、能修复」；第五章的四维审计以承受力为维度一，五项信号命中三条即判为短板，并指向第十七章坚韧与反弹、第十二章心智力量。

这一结构的问题不在于承认人需要承受力——不可改变的处境确实存在，本书若否认它就不诚实。问题在于**它没有区分两种承受**：

- 承受**不可改变**的处境：疾病、丧亲、组织的短期刚性、无法立刻退出的责任。这类承受需要支持，本书应当提供。
- 承受**本不该承受**的要求与伤害：超出授权的责任、无休息的长期加班、贬低与羞辱、骚扰与威胁。这类承受不是一种力量，把它称为力量，只是把成本从提出要求的人转移到承受的人身上。

原稿把两者合并为一个可训练的维度，并给出「命中三条即短板」的判定。后果是具体的：审计五项中的「被批评后需要很久才能恢复」「面对不确定性反复反刍、睡不好」「害怕冲突」三条，在临床上分别可能指向抑郁、焦虑或一个正在造成伤害的环境；而原稿对它们的回应是「你的承受力是短板，去读坚韧与反弹」。这把可能的健康信号与处境问题，转写成了性格缺陷加更多坚韧训练。

**因此本书的第一条修订原则是：不把自我调节写成忍受不合理工作、伤害或不平等的义务。** 状态技术改变状态，不改变处境；能扛多久取决于处境，不取决于练得够不够。

## 二、「承受力」的重新定义

处置方式不是删除该维度，而是拆分并改名，使判定不再指向人格：

1. 第一章四维表中的「承受力」改为**稳定力**，定义为「在压力下仍能感受、判断，并选择怎样回应」；其反面不是「不战自溃」，而是「失去选择：要么崩，要么全盘接受」。
2. 明确写出稳定力的适用边界：它处理的是你对不可改变之事的回应，不是你对可改变之事的沉默。可改变的事走协商、拒绝、上报或离开。
3. 第五章维度一改名并撤除计分：不计总分、不作「命中三条即短板」的判定、不作人格分类。改为自我观察与阅读导航。其中三项症状型信号（恢复慢、反刍与睡眠、害怕冲突）须补一行分流：持续两周以上、影响功能，或伴情绪低落与自伤念头时，需要的不是坚韧训练，是一次评估，入口见[第二十二章](Ch22_The_Shadow_Of_Power.md)。
4. 「别人一句硬话，就能让自己软下来答应不合理要求」一项保留，且它的方向本来就是对的——它把顺从不合理要求列为问题，而不是把承受列为美德。这一项在新版中前置，作为该维度的第一项。
5. 总纲一句改为：力量是能判断、能行动、能影响、能修复的综合能力；能判断，包括判断什么不该由你来扛。

## 四、第六章：分诊前置与处境分支

章名由「力量急救箱」改为「状态很差时，先做什么」。文件名保留 `Ch06_Power_First_Aid.md`，以免破坏本书导航、兄弟章节与仓库总索引中既有的链接。

1. 新增6.1医疗与危机分诊，前置于全部技术：急性胸痛与放射痛→120；心悸伴晕厥→急诊；持续失眠与体重变化→专科；反复惊恐发作→精神科或临床心理；自伤念头→立即求助或12356；欺凌与骚扰→110、合规与申诉渠道、工会或法律途径。
2. 新增6.2「是状态问题，还是处境问题」，作为全章唯一没有动作的一节，给出三步判断顺序，并写明本书的伦理立场。
3. 决策表第一行为「有6.1中任一情形」，第二行为「要求不合理、正在承受伤害、或反复需要急救才能上班」，其余各行明确只在确认面对的是状态问题时适用。
4. 十项技术并为七项可独立选择的尝试，逐项补停止条件、禁忌人群与替代路径；冷水项补心律失常、冠心病、未控制高血压、雷诺现象、寒冷性荨麻疹与起搏器禁忌。合并的理由是方法数量本身不构成质量：原「一句话说清你要什么」「三句开场陈述」「开口前三句放慢」同属进场前的自我陈述，并为选项六；原「进场前动一下空间」「只做最小的一步」同属做一件确定能完成的小事，并为选项七。
5. 撤除「必须在平时练习否则慌乱时用不出来」，改为可选择的熟悉，理由是熟悉的东西更容易想起来。
6. 新增虚构的林澄情境，用于说明技术能帮他在会上把话说完，但不能替他拿到排期权；该情境明确标为虚构，不作疗效证据。
