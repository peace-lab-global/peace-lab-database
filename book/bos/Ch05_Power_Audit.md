# 第五章 · 力量审计

> 上一部说清了「力量是什么、为什么会漏」。这一部回答一个更具体的问题：你的力量，漏在哪里？
> 这一章不计分，也不给你定级。它审计的对象是处境与选择，不是你的价值。读完你会得到一份只属于你的阅读路线，而不是一个关于你是什么人的结论。

---

## 5.1 四维自我观察

下面四组是**观察提示，不是量表**。它们不计分、不设阈值、不作人格分类，也不承担诊断或疗效测量——本书没有对它们做过任何验证。用法是：读一遍，看哪几条让你停下来，然后去对应的章节。命中几条不说明任何问题，让你停下来的那一条才有信息量。〔证1〕

**先做一件事。** 如果最近两周你有以下任何一项，请先读[第二十二章](Ch22_The_Shadow_Of_Power.md)，不要做下面的观察：持续的失眠或早醒；情绪低落到对平时在意的事也提不起劲；出现伤害自己的念头；工作与生活功能明显下滑。这些是需要专业评估的信号，不是某一维的短板，多练坚韧不会让它们好转。若有立即的危险或自伤念头，请直接联系当地急救与心理援助渠道。〔证2〕

### 维度一：稳定力（还能选）

这一维里有一条和其他几条不是一类，先看它：

| 观察提示 | 它可能在说什么 | 阅读入口 |
|---|---|---|
| 别人一句硬话，就能让自己软下来答应不合理要求 | 问题往往不在你承受得不够，而在那个要求本来不该由你答应 | [第十九章](Ch19_Assertiveness_And_Negotiation.md)的拒绝与协商，或[第六章](Ch06_Power_First_Aid.md)6.2的处境判断 |

把它归到「稳定力不足」并去练坚韧，是本章要避开的一个错误：它会把一个处境问题改写成性格问题。〔证1〕

其余四条是常见的困扰描述。它们可能来自你的应对方式，也可能来自你所处的环境，还可能来自需要专业评估的健康状况。本章无法区分，也不尝试区分：

| 观察提示 | 先问两件事 |
|---|---|
| 被批评或被否定后，需要很久才能恢复 | 一、处境是否可以改变？可以→[第十九章](Ch19_Assertiveness_And_Negotiation.md)、[第二十章](Ch20_Environment_And_Leverage.md) |
| 面对不确定性（裁员风声、组织调整）反复想、睡不好 | 二、是否已持续两周以上，或影响到吃饭、睡觉、上班？是→[第二十二章](Ch22_The_Shadow_Of_Power.md) |
| 害怕冲突，宁可自己憋着也不去澄清 | 两问都答否，才轮到[第十七章](Ch17_Resilience_And_Bounce_Back.md)与[第十二章](Ch12_Mental_Toughness.md) |
| 遇到挫折第一反应是自我否定，而不是分析问题 | ——顺序不要颠倒：先排除处境与健康，再谈训练 |

〔证1〕〔证2〕

### 维度二：行动力（做成）

| 观察提示 | 阅读入口 |
|---|---|
| 想做的事总是「计划了没启动」 | [第十章](Ch10_Action_And_Execution.md) |
| 重要的任务一拖再拖，拖到截止前才动 | [第十章](Ch10_Action_And_Execution.md) |
| 同时开了很多头，几乎没有彻底完成的 | [第十一章](Ch11_Focus_And_Deep_Work.md) |
| 决策慢：小事也要想很久，怕选错 | [第十二章](Ch12_Mental_Toughness.md) |
| 每天很忙，但复盘时说不清忙出了什么 | [第十五章](Ch15_Values_And_Mission.md) |

若拖延已长期影响收入、学业或健康，它可能不是意志力问题，先读[第二十二章](Ch22_The_Shadow_Of_Power.md)。〔证2〕

### 维度三：影响力（被听见）

| 观察提示 | 阅读入口 |
|---|---|
| 会议上有想法，但开不了口，或开口后被忽略 | [第十四章](Ch14_Voice_And_Presence.md) |
| 表达绕，听众常常抓不住重点 | [第十四章](Ch14_Voice_And_Presence.md) |
| 不敢要：不敢提加薪、不敢提需求、不敢对上说不 | [第十九章](Ch19_Assertiveness_And_Negotiation.md) |
| 同辈一句反驳就慌，语速不由自主加快 | [第十四章](Ch14_Voice_And_Presence.md)、[第六章](Ch06_Power_First_Aid.md) |
| 付出很多，但功劳经常被别人领走 | [第十八章](Ch18_Influence_And_Leadership.md)、[第二十章](Ch20_Environment_And_Leverage.md) |

其中「被忽略」与「功劳被领走」两条，描述的常常是环境而不是技巧。先做[第六章](Ch06_Power_First_Aid.md)6.2的判断，再决定要不要练表达。〔证1〕

### 维度四：恢复力（修回来）

| 观察提示 | 阅读入口 |
|---|---|
| 每天下班都像被掏空，周末补不回来 | [第八章](Ch08_Recharge_And_Morning_Setup.md) |
| 长期靠咖啡、酒精或熬夜维持 | [第九章](Ch09_Physical_Power.md)、[第二十二章](Ch22_The_Shadow_Of_Power.md) |
| 几乎没有让自己完全关机的时段 | [第八章](Ch08_Recharge_And_Morning_Setup.md) |
| 一次失败或错误后，反复自责很多天，无法翻篇 | [第十二章](Ch12_Mental_Toughness.md)、[第十七章](Ch17_Resilience_And_Bounce_Back.md) |
| 「忙完这阵就好了」说了很久，「这阵」从没结束 | [第二十章](Ch20_Environment_And_Leverage.md) |

这一维的多数条目描述的是工作量与休息条件，不是你的恢复能力不足。本书把「消耗与恢复需要交替」当作组织内容的框架，它出自一本大众管理著作，本章不据它给出任何恢复时长或剂量。〔证3〕

**一个常见的错位。** 林澄做完这四组观察，停下来最多的是维度一和维度三：会议上说了没人接，被点名加班时答了「好」。原本的结论是自己稳定力不够、表达也不行，打算从第十二章开始练。但林澄在项目里没有排期权限，那两次「说了没人接」都发生在自己的提议与负责人的既定安排冲突时。需要的不是更稳的心态，是[第二十章](Ch20_Environment_And_Leverage.md)的杠杆判断和[第十九章](Ch19_Assertiveness_And_Negotiation.md)的协商话术。这是本书的虚构情境，不是测评结果，也不代表所有人的处境都能改变。〔证4〕

## 5.2 六种常见的漏法

四维找「哪里漏」，这一节找「怎么漏」。

下面是六种常见的方式，**不是六种人**。同一个人身上常常同时有几种，也可能一种都不像；今天像第三种、下个月像第五种，都很正常。它们由Sonus整理，没有经过量表开发与验证，不用于分类，不表示严重程度，也没有「你是哪一型」的正确答案。〔证5〕

**一、把「不」咽回去**
常见体验：不敢拒绝，怕人失望，把别人怎么看自己放在最前面；答应完又后悔。
容易忽略的一点：说不难，很多时候不是技巧不够，而是拒绝的代价确实存在——收入、评价、关系。先分清哪些是话术问题，哪些是处境问题，两者的处理方式完全不同。
阅读入口：[第六章](Ch06_Power_First_Aid.md)6.2 → [第十九章](Ch19_Assertiveness_And_Negotiation.md) → [第十五章](Ch15_Values_And_Mission.md) → [《平静之书》第十五章](../bop/Ch15_Values_And_Boundaries.md)。

**二、一直还没开始**
常见体验：一再推迟，「再等等就是最好的选择」；用忙别的事避开真正该做的那件。
容易忽略的一点：不启动就不会失败，这个安排在短期确实有效——所以它很难自己消失。要处理的不是懒，是它在替你挡住什么。
阅读入口：[第十章](Ch10_Action_And_Execution.md) → [第十二章](Ch12_Mental_Toughness.md)。

**三、很忙，但没有进展**
常见体验：很忙、很累、很拼命，产出却不成比例；停不下来。
容易忽略的一点：忙碌会带来「我在努力」的安心，这份安心是真的。代价是「我在往哪使劲」这个更难的问题一直被推迟。
阅读入口：[第十五章](Ch15_Values_And_Mission.md) → [第十章](Ch10_Action_And_Execution.md) → [第二十一章](Ch21_Personal_Power_System.md)。

**四、对内严厉，对外憋屈**
常见体验：反复检讨自己，不爽也不说；什么都没干但累瘫。
容易忽略的一点：对自己严厉通常不是缺点，而是曾经有用的适应——它可能在你更早的处境里保护过你。在把它整个拿掉之前，先弄清它在替你防什么。
阅读入口：[《平静之书》第十三章](../bop/Ch13_Self_Compassion.md) → [第十三章](Ch13_Emotional_Power.md) → [第十九章](Ch19_Assertiveness_And_Negotiation.md)。

**五、什么都自己扛**
常见体验：单枪匹马，不找人帮忙，不暴露需求；大事无人可商量。
容易忽略的一点：独立是有价值的，问题出现在它变成唯一选项时。求助的成本常被高估——本书把「社会支持是一种可调用的资源」作为组织内容的框架，不据它承诺任何具体结果。〔证6〕
阅读入口：[第二十章](Ch20_Environment_And_Leverage.md) → [第十八章](Ch18_Influence_And_Leadership.md) → [《平静之书》第十九章](../bop/Ch19_Relationships_Peace.md)。

**六、状态像过山车**
常见体验：今天觉得能征服世界，明天全盘否定；情绪决定行动，行动决定自信，自信又决定情绪。
容易忽略的一点：波动本身不是故障，人本来就有起伏。需要处理的是波动大到让计划无法执行，或者所有安排都挂在「今天的状态」上，没有任何不依赖状态的部分。本书借用自我效能理论来解释这种联动，该理论的支持材料本轮未核读。〔证7〕
阅读入口：[第二十一章](Ch21_Personal_Power_System.md) → [第八章](Ch08_Recharge_And_Morning_Setup.md) → [《平静之书》第二十一章](../bop/Ch21_Personal_Peace_System.md)。

## 5.4 你的阅读路线

不必打分，也不必排出「最弱的一维」。写下让你停下来的那一条，和它指向的入口：

```
我的阅读路线（日期：____）

1. 让我停下来的一条：____________________
2. 它更像处境问题、技巧问题，还是我说不清：________
3. 我先读的入口：第__章 ____________
4. 读完之后我愿意试的一个动作：____________
5. 什么时候回来看一眼：________
```

两条使用规则：

1. **一次只走一条线。** 四组观察全开的计划很难维持。先处理让你停下来的那一条；目标越聚焦，越容易被执行——本书借用目标设定理论来支持这条编排建议，该理论本轮仅取得书目信息。〔证8〕
2. **先读第六章的6.1与6.2。** 无论走哪条线，[第六章](Ch06_Power_First_Aid.md)都建议先看两节：6.1判断哪些情况不属于状态问题，6.2判断你面对的是状态问题还是处境问题。这两节决定后面所有技术对你是否适用。

写下来的意义不在于承诺，在于它把「我是不是不够强」这个无法回答的问题，换成「我这周先读哪一章」这个可以回答的问题。〔证1〕

## 本章速记

- 四组观察是提示，不是量表：不计分、不设阈值、不作分类，命中几条不说明任何问题。
- 出现持续失眠、情绪低落、自伤念头或功能下滑：跳过本章，先读[第二十二章](Ch22_The_Shadow_Of_Power.md)。
- 六种漏法是常见的方式，不是六种人；同一个人常常同时有几种。
- 顺序不要颠倒：先排除处境问题与需要评估的健康状况，再谈训练。
- 一次只走一条线；先读第六章的6.1与6.2。
