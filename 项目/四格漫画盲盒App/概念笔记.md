# 情绪四格漫画盲盒 App — 概念笔记

> 状态: **概念期** | 日期: 2026-09-12 | 关联: [禅绕画 Zentangle 类 App 竞品地图](../../07-行业观察/APP专题/禅绕画Zentangle_App竞品地图_2026-09.md)

## 一句话定位

情绪急救向的「四格漫画盲盒」App:选情绪 → 开盒 → 前三格漫画直击你此刻的心情 → 第四格留白,由你慢滑补完 → 收藏进情绪档案。

## 核心循环

```
① 情绪匹配(一次滑动:很差→很好)
② 开盒(盲盒动画/音效,期待感)
③ 前三格漫画浮现(共鸣你此刻的情绪)
④ 第四格留白 → 慢滑补完(不擦除、一笔一笔,禅绕式)
⑤ 完成瞬间浮现点睛文案(一句哲理/治愈的话)
⑥ 作品入情绪档案 + 收集图鉴
```

## 已锁定决策(2026-09-12)

1. **第四格留白,慢滑补完**(前三格立即可读,第四格需要手指慢慢画)——保留主动调节机制,开盒惊喜 + 主动投入 + 独一无二笔迹作品三合一
2. **抽取逻辑 = 情绪匹配**(非纯随机):开盒前一次滑动选情绪,盒子偏向"此刻需要被接住"的内容
3. **内容风格四系全上**:共鸣系 / 哲理系 / 幽默解压 / 治愈系
4. **每日免费一盒**(克制盲盒成瘾机制,心理产品的伦理底线)

## 机制根基

- **认知重评(CBT 实证)**:四格漫画的"反转"结构是认知重评的天然载体
- **慢速运动降唤醒**(Pause App 验证):第四格慢滑是核心调节动作
- **盲盒期待机制**:开盒期待本身就是正向情绪事件;收集图鉴 = 留存钩子
- **禅绕思想落地**:不擦除、一笔一笔、no mistakes、完成即作品

## 需求强度分析（2026-09-12，质疑刚需后复盘）

### 三个硬伤（现定位不够刚需的原因）

1. 急救低频：恐慌/情绪尖峰一月几次，习惯需每日形成——代际低频 = 留存差
2. 娱乐内容红海：盲盒漫画的爽点在内容侧，内容侧小红书/抖音无限免费供给
3. C 端付费习惯：中国用户为"疗效/身份"付费，很少为"每日一笑"付费

### 需求分层表

| 场景 | 频率 | 痛感 | 付费方 | 刚需度 |
|------|------|------|--------|--------|
| 情绪急救（C 端自己用） | 低频 | 高 | 个人 | 弱 |
| 睡前反刍 | 每晚 | 高 | 个人 | 中-强 |
| 咨询师布置作业（B2B2C） | 每周 | 高 | 咨询室 | 中-强 |
| 学校心理课/心理月 | 每周 | 中 | 学校 | 中-强 |
| 企业 EAP | 每月 | 中 | 企业 | 中-强 |

核心洞察：**刚需在"别人替用户做决定"的场景**（咨询师/心理老师/HR），个人自感知需求 ≠ 付费，被推荐使用才持续 + 有人付费。

### 自有资产

**《平静之书》Ch06 90 秒急救箱**（`bop/`）＝第十一种情绪的数字化落地，自带内容库与循证背书—产品入口应从这里出发，而非从零造内容。

### 拉刚需的两个方向

- **A 场景高频化（睡前模式）**：睡前三分钟慢滑 + 漫画，打"睡前反刍"这个每晚高频场景；KPI = 助眠率
- **B 渠道化（B2B2C）**：咨询师/学校/EAP 付费订阅工具包，个人免费使用；专业分发 + B 端盈利

判断：A 打穿 C 端高频场景，B 做盈利渠道，同一产品两种叙事。

### 方向整合（2026-09-12 用户已定：三层全要）

三者不是三选一，是同一件事的三层：

| 层 | 动作 | 角色 |
|----|------|------|
| 验证层 | 访谈 5 人（睡前反刍者2 + 心理老师1 + 咨询师1 + HR/EAP 1） | 先验证需求强度，再定 MVP |
| C 端层 | 睡前模式：睡前三分钟慢滑 + 漫画，KPI = 助眠率 | 高频场景入口（跟《90秒急救箱》衔接） |
| B 端层 | B2B2C：咨询师/学校/EAP 工具包，B 端订阅付费 | 分发 + 盈利 |

验证成功标准：4/5 受访者表达"会试用/会推荐"；睡前场景意愿显著高于急救场景；至少 1 个 B 端渠道反馈采购意向。

## 商业化与付费阶梯（2026-09-12）

### 原则

**免费层完整可用；付费解锁"深度 / 个性 / 收藏"，不卖概率。** 盲盒数量终生有上限（免费每日 1 盒，订阅后每日 2-3 盒封顶），刻意保留"开盒的克制感"——这是心理产品的信誉底线，也是与抽卡类盲盒的差异化。

### 阶梯结构

| 层级 | 形态 | 内容 | 付费意愿引擎 |
|------|------|------|-------------|
| **L0 免费** | — | 每日 1 盒（情绪匹配基础版）；7 天情绪曲线；图鉴浏览（用"完成慢滑"解锁图鉴条目，而非花钱解锁） | 获客 + 留存；行为解锁强化主动调节 |
| **L1 订阅** | 月/年卡（锚定 ¥12/月、¥68/年） | 每日 2-3 盒 + 历史主题系列补盒；情绪档案周报/月报（情绪模式识别：时段/星期/触发主题）；点睛句收藏册 + 一键生成壁纸/分享卡片；慢画进阶（笔触主题 + 呼吸引导慢滑） | 数据价值（理性用户）+ 社交货币（分享卡片）+ 工具进阶 |
| **L2 按次付费** | 定制盒 ¥6.99/次（订阅含每月 1-3 次） | 用户说出今天发生了什么 → AI 生成专属四格漫画（共鸣/哲理系）→ 第四格留白由用户补完 → 无水印导出/可打印 | **最高付费意愿点**：被 AI 看见并画出我的故事 → 情感价值 + 可送人 |
| **L3 收藏/社交** | 低频高客单 | 限时主题系列（城市/四季/梦境）收集齐系列解锁专属壁纸套装 + 实体明信片印刷服务；赠送盒（给对方送一盒，附点睛留言） | 情感资产逐年增值 + 口碑传播 |

### 三个"愿意掏钱"的引擎

1. **定制盒（L2）**：个性化内容 + 情感价值，按次付费心理门槛低；需内容安全审核（AI 生成内容，注意《拟人化互动服务管理暂行办法》合规要求）
2. **情绪档案周报/月报（L1）**：数据产品——"你的情绪模式"是别处拿不到的自我认知，理性用户（含 IT 人群）付费动机强
3. **年度画廊（L1 年终权益）**：365 天的作品集自动排版成画廊/年刊，等价于 "Spotify Wrapped" 式年度报告——天然传播点 + 年底续费动机

### 护栏与风险

- 盲盒数量有上限、订阅不提升"稀有度概率"——防成瘾，宁慢不放量
- 定制盒的 AI 内容需人工审核池 + 剧作模板约束（防大模型套壳感、防内容事故）
- 混合收费结构（订阅 + 按次）复杂度高于单订阅——后台需两套计费，MVP 阶段可先只上 L0 + L2 验证付费意愿

## 待定问题(下一步)

1. **反转的位置**:传统四格反转在第四格,但第四格留白后,"反转"变成"用户完成动作本身"——点睛文案在完成后浮现。此结构需验证。
2. **幽默系降权规则**:高难过/高唤醒情绪状态下,幽默容易反效果——情绪匹配时自动降权幽默系,只发共鸣/治愈/哲理。
3. **平台与命名**:小程序 vs App;名字未定。
4. **内容生产方式**:AI 流水线 vs 创作者 + AI 辅助(品质与规模权衡)。
