# 身心共处冥想设计

## 一、开场安顿（0–5 分钟）

1. **问候介绍**，说明本次练习主题
2. **环境准备**：寻找安静空间、备好毯子，减少打扰
3. **姿势选择**：坐姿 / 躺姿
   - **坐姿**：坐椅子 1/2 或盘坐，调整身体，舒展腋窝，下颌微收
   - **躺姿**：头颈一线，双腿自然分开，双手置于身体两侧
4. **调整体态**，缓慢闭眼，注意力向内回收

## 二、身体扎根与逐层觉察（5–14 分钟）

1. **觉察支撑感**：感受椅子/垫子的承托、身体接触点的感受
2. **脊柱延展觉察**：从尾骶到头顶，逐节觉察脊柱空间
3. **自上而下扫描觉察**：头皮、面部、口腔、肩臂、手掌、胸腹
4. **探索提问**：
   - 腹部是柔软还是紧绷？
   - 是否随呼吸浮动？
   - 愿意停留在此处吗？

## 三、呼吸觉察，建立稳定锚点（14–20 分钟）

1. **觉察自然呼吸**：快慢、深浅，一手放胸口、一手放腹部，观察起伏
2. **三次深长鼻吸**，之后回归自然呼吸
3. **感受呼吸起伏**，如同在呼吸的海浪上停留

## 四、觉察想法与身体的联动（20–26 分钟）【核心板块】

> 带着好奇去看见，不急于改变：

1. 面对身体，内心是什么态度：**体谅关爱**，或是**忽视、评判、不满意**？
2. 注意力放在身体感受上，**愿意停留**，还是**陌生、无聊、想要离开**？
3. 遇到紧绷、酸麻、疼痛感，是**紧张想消除**，或是**单纯看见**？
4. 觉察疲惫、困意等身体信号：**顺应它**，还是**强迫自己坚持**？
5. **要点**：只是听见内在的声音，看见想法，不急于改变

## 五、收束唤醒（26–29 分钟）

1. 保持和身体的连接，安住在安稳感里
2. 深呼吸，活动手指、脚趾，缓慢活动脊背、肩膀、手臂
3. 舒展身体，慢慢睁开眼睛，觉察当下所有感受
