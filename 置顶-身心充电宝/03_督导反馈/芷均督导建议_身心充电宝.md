# 芷均督导建议——「身心充电宝」团督反馈

> **会议**：团督第二轮 · 芷均督导反馈
> **记录**：亚伦
> **记录日期**：2026-10-25
>
> 以下将会议中芷均（督导老师）给凡凡、夏夏、王钲以及全组的所有建议，按人 + 通用项完整列出，均带会议角标。

---

## 一、通用引导细节（老师对所有人提的）

1. **开场先说明目的**：这不是让人睡着，是保持清醒觉察；累了睡着也没关系。
2. **环境引导补上**：建议用柔和光线，可以点香薰烛火，提醒注意保暖。
3. **收尾别太突然**：睁眼前加过渡，感受眼皮划过眼球、慢慢适应光线、活动手腕、喝口温水。
4. **额头那段加连接**：皱紧眉头通常跟反复的思绪、压力思考有关，这样衔接更自然。
5. **牙关松开后加一句**：用嘴巴呼出气息，把锁住的紧绷和没表达的情绪释放掉。
6. **上场前 15 分钟进会议室调设备**，别等开始才试。

---

## 二、给凡凡（渐进式放松冥想）

1. **开场建立连接别太快**：所有带领者开头都容易赶，要和陌生伙伴慢一点建立连接。
2. **前面节奏偏快，可再放慢**；自我觉察到紧张导致快，之后要调整。
3. **冥想前先说明“放松≠睡着”**：允许困意，但目标不是睡觉，是保持身体觉察的清醒状态 [p41:51][p42:07]。
4. **坐姿引导要清晰**：坐椅子 / 床边、脚踩地、椅高不合可垫物；别让人翘腿交叉 [p54:07][p56:27][p56:47][p56:55]。
5. **环境可加柔和光线、小烛灯、注意保暖**，增强放松感 [p42:32][p42:44]。
6. **音乐用酷狗会员 + 共享屏幕“仅电脑声音 / 高保真”**，笔记本直出即可，音量别大 [p43:03][p43:18][p43:45][p44:11]。
7. **结尾睁眼太突兀**：加眼皮触感、光线由模糊变清晰、活动后再喝温水等生活化过渡 [p45:26][p46:02][p46:33]。
8. **额头 / 思绪表达要顺**：皱眉可联结“压力思绪”，但“思绪柔软下来”用词别扭，要改 [p47:35][p48:24]。
9. **牙关松开后可加一句**：用嘴巴呼出气息，把没说出口的情绪释放掉 [p49:15]。
10. **腹式呼吸**：手放肚脐上方；新手把手放在肚脐以上，不管腹式还是胸式都能有感觉。坐着别说“手掌下沉”，改“手掌随腹部回落 / 轻轻回收”（下沉像仰卧）[p51:05][p52:31][p52:54]。
11. **勾脚 / 小腿部分**：松开后多引导“安稳、踏实、扎根”，别只做动作；盘坐也可勾脚趾，但既然说脚掌触地就别再引导盘坐 [p57:18][p57:51]。
12. **衔接语要做好**：主题衔接不能一句话带过，要说清这节课给下节课铺垫了什么；引到下一位 / 下一节“关爱身体”，也可为明天板块做引导 [p30:24][p30:50]。
13. **时间偏短（约 20 分钟）**，要提前备好内容填满，可用表达 / 留白把时长补到 30–45 分钟 [p27:27][p806:37]。
14. **自己录一遍跟练，再调词** [p48:46]。
15. **掉线回来要提前准备好重新安定的衔接**：只说一句话让大家安定不够，要帮大家重新安定，而不只说“保持放松”。

---

## 三、给夏夏（关爱身体冥想）

1. **设备必须提前 15 分钟调**：收音麦 + 蓝牙音响导致听不清 / 回声 / 没音乐，后续单独调 [p59:44][p02:47][p02:52]。
2. **别一上来生硬提问“关爱是什么”**；可先共鸣“关爱 = 暖心 / 被包裹 / 阳光照身”，再进冥想 [p50:15][p56:27][p56:42]。
3. **主题混淆**：不要把凡凡的“觉察 / 收紧放松”又做一遍；关爱要给当下可体感的温暖体验 [p48:17][p49:53]。
4. **具体做法**：搓热掌心 → 敷腹部 / 脸 / 眼 / 膝 / 腰，对部位说“我看见你、谢谢你、此刻我爱你”，每个部位一两句 [p49:26][p53:21][p54:47][p55:06]。
5. **少说教**：语言描述太多会抢走身体感受时间；多留时间体感，别变成“关爱身体讲座” [p54:31][p55:11][p00:14]。
6. **身体扫描可保留，但不再做“紧—松”训练**；锚定“温暖 / 被照顾”的感受 [p51:50][p53:44]。
7. **临场掉线（手机过热黑屏）后**，重连时要帮大家重新安定，而不只说“保持放松” [p07:16][p07:27]。
8. **今天当场重带不合适，改为**：准备好 → 录音发群 → 大家跟练反馈 [p01:59:43][p02:01:14]。
9. **音乐问题单独找 CICI 再调** [p02:01:44]。

---

## 四、给王钲（后续“内化 / 转化”主题）

1. **主题层次要清**：凡凡 = 身体放松 + 心念觉察，夏夏 = 接纳基础上往心理走，王钲 = 更深内化，曹亚仑 = 转化后行动 [p44:48][p45:36]。
2. **文字稿方向没问题，不必大改**；自己录一遍跟练，再决定是否微调 [p03:17][p03:36][p04:17]。
3. **别把身体觉察部分堆太多**；身体带完再进呼吸 / 心念，避免和前两层重复 [p02:02:46][p02:03:03]。

---

## 五、给全组 / 课程设计层面

1. **四人必须清楚四课递进**：放松 → 共处 / 接纳 → 关爱 → 行动，不能“换人却同层次” [p44:01][p44:20][p44:31]。
2. **衔接不是套话**：要说明“从这节带走什么、下节为什么来、客户获得什么递进” [p05:19][p05:39][p05:56][p06:06]。
3. **冥想带领时长 30–45 分钟**；短的补内容，长的别水 [p06:37][p06:44]。
4. **陌生线上场少做开放提问**；熟悉场可互动，但要回应学员回答再过渡 [p56:12][p56:27]。
5. **音乐 / 设备 / 坐姿 / 光线都属于带领专业度**，直播前必须预检 [p02:52][p42:32]。
6. **每位带领者都要有“临时状况处理”能力**：断线、没音乐、回声，都要稳稳接住现场 [p07:08][p07:35]。
7. **小组互听录音、互相跟练反馈**，是团督成长方式 [p02:01:25]。

---

## 六、给亚仑（第四部分 · 转化 / 有信心行动）

1. **四课层次必须清晰**：凡凡 = 身体放松 + 心念觉察 → 夏夏 = 在共处 / 接纳基础上往心理走（温暖体感） → 王钲 = 更深内化 → 亚仑 = 转化后有信心行动；不是“再放松一次”，也不是“再讲接纳”，而是把前面三节攒下的觉察 / 接纳 / 关爱，落成可走出去的行动感 [p01:44:48][p01:45:51][p01:46:06]。
2. **转化不是第四节才突然开始**：王钲说“在关爱环节就开始要有转化的方面引导进来”，芷均回“好好”——说明转化在前面已埋下种子，你第四节要把前面埋的转化种子收口成“我愿意 / 我可以这样做” [p01:46:18][p01:46:22]。
3. **你的设计前提是被试者已经完成的**：① 认出紧绷 ② 接纳身体 ③ 感受到被关爱 / 被照顾 ④ 在心理层松下来——你不能再带他们回去做身体扫描 [p02:04:45][p01:45:51]。
4. **文字稿可以保留身体 / 呼吸作为入口，但落点必须是“心念 → 行为 → 信心”**：别把前三节动作重做一遍 [p02:03:17][p02:04:17]。
5. **铁律同样管你**：冥想带领 30–45 分钟；陌生线上场少开放提问；结尾要有“回到生活”的过渡（凡凡缺睁眼过渡、夏夏缺关爱体感、你要补“行动锚点 + 生活场景”过渡）[p02:06:37][p01:56:12][p00:46:33]。
6. **作为第四节，要做承前启后收尾**：没有下一个人，但要说清“这四课走到这，练习者带着什么能力回到生活” [p02:05:19][p02:06:06]。

## 七、给组长（统筹要求）

1. **组长不是分活就完事**：芷均原话“你们一定有一个共鸣是，就算这四节课我都一个人来做，也是四个层次”——组长要确保四人彼此懂别人那节在干啥，不各写各的 [p01:44:01][p01:44:31]。
2. **组长要盯“主题边界”**：凡凡放松、夏夏关爱（温暖体感不是讲座）、王钲内化、亚仑行动——谁越界组长先发现 [p01:48:01][p01:49:05]。
3. **组长管设备 / 流程红线**：提前 15 分钟调音、音乐用共享屏幕 / 电脑声音、别用电话模式 / 蓝牙音响翻车、手机过热掉线要“重新安定”不是只说“保持放松” [p01:59:44][p02:07:27]。
4. **组长推“互听录音跟练”**：夏夏重做后录音发群、王钲自己录一遍跟练、凡凡录一遍调词——亚仑也要录一遍自己跟练，再交稿；组长把大家反馈收口给芷均 [p02:01:14][p02:03:36]。
5. **衔接语是组长工程**：凡凡 → 夏夏可以，但全组要把“① 放松 ② 接纳 / 关爱 ③ 内化 ④ 行动”写成一张递进表，每节开头一句话点“上节你带了什么、这节再往哪走” [p02:05:39][p02:06:24]。
6. **组长要排练时卡表**：凡凡时间太短（20 分）要补内容、夏夏因意外拉长但有效少要砍废话、王钲别飘、亚仑别写成“励志演讲”——30–45 分钟 [p02:06:44][p00:27:27]。

## 八、亚仑马上能落的待办

- **交文字稿前先写一句话定位**：“第四节 = 把身体觉察、自我接纳、被关爱的体验，转化为‘我看见自己、我肯照顾自己、我敢做一小步’的行动信心。”
- **结构建议**：简短身体 / 呼吸锚定（≤5 分）→ 回看前三节意象（松弛的肩、温暖的腹、被看见的腿）→ 一个生活微行动（喝水 / 伸懒腰 / 拒绝一次过度承担）→ 默念“我可以” → 睁眼过渡（光线、脚踩地、做一件小事）。
- **明确不做**：别用“用力绷紧 / 再放松”；别再教“怎么关爱身体”；别大段讲道理。
- **录音自查**：录自己带练一遍，听有没有“讲座味”、有没有行动感、结尾能不能让人真的想动一下。
- **组长动作**：建个共享文档，四节各写「主题 / 不做什么 / 体感锚点 / 衔接语 / 时长」，周会前收齐。

> 老师没单独骂你，是因为你还没带；但老师说“亚仑 = 转化后行动”这句话就是给你的设计边界：前面三节是种种子，你这节是让人迈一步。组长视角再叠一层：你要把四节当成一门课，不是四个朋友圈。

---

## 核心一句话

> 芷均的老师建议 ＝ 凡凡补“清醒放松 + 结尾过渡”、夏夏把关爱从“说教”改成“温暖体感”、王钲保内化不跑题、亚仑把觉察收束为“有信心去行动”、组长把四节做成一门递进课而非四个独立朋友圈。
