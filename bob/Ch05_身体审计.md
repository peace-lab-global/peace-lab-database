# 第五章 · 身体审计

> 上一部你理解了身体，这一部回答更具体的问题：**你的**身体，缺在哪？
> 审计只需 15 分钟，但它会把后面十八章变成一份为你定制的地图。

---

## 5.1 四维身体审计

对以下四个维度逐一自评。每个维度 5 个信号，数一数你命中几条（凭最近两周的常态）。

### 维度一：感知力（听见身体的信号）

- [ ] 我听不见身体的信号（饥饿/疲惫/疼痛/紧张）
- [ ] 我经常"忘记"吃饭/喝水/上厕所
- [ ] 我不知道我的身体现在感觉如何
- [ ] 我需要别人提醒我"你该休息了"
- [ ] 我很少关注我的身体

**命中 3 条以上** → 感知力缺失，优先读：[第九章 身体感知](Ch09_身体感知.md)。

### 维度二：接纳力（接纳身体的不完美）

- [ ] 我对我的身体感到羞耻（外貌/体重/疾病）
- [ ] 我经常批评我的身体（"我太胖了"/"我太老了"）
- [ ] 我无法接纳身体的变化（衰老/疾病/受伤）
- [ ] 我很少感谢我的身体
- [ ] 我对我的身体感到不满

**命中 3 条以上** → 接纳力缺失，优先读：[第十章 身体接纳](Ch10_身体接纳.md)。

### 维度三：养护力（照顾好身体）

- [ ] 我经常熬夜/睡眠不足
- [ ] 我很少运动/久坐不动
- [ ] 我饮食不规律/不健康
- [ ] 我很少休息/放松
- [ ] 我把身体当成"工具"，不是"伙伴"

**命中 3 条以上** → 养护力缺失，优先读：[第十一章 身体养护](Ch11_身体养护.md)。

### 维度四：表达力（用身体表达自己）

- [ ] 我很少用身体表达自己（舞蹈/触摸/性）
- [ ] 我对身体表达感到羞耻/不适
- [ ] 我很少触摸他人/被他人触摸
- [ ] 我很少用身体表达情感
- [ ] 我把身体表达当成"不必要的"

**命中 3 条以上** → 表达力缺失，优先读：[第十二章 身体表达](Ch12_身体表达.md)。

## 5.2 六型身体失联模式：你是哪一型？

四维找"哪里缺"，六型找"怎么缺"。圈出最像你的（允许选两型）。

### 🔇 麻木型
**体验**：听不见身体的信号；经常"忘记"吃饭/喝水/上厕所；需要别人提醒"你该休息了"。
**底层**：感知力缺失——与身体失联。
**你的路线**：[第九章 身体感知](Ch09_身体感知.md) → [第六章 身体急救箱](Ch06_身体急救箱.md) → [第十九章 日常的身体](Ch19_日常的身体.md)。

### 😔 羞耻型
**体验**：对身体感到羞耻；经常批评身体；无法接纳身体的变化。
**底层**：接纳力缺失——对身体的不满。
**你的路线**：[第十章 身体接纳](Ch10_身体接纳.md) → [第十一章 身体养护](Ch11_身体养护.md) → [《平静之书》第十三章](../bop/Ch13_Self_Compassion.md)（自我关怀）。

### 🏃 忽视型
**体验**：忽视身体的需求；经常熬夜/久坐/饮食不规律；把身体当成"工具"。
**底层**：养护力缺失——把身体当成工具。
**你的路线**：[第十一章 身体养护](Ch11_身体养护.md) → [第六章 身体急救箱](Ch06_身体急救箱.md) → [第十九章 日常的身体](Ch19_日常的身体.md)。

### 🔍 过度型
**体验**：过度关注身体；对身体的每一个信号都过度反应；经常担心身体出问题。
**底层**：感知力过度——对身体的过度警觉。
**你的路线**：[第九章 身体感知](Ch09_身体感知.md) → [《平静之书》第十二章](../bop/Ch12_Cognitive_Tools.md)（认知重构）→ [第六章 身体急救箱](Ch06_身体急救箱.md)。

### 🌊 分离型
**体验**：与身体分离；感觉"我不是我的身体"；身体只是"载体"。
**底层**：感知力缺失——与身体分离。
**你的路线**：[第九章 身体感知](Ch09_身体感知.md) → [第十三章 身体与情绪](Ch13_身体与情绪.md) → [第十四章 身体与创伤](Ch14_身体与创伤.md)。

### 💔 创伤型
**体验**：身体记得创伤；身体经常感到紧张/疼痛/不适；身体对某些触碰/场景过度反应。
**底层**：创伤——身体记得创伤。
**你的路线**：[第十四章 身体与创伤](Ch14_身体与创伤.md) → [第 22 章 身体的阴影与求助](Ch22_身体的阴影与求助.md) → [《平静之书》第二十二章](../bop/Ch22_When_To_Seek_Help.md)。

- 四维审计：**感知/接纳/养护/表达**各 5 信号，命中 3+ 即缺失。
- 六型身体失联模式：**麻木、羞耻、忽视、过度、分离、创伤**——每型自带修炼路线。
- 一次补一维；急救箱（第 6 章）人人先学。
