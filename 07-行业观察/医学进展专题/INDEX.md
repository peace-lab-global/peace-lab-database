# 医学进展 专题

> 聚焦身心灵 / 心理健康 / 精神医学 / 神经科学领域的**最新临床研究、数字疗法、循证医学进展**。
>
> 与「APP 专题」「自媒体 专题」「咨询平台 专题」相对:本专题关注**临床证据**与**研究范式**——哪些方法被验证、哪些假设被推翻、哪些新方向被开拓。

## 收录标准

1. **临床/学术发表**:发表于同行评审期刊(npj Digital Medicine、Lancet Psychiatry、JAMA Psychiatry、Nature Mental Health 等),或重要学术会议(APA、ACNP、ECNP、WPA)
2. **有可识别的研究设计**:RCT > 队列研究 > 病例对照 > 横断面 > 案例报告
3. **样本量与效应量可考**:n=多少,效应量 Cohen's d / OR / HR
4. **影响范围**:可能改变临床实践、监管决策、或公众认知
5. **同一研究方向的多项研究**合并为 1 篇专题(系统综述/Meta-analysis 优先),后续更新写在同一专题内

## 候选研究方向

### 数字疗法(Digital Therapeutics, DTx)

- 暂停实验室 npj Digital Medicine 验证(2024-2025,中度以上焦虑抑郁效应量 1.41/1.33)
- Wysa / Woebot / SilverCloud / Headspace Health / Modern Health 等 RCT 汇总
- FDA 数字疗法审批:1200+ AI 医疗器械已授权,**心理健康 0 授权**(2026 现状)
- EMA 数字疗法审批
- 中国 NMPA 数字疗法审批

### 精准精神病学(Precision Psychiatry / P4 Medicine)

- 抑郁症分型新框架:DSM-5 之外的炎症型 / 谷氨酸型 / HPA 轴型 / 昼夜节律型
- 数字生物标志物(Digital Biomarkers):语音/打字/睡眠/HRV 模式
- 治疗反应预测模型:谁适合 CBT、谁适合 SSRI、谁适合 rTMS
- 微生物组-肠-脑轴(MGB Axis)与抑郁
- 神经炎症标志物(CRP、IL-6)与抑郁治疗反应

### 神经科学与冥想/正念的交叉

- 8 周 MBSR 对大脑结构/功能的影响(MRI 研究)— 已收录
- 默认模式网络(DMN)与正念
- 迷走神经与正念
- 长期冥想者大脑结构差异
- 神经反馈(neurofeedback)与正念

### 精神疾病新机制

- 抑郁症的谷氨酸/GABA 失衡
- PTSD 的恐惧回路与再固化(reconsolidation)
- 焦虑症的杏仁核-前额叶连接异常
- 强迫症的 CSTC 回路
- 双相情感障碍的昼夜节律紊乱

### 新治疗手段

- 氯胺酮/Esketamine 治疗难治性抑郁
- rTMS / TBS / iTBS 经颅磁刺激— 已收录
- 裸盖菇素(Psilocybin)与 MDMA 治疗 PTSD 的临床试验
- ECT(电休克治疗)的现代改良
- 迷走神经刺激(VNS)与深部脑刺激(DBS)
- 数字疗法(software as medicine)
- 微生物组移植(FMT)与抑郁
