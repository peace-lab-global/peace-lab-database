# 双相情感障碍行业全景 2026:流行病学、机制、治疗、锂盐金标准与政策

## 一句话

> **双相情感障碍(BD)** 是全球**2.0% 终生患病率**的慢性、严重精神障碍,WHO ICD-11 分 I 型、II 型、环性心境,**锂盐**是 70 年金标准(降低自杀风险 50%+),**WHO/NICE/APA 一线推荐**锂盐、丙戊酸盐、卡马西平、拉莫三嗪,**自杀风险 20-25 倍**于普通人群,中国《精神卫生诊疗规范 2020》全面纳入,**12356 热线 + 危机干预**是关键。

---

## 1. 信号(为什么 2026 年值得专题记录)

1. **全球 2.0% 终生患病率**:约 **1.2 亿患者**,与单相抑郁人数**接近**。
2. **误诊率高**:首次发作常被误诊为「**单相抑郁**」,平均误诊 **6-10 年**。
3. **自杀风险极高**:BD 患者自杀风险**20-25 倍**于普通人群,15-20% BD 患者**自杀死亡**。
4. **锂盐金标准**:70 年循证,降低自杀风险 50%+,但**全球使用率下降**。
5. **DSM-5 修订**:**混合特征**(mixed features) 成为新维度。
6. **中国 2020 版诊疗规范**全面纳入,需 **12356 热线**危机转介。

## 4. 机制:神经生物学与遗传

### 4.1 神经生物学机制

```
遗传 + 环境
   ↓
神经递质失调
   ├─ 5-HT(血清素)
   ├─ DA(多巴胺)
   ├─ NE(去甲肾上腺素)
   └─ GABA / 谷氨酸
   ↓
神经环路异常
   ├─ 前额叶(PFC)调节不足
   ├─ 杏仁核过度激活
   ├─ 纹状体异常
   └─ 昼夜节律异常(关键)
   ↓
BD 发作
```

### 4.2 关键脑区/网络变化

| 脑区/网络 | 变化 | 与 BD 症状关系 |
|---|---|---|
| **前额叶(PFC)** | 体积减少 | 情绪调节不足 |
| **杏仁核** | 体积/激活异常 | 情绪反应过度 |
| **基底节** | 异常 | 运动调节(躁狂) |
| **海马** | 体积减少 | 认知 |
| **昼夜节律系统** | 失调 | 睡眠-觉醒周期 |
| **HPA 轴** | 失调 | 应激反应 |
| **线粒体** | 功能异常 | 能量代谢 |
| **炎症系统** | 异常 | 神经炎症 |

### 4.3 遗传学

- **遗传度**:60-80%
- **多基因**:GWAS 鉴定 30+ 风险位点
- **关键基因**:**CACNA1C**(钙通道)、**ANK3**(钠通道)、**CLOCK**(昼夜节律)
- **家族聚集**:BD 一级亲属风险 7-10 倍
- **共享遗传** 与单相抑郁、精神分裂症部分共享

### 4.4 触发因素

- **睡眠剥夺**(关键,躁狂触发)
- **时差/倒班**
- **药物**(兴奋剂、皮质激素)
- **分娩后**
- **创伤、压力**
- **季节**(部分患者冬季抑郁、夏季躁狂)

## 5. 诊断:DSM-5-TR 与 ICD-11

### 5.1 BD I 型(躁狂 + 抑郁)

```
躁狂发作(M):
A. 1 周以上(任何时间住院)异常持续高涨、扩张、易激惹情绪
B. 活动增多 + 3 项以上(话语多、意念飘忽、自尊膨胀、
   睡眠需求减少、思维奔逸、注意力分散、目标行为过度、
   参与危险活动)
C. 严重功能损害,或需住院,或伴精神病性症状

抑郁发作(D):
9 项中 ≥ 5 项,2 周以上,包含抑郁心境或快感缺失
```

### 5.2 BD II 型(轻躁狂 + 抑郁)

```
轻躁狂 + 抑郁(无躁狂)
轻躁狂:4 天以上(无住院),症状同躁狂但轻
```

### 5.3 环性心境(Cyclothymia)

```
2 年以上多种轻躁狂 + 轻抑郁症状
(不符合 BD 标准)
```

### 5.4 DSM-5 新维度:混合特征(Mixed Features)

- 躁狂/轻躁狂 + **3 项以上抑郁症状**
- 抑郁 + **3 项以上躁狂症状**
- 反映**情绪不稳定** 而非**单一情绪**
- 治疗需**调整**(避免抗抑郁药单独使用)

### 5.5 评估量表

- **YMRS**(Young Mania Rating Scale):11 项,他评
- **MADRS**(Montgomery-Åsberg Depression Rating Scale)
- **HAMD-17**
- **PHQ-9**(自评抑郁)
- **ASRM**(Altman Self-Rating Mania Scale):自评
- **MDQ**(Mood Disorder Questionnaire)

### 5.6 鉴别诊断

- **BD vs 单相抑郁**:首次**抑郁**发作难鉴别,需**长期随访**
- **BD vs 边缘型人格障碍(BPD)**:BD 有**情绪发作**,BPD 是**人际关系紊乱**
- **BD vs ADHD**:儿童/青少年 BD 易被误诊为 ADHD
- **BD vs 物质使用**:物质使用可触发**类躁狂**
- **BD vs 精神分裂症**:**共病** 常见

## 6. 治疗:WHO/NICE/APA 一线

### 6.1 锂盐:70 年金标准

| 维度 | 内容 |
|---|---|
| 适用 | BD I/II,急性躁狂,维持治疗,**降低自杀风险 50%+** |
| 剂量 | 急性 1200-1800 mg/天,维持 900-1200 mg/天 |
| 血药浓度 | 0.6-1.2 mEq/L(急性 0.8-1.2,维持 0.6-0.8) |
| 监测 | 血锂浓度 + 甲状腺 + 肾 |
| 优势 | **唯一降低自杀** + 维持效果 + 长期循证 |
| 局限 | **副作用多**(震颤、体重、甲状腺、肾)、治疗指数低、**依从性差** |
| 中国 | 70 年代起,仍是主流 |

### 6.2 情感稳定剂与抗精神病药

| 药物 | 适应证 | 备注 |
|---|---|---|
| **丙戊酸盐**(Sodium Valproate) | 躁狂、混合、维持 | 中国使用最广 |
| **卡马西平**(Carbamazepine) | 躁狂 | 二线 |
| **拉莫三嗪**(Lamotrigine) | 抑郁相、维持 | 预防抑郁相 |
| **喹硫平**(Quetiapine) | 躁狂、抑郁、维持 | 一线 |
| **奥氮平**(Olanzapine) | 躁狂、维持 | 联合氟西汀治疗 BD 抑郁 |
| **利培酮**(Risperidone) | 躁狂 | 一线 |
| **阿立哌唑**(Aripiprazole) | 躁狂、维持 | 一线 |
| **卡利拉嗪**(Cariprazine) | 躁狂、混合 | 2020 中国上市,新型 |
| **Lumateperone**(Caplyta) | 抑郁相 | 2020 FDA,2024 中国探索 |

### 6.3 治疗方案

#### 6.3.1 急性躁狂

```
一线:锂盐 + 抗精神病药(喹硫平、奥氮平、利培酮)
二线:丙戊酸盐
严重:ECT(电休克)快速起效
```

#### 6.3.2 急性双相抑郁

```
一线:喹硫平(单药或联合)
一线:鲁拉西酮(Lurasidone)
二线:锂盐 / 拉莫三嗪
二线:奥氮平 + 氟西汀(联合)
避免:抗抑郁药单独使用(触发躁狂)
```

#### 6.3.3 维持治疗

```
一线:锂盐(长期最佳)
二线:丙戊酸盐、拉莫三嗪、喹硫平、阿立哌唑
关键: 持续 1-2 年,部分患者**终身**
```

### 6.4 心理治疗

- **CBT(认知行为治疗)**:稳定期辅助
- **IPT(人际心理治疗)**:稳定期辅助
- **FFT(家庭聚焦治疗)**:减少复发
- **PSYCHOED(心理教育)**:提高依从性
- **群组心理教育**:BD 群组(Colom 模式)
- **MBSR/ACT**:稳定期辅助(避免触发躁狂)

### 6.5 神经调控

- **ECT(电休克)**:严重躁狂、抑郁、自杀,**快速起效**(1-2 周)
- **rTMS**:BD 抑郁相探索
- **DBS**:探索中(难治性)
- **迷幻药**:psilocybin、ketamine 探索

## 7. 锂盐的当代挑战

### 7.1 使用率下降

- **1990s 锂盐** 80%+ BD 患者
- **2020s 锂盐** 30-40% BD 患者(部分国家)
- **原因**:新药(丙戊酸盐、喹硫平等)替代、监测繁琐、副作用、依从性差

### 7.2 不可替代性

- **唯一降低自杀风险 50%+**
- **维持治疗** 长期循证最强
- **2020+ 回归**:**锂盐 + 喹硫平** 联合治疗证据增强
- **NICE 2020**:**重新** 推荐锂盐为一线

### 7.3 监测

- 血锂浓度(每 3-6 月)
- 甲状腺功能
- 肾功能
- 体重、血糖
- 心电图(老年)

## 10. 风险与边界

### 10.1 误诊与漏诊
- **首次** 常误诊为**单相抑郁**(40-60%)
- 抗抑郁药**单独使用**可触发**躁狂/快速循环**
- **混合特征** 误诊为「**焦虑**」「**易激惹**」

### 10.2 自杀风险
- **20-25 倍** 普通人群
- **15-20% 终身自杀死亡**
- 锂盐**降低** 50%+
- **12356 热线** 关键

### 10.3 依从性差
- 维持治疗**1-2 年** 依从率 50-60%
- 锂盐**副作用** 复杂
- 自行停药**复发率高**
- 心理教育**关键**

### 10.4 妊娠与生育
- **丙戊酸盐** 致畸(神经管缺陷)
- **锂盐** 致畸(心血管)
- **卡马西平** 致畸
- **拉莫三嗪** 较安全
- 妊娠期 BD 治疗**复杂**

### 10.5 共病
- **焦虑** 50%+
- **物质使用** 40%+
- **代谢综合征**(药物副作用)

### 10.6 跨文化挑战
- 西方疗法**本土化**挑战
- 「**躁狂**」中国文化敏感性
- 「**家族聚集**」中国家族文化

## 13. 编者按

双相情感障碍(BD)是**全球 1.2 亿患者**的严重精神障碍,**自杀风险 20-25 倍**于普通人群。**锂盐**是 70 年金标准,**降低自杀风险 50%+**,但**全球使用率下降**。新型药物(Cariprazine、Lumateperone)和联合治疗(锂盐+喹硫平)持续推进。**WHO/NICE/APA 一线推荐**药物 + 心理治疗 + ECT 整合方案。中国《精神卫生诊疗规范 2020》全面纳入,但**误诊率高(常被误诊为单相抑郁)**仍是挑战。

**关键判断**:
- **锂盐** 不可替代,**NICE 2020 重新推荐一线**
- **首次**常误诊为**单相抑郁**,长期随访**关键**
- **混合特征** 是新维度
- **自杀预防** 是核心目标
- **ECT** 是**严重**病例**快速起效**选择

> 建议:出现**情绪不稳定**(高与低反复)、**睡眠需求减少**、**易激惹**等持续症状,请到三甲医院精神科评估。**避免**抗抑郁药**单独使用**(可能触发躁狂)。**危机事件**请直接拨打 12356 心理援助热线。**维持治疗** 1-2 年依从性**关键**。
