# 政策 专题

> 聚焦身心灵 / 心理健康 / AI 情感陪伴 / 数字干预 / 神经医学领域的**国家与地方级政策法规**深度专题。
>
> **基础设施视角**:政策不是抽象条文,是身心灵赛道的"地基"——决定哪些产品能上线、哪些服务能开张、哪些人群被保护、哪些红线不能碰。

## 收录标准

1. **发文主体**:中共中央、国务院、部委(网信办、卫健委、教育部、工信部、市监总局、公安部、发改委等),或省级党政机关
2. **关联赛道**:身心灵、心理健康、AI 情感陪伴、数字干预、AI 医疗器械、精神卫生、神经医学、冥想/正念、心理热线、危机干预
3. **影响范围**:全国性或示范省(直辖市/自治区)级,具备"立竿见影"的行业影响
4. **发文形式**:法律、行政法规、部门规章、规范性文件、专项行动方案、热线/平台开通通知
5. **同一政策的多个版本**(草案、征求意见稿、正式发布、实施细则、修订)合并为 1 篇专题,后续更新写在同一专题内

## 政策研究方法学(本站约定)

1. **政策原文链接必给**:每条专题必给官方原文(政府网站、官微),二手解读次之
2. **时间线完整**:草案 → 征求意见 → 正式发布 → 施行 → 修订,完整记录
3. **影响范围量化**:覆盖人群、覆盖企业、影响市场规模(可估算)
4. **国内外对照**:同类政策在国际的对照(欧盟 AI Act、加州 SB 243、WHO 建议等)
5. **风险与边界**:不仅讲政策利好,也讲合规成本、灰色地带
