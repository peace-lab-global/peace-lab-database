# 简单心理(Jiandan Xinli)— 中国专业心理咨询平台代表

> **一句话**:中国心理咨询行业**最严格的咨询师甄选**(3% 通过率)+ **最大的中立平台**(2000+ 咨询师,147 城市,350 万+ 人次)+ **Uni 培训生态**,把"专业主义"做成护城河。
>
> **信号**:中国心理咨询服务从"流量"时代进入"专业"时代,**严选 + 培训 + 督导 + 转介**四位一体的平台成为新标杆。

---

## 0. 为什么这件事值得专题

国内心理咨询行业长期存在三大问题:
1. **鱼龙混杂**:有证就能上岗,质量无保障
2. **价格不透明**:300-1500 元/次,差异巨大
3. **匹配效率低**:用户不知道选谁,咨询师不知道来哪

简单心理 2014 年起,以**APA 标准 + 3% 通过率 + 持续督导**为核心,把"专业主义"做成单一平台的最大护城河,十一年间累计服务 **350 万人次**,汇聚 **2000+ 咨询师**(全球 147 城市),运营 **460 万+ 分钟免费热线**。

它与壹心理、KnowYourself 的"内容/社区驱动"路径不同——简单心理是**典型的"严选服务驱动"平台**。

## 3. 核心模式:严选 + 培训 + 督导 + 转介

### 3.1 咨询师甄选(3% 通过率)

**参考美国心理学会(APA)标准**,严选要求:

| 维度 | 标准 |
|------|------|
| 学历 | 100% 接受过美国或欧洲系统专业训练(国际标准) |
| 经验 | 100% 长期接受个人/团体督导,数百小时个人分析 |
| 伦理 | 100% 专业伦理保障 |
| 实习/督导 | 持续接受专业督导 |
| 入驻后 | 持续监管 + 持续培训 |

> 与壹心理"2% 严选率"对比:两者都属国内最严。简单心理更强调"国际标准 + 海外训练",壹心理更强调"国内严选 + 学历 + 行业经验"。

### 3.2 服务模式

**三种形式**:

1. **面对面咨询**(线下)
   - 50-90 分钟专业心理咨询
   - 保护心理咨询的专业设定
2. **视频咨询**(线上)
   - 50-90 分钟专业心理咨询
   - 灵活、隐私、可跨城市
3. **AI 咨询助理**(24 小时)
   - 基于专业模型构建
   - 及时提供心理支持

### 3.3 服务流程

```
注册 → 心理评估(自评量表 + 1v1 访谈)
   ↓
咨询匹配(根据评估推荐适合的咨询师)
   ↓
首次咨询(50-90 分钟,签订服务协议)
   ↓
长程咨询(4-26 次,平均)
   ↓
效果评估 + 复发预防
```

### 3.4 转介机制

- 简单森林(线下)与三甲医院/精神专科医院合作
- 精神科医生 + 心理咨询师双轨
- 危机转介 12356 + 当地精神卫生中心

| 适用 | 怀疑需要药物辅助 / 已被诊断 / 中重度困扰 |
| 价值 | 与心理咨询形成"诊断-治疗-心理"闭环 |

## 5. 商业模式

### 5.1 营收结构

| 业务 | 占比(估) | 单价 |
|------|----------|------|
| 心理咨询(线上) | ~50% | 300-800 元/次 |
| 心理咨询(线下) | ~20% | 500-1500 元/次 |
| 简单森林(线下) | ~10% | 套餐制 |
| 心理课程 | ~10% | 99-1999 元 |
| 简单心理 Uni(培训) | ~5% | 数千-数万元 |
| 免费热线 + AI 咨询助理 | 流量入口 | 0 元 |

### 5.2 商业逻辑

1. **严选是核心壁垒**:3% 通过率 = 高质量 = 高溢价 = 高续费
2. **培训是补充壁垒**:Uni 培养未来咨询师,扩大供给
3. **AI + 热线是漏斗**:降低获客成本
4. **线下中心是高端**:高客单价,补足线上无法覆盖的场景
5. **精神科顾问是闭环**:中重度需求不会流失到医院

## 8. 行业意义

### 8.1 把"专业"做成护城河

- 国内心理咨询行业长期被"无标准、无监管、无保障"困扰
- 简单心理 11 年坚持"3% 通过率 + 持续督导 + APA 标准"
- 在壹心理/KnowYourself 等"流量派"外,走出"专业派"路径
- 这种坚持**短期内慢,长期是护城河**

### 8.2 培训-服务闭环

- 简单心理 Uni 培养咨询师
- 培养出的咨询师入驻简单心理
- 入驻咨询师在平台上累积经验
- 经验丰富的咨询师反过来指导 Uni 学员
- **形成正向飞轮**

### 8.3 行业基础设施

- 460 万+ 分钟免费热线 = 中国心理服务基础设施的一部分
- 2000+ 咨询师池 = 中国最大的中立咨询师网络之一
- Uni 培训 = 中国咨询师职业化的重要推手

### 8.4 与国家政策的协同

- 12356 国家热线(2025-05)开通后,简单心理的免费热线做"长尾补充"
- 网信办 拟人化办法(2026-07)下,简单心理 AI 咨询助理做"高门槛内产品,合规可期"
- 国家"儿科和精神卫生服务年"(2025-2027)下,简单心理的儿童青少年/家庭治疗有政策红利

## 9. 风险与边界

### 9.1 严选 = 增长慢

- 3% 通过率意味着每年新增咨询师数量有限
- 中长尾用户可能因"匹配不到合适的咨询师"流失
- 平台规模扩张速度低于"流量派"

### 9.2 价格 = 用户门槛

- 300-1000 元/次仍属中高价
- 大量潜在用户被价格挡在门外
- **12356 + 鲸鱼 Alice 等免费工具的兴起,可能蚕食中低付费意愿用户**

### 9.3 国际标准 vs 本土化

- "100% 接受过美国或欧洲系统专业训练"是双刃剑
- 一方面:质量有保障
- 另一方面:本土化(中国文化、家庭、关系)适配挑战

### 9.4 监管风险

- 网信办 拟人化办法(2026-07)下,AI 咨询助理需评估
- 精神科医生在线问诊需互联网医院资质
- 危机干预后转介机制需符合伦理

### 9.5 资本可持续性

- 简单心理未公开完整融资历史
- 平台模式盈利周期长
- 与"流量派"竞争需要持续投入

## 11. 给不同主体的启示

### 11.1 对创业者

1. **专业壁垒 > 流量壁垒**:在鱼龙混杂的行业,严选本身就是护城河
2. **培训-服务闭环**:从培训到服务,飞轮飞起来
3. **AI 不替代人,而是补足人**:AI 咨询助理是入口,真人咨询是核心

### 11.2 对咨询师

1. **平台比独立执业更有"基础设施"价值**:督导、危机转介、品牌信用
2. **持续督导是底线**:100% 接受督导不是装饰
3. **本土化训练** + 国际标准 = 长期竞争力

### 11.3 对用户

1. 简理心理咨询是**专业派代表**,质量有保障
2. 适合:愿意为质量付费、追求长程深度干预
3. 不适合:急性危机(请用 12356)、只想要"轻倾诉"(鲸鱼 Alice 等免费工具更合适)

### 11.4 对政策制定者

1. **简理心模式可作为"高质量心理咨询平台"标准参考**
2. **国家"儿科和精神卫生服务年"可与简单森林等线下中心合作**
3. **简单心理 Uni 模式可作为"咨询师职业化"国家认证参考**
