# 工具 专题

> 聚焦身心灵 / 心理健康领域的**轻量级工具**:心理援助热线、自测量表、危机干预工具、自助小工具。
>
> 与「APP 专题」「自媒体 专题」「咨询平台 专题」相对:本专题关注**单点式工具**——可以一次使用、立即反馈、解决具体问题。

## 收录标准

1. **轻量级**:不是综合 App 或综合平台,而是单一功能 / 单一工具
2. **可独立使用**:不需要长期订阅,不需要完整服务链
3. **可识别功能**:心理热线、量表(焦虑/抑郁/PTSD/睡眠等)、危机干预、单次练习工具、筛查工具
4. **可获取**:有公开访问路径(电话、App、小程序、网页、PDF)
5. **同一工具的多次更新**合并为 1 篇专题,后续更新写在同一专题内
