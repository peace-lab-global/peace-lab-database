# 自媒体 专题

> 聚焦以 **自媒体 / 内容生态** 为核心驱动的心理 / 身心灵品牌深度专题。
>
> 与「APP 专题」相对:本专题关注**无 App、靠自媒体获客**的产品(如暂停实验室、KnowYourself、武志红、Lachel 等);
> 「APP 专题」关注**自有 App / 平台**驱动的产品(如壹心理、Calm、Headspace、Wysa)。

## 收录标准

1. **核心载体不是 App**:无独立 App,或 App 仅作为辅助
2. **核心获客渠道是自媒体**:微信公众号、微博、知乎、哔哩哔哩、小红书、播客、抖音、视频号
3. **核心交付有结构化形态**:21 天行动营、训练营、系列课、训练手册等
4. **循证基础可考**:背后有 APA 推荐方法(CBT/ACT/MBCT/MBSR/CBT-I 等)或严肃心理学科普
5. **有可考的数据披露**:用户量、改善率、留存率、复购率、融资等
