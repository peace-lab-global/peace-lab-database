# 第五章 · 平静审计

> 上一部你理解了平静，这一部来回答更具体的问题：**你的**平静，是从哪里漏掉的？
> 审计只需 15 分钟，但它会把后面二十章变成一份为你定制的地图。

---

## 5.1 六维平静审计

对以下六个维度逐一自评。每个维度 5 个信号，数一数你命中几条（答案凭最近两周的常态，不凭某一天）。

### 维度一：身体

- [ ] 早晨醒来不解乏，像没睡过
- [ ] 肩颈/下颌/胃部长期紧绷，自己能摸到"结"
- [ ] 呼吸浅，常停留在胸口，有时需要刻意深吸一口气
- [ ] 一天里没有一刻身体是"松"的
- [ ] 生病恢复变慢，或常有说不清的小毛病（头痛、肠胃、皮疹）

**命中 3 条以上** → 身体层泄漏明显，优先读：[第九章 身体地基](Ch09_Body_Foundation.md)、[第八章 晚间卸载与睡眠](Ch08_Evening_Offload.md)。

### 维度二：心智

- [ ] 工作时反复解锁手机，一段专注很少超过 15 分钟
- [ ] 夜里躺下，大脑自动播放白天的画面与对话
- [ ] 读一页书/一份文档，读完了不记得内容
- [ ] 同时开着一堆窗口/任务，哪件都推不动
- [ ] 常常"人在这里，心在别处"

**命中 3 条以上** → 心智层泄漏明显，优先读：[第十章 数字卫生](Ch10_Digital_Hygiene.md)、[第十一章 冥想最小可行练习](Ch11_Meditation_Practice.md)。

### 维度三：情绪

- [ ] 小事就能点炸（堵车、一条消息的语气）
- [ ] 情绪来了以后，很久都缓不过来（半天以上）
- [ ] 说不清自己在感受什么，只有一个笼统的"烦"
- [ ] 用刷手机/吃/买东西/酒精来"处理"情绪
- [ ] 偶尔会有突然的心慌、胸闷，像惊吓

**命中 3 条以上** → 情绪层泄漏明显，优先读：[第十四章 情绪炼金术](Ch14_Emotional_Alchemy.md)、[第六章 90 秒急救箱](Ch06_First_Aid_Toolkit.md)。
⚠️ 若"心慌胸闷"频繁发作，或情绪低落已持续两周以上且影响工作生活，请先读[第 22 章 何时求助](Ch22_When_To_Seek_Help.md)。

### 维度四：关系

- [ ] 说不上"能说真话的人"（工作烦恼无人可讲）
- [ ] 有的人一出现/一发消息，你的身体就先紧起来
- [ ] 冲突后反复回想、自责或生闷气，超过一天
- [ ] 你是团队/家庭里那个"必须稳住"的人，不敢暴露脆弱
- [ ] 周末宁愿刷手机也不想约人，但独处又空虚

**命中 3 条以上** → 关系层泄漏明显，优先读：[第十九章 关系中的平静](Ch19_Relationships_Peace.md)、[第十三章 与内在批评者和解](Ch13_Self_Compassion.md)。

### 维度五：环境

- [ ] 通知永远开着，红点不清理就难受
- [ ] 工位/房间杂乱，找不到"能深呼吸的角落"
- [ ] 一周里几乎没有户外/自然接触
- [ ] 通勤时间全耗在刷屏上，到公司/到家时更累
- [ ] 卧室里手机就在枕边充电

**命中 3 条以上** → 环境层泄漏明显，优先读：[第二十章 环境即心境](Ch20_Environment_Design.md)、[第十章 数字卫生](Ch10_Digital_Hygiene.md)。

### 维度六：意义

- [ ] 说不清"这份工作除了薪水还为了什么"
- [ ] 周日傍晚开始出现规律性低落
- [ ] 完成目标后没有满足感，只有"下一个"的疲惫
- [ ] 长期做着自己不认同的事，或用"没时间"推迟真正想做的事
- [ ] 感觉自己在"过别人期待的人生"

**命中 3 条以上** → 意义层泄漏明显，优先读：[第十五章 价值观与边界](Ch15_Values_And_Boundaries.md)、[第十八章 意义与工作](Ch18_Meaning_And_Work.md)。

## 5.2 主导扰动模式：你是哪一型？

六个维度找的是"哪里漏"，六型找的是"怎么漏"。多数人会认领一到两型。读下面的描述，圈出最像你的那一型。

### 🌀 反刍型

**典型体验**：深夜重播白天的会议、三年前的尴尬、说错的那句话；一件事结束后，脑子仍在"复盘"里加班。
**底层机制**：大脑试图靠"反复想"获得控制感，但反刍不产生新信息，只产生新焦虑（第二支箭的标准生产线）。
**你的路线**：[第十一章 冥想](Ch11_Meditation_Practice.md)（练"注意到并回来"）→ [第十四章 情绪炼金术](Ch14_Emotional_Alchemy.md)（书写外化）→ [第八章 晚间卸载](Ch08_Evening_Offload.md)（担忧时间）。

### 🔮 灾难型

**典型体验**：一封"在吗"就能脑补出一场裁员；没发生的事先在想象里演练三遍最坏版本；体检报告没出先查骨灰级病症。
**底层机制**：威胁系统把"可能性"当"预告片"循环播放，用预演换取虚幻的准备感。
**你的路线**：[第十七章 接纳与不确定](Ch17_Acceptance_Uncertainty.md)（概率校准 + 控制三层）→ [第十二章 认知工具箱](Ch12_Cognitive_Tools.md)（灾难化反驳）→ [第六章 急救箱](Ch06_First_Aid_Toolkit.md)（浪来时的锚）。

### ⚖️ 自我批评型

**典型体验**：内心住着一个永不满意的法官："这都不行？""别人怎么就行？"；成功归运气，失败归自己；对别人宽容，对自己严苛。
**底层机制**：把幼年/早期内化的批评声音当成了"客观自评"，误以为不骂自己就会退步。
**你的路线**：[第十三章 与内在批评者和解](Ch13_Self_Compassion.md)（全书为你而写的一章）→ [第十四章 情绪炼金术](Ch14_Emotional_Alchemy.md)（识别羞耻的嗓音）。

### 📱 麻木型

**典型体验**：不觉得特别痛苦，也不觉得特别活着；下班只想瘫着刷手机，一刷两小时；对原本喜欢的事提不起劲。
**底层机制**：长期超载后系统降档运行（背侧迷走"断电档"，见[第三章](Ch03_The_Science_Of_Calm.md)），用低刺激麻痹回避高刺激消耗。
**你的路线**：[第九章 身体地基](Ch09_Body_Foundation.md)（温和激活：光照、走路、冷水）→ [第二十章 环境即心境](Ch20_Environment_Design.md)（自然剂量）→ [第十八章 意义与工作](Ch18_Meaning_And_Work.md)。
⚠️ 若"提不起劲"已持续两周以上并影响功能，这不是懒，请读[第 22 章](Ch22_When_To_Seek_Help.md)。

### 🐫 过载型

**典型体验**：不会说不；日历满到没有空白；谁的请求都接，自己的事永远排在最后；疲惫但停不下来。
**底层机制**：用"被需要"换取安全感和价值感，把边界当成了危险品。
**你的路线**：[第十五章 价值观与边界](Ch15_Values_And_Boundaries.md)（说不的艺术，全书为你而写的一章）→ [第二十一章 个人平静系统](Ch21_Personal_Peace_System.md)（平静预算）。

### 🏝️ 孤立型

**典型体验**：压力全自己扛，"说了也没用"；朋友圈很大，深夜想说话却翻不出一个名字；报喜不报忧成了本能。
**底层机制**：把脆弱等同于负担别人，把孤立误认成坚强；而神经系统恰恰需要"安全的连接"才能回落（迷走神经的社会参与系统）。
**你的路线**：[第十九章 关系中的平静](Ch19_Relationships_Peace.md)（建立你的平静支持系统）→ [第十三章 自我关怀](Ch13_Self_Compassion.md)（共同人性：你不是唯一这样熬着的人）。

## 5.3 你的定制阅读地图

完成审计后，写下三样东西（建议真的写在本子上，而不是想想而已）：

```
我的平静审计（日期：____）
1. 泄漏最多的维度：____ / 6
2. 我的主导模式：____ 型（次要：____ 型）
3. 未来四周我的三本"必读章"：
   第一周读：第__章 ________
   第二周读：第__章 ________
   第三周读：第__章 ________
```

**两条使用规则：**

1. **一次只改一个维度。** 六维全开的新手计划，存活率接近于零。先攻你最痛的那一维。
2. **急救箱人人先学。** 无论哪型，[第六章 90 秒急救箱](Ch06_First_Aid_Toolkit.md)都是所有人的第一课——就像学游泳先学漂浮，不是先学泳姿。
